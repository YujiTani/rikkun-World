## 色と すけ

- 色: 白〜うす水色 3（W1 `#F4FCFF`・W2 `#CDEFFC`・B1 `#8FD6F2`）＋ にじ 5（`#FF8C94` `#FFE585` `#86EBA8` `#82C6FF` `#C79CFF`。虹の アイコンと 同じ）＝ **8 色**。（オーナー確認待ち: DESIGN 18.5「エフェクト 1 つ 5 色」を こえる。にじ 5 色は 仕様 §5.3 が 求める ので 別あつかい に したい）
- 半透明の だん（`stats()` の semi-alpha）: **4 だん**（alpha 48・96・160・230）。つなぎ目は あみ（ディザ）。core・dome・ring の 3 まいの みで、band・rainbow・spark は 不透明（band は グレー 3 だん〔#000・#969696・#EBEBEB〕の かたち）。
- core: まん中 alpha 160〜230（白で ぬりつぶさない。体が 見える）。外へ あみで 0。
- dome: 中（半径 22 点 = 47%）は ほとんど 0（まばらな あみ 1/16 だけ alpha 48）→ 22〜26 点で ふちへ → ふち 6 点（= 1.3 ブロック）が 明るい（alpha 96 → 160 → 230）。**ふちの 内がわ（半径 26 点）の 平均 alpha = 6.7%（93% すける）**・そのうち 69% の 点は alpha 0。左上の ふちが 少し 明るい（光は 左上から）。
- ring: 外の 3 点が いちばん 明るい（alpha 230）・内へ 160・あみで 薄く・内がわに 16 本の 小さな めもり。

## 出る・消える（点滅なし）

- 全部の 部品の 明るさ = `opacity` を **うかぶ 40 ステップで 0 → 1、おりる 40 ステップで 1 → 0 の 1 回ずつ だけ**。とどまる 160 ステップの 間は 一定（帯の `offset` と かけらの 動きだけ 動く）。
- 大きさ s: うかぶで 0 → 1、おりるで 1 → 0（ゆっくり 始め ゆっくり 終わり の イーズ）。
- 一人称: 部品 1（まん中の 光 ＋ まく）は 出さない（`visible = false`）。2・3・4 は 出す。
- 「動きを へらす」: `offset` を 動かさない・かけらを 止める（動かさず 位置は 固定）。
- 点滅: なし。

- 1 点の 大きさ: dome = 14 ブロック ÷ 64 = 0.22 ブロック・ring = 12.8 ÷ 64 = 0.2・core = 3 ÷ 32 = 0.094・かけら 0.3 ÷ 8。**ドーム 用の 大きな 板 は 1 点 が 大きい**（PIPELINE 2.4 の 1/8 ブロック より 粗い。球の 大きさ 14 ブロック に 64 点 では こう なる）。（オーナー確認待ち）粗い と 感じたら dome・ring を 128×128 に して 作り なおせる（4096 以下 の まま・半透明 の だん 同じ）。
- つなぎ目の 注意: three の SphereGeometry の v は 上が 1。`flipY`・`offset` の 向きは 見た目で 直す。atlas の uv は dome = (0, 0)〜(64/96, 1)、core = (64/96, 0.5)〜(1, 1)（flipY = true の とき）。
