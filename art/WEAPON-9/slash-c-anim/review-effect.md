## 直す 所（具体）
1. 出す 時（観点 1・開発）: 今は techStart で 呼ぶ。けさは 出だし 28（2 段目 20）、きりあげ 19（12）、つき 4 なので、出だし − 2 ステップ（C1 の 決めが 当たりの 初日に 重なる）まで 待って 呼ぶ。待つ ステップ数は わざと 段で 表に する。
2. 決めの 長さ（観点 1・絵）: C1 の コマ 1（決め）5 ステップ → つき 2・きりあげ 3・けさ 6 に 合わせて、「決め」だけ わざごとに 2/3/5〜6 ステップに かえる（今は 1 とおり）。決めが 当たりより 長いと 当たらないのに 当たりに 見える。
3. はば（観点 1・絵）: うしろ・正面（scale 1.0）の「く」の はばを 57px → 約 46px（4.3 マス = けさの 弦 4.25）に する。または scale を 0.8 に して、真横 0.55 → 0.45。きりあげ用は 約 3.1 マス（約 33px）。
4. 3 段で 形を かえる（観点 3・5）: つき = 細い 水平の 一本線（高さ 6px 以内・白芯＋虹）／ きりあげ = 下から 上へ 立てた「/」の 弧（45° ±）／ けさ = 今の「く」（けさだけ 大きい 150°）。板は 1 まいの まま、texture を 3 行に ふやす（描画 回数・三角形は 同じ）。
5. 左右（観点 4）: 板は カメラに 向く ので 振った 向きが 画面の 右か 左か で 絵が 逆に なる。slashAngleDeg は 0〜180° で 符号が ない。左右の 符号（カメラから 見て 右へ 振る = +）を 足し、左へ 振る とき は 板を 左右 反転（centroid の x も 32 を 軸に 反転: x → 64 − x）。
6. 先の 光（観点 4）: 「く」の 左右の 先 3〜4px を 白 → 水色 → 虹の 2 色に して 1px の 点から 3〜4px の くさびに する。C2 の 星は かどでは なく 振った 先の はしに 移す（かどの 星は 刃の さきでは ない）。
7. 後半（観点 3）: コマ 2 の 網（うすい ふじ）を 半分の 点数に し、コマ 3 以降の 虹の 帯を 3 色 → 紫 1 色の 細線に 落として「もう 当たらない」を はっきり。残像の 色は 空と 同じ 明るさに ならないよう、夜用に 紺に 近い ふじ（#6b4fa0 など）の 点も 少し 混ぜる。
8. 暗い 下地（観点 2）: 紺の ふちを 1px → 白芯の 出る コマ（0）と 星の 周りだけ 2px に する。コマ 0 の 白だけの「く」は 空に とけるので 紺の ふちを 太く。C2 の コマ 0（1 ステップの 細い 線）は 2 ステップに するか 太さ 2px に する。
9. 前へ 進む（観点 4）: C1 は 消える 間に まん中が 右へ 54.7 まで 動く（OK）。ただし 右へ 動く 量は 刀の さきの 動き（けさ advance 3.1 マス）と 別。ゲーム内で 動かして 向きと 量を 確かめる。
10. ヒットの セット（観点 3・4・未確認）: この 案には 当たった 時の 火花・はじきの 絵が ない。斬撃の 決めの コマ（ステップ 3 ごろ）と 同じ 時に、虹 5 色の 細長い 火花 6〜8 つぶ（はじめ 速く → 遅く・角度・寿命に ばらつき）と、中央の 小さい 白い 光 1 つを 出す セットを 足す。はじきは 向き（振った 向き）に ひるむ ことを 確認。
