# 二つ名の出現音（BAL-G #115 / SND-BAL #114）

`appear_oyabun.mp3`・`appear_taisho.mp3`・`appear_nushi.mp3` は、版 B「しんぞう と おてらの かね」（オーナーが聞いて決めた物）を mp3（48kHz・ステレオ・128kbps）にした物です。音そのもの（長さ・音色・大きさ）は変えていません。聞こえる長さ（−20 dB まで）は 3.0・3.8・5.2 秒（重ねない時間）。

## 出どころ
- 太鼓・心臓・鐘の素材は **効果音ラボ** https://soundeffect-lab.info/sound/anime/ の 和太鼓（ドン・ドドン・カカッ）・心臓の鼓動・お寺の鐘 を加工した物です。
- 規約: 加工してゲームに入れてよい・商用可・クレジットは任意・**素材ファイルそのものの再配布はできない**。そのため このリポジトリには **加工後の mp3 3 つだけ** 入れ、元の素材（`samples/*.mp3`）は入れません。
- 尺八は 外の素材を使わず、コードで合成しました。

## 加工の方法（元: `v4/README.md`、作り直しは `build.py`。素材は リポジトリの外）
1. 48kHz・ステレオにして、いちばん大きい所をそろえる。
2. ドドンの 1 打目・心臓 1 拍などを切り出す（切り口は ふわっと消す）。
3. 音程を下げる（テープを遅くするのと同じやり方）。どーん = ドン（ふつう）＋ ドン（−5 半音）＋ ドン（−12 半音）＋ ドドンの 2 打目。
4. 心臓の ドクン…が だんだん速くなり、遠くの太鼓が近づいて どーん！＋ 低くした鐘の ゴーン。たいしょう・ヌシは 尺八（合成）が うなる。強いほど 低く・長く・楽器が増える。
5. 合成した お堂の響きを足し、ノートPC のスピーカーでも聞こえるよう 倍音を少し足す。
6. いちばん大きい 400ms を −14 LUFS にそろえ、ピークは −1 dBFS 以下（どれも −4.8 dB 以下）。
7. 書き出し: `ffmpeg -i B_appear_<名前>.wav -ar 48000 -ac 2 -c:a libmp3lame -b:a 128k appear_<名前>.mp3`

## 試聴
`listen.html`（開発サーバーで `/sound/nick/listen.html`）で 3 つを鳴らせます。ゲームの はじめの音量 0.5 で 鳴ります。
