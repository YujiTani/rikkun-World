# 明珍下駄の足音（issue #300）
- `geta_0.ogg`・`geta_1.ogg` = カラン、`geta_2.ogg`・`geta_3.ogg` = コロン。1 歩 約 0.24 秒、Vorbis モノ 48kHz。
- 出どころ: オーナー（yuzu）が えらんだ 効果音ラボ「下駄で走る」を、1 歩 ぶんずつ 切り出して 加工した もの（頭の 無音を 切る・短い フェード・大きさを そろえる）。効果音ラボの 規約に より、加工して ゲームに 入れて よいが 素材 そのものの 再配布は できないので、もとの mp3 は リポジトリに 入れない（共有フォルダ samurai-gear/sound/ に ある。作り方は そこの build.py と README.md）。
- 鳴らす 場面・音量・ゆらぎは `docs/design/SAMURAI-1.md` §3.3 と 調整表。
