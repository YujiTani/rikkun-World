# VOX-3 性能レポート（高低差を 2〜3 倍にしたとき）

- 判定: **数の上では軽い（k=3 でも 三角形 +30%）。本当の fps と見た目は オーナーの Mac で確認待ち**（受け入れ基準 3）
- 計測: `e2e-perf/voxelProto.perf.ts` の「高さの倍率ごとの重さと絵」（`npm run perf -- e2e-perf/voxelProto.perf.ts -g 高さの倍率` → `perf-results/voxel-height.json`）。B ごつごつ・小ブロック地形・hybrid r=16、島 `generateIsland` の本物の世界。クラウド（GPU なし・SwiftShader、1280×720）なので **fps は目安にならない**。三角形・描画回数・データ量・作る時間で比べる。
- 遊ぶとき: `voxel-proto.html?height=1|2|3`（ボタン「たかさ: 1 / 2 / 3 ばい」。押すと世界を作り直すのでページを読みなおす）。「みあげる」ボタン = 岩山のふもとから見上げる。

## 高さの作り方（`src/proto/voxel/terrain/stretchHeight.ts`・試作の中だけ）

- 今の島を生成 → 列ごとに、地面（草・土・すな・石・鉱石）のいちばん上 `ty` を `7 + (ty-7)×k` に のばす（7 = 海面。海・浜の列は そのまま）。
- 地層: 上から 草（元の最上段）→ 土 1 段 → その下は 石（鉱石は元の位置を k 倍に引きのばして使う）。薄くしたのは、1 段の崖（元の差 1 = k ブロック）にも 草→土→石 が見えるようにするため（土を 3 段のままにすると 3 ブロックの崖が全部土になった）。
- 木・花・水・たいまつ・建物など地面の上の物は、その列の地面が上がった分だけ上へずらす。世界の高さは 48×k（48 / 96 / 144）。
- 最高点（岩山）: k=1 で y=23、k=2 で 38、k=3 で 53。ふつうの丘の高低差は 約 10 → 20 → 30 ブロック。
- ゲーム本体（`src/world/gen/`）は変えていない。

- 見える小ブロックのチャンクの数は k によらず同じ（スタート micro 8・箱 32・遠く 24、上空 12 / 32 / 20）。
- 見上げるの描画回数が減るのは、見上げると視野の中のチャンクが減るため（高さを足したせいではない）。
- 作る時間・作り直しの時間は 1 回〜20 回の測りで **±30% くらいの誤差**（VOX-0 と同じ読み方）。k による差は「k=3 でやや増える」くらいにしか言えない。
- `renderWithFinishMs` は SwiftShader で 1ms 前後と意味がないので表から外した（`perf-results/voxel-height.json` にはある）。
- 世界のデータは 1 ブロック 1 バイトなので k に比例（k=3 で 2.25MB）。小さい。ただし、ゲーム本体は光の配列（世界と同じ大きさ）なども持つので 本番では その分も k 倍。

## 重さの主な原因（分析）

1. **見える崖の面が増える**のが主な増え方。k=3 のスタートで三角形 +30%。崖の壁は 1 段あたり k ブロックの高さになり、近くの小ブロックの形（r=16 の 8 チャンク）で 1 面ずつ段を描く分だけ増える。でも 近くの小ブロックの形は 距離で絞っているので、倍率の割に増え方は小さい（高さ 3 倍で三角形 1.3 倍）。
2. **縦に広げたことによる仕事**: メッシュ作りは 1 チャンクの高さぶんの配列（`meshVoxel.ts` の grid など）を毎回ならす・なめるので、世界の高さに比例して増える。作り直し 1 チャンクが k=3 で 約 +25%（59→74ms の中央値。ばらつきあり）。チャンクの上のほうは ほとんど空気なので、本番では「チャンクの一番高い所までだけ」を見ている `topOf` と同じように、空気の段を飛ばすと良い。
3. 縦のチャンクの数: このゲームのチャンクは高さ全部で 1 本なので、チャンク数・描画回数は k で増えない（スタート 62→66）。
4. 遠くの LOD は 列ごとの 1 枚の天面＋横の壁。壁が k 倍高くなるので、遠景の崖は少し増える（上空 +17%）が、全体の中では小さい。
5. 霧: 霧は距離で決まるので、高さを足しても 遠くの山が早く消えることはない。見上げるとき・上空のときは 3D の距離なので 霧に かかりやすい（上空の高さは k に合わせて上げた）。

## 試作で 48 を前提にしていた所（直した）

- 世界の高さ（`new ArrayVoxelWorld` のサイズ）→ 48×k。メッシュ作り・LOD・地面さがしは `world.size.y` を見ているので そのまま動いた。
- 上空のカメラの高さ（125）→ `125 + 24(k-1)`、ぐるっとまわるの高さ（48）→ `48 + 29(k-1)`、「スタートから中心を見る」の目当ての高さ（14）→ のばした地面の高さ。
- スタート地点の高さ・キャラの足もと → のばした世界から探す。

## 気づいたこと（本番で直すもの）

- 「見上げる」で 近くの岩が 大きなのっぺりした面に見える（箱の方式。hybrid の「中くらい」= 1 マスの箱・色だけ模様）。高い岩山は 近くに 見えやすいので、r を広げるか、箱の方式の岩にも模様を足すと良い。
- 木の葉は 列ごとにずらしているので、急な坂の木では 葉が少し ちぎれて見えることがある（試作では未対応）。
- 地面の地層は 試作では「草 1・土 1・あとは石」。本番では ブロックをこわしたときの見え方（土を何段にするか）も決める。
