# PERF-405 性能レポート: 地上から 見えない 地下を 描かない（#405）

判定: **合格**（重大 0）。スタートと 草花の 描画回数は 上げる 前の 上限に もどった。上空は 入口が 画面に 残るので、上乗せを 17 から 5 に 減らした。

- 測り方: texA AC12 と 同じ 開き方（`microR=28`・`ring=full`・`?nosave=1`）。スタートはそのまま、上空は 足元 +26・yaw 20・pitch −38。草花 AC11 は 北を向いて 立つ。くらべは `?mine=0&nosave=1`。
- クラウド（GPU なし・SwiftShader）。fps は 見ない。描画回数・三角形・さがしの 回数で 見る（#255）。
- 前 = この しくみの 前（同じ 測り。さがしが 上限で 止まって かくさなかった ときの 数）。あと = 今の ブランチ。

- スタート 137 は 上限 141 の 中（`START_SHAFT_DRAWS` を 5 → 0）。
- 草花は ゴールデン 87 との 差 7（上限 +10 の 中。上乗せ 5 → 0）。3 国の E2E も 通った。
- 上空 173 は 168 を 5 こえる。見おろすと 坑道の 入口が 画面に 入るので、その 奥は 描いたまま。`HIGH_SHAFT_DRAWS` を 17 → 5。
- 坑道を 切った 世界も 描画が へった（スタート 126 → 117、上空 166 → 158）。空と つながっていても 画面の 穴から 見えない 地下を かくしている。
- 三角形は ふえていない（地面を 消したときの 73 描画・20 万 三角形までは 落ちていない）。

上限は 8,192 回。超えた コマは かくさない（欠けない ほう）。カメラも 中身も 同じなら さがし直さない。2 人の 画面は カメラごとに やり直す。

## オーナーに Mac で 見てほしい ところ

F3 を 出して、次の 4 つで 地面や 穴の 奥が 消えないか・ちらつかないかを 見る。

1. スタートで まわりを 見わたす（北の 坑道の 入口）。
2. 入口を のぞき、中に 入って たいまつが 見えるか。
3. かべを ほって 奥が すぐ 出るか。ふさぐと 奥が 消えるか。
4. 2 人で 画面を 分け、片方が 穴の 中・もう片方が 地上の とき、それぞれの 画面だけが 変わるか。
