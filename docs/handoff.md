# 引きつぎメモ（PO セッション → 次の PO セッション）

新しいセッションの最初に、このファイルと `CLAUDE.md` を読む。PO はコードを書かず、`.claude/agents/` のチームに頼む。オーナーとは **日本語** で、短く、進み具合と見こみ時間をこまめに伝える。

## 1. オーナーの進め方の決まり（CLAUDE.md にないもの・念押し）

- 変更は 1 つずつ **別ブランチ → main への PR**。マージはオーナーがする。PR の前に main を取りこみ、ぶつかりは PO 側で直す。
- 軽微な指摘ではループを回さない。テストは関係する E2E だけ（`npm run test:e2e:fast -- <spec>`、`--workers` は付けない）。
- 「子どもが早く遊びたい」と言われたら、最低限のテストで PR を作り、レビューと受け入れはあとで。
- オーナーへの質問は、ふつうの文章で聞く（AskUserQuestion は使わない）。
- 画面の文字は、ルビを付ければ漢字でもよい。分かりやすければ文字だけで、絵はいらない。操作の案内はアイコンを優先する。
- `docs/screenshots/` は E2E で書き換わるが、コミットしない（`git checkout -- docs/screenshots`）。
- サブエージェントが利用の上限で止まったら、作業途中をコミットして push し、上限が解けたら同じエージェントに続きを頼む。
