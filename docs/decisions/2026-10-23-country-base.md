# 国の土台（#291・COUNTRY-1）のオーナー決定

日付: 2026-10-23 / 決めた人: yuzu（オーナー）

- 国の名前のふだは作らない。実績「はじめて ○○ に きた！」のおしらせがあるので、それで足りる（VOX-I §4 のふだは作らない）。12 国ぜんぶも、実績「ぜんぶの くに に いった！」のおしらせにまとめる。
- 古い「ばしょ」実績（やま・もり・くさはら・ひらち・いずみ・いけ・かわ と ぜんぶの ばしょ）は、新しくは取れなくし、取った物は「むかしの ばしょ」として残す。うみ・やまの てっぺん は残し、てっぺんは本当の山の頂上で取れるようにする。
