# がしゃどくろ（大）の コアを 心臓へ・背中の 穴から 道で 行く（2026-10-24 yuzu、#293）
- きっかけ: 顔が 振り向く ように なって、頭の コアは ねらいにくく（たどりつきにくく）なった。
- オーナー「顔が振り向くようになったことで頭のコアはが到達がむずかしくなった／なので、心臓の位置にコアがあることにしましょう／コアへの道は背中に穴があいてて、コアまでのみちがあるような作りにしましょう」
- きまり:
  - コアは 頭がいの 中 → 胸の 心臓の 位置（体の 中、少し 左）。頭の てっぺんの 穴・後頭部の 欠けから ねらう しくみは やめる（頭の 欠けの 見た目は そのまま、光る 石だけ なくした）。
  - 背中（肩甲骨の あいだ）に 穴。穴から 体の 中の 道（トンネル。幅 約 3 ブロック・高さ 約 3 ブロック。床は 乗れる 当たり）を 歩いて コアの 前まで 行ける。中は ろっ骨と 暗い 内がわ、道の 先で コアが 光って 見える。
  - 道: 間欠泉 → 肩の 雲 → 背中の 雲の 段（下がり 1 ブロック いない）→ 穴の 入り口の 床の だん → 道 → コアの 前。はう・首ふり・怒りの 間も 途切れない ことを ユニットテスト（全コマ）で 確かめる。
  - コアを たたくと 近くの プレイヤーは 背中の 外へ ふり落とされる（穴の 外へ ワープして うしろへ とばす。落下ダメージなし）。コアの 倍率 3.0・防御力 0 は そのまま。
  - 位置・大きさ・道の 幅・とばす 強さは `src/proto/gashaBigTuning.ts` の `core`。
