# がしゃどくろ（大）の コアを 心臓へ・背中の 穴から 道で 行く（2026-10-24 yuzu、#293）
- きっかけ: 顔が 振り向く ように なって、頭の コアは ねらいにくく（たどりつきにくく）なった。
- オーナー「顔が振り向くようになったことで頭のコアはが到達がむずかしくなった／なので、心臓の位置にコアがあることにしましょう／コアへの道は背中に穴があいてて、コアまでのみちがあるような作りにしましょう」
- きまり:
  - コアは 頭がいの 中 → 胸の 心臓の 位置（体の 中、少し 左）。頭の てっぺんの 穴・後頭部の 欠けから ねらう しくみは やめる（頭の 欠けの 見た目は そのまま、光る 石だけ なくした）。
  - 背中（肩甲骨の あいだ）に 穴。穴から 体の 中の 道（トンネル。幅 約 3 ブロック・高さ 約 3 ブロック。床は 乗れる 当たり）を 歩いて コアの 前まで 行ける。中は ろっ骨と 暗い 内がわ、道の 先で コアが 光って 見える。
  - 道: 間欠泉 → 肩の 雲 → 背中の 雲の 段（下がり 1 ブロック いない）→ 穴の 入り口の 床の だん → 道 → コアの 前。はう・首ふり・怒りの 間も 途切れない ことを ユニットテスト（全コマ）で 確かめる。
  - コアを たたくと 近くの プレイヤーは 背中の 外へ ふり落とされる（穴の 外へ ワープして うしろへ とばす。落下ダメージなし）。コアの 倍率 3.0・防御力 0 は そのまま。
  - 位置・大きさ・道の 幅・とばす 強さは `src/proto/gashaBigTuning.ts` の `core`。

## 追記: コアへの道を「とぎれた 一方通行」に（2026-10-24 yuzu、#293）
- オーナー「コアへの道は途中でとぎれていて、遠隔でしか攻撃できないようにして／ブロックはおけるようにしてもいい／内部にこけの草をたくさん生やして／くさやコケはブロックタイプではなく十字のドット絵で／肩から降りていく道は途中、飛び降りないといけない道にして、一回降りたら戻れないように／透明の雲をガラスブロックに／腰回りをガラスの雲でちゃんと囲む／頭の周りの雲は減らす」
- きまり:
  - 道: 肩の 雲 → 背中の 雲の 道 → **4〜6 ブロックの 飛び降り**（足袋なしでも 小ダメージで しなない）→ 背中の 穴の 床の だん → とぎれた 穴（横 約 6 ブロック。`core.tunnel.gap`）→ むこうの 床と コア。走って ジャンプしても わたれない（むこうの 床の ふちまで 横 4.4・走り幅とびで 2.3）。穴の 手前から 肩へは もどれない（もどるには コアを たたいて ふり落とされる）。
  - コアは **遠隔（弓）だけ**: 穴の 手前から コアまで 約 8 ブロック。刀の とどき（約 2.2〜3）に とどかない ことは **形だけ**で 守る（特別な 判定は なし）。手前の 床から コアへ 線が 通る ことは スクリプトで 確認。
  - ブロックを おく: 体の 固い 当たりは ワールドの ブロックでは ないので、穴に ブロックを おいても 体の 当たりには ならない（試して いない・未対応）。「おいた ブロックだけ 体に ついて くる」は あとで。
  - こけ・くさ: ブロックの 種類ではなく、くさ（FLORA-75 の kusaTile と 同じ 色）と おなじ「十字の 板」と、面に はる 平らな こけの しきもの（`src/proto/gashaBigPlants.ts`）。InstancedMesh 3 つ（くさ・房・しきもの）で 描く。当たりなし。密度・大きさ・上限は `core.moss`。
  - ガラスの 雲: 1 ブロックの すりガラス（明るい ふち + 白っぽい 半透明の 中。ぐるぐる 模様なし）。1 ブロック ずつ 歩ける。`breakGlass(center, radius)`（火の 攻撃用の 口。テスト用に `__gashaBig.breakGlass`）で 割ると 消えて、`glass.regenDelaySec` 後に `regenGapSec` ごと 1 つずつ もどる。割れる とき 小さな かけら（`glass.fragments`）と 既存の 割れる 音（fxSound 'break'）。火の 攻撃は あとで（口だけ）。
  - 腰（こしより 下）は 雲の 輪（`bank.rings`・`innerRad`・`innerTop`）で 囲む。頭の まわりの 雲（`rise.count` 7）は 減らして、肩の 雲と 背中の 穴への 道は のこす。頭には 登らなくて よい。
  - ふり落とし（v2）: **予兆 → とばす**。コアを たたくと `core.throwOff.warnSec`（1.5 秒）の 間、大きな 音（既存の「かみなり」`LEGEND_SOUNDS.lightning`）・画面が 大きく ゆれる（`warnShakeDeg`。「うごきを へらす」は 4 分の 1）・コアが 激しく ゆれて 半透明（`warnJitter`・`warnAlpha`）・**むてき**（ダメージ 0・「はじかれた」水色の 火花）。この 間も プレイヤーは 動ける。予兆の あと 風の 音（`public/sound/legend/spiralWind.ogg`）と ともに もとの **2 倍**（`range` 28・`exitOut` 5・`speed` 20）とばす。飛んで いる 間 カメラが 横に 1 回転（`spinTurns`・`spinSec`。着地前に もとの 向き。「うごきを へらす」は 回さない）。**ふり落とし自体の ダメージは なし・着地ダメージは ふつうに 入る**（`noFallSec` は やめた。足袋・間欠泉の 守りは そのまま）。着地は 約 13 ブロック 下（足袋なしで 体力 20 → 8）。

## 追記: 体の 上に ブロックを おける・外の こけ・ガラスを こわせる・体の 上の 丸影（2026-10-24 yuzu、#293）
- オーナー「隙間にブロックはプレイヤーが橋作ればいいのかも気づいたら、そういう攻略もさせてあげたいだけなので こちらからの実装はないです／がしゃどくろのうえのどこにでも、ブロックが置ければok」「コアの近くに生えてるコケだけど、普通にがしゃどくろのからだのあちこちにも生やして欲しい」「ガラスブロックは普通に壊せるようにして欲しいです。閉じ込められるバグが発生するので」「がしゃどくろの上には特別にプレイヤーの丸影を表示して欲しい」
- 体の 上に ブロック（`src/proto/gashaBigPlaced.ts`・`src/dig/bodyBlocks.ts`）:
  - 体の どこでも（腕・手・肩・胴・頭・ガラスの 雲・道の 壁と 床・穴の ふち）に 置ける。ねらい方・面・持ち物 -1 は ワールドと 同じ（`DigSystem` に 後づけの 口 `BodyBlocksPort`）。
  - 置いた ブロックは いちばん 近い 部品（関節の Group）に つき、体と いっしょに 動く。固く、歩ける（体の 当たりの 後ろに 1 ブロック 分の 箱として 足す）。見た目は ふつうの ブロックの 絵（部品ごとに 1 メッシュ）。
  - 置ける ブロックは `BODY_PLACEABLE`（土・石・レンガ・木・板・ガラスなど 建てる 用）。上限 `placed.max`（200）。がしゃどくろを 置きなおす・消える と いっしょに 消える。
  - ほる（左クリック）と もどる（持ち物 +1）。**刀を 持って いる 間は 体の ブロックは ほれない**（刀の 攻撃を 変えない ため）。矢・刀は 置いた ブロックに 当たらない。怒りの 攻撃で こわれるかは 未決定（いまは こわれない）。
  - 橋: 特別な 実装は なし。**橋は 手前の 床より 1 だん 低い 高さ（足の 1 つ 下の だん）に かける**（手前の 床の 高さだと 先の 天井が 低くて 頭が つかえる）。最初の 1 つは 床の ふちで うしろ向きに 立って、ふちの 前の 面を ねらって 置く。むこうの 床との 差（3 ブロック）は 橋の はしから よこへ 降りる。`scripts/bridge-gasha.mjs` で 本物の 入力で 6 こ 置いて コアの 前まで 行ける ことを 確認。
- 外の こけ: 道の 中と 同じ 十字の 板を 肩・腕の 上・ひじ・背中・頭の てっぺん・服の すそ・ろっ骨の すきまに まばらに。`core.moss.outside`（`count` 110・`clump` 8・`size`・`sideFrac`・`max` 900・`parts` で 部品ごとの 生えやすさ）。関節に ついて 動く。InstancedMesh 3 つ（描画 +3）。当たりなし。
- ガラスの 雲を ふつうに こわせる: ほる（左クリック。体の ブロックと 同じ 1 つ ずつ・`glass.digRadius`）、刀（ふった 1 回で まとめて `glass.swordRadius`）。こわれた 所は 時間で もどる（アイテム なし）。**もどる 場所に プレイヤーが かさなって いる 間は もどらない**（とじこめ 防止）。ほか の とじこめ 原因: 雲で かこまれる → こわせる ように なって 解決。体の 中に うまる もどり方は 見つからず。
- 体の 上の 丸影: 体・ガラスの 雲・置いた ブロックの 上では、足の すぐ 下に 向けた 短い 線で いちばん 近い 上面を さがして、その 上に 丸い かげ（`blobShadow` の `surfaceBelow`）。ワールドの 地面の 上は 今まで どおり。当たり箱の 上面だけ を 見る（見た目の すこし 上に 出る ぶんの 差は 許す）。
