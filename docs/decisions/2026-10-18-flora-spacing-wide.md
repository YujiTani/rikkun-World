# 木と草の間の広さは「ひろい」（#75）

- 日付: 2026-10-18
- 決めた人: オーナー（スレッド「#75 草や花」の決定カード）。きっかけはオーナーの声「草とか木とか、密集して生えすぎているので、もう少し間隔を開けて生えるように」。
- 決定: `docs/design/FLORA-75.md` §14 の 3 段のうち **ひろい** を 12 の国すべてに使う。
- 見たもの: ゲーム内試作の比べ絵（もり・たけやぶ・はらっぱ × 今／せまい／ふつう／ひろい）。
- いっしょに伝えた既定（オーナーがちがうと言わなければこのまま）: くさ（板）からは たね を出さない／のばな は あわい青／前のセーブで行った列は そのまま（さかいで はっぱが切れることがある）。
- あとで見ること: 木が減るので、木材の集めやすさを 実装のあとに遊んで確かめる。
