# ぼうぎょりょく（防御力）を はじめて 入れる（2026-10-24 yuzu、#293）
- きっかけ: 大きな がしゃどくろを レジェンダリー武器で 手だけ なぐりつづけて 体力 0 に できた。
- オーナー「個人的には、手は 被ダメージを 30 さげる 防御力が あって、最低ダメージが 1 に なるように したいです。はじめての 防御力の 概念なので、ルールとかに 加えてもいいかも」。
- きまり: 部位ごとに 防御力（受ける ダメージから ひく 数）。ダメージ = 最低 1（武器の 強さ × 部位の 倍率 − 防御力）。がしゃどくろの **手 = 30**。ほかの 部位（前わん・上わん・頭・コア・胴体）は 0。倍率 0 の 部位は 今までどおり 当たらない。
- 数は `src/proto/gashaBigTuning.ts` の `hit.partDef`（日本語・単位つき）。ルールは `docs/design/BALANCE.md` §2.9 に書いた。
- 子ども向けの 本（ルールブック）は 週一の 更新で まとめる（今回は 足さない）。
