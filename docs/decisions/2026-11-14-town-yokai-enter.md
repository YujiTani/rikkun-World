# 2026-11-14 拠点の街: 妖怪は 入れる・はじまりの木を 守る・門と 見た目（#381）

仕様: `docs/design/TOWN-1.md` 1.3 版（くわしくは `TOWN-1-place.md` §2.2・§4.5）。前の 決定: `2026-11-13-town.md`（その 行に「→ ここで 変わった」と 書いた）。

## 1. 妖怪は 街に 入れて、ふつうに たたかう（yuzu 11:04・11:07）
- 11:04 yuzu「街が壊れないなら、ようかいはいってもいいですよ」。
- 11:07 カードで「入れて、ふつうに たたかう」を えらんだ。
- → 妖怪は 外から 歩いて 街に 入れる。街の 中でも 攻撃が 当たる（プレイヤーも 妖怪も）。
- → 街の 中（と まわり 8 マス）では 妖怪は わかない。
- → 建物・街の ブロックは こわれない（妖怪にも プレイヤーにも）。あきちの 中だけ ほれる・置ける のは 今の まま。
- → 街の 中で 落ちても いたくない は 今の まま。ふちの 灯りは かざり・目じるしとして のこす（妖怪を 止める しくみでは ない）。
- PO（仕様で おすすめに した こと。オーナー確認①で 見る）: 1 人の ときは 画面を 開いて いる 間 今の まま 世界が 止まる。2 人の ときは 止めず、開いて いる 人にも 当たる（COOP-1 の もちもの画面と 同じ）。

## 2. はじまりの木を 先に 守る（yuzu 15:12「あなたのおすすめでok」）
- 街の 置き場所は、街の はんい・すそ・門から スタートへの 見通しの 道が はじまりの木の みきに かからない 所を 先に えらぶ。
- その ため、世界の シードに よっては 門が スタートから 28 マスより 遠く なって よい（100 の シードで 数こ）。
- はじまりの 坑道も よける。

## 3. 門と 見た目（yuzu 午前）
- アスレチックの 門の かんばん「どうじょうへ」と 街の 門の かんばん「りっくんの まち」は なし。
- かじやは 赤が 主役で、えんとつから 黒い けむり。
- だいくさんの こやは 明るい 白木。
- 街の 門は 2 かいだての 楼門（はば 19・おく 13・高さ 17、通り道 はば 5・高さ 6）。設計は 共有フォルダ `town/art/gate/`（リポジトリ外）。
- 細かい 作りこみは 門だけ。パーツの 刻みは 1 マス 16 分け。
