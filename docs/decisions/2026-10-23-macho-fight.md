## きめたこと

1. 妖怪 に **ねらわれない**（やられない）。
2. パンチ の はやさ は **ぼくとう と 同じ**。**3 回 に 1 回 は ノックアップ**（刀 の 切り上げ と 同じ ことを する）。
3. いっしょ に たたかう の は **1 わ だけ**。
4. ついてくる 時間 は **ふつう の なかま と 同じ**（むし で のびる）。
5. りっくん が たたいた 妖怪 に くわえて、**りっくん を たたいた 妖怪 にも** 向かって いく。
