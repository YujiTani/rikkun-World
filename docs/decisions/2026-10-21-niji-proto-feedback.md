# 虹（にじ）の 試作を 見た 直し（WEAPON-9）

2026-10-21 オーナー（yuzu）決定。試作 `claude/weapon-9-proto`（`docs/art/WEAPON-9/proto/`）を 見て。

1. **ドームの 形は こまかくする（例外）**: 球を こまかくして なめらかに（三角形 約 200）。「エフェクト 1 つ 三角形 150 まで」の **例外** に する（「A、例外にしましょう」）。
2. **カメラ**: 上が 切れるなら **もっと 引いて よい**（12 より 遠くても OK）。
3. **斬撃 A は OK**。
4. **ための 光**（WEAPON-8 で「ため 完了で 手が 光る」を 作っている）: **ため中は 光が キャラの 中心へ 向かって 集まる** エフェクト、**ため 完了後は 右手を 光らせる**。今は ため中も 光が 腕に 集まっているので 変える。
5. **手に 持つ 絵**: 虹の 太刀の 手持ちの 絵も アイコンを 体現した 物に する。**見た目が ユニークな 武器は ぜんぶ 手持ち用の 絵を 作る**（雷神剣・風神剣も）。
6. **斬撃の 板は カメラの 向きで 絵を 変える**（風神剣の 真空波も）: うしろからの カメラなら 斬撃を 横に した（寝かせた）絵、横からなら 今の 斬撃。**カメラから かっこよく 見えて いるかは スクショで ちゃんと 確かめる**。
- （同 yuzu）4〜6 の 雷神剣・風神剣の 分も **ぜんぶ WEAPON-9 で** 作る（WEAPON-8 の マージ後に 取りこんで から）。
- （同 yuzu）**PR は 2 つに 分けて、PR-2（虹）から 進める**。PR-2 = 虹の 本体（強さ・シャイニング・ドーム・カメラ・1/3・弾を 消す・3 段・音・虹の 手持ちの 絵・虹の 斬撃の カメラ向きの 切りかえ）。PR-1 = 共通の 直し（ための 光 3 本・雷神剣と 風神剣の 手持ちの 絵・真空波の カメラ向き）。PR-1 は 虹の あとで、別ブランチ。
- （同 yuzu、designer の 質問への 答え）新しい 手持ちの 絵は **女の子と 男の子の 両方に 持たせる**。弾は ぜんぶ ドームで 消えるので、受ける ダメージ 1/3 が 効くのは 近くの 妖怪が じかに 当てた とき だけ → **それで よい**。
- （同 yuzu）男の子は **今の 4 つの 絵（たつ・あるく・はしる・ジャンプ）の 手に 虹の 太刀を 描きこむ**。わざの 間は 今どおり。男の子の わざの 絵（GLB の 3 連続攻撃など）は 別の issue。
- （同 yuzu）虹の 手持ちの 絵（女の子）と 寝かせた 斬撃は **OK**（「両方ok」）。
- （同 yuzu）男の子の 分は **別 issue（#242）**（「少年の修正は別issueでおk」）。WEAPON-9 では 作らない。
