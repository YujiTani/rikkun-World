## 決まったこと

1. **家の ブロック ＝ 案 C「ふとい いたの やまごや」**: はちみつ色の ふとい 横板の かべ・こい 木の 板に 石を のせた 平らな やね（かべと 色も 明るさも ちがう）・石だたみの ゆか・かべの あつみの 中に へこんだ しょうじ（光は 通る）・てつの おびの あつい 2 まい とびら（外へ 左右に ひらく）。
2. **人が 作った 物は 平らな 箱**（DESIGN 5.3・15.1、CRITERIA #10）。3 案の C は かべに 9×9×9 の みぞ（でこぼこ）が あった が、しあげで **平らな 箱 ＋ 絵の みぞ（線と かげ）** に した（art-director。PO の 依頼: ふとい 横板・石の やね・あつい とびら・へこんだ しょうじ の 印象は のこして 三角形を へらす）。家 1 けん（いちばん 大きい 外 11×11）の 三角形は 約 12,108 → 約 1,414（見本の 外 7×7 は 6,792 → 678。描画は +0 の まま）（`docs/art/design/06-housing.md` §21.7）。
3. **置いた ふとんは 今の ふとんの 見た目の まま**（PO 決定。C の 藍の かすりの ふとんは 使わない。家の 外に 置いた ふとんが 変わらない ため）。天井の ちょうちんも 今の 小物 `lantern` の まま。
4. **アイテムの 絵は 今の ブロックと 同じ きまり**（ブロックの 面の 16×16）: かべ ＝ 横の 面、ゆか・やね ＝ 上の 面（はたけと 同じ 例外）、しょうじ ＝ 前の 面。2 マスの 戸 と せっけいず（方眼の 紙に 家 ＋ 赤い はんこ）は 物の 絵（ふとん・ちょうちんと 同じ）。3 案の C の「ななめから 見た 小さな ブロック」は やめた（今の アイテムに ななめの 絵は なく、ホットバーで 浮く）。
5. 実装の 前に、**しあげた 見た目（平らな 箱）の ゲームの スクショで もう 一度 yuzu の OK** を もらう（3 案で 見せた C は でこぼこの かべ だった。また 3 案の 試作では ひだり・みぎの かべの しょうじが 横向きで 細い すき間に 見えて いた のを、しあげで 向き 2 つに 直した。見くらべ: `docs/art/house-1/house-C-before-after.png`）。

## のこる 気を つける 所

- 家の 中は かべも 家具も 木の 茶色で、ぼかすと 家具が かべに とけやすい（CRITERIA #3 △。ちょうちん・ざぶとん・プレイヤーは うかぶ）。家具の くり茶 と かべの はちみつ色の 明るさの 差を 本番の スクショで 見る。
- かべ・やねは 今の つち・き と 同じ 茶色の なかま（#8 △。明るさと 板の 線で 分ける）。
- しまった 戸は 小物 なので 光を 通す（試作）→ よる、戸と 窓から ちょうちんの 光が 外へ もれる。しまった 戸が 光を 止めるか は 仕様で 決める。
- エディターの 見本（#339 の「なか」）は 屋根を はずす ので、天井の ちょうちんが 宙に うく。見本では ちょうちんの 印に する か やねの ふちだけ のこす（デザイン・developer と 相談）。
- しょうじは 向きが 2 つ（まえ・うしろの かべ ／ ひだり・みぎの かべ）、戸は 4 つ いる（ふとんと 同じ やり方）。

くわしい 形・色・数は スタイルガイド（`docs/art/DESIGN.md` §21 ＝ `docs/art/design/06-housing.md`）、作る 係への 依頼は `docs/art/requests/HOUSE-1-house-blocks.md`。
