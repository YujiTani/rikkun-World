# 2026-10-30 レア度の宝石の印をなくす

- 決めた人: yuzu（オーナー）
- 決めたこと: アイテムの枠の右上などに出していたレア度の印（宝石の形 7 つ: まる・ひしがた・六角・ほし・みかづき・ほのお・かんむり）を、全部の画面（ホットバー・もちもの・つくる画面・たんす・ツールチップ）でなくす。レア度は **★の数 と ふちの色** だけで見せる。
- 理由: ★6 の「ほのお」の形が「炎属性」に見えてしまうため。
- やったこと: `src/ui/gemArt.ts`・`GemShape`・`RarityTier.gem`・`__rikkun.rarity` の `gem`・`.slot-gem` を消した。E2E は「印が出ない」ことを確かめる形にした。
- 直した資料: `docs/design/RARITY-7.md`（宝石の印の所を廃止と書いた）。
