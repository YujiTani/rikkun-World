# 2026-11-06 妖怪の 同時の 数を 3 体に する

- オーナー（yuzu）2026-11-06: 「妖怪の 出現を いまの 8 匹から 3 匹に して ください」（最優先）。
- 読み方: 同時に 出て いる 妖怪の 上限（湧きの 上限）。地下 `yokaiMaxUnder` 8 → 3。地上 `yokaiMax` も 5 → 3 に そろえた（3 より 多く 出る 所を のこさない）。
- 数は `src/yokai/ai/config.ts` の `createYokaiConfig` 1 か所。出る 間かく・ぬりかべ 1 体・タコ 2 体・手で 出す 妖怪（ボス・挑戦）は かえない。
- MINE-1 §4.3・A13・A14 の「地下 8 体・地上 5 体」は この 決定で 3 体に おきかわる。
