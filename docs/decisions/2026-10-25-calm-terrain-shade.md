# 2026-10-25 ごつごつ控えめ ＋ 影を少し強く（#309）

## なやみ（yuzu）
9×9×9 にして表現力は増えたが、ブロックを置く場所や、道（地形）がどうなっているかが分かりにくい。

## 決めたこと（yuzu がゲームの試作 `?calm=1&shade=1` を見て OK「これがいいね！すぐ対応していい」）
1. **ごつごつ控えめ**（`src/world/micro/microSurface.ts` の MICRO_PARAMS）: 見た目の高さを 本当の高さ（1 ブロック）に近づける。
   - 1 段の段差は 崖だけ（slopeRate 0.6 → 0）
   - 丘・くぼ地なし（hillHeight 7 → 0、hollowDepth 5 → 0）
   - うねり 1.6 → 0.4、ごつごつ 0.6 → 0.3、草むら 2 → 1、岩の高さ 6 → 3
2. **影を少し強く**（`src/world/render/config.ts`）
   - 面の明るさ: 上 1.0・下 0.5 → 0.45・東西 0.6 → 0.5・南北 0.8 → 0.68
   - 角の暗がり（AO）: 0.82 / 0.68 / 0.55 → 0.75 / 0.58 / 0.45
3. ねらいのわくは 今の黒いわくのまま（白い線＋黒ふちの新しいわくは yuzu「もとのがいちばんよかった」）。

VOX-1 の「もっとゴツゴツでよい」を 地面の高さについては一部もどす。ブロックの面のへこみ（DESIGN 5.2 の表）は そのまま。
