# 2026-11-05 2 人で いっしょに あそぶ（画面分割）COOP-1

## yuzu の ねがい

子ども 2 人が けんかしないで 一緒に 遊べるように、2 人プレイを 最優先に する。

## yuzu の 決定（2026-11-05〜06 JST）

1. 1 つの 世界を、コントローラー 2 本（同じ 機種）で。ネット対戦は しない。1P は キーボード＋マウスも 使える まま。
2. **ダイナミック分割画面**: 近い ときは 1 画面（1P が 中心、カメラは いつもより 引く）→ 2P が 画面の 外に 出ると **ルーペ** → もっと 離れると **左右に 分割**（左右 固定。ななめに しない）。
3. ルーペから 分割に なる 前に、ルーペの わくの 色を **2 段階** で 少しずつ 変える（白 → 黄 → オレンジの 仮。赤は 使わない）。色は アートの 3 案から 選ぶ。
4. 画面に **距離メーター**（▼P1 ━━ ▼P2。2 人の 直線距離で 伸びる）。
5. 2 人が 離れすぎない しくみ（引っぱる・ワープ）は **入れない**。重く なったら ゲーム側で 軽く する。
6. 持ち物は 別々、たんすは 共有。仲間への 攻撃は なし。2P は 1P の 横に 出る。
7. 2P の 見た目は、いったん 1P と 同じ キャラ＋頭の 上の 色つき ▼。
8. **レベルは 別々、実績は 2 人で 1 つ**。
9. 作る 順の つごうで 仮の 見えない 壁が ある 期間は あっても よい（仕様では 使わない 順に した）。
10. 重さの 試作の 結果（分割中は こまかい 形を 近く だけ・読みこむ 輪を 小さく → 合格）を 見て、作業 1 から 進める（2026-11-06 00:54「ok、それでいこう」）。
11. 2P が いなく なっても、2P の 持ち物は 世界の セーブに 残す（仕様 §6 の とおり）。

仕様: `docs/design/COOP-1.md`（1.2 版）。重さの 結果: 共有フォルダ coop/perf/README.md。
12. 色は案 B（2026-11-06）: 1P ライム・2P むらさき、ルーペの段は 白 → こがねいろ → オレンジ、わくの太さ 4→6→8px。ルーペの ● の印は いらない。
13. キーボードと コントローラー 1 本でも 2 人で 遊べるように、せってい画面の コントローラーに「1P が つかう」「2P が つかう」を 足す（せってい画面 #394 の あと）。それまでは 開発用 `?duo=dev&pad=2p`。
14. **2 人の ときの もちもの・クラフト画面**（2026-11-06 20:39 JST）: yuzu「であれば、1Pも画面半分のクラフト画面にすべきだと思います。」「2Pで遊ぶ時だけ」「2P用のクラフトがめんになるようにしましょうか」。→ 2 人で 遊ぶ ときだけ、1P も 2P も 同じ 形の「2 人用の もちもの・クラフト画面」（1 人の ときと 同じ 中身、つくる も ふくむ）を 自分の 側の 半分（1P 左・2P 右）に 出す。もう 1 人は 止まらず 遊びつづける（時間も ゆっくりに しない）。1 人の ときは 今の 全面の まま。2P の「つくる」は 段階 2 から 作業 3 に 前だおし。2P の「やめる」長押しは のこす。前に 出した「開いている あいだ 世界を 止めて もう 1 人に『ちょっと まってね』」の 案は やめ。見た目は 試作の スクショで OK して から テスト準備。仕様: `docs/design/COOP-1.md` 1.5 版 §3.3。
