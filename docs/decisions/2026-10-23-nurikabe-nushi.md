# ぬりかべ にも たいしょう・ヌシ を出す（2026-10-23 yuzu、#270）
- オーナー「ぬりかべのぬしをだすし、体力も他のと同じ仕組みでいいし、レジェンダリーもおとします」。
- 前のきまり「ぬりかべ は おやぶん まで」（BALANCE §2.5・§6・AC4・AC7）を やめる。ぬりかべ も ほかの 3 種と同じ確率（おやぶん 3%・たいしょう 1%・ヌシ 0.3%）で 二つ名がつく。
- 体力・はやさ・経験値・大きさ・ドロップの回数は ほかと同じ 二つ名の倍率（ヌシ 体力 40 × 3 = 120）。攻撃力は 上限 16 のまま。
- ぬりかべ の ヌシ を プレイヤーが たおすと、ほかの ヌシ と同じく レジェンダリー武器を 1 本 落とす。
- 頭の印（たいしょう = はちまき、ヌシ = かんむり ＋ ふんわり光）も ほかと同じに つける。
- 安全のきまりの「ぬりかべ: はやさ 0.5 以下」は、二つ名の倍率をかけた はやさ 0.6 以下 に読みかえる（プレイヤーの歩き 4.0 より ずっと おそいので にげられる）。
