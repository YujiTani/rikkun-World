## 遊びやすさ: ねらいの線が P（足もと + 2.12）から出る件
数字（e2e/char1-accept.spec.ts「ねらいの高さ」。P から 5.0 までの視線。0.5 度刻み）:

| 場面 | pitch 0 | 当たる pitch の はば（P = 2.12） | 参考: 変更前の目 1.62 |
|---|---|---|---|
| からかさ 2 マス | **当たらない**（−0.5 から当たる） | −0.5 〜 −68.5 | 0 でも当たる（+26.5 〜） |
| からかさ 3 マス | 当たらない | −0.5 〜 −51 | +13.5 〜 −44.5 |
| からかさ 4 マス | 当たらない | −0.5 〜 −39 | +9 〜 −33 |
| ちょうちん 3 マス | 当たらない（−2 から） | −2 〜 −39.5 | +9 〜 −31.5 |
| ぬりかべ・ろくろ首 | （当たり判定の上 3.3 / 3.0 で 高い） | 当たる | |
| 地面のブロック | ねらいなし（pitch −25 まで なし） | −26 で 4 マスさき、−35〜−40 で 3 マス、−45〜−50 で 2 マス、−60 で 1 マス | 変更前は 約 −19 から |

- からかさの当たり判定の上は 足もと + 2.10、ちょうちんは 2.00。P は 2.12。**まっすぐ（pitch 0）だと からかさは 2 cm、ちょうちんは 12 cm 上を すり抜ける**。ほんの少し（0.5〜2 度）下げれば 当たる。
- 見た目: 十字は 視線の上にあるので「十字が妖怪の頭の すぐ上」に見え、十字を妖怪に重ねれば 当たる（いま見えている物と 当たる物が 一致する）。pitch 0 のスクショ: REACH-karakasa-pitch0-d3.png（十字が頭の上・ふちどりなし）。pitch −12: REACH-karakasa-pitch-12-d3.png（ふちどり「たたく」が出て 当たる）。地面: REACH-ground-pitch-35.png。
- 判定: 変更前も 地面は 下を向かないと ねらえず、からかさも 目 1.62 で ぎりぎり。だから 6 歳が「ぜんぜん 当たらず こまる」ほどではない（十字を妖怪に重ねれば 当たる）。ただし **気づき 2 つ**（軽微）: (1) pitch 0 で 十字が 低い妖怪の 頭のすぐ上を 通る「あと少し」が 起きやすい（当たり判定の上を 2.12 より 少し高くするか、からかさ・ちょうちんの当たり判定を 上げる／P から線を少し下げると 直る）。(2) 正面 3 マスの妖怪は カメラ（うしろ 4）から キャラの体の かげになり 一部しか見えない（REACH-karakasa-pitch0-d3.png）。
