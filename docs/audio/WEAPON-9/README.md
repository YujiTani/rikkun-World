### おすすめ: A「にじの すず刃」

- **見本の 性格**（「シャキン」と 何回も 切りきざむ）を 3 段目の 4 回の 切りで 出しつつ、刃の 鳴りを 本物の 鉄琴に して **にじ（音の 色が ふえる）** に した。ドームの 絵 A「ひかりの まく」の キラキラと 合う。
- 雷神剣（ばちばち）・風神剣（風）と 聞き分けやすい。B は はがねの 音が 雷神剣の「バチッ」と 近く、耳に 少し 強い。C は やさしいが「切った」感じが うすい。
- 高い 音（3 kHz より 上）の 量が 見本（-4.5 dB）より 少ない（-5〜-9 dB）。くり返して 聞いても 耳に ささりにくい。
- B と C も ふつうに 使える 大きさ・安全さに して ある。オーナーが「見本に 近いのが いい」なら B、「やさしいのが いい」なら C。

## 盛り上げのきまり（`docs/fun.md`）との 合わせ方

- **斬撃・かき消す・はじく は くり返す 音** → 控えめ・一定に しない。どれも 高さの ちがう 3 とおりを 作り、ゲームでは 直前と ちがう 物を えらぶ（`*_combo` の 2 回目・`*_x3` で 聞ける）。続けても 大きく しない（同じ 段の 3 とおりは 同じ 大きさ）。
- 3 段攻撃は 段で 音が かわる（1 → 2 → 3 で 音の 数が ふえ、高く なる。今の 掘る音・ゆみの 段と 同じ 考え）。3 段目は めやす +1.5 dB だけ（「しめ」が 分かる くらい）。
- 音の 高さは ハ長調の 五音（ド レ ミ ソ ラ）。ゲームでは ド を 根音に して BGM の 和音に 合わせて 動かせる（SOUND.md §6 の `root`・`tones`）。
- **達成の ファンファーレ は ここでは 作らない**。シャイニングは ためわざ（何回も 使う）なので `shiningStart` は「この 中で いちばん 大きい」けれど 祝う 音より 小さい（`pickup` の 約 +1 dB）。虹を はじめて 手に 入れた ときの 祝い は 今の `legendDrop`（キラキラ）＋ 実績の ファンファーレの まま。
- 失敗（ためが たりない・休み中）で 音を 暗く しない。休み中に はなしたら ふつうの わざの 音。

## 安全（数で たしかめた。`python3 -I measure.py .`）

ものさしは WEAPON-8 と 同じ「ゲームの はじめの 設定・リミッターの 前」。大きさは `render.py` の `TARGET`（400 ms の いちばん 大きい 所）に 1 つずつ そろえた。

## 素材と ライセンス

- **本物の 楽器の 録音**: VCSL（Versilian Community Sample Library、Versilian Studios）https://github.com/sgossner/VCSL — **CC0 1.0**（パブリックドメイン。ゲームに 入れて よい・子どもたちに 公開 して よい・商用 可・クレジット 不要・再配布 可）。使った 録音は `sources.txt`（鉄琴・ハンドチャイム・ベルツリー・ウィンドチャイム・ワイングラス・弓の ビブラフォン・フィンガーシンバル・トライアングル・金床・弓の シンバル）。CC0 なので 再配布も できるが、大きいので 元の ファイルは リポジトリに 入れない（`fetch_samples.sh` で とれる）。
- **合成**: 刃の 風「シャッ」（帯を 動かす ノイズ）・はがねの 鳴り（くし形フィルタ）・「ぽん」「ぽよん」（サイン波）・響き（合成の 残響）。`render.py`・`common.py`。
- **オーナーの 見本**（on-jin `sen_ka_katana_kirikizamu02.mp3`）: 聞いて「シャキン を 何回も・高い 帯域が 多い・6 秒 ずっと 切る」と いう 性格を 決めるのに だけ 使った。切り出し・加工・まねて 写す は して いない。リポジトリに 入れて いない。
- 効果音の 生成サービス（ElevenLabs など）は この 環境に 使える 鍵が なく、外への 通信も 一部 だけ なので 今回は 使って いない。本物の 録音（CC0）＋ 合成で 作った。

## 作りなおし

```sh
sh docs/audio/WEAPON-9/fetch_samples.sh <リポジトリの 外の フォルダ>
python3 -I docs/audio/WEAPON-9/render.py <その フォルダ> docs/audio/WEAPON-9
python3 -I docs/audio/WEAPON-9/measure.py docs/audio/WEAPON-9
```

乱数は 案ごとに シード 固定（同じ 素材なら 同じ wav が できる。たしかめた）。

## ゲームに 入れる とき（えらばれた あと。sfx-designer へ）

- 雷神剣・風神剣の `src/fx/legendSounds.ts`（`claude/weapon-8-fujin` で 作り直し中）と ぶつからない ように、虹の 分は **別の 表・別の 名前**（例 `NIJI_FILES`・`playNiji()`、ファイルは `public/sound/niji/*.ogg`）。
- 斬撃は 段ごとに 3 とおり（`nijiSlash1_0..2`・`nijiSlash2_*`・`nijiSlash3_*`）、かき消す `nijiErase_0..2`、はじく `shiningHit_0..2`、ほかは 1 つずつ。直前と ちがう 物を えらぶ。同じ 名前の 重なりは 3 つまで（`LEGEND_MAX_SAME` と 同じ）。
- `combat.sounds()` の 名前（仕様 §11 の 表）に **斬撃（段）と かき消す の 名前が まだ ない** → designer に 仕様へ 足して もらう（例 `nijiSlash`〈段 1〜3〉・`domeErase`）。
- 大きさは ここの `TARGET` を そのまま（WAV が ゲームの ものさしの 大きさ）。その場で 聞いて `pickup` と くらべ ±2 dB で 合わせる。
