## 3 案

| 案 | 名前 | ひとことで | 作り |
|---|---|---|---|
| A | からくり やしき | こわれた おもちゃ箱（ゆがんだ オルゴール・木の 大だいこ・うなり・風）。今の 方向 B の まま こわく した。いちばん やさしい | コードで 合成（`songs.ts` の 書き方・`sfxVoices.ts` の 部品。ファイル なし） |
| **B（おすすめ）** | よるの おてら | 本物の 和太鼓・お寺の 鐘・尺八（合成）・風・しずく。二つ名の 出現音（版 B）と 同じ 素材なので、出現音から 挑戦の 太鼓へ ひとつながり。いちばん こわく 迫力 | ファイル（効果音ラボを 加工 ＋ 合成） |
| C | まじないの どうくつ | 弓で ひく ビブラフォン・ワイングラス・低い 木の つつみ・ハンドチャイム。ふしぎで ぶきみ（和風で ない） | ファイル（VCSL・CC0 ＋ 合成） |

- 3 案とも D（レ）が 中心。音ごとに 案を まぜられる。挑戦の 曲は 今の たたかいの 曲 ＋1 dB、ふんいきは 今の 曲 −4 dB、ずずんは 宝箱 4 段目・実績と 同じ くらいの 大きさ。
- 安全（§3.4 の 上限）: ゲームに 入れる 形（ogg）で ピーク −2.6 dBFS 以下、立ち上がり 0.28 秒 以上（ループは 2 秒 以上）。くわしい 数は 共有フォルダの README。

## 場面の つなぎ方（提案。designer・PO が 決める）

- ふんいき: 足が やかたに いる 間、今の BGM と 1.5 秒で 入れかえる（かった あとは 鳴らさない）。
- 挑戦の はじまり: ずずん ＋ 出現音（同じ コマ）→ 挑戦の 曲は 3.4 秒 あと から 1.5 秒で 入る（出現音と ぶつけない）。ふんいきは 曲の 下で −6 dB。
- かち: 曲・ふんいきを 0.8 秒で 消す → 門が ひらく 音・ファンファーレ → 宝箱 4 段目 → 実績（big を ずらす）→ 今の BGM。
- まけ: 挑戦の 曲を 0.8 秒で 消す。かなしい 曲は ない。

## 素材の 規約（えらばれたら ゲームの README と 仕様書にも 書く）

- 効果音ラボ（B）: 加工して ゲームに 入れて よい・商用 可・クレジット 任意・素材と 加工物の 再配布は 不可。元の 素材は リポジトリに 入れない（加工した ogg だけ）。
- VCSL（C）: CC0 1.0（パブリックドメイン）。
