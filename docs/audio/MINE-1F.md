## 場面の つなぎ方（決まり）

| とき | どうする |
|---|---|
| 足が あやしい 横穴・大広間に 入った（かつ まで） | 今の BGM（ひる・よる）を 1.5 秒の クロスフェードで **ふんいき** に かえる。出たら もとの BGM へ。かった あとは 鳴らさない。ふつうの 妖怪で たたかいに なった ときは 今の まま たたかいの 曲が 来て よい |
| 挑戦の はじまり（宝箱を あけた コマ） | 同じ コマで **ずずん**（「ず」が 0.5 秒 ＝ 門が せり上がり おわる 時）＋ 二つ名の 出現音（たいしょう 1 回）。**挑戦の 曲は 3.4 秒 あと から 1.5 秒で 入る**（出現音の 心臓・太鼓と ぶつけない）。ふんいきは 曲の 下で −6 dB に して のこす |
| かち（7 ひき目が たおれた コマ） | 挑戦の 曲・ふんいきを 0.8 秒で 消す → **ひらく** ＋ ファンファーレ（big）→ 1.3 秒 あと 宝箱 4 段目（big）→ 実績（big。宝箱の 音の あと）→ 今の BGM が 1.5 秒で 入る（big の 間は duck）。big は 1 つ ずつ なので 時刻を ずらす |
| まけ | 挑戦の 曲を 0.8 秒で 消して いつもの やられた。門が ひらく ときは **ひらく**。かなしい 曲は ない。BGM を 暗く しない |
| 一時停止・「動きを へらす」 | 一時停止で 曲も 止まる（今の BGM と 同じ）。「動きを へらす」でも 音は 同じ（門が すぐ ふさがる ときも 同じ ずずん） |
| 「効果音の 音量」「音楽の 音量」0 | その 音は 鳴らない |

## ゲームに 入れる とき（sfx-designer・developer へ。くわしくは 共有フォルダの README）

- ファイル: `public/sound/yakata/` に `ambience.ogg`（B1）・`challenge.ogg`（B3）・`gate_close.ogg`（B2 ずずん）・`gate_open.ogg`（B2 ひらく）と README（出どころ・規約）。
- 共有フォルダの wav は ゲームの ものさし。ogg に する ときは ループ **+12.4 dB**（÷ BGM 0.4 × 全体 0.6）・ずずん **+4.4 dB**（÷ 全体 0.6）。vorbis q3（ループは モノでも よい）。
- ループは がしゃどくろの BGM（`src/gasha/gashaBgm.ts`: BGM の 口 `bgmOut`・ふだんの BGM を `suppressBgm`）と 同じ 流し方。ファイル ぜんぶを ループ（余韻は 頭に たたんで ある）。ずずんは `legendSounds.ts` の `playFile` と 同じ 倍率。
- 名前の 案: `yakataAmbience`・`yakataChallenge`・`yakataGateClose`・`yakataGateOpen`。読めて いない・失敗した ときは 鳴らさず 止まらない（二つ名の 出現音と 同じ）。

## 素材の 規約（ゲームの README と 仕様書にも 書く）

- **効果音ラボ** https://soundeffect-lab.info/ の 和太鼓（ドン・ドドン・カカッ）・お寺の 鐘: 加工して ゲームに 入れて よい・商用 可・クレジット 任意。素材 そのものと 加工した 物の **再配布は 不可**（アプリの 中の 音・楽曲の 中に 組み込むのは 再配布で ない）。AI の 学習に 使わない（2026-11-06 に 規約を 確かめた）。
- 二つ名の 出現音の ときに とった 物（共有フォルダ `balance/sound/samples/`）を 使う。**元の 素材は リポジトリに 入れない**（入れるのは 加工した ogg だけ。`public/sound/nick/` と 同じ）。
- 風・しずく・尺八・うなり・石の ずりずり・響きは 合成（権利の 問題 なし）。
