# 音のきまり（SOUND.md）

- **決定: 案 B「木のおもちゃとオルゴール」**（2026-10-16 オーナーが `docs/audio/preview.html` を試聴して選んだ）。
- 上のきまり: `docs/rules.md`・`docs/fun.md`（くり返す音は控えめ・一定でない／大きく祝うのは達成だけ／失敗は明るくはずむ）。
- 音は外の素材を使わず、Web Audio の合成だけで作る（ライセンスの心配なし）。音のデータの正本は、ゲームに移したあとは `src/fx/` のコード。`preview.html` は「選んだときの見本」として残す（消さない・直さない）。
- **聞き比べの基準**: 作る係・見る係は、`preview.html` の案 B（BGM 3 曲・効果音 8 こ・MIX・VARY）と同じ聞こえ方になっているかで比べる。違えてよいのは、このファイルに書いた所だけ。

## 1. 音色とテンポ（案 B）

| 楽器（名前） | 作り方（preview の `instruments`） | 使う所 |
|---|---|---|
| オルゴール `musicbox` | sine ＋ 倍音 ×2（0.15）・×5.4（0.06）、立ち上がり 0.002 秒、1.4 秒で消える | メロディ、キラッ・チリン系の効果音 |
| マリンバ `marimba` | sine ＋ ×4（0.18）・×10（0.04）、0.45 秒で消える | 和音、コン・ポコ系 |
| マリンバの低い音 `mbass` | sine ＋ ×4・×2、0.6 秒 | ベース |
| 木琴 `xylo` | sine ＋ ×3・×6、0.3 秒 | たたかいのメロディ、明るい短い音 |
| ハミング `hum` | sine、ゆっくり入る（0.4 秒） | よるの下じき |
| 木の打楽器 `kit` | k = 低い木の「ドン」、w = ウッドブロック、h = シャカ（5 kHz より上のノイズ） | リズム |

効果音は、この楽器と同じ作り方の「部品」で作る（木 = マリンバ型、キラ = オルゴール型、シャカ・ザク = 角を丸めたノイズ、ぽわん = ゆっくり入る sine）。四角い波（square）は使わない。ノイズはシード付き（毎回同じ並び）。

## 2. 場面ごとの BGM

ゲームに今ある場面だけ。曲は案 B の 3 曲を正本にし、**長さだけ足す**（下の「長さ」。preview の 8 小節を頭に置き、同じ楽器・テンポ・和音の流れで続きを作る。足した部分はオーナー確認）。

| 場面 | いつ（ゲームの状態） | 曲 | テンポ・拍子・和音 | 曲の大きさ `level` | 長さ（ループ） |
|---|---|---|---|---|---|
| ひる | 時間帯 `day`・`dawn`（`time.phase()`） | B ひる | 108・3 拍子・G C D G Em C D G | 1.27 | 40 秒以上 |
| よる | 時間帯 `dusk`・`night` | B よる（こだまつき） | 72・4 拍子・F Dm Bb C | 1.48 | 40 秒以上 |
| たたかい | 近くの妖怪が `chase` か `attack`（下の判定）。時間帯より先 | B たたかい | 132・4 拍子・Am F G C Am F G E | 1.0 | 25 秒以上 |

- たたかいの判定: 妖怪の `state` が `chase`・`attack` で、プレイヤーから `battleRange`（16 ブロック）以内が 1 ぴき以上。`battleEnterTicks`（30 ステップ = 0.5 秒）続いたら たたかい、いなくなって `battleExitTicks`（240 ステップ = 4 秒）たったら もどる（行ったり来たりしない）。やられている（`combat.dead()`）あいだは判定しない（曲はそのまま）。
- ゆうがたの始め「ゴーン」・あさの始め「チュンチュン」（今の効果音）はそのまま鳴らし、そこで曲を入れかえる。
- **まだ無い場面**: はたけ・家の中・どうくつ。場所の判定がゲームに無いので、今は曲を作らない（判定ができたら、ここに 1 行足して曲を作る）。
- 遊びを続けても、テンポ・音量は上げない（fun.md §3）。

## 3. 音量のきまり（preview の `MIX` をそのまま使う）

| 名前 | 値 | 意味 |
|---|---|---|
| 全体の音量のはじめ `masterVolume` | 0.6 | 0〜1。はじめは小さめ |
| BGM の大きさ `bgmVolume` | 0.4 | 効果音を 1 としたとき（約 -8 dB） |
| 効果音の大きさ `fxVolume` | 今の設定の名前のまま | 0 で効果音だけ無音。中の倍率は「はじめの値で preview と同じ大きさ」になるよう合わせる |
| リミッター | threshold -14 dB・knee 6・ratio 4・attack 0.005・release 0.25 | 全体の最後 |
| 2 段目の天井 | 0.5 までそのまま、上を tanh で 0.85 までにおさえる | 連打で重なっても -1 dBFS を超えない |
| 達成のときの BGM 下げ `duck` | 0.45 倍・下げる 0.08 秒・保つ 1.4 秒・もどす 1.0 秒 | 大きく祝う音のときだけ。祝う音そのものは大きくしない |

- つなぎ方: `BGM → 曲ごとのフェード → BGM バス(bgmVolume) → duck → 全体(masterVolume)`、`効果音 → 効果音バス → 全体`。`全体 → ミュート → リミッター → 天井 → スピーカー`。
- 大きさの目安（はじめの設定・リミッターの前。preview の「数で見る」で案 B を測った値に ±2 dB で合わせる）: くり返す音（ほる・おく・あるく系）は ひろう より小さい。祝う音（levelUp・fanfare・modal）がいちばん大きいが、ひろう より +5 dB 前後（preview の案 B に合わせる）。BGM の平均は効果音の平均より 6〜10 dB 小さい。
- 急に大きな音を出さない: どの音も立ち上がりは 0.002 秒以上、音量を変えるときは 0.05 秒以上かけて変える（ぷつっと鳴らさない）。

## 4. 切り替え（ふわっと入れかえる）

| とき | どうする |
|---|---|
| はじめて鳴らす | 1.5 秒でふわっと入る（`fadeIn`）。プレイヤーが押した・クリックした後に AudioContext を作る（ブラウザのきまり） |
| 場面が変わった | 1.5 秒のクロスフェード（`crossfade`）。新しい曲は頭から。同時に鳴る曲は 2 つまで（3 つ目が来たら、いちばん古い曲を 0.1 秒で消す） |
| とめる | 0.8 秒で小さくして止める（`fadeOut`） |
| ループのつなぎ目 | 先読み 0.2 秒で予約し、切れ目なし（音の時計で予約。ゲームのステップに合わせない） |

## 5. 止めたとき・画面を開いたとき

曲は止めずに大きさだけ変える（0.3 秒かけて）。数は BGM にかける倍率（`screenLevel`）。

| 画面（`screen.mode()` など） | 倍率 | 理由 |
|---|---|---|
| あそぶ `play` | 1.0 | |
| もちもの・つくる・たんす `inventory` | 0.7 | 時間はゆっくり進む。少し下げる |
| 案内画面 `guide`（ロックが外れて止まっている） | 0.4 | 止まっていると分かる。止めはしない |
| おめでとう画面 `celebrate` | duck（0.45）を出ているあいだ保つ | 祝う音を目立たせる |
| やられた画面 | 1.0 | 失敗で BGM を止めない・暗くしない（fun.md §4） |
| タブを見ていない（`document.hidden`） | 0.8 秒で 0 → AudioContext を止める（suspend）。もどったら再開して 1.5 秒で入る | |

## 6. 効果音

### 6.1 共通のきまり（preview の `VARY`）
- **ゆらぎ**: 1 回ごとに、高さ ±cents・大きさ ±gain・長さ ±dur の中でずらす（シード付きの乱数）。続けて鳴らしても、だんだん大きく・高く・速くはしない。
- **和音合わせ**: `tones` = いまの BGM の和音の音（根音・3 度・5 度）から直前と違う音を選ぶ。`root` = 和音の根音に合わせる（短調なら「ミ」を半音下げる）。高さのある効果音は「ド（C）を根音」として作り、鳴らすときに動かす。BGM が無いときは C の和音。
- **今の良さを残す**: ほる「コツ」→ ひび「カッ」→ ひび最後 → 「キラッ」→ こわれる「ポン」と **段階で音が変わる** こと、ゆみの段 1・2・3 が上がっていくこと、めずらしさで音の数が増えること、続けて ひろう と少しずつ高くなること（上限あり・2.5 秒で もどる）。音の形（上がる・下がる・長さ）も今と同じにし、音色だけ B にする。
- **大きく祝う音（big）**: levelUp・fanfare・modal の 3 つだけ。鳴ったら BGM を duck する。

## 7. ミュートと音量の設定

| 何 | どこ | 中身 |
|---|---|---|
| ミュート | 案内画面（止まっているときに出る画面）の大きいボタン「おと」（スピーカーの絵。押すと ✕ の絵） | BGM も効果音も 0.05 秒で 0。もう一度押すともどる |
| 音量 | 案内画面の「おとの おおきさ」を開くと、つまみ 3 本「ぜんぶ」「おんがく」「こうかおん」 | `masterVolume`・`bgmVolume`・`fxVolume`（0〜1） |
| おぼえる | `localStorage` の `rikkun.audio.v1` | 次に開いたときも同じ（はじめは 0.6・0.4・今の fxVolume、ミュートなし） |
| テスト | `settings.get/set` | `masterVolume`・`bgmVolume`・`fxVolume`・`audioMuted`（true/false）。`set` したらすぐ効く |

文字はひらがな・カタカナ（漢字は使わない）。画面は HTML で重ねる。

**画面の配置**（案内画面の中。見た目の細かさはアートチーム）
- 案内画面の右下に、大きい丸いボタン「おと」（スピーカーの絵 ＋ 文字、64px 以上）。ふだんは、これだけが見える。
- 「おとの おおきさ」を押すと、ボタンの上に小さな枠が開き、つまみが 3 本、たてに並ぶ（上から「ぜんぶ」「おんがく」「こうかおん」）。つまみは 1 本ずつ大きく（高さ 40px 以上）、動かすと その場で音が変わる。もう一度押すと閉じる。
- 案内画面を閉じる（あそぶにもどる）と、枠も閉じる。あそぶ画面・もちもの画面には出さない。

## 8. テストで確かめる（`window.__rikkun.audio`）

音そのものはテストで聞けないので、**「何を鳴らすと決めたか」** をゲームに聞いて確かめる（音の時計に頼らない値）。

| 関数 | 返すもの |
|---|---|
| `audio.state()` | `{ context: 'none' / 'suspended' / 'running' / 'closed', scene: 'day' / 'night' / 'battle', song: 'day' / 'night' / 'battle' / null, songs: number（鳴っている曲の数）, screenLevel: number（§5 の倍率）, ducking: boolean, chord: string（いまの和音の名前。曲が無ければ 'C'）, master, bgm, fx: number, muted: boolean }` |
| `audio.chord()` | `{ name: string, root: number（0〜11。C = 0）, minor: boolean }` |
| `audio.sfx()` | 鳴らした効果音の記録（読むと空）: `{ name, semis, cents, chord, big, dropped }[]`（`dropped` = 数の上限で鳴らさなかった） |
| `audio.voices()` | `{ sfx: number, bgm: number }`（いま鳴っている部品の数） |

- 場面: `time.set` で時間帯を変える・妖怪を近くに出す → `audio.state().scene` が変わる（判定のステップ数で）。
- 和音合わせ: `audio.sfx()` の `semis` が、そのときの `chord` の音（根音・3 度・5 度）になっている。
- 数で見る（作る係・見る係）: 曲と効果音を OfflineAudioContext で書き出し、ピーク・いちばん大きい 50ms・平均・ループのつなぎ目の差を測る（preview の「数で見る」と同じやり方）。
