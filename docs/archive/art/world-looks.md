## おすすめ: **B ごつごつ**

1. オーナーの言葉「カクカクの形・レトロなドット感は残しつつ **表現力を上げる**」に いちばん合う。9×9×9 にした意味（形で表情を出す）が いちばん見える。C は形を使わないので、9×9×9 の よさが出にくい。
2. ばらばらの つぶ を使わず、3×3 の かたまり・くさむら・ひさし で作るので、マイクラの「ざらざら の箱」とは ちがう手ざわり。
3. キャラが いちばん はっきり見える（こい自然な緑 × ピンク、白い髪も 地面の前で目立つ）。
4. 性能は 仮の見た目の 約 1/5（15 万 三角形・6.6MB）。まだ でこぼこを足す よゆう がある。

次点は A つみき（いちばん やさしく、置く場所が分かりやすい）。「A の マス目の分かりやすさ」がほしければ、B の地面に うすい さかい線を足すことも できる（色だけなので 三角形は ふえない）。

- 3 案とも 世界のブロックは 動かない・光らない（点滅なし）。ほる・おく など くり返す行動の 演出は ここでは足していない。

## 開発チームへの申し送り（今回は直していない。PO が issue にするか決める）
1. **水の色を Look で変えられない**: 水は `ProtoScene` の 平らな半透明（`0x2f6fe0`）のまま。3 案とも同じ色に見える。`Look` に `water`（色・すき通り）を足してほしい。
2. **遠くの LOD は ゲーム本体の色**: 上空の絵の外がわ（かんたんメッシュ）は Look と関係なく 本体の色。霧で なじませている。決まった案の色に LOD の色を合わせる作業がいる。
3. **3D テクスチャの約束**: テクスチャは `exposed = ALL_FACES`・仮の位置（1000+）で `fill` を呼び、穴のマスは `base` 1 色になる。そのため 穴の形と色が ずれる。3 案は「`exposed === ALL_FACES` のときは 穴をあけない」で色を正しくした（6 面とも見える 宙に浮いた 1 個だけ へこまない）。きちんと直すなら `KindSpec` に「色だけを返す `color(x,y,z)`」を足し、テクスチャはそれで作るのが良い。
4. 案ごとの、世界のブロック以外（かまど・かわら・レンガ・たんす・はたけ・スプリンクラー）は 仮の色。選ばれた案で アートが作り直す。
