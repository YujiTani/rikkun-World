# rikkun-World 開発計画（v1.0）

> ステータス: **壁打ち中**。決まったことはここに追記していく。

## 1. 前提

| 項目 | 内容 |
|---|---|
| 動作環境 | M4 MacBook Pro |
| 遊ぶ人 | 6歳の男の子（りっくん） |
| 開発体制 | AI エージェントのチーム開発（[organization.md](./organization.md)） |
| 最初のゴール | **プロトタイプ**: 掘る → 作る → 食べる → モンスターと戦う が一通り遊べる |

## 2. 技術（決定）

**Web（TypeScript + Three.js）で作る。** M4 Mac のブラウザ（Chrome / Safari）で遊ぶ。アプリとしてのリリースは目指さない。

- 理由: テストチームの AI がブラウザを自動操作・スクショ確認できる／漢字のルビ（ふりがな）が HTML の `<ruby>` でそのまま使える
- 参考: Godot も検討した（物理・アニメーション・エディタが揃っている）が、AI による自動テストと画面確認のしやすさを優先して Web にした

## 3. 6歳向けのデザイン方針（決定）

| 項目 | 決定内容 |
|---|---|
| 文字 | ひらがな基本。カタカナ OK。漢字を使うときは必ずルビ（ふりがな）をふる |
| 視点 | 一人称と三人称をボタン 1 つで切り替えられる |
| モンスター | **妖怪**（詳細はモンスターを作るフェーズでオーナーと相談） |
| やられたとき | 持ち物の各スロットが **50% ずつランダム**でその場に落ちる。残りは持ったまま復活 |
| 操作 | まずキーボード＋マウス: 移動（WASD / 矢印）、ジャンプ（スペース）、クリックで掘る／攻撃、右クリックで置く／食べる。**ゲームコントローラーにも後で対応**（操作は「入力 → 行動」の変換層を挟んで作り、あとから足せる設計にする） |
| その他 | 起動したらすぐ遊べる、自動セーブ、迷子にならない小さめの世界 |

### やられたときのルール（決定）

- 判定はスロット（同じアイテムのまとまり）ごとに 50% でコイン投げ → 「落とす」スロットは全部その場に落ちる
- **手に持っているアイテムは守られる**（50% の対象外）
- 落としたアイテムは、やられた場所で光りながら待っている
- 落としたアイテムは **10 分で消える**

## 4. プロトタイプの機能一覧

| # | 機能 | 中身 |
|---|---|---|
| F1 | 世界 | ブロックでできた小さな島（草・土・石・木・鉱石） |
| F2 | 移動 | 歩く・ジャンプ・一人称／三人称の切り替え |
| F3 | 掘る・置く | ブロックを壊してアイテムになる／置ける |
| F4 | 持ち物 | ホットバー（下に9マス）と持ち物画面 |
| F5 | クラフト | 木の剣 → 石の剣、木のツルハシ → 石のツルハシ など（レシピは少数） |
| F6 | 体力・おなか | ハート表示。おなかが減る／食べると回復。やられたら 50% ロストして復活 |
| F7 | 食料 | りんご（木から）、お肉（動物から）、焼く？は後回し |
| F8 | 回復アイテム | 回復ポーション（簡単なレシピで作れる） |
| F9 | モンスター（妖怪） | 夜や洞窟で出る。近づいてくる、攻撃してくる、倒すとアイテム |
| F10 | 戦い | 剣で叩く、ダメージ・ノックバック、武器で強さが変わる |
| F11 | 昼と夜 | 夜はモンスターが出る（短めのサイクル） |

## 5. マイルストーン（決定: 戦いを M3 に前倒し）

| M | 名前 | できるようになること | 確認方法 |
|---|---|---|---|
| M0 ✅ | 準備 | 開発環境、エージェント定義、テストの仕組み、性能の計測の仕組み | 空の画面が出て自動テストが通る |
| M1 ✅ | 歩ける世界 | F1, F2 | 島を歩き回れる。**りっくんに操作だけ試してもらう** |
| M2 ✅ | 掘って置ける | F3, F4 | 土を掘って持ち物に入り、置ける |
| M3 | 戦う（最小） | F9, F10 と F6 の体力・やられて復活（50% ロスト） | 仮の妖怪 1 種と素手／木の剣で戦える |
| M4 | 作る | F5 | 木や石から剣・ツルハシを作って強くなれる |
| M5 | 生きのびる | F6 のおなか, F7, F8, F11 | おなかが減り、食べて回復。夜に妖怪が増える |
| M6 | **プロトタイプ完成** | 全体の調整、性能チューニング | りっくんが 15分 楽しく遊べる 🎉 |
| 後 | コントローラー対応 | ゲームコントローラーで遊べる | M1 の操作テスト次第で前倒し |

各マイルストーンの最後に **オーナー＋りっくんのプレイ確認** を入れる。
仕様確認（オーナー確認①）はマイルストーン単位でまとめて 1 回。

## 遊び方

- 基本: Mac で `npm run dev` → http://localhost:5173
- 予備: GitHub Pages。AI には GitHub Actions の設定ファイルを置く権限がないため、オーナーが `docs/setup/pages.yml` を `.github/workflows/pages.yml` にコピーし、Settings → Pages → Source を「GitHub Actions」にする。以後 `main` に入ると自動で公開
