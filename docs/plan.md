# rikkun-World 開発計画（ドラフト v0.1）

> ステータス: **壁打ち中**。決まったことはここに追記していく。

## 1. 前提

| 項目 | 内容 |
|---|---|
| 動作環境 | M4 MacBook Pro |
| 遊ぶ人 | 6歳の男の子（りっくん） |
| 開発体制 | AI エージェントのチーム開発（[organization.md](./organization.md)） |
| 最初のゴール | **プロトタイプ**: 掘る → 作る → 食べる → モンスターと戦う が一通り遊べる |

## 2. 技術の選び方（提案）

| 案 | 内容 | 良い点 | 気になる点 |
|---|---|---|---|
| **A. Web（TypeScript + Three.js）** ★おすすめ | Mac の Chrome/Safari で遊ぶ | インストール不要／AI が自動テスト・スクショ確認しやすい／修正がすぐ反映 | 本格的な重さの表現は控えめ |
| B. Godot エンジン | ゲームエンジンでアプリ化 | ゲーム向け機能が豊富 | AI の自動テストがやりにくい |
| C. Swift + Metal | Mac ネイティブアプリ | 最も高速 | 開発コストが高い、検証が Mac 必須 |

おすすめ理由: このプロジェクトは「テストチームが動作確認する」ことが大事。
Web なら AI がクラウド上でブラウザを動かして、画面を撮って確認できる。

## 3. 6歳向けのデザイン方針（案）

- **文字はひらがな＋アイコン**中心。読めなくても遊べる
- **怖すぎない**: モンスターはかわいい系（スライム、まるいゾンビ等）。血の表現なし
- **やられても大丈夫**: 倒れてもアイテムは無くならず、家の近くで復活
- **操作はシンプル**: 移動（WASD / 矢印）、ジャンプ（スペース）、クリックで掘る／攻撃、右クリックで置く／食べる
- **すぐ遊べる**: 起動したらすぐゲーム開始。セーブは自動
- **世界は小さめ**: 迷子にならない広さから始める

## 4. プロトタイプの機能一覧

| # | 機能 | 中身 |
|---|---|---|
| F1 | 世界 | ブロックでできた小さな島（草・土・石・木・鉱石） |
| F2 | 移動 | 歩く・ジャンプ・一人称視点 |
| F3 | 掘る・置く | ブロックを壊してアイテムになる／置ける |
| F4 | 持ち物 | ホットバー（下に9マス）と持ち物画面 |
| F5 | クラフト | 木の剣 → 石の剣、木のツルハシ → 石のツルハシ など（レシピは少数） |
| F6 | 体力・おなか | ハート表示。おなかが減る／食べると回復 |
| F7 | 食料 | りんご（木から）、お肉（動物から）、焼く？は後回し |
| F8 | 回復アイテム | 回復ポーション（簡単なレシピで作れる） |
| F9 | モンスター | 夜や洞窟で出る。近づいてくる、攻撃してくる、倒すとアイテム |
| F10 | 戦い | 剣で叩く、ダメージ・ノックバック、武器で強さが変わる |
| F11 | 昼と夜 | 夜はモンスターが出る（短めのサイクル） |

## 5. マイルストーン（案）

| M | 名前 | できるようになること | 確認方法 |
|---|---|---|---|
| M0 | 準備 | 開発環境、エージェント定義、テストの仕組み | 空の画面が出て自動テストが通る |
| M1 | 歩ける世界 | F1, F2 | 島を歩き回れる |
| M2 | 掘って置ける | F3, F4 | 土を掘って持ち物に入り、置ける |
| M3 | 作れる | F5 | 木から剣とツルハシを作れる |
| M4 | 生きのびる | F6, F7, F8 | おなかが減り、りんごで回復 |
| M5 | 戦える | F9, F10, F11 | 夜にスライムが出て、剣で倒せる |
| M6 | **プロトタイプ完成** | 全体の調整 | りっくんが 15分 楽しく遊べる 🎉 |

各マイルストーンの最後に **オーナー＋りっくんのプレイ確認** を入れる。
