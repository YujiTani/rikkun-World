# CHAR-1: プレイヤーのキャラモデルをオリジナルに（現代風お侍さん）

オーナー要望（2026-10-13）:
「キャラモデルもマイクラそのままなので、オリジナルモデルにしたい。キャラモデルだけ Blender を使って、現代風お侍さんみたいなキャラにしたい」
（きっかけ: WEAPON-2 の両手持ち・弓を引くポーズが、マイクラ型の人形では無理がある＝三人称で左手が刀に届かない、ひじを引けない）

## ねらい
- プレイヤーの人形（BlockDoll）を、Blender で作ったオリジナルのモデルに置きかえる。
- 見た目: **現代風のお侍さん**（6 歳がかっこいいと思う・こわくない・ちびキャラ寄りの等身でもよい）。ほかはブロックの世界なので、ローポリ＋ドット絵っぽいテクスチャで世界になじませる。
- ひじ・ひざ・手首が曲がる骨（リグ）を入れ、WEAPON-2 の構え（中段・上段・下段）・技（突き・大げさ斬り・切り上げ）・弓を引く・歩く・ジャンプ・たたく・ほる・投げる・やられる を アニメーションで作る（両手持ちで ちゃんと両手が刀に届く）。
- 防具（かぶと・よろい・こて・すねあて）を着た見た目も付けかえられる。

## 決めること（デザイナー → オーナー確認①）
- 姿・色・等身・顔（ラフ案を 2〜3 種、絵で見せる）。
- 骨の数とアニメーションの一覧、Three.js での読み込み方（glTF/GLB、GLTFLoader、AnimationMixer）。
- 一人称の手（刀・弓の持ち方）もこのモデルの腕にするか。
- 性能（ポリゴン数・描画回数の上限）。
- 作り方: クラウドで Blender をコマンドで動かせるか（bpy・スクリプトでモデルを作る）を調べ、できなければ Python スクリプトで glTF を直接作る方法も比べる。
