## 4. ゲームで今できること（モデルが対応すること）

オーナーの要望ではない。今のゲームにある動きと装備で、新しいモデルでも見せる必要があるもの。

- **動き**:
  - 立つ・歩く・ジャンプ
  - たたく・ほる・ブロックをおく・なげる
  - ダメージを受けてよろめく・たおれる
- **刀（WEAPON-2）**:
  - かまえは中段・上段・下段の 3 つ（R キーで切りかえ）。
  - わざは、突き・大げさ斬り・切り上げ。
  - **刀は両手で持ち、両手がちゃんと刀に届く**。
- **弓**: 3 段階に引く。ひじを後ろに引く。
- **防具 4 つ**: かぶと・よろい・こて・すねあて。それぞれ付けたりはずしたりでき、付けた見た目が変わる。
- **手に持つもの**: どうぐ・ブロック・刀・弓・食べ物など。

## 6. ゲームとつなぐときのメモ（作り方は自由）

- ゲームは Three.js で動いている。モデルは **glTF（.glb）** で書き出すと読みこみやすい（`GLTFLoader` と `AnimationMixer`）。
- 性能の目安: オーナーの M4 MacBook Pro のブラウザで、なめらかに動くこと。クラウドでは GPU がないので、描画回数と三角形の数で比べる。今の箱人形の描画回数は約 20。
- 今の人形の口（ゲームが人形に命令する関数）は `src/camera/BlockDoll.ts` と `src/camera/CameraRig.ts` にある。新しいモデルは、これと同じことができるようにつなぐ。
- 作ったモデルを入れたら、ゲームにつなぐ作業と、テストの直しはクラウドの PO がチームに頼める。
