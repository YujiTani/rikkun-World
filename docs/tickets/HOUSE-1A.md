## やること

1. 建築士さんを 出す: 最初の 1 人は 始まりの 場所から 横 6〜10 マス（`first:true`）。ほかは 192×192 区画に 0 か 1 人（3 区画に 1 人）、シードで 決まる、水の 上には 出さない。
2. 体力なし（たたいても 消えない）。妖怪は ねらわない。自分の 場所から 横 3 マス以内を ぶらぶら。
3. 右クリックで 話す: うなずき（22 ステップ）→ ふきだし・声 → メニュー（§2.3 の ならび。この 票で 動く ボタンは くら・どうぐを もらう・とじる。ほかの ボタンは 出すが HOUSE-1B 以降で つなぐ）。
4. 初めて 話すと みずもり・どうづき を 1 こずつ もらう（アイテムだけ。はたらきは HOUSE-1C）。両方 なくしたら「どうぐを もらう」で もどる。
5. くら: あずける・とりだす（好きな 数・ぜんぶ）、1 種 999、種類は 無制限、建築士さん どうしで 共有。1 マス 1 こしか 重ならない 物（刀・せっけいず・キット）は あずけられない。
6. メニュー・くらが 開いている 間は 時刻・妖怪が 止まる（本の 画面と 同じ）。
7. 保存: くら・建築士さんの 記録（最初の 1 人・道具を もらったか）。古い セーブは くら 空・最初の 建築士さんが いる。
8. テスト用 フック `window.__rikkun.house`: `architects()`・`talk(id)`・`menu()`・`press(id, arg?)`・`kura()`・`deposit(item, n)`・`withdraw(item, n)`（形は §6.1）。
