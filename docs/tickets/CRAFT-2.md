## 目的（オーナーの言葉で・2026-10-14）
1. すべての「つくる」アクションに必要な素材は、プレイヤーが手持ちやカバンに入れていようと、タンスにしまっていようと、等しく素材として使えるようにする。
2. 手持ち以外から使ったときは、どこから使ったのかをログに表示する。
3. ログの履歴を見られる UI を用意する。各ログは、カテゴリーごとに色分けされたアイコンの後ろに、白テキストで表示する。
4. すべての UI を半透明にして、ゲーム画面を圧迫しすぎないようにする。ただし、テキストの視認性は下げない。

## やること
- 仕様書 `docs/design/CRAFT-2.md`（デザイナー 1 人）。決めること:
  - **対象のアクション**: つくる画面のレシピに加えて、かまど（材料・燃料）、防具、ほか素材を使う所を洗い出し、どれを対象にするか。
  - **素材の使い方**: 手持ち（ホットバー）→ カバン → タンス の順に使うか。数の表示（つくる画面の「もっている数」）に、タンスの分を足すか。足りるかどうかの判定、足りないときの見え方。
  - **どのタンスか**: 世界のすべてのタンスか、近く（半径 N マス）のタンスだけか。遠いタンスのときの考え方（6 歳が混乱しない）。複数のタンスから取る順番。
  - **ログ**: 文言（ひらがな・カタカナ。漢字はルビ）、どこから使ったかの出し方（例: 「タンス（x,y,z の近く）から 〇〇 を 3 こ つかった」）。今の拾ったログ（`src/ui/pickupLog*`）・お知らせ（`src/ui/notice*`）との関係（ひとつにまとめるか、並べるか）。
  - **ログの履歴 UI**: どう開くか（キー・ボタン。操作はアイコン優先）、何件まで残すか、スクロール、保存するか（セーブに入れるか、起動中だけか）。
  - **カテゴリーと色**: ログのカテゴリー（例: つくる・拾う・戦い・農業・お知らせ…）を洗い出し、色分けアイコンの色と形（色だけに頼らない: 形も変える）。白テキストの読みやすさ（アイコン〈色つきの丸や角〉の後ろに白文字）。
  - **半透明 UI**: すべての UI パネル（ホットバー、もちもの、つくる、タンス、案内画面、HUD ほか）の背景の透明度の基準値（設定で持つ）。文字の視認性を保つ方法（文字の影やふち、パネルの暗さの下限）。ゲーム画面が透けるので、明るい場面でも白文字が読めること。
- 受け入れ基準は `window.__rikkun` のフックでテスト可能に（素材の判定・減らす順番・ログの中身・履歴の件数・透明度の値）。
- 絶対ルール（ひらがな・ふりがな・アイコン優先・怖くない）を守る。
