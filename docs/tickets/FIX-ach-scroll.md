# FIX-ach-scroll: じっせき の分類ページが縦にスクロールできない

オーナー報告（2026-10-13、スクショあり。Mac のブラウザ）: じっせき 画面の各分類（あつめる・たたかう など）の中に実績がいくつもあるのに、縦スクロールができず、見えている 6 こしか確かめられない。

## やること
- 分類ごとの実績の一覧（右側のカード）を、パネルの中で 縦にスクロールできるようにする（マウスのホイール・トラックパッド・スクロールバーのドラッグ）。
- PR #14 で「一覧と分類の列をスクロール」にしたはずなのに効いていない原因を調べて直す（高さが決まっていない・overflow が親で切られている・ホイールを ほかの所（ゲームの入力や pointer lock の見張り）が止めている、など）。
- 分類を切りかえたら 一覧のいちばん上にもどる。
- E2E: 実績が 6 こより多い分類（あつめる・たたかう）で、ホイールを回すと 一覧が動き、いちばん下のカードが見えるようになる（960×540 と 1280×720 と 1440×900）。実際の `page.mouse.wheel` で確かめる（scrollTop を直接いじらない）。
