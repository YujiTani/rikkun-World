# FIX-fall-reach: 妖怪が高い所から降りる・落下ダメージ・攻撃の当たり判定を広く

オーナー要望（2026-10-12）:
「モンスターが高い場所にいる場合、降りてはこれるようにして。あと落下ダメージも実装しましょう。
敵も味方も攻撃の当たり判定がシビアなので、もう少し広くして欲しいです」

## 1. 妖怪が高い所から降りる
- プレイヤーが低い所にいるとき、妖怪は段差（何マスでも）から歩いて降りて近づく。今は降りずに止まっている原因を調べて直す。
- 降りられるのに崖のふちで止まり続けない。みず には今までどおり入らない（落ちる先が みず の列なら降りない）。
- 浮いている妖怪（ちょうちん など、もし飛ぶなら）は今の動きのまま。

## 2. 落下ダメージ（プレイヤー・妖怪の両方）
- 落ちた高さ h（落ち始めの y − 着地の y、マス）が 3 以下なら 0。4 以上なら ダメージ = h − 3（体力の単位。1 = ハート半分）。
- みず に着地したら 0。はしご等はないので考えない。ジャンプの着地（1 マス程度）は 0。
- 防具では減らさない（ぼうぐ は たたかい用）。プレイヤーは ダメージのときの点滅は出す。ノックバックはしない。
- 妖怪も同じ式。落下で倒れたら、ふつうに倒したのと同じ扱い（ドロップ・経験値はなし でよい。倒した人がいないため）。
- 値は設定ファイルに置く（safeFallHeight = 3, perBlock = 1）。
- 死んだときの流れは今の死亡処理に乗せる（50% ドロップ など）。

## 3. 攻撃の当たり判定を広く（敵も味方も）
- プレイヤーの攻撃（素手・ぶき・や）: 今の当たり判定（届く距離・妖怪の当たり箱）を調べ、届く距離 +0.5 マス、妖怪の当たり箱を左右・上下に 0.3 マスずつ大きく（攻撃を受ける判定用。ぶつかり・移動の箱は変えない）。
- 妖怪の攻撃（かみつき・ふみつけ・たいあたり・火の玉 など）: 届く距離 / 当たる半径を 約 +0.4 マス（または約 1.3 倍）。火の玉の当たる半径も広げる。
- ろくろくび の首（射程 8）は射程はそのまま、当たる太さだけ広げる。
- 変えた数値は前と後を返答とこのタスク票の末尾に表で書く。

## テスト
- ユニット: 落下 3 マスで 0、5 マスで 2、みず で 0、妖怪も同じ。少し外れた位置で攻撃が当たる（前は外れた位置）。
- 妖怪が 5 マスの段差の上から、下のプレイヤーへ降りてくる（ai のシミュレーション）。
- `npm run check:fast` と、関係する E2E（m3 / m4 の戦い）を通す。

## 追加のオーナー要望（2026-10-12 その2）
「からかさおばけだけは、高いところから降りてくる時に、落ち葉のようにゆらゆらと大きく揺れながら落ちてきてください。
妖怪も、苦手じゃない妖怪は水の中にも追いかけてきてください。
その代わりプレイヤーも妖怪も水の中に入ると、動きづらくなります。」

### 4. からかさ は落ち葉のように落ちる
- 2 マス以上の段差から降りるとき（足もとが空になったとき）、ゆっくり落ちる: 落ちる速さは 最大 2 マス/秒。
- 落ちる間、左右に大きくゆれる: 横に ±0.8 マスくらいを 約 1.2 秒で 1 往復。体も ゆれに合わせて ±25° くらい かたむく。
- 着地したら元の向きにもどる。からかさ は落下ダメージを受けない。
- ゆれは見た目と位置の両方（横にずれる）。ゆれた先が かべ なら ずれない。

### 5. 水に入る妖怪・入らない妖怪
- みず が苦手（入らない・落ちる先が みず なら降りない）: ちょうちん（火が消える）、からかさ（紙がぬれる）。
- 平気（みず の中まで追いかける）: ぬりかべ、ろくろくび。
- 生まれる場所は今のまま（みず の列には出ない）。
- 苦手かどうかは stats（妖怪ごとの設定）に `avoidsWater` で持つ。

### 6. 水の中は動きづらい（プレイヤーも妖怪も）
- 体（足もと か 腰）が みず のマスにあるあいだ、歩く速さ ×0.5、ジャンプの高さ ×0.6。
- 値は設定に置く（waterSpeedMul = 0.5, waterJumpMul = 0.6）。
- テスト: みず の中で 1 秒歩いた距離が 外の約半分。ぬりかべ は みず に入って追いかけ、ちょうちん は入らない。からかさ の落下は 2 マス/秒 以下で横にゆれる（位置の x/z が変わる）。

## 追加のオーナー要望（2026-10-12 その3）ぬりかべ を強く
「ぬりかべは、常にスーパーアーマーにして、体力も4倍にしてください。攻撃力も4倍にして。
ぬりかべが倒れたばしょのブロックは全部壊れるようにしましょう。現状弱すぎます。顔も少し怖くして」

### 7. ぬりかべ
- **スーパーアーマー**: 攻撃を受けても のけぞらない・ノックバックしない・攻撃の動き（のけぞり→たおれこみ）が止まらない。ダメージ（点滅）は受ける。
- **体力 ×4**: 今の値（12）→ 48。
- **攻撃力 ×4**: 今の値（たおれこみ・体当たり とも）を 4 倍。
- **たおれこんだ場所のブロックをこわす**: たおれこみ攻撃が地面に着いた瞬間、たおれた体が重なるマス（体の幅×長さ×高さ）と、その真下 1 段のブロックを全部こわす。
  - こわさないもの: はじめの たいまつ（start_torch）、みず、いちばん下の段（y=0）。
  - こわれたブロックは 落とし物にならない（消える）。こわれるときに ほったときと同じ くだける見た目（つぶ）を出す。
  - 明るさ・メッシュの作り直しは 1 回にまとめる（1 マスずつ作り直さない）。
- **顔を少し怖く**: つり上がった太いまゆ、にらむ目（白目に小さい黒目）、横に大きい口に四角い歯。血・赤いしたたりはなし（6 歳ルール）。シルエットは今のまま。
- テスト: 48 で倒れる、ノックバック 0、たおれこみで前のブロック（木・石・置いたブロック）がこわれる、start_torch はこわれない。

## 追加のオーナー要望（2026-10-12 その4）ぬりかべ は みず に弱い
「ぬりかべは水の中に入ると徐々に固まってただの石のブロックに変化してください。水に弱いので」

### 8. ぬりかべ が みず で石になる
- ぬりかべ は §5 のとおり みず に入って追いかける（入るのをいやがらない）。
- 体（足もと）が みず のマスにあるあいだ「かたまり」がたまる: 3 秒（180 ステップ）で石になる。みず から出ると 1 秒に 1/3 ずつ もどる。
- かたまっていく間: 動きがだんだん おそくなる（かたまり 0→1 で 速さ ×1→×0.2）、色がだんだん 灰色の石の色に変わる、攻撃しない（かたまり 0.5 以上）。
- 石になった瞬間: ぬりかべ は消え、体が重なっていたマスのうち 空気・みず のマスを 石（stone）ブロックにする（ほかのブロックは上書きしない）。くだけるつぶ と「ゴトッ」の音。
- 倒したあつかい: 経験値とドロップはふつうに出す（みず に さそいこんだのは プレイヤーの作戦なので）。実績の「たおした」にも数える。
- テスト: みず の中で 180 ステップで石ブロックになる、途中で出るともどる、経験値が入る、ほかのブロックを上書きしない。

## 追加のオーナー要望（2026-10-12 その5）防具の役わり分け
「落下ダメージは、くつを装備していたら軽減します。なので、くつは通常ダメージは軽減しません。
頭を装備していると、玉属性のダメージを軽減します。通常ダメージは軽減しません」

### 9. ダメージの種類と防具
- ダメージに種類をつける: `normal`（かみつき・ふみつけ・たいあたり・たおれこみ・首）、`ball`（玉: ちょうちん の火の玉。今後の 飛んでくる玉 も）、`fall`（落下）。
- へらし方（どれも「受けるダメージ − へらす量」）:
  | 防具 | normal | ball | fall |
  |---|---|---|---|
  | かぶと（頭） | へらさない | −2 | へらさない |
  | よろい（体） | −2 | へらさない | へらさない |
  | こて（うで） | −1 | へらさない | へらさない |
  | すねあて（くつ） | へらさない | へらさない | −2 |
- normal と ball は へらしても 最低 1（ハート半分）。fall は 0 まで へる（すねあて があれば 4〜5 マスの落下は 0）。
- 値は設定（`src/craft/config.ts` の armorValue を種類ごとの表にする）。
- ツールチップの説明（`tooltipModel.ts`「カキン と ふせぐ」）を部位ごとに: かぶと「たま から まもる」、よろい・こて「こうげき から まもる」、すねあて「おちても いたくない」。案内画面の防具の説明も合わせる。
- テスト: 表の 4×3 の組み合わせ、最低 1 / 0 のちがい。
