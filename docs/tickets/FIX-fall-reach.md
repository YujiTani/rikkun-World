# FIX-fall-reach: 妖怪が高い所から降りる・落下ダメージ・攻撃の当たり判定を広く

オーナー要望（2026-10-12）:
「モンスターが高い場所にいる場合、降りてはこれるようにして。あと落下ダメージも実装しましょう。
敵も味方も攻撃の当たり判定がシビアなので、もう少し広くして欲しいです」

## 1. 妖怪が高い所から降りる
- プレイヤーが低い所にいるとき、妖怪は段差（何マスでも）から歩いて降りて近づく。今は降りずに止まっている原因を調べて直す。
- 降りられるのに崖のふちで止まり続けない。みず には今までどおり入らない（落ちる先が みず の列なら降りない）。
- 浮いている妖怪（ちょうちん など、もし飛ぶなら）は今の動きのまま。

## 2. 落下ダメージ（プレイヤー・妖怪の両方）
- 落ちた高さ h（落ち始めの y − 着地の y、マス）が 3 以下なら 0。4 以上なら ダメージ = h − 3（体力の単位。1 = ハート半分）。
- みず に着地したら 0。はしご等はないので考えない。ジャンプの着地（1 マス程度）は 0。
- 防具では減らさない（ぼうぐ は たたかい用）。プレイヤーは ダメージのときの点滅は出す。ノックバックはしない。
- 妖怪も同じ式。落下で倒れたら、ふつうに倒したのと同じ扱い（ドロップ・経験値はなし でよい。倒した人がいないため）。
- 値は設定ファイルに置く（safeFallHeight = 3, perBlock = 1）。
- 死んだときの流れは今の死亡処理に乗せる（50% ドロップ など）。

## 3. 攻撃の当たり判定を広く（敵も味方も）
- プレイヤーの攻撃（素手・ぶき・や）: 今の当たり判定（届く距離・妖怪の当たり箱）を調べ、届く距離 +0.5 マス、妖怪の当たり箱を左右・上下に 0.3 マスずつ大きく（攻撃を受ける判定用。ぶつかり・移動の箱は変えない）。
- 妖怪の攻撃（かみつき・ふみつけ・たいあたり・火の玉 など）: 届く距離 / 当たる半径を 約 +0.4 マス（または約 1.3 倍）。火の玉の当たる半径も広げる。
- ろくろくび の首（射程 8）は射程はそのまま、当たる太さだけ広げる。
- 変えた数値は前と後を返答とこのタスク票の末尾に表で書く。

## テスト
- ユニット: 落下 3 マスで 0、5 マスで 2、みず で 0、妖怪も同じ。少し外れた位置で攻撃が当たる（前は外れた位置）。
- 妖怪が 5 マスの段差の上から、下のプレイヤーへ降りてくる（ai のシミュレーション）。
- `npm run check:fast` と、関係する E2E（m3 / m4 の戦い）を通す。
