# FIX-action-hint: ねらっている所で「右クリックすると どうなるか」を出す

オーナー要望（2026-10-12）:「アクションが増えてきたので、フォーカスしているブロックに右ボタンを押下するとどうなるか、UIで表示してあげる機能が欲しい」

## きまり（PO 決定）
- 画面中央の照準（＋）の すぐ下に、小さなチップで「右クリック: 〇〇」を出す（文が主役。漢字は ruby で ふりがな。例「右クリック: たんす を ひらく」「右クリック: ブロック を おく」「右クリック: かぶと を きる」「右クリック: かまど を ひらく」「右クリック: や を うつ（ひきしぼる）」）。
- 左クリックも 意味があるときは 2 行目に出す（例「左クリック: ほる」「左クリック: たたく」）。出しすぎないよう、ほる・たたく は 薄めでよい。
- 何も起きないときは 出さない。
- **右クリックで実際に起きることと 必ず同じ** にする: `DigSystem` の右クリックのふりわけ（たんす → かまど → 防具 → … → 置く）と同じ判定を「やったら どうなるか だけ返す関数（previewRightClick）」として 1 か所に作り、実行と表示の両方が それを使う。
- あとから増える動き（M7 の たがやす・まく・たべる・しゅうかく、WEAPON-2 の 構え）は、その関数に 1 行足せば 出るようにする（M7・WEAPON-2 の仕様に そう書いておく）。
- もちもの画面などを開いているとき・おめでとう画面のときは 出さない。
- 設定で 消せる（`actionHint: true`）。
- 窓口: `hud.actionHint()` → `{ right?: string, left?: string }`。

## テスト
- ユニット: 持ち物 × ねらうブロック の組み合わせで previewRightClick と 実際の右クリックの結果が同じ。
- E2E（1 ファイルだけ回す）: たんす・かまど・つち・何もない所 を ねらって 文が かわる。
- スクショ: docs/screenshots/fix-action-hint.png

## 追加（オーナー要望 2026-10-12）アイコン中心に
- 「左クリックの動きもわかりやすく。テキストが多いと見づらい。アイコンで分かりやすくできれば それを採用」
- PO 決定: ヒントは **アイコン中心**。1 つのヒント = 「マウスの絵（L か R のボタンが光る）」＋「すること の絵」＋ 小さな 1 語（例「ひらく」）。文（右クリック: 〇〇 を 〇〇）は やめる。
  - すること の絵: ほる = ツルハシ（持っている道具の絵）、たたく = こぶし or 持っている武器、うつ = ゆみ、ひらく = ねらった たんす／かまど の絵、きる = その防具の絵、おく = 持っているブロックの絵。あとで たがやす = くわ、まく = たね、たべる = やさい、しゅうかく = かご など。
  - 右と左を 横に並べる（左クリックは左、右クリックは右）。照準の下、小さく・うすい下地。
  - 1 語の文字は 小（16px）。アイコンは 32px くらい。
- **左クリックの「たたく」**: 妖怪をねらっているかを返す窓口（PunchGate か 戦いの側）を足して、妖怪が手前なら「たたく」（武器の絵）を出す。
- テスト・スクショを 新しい形に合わせる。
