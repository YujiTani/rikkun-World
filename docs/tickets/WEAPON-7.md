## PO が決めた初めの値（仕様でたしかめて直してよい）
- どの武器: いまほし 7（`legendary`）の武器は 0 本。PO の推奨は **金の かたな**（ゴールドシリーズ #222 の 1 本目。めずらしさ `legendary`、金のたまごで作る）。yuzu にカードで聞いている（答えで変わったら ここを直す）。チャージが出るかは `rarityAtLeast(item, 'legendary')` で聞く（RARITY-7 §4.6）。金のたまご（#65）がまだないので、この issue ではレシピは仮（テストとデバッグで渡す）。
- 金の かたな の数: 強さ・たいきゅう・材料は 2〜3 案 → yuzu。かまえ・わざ・絵は今の刀を使い回す（色だけ金）。きらめく カタナの 3 段攻撃は つけない（それぞれの特色を分ける）。
- 押し方: **ひだりクリックを押しっぱなしで ためる → はなすと チャージわざ**（ゆみと同じ手ざわり）。この武器では「押しつづけで同じわざをくり返す」の代わりになる。短く押してはなせば 今のかまえの ふつうのわざ。
- ため: 段（例 2 段）と最大までの時間、ためている間の歩く速さ、ためが分かる見た目と音（ゲージは出さない方向。ゆみの段と同じ考え）。
- チャージわざ: かまえごとに変えるか 1 つにするかは仕様が決める。強さは BALANCE.md をこわさない（ためた時間ぶん損しない・強すぎない）。決めは ふっとび・小さなゆれ。fun.md のきまり。
- パリィ（Shift＋攻撃）・向き（WEAPON-3）・ふみこみ（WEAPON-4）とぶつからないこと。ためている間に Shift＋攻撃なら？も仕様で決める。
- 動き: docs/art/MOTION.md のものさし。新しい絵がいるかは仕様が決める（できれば使い回し）。
- ルールブック #42 に足す項目（`fight-charge`。BOOK-1）。
