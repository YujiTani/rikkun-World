# FIX-m6-scroll: もちもの・作る・じっせき の画面がはみ出す・かくかくする

オーナー報告（2026-10-12、Mac のブラウザ。スクショの画面は 約 1000×560 の CSS ピクセルで、1280×720 より小さい）:
1. もちもの画面の アイテムの説明（ツールチップ）が「…」で途中で切れる → 省略せず全部見せる。長いときはツールチップの中をスクロール。
2. 作る画面で マスにカーソルを合わせると、せつめい パネルの高さがアイテムごとに変わって画面がかくかくする → パネルの大きさを一定にし、中身が多いときはパネルの中をスクロール（つくる ボタンはいつも見える下に固定）。
3. じっせき ページ: 実績の一覧が画面の下で見切れる（分類の列の「ばしょ」も切れている）→ 一覧と分類の列を それぞれスクロールできるようにして、パネルの中に収める。
4. 実績にカーソルを合わせたときの説明が画面の外に出る → 画面の中に収める。画面の下の方なら カーソルの上に出す、右はしなら左に出す。もちもの のツールチップも同じきまりにする。

## きまり
- パネル・ツールチップは どの画面の大きさ（最小 960×540 くらいまで）でも画面の中に収まる。はみ出す所は スクロール（スクロールバーは S1 の部品の色に合わせ、細めに）。
- 大きさは中身で変わらない（作る画面の せつめい パネル・じっせき の一覧）。
- 文字の大きさの段階・色は M6 のスタイルのまま。

## テスト

## 追加（オーナー要望 2026-10-12）画面の大きさに左右されない
6. **どの画面の大きさでも同じように使える**ようにする（ブラウザの窓を小さくしても・大きくしても・縦横の比がちがっても）。
   - パネル（もちもの・作る・じっせき・たんす・かまど・案内・おめでとう）は 画面に合わせて大きさを決める（vw/vh・clamp・全体の縮小）。はみ出すときは 決めた所だけスクロール。
   - HUD（ホットバー・じぶん・時計・ログ）も 画面のはし・下に そろえたまま、小さい画面では 縮む。
   - ツールチップ・説明は いつも画面の中。
   - 窓の大きさを 変えたら（resize）すぐ 合わせ直す。
   - E2E: 960×540・1280×720・1920×1080・1024×768（4:3）・1440×900 で、各パネルと HUD が 画面の中に収まり、重ならないこと。スクショは 960×540 と 1920×1080。

## 追加（オーナー報告 2026-10-12 その2）
7. **D キーで右に動かない気がする**（WASD の D）。`src/input/actions.ts` には `KeyD: 'moveRight'` があるので、ほかの所（M6 で足した keydown の見張り: celebrate の guard・dragOut・たんす・Shift の修飾キー など）が D を止めていないか、moveRight の使われ方を調べて直す。E2E: 実際の `page.keyboard.down('KeyD')` で プレイヤーが右へ動く（W・A・S・D 全部と、Shift を押しながらも）。
8. **もちもの画面に、そこでできる操作を出す**。わかりやすく シンプルな ひらがなの文で、画面の下に 1〜2 行（S1 の小さいチップの部品）。例:
   - 「Q: 1こ すてる」「Shift＋Q: ぜんぶ すてる」「わくの そとへ ひっぱる: すてる」「Shift＋クリック: いっきに うつす」「E: とじる」
   - たんす を開いているときは「Shift＋クリック: たんす へ うつす」などに変える。じっせき タブでは出さない。
   - キーは キーの形の絵（案内画面と同じ）で見せる。
