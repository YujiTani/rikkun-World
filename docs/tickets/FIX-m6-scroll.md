# FIX-m6-scroll: もちもの・作る・じっせき の画面がはみ出す・かくかくする

オーナー報告（2026-10-12、Mac のブラウザ。スクショの画面は 約 1000×560 の CSS ピクセルで、1280×720 より小さい）:
1. もちもの画面の アイテムの説明（ツールチップ）が「…」で途中で切れる → 省略せず全部見せる。長いときはツールチップの中をスクロール。
2. 作る画面で マスにカーソルを合わせると、せつめい パネルの高さがアイテムごとに変わって画面がかくかくする → パネルの大きさを一定にし、中身が多いときはパネルの中をスクロール（つくる ボタンはいつも見える下に固定）。
3. じっせき ページ: 実績の一覧が画面の下で見切れる（分類の列の「ばしょ」も切れている）→ 一覧と分類の列を それぞれスクロールできるようにして、パネルの中に収める。
4. 実績にカーソルを合わせたときの説明が画面の外に出る → 画面の中に収める。画面の下の方なら カーソルの上に出す、右はしなら左に出す。もちもの のツールチップも同じきまりにする。

## きまり

- 大きさは中身で変わらない（作る画面の せつめい パネル・じっせき の一覧）。
- 文字の大きさの段階・色は M6 のスタイルのまま。

## PO 決定（2026-10-12）5. ねんりょう を えらぶ（M4 仕様の変更）
- M4 は「せきたん → あぶら → き の順に自動」だったが、オーナーは えらびたい → 仕様を変える。
- やく タブの せつめい パネルに「ねんりょう」の行を足す。持っている ねんりょう（せきたん・あぶら・き）を アイテムの絵のチップで並べ、クリックで えらぶ（えらんだ物は アクセントのわく）。持っていない物は出さない。
- はじめは 今の自動の順の先頭を えらんだ状態。えらんだ物は 覚えておく（保存しなくてよい）。えらんだ物が 0 こになったら 自動の順の次へ。
- やく ときは えらんだ ねんりょう を使う。窓口: `craft.fuel()`（えらんでいる物）・`craft.setFuel(id)`。
- E2E: せきたん と き を持って き を えらぶと き が へり、せきたん は へらない。

## 追加（オーナー報告 2026-10-12 その4）たんす
10. **とじる ボタンが 2 こ**（もちもの画面の右上 と たんす の見出し）→ 右上の 1 こ だけにする（たんす の見出しの とじる は消す）。
11. **たんす に いっきに しまう・えらんで しまう**（PO 決定）。たんす の見出しの右に ボタンを並べる（S1 のボタン部品、ひらがな）:
   - 「ぜんぶ しまう」: もちもの の上 3 だん（27 マス）の中身を たんす へ（ホットバー と そうび は うごかさない）。入りきらない分は もちもの に のこる。
   - 「おなじ もの を しまう」: たんす に もう ある アイテム と おなじ ものだけ、もちもの（ホットバー以外）から しまう。
   - 「ぜんぶ とりだす」: たんす の中身を もちもの へ（入る分だけ）。
   - えらんで しまう: Ctrl（Mac は ⌘）を おしながら もちもの の マスを クリックすると ✓ が つく（もう一度で はずれる）。✓ が 1 こ以上あると「えらんだ もの を しまう」ボタンが出る。たんす を閉じると ✓ は消える。
