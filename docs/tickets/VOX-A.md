## 目的
無限の世界（`docs/design/VOX-plan.md`）の土台。世界を「列（16×352×16）の辞書＋1 列 22 個のセクション（16³）」で持つ。ほかの VOX-B〜G はこの型の上で並列に作る。

## やること（設計書 §2・§6・§9）
1. `src/contracts.ts` に `WORLD_HEIGHT`・`SEA_Y`（**この PR では今の値 48・6 のまま**。352・144 にするのは新しい生成と一緒の VOX-B）・`CHUNK_SIZE=16`・`SECTION_SIZE=16`、つなぎ目の型（列・セクション・`generateChunk` のかたち・`ChunkStore` のかたち・`buildSectionMesh(cx,sy,cz)` のかたち）を入れる。中身を作るのは B〜F。
2. `ChunkedVoxelWorld`: 列の辞書（キーは §2 の数 1 つ）、セクションの 3 つの形（1 種類だけ / パレット / そのまま 4,096 B）、`getBlock/setBlock`、`isLoaded(x,z)`、読みこんでいないマスは `'outside'`、負の座標（`>>4`・`&15`）、セクションごとの dirty、「見えない」印（§6: 全部固くて 6 面のとなりも固い → メッシュも光も作らない。ほったら自分と 6 つのとなりを見なおす）。
3. `size.x/z` を消して、§9 の一覧の所をコンパイルが通るように直す。**ゲームの見た目と動きは今のまま**: 今の島（`generateIsland`）を列に切って入れ、島の外は今と同じ「外」。regions・畑なども今のまま動かす（中身の作りかえは VOX-B・G）。こうして main の CI を緑のまま保つ。
4. 保存は今のしくみのまま動けばよい（全マス比べは新しい入れ物の上で。IndexedDB 化は VOX-F）。
5. 光・メッシュは今の作りのまま、新しい入れ物の上で動けばよい（セクション化は VOX-C・E）。
6. 高さが 352 でも入れ物が動くことは、ユニットで確かめる（定数を差しかえて）。
