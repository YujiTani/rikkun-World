## やること

1. **刃の軌跡**: 刀（ぼくとう・かたな・きらきらの かたな）の わざ 3 つ（突き・大けさぎり・切り上げ）で、刃先が 通った所に 半月の 光の 帯を 出す。見た目は B（そと → うち で 4 だんに すける、9 ステップ = 0.15 秒で 4 だんに 消える、しっぽから 消える）。刃先の 位置は `blade_path.json` の 1 ステップごとの 点（右・上・前、腰の 真下の 地面から）を 体の 本当の位置に 足して 取る。
2. **武器ごとの色**: `W2Settings.bladeTrail`（`src/contracts.ts`）を 軌跡の色・そとの光・刃の地・刃の光 の 表にする。
3. **キャラの絵の 刃の色**: 刀の 6 まい（`katana_thrust`・`katana_kesa`・`katana_kiriage`・`katana_walk_chudan`・`_jodan`・`_gedan`）の 刃を 新しい 2 色（色見本の 表の 20 番 = 刃の地・21 番 = ふちの光。色見本は 22 色）で 撮り直した絵を 入れ、板の 色を 持っている 武器の色に かえる。弓は 刃が ないので 変えない。
4. 今の 刀の 白い帯・線（`src/fx/weaponFx.ts` の 扇の帯と 突きの線）と、きらきらの かたなが ふったとき とばす 星 3 つは、新しい軌跡に 置きかえる。
5. **なぎなたは 今のまま**（パンチ ＋ 白い弧。#67）。表の 値だけ 持つ。

## 撮り直しの 記録（PO、2026-10-17）

- 刀の 6 まいを 刃の 色番号つき（表の 20 = (218,215,225)・21 = (253,251,252)）で 撮り直して `art/char-sheets/` に 置いた。`atlas.json` の 中身（コマ数・ticks）は 同じ。`blade_path.json` も `art/char-sheets/` に 置いた。`art/CHAR-1-v2/palette.json` は 22 色。
- 前と ちがう ドット（1 まいの 見える ドット 100〜150 万 のうち）: 刃の 色の 入れかえ 2.6〜8.6 万。ほかに 刃の ふちの ドットが 1,094〜2,680（刃の まわり 3 ドット以内。外は 1 まいに 0〜7）。刃の 色の 重みが 変わって ふちの 多数決が 少し ずれた分で、刃から はなれた 体の ドットは 変わらない。
- 刃から 3 ドット 以内の ふちは 変わって よく（1 まい 約 0.2% 以下）、それより 外は 1 まい 10 ドット 以下（仕様書 §4.6）。数は この 記録（PO）、見た目は オーナー（AC21）。
- 次の 順番（コードと 書き出しなので developer の B。仕様書 §10）: `src/char/palette.ts` を 22 色に → `npm run pack:char` → `public/models/char/` を 入れかえ → 組ごとの 本当の値を PO へ → PO が CHAR-2 §4.7 の 表を 書きなおす。試作（§10 の 4-1）の 最初の 仕事で やり、本番の ブランチでは 開発（§10 の 6）で 同じ 手順を やる。`palette.ts` より 先に 絵を 入れると 20・21 番が 6・18 番に 丸まるので、この 順番を 守る。
