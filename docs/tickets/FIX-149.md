# FIX-149: ほったあと、ななめのセクションに段差の下のすき間が残る（issue #149）

## どうなるか
- ブロック T の上をほって T が新しい表面になったとき、T のよこの **ななめのセクション** の面と「見えない（hidden）」印が その場で作り直されない。段差の下にすき間が残る。
- セクションの角（lx・lz とも 0〜1 か 14〜15）をほると、x と z のななめのとなりの列のセクションが作り直されず、AO の角が古いまま残る。

## 原因（src/world/VoxelWorld.ts）
- `markEdgeNeighbors` は x・z・y の 1 方向ずつしか作り直しに入れない。ななめ（x と z、x と y、z と y、3 つとも）を入れていない。
- `noteDirty` → `staleAround(col.cx, sy, col.cz)` は、変えたマスのセクションと その 6 つのとなりの hidden 印しか 見なおさない。
  `computeHidden` は となりの面にある「列の地面の表面ブロック」（`scanColumn` の ty）を見る。ほった / おいたマスが セクションの底の段（ly=0）だと、
  列の ty が 1 つ下のセクション（sy-1）の いちばん上の段にうつる（ほる）/ そこから うつってくる（おく）。だから sy-1 の 6 つのとなりの印も 見なおしが要る。

## 直し方
1. `markEdgeNeighbors`: nx（-1/0/+1）・nz・ny の組み合わせを ぜんぶ（0 でない向きの すべての組み合わせ、最大 7 個）作り直しに入れる。列が変わるもの（nx か nz が 0 でない）は `markNeighbor(..., true)`、同じ列で y だけ変わるのは今までどおり `markSec`。y の範囲（0 ≤ sy+ny < nSections）を守る。
2. `noteDirty`: 印を見なおすとき、ly === 0 かつ sy > 0 なら `staleAround(col.cx, sy - 1, col.cz)` も呼ぶ。
