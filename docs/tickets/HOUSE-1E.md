## 2. 内装は 置けない 所にも 仮置き できる（§2.5・§4.3・AC13）

| PO が 決めた こと | 中身 |
|---|---|
| 2-1 置く | 押した マスが 方眼（中の 床）の 中 なら、**はみ出す・重なる・戸の 前 でも 置ける**。置けない 所に ある 家具は **赤**（仮置き）。置ける 所に ある 家具は 今の まま。重なった ときは **両方** 赤。赤く 置いた・赤く なる 向きに まわした ときの 音は ふつうと 同じ（PO 2026-10-31） |
| 2-2 押した マス | 押した マス ＝ 家具の **もとの マス**（rot 0 の ときの 左上。ふとんは まくらの マス）。置く 前に まわした 形（置く 前の 向き）でも 押した マスが もとの マス。置くのは 空いた マスを 押した とき（家具の ある マスは 2-4） |
| 2-3 まわす | ↻↺ は **もとの マスを 中心に** まわる（今の「左上の マスは 同じ」を やめる）。右下の すみの ふとん（たて）は ↻ 1 回で 部屋に おさまる。1×1 は その場で 向きだけ。2×2・3×1 も もとの マスを 中心に うごく。**赤く なる 向きにも まわる**（今の「まわらない・赤く 1 回 光る」は やめる）。ただし もとの マスが 方眼の 外に 出た 家具（2-6 で のこった 物）を まわして 1 マスも 入らなく なる ときは まわらない・赤く 1 回 光る（PO 2026-10-31） |
| 2-4 えらぶ | 家具の ある マスを 押すと 置かずに その 家具を えらぶ（今の まま）。重なった マスを 押すと **あとから 置いた 方** を えらぶ。かべの 帯の 上に 見えて いる 赤い 家具の はみ出しを 押しても その 家具を えらぶ（PO 2026-10-31）。そばの ボタン［とる］［↻］［↺］は 今の まま |
| 2-5 すすめない | 赤い 家具が ある 間は「つぎへ」（② → ③）と「できた！」（どの すすみでも）で 進まない。建築士さんの ふきだし **「あかい かぐを なおしてね」**、赤い 家具が 1 回 光る（今の 光り方。点滅 しない）。もどす の 1 回には 入らない。できた！で 止まったら ② なか へ 切りかえる。返しは できた！の しらべで 止まった ときと 同じ（建築士さんが 首を かしげる「おしい」・はずむ 明るい 音）。赤い 家具が ある 作りかけは ② なか で 開く（よくない ことばより 先）（PO 2026-10-31） |
| 2-6 大きさを かえる | 小さく して 入らなく なった 家具は **消さずに 赤く のこす**。方眼に 1 マスも 入らなく なった 家具 だけ 今 どおり 消して ふきだし「はいらない かぐを かたづけたよ」 |
| 2-7 見本（3D） | 赤い 家具は 見本に **出さない**（建つ 形 だけ 見せる）。白に なったら 出る【PO 案。yuzu が 手元で 見る】 |
| 2-8 材料・保存 | 「ひつような もの」の 数には 赤い 家具も 入れる。オートセーブにも 赤い 家具が のこる。できた せっけいずには 赤い 家具は 入らない（2-5 で 止まる ため） |
| 2-9 置く 前の 形 | マウスの 下の 形は 今 どおり 白／赤 で 出す。赤でも 押せる。**家具の ある マスの 上では 形を 出さない**（押すと えらぶ ため。デザインの 提案を PO が 採用 2026-10-31） |
