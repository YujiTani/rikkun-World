# CRAFT-PAGE: たいまつのレシピを 3 つに・作る画面の説明欄をページめくりに（#277）

決定: `docs/decisions/2026-10-23-night-darker.md` の「たいまつのレシピを ふやす」と、下の「説明欄のページめくり」（yuzu 2026-10-23、試作 `/mnt/project-files/night-dark/ui/pages-proto.png` を見て「横移動の矢印もっと小さくてもいい」「説明欄だけです」）。

## A. たいまつのレシピ

- 今の「き 1・あぶら 1 → 4」はそのまま（id `torch` は変えない）。
- 足す: 「き 1・せきたん（`coal_ore`）1 → 4」「き 3 → 1」。どちらも 出来る物は `torch`、works: true、station: craft。
- 作る画面のカードは **たいまつ 1 枚のまま**（作り方ごとにカードを増やさない）。作り方は説明欄のページで選ぶ（B）。
- 新しいレシピの id は開発が決めてよい（例 `torch_coal`・`torch_log`）。`craft.list()` / `craft.make(id)` でそれぞれ作れること（テスト用）。カード（`craft.ui().tiles`）には たいまつ 1 枚。
- カードの「作れる」の光り方・材料の足りる足りない は、3 つのどれかが作れれば「作れる」。

## B. 説明欄のページめくり（作る画面の右の説明欄だけ。やく（かまど）の画面も同じ説明欄なので同じ形）

1. スクロールと「▼ つづき」をやめる。説明欄の中は **ページ** に分け、◀ ▶ でめくる。ページ名（例「つくりかた ②」「せつめい」「つよさ 1/2」）と、その下に今のページの位置を ●○○ で出す。
2. ページの順: **つくりかた**（作り方が 1 つなら名前は「ざいりょう」、複数なら「つくりかた ①②③」）→ **せつめい**（つかいみち・つかいかた）→ **つよさ**（分類・つよさの数。ある物だけ）。ねんりょう（かまど）は ざいりょう と同じページ。
3. **1 ページに入りきらない物は ページを分ける**（スクロールさせない）。どの大きさの画面（UI 検査の 3 つ）でも、どのページも はみ出さない。
4. 説明欄を開いたとき（ちがうカードにうつったとき）は、**今の材料で作れる作り方のうち いちばん前のページ**、どれも作れないなら 1 ページ目。
5. 「つくる」は **今見ている作り方** で作る。せつめい・つよさ のページを見ているときは、さいごに見た作り方（無ければ 4 の作り方）。見ている作り方の材料が足りないときは 今と同じ 押せない形。
6. 矢印の **絵は小さく**（試作より小さい）。押せる広さは きまりどおり 44px 以上（見えない当たりを広げてよい）。1 ページ目の ◀・最後の ▶ はうすい色で押せない。ページが 1 枚だけなら ◀▶ と ● は出さない。
7. カードの ×4 などの数は そのまま。作り方のページには「材料 → 出来る物 ×数」と できる かず を出す。
8. 文字は ひらがな・カタカナ、漢字はルビ（今のきまり）。

## 受け入れ基準

1. き 1・せきたん 1 だけ持って たいまつ を作ると、たいまつ +4、き −1、せきたん −1。き 3 だけ持って作ると +1、き −3。き 1・あぶら 1 は今と同じ +4。
2. カードの たいまつ は 1 枚。
3. 説明欄の中は どの物・どのページでも 縦にスクロールしない（はみ出しなし）。「▼ つづき」は出ない。
4. ◀ ▶ でページが前後にかわる。最初と最後で止まる。ページの数・順は 2 のとおり（たいまつは つくりかた ①②③・せつめい、かたなは ざいりょう・せつめい・つよさ…）。
5. き と せきたん を持って たいまつ の説明欄を開くと「つくりかた ②」が出て、「つくる」で せきたん の作り方で作れる。◀ で ① にすると あぶら が足りないので押せない。
6. 矢印の当たりは 44×44px 以上。
7. `npm run check:ui` で 3 つの大きさとも 新しいくずれなし。
