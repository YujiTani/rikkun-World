## 目的（オーナーの言葉で）
グラフィックはオリジナルに一新。カクカクの形、レトロなドット感は残しつつ表現力を上げる（9×9×9）。マイクラのまねから抜け出す。
見た目の方向はオーナーが自分の感覚で決める → アートチームが 3 案出し、オーナーが 1 つ選ぶ。

## 前提
- 試作ページ `voxel-proto.html`（VOX-0、hybrid 方式。Mac で fps 問題なし）の上で見せる。
- 見た目は `src/proto/voxel/looks/` の 1 ファイル = 1 案（今は `placeholder.ts`）。形と色はそこだけで変わる。
- 新しいキャラは 8 方向ドット絵スプライト（256 ドット・20 色、三人称のみ）。コマ表 `public/proto/char_atlas.png`（1152×1024、128×128 のコマが 横 9 × 縦 8。行 = 向き 8 つ、列 0 = 立ち、1〜8 = 歩く）。

## 1. 開発（developer）: 3 案を見せるしくみ
1. 見た目を切りかえられるようにする: `looks/` の各ファイルが同じ形の `Look` オブジェクト（名前・パレット・`fillBlockLook`・はっぱのように となりを かくさない種類 など、今の placeholder の約束）を export。ボタンと `?look=<id>` で切りかえ。切りかえたら 3D テクスチャ（greedyShape/hybrid の色）とメッシュを作り直す。案のファイルを足すのは 1 行の登録だけで済むように（`looks/index.ts`）。
2. キャラを立たせる: スタート地点の前（カメラから 4〜5 ブロック先の地面の上）に、コマ表の立ちのコマを板（スプライト）で立てる。高さ 1.8 ブロック。カメラの向きからキャラを見た向きの行を選ぶ（8 方向）。`?char=0` で消せる。テクスチャは NearestFilter（ドットがぼけない）。
3. 空の色・霧の色も `Look` に入れて切りかえられるように（案ごとに空気感が変わるため）。
4. `__voxelProto.setLook(id)`、計測シナリオに look ごとの三角形・頂点データの数を足す（hybrid r=16 だけで良い）。

## 2. アート（art-director）: 3 案
- `docs/art/world-looks.md` に 3 案（名前・ねらい・色の表・ブロックごとの 9×9×9 の作り方・6 歳にとっての分かりやすさ）を書き、`src/proto/voxel/looks/<id>.ts` に実装（試作ページの見た目データだけ。ゲーム本体の `src/` は直さない）。
- 世界のブロック: くさ・つち・すな・いし・せきたん・てつ・き・はっぱ・みず・そこいし（ほかは今の placeholder のままで可）。
- 案ごとにスクショ（スタート地点・キャラの近く・上空）を撮って自分で見る → `docs/screenshots/VOX-1/<id>-*.png`。
- 3 案とも、キャラ（ピンクのパーカー）が地面からはっきり浮いて見えること。
- 性能: 案ごとに hybrid r=16 の三角形・頂点データを書く（VOX-0 の 70 万・30MB から大きく増やさない。でこぼこを増やすなら理由を書く）。

## 3. 見る
- `art-reviewer` が 3 案のスクショを見る（6 歳に分かるか・キャラが見やすいか・案どうしが本当にちがうか）。
- オーナーが Mac で 3 案をくらべて 1 つ選ぶ → `docs/art/DESIGN.md` に書く。
