## 目的
光を世界全体の配列から「セクション（16³）ごと」に持ちかえる（`docs/design/VOX-plan.md` §4・§6）。無限の世界と高さ 352 でも、要る所だけ計算して軽くする。オーナー決定: 光は 1 ブロック単位のざっくりした形でよい。

## やること（設計書 §4 のとおり）
1. `WorldLight` をセクションごとに: 3 つの形（空 15 だけ = 1 バイト / 見えない = 持たない / ふつう = `Uint8Array(4096)` に空 4 ビット・明かり 4 ビット）。`oldSky`/`oldBlock` はやめる。値と広がり方（たいまつ 14、1 マス 1 弱まる）は今と同じ。
2. 列ごとの高さ地図。セクション S の光は、まわり 3×3×3 のセクションの光の元から計算し、S の中だけ書く（順番に関係なく同じ答え）。
3. ブロックを変えたら、15 以内にかかるセクションを作り直し待ちに。1 コマに光 2 セクションまで、プレイヤーが変えた所を先に。光が変わった列だけメッシュ作り直し待ち（メッシュのセクション化は VOX-E）。
4. `isSectionHidden`（VOX-A）のセクションは計算しない。そのとなりをほったら計算する。
5. 列を読みこむ / 捨てるとき（`loadColumn`/`unloadColumn`）にも、まわりの光を作り直し待ちに入れる（VOX-A のレビュー台帳の「中」）。
6. メッシュへの光の渡し方（角の平均・`aLight`）と昼夜のシェーダーは今のまま。**見た目は変えない。**

## 受け入れ基準
| # | 基準 | 確かめ方 |
|---|---|---|
| 1 | 今の島で、光の値が全マスで前と同じ（または差が説明できる） | ユニット（前の `WorldLight` と比べる） |
| 2 | 順番に関係なく同じ答え・見えないセクションは計算しない・ほったら計算する | ユニット |
| 3 | たいまつを置く/取る・ほる で、光が正しく変わる | ユニット・関係する E2E（たいまつ・夜） |
| 4 | 光の初期化の時間とメモリが前より小さい。高さ 352（定数を差しかえ）でも数を出す | perf（worktree の中で、関係する spec だけ） |
| 5 | 見た目が変わらない | UI 検査・スクショ |
