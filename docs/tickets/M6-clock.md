# M6-clock: 右上の時計を「いまの時間の絵」に（オーナー要望 2026-10-12）

「右上の時間経過のアイコンも、日の出、午前中、正午、夕焼け、日没、月に変わるようにしたい。今の時計回りに回るのは時間がわかりにくいので」

## きまり（PO 決定）
- 回る文字盤をやめ、**いまの時間帯の絵 1 つ**＋その下に ことば（本文 20px）＋「N にちめ」（小 16px）を出す。
- 6 つの時間帯（1 日 = 夜明け 1.5 分・ひる 15 分・ゆうがた 1.5 分・よる 7.5 分）:
  | 絵 | ことば | いつ |
  |---|---|---|
  | 日の出（地平線から半分の太陽、だいだい〜ももいろの空） | ひので | 夜明け（dawn）全部 |
  | 午前（ななめ上の太陽、水色の空） | あさ | ひる の はじめ 0〜40% |
  | 正午（まうえの大きな太陽、こい青の空） | おひる | ひる の 40〜70% |
  | 夕焼け（ななめ下の太陽、だいだいの空） | ゆうやけ | ひる の 70〜100% |
  | 日没（地平線に しずむ 太陽、むらさきの空） | ひのいり | ゆうがた（dusk）全部 |
  | 月（三日月と星、こい紺の空） | よる | よる（night）全部 |
- 絵は 16×16 のドット絵をコードで描き、64px くらいで出す（今の時計の場所・大きさ）。かわるときは 0.5 秒で ふわっと入れかえ（点滅しない）。
- 区切りの割合は設定（`clockPhases`）に置く。
- テスト: ユニットで 各時間帯の境目（dawn → あさ → おひる → ゆうやけ → ひのいり → よる）、DOM で `data-phase`・ことば。
- 担当ファイル: `src/ui/clock.*`・`src/ui/clockModel.ts`（と新しい絵のファイル）だけ。`setTime(dayTick, settings, day)` の形は変えない。
