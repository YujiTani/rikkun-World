## 目的
島（`generateIsland`）をやめて、**どこまでも続く地形**を `generateChunk(seed, cx, cz)` で作る。世界の高さを 352・海面を 144 にする。設計は `docs/design/VOX-plan.md` §1・§3・§7・§9・§10（オーナー OK 済み）。読みこみ範囲を動かす（ストリーミング）のは VOX-D。

## 範囲（この PR でやる・やらない）
1. **作る**: `generateChunk(seed, cx, cz) → ChunkColumn`（22 セクション）。同じ seed・同じ (cx,cz) なら、作る順・ほかの列を読んだかに関係なく同じ中身。負の座標・±30,000（cx ±1875）でも動く。
2. **読みこむ範囲は今のまま 8×8 列（cx, cz = 0〜7、x・z = 0〜127）に固定**。その外は今と同じ「外」（`'outside'`、固い）。スタートさがしはこの範囲のまん中 (64, 64) から始める（下の表）。こうすると 0〜127 を前提にした多くのテストと、起動の重さ（64 列）が今と同じままで、CI を緑に保てる。VOX-D でプレイヤーのまわりへ広げる。
3. **仮の海のふち（VOX-D で消す）**: 読みこみ範囲のはしの切り口を見せないため、読みこむときに はしの近くの高さを下げて海にする（数は下の表）。`generateChunk` の中ではなく、読みこむ所でかける（`generateChunk` は無限の世界の本物の形のまま）。
4. **高さ 352・海面 144**: `src/contracts.ts` の `WORLD_HEIGHT = 352`・`SEA_Y = 144`。海の板（`src/game/scenery.ts`）も `SEA_Y` の高さに。高さ 48・海 6/7 を前提にした所は `WORLD_HEIGHT`・`SEA_Y` から求める（`GEN_CONFIG.seaH`・`waterY`・`WORLD_SIZE.y` を使う所を残さない）。
5. **今のセーブは読まない・消さない（全部リセット。§7・決定 5）**: 新しい世界は新しい `saveId`（今の `main`・`seed-N` と別の名前。名前は開発が決めてよい）に保存する。`main` の IndexedDB と、古い localStorage（`rikkun-world-save-v1-*`）は読まず、消さない。古い localStorage から移すしくみ（VOX-F AC4）と M6 の前の保存（`src/farm/legacy.ts`）は使わなくなる。`SAVE_GEN` を上げる。`?reset=1` は新しい saveId だけを消す。ファイルから読む（`.rikkun.gz`）で古い世界のファイルは読まず「まえの せかいの ファイルなので よめません」と出す。
6. **島に頼っていた所の置きかえ**（VOX-G で本番にする。B は「今の遊びがこわれない」ための仮）:
   - `regions()` は形を変えず、新しい地形から仮に作る（下の「仮の regions」）。
   - ふるい畑・やせいの やさい の置き場所は、新しい地形の上で決める（数・形は今のまま。下の表）。
   - `generateIsland.ts` とそのユニットテスト、`farmPlacement` の島を作り直す所、`src/farm/legacy.ts` は消してよい（島を作らなくなるため。消すテストは PR に理由を書く）。
7. **小ブロック地形 S(mx,mz) を本番へ**: `src/proto/voxel/terrain/microSurface.ts`（と `worldColumns.ts`）を `src/world/micro/` に移す。`ColumnSource` は列の辞書から読む。`MICRO_PARAMS` はバイオームごとに持ち、境目でまぜる（§3）。小ブロックは**見た目だけ**。ほる・おく・当たり判定・光・保存は 1 ブロック単位のまま（決定 2）。
8. **やらない**: 読みこみ範囲を動かす・捨てる・`world.teleport`・じゅんびちゅう（VOX-D）、±30,000 の壁（VOX-D/G）、弓・妖怪・実績の regions → biome の本番化と高さの相対化（VOX-G）、バイオームの中身と名前（VOX-I）、Worker（VOX-H）。**新しい演出・音はなし**（地形だけ。`docs/fun.md` に足すものなし）。

## 数の表（デザインの「数」）
`n(s)` = seed つき `valueNoise`（0〜1、格子の大きさ s ブロック。今の `src/world/gen/random.ts:38`）。ノイズはそれぞれ別の seed から作る。d = (64, 64) からの横の距離。

### 高さ H(x,z)（その列のいちばん上の地面ブロックの y）
| # | 項目 | 値 | 理由 |
|---|---|---|---|
| H1 | 大陸 c | `0.7·n(512) + 0.3·n(256)` | §3 の「大きい形 512」。256 を足して海岸線を少し細かく |
| H2 | 基の高さ Hb | `SEA_Y + (c − 0.42) × 86`、`SEA_Y−30`〜`SEA_Y+50` に収める | c が まん中（0.5）なら 少し陸。陸がおよそ 6 割、海は深くても 30（こわくない深さ） |
| H3 | はじまりの土地 | d ≤ 48 は Hb を `SEA_Y+6`（=150）にする。48〜192 で なめらかに（smoothstep）もとの Hb へ。重み w（1→0） | スタートは いつも海の近くの低い陸。どのシードでも同じ遊び出し |
| H4 | 陸の重み L | `clamp((Hb − SEA_Y) / 24, 0, 1)` | 海の近くほど 丘・山・崖を弱める → 海からいつも歩いて上がれる |
| H5 | 山 | `smoothstep(0.62, 0.85, n(512)) × 50 × L × (1 − w)` | §3「海・陸・山の地方」。地方の 2 割ほどに山 |
| H6 | 丘 | `(n(丘の大きさ) − 0.5) × 2 × 丘の強さ × L`（バイオームの表） | §3「中くらい 64」 |
| H7 | でこぼこ | `(n(16) − 0.5) × 2 × でこぼこ × (0.3 + 0.7·L)` | §3「小さい 16」 |
| H8 | 崖 | `n(96)` が `1 − 崖の割合` より上で、L ≥ 0.5 かつ w = 0 の所は、高さを 3 の倍数に切り下げる（3 段の崖） | ほる・おくで登る遊び。スタートと海辺には作らない |
| H9 | H | `round(Hb + 山 + 丘 + でこぼこ)`、崖をかけて `SEA_Y−30`〜`270` に収める | §3「陸は 146〜270」 |

計算しなおし: 最高 = 194（Hb）+ 50（山）+ 14（森の丘）+ 2 = 260 ≤ 270。最低 = 114。スタートのまわり（w=1, L=0.25、草原）: 150 ± 2.5 ± 0.7 → 147〜153 で、条件 146〜156 にいつも入る。5×5 の傾きは 1 マスあたり 0.25 以下 → 差 2 以下。海辺（L≈0）の傾きは 1 マスあたり 0.4 以下 → となりの差は 1 以下。

## テストが使う hook
`window.__rikkun.world.*`（`src/world/hook.ts`）に開発が足す。既にあるもの（`size`・`getBlock`・`setBlock`・`fill`・`groundHeight`・`hash(cx?,cz?)`・`spawn`・`testArea`・`regions`・`genTimeMs`・`sectionInfo`・`sectionStats`・`meshStats`・`lightPending`）は今の名前のまま使う。

```ts
seaY(): number;                                  // SEA_Y（144）
isLoaded(x: number, z: number): boolean;
loadedChunks(): { cx: number; cz: number }[];    // 読みこんだ列（B では 64）
genHash(cx: number, cz: number): string;         // generateChunk の結果のハッシュ。読みこまずに作る（仮の海のふち・畑の置きものは入らない）
terrainAt(x: number, z: number): {               // 生成の値。読みこまずに計算（仮の海のふちの前）
  h: number;                                     // H(x,z)
  biome: 'grassland' | 'forest';
  sea: boolean;                                  // h ≤ SEA_Y − 1
};
spawnInfo(): { from: { x: number; z: number }; fallback: boolean; checked: number }; // さがし始めの点・P3 を使ったか・調べた列の数
startTorch(): { x: number; y: number; z: number };
startFeatures(): { rock: { cx: number; cz: number; r: number; peakY: number }; trees: { x: number; y: number; z: number }[] }; // y = みきの いちばん下
caveMouths(): { x: number; y: number; z: number; dir: 0 | 1 | 2 | 3; room: { x: number; y: number; z: number } }[]; // 読みこみ範囲の口。dir = yaw 0/90/180/270
genStats(): { columns: number; medianMs: number; maxMs: number; spawnSearchMs: number }; // 記録用（合否は perf）
```
`save.info()` に `saveId: string` を足す。`world.size()` は `{ x: 128, y: 352, z: 128 }` になる。`world.teleport` は VOX-D。
