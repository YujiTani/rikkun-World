## 目的（オーナーの言葉そのまま、2026-10-21 yuzu）
「風神剣もおなじようにあっぷでーとしてほしいです。風神剣は、今攻撃時に衝撃波をだしてるんだけど、チャージもほしくて、チャージすると雷神剣と同じもーしょんで、前方にまっすぐ飛ぶ螺旋回転の風の衝撃波をとばすようにしてほしいです。あとは、移動時にバフがついてるんだけど、バフアイコンもどこかに表示して欲しい。体力の上とかかな」

## PO が決めた初めの値（仕様で確かめて直してよい）
- 風神剣に **ためわざ** を足す（2026-10-18 の決定「風神剣はためわざ無し」をこの issue で変える。決定ファイルを足す）。ふつうの攻撃の真空波はそのまま。
- 押し方・ためる時間・ため中の歩く速さ・パリィとの関係は **雷神剣（WEAPON-7）と同じ** にする（同じしくみを使い回す）。体の動きも雷神剣と同じ。
- はなすと、**前へまっすぐ飛ぶ らせん回転の 風の衝撃波**。飛ぶ距離・太さ・速さ・当たり方（つらぬくか）・強さは仕様で決める。BALANCE.md をこわさない。
- 絵は **新しい絵の作り方**（`docs/art/PIPELINE.md`、ART-PIPE-1）。「常にカメラに正面・一番決まる絵・ペラペラに見せない」。螺旋をどう作るか（板・リボンの帯・ビルボードの重ねなど）は art-director の 3 案 → オーナーが選ぶ。PixelLab は lite だけ（使う前後の残りを記録）。
- 音: 風の音（今の真空波の音の強い版でよいか）は sound の判断。いらなければ既存の音を使い回す。
- **速さバフのアイコン**: 風神剣を持っている間（バフがきいている間）だけ出す。置き場所の候補（体力の上など）を designer が 2〜3 案出し、オーナーが選ぶ。アイコンの絵は art（新しい作り方）。文字はひらがな・ルビ。

## オーナーの追加の言葉（2026-10-21 yuzu、そのまま）
「アイコンに早いとか書かなくていいです。
あとはチャージエフェクトがださいので、変えて欲しいです。
ロックマンのチャージショットのように、光のパーティクルがキャラの中心に集まり続けるような演出にして欲しいです。
チャージが完了したら、キャラクターをチャージ完了したとわかるようなエフェクトが欲しいです

チャージ音も、もっときもちいいチャージ感のわかる世界観を崩さない音にして欲しい」

→ PO のまとめ:
- バフアイコンは絵だけ（「はやい」の字なし）。
- **ため中の見た目を作り直す**: 光のつぶがキャラの中心へ集まりつづける。ためが いっぱいになったら、キャラに「いっぱい！」と分かるエフェクト（点滅は安全の上限内）。ためのしくみは雷神剣・風神剣で共通なので、**両方とも新しいため演出に変わる**。
- **ため音を作り直す**: ためている間の気持ちいい「たまっていく」音＋いっぱいの合図。世界観（和・やさしい）をこわさない。sound-director の 3 案 → オーナーが試聴して選ぶ。
