# PERF-405: 地上から 見えない 地下を 描かない

issue: #405 / 決定: `docs/decisions/2026-10-29-mine.md` の 13

坑道（#350）の あと、スタートで 地下の たいまつ・わく・地形が 地面の 下でも 描かれ、描画回数が ふえた。上限を 上げて 先に マージした分を、見える ところだけ 描くように して もどす。

## やり方

- セクション（16³）ごとに、光を通さない マスを よけて **どの 面から どの 面へ 抜けられるか** を メッシュを 作るときに 覚える。空気だけ・石だけ の セクションは 表を 見ない。
- 描く直前に、カメラの いる セクションから その つながりを たどる。穴の 四角が 画面に 入っているときだけ 奥へ 進み、穴の 大きさで 画面の 範囲を せばめる。
- **地面は かくさない。** 空気の セクションから その 面が 画面に 入っていれば、となりの 地面の メッシュは 描く。奥の 坑道は、穴を 通して 画面に 入るときだけ 描く。
- 中身が 変わった セクションは、作り直すまで「全部 あいている」と みなす（ほった 直後に 奥が 欠けない）。
- 1 回の たどりは **8192 回** まで。超えた コマは かくさない。カメラも 中身も 同じなら さがし直さない。
- 2 人で 画面を 分けるときは、描く直前に **カメラごとに** やり直す。片側の 穴を、もう片側が まとめて 描かない。

## 受け入れ

- 地上・穴の 外・穴を のぞいた とき・穴を ほった・ふさいだ とき、見える 地面と 穴の 奥が 欠けない。見えない 奥は メッシュを 出さない。
- 見える 穴の 中の たいまつ・水・地面は 今までどおり 描く。
- 数（ルール #255）: `?nosave=1` と `?mine=0&nosave=1` を、texA AC12（スタート・上空）と 草花 AC11（スタート）の 同じ 置き方で くらべる。へったら texA の `START_SHAFT_DRAWS`・`HIGH_SHAFT_DRAWS` と 草花 AC11 の 上乗せを もと（0）に もどす。上空は 入口が 画面に 残るぶんだけ 上乗せを 残してよい（測った 数。レポート `docs/perf-reports/PERF-405.md`）。
- 既存の メッシュの ゴールデンと シードの 地形は 変えない（描く・かくすだけ）。
