# NIGHT-76: 夜の外をもっと暗く・見える範囲 1/3・妖怪と作物を光らせない（#76）

決定: `docs/decisions/2026-10-23-night-darker.md`（yuzu 2026-10-23 カードで C）。試作のコード `/mnt/project-files/night-dark/proto.diff`（URL で切りかえ。本番では URL を使わず config の数にする）。

## 数（config に 1 か所ずつ。名前は開発が決めてよい）

- 夜の度合い `nt` = 今の空の光の よわまり段数 ÷ `LIGHT_CONFIG.nightDarken`（0 = 昼、1 = 夜。今の `darkenFromBrightness` と `skyDarkness` を使う）。
- **空の光の夜の倍率** `nightSkyMul = 0.16`: 空の光の曲線の明るさ `sb` に `mix(1, 0.16, nt × w)` をかける。`w = clamp(空の光(0〜15) / 4, 0, 1)`（空の光 0 = どうくつは かけない → 0.045 のまま。どうくつの 入り口は なめらかに）。夜の外（空の光 15）は 0.125 × 0.16 = 0.02。
  - ブロックの材料（`lightShader.ts` の 2 か所・`voxel/voxelMaterial.ts`・`shadow/shadowPatch.ts` の 置きかえ文字列）と、CPU の同じ式（`world/light/curve.ts`・`LightField.brightness`・`Sky` の `outdoor`）を そろえる。`nightDarken`（11）・妖怪の出る「暗い所」（`isDarkForSpawn`）・`LightField.level` は **変えない**。
  - ブロックの光（たいまつ）の 3 だんかい・暖かい色あいは 変えない。
- **夜空とかすみの色の倍率** `nightSkyColorMul = 0.4`: `Sky.update` で 空の色に `mix(1, 0.4, nt)` をかけてから background と fog に入れる。
- **夜の かすみの倍率** `nightFogMul = 1/3`: `fog.near/far` = `SCENERY_CONFIG.fogNear/fogFar × mix(1, 1/3, nt)`。
- **光らない**: 妖怪の明るさの下限 `YokaiManager` の `lightMin` の既定 0.3 → 0。作物の下限 `farmRipeMinBrightness` の既定 0.7 → 0（設定と しくみは残す）。
- **変えない**: `dollMin` 0.3（自分のキャラ）、`minBrightness` 0.045、`timeSettings.nightBrightness`、たいまつ、昼。

## 受け入れ基準（ゲームに聞く。一時停止・tick を指定）

1. 夜（tick 67400）の 空の下の 平らな草の上の 見た目の明るさ ≈ 0.02（空の光 15 の点。式 0.125 × 0.16、±0.005）。昼（tick 14000）は 今と同じ 1.0。
2. 夜の どうくつの中（空の光 0、ブロックの光 0）は 0.045（今と同じ）。昼の どうくつも 0.045。
3. 夜に たいまつの 4 マス以内は 0.95（今と同じ）、5〜8 マスは 0.5。
4. 夜の かすみ: near ≈ 13.3・far ≈ 26.7。昼は 40・80。夕方（よわまり段数が 半分）は その間（near ≈ 26.7）。
5. 夜の 空の色（scene.background）= 夜の色 `0x1b2350` × 0.4（色ごと ±1/255）。昼の空の色は 今と同じ。
6. 夜、空の下の 妖怪（ちょうちん 以外）の 体の明るさの数 = 足もとの明るさ（0.3 の下限なし。≈ 0.02）。たいまつの 4 マス以内では 0.95。
7. 夜、空の下の やせいの野菜・みのった作物の 明るさ = まわりの草と同じ（0.7 の下限なし）。
8. 夜の 自分のキャラの明るさは 0.3 以上のまま。
9. 妖怪が出る「暗い所」の判定（`isDarkForSpawn`）と `world.skyDarkness()` は 今と同じ値（夕方・夜・朝の 3 点）。
10. 画面（夜・空の下）: 地面の画素の明るさが 今より暗い（同じ場面で 今の式の見本と くらべる。画素を読むなら `?microR=28` と `?shadow=1` を そろえる）。
