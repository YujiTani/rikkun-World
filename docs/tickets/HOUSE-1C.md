- `house.buildNow(number, at)` … せっけいず（`blueprints()` の 番号）から 家を その場に 建てる。`at` ＝ 外の 箱の 北西の すみの 床の 段。箱の ぜんぶの マスを 書く（床・かべ・屋根・窓・戸〔しまって いる〕・ちょうちん・家具・空気）。材料は へらさない。形の 式は `model.ts`。

- `ui.houseNameBand()` … `{ text, ticksLeft } | null`（出はじめ 180・1 ステップに 1 へる）。DOM は `house-name-band`。
- なまえを かえる … `menu().page` が `'rename'`（一覧）・`'renameName'`（名前の 画面）。ボタン `renamePick-<家の id>`・`renameOk`・`renameCancel`、`house.renaming()`。家 0 けんの `rename` は 押せない。
- 向き（決め 1）: 家の まえ ＝ 南 ＝ +z、方眼の 右 ＝ 東 ＝ +x。rot 0 ＝ 前が 南 → 1 ＝ 西 → 2 ＝ 北 → 3 ＝ 東。ふとんは 頭〔まくら〕が 家具の うしろ側（rot 0 ＝ 北）。
