# WEAPON-2: 弓矢と刀（カタナ）の作り直し

オーナー要望（2026-10-12）:「弓矢の軌道や、それぞれの武器を使った時の攻撃の仕方、モーションがいまいち。どこかのフェーズで直したい」

## 弓矢
- **山なりの軌道**にする（重力で落ちる放物線）。
- 弓の **ひきしぼり具合（ボタンを押す長さ）で 飛ぶ距離と山なりが決まる**。毎回 同じ長さなら 同じ所に落ちる（ランダムなし）。
- こどもが **どこに当たるか エイムする** タイプ（狙う練習になる）。
- （PO 案）ひきしぼりの段階が分かる表示（弓のしなり・ゲージ）、落ちる場所の目安は 出さない or さいしょの数回だけ出す はデザイナーが提案。

## 刀（システムごと作る）
- 刀を持っているときは **両手持ち**。**構え** を 3 つ切り替える: 構え切り替えボタンを押すごとに **中段 → 上段 → 下段 → 中段** とループ。
- 攻撃ボタン（ひだりクリック）で、構えごとの技:
  | 構え | 技 | 特徴 |
  |---|---|---|
  | 中段（正眼） | **突き** | 隙が少なく、長く（リーチ長い）、速い。当たり判定は正面だけで少し当てにくい |
  | 上段 | **大袈裟斬り**（頭上から思いきり振り下ろす） | 斜め前方をすべてカバー（とても広い）。ダメージとても高い。発生 9F・持続 3F・振り切って動けない 24F |
  | 下段 | **切り上げ** | 下から斜め前方の上までカバー。高い所の敵にも当てやすい。モーションの長さは大袈裟斬りの半分くらい。ダメージ・隙の少なさは 3 つの中で 2 番目 |
- 構え方・キャラクターの動きは 調べて考える（オーナーが調べた資料: 五方の構え。正眼=剣先を相手の喉・眉間、右足前。上段=頭上に掲げ剣先は斜め後ろ、左足前の左上段。下段=剣先を膝の高さ。大袈裟斬り=肩から脇腹へ斜めに斬り下ろす。斬り上げ（逆袈裟）=下から斜めに）。
- 6 歳ルール: 血の表現なし。点滅の決まり。

## その他
- なぎなた・素手 など ほかの武器の動きも いまいち → 今回の仕様で「直す方針」だけ書く（作るのは あと）。
