# PERF-3（#202）ブロックの型

決定: `docs/decisions/2026-10-18-kata-202.md`。試作はこのブランチの最初のコミット（`src/proto/voxel/looks/kata.ts`・`index.ts` の `fillBlockLookKata`・`sectionMesher.ts` の `uniq`/`underground`）。

## 受け入れ基準
1. 型の表 `KATA_TABLE` は決定どおり（はっぱ 3 種 4・き 3・たけ 3・くさ/つち/すな/ゆき/そこいし 4・いし/せきたん/てつ 8・地下 `@under` 8）。表に無い種類は型を使わない。
2. ゲームの既定（`?kata` なし）は この表。`?kata=off` で 型なし（いままでと同じ 毎回計算）、`?kata=4|8|16` で 全部その数、`&kataUnder=K` で地下の数を上書き。
3. 型を使うとき、同じ（種類・見える面・位置）からは いつも同じ 729 マス。出力は どれも「その種類の ふつうの形」の 1 つ（= ある位置で `fillBlockLook` した結果と同じ）。1 つの（種類・見える面）で ちがう出力は K 通り以下。
4. 型の出力も 見えない面の外がわは つまっている（ブロックのさかいに すきまがない。looks.test の約束 3 と同じ）。
5. 水がとなりにある ブロックは 型を使わず 毎回計算（`fillBlockLook` と同じ結果）。
6. 地下の見分け: 見える面の前の空気が、その列の地面より下なら 地下（型 `@under`）。崖の横の面（となりの列の地面が低い）は 地下ではない。はっぱは 地下あつかいしない。
7. `setCurrentLook` で見た目を切りかえると とっておいた型は捨てる。
8. 性能: `npm run perf` の budget（はらっぱ・もり、影なし）で 歩く 1 コマ p95 が 8 ms 以下のまま、小ブロック 1 区切りの中央値が 型なしより 25% 以上 小さい（PR に前後の数を書く。CI では見ない）。
9. E2E の見た目の spec（`fine()`）は 既定の型で 緑。
