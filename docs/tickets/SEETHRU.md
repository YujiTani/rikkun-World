## 目的
段差の下（崖のいちばん下の固いブロック・れんがや置いたブロックの下）で、地面の中ごしに空の色が見える穴を なくす。調査: `/mnt/project-files/vox-e/see-through-investigation.md`。
- 原因: 段差の下の固いブロック X は「1 ブロック単位」の判定で見える面が 0 になり、面が作られない（`sectionMesher.ts:443-447`・`:470-475`・`:684`）。小ブロック地形の表面 S は、となりの表面ブロック T の上のへりより最大 6 小ブロック下までへこむので、S と上のへりの間の帯に だれも面を作らない。
- 直し方（案 a）: 表面ブロックのとなりの固いブロックを「けずらない平らな箱（`fillSolid`）」として、面を作る対象（active）に入れる。面を省くのは 小ブロック単位の判定（`:704-705`）が自動で やる。

## きまり
- 面を省いてよいのは、となりが本当にふさいでいるときだけ。X の T がわの面は「見えない面」なので、外がわの層は 9×9 すべてつまっている（Look の約束 3）。
- 「ほったら でこぼこになる」は 今のしくみのまま（上をほれば、その列の表面になって小ブロック地形で描かれる）。追加の仕事は いらない。
- 三角形の増えは 少しだけ（調査では いつもの島で +0.4%）。作る時間は 変えない。

## 数え方（基準 1〜5・7）
`src/world/render/voxel/seeThrough.test.ts` の `countHoles`。調査の付録の数え方を、メッシュの中身（格子・active）を見ずに 世界と式だけで決めるようにした。
- セクションを小ブロック段（`build(cx, sy, cz, 'micro')`）で作り、出てきた四角を「向き・面の高さ・u・v」ごとの 1 小ブロックの印にする。
- X = 固くてとなりの面をかくすブロックで、その列の地面の表面ブロック（`scanColumn` の `ty`）ではないもの。T = X のとなりの地面の表面ブロック。
- X の T がわの 9×9 のそれぞれについて、となりの小ブロック（T の中）が S より上（`sampleSurface` の h 以上）なら、その面の四角が作られていなければならない。
- 作られていない 1 小ブロックの面 = 「ぬけている面」、1 つでもある X = 「穴のあるブロック」。
- 確かめ済み: いつもの島で ぬけている面が **10,048**（調査と同じ数）。向きごと: +x 2,353・-x 2,914・+z 2,447・-z 2,334・上下 0。穴のあるブロックは この数え方で 1,072（調査の 1,271 は 数え方の単位がちがう）。調べた面（見えるはずの面）は 11,272。
