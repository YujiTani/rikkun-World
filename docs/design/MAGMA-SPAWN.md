# MAGMA-SPAWN: マグマを はじめの そばで 確かめる・自然の 溶岩の いけ と 滝

## §1 ねらい
ゆず（オーナー）が 自分の PC で マグマ（WATERFALL-1 の 溶岩・ぐつぐつ・こげた ブロック）を すぐ 見られる こと。
あわせて 世界の 生成で 溶岩の いけ・マグマの 滝・水の 滝が 自然に 出る（かっぱの ぬま の いけ と 同じ 作り）。

## §2 順番（ロール）
設計（この 文書）→ 開発（①見本 ②生成 ③マグマの わきみずの たきつぼ）→ テスト（ユニット・E2E・画面）→ レビュー。

## §3 確かめる ための 見本（`?demo=magma`）
- URL に `?demo=magma` を つけた ときだけ。はじめの 場所の 前（北、スタートの 向き）6〜20 マスに 1 回 置く（`src/debug/magmaDemo.ts`）。
- 中身: マグマの いけ 6×5（深さ 2・ぐつぐつ マスは 座標で 15%）、東どなりの 水の みぞ（ふれた マグマが こくようせき）、
  マグマの わきみず（こくようせきの ます。いっぱいで とまる）、水の わきみず ＋ たきつぼ（さいしょから つながった 滝）、こげた ブロックの 見本。
- 保存の ある 世界でも 置ける（保存される）。ためす だけなら `?nosave=1&demo=magma`（保存しない 新しい 世界）。
- ふつうの ゲーム・生成・ゴールデンには さわらない（URL が なければ 何も しない）。

## §4 自然の 溶岩の いけ・滝（`src/world/gen/liquidPonds.ts`）
かっぱの いけ（biome.ts `pondsOfCell`・`pondAt`）と 同じ 作り: だ円の inner ＋ ring 1 マス、高さは terrain.ts の heightUncached で
inner = へり − 深さ − 1・ring = へり、chunk.ts が 底の 上から へりの 1 つ下まで 液体で うめる。底・へりは いし。木・くさ・やさい・見える 鉱石は 出ない。surface.ts も 同じ 答え。

| | きまり |
|---|---|
| 場所 | 96×96 の 升目（anchor から）に 0 か 1 こ。升目の へりから 12 マス 内がわ。陸（高さ ≥ 海 ＋ 3）・へりの 高さの 差 ≤ 2・岩山・かっぱの いけ に かからない |
| 頻度 | 升目の 30%。しゅるい: 溶岩の いけ 45%・マグマの 滝 25%・水の 滝 30% |
| 大きさ | はば 4〜6、深さ 1〜2、滝の 高さ（はしら）4〜6 |
| はじめの 場所 | チェビシェフ 40 以内には 升目の いけを 置かない。かわりに「はじめの そばの 溶岩の いけ」1 こ: 広場（ringMax 6）の 外、候補（東 13 → 西 13 → 南 13 → …）の 最初の 平らな 所。6×5・深さ 2・滝なし（はじめの そばで ずっと 動く 物を 置かない: 光・メッシュ・E2E の しずけさ）|
| 安全 | スタート地点・広場・スタートの たいまつ に かからない（広場の へり から 3 マス 以上 はなれる）。いけの まわりは いしの へり 1 マス |
| 滝 | いけの 南の へりに はしら（マグマ = こくようせき、水 = いし）、上に わきみず。下が はしら なので 北（いけの 上）へ 出る。落ちる 先の 底は 1 マス くぼませた たきつぼ |
- くぼみ: 底と 同じ 高さの たきつぼ だと 地形の 小ブロックの 横の 面が ぬける（seeThrough テスト）ので 1 つ 深く した。
- はしらの 東・西・南の 地面が へりより 高い ときは 滝なし（同じ 理由）。そのときの 水は ただの いけ。

## §5 マグマの わきみずの たきつぼ（`springs.ts`）
マグマの わきみずも 真下の 床が たきつぼ なら つながる（たきつぼの 上の マグマ 1 つぶ → 出口。量は かわらない）。自然の マグマの 滝が あふれない ため。
マグマで たきつぼは できない（置く か 生成だけ）。生成した 列で 滝の ある 列だけ わきみずを さがす（`springsIn`。ほかの 列は さがさない = perf）。

## §5.1 遠い わきみずは 休む・光の 仕事
- プレイヤーから チェビシェフ 32（`SPRING_TUNING.activeRadius`）より 遠い わきみずは 休む（自然の 滝が 世界中で 仕事を しない）。置いた わきみずも 同じ。
- 同じ 液体の 量だけ かわる ブロックの 変化（水 → 水・マグマ → マグマ）は 光の 計算し直しに 知らせない（光を 弱める 量・出す 光が 同じ）。滝が 動いても 光の 仕事が ふえない。

## §6 ゴールデン・決まり
- 生成は シードと 座標だけで きまる（作る 順に よらない。テスト あり）。
- mesher の golden: いけ・滝を ふくむ 6 セクション（seed 20261012・31415 など）だけ ハッシュが かわる → `GOLDEN_WRITE=1` で 作り直し。
- mineOres A4（MINE-1 前の 列の ハッシュ）: いけに かかる 列は くらべない（それ いがいは 前と 同じ）。地層の テスト（基準 4）: いけの 列は のぞく。
- surface.test: マグマ（量 8）は 水と 同じ 液体として 数える。

## §7 制限
- 生成の マグマは 起こされる まで 計算しない → まわりの いしが こげるのは 滝の まわりなど 動いた マグマ だけ。
- 地下の 溶岩だまりは 入れて いない（次の 候補）。
