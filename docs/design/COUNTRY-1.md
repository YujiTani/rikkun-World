### 3.3 妖怪の えらび方（順番のきまり）

1. **場所を さきに決める**: 今と同じように、プレイヤーのまわりで 置ける所（読みこんだ列・水でない・立てる床）を さがす。
2. **その場所の国の行で 種類を えらぶ**: その (x, z) の `countryAt` の `kind` の行。重み × 全体の倍率（下）で、シード付きの乱数（今の 妖怪の乱数と同じもの）で 1 つ えらぶ。
3. えらんだ種類の 体の大きさで 足場・暗さ・屋根 を たしかめる（今のきまり。種類で 体の高さが ちがうため、えらんだあとに 見る）。だめなら その「ためし」は 失敗にして、次の ためしで 場所から やりなおす（種類も えらびなおす）。ためしの回数は 今のまま。
- **境目**（`e < blend`）: **特別な処理は ない**。`countryAt(seed, x, z).kind` は もともと いちばん近い点の国なので、境目でも その行を そのまま使う（2 つの国を まぜない）。理由: 境目は はば 14 ほどで せまく、まぜても 子どもには ちがいが分からない。1 つの行だけなら テストで 決まった答えになる。
- **今のコードからの 組みかえ**（事実の確認。やり方は developer）: 今の `trySpawn` は「種類（`pickKind`）→ その種類の `KIND_AI` → 場所を さがす」の順。これを「場所 → 国 → 種類 → その種類の `KIND_AI` で 足場・屋根」の順に 組みかえる。**乱数を使う順番が かわる** ので、同じシードでも 出る妖怪の 種類・場所・順は この issue の前と かわる（AC8 は 強さの計算だけを「前と同じ」で見る。こわれる既存テストは タスク票の「テスト準備で 見ること」）。
- **表に ない種類は 重み 0**（その国では出ない）。のちに国だけの妖怪を足すときは、その国の行に 書き足すだけ（ほかの国の行は さわらない）。
- **行の合計が 0** のとき（全体の倍率で ぜんぶ 0 にした など）: ものさしの行（はらっぱ）を使う。それも 0 なら そのためしでは 出さない（今の「重みが ぜんぶ 0 なら 出さない」と同じ）。
- **全体の倍率**: 今の設定 `config.yokaiWeights` は「全体の倍率」に 意味をかえる（既定は 4 種とも 1。0 か null なら その種類は どの国にも出ない。2 なら どの国でも 2 倍）。30・25・25・20 の数は 表の ものさしの行に うつす（同じ数が 2 か所に ならないように）。今 `yokaiWeights` を使っている テストは ない（2026-10-23 grep）。
- **テストできる形の約束**（名前と 引数・返す形だけ。置くファイルは developer）:
  - 純粋な関数 `pickYokaiKind(row, scale, nurikabeFull, r)` → 種類 か `null`。`row` = 国の行（種類 → 重み）、`scale` = 全体の倍率（`config.yokaiWeights`。種類 → 数 か null）、`nurikabeFull` = ぬりかべ が 同時の上限に いるか、`r` = 0 以上 1 未満の 乱数 1 つ。行の合計が 0 のときの ものさしの行への もどしは この関数の外（呼ぶ がわ）で する。
  - 妖怪の係（今の `YokaiManager`）は 作るときに **国を聞く口** `countryOf(x, z) → kind` と **国の表**（12 行）を 外から 受けとる。つなぎ込みでは `countryAt` と §3 の表を渡し、ユニットテストでは 差しかえる（AC6）。
- 地下（ほらあな）でも 今は 同じ表（その列の国の行）を使う。地下だけの表（大百足のすみか・いわやまの地下 など）は 国の妖怪 36 体・炭鉱 #265 の issue で 足す。


## 4. 「国に入った」の判定（実績のため）

名前のふだ は 作らない（オーナー決定）。判定だけ のこし、見つけた国の並び と 実績 に使う。

### 4.1 判定
- その国の **まん中寄り**（`e ≥ blend`）に **続けて 180 コマ（3 秒）** いたら「その国に入った」。境目（`e < blend`）に出たら 数えなおし（0 から）。
- **地下では 数えない**: 足の高さ（y）が その列の **生成の地面の高さ** `heightAt(seed, x, z)`（`src/world/gen/terrain.ts`。プレイヤーが ほった・積んだ 分は 入らない）より **8 以上 ひくい**（足の y ≤ `heightAt` − 8）ときは 数えない。足の y = プレイヤーの位置の y（立っているときは 立っている ブロックの y ＋ 1。`heightAt` は 地面の いちばん上の ブロックの y なので、地面に立つと 足の y = `heightAt` ＋ 1）（ほらあなの中で 見ていない国を「行った」ことに しない）。海・池・川の中は 数える。
- 「今の国」= さいごに 入った国。はじめは なし（`null`）。ロードした直後も なし（もう一度 180 コマで決まる）。境目を 行き来するだけでは かわらない。
- 入った国が 見つけた国の並びに なければ: 並びの うしろに足す → 実績（§5）。もう並びに あれば 何もしない（音・表示なし）。
- テレポート（テストの 移動）でも 同じきまり。ゲームの時間が 止まっている間（ポーズ・案内画面）は コマを数えない（もちもの画面の 1/4 の速さの間は 今の時間の すすみ どおり）。実績の おしらせ は ゲームを 止めないので その間も 数える。やられた画面の間も 数えない。

### 4.3 ゲームの はじめ と テスト用の しずかモード
- **新しい世界**: スタートの国 はじまりの はらっぱ を、はじめから 見つけた国の並びに 入れておき、実績 `visit.country.harappa.1` を **しずかに取る**（M6 §2.6 (4) の `level` と同じ: 見せた ことにし、まだ見せていない列に 入れない・メダルの数・音なし）。
  - **足す場所**: 今の `syncSilently`（`src/achievements/AchievementSystem.ts`。ロードした直後に レベル・防具を しずかに取る口）に ならべる。「並びに `harappa` が なければ **先頭に** 足し、記録と `visit.country.harappa.1` を しずかに そろえる」。つなぎ込みが **ロード（`deserialize`）のあと と 新しい世界の 開始時** に 呼ぶ（今の `src/main.ts` の `syncSilently` の 呼び出しと 同じ所）。`reset()`（テスト用に 全部 0）では 足さない。
  - `foundCountries` が あって `harappa` が ない セーブ: ロードのあと `syncSilently` で 先頭に 足す（ほかの国の 順は そのまま）。
  - `setFound([])` のあと: その場では 空のまま（テストの 口なので 足さない）。セーブして 開きなおすと `syncSilently` で [`harappa`] に なる。
  - 理由: スタートは かならず はらっぱ（VOX-I §3.5）。はじまって 3 秒で 実績が出ると、すべてのテストの はじめに 実績・メダルの数・音が ふえて、実績の数・音の回数を見る 今のテストが こわれる。りっくんにも「なにもしていないのに 取れた」になる。
- **見つけた国の並びが ない 今までの セーブ** を開いたときも 同じ（はらっぱ を しずかに 入れて しずかに取る）。ほかの国は ふつうに 見つける。
- **「入った」を 実績の係に 伝える口**（名前と 形だけ約束）: `AchievementSystem.enterCountry(kind, silent)` → 新しく 並びに 足したら `true`、もう あれば `false`。180 コマを 数える係は `enterCountry(kind, false)` を 呼ぶ（実績を ふつうに 取る）。`syncSilently` は `enterCountry('harappa', true)`、`biome.setFound` は 並びを 入れかえて しずかに そろえる（`silent = true` と 同じ あつかい）。
- **テスト用の しずかモード** `biome.quiet(on)`: on の間は「入った」の判定を しない（見つけた国・実績・音 が ふえない）。はじめは off。国へ テレポートする 今のテスト（実績・音の回数・おしらせが 出ると こまるもの）を まもるための 口。ゲームの中から on にする道は ない。
