## 1. ねらい（りっくんが どう 楽しむか）
- はじまりの はらっぱ に、さいしょから 小さな **街（まち）** が ある。妖怪が 入って こない、ほっと する 場所。
- 妖怪を たおすと かならず **ようかいダマ** が もらえる。ためて **よろずや** で ほしい 物と こうかん したり、**たからばこ** を あけたり。おやぶん・たいしょう・ヌシ は ダマが いっぱい。「たおす → ためる → えらぶ」が 1 本に つながる。
- 実績を とっても ダマ。にじ の メダルは たくさん。
- **ものしりさん** が「いまの めあて」を 1 つずつ くれる。画面の すみに いつも 出て いるので、つぎに 何を すれば よいか まよわない。ジャンプ → ダッシュ → ロープ → かたな → ゆみ → むし・にわとり → けんちく → ぼうけん と、遊び方を ぜんぶ さわれる。できたら ものしりさんに 話すと ごほうびと つぎの めあて。にわの わらにんぎょう と まと で、かたな と ゆみ を あんしんして れんしゅう できる。
- 遠くで まよっても **かえりの おふだ** で 街へ ひとっとび。こわれそうな かたなは **かじやさん** が なおして くれる。はたけの やさい・たまご・ほった 鉱石は **やたい** で 少し ダマに なる。
- 2 人の ときは、ダマも めあても それぞれ。きょうだいで「どっちが さきに できるか」。

### 2.2 街〔1B〕
1. 新しい 世界でも 前の 世界でも、はじまりの はらっぱ の **スタート地点の そば** に 街が 1 つ ある（§4.5）。同じ シードなら いつも 同じ 場所・同じ 形。 **街の 入り口の 門は スタート地点の ほうを 向き、スタート地点に 立つと 門と あかりが 見える**（yuzu 2026-11-13「プレイヤーの最初のリスポンの場所の近くに作って」。やられて もどった ときも 同じ）。
2. 建物は 3 つ: **よろずや**（お店。中に よろずやさん と たからばこ）、**だいくさんの こや**（中に 建築士さん）、**ものしりさんの いえ**（中に ものしりさん。前に **にわ**）。戸口は 戸の ない 入り口（あける 手間 なし）【PO 案】。街の まん中は **ひろば** で、まん中に **ふんすい**（決定 16:59。目じるし。水は かざりで ながれ出さない）。〔1E〕ひろばの ふちに やたいが 2 つ: **かじやさんの やたい**（かなとこ と ふいご）と **やたい**（やたいさん。かいとり）【PO 案: かじやさんは 建物で なく やたいに する。外から 見えて 6 歳が 見つけやすい】。ふんすいの 前が おふだで もどる 所。
2b. **あきち**（決定 16:59「何軒か空き地」）: 街の 中に **3 区画**【PO 案: 3〜4 の 3。48×48 には 12×12 が 3 つ まで しか 入らない（アートの 配置で 確かめた）。たりなければ あとで 街を 広げて 足す】。どの 区画も 家を 1 けん 建てられる 広さ（§4.5）。ふちに くい（区画が 分かる）。あきちは 安全地帯の 中なので、建てた 家は はじめから 妖怪の 来ない 家。**地盤の きまりは HOUSE-1 の まま**: 地面は はじめ たいらな つち（同じ 高さ）にして おき、みずもり → どうづきで かためた つち に する のは プレイヤー（HOUSE-1 §2.9）。だれの 区画かは 決めない（2 人で どれを 使っても よい）。
3. **にわ**: わらにんぎょう 1 つ、まと 2 つ（ちかい まと・とおい まと）、ジャンプの **れんしゅうの だん**、ロープの **れんしゅうの がけ**（§4.5）。
4. **あかり**（決定 17:00「灯りをたくさんつけて妖怪が来れないように」）: 街の **ふちに ぐるっと あかりを ならべ**、ひろば・道にも 置く。夜は 街が 遠くから 明るく 見え、6 歳に「**あかるいから ようかいは こられない**」と 分かる（ものしりさんの めあて 1 の 説明でも ひとこと「まちは あかるいから ようかいは こないよ」）。しくみは 下の 安全地帯の まま（あかりで 決めて いるのでは ない）。あかりは 街の ブロック なので こわせず、もし 消えても 安全地帯は 消えない。数と 間は §4.5。
5. **安全地帯**: 街の はんい（§4.5）には 妖怪が **わかない**。外の 妖怪は はんいの ふちから 中へ **入れない**（ふちで 向きを かえて はなれる）。妖怪の こうげき（とびどうぐ も）は はんいの 中の プレイヤーに 当たらない。夜も 同じ。
6. **街は こわせない**: 街の はんいの ブロックは ほれない（ひびも 入らない）・ブロックを 置けない。ほろうと すると 手が「こつん」と はねかえる（1 回の 小さな 返し）。右の 案内は「ほる」を 出さない【PO 案】。**ただし あきちの 区画の 中**（地面から 上も 下も）は ふつうに ほる・おく が できる（地盤を つくり、家を 建て、作りかえる ため）。街の 中で 家を 建てられるのは **1 つの あきちの 中に ぜんぶ 入る 場所 だけ**（HOUSE-1 の 上空の 視点で、あきちから はみ出す 所・道・ひろばは 赤）。街の 外は 今の まま。
7. 街の 人（よろずやさん・建築士さん・ものしりさん・かじやさん・やたいさん）と わらにんぎょう・まとは たたいても 弓で うっても **へらない・たおれない**（HOUSE-1 §2.2 の 3 と 同じ よろけ）。ダマ・けいけんちは 出ない。

### 2.9 2 人の とき（COOP-1）
