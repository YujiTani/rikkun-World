## 1. ねらい（りっくんが どう 楽しむか）
- はじまりの はらっぱ に、さいしょから 小さな **街（まち）** が ある。妖怪が 入って こない、ほっと する 場所。
- 妖怪を たおすと かならず **ようかいダマ** が もらえる。ためて **よろずや** で ほしい 物と こうかん したり、**たからばこ** を あけたり。おやぶん・たいしょう・ヌシ は ダマが いっぱい。「たおす → ためる → えらぶ」が 1 本に つながる。
- 実績を とっても ダマ。にじ の メダルは たくさん。
- **ものしりさん** が「いまの めあて」を 1 つずつ くれる。画面の すみに いつも 出て いるので、つぎに 何を すれば よいか まよわない。ジャンプ → ダッシュ → ロープ → かたな → ゆみ → むし・にわとり → けんちく → ぼうけん と、遊び方を ぜんぶ さわれる。できたら ものしりさんに 話すと ごほうびと つぎの めあて。にわの わらにんぎょう と まと で、かたな と ゆみ を あんしんして れんしゅう できる。
- 2 人の ときは、ダマも めあても それぞれ。きょうだいで「どっちが さきに できるか」。

### 2.2 街〔1B〕
1. 新しい 世界でも 前の 世界でも、はじまりの はらっぱ の **スタート地点の そば** に 街が 1 つ ある（§4.5）。同じ シードなら いつも 同じ 場所・同じ 形。
2. 建物は 3 つ: **よろずや**（お店。中に よろずやさん と たからばこ）、**だいくさんの こや**（中に 建築士さん）、**ものしりさんの いえ**（中に ものしりさん。前に **にわ**）。戸口は 戸の ない 入り口（あける 手間 なし）【PO 案】。
3. **にわ**: わらにんぎょう 1 つ、まと 2 つ（ちかい まと・とおい まと）、ジャンプの **れんしゅうの だん**、ロープの **れんしゅうの がけ**（§4.5）。
4. **安全地帯**: 街の はんい（§4.5）には 妖怪が **わかない**。外の 妖怪は はんいの ふちから 中へ **入れない**（ふちで 向きを かえて はなれる）。妖怪の こうげき（とびどうぐ も）は はんいの 中の プレイヤーに 当たらない。夜も 同じ。
5. **街は こわせない**: 街の はんいの ブロックは ほれない（ひびも 入らない）・ブロックを 置けない。ほろうと すると 手が「こつん」と はねかえる（1 回の 小さな 返し）。右の 案内は「ほる」を 出さない【PO 案】。街の 中に 家を 建てる 場所は 選べない（HOUSE-1 の 上空の 視点で 赤）。
6. 街の 人（よろずやさん・建築士さん・ものしりさん）と わらにんぎょう・まとは たたいても 弓で うっても **へらない・たおれない**（HOUSE-1 §2.2 の 3 と 同じ よろけ）。ダマ・けいけんちは 出ない。

### 2.8 ものしりさん と いまの めあて〔1D〕
1. **すみの パネル**（§3.2）に 今の めあてを 1 つ: 絵（なかまの 印: うごく・とる・つくる・かたな・ゆみ・いきもの・けんちく・ぼうけん）＋ みじかい 文 ＋ すすみ（数の ある めあては「3 / 5」、ない めあては なし）。
2. めあてが **できた** ら パネルが「できた！」に かわり、ものしりさんの 顔と、ものしりさんへの **向きの やじるし**（カメラの 向きに 合わせて まわる）。小さな 音 1 回。パネルは そのまま（つぎの めあては 話すまで 出ない）。
3. **ものしりさんに 話す**（右クリック「はなす」）: ふきだしで —
   - できた めあてが あれば「よく できたね！」→ ごほうび（§4.4。ダマ ＋ つぎに 使う 物）が もちものに（入らない 分は 足もと）→ つぎの めあての 説明（1〜2 行。ボタンの 絵 つき。例「Shift を おしながら あるくと はやく はしれるよ」。パッドの ときは パッドの ボタンの 絵）。
   - まだ なら 今の めあての 説明を もう 1 回。
   - その あと メニュー: 「**もういちど きく**」「**めあてを とばす**」「**めあての いちらん**」「✕ とじる」。
4. **とばす**: 確かめ「ほんとうに とばす？」［とばす］［やめる］。とばすと **ダマは なし**、つぎに 使う 物は もらえる（つぎの めあてに いるので）。とばした めあては 一覧に「とばした」印。1 版では やりなおせない。
5. **順番**: §4.4 の 1 → 20。今の めあて だけ 数える。数を 数える めあて（「3 びき たおす」など）は その めあてが 出てから 数える。**もちもの・家など 今の ようすで 決まる めあて**（「き を 5 こ もつ」「家が ある」など。§4.4 の「ようす」）は、出た とき もう 満たして いれば すぐ「できた！」。

8. **まと**: 矢が 当たると まん中が ぱっと 光り「とん」。矢は まとに ささって 少しで 消える。
9. ものしりさんの 画面も よろずやと 同じ（1 人 全面・止める／2 人 半分・止めない）【PO 案】。
