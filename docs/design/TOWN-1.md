## 1. ねらい（りっくんが どう 楽しむか）
- はじまりの はらっぱ に、さいしょから 大きな **街（まち）** が ある。さいしょに 立つと 赤い **門** と **たいこ橋**、石どうろうの あかりが 見えて「あそこに 行こう」と 思える。街の 中では 妖怪が **わかない**。外から 来る 妖怪は いて、街の 中でも 刀と 弓で たたかう（1.3。決定 2026-11-14）。大きな 妖怪が あばれて 街が こわれても、つぎの 朝には **街の だいくさん**（こやの 建築士さん）が こやから 歩いて 来て、足場の そばで トントン なおして いて、2 日で もとどおり（1.4）。その 間 こやは るす。「まちは みんなで まもって なおす 所」と 感じられる。
- 街の 中は 見て まわるのが 楽しい: 石がきの **用水路**（落ちても いたくない。石段で すぐ 上がれる）、白い 石の **段々の ふんすい**、ものが あふれる **よろずや**、火が ごうごう の **かじや**、木の においの **だいくさんの こや**、**道場** と 忍者の しゅぎょう場みたいな **アスレチック**。
- 妖怪を たおすと かならず **ようかいダマ** が もらえる。ためて **よろずや** で ほしい 物と こうかん したり、**たからばこ** を あけたり、**やたいで だんご・ごはん** を 食べて 元気に なったり。おやぶん・たいしょう・ヌシ は ようかいダマが いっぱい、がしゃどくろ は 300 こ。「たおす → ためる → えらぶ」が 1 本に つながる。
- 実績を とっても ようかいダマ。にじ の メダルは たくさん。
- **ものしりさん** が「いまの めあて」を 1 つずつ くれる。画面の すみに いつも 出て いるので、つぎに 何を すれば よいか まよわない。ジャンプ → ダッシュ → ロープ → かたな → ゆみ → むし・にわとり → けんちく → ぼうけん と、遊び方を ぜんぶ さわれる。道場の けいこ場の わらにんぎょう と まと で、かたな と ゆみ を あんしんして れんしゅう できる。
- 遠くで まよっても **かえりの おふだ** で 街へ ひとっとび。こわれそうな かたなは **かじやさん**（ひげの むきむきの 大男）が なおして くれる。はたけの やさい・たまご・ほった 鉱石は **やたい** で 少し ようかいダマに なる。
- 2 人の ときは、ようかいダマも めあても 体力も それぞれ。きょうだいで「どっちが さきに アスレチックの 太鼓を ならせるか」。

- 人ごと（1P・2P）: ようかいダマ（もちものの 中）、めあての 番号・すすみの 数・できた か・とばした 番号、こばこ／おおばこ／まきものを 買った 回数（くじの たね）、〔1E〕やたいで きょう もらった ようかいダマの 数と その 日、〔1B-2〕アスレチックの 太鼓を はじめて たたいた か。
- 世界: 街の 場所・向き と 作った 記録（街の 形の 版 ＝ 1.3。TOWN-1-place §4.5 の 下）、実績の ダマを わたした 記録（実績ごと）、前の セーブの あずかり（わたしたら 消す）。
- 世界（1.4）: **まだ もどって いない 街の マスの 位置（x・y・z）と こわれた 日（`time.day()`）だけ**。レビュー直し: プレイヤーが ほった ふちの マスには「プレイヤーの 印」、プレイヤーが ブロックを 置いた マスには「置いた 物と 置いた 人（1・2）」を 足す（その マス だけ。TOWN-1-place §2.16 の 4b）。設計の 中身・だいくさん（建築士さんが どこに いるか・るす か）・足場・まつ か どうか は 保存しない（ロードの ときは 建築士さんは こやに いて、つぎの 朝から 回る）（中身は 設計と 生成から、だいくさん・足場は マスと 日から 作りなおす。TOWN-1-place §2.16 の 7）。もどした マスは 記録から 消す。
- 古い セーブ（記録 なし）: めあて 1・すすみ 0・回数 0・太鼓 まだ。あずかりは §2.4 の 5。こわれた マスの 記録 なし ＝ 0 こ（1.3 までは 街が こわれない ので 前の こわれは ない）。
