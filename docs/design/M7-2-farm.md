## 1. ねらい（りっくんがどう楽しむか）

- **みず を はこべる**: じょうろ で かわ の みず を くんで、とおくの はたけ に まく。まいた はたけ は こい色（しめった）に なって、はやく そだつ。「みず を あげたら げんきに なった！」
- じょうろ は 1 回で ねらった はたけ 1 マス。**ながい じょうろ** は 1 回で 2 マス（ねらった はたけ と その むこう）、みず も 2 倍 入る。てつ を あつめる 目当て に なる。
- **スプリンクラー** を おくと、まわり（5×5）の はたけ が ずっと しめる。ときどき みず の しぶき が くるっと とぶ のが 見えて、「うごいてる！」と 分かる。
- **なでる**: そだっている やさい を 右（みぎ）クリック すると、やさい が ふるふる ゆれて ハート が ふわっと 出て、やさしい 音。なでた やさい は「ごきげん」に なって **すこし** はやく そだつ（1 にち 1 回。ごきげん の やさい からは ときどき 小さな ハート）。
- **みのった やさい は キラキラ** 光る（星の つぶ が ふわっと のぼる）。とおくから「とれる やさい」が 見つけられる。

## 2. 遊び方（プレイヤーから見た動き）

### 2.1 じょうろ・ながい じょうろ

- **つくる**: つくる画面 で（§4.2）。できた じょうろ は **からっぽ**。
- **みず が 入っている量** は、ホットバー・持ち物 の マスの 下に **青い 棒**（§3.2 (4)）で見える。からっぽ なら 棒は 灰色の わく だけ。
- **くむ**: じょうろ を持って **みず を ねらって 右クリック 1 回** → **まんたん**（じょうろ **10 回分**・ながい じょうろ **20 回分**）。ゴボゴボ という音、じょうろ に みず の つぶ が 入る。
  - 「みず を ねらう」= 目から ねらいの線（M2 の とどく距離 5）を のばして、**固いブロック・作物 に 当たる より 手前で `water` の マス を 通る**。目の ある マス の みず は 数えない（かわ に 立っていても、はたけ に まける）。
  - まんたん の ときに くんでも 何も変わらない（小さな ちゃぷん の音 だけ）。
  - **みず の むこう の はたけ（かわ ごし など）には まけない**: 線 が みず を 通る と いつも くむ（4a が 4b より 先）。まく ときは みず を 通らない 所 から ねらう。
- **まく（みずやり）**: みず の 入った じょうろ を持って、**はたけ か 作物 を ねらって 右クリック** →
  - **じょうろ**: **ねらった はたけ 1 マス**（1×1）。
  - **ながい じょうろ**: **2 マス**（2×1）= ねらった はたけ と、その **むこう** の となり 1 マス。「むこう」は プレイヤー の 見ている 向き を 水平 に した ベクトル (dx, dz) で、**|dx| ≥ |dz| なら x の 向き（dx が 正 なら 東 +x、負 なら 西 −x）、そうでなければ z の 向き（dz が 正 なら 南 +z、負 なら 北 −z）**（東西南北 の うち 近い 方。ちょうど 45° は x）。むこう の マス は ねらった はたけ と 同じ 高さ ± 1 の はたけ（無ければ 1 マス だけ）。
  の はたけ が **その ステップで しめった** に なる。みず が 1 回分 へる。シャーッ という音、じょうろ が 前に かたむき、はたけ の上に しずく が ふる。
  - ねらう もの: はたけ なら その はたけ、作物 なら その下 の はたけ。ほかの ブロック（くさ など）を ねらったら はたけ は 0 マス。
  - **数えかた**: はんい に はたけ が 1 つ でも あれば（もう ①③ で しめっていても）**みず は 1 回分 へり**、`tiles` = はんい の はたけ の 数、記録 `water:*` も 1 ふえ、② の のこり も 1 にち に なる。はたけ が **1 つも 無い** ときは しずく と 音 は 出るが、**みず は へらず** 記録 も ふえない（むだに ならない）。
  - **おしつづける** と、押した瞬間 と **30 ステップごと** に まく（M2 の 置く と同じ間）。ねらいを 動かせば つぎつぎ まける。くりかえし の ステップ で ねらい（線）が みず を 通って いても **くまない**（くむ は 押した瞬間 だけ）。その ステップ は 何も しない。
- **からっぽ で まこうとした**（みず を ねらっていない）: 何も変わらず、合図 `fill`（§3.3）「じょうろ が からっぽ。水（みず）に むけて 右（みぎ）クリック で くもう」。
- まいた はたけ は **1 にち（91,800 ステップ）しめった まま**（§4.3）。そのあいだに もう 1 回 まくと、のこり は **1 にち に もどる**（足し算 しない）。
- じょうろ は **こわれない**（たいきゅう 無し。WEAPON-2 の「ずっと へらない もの」）。

### 2.2 スプリンクラー

- **つくる**（§4.2）→ ブロック として **置く**（M2 の 置く と同じ。はたけ の上にも 置ける）。
- 置いた スプリンクラー から 横 x・z が **2 以内**（5×5）、高さ が スプリンクラー と 同じ〜2 下 の はたけ が **60 ステップ以内に しめった** に なり、スプリンクラー が ある あいだ ずっと しめった まま。
- **みず は いらない**（6 歳が こまらないように。どこに 置いても 動く）。**よる も 動く**。
- **そだつ 条件（明るさ 9 以上）とは 別**: スプリンクラー は しめらせる だけ。くらい 所 では しめっていても そだたない（M7 のまま）。スプリンクラー は 光らない・光を さえぎらない。
- 動いている しるし: **120 ステップごと**（スプリンクラー ごと に 場所 で 決まる ずらし。そろって とばない）に みず の しぶき 16 つぶ が まわり 2 マス に くるっと とぶ（§3.4）。音は 置いた とき だけ（動いている あいだ は 音なし。うるさく しない）。
- こわすと スプリンクラー 1 こ が もどり、60 ステップ以内に まわりの はたけ は ほかの みず が 無ければ かわく（じょうろ の のこり が あれば その分 しめった まま）。

### 2.3 なでる

- **作物（はたけ の やさい。stage 0〜3）を ねらって 右クリック**（押した瞬間 だけ）→ **なでる**。
  - 持っているもの: **防具・じょうろ 以外 なんでも**（すで・たね・やさい・ブロック・道具・武器）。防具 は きる、じょうろ は みずやり が 先（§2.4 の 順）。
  - 反応（いつも 出る）: 作物 が ふるふる ゆれる（24 ステップ）、ハート の つぶ が ふわっと のぼる、「ふわっ♪」の音、うで を 置く と同じ ように 小さく ふる。
- **ごきげん**: なでた 作物 は **1 にち（91,800 ステップ）ごきげん**。
  - ごきげん の あいだ は **そだつ 確率 が 1.1 倍**（§4.4）。待ちすぎない きまり も 同じ 倍率 で 計算するので、**ずっと ごきげん なら 平均 で T ÷ 1.1（約 9% はやい）**。
  - ごきげん の あいだに もう 一度 なでても **反応 だけ**（ハート 1 つ・音 1 つ）。ごきげん の のこり は のびない（**1 にち 1 回**）。ごきげん が おわったら また なでられる。
  - ごきげん は 段階 が 変わっても つづく。しゅうかく・作物 が なくなる と おわる。
  - ごきげん の 作物 からは **180 ステップごと** に 小さな ハート が 1 つ のぼる（なでた かどうか が 見て 分かる）。
  - しゅうかく の 数 は 変わらない（ボーナス は そだつ はやさ だけ。小さく する）。
- **やせいの やさい** を なでる: 反応（ハート 1 つ・音）だけ。ごきげん に ならない（そだたない ため）。
- かかし・さく・はたけ は なでない（今までどおり）。

## 5. 例外のとき

- **じょうろ を たんす に 入れる・すてる・やられて 落とす・入りきらず 落とし物 に なる**: みず の 量 は そのまま（拾えば 同じ 量）。
- **じょうろ を 2 つ 以上 持つ**: それぞれ 別 の 量（上限 1 なので かさならない）。
- **みず の 中 から ねらう**（目 が みず の マス）: その マス は 数えない（§2.1）。
- **ながい じょうろ の むこう の マス が はたけ で ない**（くさ・みず・世界 の はし など）: ねらった はたけ 1 マス だけ しめる（みず は 1 回分 へる。`tiles` 1）。みず は ふえない（みず ブロック は できない）。
- **はたけ の 上 に ブロック が ある**: その はたけ も しめる（はたけ は はたけ）。ただし ねらい は その ブロック に 当たる ので、ねらった はたけ に は ならない（むこう の マス と して なら しめる）。
- **作物 を ねらって まく**: その 下 の はたけ を ねらった と する。作物 は こわれない。
- **みず の むこう の はたけ**: まけない（線 が みず を 通る と くむ。§2.1）。
- **スプリンクラー を はたけ の 上 に 置いた**: その はたけ も しめる（上 が うまって いるので まけない）。こわせば まける。
- **スプリンクラー が かさなる**: どれか 1 つ の はんい なら しめる（2 倍 には ならない）。
- **よる・くらい 所**: しめる（①②③）は 時刻 に 関係 ない。そだつ のは M7 の まま 明るさ 9 以上 だけ。
- **なでた 作物 が しゅうかく された／はたけ ごと こわれた**: ごきげん は 消える。同じ マス に まいた 新しい 作物 は ごきげん で ない。
- **やられた とき**: じょうろ・スプリンクラー も ほかの 持ち物 と 同じ（M3 §2.8 の 50%）。はたけ の しめり・ごきげん は そのまま。
- **ページを 閉じていた 時間・止まっている あいだ**: じょうろ の のこり も ごきげん の のこり も へらない（そだつ と 同じ）。
- **ねらい が とどかない**: M2 の 5 マス の まま。くむ も 5 マス 以内 の みず だけ。

## 8. デザイナーが決めたこと（オーナー確認①で見せる要点）

1. **じょうろ**（第 2 版 オーナー判断）: みず に 右クリック 1 回 で まんたん（じょうろ **10 回分**・ながい じょうろ **20 回分**）。はたけ に 右クリック で じょうろ は **ねらった 1 マス（1×1）**、ながい じょうろ は **2 マス（2×1）**= ねらった はたけ と、見ている 向き の 近い 軸（東西南北）の むこう 1 マス。まいた はたけ は **1 にち（25.5 分）しめる**。もう 1 回 まくと 1 にち に もどる。こわれない（たいきゅう 無し）。からっぽ なら「くもう」の 合図。
2. **レシピ**: じょうろ = てつ 1・いし 2、ながい じょうろ = てつ 3・き 1、スプリンクラー = てつ 4・いし 2。つくる画面 は カード 25 まい に なるので **4×7（マス 28）** に ひろげる。
3. **スプリンクラー**（第 2 版 オーナー判断）: まわり **5×5**（x・z ± 2。高さ は 自分 〜 下 2）。**みず は いらない・よる も 動く**。しめらせる だけ で、そだつ のは 今までどおり 明るい 所 だけ。120 ステップ ごと に しぶき（音 なし）。
4. **なでる**: 作物 を 右クリック（防具・じょうろ 以外 なら 何を 持っていても）。ゆれ・ハート・やさしい 音。**1 にち 1 回 ごきげん**、ごきげん の あいだ そだつ 確率 **1.1 倍**（ずっと ごきげん で 約 9% はやい。小さく）。しゅうかく の 数 は 増やさない（オーナー資料 の「収量ボーナス」は 入れない: ボーナス は 小さく という 依頼 の ため）。ごきげん は 数字 で 出さず、ハート で 見せる（オーナー資料 の「数値は表示しない」）。
5. **右クリック の 順**: たんす → かまど → 防具 → **じょうろ** → **なでる** → たがやす → まく → 合図 → たべる → 置く。作物 を ねらう と なでる が 先 なので、やさい を 持って 作物 を ねらうと たべない（変わる 所）。
6. **キラキラ**: みのった 作物 と やせいの やさい から 45 ステップ に 1 つ 星 が のぼる（24 マス 以内・同時 96 まで・音 なし）。

8. **実績**: §4.7 の 数の表（そだてる 8・つくる 3）。
