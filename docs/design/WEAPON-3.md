## 0. オーナー決定（変えない。計画 §2〜§4）

| # | 決まり |
|---|---|
| O1 | 近接の 攻撃は ＋マークでなく **キャラの 向いている方** に出す（ダンジョンズ風）。カメラは マウスで 自由に回るまま（キャラの向きに ついていかない） |
| O2 | 向きの決め方は **案 A**: 出しはじめに 方向キー（W A S D・矢印）を 押していれば その方向、押していなければ 今の キャラの向き。**まるめない**（45° きざみに しない） |
| O3 | **向きの補助**: その向きから 左右 **30°** 以内・届く所に 妖怪が いたら、いちばん近い 妖怪の方へ 向きを合わせる。設定 `bladeFaceAssistDeg`（0 で 切れる） |
| O4 | **上下**: 突きは 水平（肩の高さ）。補助で 妖怪を えらんだ ときだけ、その妖怪の 高さへ 線を かたむける。けさぎり・切り上げは 今の 扇の柱（高さの範囲つき）のまま |
| O5 | 変える攻撃: 刀の わざ（ぼくとう・かたな・きらきらの かたな）と、すで・おの・なぎなた（今は パンチと同じ）。**弓は ＋マークのまま**（引いている間 キャラも ＋マークの方を向く。今のまま） |
| O6 | **ほる・たたくの 分け方**: 向いている方（補助の 30° 込み）の 届く所に 妖怪が いる → 攻撃。いない → 今のまま（＋マークの先が ブロック・作物なら ほる・しゅうかく、何もなければ 空ぶり／わざ） |
| O7 | 攻撃のときは キャラを ＋マークの方へ 回さない。ほる・おく・すてる ときは 今どおり ＋マークの方を向く |
| O8 | わざの向きは 出しはじめで 固定（CHAR-2 O8）。わざの間は 歩けない・ジャンプできない（CHAR-2 §9）。どちらも 今のまま |

- O2 をえらんだ理由（もと計画 `docs/archive/design/WEAPON-3-plan.md` §2 の 3 案くらべ。#312 で写した）: B「今の向きだけ」は、キャラが 1 秒に 720° で少しずつ回るので、キーを押してすぐ切ると回りきる前の中途半端な向きに出る（最大 0.25 秒おくれる）。C「8 方向にまるめる」は、絵の 8 方向が「カメラから見て」の 8 方向なので、世界の 45° にまるめても絵とそろわず、かえってずれる。A でまるめないときの絵とのずれは最大 22.5° で、けさぎり・切り上げの扇の広さの中におさまる。

## 1. ねらい（りっくんが どう楽しむか）

- 「＋」を 前に向けたまま、**よこや うしろの 妖怪も 切れる**。D を押しながら クリックすれば 右へ、S なら うしろへ ずばっ。キャラの体が 切った方を 向くので「自分が 切った」と 分かる。
- ぴったり ねらわなくても、だいたいの方（左右 30°）に 妖怪が いれば そっちへ 体が 向いて 当たる。8 つの キーの向きの どれかを 押せば、届く所の 妖怪には どこにいても 当たる（キーの向きと 妖怪の 向きの差は いちばん大きくて 22.5° で、30° より 小さい）。
- 弓だけは 今までどおり「＋」で 遠くを ねらう（ねらう練習の 道具）。
- 字が 読めなくても、**キャラの体の向き** と **黄色い ふちどり**（「この妖怪を たたくよ」）で、どこへ 攻撃が 出るか 分かる。

## 2. 遊び方（プレイヤーから見た動き）

### 2.1 刀（ぼくとう・かたな・きらきらの かたな）

1. 左クリック → わざが **キャラの 向き** に出る。
   - W A S D を 押しながらなら、その キーの方（カメラから見て 前・右・うしろ・左・ななめ）。
   - 何も 押していなければ、今 キャラが 向いている方（さいごに 歩いた方・さいごに 切った方）。
   - その向きから 左右 30° の中に 妖怪が いれば、その妖怪の方へ ぴたっと 向く。
2. わざを 始めた ステップに キャラは その向きへ すぐ向き（回らずに）、わざの 間 ずっと その向き（今の CHAR-2 と同じ。向きの 出どころだけ 変わる）。
3. おしつづけると わざを くりかえす（今のまま）。**次の わざの 向きは 次の わざを 始めた ステップに 決め直す**。だから わざの とちゅうに D を押しておけば、次の わざは 右へ出る（わざの間は 歩けない のは 今のまま）。
4. 突きは 肩の高さで まっすぐ。補助で えらんだ 妖怪が 高い所（うかんでいる ちょうちん）や 低い所に いれば、その妖怪へ 線が かたむく。
5. 向いている方に 妖怪が いなくて、「＋」の先が ブロック・作物なら ほる・しゅうかく（今のまま）。何もなければ 向いている方へ わざ（空ぶり）。

### 2.2 すで・おの・なぎなた ほか（刀と弓 いがいの 持ち物）

- **デザイナーが決めた**: 計画の「すで・おの・なぎなた」に、**刀と弓 いがいの 持ち物 ぜんぶ**（つるはし・くわ・ブロック・たべもの など、今 パンチに なる物）を 入れる。持ち物で 出る方が ちがうと 6 歳が まよう ため（計画 §3 の理由と 同じ）。
- 左クリックで パンチ（なぎなたは 今の なぎなたの ふり。白い弧の 形・長さ（9 ステップ）は 今のまま。**弧を 出す 向きだけ** パンチの 向き u に する。§7）が **向いている方** に出る。向きの決め方・補助・ほるとの 分け方は 刀と 同じ（§4.1〜§4.4）。
- 当たるまでの 時間（すで 30 ステップ・なぎなた 40 ステップ）、ダメージ、押す強さは 今のまま。
- パンチを 始めてから 当たるまで、キャラの向きは パンチの向きのまま（**デザイナーが決めた**。体が 横を向いたまま 前に パンチが 当たると おかしい ため）。歩くのは 今までどおり できる。

### 2.3 弓

- 今のまま（CHAR-1 §4.5 の 矢・ねらう行動）。矢は 体の点から「＋」の先へ 飛ぶ。引いている間 キャラは ＋マークの方を向く。向きの補助は 使わない。

### 2.4 キャラの向き（まとめ）

| とき | キャラの向き |
|---|---|
| 歩く | 歩く向き（今のまま） |
| ほる・しゅうかく・おく・すてる・右クリックの 行動・弓を引く | ＋マークの方（今の「ねらう行動」。はなして 30 ステップ 保つ も 今のまま） |
| 刀の わざ・パンチを 始めた | そのステップの おわりに 攻撃の向き u（回らずに）。わざ・パンチの 間は u のまま |
| 攻撃の あと | 「ねらう行動」には ならない（＋マークの方へ 回らない）。歩けば 歩く向き、止まれば u のまま |
| 空ぶり（すで・何もない所で 左クリック） | 「ねらう行動」には ならない（**デザイナーが決めた**。腕を ふる向きが 向いている方なので） |

## 4. ルール・数値

### 4.1 言葉と 点

- P = 足もとの 中央。B = **体の点**（**デザイナーが決めた**）= P の 真上で、高さは 肩の点 S と 同じ（CHAR-1 §4.1。ひらけた所で 足もと + 1.40、2 マスの トンネルで + 1.18）。**右へは ずらさない**（S は カメラの 右へ 0.70 ずれているので、うしろ・左へ 出すと ずれが 目立つ ため）。
- 向き（度）は yaw と 同じ 数え方（0 = 北 −Z、90 = 東 +X、上から見て 時計まわり。0 以上 360 未満）。向き a の 前 f(a) = (sin a, 0, −cos a)。
- 妖怪の 向きの角: P から 妖怪の 当たりの箱の **中心**（横の中心）への 水平の 向きと、今の 向きとの 差（0〜180°）。妖怪の 中心が P から 水平 0.01 より 近い（重なっている）ときは 0° とする。
- 「当たりの箱」の 大きさ・「必ず 当たる／必ず 当たらない」の 考え方は WEAPON-2 §4.1 のまま（テストは 0.3 の ゆとりを とる）。

### 4.2 向きの 決め方（方向キー優先。O2）

攻撃を **始める ステップ** に 決める（押した ステップ・先行入力が 出た ステップ・おしつづけの くりかえしが 始まる ステップ）。

1. **キーの向き k**: そのステップに 押されている 方向の Action（`moveForward`・`moveBack`・`moveRight`・`moveLeft`）から、歩くのと 同じ計算で 出す（カメラの yaw ＋ 前 0・右 90・うしろ 180・左 270、ななめは 2 つの まん中）。前と うしろ（左と 右）を 同時に 押して 打ち消しあう ときは「押していない」。
2. **もとの 向き a₀** = k（押していれば）、そうでなければ 今の キャラの向き facing。
3. **向きの補助**（§4.3）で 妖怪 T が えらばれたら、**u = P から T の 中心への 水平の 向き**。えらばれなければ u = a₀。
4. 刀の わざ・パンチは u に出す（`blade.state().move.dirDeg` = u）。わざの 間は 変えない（CHAR-2 O8）。

- キーは 歩いて いなくても（わざの 間で 歩けなくても）読む。
- まるめない（u は 小数の 角のまま）。

### 4.3 向きの 補助（O3）

**えらべる 妖怪**: 次を ぜんぶ 満たす 妖怪。

| | 条件 |
|---|---|
| ア 角 | 向きの角（§4.1。a₀ から）が `bladeFaceAssistDeg`（30°）以下 |
| イ 当たる | その攻撃（今の かまえの わざ／パンチ）を **その妖怪の 中心の 向きに 出したら 当たりの形に 入る**（§4.5 の 形。届く距離・高さの 範囲も ここで 見る） |
| ウ かべ | B から その妖怪の 箱の 中心への まっすぐな 線が 固い ブロックを 通らない（**デザイナーが決めた**: かべの むこうの 妖怪は えらばない。当たりの「かべごし」も B から 見る） |
| エ 状態 | 消えかけ・帰りかけ（`dying`・`leaving`）でない。攻撃できない 妖怪（いれば）でない |

**どれを えらぶか**（**デザイナーが決めた**）: P から 中心までの 水平の 距離が **いちばん 近い** 妖怪（計画どおり。いちばん 近い = いちばん さきに こちらへ 来る 妖怪）。距離の 差が 0.01 未満なら 向きの角が 小さい方、それも 同じなら id が 小さい方（いつも 同じに 決まる）。

- `bladeFaceAssistDeg` が 0 以下なら 補助を しない（u = a₀）。
- 補助は ブロックには しない（妖怪だけ）。
- 刀の 「届く」は かまえで ちがう（突き 4.5・大げさ斬り 3.2・切り上げ 3.0。WEAPON-2 §4.3 の 形の 大きさ）。今の かまえの わざで 見る。

### 4.4 左クリックの 使いみち（ほる・たたくの 分け方。O6）

刀・パンチの 持ち物で 左クリックを 押した（おしつづけの くりかえしを ふくむ）ステップに、上から 順に 見て 最初に あてはまる ものに する。

| 順 | 条件 | 使いみち | 攻撃の向き u |
|---|---|---|---|
| (1) | §4.3 で 妖怪 T が えらべた | **攻撃**（刀は わざ・ほかは パンチ） | T の 中心の 向き |
| (2) | **方向キーを 押していない**、そして ＋マークで 妖怪を ねらっている（CHAR-1 §4.5 の 線と 4° の ねらい補助。届く距離は 今のまま: 刀 4.5〈`bladeAimReach`〉、パンチは 今の 届く距離） | **攻撃** | その妖怪の 中心の 向き |
| (3) | ＋マークの先が 作物（しゅうかくできる）・ブロック（届く） | **しゅうかく・ほる**（今のまま。M7 §2.5・M2） | —（キャラは ＋マークの方を向く） |
| (4) | どれでもない | 刀: **わざ**（空ぶり）。ほか: 今の 空ぶり（腕を ふる） | a₀（補助なし） |

- **(2) は デザイナーが決めた**: 「＋」で 妖怪を ねらって クリックしたのに、キャラが 横を 向いていて 空ぶり、を なくす（今までの 遊び方も そのまま 通る）。キーを 押しているときは 押した方を 優先する（「押した方に 切れる」を こわさない）ので (2) は 使わない。
- (1) が (3) より 先: 「＋」が 地面・作物で、横に 妖怪 → ほらずに 攻撃（O6）。
- ほっている とちゅう（おしつづけ）に (1)・(2) に なったら、次の ステップから 攻撃（ほった 量は M2 の きまりで へっていく。WEAPON-2 §2.1-6 と 同じ）。わざ・パンチの とちゅうは ほらない。
- 弓は この表を 使わない（今のまま）。
- 黄色い ふちどり・ヒントは、刀・パンチの 持ち物の とき、毎ステップ この表の (1)・(2) で えらばれる 妖怪に 出す（押していなくても。§3）。

### 4.5 当たりの 形（WEAPON-2 §4.3 からの 変わり）

| 攻撃 | 形 | 今との ちがい |
|---|---|---|
| 突き | **B から 向き u の カプセル**。長さ 4.5・半径 0.2（今のまま）。1 体だけ（線で いちばん 手前） | 出どころ E（S）→ B。向き ＋マークの d → u。**上下**: T（(1)・(2) の 妖怪）が いれば B から T の 箱の 中心へ かたむける。ただし かたむきは 上下 `thrustTiltMaxDeg`（45°）まで（**デザイナーが決めた**: 真上・真下へ つくと 絵と 合わない ため）。T が いなければ 水平 |
| 大げさ斬り・切り上げ | 扇の柱（大きさ・高さは 今のまま）。中心は P | 前 f を カメラの yaw から → **u** から |
| パンチ（すで・なぎなた ほか） | **扇の柱**（**デザイナーが決めた**）: 中心 P、前 f(u)、左右 `punchShape.halfAngleDeg`（**45°**）、水平の 距離 = 妖怪の 広げた箱（半径 r + 0.3。＋マークの ねらいと 同じ 箱）の いちばん近い所まで **今の 届く距離 以下**（すで 3.5・なぎなた 5.0・ほか 今の表）、高さ P.y + `punchShape.yMin`（−0.5）〜 P.y + `punchShape.yMax`（+3.0）。**1 体だけ** | 今は ＋マークの 線 1 本 |

- **パンチの 当たる ステップ**（今の 30 ステップ目・なぎなた 40 ステップ目）に、その時の P から 上の 扇で 見る。当たる 妖怪: T が 扇の中に いれば T。いなければ 扇の中で P に いちばん 近い 1 体。だれも いなければ 空ぶり（`punchMiss`。今のまま）。向き u は パンチを 始めた ステップのまま（**デザイナーが決めた**: 動く 妖怪にも 45° の 広さで 当たりやすく、えらんだ 1 体を 先に たたく）。
- かべごし は 当たらない: B から 妖怪の 箱の 中心への 線が 固い ブロックに さえぎられたら 当たらない（WEAPON-2 §4.1 の E を B に）。
- ダメージ・押す 距離・押す向き（P から 妖怪へ）・たいきゅうの へり方・1 回の わざで 同じ 妖怪に 1 回は 今のまま。

**数の 確かめ（自分で 計算し直した）**

- 補助 30° の 横の はば: 届く距離 3.2（大げさ斬り）の 所で 3.2 × sin30° = **1.6**、4.5（突き）で 2.25。キーの 8 方向（45° きざみ）と 妖怪の向きの差は 最大 **22.5° < 30°** → どの方向の 妖怪も どれかの キーで えらべる。
- 突きの かたむき: うかぶ ちょうちん（箱の下 足もと + 2.0・高さ 1.7 → 中心 + 2.85）が 水平 3.0 先 → 上へ atan((2.85 − 1.40) ÷ 3.0) = **25.8°**（45° 以下）、中心まで √(3.0² + 1.45²) = **3.33**（4.5 以下で 届く）。
- 突きの かたむきの 上限 45° に かかる 例: 水平 1.0 先・中心 + 2.6 → atan(1.2 ÷ 1.0) = 50.2° → 45° に する（そのときは 当たるか どうかを 形で 見る。イの 条件で 当たらなければ えらばない）。
- パンチ（すで 3.5）と 今の m3 AC18 の 場面（からかさ。箱の 手前の 面まで 3.4 → 当たる、3.9 → 当たらない）: からかさ 半径 0.6 + 0.3 = 0.9。3.4 の場面は 中心まで 4.15 → 広げた箱まで 3.25 ≤ 3.5（当たる）。3.9 の場面は 4.65 → 3.75 > 3.5（当たらない）。**今の 結果と 同じ**。

### 4.6 キャラの向きと 「ねらう行動」（CHAR-1 §4.2 の 変わり）

- 左クリックが 「ねらう行動」に なるのは、そのステップの 使いみち（§4.4）が **(3) ほる・しゅうかく** の とき と、**弓を 引く** とき だけ。(1)(2) 攻撃・(4) 空ぶり は ならない（30 ステップ 保つ も しない）。右クリック・Q・シフト＋Q は 今のまま。
- 攻撃を 始めた ステップの おわりに facing = u（回らずに）。刀は わざの 間（今の CHAR-2 の `faceDeg`）、パンチは 当たる ステップまで facing = u。
- おしつづけて ほっていて (1) に 切りかわった ステップも、おわりに facing = u（その前の ＋マークの方から すぐ 変わる）。
