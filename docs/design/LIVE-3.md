## 1. ねらい（りっくん が どう 楽しむか・何 を 感じて ほしいか）

- **そだてた から いただける**: こたつ で かえして、とりごや で 大人 に した にわとり だけ が「おにく に する」に 出る。野原 で なかよく なった なかま は 出ない。「そだてる → いただく」の つながり が 分かる。
- **自分 で えらんで、たしかめて、手 を あわせる**: どの 子 に するか を 自分 で えらび、「ほんとう に いい？」で たしかめて から「いただきます」。うっかり では おきない。
- **しずか で やさしい ひととき**: にわとり が ねぐら に 入り、とびら が しまる。手 を あわせる 絵 と「いのち を いただきます」。紙ふぶき・ファンファーレ は 出さない（お祝い で は ない）。たたく・血・いたい 場面 は 1 つ も 無い。
- **やいて たべる（理科・料理）**: なま の もも にく は そのまま では たべられない。かまど で やくと こんがり。たべると ハート が たくさん もどる（ぼうけん の 力 に なる）。

## 2. 遊び方

### 2.1 えらべる 子（LIVE-2 §2.12 の まま）

- えらべる の は **`home` が ある かつ `stage` `'adult'` かつ `raised` true** の 子（今 の `meatEligible`）。ふつう も マッチョ も（§9 Q2）。
- さらに この 仕様 で 足す 条件: **だっこ 中 で ない**・**「いただきます」の 演出 中 で ない**。
- 野原 で なかま に した 大人 を 小屋 に 入れた 子（`raised` false）・ひよこ・外 に 出した 子（`home` null）は えらべない（LIVE-2 AC22 の まま）。

### 2.2 小屋 を 右クリック（LIVE-2 §2.11 の 1b を かえる）

- 小屋 の ブロック（さく・もん・ねぐら・すばこ。外 から でも）を ねらって 右クリック:
  - その 小屋 に **えらべる 子 が 0 わ** → **LIVE-2 の まま**（たまご が あれば あつめる／0 こ で 置ける 物 なら 置く／ほか は `coopNoEgg`）。そだてて いない 子 には メニュー の 手間 を ふやさない。
  - **えらべる 子 が 1 わ 以上** → **とりごや の メニュー** を ひらく（§2.3）。置ける 物 を 持って いても ひらく（すばこ 0 こ でも）。

### 2.3 とりごや の メニュー（3 つ の ページ）

- ひらき方 は たんす と 同じ あつかい（マウス が 出る・ゲーム の 時計 は 止めない）。とじる: `Esc`・`E`・右上 の ×・小屋 から とどく 距離（M2 の 5.0）より はなれた とき。とじた とき は どの ページ でも 何 も おきない。
- **ページ 1「とりごや」**: 大きな ボタン 2 つ。
  1. `たまご を あつめる`（たまご の 絵 ＋ すばこ の 数。0 こ なら うすく 押せない）→ LIVE-2 §2.6 の あつめる と 同じ（出来事 `coopCollect`・音 `collect`）。押した あと も メニュー は ひらいた まま（数 が 0 に なる）。
  2. `おにく に する`（もも にく の 絵）→ ページ 2。
- **ページ 2「どの こ に する？」**: その 小屋 の えらべる 子 を カード で ならべる（多くて 6 まい。3×2）。カード = その 子 の 絵（ふつう／マッチョ の 形 と リボン）だけ。カード に マウス を のせる か 押す と、**世界 の その 子 の 頭 の 上 に ▼**（小屋 が 見える ように パネル は 画面 の 下 がわ に 出す。§3.4）。`もどる` で ページ 1。
  - カード を 押す → ページ 3。
- **ページ 3「ほんとう に いい？」**: えらんだ 子 の 大きな 絵、文 `この こ の いのち を いただきます。いい？`、ボタン `やめる`（左）と `いただきます`（右。手 を あわせる 絵）。2 つ の ボタン の あいだ は ボタン 1 つ 分 以上 あける。`やめる` → ページ 2。
  - `いただきます` を 押した ステップ に メニュー を とじて 演出（§2.4）を はじめる。
  - その とき もう えらべない 子 に なって いた（だっこ された・大人 で なくなる こと は 無い が 念のため）→ 何 も せず ページ 2 に もどる（カード を 出し直す）。0 わ なら ページ 1。
- 同じ 小屋 で 演出 中 の とき は `おにく に する` を うすく して 押せない（1 つ の 小屋 で 同時 に 1 わ だけ）。べつ の 小屋 は できる。

## 5. 例外 の とき

- **持ち物 が いっぱい**: 入らない `momo_nama` は プレイヤー の 足もと に おとしもの（ふつう の おとしもの と 同じ）。
- **演出 中 に 小屋 を こわそう と した**: こわれない（子 と して 数える。LIVE-2 の こわせない しらせ）。200 ステップ 目 の あと は ほか の 子 しだい。
- **演出 中 に はなれた・読みこまない 所 に なった**: その場 で おわらせる（にく は 持ち物 へ。プレイヤー の いる 所 で 入る）。
- **演出 中 に 保存・とじる**: §4.4。
- **夜 に えらんだ**: その 子 は おきて 歩く。ほか の 子 は ねた まま。
- **メニュー を ひらいて いる あいだ に 子 が かわった**（だっこ は できない が、ひよこ が 大人 に なる など）: ページ 2 を 出す とき に 毎回 えらべる 子 を 出し直す。`いただきます` の とき に えらべなければ §2.3 の とおり 何 も しない。
- **その 小屋 の 最後 の 1 わ を いただいた**: ふつう に できる。小屋 は から（こわせる・また ひよこ を 入れられる）。
- **なま もも にく を こたつ に 入れよう と した**: `egg` で ない ので `kitNeedEgg`（LIVE-2 の まま）。
- **なま もも にく を にわとり に あげよう と した**: なでる（LIVE-1 の「むし 以外 は なでる」の まま）。
- **体力 まんたん で やいた にく**: たべない・合図 `full`（今 の まま）。
- **妖怪**: さわらない（どこ も かわらない）。

## 8. オーナー に 見せる 要点

1. こたつ → とりごや で **ひよこ から そだてた 大人** が いる とりごや を 右クリック → メニュー（`たまご を あつめる`／`おにく に する`）。そだてた 子 が いない 小屋 は 今 まで どおり すぐ たまご を あつめる。
2. `おにく に する` → **どの こ に する？**（カード。世界 の その 子 の 頭 に ▼）→ **ほんとう に いい？** → `いただきます`。
3. その 子 が ねぐら に 入り、**とびら が しまる**。手 を あわせる 絵 と `いのち を いただきます`、しずか な 音。約 3 秒 で とびら が ひらき、ねぐら は から。**なま もも にく 2 こ**。紙ふぶき・ファンファーレ・実績 は 出さない。血・たたく 場面 なし。
4. なま は たべられない（「かまど で やこう」）。**かまど で やく と やいた もも にく**、たべると **ハート 5 こ** もどる。はじめて たべた とき だけ 小さな 実績。
5. 野原 で なかま に した 子・ひよこ・外 に いる 子 は えらべない。
