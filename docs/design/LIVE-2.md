## 5. 例外 の とき

- **こたつ を 水 の 中・空中 に 置く**: ふつう の ブロック と 同じ。かえった ひよこ は パタパタ で おりる・水 なら うく。
- **かえる とき に まわり が ぜんぶ 固い**: こたつ の 上。上 も 固い → かえらず 待つ（60 ステップ ごと に さがし直す）。
- **こたつ を こわした**: たまご は もどる（あたため は 0）。金 の たまご も `kin_tamago` で もどる。
- **小屋 の 中 に ブロック を 置く・中 の 床 を ほる**: できる。子 が うまったら 中 の あいた 所 へ。中 に あいた 所 が ない → だっこ できる 位置（プレイヤー の そば）へ ワープ して なかま に もどる（8 わ を こえて も この とき だけ ゆるす）。
- **さく の 外 に ブロック を 置いて 足場 に して こえる**: できる（さく の 当たり は ジャンプ だけ を ふせぐ）。小屋 の 子 は 中 3×3 から 出ない ので にげない。
- **小屋 の さく を 1 つ だけ ほりたい**: できない（小屋 ぜんぶ が 1 つ。子 が いる と こわれない・しらせ）。
- **子 を だっこ した まま 小屋 を ほる**: こわれない（だっこ 中 の 子 も 数える。§2.3）。だっこ 中 は 左クリック が 何も しない（LIVE-1 §2.8）ので、しらせ も 出ない。
- **小屋 の 中 へ なかま を つれた まま 見に 入った**: 頭 の いえ の しるし が うまる 3 秒 の うち に 出れば なかま の まま。3 秒 いる と 小屋 の 子（案内画面 2 行目「なか で すこし まつ と」と いえ の しるし で 分かる）。小屋 の 子 に なって も だっこ で 出せば なかま に もどる。
- **小屋 に 入る とちゅう（いえ の しるし が うまる 前）の なかま しか いない 小屋 を こわす**: こわせる（まだ 小屋 の 子 で ない）。なかま は なかま の まま。
- **夜 に 小屋 の 外 の 大人**: 何も かわらない（ねる の は 小屋 の 子 だけ）。
- **すばこ いっぱい**: 中 の 足もと に おちる（10 分 で 消える）。
- **金 の たまご を すてた・おとした**: ふつう の おとしもの（RARITY-7 の `epic` の 光 の 柱 で 見つけやすい）。
- **読みこんで いない 所 の 小屋**: 子 は うごかない。そだつ 日 は あさ に 数える（小屋 の データ で）。大人 に なる の は 見に きた とき。

## 8. オーナー に 見せる 要点

1. たまご を **こたつ**（くさ・き・たいまつ で つくる）に 入れて **2 分**。すそ の たまご が ゆれて ひび → 見て いる 前 で ぽんっ と **ひよこ**、すぐ ついてくる。
2. **とりごや**（5×5 の さく の にわ、6 わ まで、3 つ まで）を ドン と 置く。ずれて いても 近く の たいら な 所 に 入る。さく は ひくく 見える が ジャンプ では こえられない（入口 は のれん の もん だけ）。
3. ひよこ を つれて 小屋 に 入り **3 秒 まつ**（頭 の いえ の しるし が うまる）か、だっこ で 中 に おろす と **小屋 の 子**。あさ を **2 回** むかえる と、見に きた とき ぴかっ と **大人**。
4. 小屋 の 大人 に むし → **すばこ に たまご**（4 回 に 1 回 くらい・8 回目 は かならず）。小屋 を 右クリック で ぜんぶ あつまる。夜 は 小屋 で すやすや。
5. **金 の たまご**: むし を いっぱい あげた 子・ひよこ から そだてた 子 ほど 出やすい（1〜8%、30 こ で かならず）。毎回 光 の 柱 と 紙ふぶき。
6. かえる とき **5% で マッチョ ひよこ**（20 回 で かならず）。**金 の たまご を こたつ に 入れる と かならず マッチョ ひよこ**（金 の たまご は そうび の 材料 に も 使える。どちら に 使う か は りっくん しだい）。小屋 で そだつ と **マッチョ にわとり**。
7. **中 に 子 が いる 小屋 は こわせない**。ほろう と すると「こ が いる から こわせない よ。だっこ で そと へ」の しらせ。
8. お肉（LIVE-3）と マッチョ の たたかい（#223）は まだ。お肉 に えらべる の は **ひよこ から 小屋 で そだった 大人 だけ**（野原 の なかま は 小屋 に 入れて も えらべない）の 印 を 用意 した。
