### 2.1 ぬくぬく かご（たまご を あたためる 道具）

### 2.3 とりごや

- **つくる**: `toriya` 1 = き（`log`）8・くさ（`grass`）4。つくる カード の いちばん うしろ（`nukunuku` の うしろ）。

### 2.8 金 の たまご（`kin_tamago`）

- **うむ 時**: 大人（小屋 の 子 でも 外 の なかま でも）が たまご を うむ たび に、その たまご が **金 か** を きめる。
- **金 に なる 確率**（その にわとり ごと）:

| もと | 値 |
|---|---|
| きほん | 野原 で なかま に した 子 **1%**、ひよこ から 小屋 で そだてた 子（`raised`）**4%**、金 の にわとり（§2.10）**10%** |
| なかよし | その 子 が これまで に たべた むし の 数 × **0.05%**（80 ぴき で ＋4% が 上限） |
| 上限 | **8%**（金 の にわとり は 14%） |
| かならず | その 子 が 金 で ない たまご を **30 こ** つづけて うんだら、次 は かならず 金 |

  - 計算 し直し: そだてた 子 に むし 80 ぴき → 4%＋4% ＝ 8%（上限）。野原 の 子 に 40 ぴき → 1%＋2% ＝ 3%。かならず まで は たまご 30 こ ＝ むし 約 45〜60 ぴき（たまご は むし 3 こ で かならず 1 こ、ふつう は 2 こ に 1 こ）。「がんばれば いつか 出る」。
- **金 の たまご**: アイテム `kin_tamago`（`きん の たまご`）。めずらしさ **`epic`（ほし 5・きん・ウルトラレア。RARITY-7）**。たべられない（たから もの）。ぬくぬく かご に 入れられる（§2.10）。ゴールド シリーズ の 材料（別 issue）。
- **出た とき（大きな お祝い。fun.md §2）**: うんだ 子 が 2 回 ジャンプ、たまご に きんいろ の 光 の 柱（RARITY-7 の `epic` の 光 の 柱）、紙ふぶき 60、ファンファーレ `goldenEgg`（BGM を 一時 もりあげて もどす）、実績 おめでとう画面（はじめて）。**毎回 大きく**（めったに 出ない 達成 なので）。小屋 なら すばこ が きんいろ に 光る（ひろう まで、ゆっくり。点滅 なし）。

## 5. 例外 の とき

- **かご を 水 の 中・空中 に 置く**: ふつう の ブロック と 同じ。かえった ひよこ は パタパタ で おりる・水 なら うく。
- **かえる とき に まわり が ぜんぶ 固い**: かご の 上。上 も 固い → かえらず 待つ（60 ステップ ごと に さがし直す）。
- **かご を こわした**: たまご は もどる（あたため は 0）。金 の たまご も もどる。
- **小屋 の 中 に ブロック を 置く・中 の 床 を ほる**: できる。子 が うまったら 中 の あいた 所 へ。中 に あいた 所 が ない → だっこ できる 位置（プレイヤー の そば）へ ワープ して なかま に もどる（8 わ を こえて も この とき だけ ゆるす）。
- **小屋 の かべ を 1 つ だけ ほりたい**: できない（小屋 ぜんぶ が 1 つ。子 が いる と こわれない）。
- **小屋 の 中 へ なかま を つれた まま 見に 入った**: 頭 の いえ の しるし が うまる 3 秒 の うち に 出れば なかま の まま。3 秒 いる と 小屋 の 子（案内画面 2 行目「なか で すこし まつ と」と いえ の しるし で 分かる）。小屋 の 子 に なって も だっこ で 出せば なかま に もどる。
- **夜 に 小屋 の 外 の 大人**: 何も かわらない（ねる の は 小屋 の 子 だけ）。
- **すばこ いっぱい**: 中 の 足もと に おちる（10 分 で 消える）。
- **金 の たまご を すてた・おとした**: ふつう の おとしもの（RARITY-7 の `epic` の 光 の 柱 で 見つけやすい）。
- **読みこんで いない 所 の 小屋**: 子 は うごかない。そだつ 日 は あさ に 数える（小屋 の データ で）。大人 に なる の は 見に きた とき。

## 8. オーナー に 見せる 要点

1. たまご を **ぬくぬく かご**（くさ・き・たいまつ で つくる）に 入れて **2 分**。ゆれて ひび → 見て いる 前 で ぽんっ と **ひよこ**、すぐ ついてくる。
2. **とりごや**（5×5 の 小屋、6 わ まで、3 つ まで）を ドン と 置く。ずれて いても 近く の たいら な 所 に 入る。
3. ひよこ を つれて 小屋 に 入り **3 秒 まつ**（頭 の いえ の しるし が うまる）か、だっこ で 中 に おろす と **小屋 の 子**。あさ を **2 回** むかえる と、見に きた とき ぴかっ と **大人**。
4. 小屋 の 大人 に むし → **すばこ に たまご**。小屋 を 右クリック で ぜんぶ あつまる。夜 は 小屋 で すやすや。
5. **金 の たまご**: むし を いっぱい あげた 子・ひよこ から そだてた 子 ほど 出やすい（1〜8%、30 こ で かならず）。毎回 光 の 柱 と 紙ふぶき。
6. かえる とき **5% で マッチョ ひよこ**（20 回 で かならず）→ 小屋 で **マッチョ にわとり**。金 の たまご から は **金 の ひよこ**（案）。
7. お肉（LIVE-3）と マッチョ の たたかい（#223）は まだ。お肉 に えらべる の は **ひよこ から 小屋 で そだった 大人 だけ**（野原 の なかま は 小屋 に 入れて も えらべない）の 印 を 用意 した。

## 9. オーナー に 聞く こと・PO が 決める こと

- オーナー: (a) 金 の たまご を かご に 入れる と **かならず 金 の ひよこ**（金 の たまご が 出やすい 子 に なる）で よいか。だいじ な 材料 を つかって しまう ので「入れられない」案 も ある。(b) 大人 まで **あさ 2 回**（25〜51 分）で よいか（1 回 なら 0〜25 分）。(c) 金 1〜8%・30 こ で かならず、マッチョ 5%・20 回 で かならず、の 出やすさ。(d) なか の 子 が いる 小屋 は こわせない、で よいか。
- PO: 小屋 を 一度 に 置く・こわす 口（`src/world/` の 担当）、`contracts.ts` の `AnimalInfo` に `stage`・`breed`・`home`・`raised`。
