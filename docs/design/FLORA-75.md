# FLORA-75: まわりの 自然の物（くさ・のばな）を 足す（仕様書・1 版）

- issue: #75（オーナー要望: 草・花など 景色を作る物を 世界に置く。9×9×9 化と合わせて 重さも見る）。
- 前の仕様: `docs/design/VOX-I.md`（§5 ブロック・§6 国の数・§3.9 重さ）、`docs/design/M7-farm.md`（たね・たがやす）。
- 絵・形・色・ゆれの細かいきまりは `docs/art/DESIGN.md`（6 章 ピンクなし・15 章 予算）に任せる。音は `docs/audio/SOUND.md`。この仕様は **役わり・置き方・数・重さ・テストで聞くこと** を書く。
- **重ねないもの**: #187 の 国だけの物（きのこ・ひまわり・かいがら・たけのこ など）、はなばたけ の はな 3 色、すすき、たけ。今の 地面の「草の芽」（小ブロック地形の tuft）は そのまま。

## 1. ねらい（りっくんがどう楽しむか）
- 今は はなばたけ・すすき・たけやぶ 以外の 国の くさ の上が **まっさら**。歩いても 地面が 平らな 緑の じゅうたん に見える。
- くさ と 小さな はな が ところどころ 生えて、**「そとを あるいている」感じ** が出る。国ごとに 多い・少ない が ちがうので、ぬま は くさぼうぼう、やま は まばら、と 景色の手ざわりが変わる。
- 見つけた はな を つんで、自分の 家や はたけ の まわりに 植えられる（つくり手の 楽しみ。rules A-0）。

## 2. 足す物（2 種類。ブロックは 2 こ ふえる）
地面の「草の芽」が もう ひくい草の役をしているので、**ひくい くさ は 足さない**（同じ物を 2 つ作らない）。

| 物（`id` 仮） | 名前（画面） | 形 | 通る | こわすと | 持てる・置ける | 光 |
|---|---|---|---|---|---|---|
| せの たかい くさ（`kusa`） | くさ | 十字の板（C 組）。高さ 小ブロック 3〜5（1 ブロックの 1/3〜5/9）。キャラの くつ・ひざ は かくれても 体は見える | 通りぬけ（あたり なし。自動ジャンプしない） | 1 回で 消える。**持ち物は 出ない**（すすき と同じ） | 持てない・置けない | 通す |
| のはらの ちいさな はな（`nobana`） | のばな | 十字の板（C 組）。高さ 小ブロック 2〜4。色は **あわい あお 1 色**（はなばたけ の き・だいだい・うす紫 と かぶらない。ピンク・白は 使わない） | 通りぬけ | 1 回で 消える。**のばな 1 こ** が 持ち物へ | 持てる。今の はな と同じ所（くさ・つち の上で 上が くうき）に 置ける | 通す |

- こわす はやさ: 今の はな と同じ（手で 0.05 秒ていど・道具 いらない）。
- 下の くさ ブロック を こわす・ほる と、上の くさ／のばな も いっしょに消える（のばな は 1 こ 持ち物へ。くさ は 何も出ない）。
- ブロックを くさ の マスに 置く と、くさ は 消えて そこに置ける（くさ は「じゃまをしない 物」。何も出ない）。のばな の マスには 置けない（はな と同じ）。
- **妖怪の出かた・光・あたり では、くさ・のばな の マスは くうき と同じ**（妖怪の数・夜の暗さは 今と かわらない。`isDarkForSpawn` は かえない）。

### 2.1 はたけ（M7）との関係
- **たがやす**: くわ（すで）で くさ・のばな を ねらっても、その下の くさ ブロック を ねらっても、**くさ・のばな を どけて 下を はたけ にする**（くわ なら 1 回。M7 の「上が くうき」は くさ・のばな を くうき と数える）。のばな は 1 こ 持ち物へ。
- **たね**: M7 の「くさ ブロック を こわすと 1/8 で たね」は **かえない**。くさ（板）からは たね を出さない（§8 でオーナーに確認）。理由: 板は 1 回で こわれ 数も多いので、たね が ありあまり「たね の ありか を さがす」ぼうけん（M7 §1）が 弱くなる。
- 生えるのは **世界を作るときだけ**。あとから 生えてこない（はたけ・道・家の まわりが 草で うまらない）。
- やせいの やさい・ふるい はたけ の あと（かかし の 8×8）・国だけの物 の 場所には 置かない（§3）。今の やせいの やさい の 数は かわらない。

## 3. 置き方（世界を作るとき。乱数は シード付き）
- 乱数は **(シード, x, z, 新しい 番号)** から作る（今の はな・すすき・たけ の 乱数と 別の 番号 → **くさ・のばな を 足しても はな・すすき・たけ・木 の場所は かわらない**。ただし §14 の 間隔のきまり で それらの場所は かわる）。作る順に 関係なく 同じ。
- 1 マスに 1 つだけ。その国の「くさ の こさ」「のばな の こさ」（§4）で 決める。くさ と のばな が 両方 当たったら のばな。
- 置ける所: いちばん上が **くさ** ブロック、上が くうき、陸（今の はな と同じ高さの きまり）、池・水 でない。
- 置かない所（**先に ある物が 勝つ**）:
  1. 木・たけ・はな・すすき・やせいの やさい・#187 の 国だけの物 の マス（と 国だけの物が「どける」はんい）。
  2. **スタートから チェビシェフ 8 以内**（17×17。スタートの たいまつ・足もと・4 方向の 道（今の 7 以内）を 見やすく）。
  3. たけやぶ の 道（`take.path`）の上（道が 道に見えるように）。
  4. 洞くつの口 から 2 以内（今の はな と同じ `nearMouth 2`）。
  5. ふるい はたけ の あと（かかし の 8×8 列）。
- 1 列（16×16）の上限まで来たら、乱数の 小さい順に 上限までだけ 置く（今の はな と同じ 切りすて）。

## 8. オーナーに 選んでほしいこと
1. 見た目: 案 A ／ B ／ C（ゲーム内試作の スクショで）。
2. くさ（板）を こわすと たね が出る（例: 1/16）にするか。ふつうは **出さない**（§2.1 の わけ）。
3. のばな の 色: あわい あお で よいか（ほかの 案: しろっぽい き は 白に近いので さける）。
4・5. 間の広さ（せまい／ふつう／ひろい）と 古いセーブの さかい → §14.6。

## 9. 例外のとき
- 持ち物が いっぱいで のばな を つめない: 今の はな と同じ（地面に のこる 動き は 今のまま）。
- 世界の はし・まだ 読んでいない列: 作る順に 関係なく 同じ場所に 生える（§3）。
- セーブ: 生えた くさ・のばな は 世界を作るときの物。こわした・つんだ 分だけ 今の きまりで のこる（かえない）。
- 案 C を えらんだら: §2 の ブロック は 作らない。AC は §10 の【C】の行に かえる。

## 12. 計算の たしかめ（designer が 計算し直した）
- 1 列 = 16 × 16 = 256 マス。くさ 0.08 × 256 = 20.48 ≤ 24、0.06 × 256 = 15.4、0.03 × 256 = 7.7。のばな 0.02 × 256 = 5.12 ≤ 8。
- 1 列の三角形: 案 A (24 + 8) × 8 = 256 ≤ 400。案 A で 1 本 16 に しても 32 × 16 = 512 > 400 → **案 A で 1 本 16 を 使うなら 上限を 本数 そのまま・三角形 400 で 切る**（AC9 は 三角形で見る）。案 B (12 + 4) × 24 = 384 ≤ 400。
- 1 コマ: 描く距離 88 ÷ 16 = 5.5 → 11 × 11 = 121 列（まるく 読むなら π × 88² ÷ 256 ≈ 95 列）。多い方 121 × 400 = 48,400。602,024 に 対して 8.0%。もり 754,138 + 48,400 = 802,538 ≤ 903,036。
- スタート: チェビシェフ 8 → 17 × 17 = 289 マス。今の 木の 道（7 以内）を ふくむ。
- たね: 1/8 = 0.125。1 万回 の ゆれ（標準偏差 √(10000 × 0.125 × 0.875) ≈ 33 → 0.0033）→ 0.11〜0.14 は 約 ±4.5 σ。

## 14. 間隔のきまり（オーナー追加の要望 2026-10-18）
オーナー: 「草とか木とか、密集して生えすぎているので、もう少し間隔を開けて生えるような仕様を考えて欲しい」。
対象: 今ある **木（ふつう・大木・まつ・もみじ）・はな・すすき・たけ** と、新しい **くさ・のばな**。国だけの物（#187）・やせいの やさい・はたけあと は 対象外（数が少なく、置き方が 別に決まっている）。

### 14.1 3 つの きまり
1. **物ごとの 最小の間**（近すぎる 2 つを つくらない）。
2. **あき地**（何もない 広場が ところどころ ある）。
3. **むら**（草花は「こい所」と「うすい所」に分かれる ＝ まとまりと すき間）。

**決め方は 位置だけ**（シード・x・z）: 
- 近すぎる 2 つは、位置から決まる シード付きの順番の **早い方を のこす**。遅い方は、早い方が ほかの物に まけて 消えていても やめる（となりの列を 読む順に 関係なく 同じ答えになる）。
- あき地・むら も シードと 位置だけで決まる。どの列から 作っても 同じ。
- **スタートの木 3 本は いちばん早い**（ほかの木が 近ければ ほかの木を やめる。あき地でも けさない）。3 本どうしも 最小の間を守る（守れない こうほ は とばして 次の こうほ。北に 1 本 見える きまりは そのまま）。

### 14.2 最小の間（せまい／ふつう／ひろい。**おすすめ: ふつう**）
**木**: ちがう木の はっぱ（上から見た いちばん外の 四角）の間に **あき列 g 列以上**。木の はっぱ の 広がりは 今の形（ふつうの木・もみじ 半径 2、まつ 半径 3、大木 みき 2×2 の まわり 3）。

| g（もり・おおきな きの もり・もみじやま） | −1（1 列 かさなってよい） | 0（くっつくが かさならない） | 1 |

| みきの間（ふつうの木どうし。チェビシェフ）もりの国 ／ ほか | 4 ／ 5 | 5 ／ 6 | 6 ／ 7 |

### 14.3 あき地と むら
- **あき地**: 世界を 32×32（4 列ぶん）の 区に分け、**区ごとに 1 こ**。まん中は 区の中で シード付き（区の ふちから r 以上 内がわ → となりの区の あき地と かさならない）。まるい 半径 r。
  - あき地の中（まん中から r 以内）には 木の みき・はっぱ・たけ・はな・すすき・くさ・のばな を 置かない（木は はっぱが かからないよう、みき を r ＋ はっぱの半径 より外に）。地面・池・道・国だけの物・やせいの やさい は そのまま。
  - 歩いて 32 ブロック（約 8 秒）に 1 回 ぐらい 広場に出る。もり・たけやぶ でも「ひと休みの 場所」ができる。
- **むら**（はな・すすき・くさ・のばな。ひろい では たけ も）: なめらかな ノイズ（大きさ 12 ブロック）で 場所を「こい所」「うすい所」に分け、うすい所では こさ（§4・VOX-I §6）に かける数を へらす。木には かけない（あき地と 最小の間で すき間ができる）。

### 14.5 木の位置が かわる 影響
- **スタートの木 3 本**: スタートから チェビシェフ 5〜12・北に 1 本 見える は かわらない。でも 3 本の間を 守るので、えらばれる 木が かわることがある（同じシードでも 前と ちがう 3 本）。
- **今の テスト**: 木・はな・すすき・たけ の **場所や 数を 決め打ちで 見ている テストは 直す**（例: `src/world/gen/generateChunk.test.ts` の もりの木 平均、`biome.test.ts` の 1 列の数、`startArea.test.ts`・`surface.test.ts`、E2E の `voxB-terrain`・`voxI1-biome`・`voxF-save`・`m2`（木を こわす 所）、UI 検査の 見本の スクショ）。どれを直すかは tester が テストの準備で 調べる。期待は「ゲームに 聞く」形（`startTrees`・`biome.flora` など）に かえる。
- **保存した世界**: セーブは さわった 列だけ。**さわった列は そのまま、まだ さわっていない列だけ 新しい置き方** になる。そのため 保存した列と 新しい列の さかいで、前の木の はっぱ が 少し 切れて のこる・新しい木の はっぱ が 保存した列に 入らない（はっぱ が 半分の 木）ことが ある。数は さかいの 木 だけで、1 回 さわれば なおせる。→ 古いセーブを 前の置き方のまま にするかは §8 の 4 でオーナーに聞く（ふつうは このまま。りっくんの 世界は まだ 小さい）。
- 国だけの物（#187）が「どける」はんい の きまりは かわらない（先に 国だけの物 → あとで 間隔の きまり）。

### 14.8 計算の たしかめ
- みきの間: ふつうの木 5 + g → g = −1/0/1/2 で 4/5/6/7。まつ 3 + 3 + 1 + g → g = 0/1/2 で 7/8/9。大木 3 + 3 + 2 + g → g = −1/0/1 で 7/8/9（もりの国の g）。
- あき地: π × 4² = 50.3、5² = 78.5、6² = 113.1 → ÷ 1024 = 4.9%・7.7%・11.0%。木（r + 2）: π × 36 = 113、49 = 154、64 = 201 → 11.0%・15.0%・19.6%。32 ブロック ÷ 歩き 4.0 = 8 秒。
- もり（ふつう）: こうほ 7.7 ÷ 256 = 0.030、間 5 の 面積 9 × 9 − 5 × 5 = 56 → x = 1.68、(1 − e^−1.68) ÷ 1.68 = 0.485 → 7.7 × 0.485 = 3.7 → あき地 × 0.85 = **3.1**。
- はな（ふつう）: こい所 0.15 × (1 − e^−1.2) ÷ 1.2 = 0.087、うすい所 0.045 × 0.84 = 0.038 → 0.6 × 0.087 + 0.4 × 0.038 = 0.067 → × 256 = 17.2 → × 0.923 = **16**。
- たけ（ふつう）: 0.23 × (1 − e^−1.84) ÷ 1.84 = 0.105 → 26.9 → × 0.923 = **25**。ひろい は むら 5 割 → 13.4 × 0.89 = **12**。
