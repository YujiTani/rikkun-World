## 1. ねらい（りっくんがどう楽しむか）
- 今は はなばたけ・すすき・たけやぶ 以外の 国の くさ の上が **まっさら**。くさ と 小さな はな が ところどころ 生えて、**「そとを あるいている」感じ** が出る。ぬま は くさが多め、やま は まばら、と 国ごとに 手ざわりが変わる。
- 木・草花は **間を あけて** 生え、ところどころ **あき地（広場）** がある。すき間から 地面と 空が見え、歩きやすく、目が休まる（CRITERIA #4）。
- 見つけた のばな を つんで、自分の 家や はたけ の まわりに 植えられる（つくり手の 楽しみ。rules A-0）。

## 2. 足す物（2 種類。ブロックは 2 こ ふえる）
地面の「草の芽」が もう ひくい草の役をしているので、**ひくい くさ は 足さない**。

- **ねらい**: くさ・のばな の 板にも ねらいの わく が出る（今の はな と同じ）。

- **妖怪の出かた・光・あたり では、くさ・のばな の マスは くうき と同じ**（妖怪の数・夜の暗さは 今と かわらない。`isDarkForSpawn` は かえない）。

### 2.1 はたけ（M7）との関係
- **たがやす**: くわ（すで）で くさ・のばな を ねらっても、その下の くさ ブロック を ねらっても、**くさ・のばな を どけて 下を はたけ にする**（くわ なら 1 回。M7 の「上が くうき」は くさ・のばな を くうき と数える）。のばな は 1 こ 持ち物へ。
- **たね**: M7 の「くさ ブロック を こわすと 1/8 で たね」は **かえない**。くさ（板）からは たね を出さない（オーナー既定）。理由: 板は 1 回で こわれるので、たね が ありあまり「たね の ありか を さがす」ぼうけん（M7 §1）が 弱くなる。
- 生えるのは **世界を作るときだけ**。あとから 生えてこない（はたけ・道・家の まわりが 草で うまらない）。

## 3. くさ・のばな の 置き方（世界を作るとき。乱数は シード付き）
- 乱数は **(シード, x, z, 新しい 番号)** から作る（今の 木・はな・すすき・たけ と 別の番号 → くさ・のばな を 足しても それらの場所は かわらない）。作る順に 関係なく 同じ。
- 1 マスに 1 つだけ。§4.1 の こさ で 決める。くさ と のばな が 両方 当たったら のばな。
- 置ける所: いちばん上が **くさ** ブロック、上が くうき、陸（今の はな と同じ高さの きまり）、池・水 でない。
- 置かない所（**先に ある物が 勝つ**）:
  1. 木（みき・はっぱ）・たけ・はな・すすき・やせいの やさい・国だけの物 の マス。
  2. スタートから チェビシェフ 8 以内（17×17。スタートの たいまつ・4 方向の 道を 見やすく）。
  3. たけやぶ の 道（`take.path`）の上。
  4. 洞くつの口 から 2 以内（今の はな と同じ）。
  5. ふるい はたけ の あと（かかし の 8×8 列）。
  6. あき地の中（§5.3）。
- **作る順番**: ① 地形・木・たけ・はな・すすき（今のまま）→ ② 国だけの物（#187）→ ③ 間隔のきまり（§5）→ ④ くさ・のばな。

## 5. 間隔のきまり（12 の国 すべて。はなばたけ・すすき・たけやぶ も 同じ）
対象: 今ある **木（ふつう・大木・まつ・もみじ）・はな・すすき・たけ** と、**くさ・のばな**。国だけの物（#187）・やせいの やさい・はたけあと は 対象外。

### 5.0 間の広さ（段）は 場所ごとに まざる
- 場所ごとに **段**（ひろい／ふつう／せまい）が ある。段は シード付きの **ゆっくり変わる ノイズ**（大きさ **96 ブロック**。だいたい 64〜128 の まとまり）の 値 v で決める。位置と シードだけで 決まる（作る順に 関係ない）。
- v は 国と 同じく **順位**（0〜1）にして しきい で 分ける（VOX-I §3.1 と 同じ 作り方の 表。シードで 変えない）: **v < 0.70 → ひろい、0.70〜0.95 → ふつう、0.95 以上 → せまい**。
  - ノイズは なめらかなので、せまい（いちばん上の 5%）は いつも ふつう に かこまれる → **ひろい → ふつう → せまい と だんだん 変わり、ひろい と せまい が いきなり となりあわない**（さかいが なめらか）。
  - まとまりの 大きさは 歩いて 15〜30 秒。せまい（密集）の 場所は めったに ない「こい やぶ・こい 花畑」に なる。
- **割合と 大きさは config の 1 か所** で かえられる（例: `spacing: { share: { wide: 0.70, normal: 0.25, narrow: 0.05 }, noiseScale: 96 }`）。テストでは 生成の config に「全部 ひろい」などを わたせる。
- **スタートの まわりは ひろい に 寄せる**（はじめの 見やすさ。スタートの木の テストが 段で ゆれない）: スタートから の チェビシェフ きょり d で、順位を v' = v × t にする。t = 0（d ≤ 64）、t = (d − 64) ÷ 32（64〜96）、t = 1（d ≥ 96）。
  - 64 以内は v' = 0 → いつも ひろい。64〜96 は v' が なめらかに もとの v に もどるので、ふちでも ひろい → ふつう → せまい の 順は くずれない（1 ブロックで v' が かわるのは ノイズの分 ＋ 1/32 以下。ふつう の はば 0.25 を 1 ブロックで とびこえない）。
- 1 つ 1 つの 物は **自分の 位置の 段** を使う（間 g・a、むら）。2 つの 間を 見るときは、**遅い方（まけるかを 見られる方）の 位置の 段と 国**。
- あき地: **半径を 決める 段** は 区の 中心の マス（区の 角 ＋ 16, 16）の 段。**あき地の まん中の 場所** は それとは 別に シード付きで ランダム（§5.3）。

### 5.1 決め方（位置と シードだけ）
- 木などの **こうほ** は 今の置き方（坂・水・1 列の上限 まで 見た あと）の 物。こうほ は その列の シードと 位置だけで 決まる。
- 近すぎる 2 つは、位置から決まる シード付きの **順番の 早い方を のこす**。遅い方は、早い方が ほかの物に まけて 消えていても やめる（→ となりの列を 読む順に 関係なく 同じ答え）。順番が 同じ数なら x が 小さい方、それも 同じなら z が 小さい方が 早い。
- 自分の列と **まわり 8 列**（3×3 列）の こうほ を 見る（いちばん長い 間 ＝ ひろい の 大木どうし・まつ どうし 9 ＜ 16 なので たりる）。
- **国・段の さかい**: 間 g・a は **遅い方（まけるかを 見られる方）の 位置の 国と 段** で決める（§5.0）。
- **スタートの木 3 本は いちばん早い**（ほかの木が 近ければ ほかの木を やめる。あき地でも けさない）。3 本の えらび方（スタートから チェビシェフ 5〜12・北に 1 本 見える）は 今のまま。

### 5.3 あき地と むら
- **あき地**: 世界を 32×32（4 列ぶん）の 区に分け、**区ごとに 1 こ**。まん中は 区の ふちから 6 以上 内がわ（シード付き。段に 関係なく 同じ場所）→ となりの区の あき地と かさならない。**まるい 半径 r**（区の 中心の マス（角 ＋ 16, 16）の 段で: ひろい 6・ふつう 5・せまい 4。まん中の 場所は ランダムの まま）。

### 5.4 木の位置が かわる 影響
- **スタートの木 3 本**: きまりは 同じでも、3 本の間を 守るので 前と ちがう 3 本に なることがある。
- **今の テスト**: 木・はな・すすき・たけ の 場所や 数を 決め打ちで 見ている テストは 直す（例: `generateChunk.test.ts` の もりの木 平均、`biome.test.ts` の 1 列の数、`startArea.test.ts`・`surface.test.ts`、E2E の `voxB-terrain`・`voxI1-biome`・`voxF-save`・`m2`（木を こわす所）、UI 検査の 見本の スクショ）。どれを直すかは tester が テストの準備で 調べ、期待は「ゲームに 聞く」形（`startTrees`・`biome.plants`）に かえる。
- **保存した世界**: セーブは さわった 列だけ。さわった列は そのまま、まだ さわっていない列だけ 新しい置き方（オーナー既定）。さかいで 前の木の はっぱ が 少し 切れて のこる・新しい木の はっぱ が 保存した列に 入らない ことが ある。
  - 保存した列の となりの 新しい列は、保存した列の「前の木」ではなく 新しい置き方の こうほ を 見て 間を 決める → **さかいの 木は 間の きまり（AC14）の 対象外**。
- 重さ: 木・たけ・はな・すすき が へるので どの国も 三角形が へる。

## 8. 例外のとき
- 持ち物が いっぱいで のばな を つめない: 今の はな と同じ（地面に のこる 動き は 今のまま）。
- 世界の はし・まだ 読んでいない列: 作る順に 関係なく 同じ場所に 生える（§3・§5.1）。
- セーブ: 生えた くさ・のばな は 世界を作るときの物。こわした・つんだ 分だけ 今の きまりで のこる。

## 9. テストで聞くこと（`window.__rikkun`。名前と 返す値の形だけ 約束）
- `biome.plants(x0, z0, x1, z1)` → `{ type, x, y, z }[]`。`type` は `tree`・`bigTree`・`matsu`・`momiji`・`flower`・`susuki`・`take`・`kusa`・`nobana`（木は みきの 根もと、大木は 北西の みき）。間隔のきまり の あとの 生成と 同じ 置き場所を返す（読んでいない所でも よい）。
- `biome.flora(cx, cz)` → `{ kusa, nobana, tris }`（その列の 本数・くさ＋のばな の三角形）。
- `biome.clearings(x0, z0, x1, z1)` → `{ x, z, r }[]`（あき地の まん中と 半径）。
- `biome.spacing(x, z)` → `{ level: 'wide' | 'normal' | 'narrow', v }`（その場所の 段と 順位 v）。
- `biome.findSpacing(level, { from?, kind? })` → `{ x, z } | null`（`from`（ふだんは スタート）から いちばん近い、**まわり 3×3 列（48×48）が ぜんぶ その段**で、`kind` を わたしたら 3×3 列が ぜんぶ その国（`e ≥ blend`）の 場所の まん中。4096 以内に なければ `null`）。E2E は これで「せまい の 場所」へ 行く（シードを 決め打ちしない。`null` なら 次の シード）。
- ユニットテストは 生成に config の 割合を わたして、世界 ぜんぶを 1 つの段に できる（例: `{ wide: 0, normal: 0, narrow: 1 }`。§4.3 の 段ごとの 数は この形で 数えた）。
- ブロックの 読み書き・こわす・置く・たがやす は 今の `world`・`dig`・`farm` の hook を使う。
- **ゴールデン**: tester は テストの準備（実装の前）に、スタートでの `renderStats()` の 描画回数・三角形を 記録しておく（AC11 で 比べる 「前」）。

## 11. 計算の たしかめ（designer が 計算し直した）
- 1 列 = 256 マス。くさ 0.08 × 256 = 20.48 ≤ 24、のばな 0.02 × 256 = 5.12 ≤ 8。1 列の三角形 (24 + 8) × 8 = 256。
- 1 コマ: 88 × 2 ÷ 16 = 11 列 → さかいで 12 × 12 = 144 列 × 256 = 36,864。602,024 の 6.1%。おおきな 約 830,000 + 36,864 = 866,864 ≤ 903,036。
- みきの間: ふつう 2 + 2 + 1 + g → もりの国 6・ほか 7。まつ 3 + 3 + 1 + 2 = 9。大木 3 + 3 + 2 + 1 = 9。大木と ふつう 3 + 2 + 2 + 1 = 8。まつ と ふつう 3 + 2 + 1 + 2 = 8。見る はば 9 ≤ 16（1 列）。
- あき地: 区 32、ふちから 6 → まん中は 6〜26。となりの区の まん中とは 12 以上 → 半径 6 どうしは かさならない。面積 113.1 ÷ 1024 = 11.0%、201.1 ÷ 1024 = 19.6%、254.5 ÷ 1024 = 24.9%。32 ÷ 4.0 = 8 秒。
- スタート: チェビシェフ 8 → 17 × 17 = 289 マス。
- たね: 1/8 = 0.125。1 万回 の 標準偏差 √(10000 × 0.125 × 0.875) ÷ 10000 ≈ 0.0033 → 0.11〜0.14 は 約 ±4.5 σ。
- みきの間（段ごと）: ふつうの木 5 + g → もりの国 g 1/0/−1 で 6/5/4、ほか g 2/1/0 で 7/6/5。まつ 7 + g → 9/8/7。大木 8 + g（もりの国）→ 9/8/7。
- 段の 割合: 0.70 + 0.25 + 0.05 = 1.00。まぜた平均（§4.3）: もりの木 0.7 × 0.3 + 0.25 × 0.5 + 0.05 × 0.9 = 0.21 + 0.125 + 0.045 = 0.38、たけ 0.7 × 8.5 + 0.25 × 18.5 + 0.05 × 38.7 = 5.95 + 4.625 + 1.935 = 12.51、すすき 2.73 + 3.225 + 1.495 = 7.45、ぬまの くさ 2.38 + 2.05 + 0.715 = 5.15。
- 実測の へり方（まぜた平均 ÷ 今）: もりの木 0.4 ÷ 1.5 = 27%、はな 4.3 ÷ 19.3 = 22%、すすき 7.5 ÷ 31.4 = 24%、たけ 12.5 ÷ 40.6 = 31%、はらっぱの木 0.6 ÷ 1.0 = 60%。
- スタートの 寄せ: t は 64〜96 の 32 ブロックで 0 → 1、1 ブロックで 1/32 = 0.031。v' = v × t の 1 ブロックの かわり ≤ 0.031 ＋ ノイズの分（96 の なめらかな ノイズで 0.03 ていど）＝ 約 0.06 ＜ ふつう の はば 0.25 → ひろい（< 0.70）から せまい（≥ 0.95）へ 1 ブロックで とばない。
- AC17 の 取り方: 8192 ÷ 128 = 64 → 64 × 64 = 4,096 列 / シード。国の わりあい 4〜10% → 160〜400 列 / シード → 3 シードで 300 以上（足りなければ 16384 四方）。
- 段の まとまり: ノイズ 96 → まとまり 約 64〜128 ブロック ÷ 歩き 4.0 = 16〜32 秒。スタートの 64 以内（129 × 129）を ひろい に しても 8192 四方の 0.03% で 割合は かわらない。
- 重さ（§6）は いちばん 多い せまい でも くさ＋のばな 1 列 18 本（ぬま 14.3 ＋ 3.7）× 8 = 144 ≤ 256。
