- タスク票: `docs/tickets/CRAFT-2.md`
- 前の仕様: M4（`docs/design/M4-craft.md` §2.2・§2.3・§2.12）、M6（`docs/design/M6-ui-achievements.md` §2.1・§2.9・§3.5・§3.6）、WEAPON-2（こわれた ログ）、M7・M7-2（農業の合図）

## 1. ねらい（りっくんがどう楽しむか）

- たんす に しまった き や てつ を、いちいち 取りに行かなくても **そのまま つくる・やく に使える**。「しまっても こまらない」ので、たんす に どんどん 片づけたくなる。
- たんす から 使ったときは、左の ログに **たんす の絵と「たんす から き ×3」** が出る。「あ、たんす の を つかったんだ」と分かる。
- **できごと**（ログの履歴）の ページで、さっき 何を拾った・何を つくった・何が おきた を、色と形の 印で ふりかえれる。
- 画面の パネルや HUD が **うっすら すける**。もちもの画面を開いても 世界が見えていて、とじこめられた感じがしない。でも 白い字は どんなに明るい所でも 読める。

## 2. 遊び方（プレイヤーから見た動き）

### 2.1 どの アクションで たんす の素材を使うか（対象）

素材を へらす所を ぜんぶ 洗い出して、**「つくる」ための 2 つだけ** を対象にする（オーナーの言葉「すべての『つくる』アクション」）。

| 素材を へらす所 | 対象？ | 理由 |
|---|---|---|
| **つくる**（もちもの画面の つくる。M4 §4.1・M6・M7・M7-2 の 25 こ） | **する** | 「つくる」そのもの |
| **やく**（かまど の 材料 と ねんりょう。M4 §4.2 の 4 こ） | **する**（材料も ねんりょう も） | かまど で「つくる」 |
| ブロック・たね を おく（手に持った 1 こ） | しない | 手に持ったものを置く動き。手に無いものは置けない（M2・M7） |
| ゆみ で や を うつ | しない | せなかの や をうつ動き。遠くの たんす の や が 飛ぶのは へん |
| 防具を着る・すてる（Q）・たべる・じょうろ の水 | しない | 「つくる」ではない。手や マスのものを使う |

- これから「つくる」のレシピが増えたとき（別の作業台など）も、**つくる・やく と同じきまり** を使う（決まり）。

### 2.2 素材の数え方（足りるかどうか）

- 数える所は 3 つ: **ホットバー（マス 0〜8）＋ ふくろ（マス 9〜35）＋ たんす**（§2.4 の「使える たんす」すべての 54 マス）。
- 数えないもの（M4 のまま）: **カーソルに持っているもの**（たんす から持ち上げたものも）、**着ている防具**。
- 足りる = 3 つの合計 ≧ 要る数。足りれば カードが光る・せつめい パネルの つくる ボタンが押せる・ホットバーの横の かなづち の印（M4 §2.10）も出る。ねんりょう も同じ（3 つの合計で「ある」か決める）。
- 画面の数（`2 / 3` の 2、ねんりょう の チップの数、`できる かず ×4`）も **3 つの合計**。

### 2.3 素材の へらし方（使う順）

1. **もちもの**（36 マス）から。順番は **M4 §2.2 のまま**（ふくろ のマス 35 → 9 → ホットバー 8 → 0。うしろのマスから）。M4 AC3（ふくろ から先）を こわさないため、ホットバー（手もと）は なるべく のこす。
2. もちもの で 足りない分だけ **たんす** から。たんす の順は §2.4。1 つの たんす の中は **うしろのマス（53 → 0）から**（もちもの と同じ向き）。
3. ねんりょう も同じ順（もちもの → たんす）。どの ねんりょう を使うかは M4 のまま（えらんだ ねんりょう か、せきたん → あぶら → き の順の先頭）。その種類が もちもの と たんす の合計で 1 こ以上あれば使える。

- タスク票の「ホットバー → カバン → タンス」の案は、M4 の「ふくろ から先」と ぶつかるので **もちもの の中は 今のまま** にした（オーナーに聞くこと 1）。
- **いっぱいのとき**（M4 §2.2）: もちもの から取る分を取ったあとの 持ち物に、できたものが 全部 入るかで決める（たんす から取る分は 持ち物の空きを ふやさない）。入らなければ **何も変えない**（たんす も そのまま）で `もちもの が いっぱい！`。できたものは いつも 持ち物に入る（たんす には入れない）。
- かまど を こわしたとき の返し方（M4 §2.3）は 今のまま **持ち物へ**（たんす から来た分も 持ち物へ。たんす へは もどさない）。
- たんす から取っても `store` の出来事・実績は ふえない（しまったのではない）。たんす の「いっぱい」の印（`storeFull`）は 今のきまりで 空きができたら はずれる。保存をたのむ（自動セーブに入る）。

### 2.4 どの たんす を使うか

- **はじめの値: 世界の すべての たんす**（設定 `craftTansuRange` = 0 は「きょり の 制限なし」）。オーナーの言葉「等しく 素材として使える」に いちばん近く、6 歳には「たんす に しまえば いつでも つかえる」の 1 つの きまりだけで分かる。「ときどき 使えない」が無いので まよわない。
- 設定で 半径を決められる: `craftTansuRange` = N（N > 0）なら、プレイヤーから **N ブロック以内** の たんす だけ。きょりは たんす を 閉じる きょり（M6 §2.9 (2)）と同じ はかり方（足もと と、たんす の 下の面の まん中 との 3D の まっすぐな きょり）。どちらにするかは オーナーに聞く（聞くこと 2）。
- **取る順**: プレイヤーに **近い たんす から**。同じ きょり なら x が小さい → z が小さい → y が小さい 順（テストで決まるように）。
- 開いている たんす も ふつうの たんす と同じに数える。
- ワールドは 128×128 で、ブロックの 読みこみを 消さない（M5）ので、遠い たんす も 数えられる。
- 遠い たんす のときの 考え方: 遠くても 使える。かわりに ログに `たんす から` と出し、**どこから来たか** は「たんす の絵」で分かる。6 歳に 座標（x,y,z）は 出さない（読めないので）。テストの窓口では 位置を返す（§6.1）。

### 2.5 ログ（画面の 左の ログ）— 拾ったログ と ひとつにまとめる

- 画面の左（M6 §3.6 (1) の かたまり D。今の「拾ったログ」の場所）を **ログ** と呼び、ここに **2 種類の行** を流す:
  1. **ひろった**（M4 §2.12 のまま。ほった・拾った・焼けて入った）: `{名前} ×{数}`
  2. **たんす から つかった**（新しい）: `たんす から {名前} ×{数}`。たんす から 1 こ以上 使ったときだけ。もちもの から使った分は 出さない（いつものこと なので）。
- 1 回の つくる・やく で、たんす から使った **アイテムごとに 1 行**（いくつの たんす から取っても 合計 1 行）。ねんりょう を たんす から使ったら、それも 1 行。
- 行の決まりは M4 §2.12 のまま、ただし **同じ行** = 「種類（ひろった／たんす から）と アイテム が同じ」。のこり時間 180 ステップ・最後の 30 ステップで うすく・**合わせて 5 行まで**（2 種類 で 5 行を分け合う。6 行目で いちばん古いのが消える）。
- 合図（照準の下の チップ: `もちもの が いっぱい！`・つるはし・や の絵 など）、`〇〇 が もうすぐ こわれるよ`、`〇〇 が こわれた`（WEAPON-2）、`スタートに もどったよ`、農業の合図（M7）、横断幕・おめでとう画面 は **今の場所のまま**（照準の近くに出す合図は、見てほしい所に出すため。動かさない）。ただし どれも §2.6 の **できごと（履歴）** には入る。
- 拾ったログの 行の 見た目を 少し変える（§3.2）: 左に **カテゴリーの印**、字は **白**（前は めずらしさの色。オーナーの言葉「白テキスト」）。めずらしさ は アイテムの絵で分かる。`こわれた` ログ（`#wear-log`）の 行にも 同じく カテゴリーの印を付ける。

### 2.6 できごと（ログの履歴）の ページ

**(1) 何が入るか**（カテゴリーは §2.7）

| できごと | カテゴリー | 文（画面は ひらがな・カタカナ） | アイテムの絵 | 画面に出る所 |
|---|---|---|---|---|
| 拾った（ほった・おとしもの・焼けて入った・しゅうかく） | ひろう | `{名前} ×{数}` | あり | ログ（D） |
| たんす から つかった | つくる | `たんす から {名前} ×{数}` | あり（＋ たんす の小さな絵） | ログ（D） |
| つくった | つくる | `{名前} ×{数} を つくった` | あり | 履歴だけ（画面は ばんざい・横断幕 があるので M4 のまま出さない） |
| やきはじめた（やく を押した） | つくる | `かまど で {できるもの} を やく` | あり | 履歴だけ |
| 合図: いっぱい | できない | `もちもの が いっぱい！`・`たんす が いっぱい！` | なし | 照準の下（今のまま） |
| 合図: つるはし・や | できない | `つるはし が いるよ`・`や が いるよ` | あり（いしの つるはし・や） | 照準の下（今のまま。画面は絵だけ） |
| 合図: 農業（M7・M7-2） | おしらせ | M7 の文のまま（漢字は ふりがな付き） | M7 の絵のまま | 今のまま |
| 道具が もうすぐ こわれる・こわれた（WEAPON-2） | おしらせ | `{名前} が もうすぐ こわれるよ`・`{名前} が こわれた` | あり | 今のまま |
| 妖怪（ようかい）を たおした | たたかい | `{妖怪の名前} を たおした` | なし（印だけ） | 履歴だけ |
| やられて もどった | たたかい | `スタートに もどったよ` | なし | 今のまま |
| 実績（じっせき）を とった | じっせき | `「{実績の名前}」 を とった` | なし | 今のまま（横断幕・おめでとう画面・メダル） |
| レベル が あがった | じっせき | `レベル {n} に なった` | なし | 今のまま |

- 「履歴だけ」の 3 つ（つくった・やきはじめた・たおした）は、画面を にぎやかに しすぎないため 左のログには出さない（オーナーに聞くこと 6）。
- 同じ合図が 出たまま 時間を もどしただけ のとき（M7 §3.3 など）は 履歴に 足さない（同じ合図が 出ていない状態から 出たときだけ 1 件）。

**(2) まとめ方**
- いちばん新しい 1 件と **カテゴリー・文の種類・アイテム が同じ** で、その 1 件が できてから **180 ステップ以内**（`logMergeTicks`）なら、新しい件を作らず **数を足す**（例 `つち ×1` → `つち ×5`。ほりつづけても 100 件が つちで うまらない）。数の無い件（合図など）は 右に `×2` を足す（同じ合図が 2 回）。
- **100 件まで**（`logHistoryMax`）。101 件目で いちばん古いのが消える。
- **保存しない**（起動しているあいだだけ。ページを開き直すと空。オーナーに聞くこと 4）。やられても 消えない。

**(3) 開き方**（アイコン優先）
- もちもの画面（E）の 上のタブに **`できごと`** を足す: `もちもの`・`じっせき`・**`できごと`**（3 つ目）。タブには **まきもの の絵**（16×16 を 2 倍。クリーム色の紙に 茶色の じく）＋字。
- あそんでいるとき **L キー**（新しい Action `openLog`）→ もちもの画面を **できごと タブ** で開く。開いているとき L → 閉じる（E・Esc・とじる も今までどおり閉じる）。もちもの画面の 別のタブのとき L → できごと タブに 替える。
- たんす画面（M6 §2.9 (4)）には タブが無いので、たんす を開いているあいだ L は 何もしない。
- 案内画面（Esc）の **つくる・やく** タブに 2 行 足す: `L で できごと を みる`（まきもの の絵）、`たんす の ものも つかえる`（たんす と かなづち の絵）。

**(4) ページの見た目**
- パネル全体が できごと ページ（じっせき ページと同じ大きさ。M6 §3.6 (2) の 1224×568）。上に 見出し `できごと`（タイトル 32px）。
- 行は **新しいものが いちばん上**。1 行 = 高さ 56px のカード（`--rk-bg-700`、角 小）: 左から **カテゴリーの印 32px** → **アイテムの絵 32px**（あれば）→ **白い字**（本文 20px・太さ 500。`×5` の数も白、`tabular-nums`）。いちばん上の 1 行だけ 左はしに アクセントの 帯 4px（「いま」の しるし）。
- 1280×720 で 7 行 見える。のこりは **スクロール**: ホイール、または 右はしの **▲・▼ ボタン**（56×56px、§3.5「ボタン（ふつう）」。1 回で 3 行）。いちばん上なら ▲ は「ボタン（押せない）」、いちばん下なら ▼ も 同じ。開いたときは いつも いちばん上（新しい所）。
- 0 件なら まんなかに まきもの の絵 と `まだ なにも ないよ`（本文 20px・`--rk-text-sub`）。
- 開いているあいだに できごと が ふえたら、いちばん上に 足す（スクロールの位置が いちばん上なら そのまま見える。下を見ていたら 位置を動かさない）。

### 2.7 カテゴリー と 色・形

- 6 つ。**色だけに たよらない**: 印の **外の形** が ぜんぶ ちがい、中に **白い小さな絵** を入れる。印は 16×16 のドット絵（コードで描く）を 2 倍の 32px。外の形には こい色（`--rk-bg-900`）の 1 ドットの ふち（明るい世界の上でも 形が見える）。
- 色は M6 §3.5 (2) の色だけを使う（新しい色は足さない）。

| # | カテゴリー（id） | 色 | 外の形 | 中の白い絵 | 入るもの |
|---|---|---|---|---|---|
| 1 | ひろう（`pickup`） | みどり `--rk-ok` | **まる** | 下向きの やじるし | 拾った |
| 2 | つくる（`craft`） | きいろ `--rk-accent` | **しかく**（角まる） | かなづち | たんす から つかった・つくった・やきはじめた |
| 3 | たたかい（`fight`） | だいだい `--rk-accent-2` | **六角** | かたな（ななめ） | たおした・スタートに もどった |
| 4 | じっせき（`achieve`） | むらさき `--rk-rarity-3` | **星**（5 つの とがり） | 白い 小さな ひかり（2×2） | 実績・レベル |
| 5 | おしらせ（`info`） | あお `--rk-info` | **ひしがた** | てん 3 つ（…） | 道具が こわれる・こわれた・農業の合図 |
| 6 | できない（`warn`） | あか `--rk-ng` | **さんかく**（上向き） | ！ | いっぱい・つるはし が いる・や が いる |

- 黄 = 押せる・えらんでいる、みどり = ある・できた、赤 = 足りない・できない、青 = 知らせ、の M6 の 色の意味と そろえた（つくる は「できた」の黄の光と同じ色）。
- 印の 中の白い絵は どれも 白 `#FFFFFF`。外の形の色の上の 白い絵は、明るい色（きいろ）の上では こい色の 1 ドットの ふちで囲む（見えるように）。

### 2.8 半透明の UI

**(1) 何を すけさせるか**

| 所 | 今 | これから（はじめの値） | 設定の名前 |
|---|---|---|---|
| 大きな パネル（もちもの画面・たんす画面・案内画面。M6 §3.5 (6) の「パネル」） | `--rk-bg-900` 96% | **80%** | `uiPanelAlpha` |
| HUD の かたまり・チップ（ログの行・合図・名前・時計・じぶん・おしらせ・農業の しるし など `--rk-hud-bg` を使う所） | 72% | **60%** | `uiHudAlpha` |
| もちもの画面・たんす画面・案内画面の うしろの 暗さ（`--rk-scrim` を使う所のうち、この 3 つ） | 黒 50% | **黒 20%** | `uiScrimAlpha` |
| HUD の ホットバーの **からっぽ のマス**（`--rk-bg-700`） | 100% | **60%**（`uiHudAlpha` と同じ値を使う） | — |
| 下限（上の 2 つは これより小さくできない） | — | **60%** | `uiAlphaMin` |

- **すけさせないもの**（字と絵を読むため。今のまま 不透明）: アイテムの入った マス（カテゴリーの色。白い数がある）、パネルの中の カード（`--rk-bg-800`：せつめい パネル・ツールチップ）・マス・行（`--rk-bg-700`）・ボタン・タブ・バー・メーター、**おめでとう画面・やられた画面** の うしろの暗さ（モーダル。50% のまま）、横断幕。
- 設定を `settings.set` で変えると **次のステップで** 画面に出る。`uiPanelAlpha`・`uiHudAlpha` に `uiAlphaMin` より小さい値を入れたら `uiAlphaMin` に なる（0〜1 の外は 0・1 に）。

**(2) 字が読めることを たもつ方法**
1. **下地の下限 60%**: いちばん明るい空（白 `#FFFFFF`）の上に `--rk-bg-900` を 60% で重ねても、白い字との 明るさの比は 約 **4.8**（4.5 以上）。下限より うすくは できない。
2. **すける下地の上に じかに のる字は 白（`--rk-text`）だけ**。`--rk-text-sub`・`--rk-ng`・`--rk-accent` の字は、不透明な カード・マス・行 の上だけに置く（今 じかに のっていたら 白にするか、カードに入れる）。例外: 24px 以上・太さ 700 以上 の字は 比 3 以上なら よい（M6 AC33 と同じ）。
3. **字の ふち**: すける下地の上の字には 2px の こいふち（`--rk-bg-900`。今の 拾ったログ・合図 と同じ 4 方向の `text-shadow`）を必ず付ける。
4. 明るい場面でも読めることは、AC で **世界を白 とみなして** 比を しらべて確かめる（§6 AC21）。

## 3. 画面・見た目

### 3.1 文字（ひらがな・カタカナ・数字・記号だけ。漢字は無し。M7 の農業の合図は 今のまま ふりがな付き）

| 場所 | 文字 |
|---|---|
| ログ（左） | `{名前} ×{数}`・`たんす から {名前} ×{数}` |
| もちもの画面のタブ | `もちもの`・`じっせき`・`できごと` |
| できごと ページ | 見出し `できごと`・§2.6 (1) の文・`まだ なにも ないよ`・`×2` |

### 3.2 色・形（コードで描く）

- **ログの行**（左。M6 §3.5「チップ」のまま形は同じ）: `[カテゴリーの印 32px][アイテムの絵 32px][白い字]`。下地 `--rk-hud-bg`（`uiHudAlpha`）、角 まる。字は 本文 20px・太さ 500・白・2px の こいふち。たんす から の行は、アイテムの絵の 左下に **たんす の小さな絵**（16×16 を 1 倍、16px。M6 §2.9 (6) の アイテムの絵）を 重ねる（字が読めなくても「たんす の ものだ」と分かる）。
- **せつめい パネルの ざいりょう**（M6 §2.1 (2) の 6）: まる（要る数だけ）の ぬり方を 3 つに:
  - もちもの にある分 = **みどり**（`--rk-ok`。今のまま）
  - たんす から使う分 = **桐色（きりいろ）**（`--rk-kiri`）でぬり、チップの 右上に **たんす の小さな絵 16px**
  - 足りない分 = 赤いわくの白いまる（今のまま）
  - 例: き 3 要る・もちもの 1・たんす 5 → ●（みどり）●●（桐色）。まるの順は みどり → 桐色 → 足りない。
- **やく の ねんりょう チップ**（M6 §3.6 (2)）: 数は 合計。たんす の分が 1 こ以上あれば チップの右上に たんす の小さな絵 16px。
- **カテゴリーの印**: §2.7 の表。どの印も 16×16 の 外わく 1 ドット `--rk-bg-900`。
- **できごと タブの絵**: まきもの（クリーム `#F3E3C0` の紙、茶 `#8A5A2E` の じく 上下、紙に こい茶の よこ線 3 本）。ドット絵の中の色なので M6 の色の表の外でよい（M6 AC31 の「ドット絵の中だけ」）。
- 点滅なし。行が出るときの動き（下から 16px・160ms）・同じ行で数が足されたときの ぴょこん は M4 のまま（明るさを くり返し変えない）。

### 3.3 音
- 新しい音は無し。たんす から使っても 「ガラッ」は鳴らさない（遠くの たんす の音が聞こえるのは へん）。つくる・やく の音は 今のまま。できごと タブを押したら M4 のタブの「ポン」。

## 5. 例外のとき

- **たんす が こわれた・消えた**（同じステップも）: その たんす は もう数えない。こわれた中身は 落とし物（M6 のまま）で、拾えば もちもの として使える。
- **たんす を開いて カーソルに持ち上げた もの**: 数えない（カーソルのもの）。閉じて たんす に もどれば また数える。
- **たんす の中の 道具**（たいきゅう・水の 印つき）: レシピの材料に 道具は無いので 関係しない（材料は 数だけ見る）。
- **もちもの が いっぱい**: §2.3。たんす から 取らない・ログも出さない・`craftFail`（`full`）。
- **かまど の じゅんばん が いっぱい・ねんりょう 0**: M4 のまま。たんす から 何も取らない。
- **もちもの画面が 閉じている**: つくれない（M4 のまま）。窓口（`craft.make`・`furnace.bake`）は 画面に関係なく 同じきまりで たんす から使う。
- **`craftTansuRange` を あとで小さくした**: 次のステップから その きょり で数える（すでに やいている じゅんばん は そのまま）。
- **できごと が 100 件 を こえた**: 古い件から消える。開いて下の方を見ていたら、見ている行は 位置がずれないようにする（消えた行の分だけ）。
- **案内画面・おめでとう画面 のあいだ**: L は 何もしない（M6 のとおり ほかの入力も止まっている）。やられた画面のあいだ も 何もしない。
- **古い保存**: 何も足さない（履歴は保存しない・設定は はじめの値）。M7-2 までの保存が そのまま開ける。

## 8. デザイナーが決めたこと（オーナー確認①で見せる要点）

1. **たんす の中の素材も つくる・やく（材料と ねんりょう）に使える**。おく・や・たね は今までどおり 手（もちもの）のものだけ。
2. 使う順は **もちもの（今までどおり ふくろ から）→ たんす（近い たんす から）**。足りるかは もちもの＋たんす の合計。
3. はじめは **世界の すべての たんす** が使える（設定で「N ブロック以内」にもできる）。
4. たんす から使ったら 左のログに **`たんす から き ×2`**（たんす の絵つき）。もちもの から使ったときは出さない。せつめい パネルの まるは たんす の分が **桐色**。
5. **できごと**（ログの履歴）: E の画面の 3 つ目のタブ、または **L キー**。新しい順・100 件・起動中だけ。同じものが続くと 数を足す。
6. **カテゴリー 6 つ**: ひろう（みどり・まる）・つくる（きいろ・しかく）・たたかい（だいだい・六角）・じっせき（むらさき・星）・おしらせ（あお・ひしがた）・できない（あか・さんかく）。字は 白＋こいふち。
7. **半透明**: 大きなパネル 80%・HUD 60%・うしろの暗さ 20%（設定で変えられ、60% より うすくは できない）。マス・カード・ボタンは 読みやすさのため 不透明のまま。世界が まっ白でも 白い字が 読めることを 自動で確かめる。
