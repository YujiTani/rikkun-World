- タスク票: `docs/tickets/WEAPON-5.md`（issue #199）。前の仕様: `WEAPON-4.md`（今の刀の わざ・数）・`WEAPON-2.md`（わざ・先行入力・おしつづけ）・`WEAPON-3.md`（向き）・`CHAR-2.md`（絵のコマ）・`BALANCE.md`（ダメージの物さし）。動きのものさし `docs/art/MOTION.md`、見た目のものさし `docs/art/CRITERIA.md`、盛り上げ `docs/fun.md`。

## 1. ねらい（りっくんがどう楽しむか）

- 妖怪が「ためて」攻撃してくるのを見て、**タイミングよく Shift＋クリック → パキィーン！** 。こわい攻撃を はじき返す「かっこいい」瞬間を作る。
- はじくと妖怪が ふらふらになり、頭の上に マークが出る。「今だ！」と 切りかかると **いつもの 2 倍** 。守り → 反撃 の 気持ちよい流れ。
- ちょうちんの火の玉を はね返して、ちょうちんに 当てかえせる（飛び道具に 手も足も出なかった のが、逆に チャンスになる）。
- 受けられる時間は 0.3 秒と長め、少し早くても 半分で すむ。6 歳でも「ときどき できる」→「ねらって できる」に なる。

## 2. 遊び方（プレイヤーから見た動き）

1. **刀（ぼくとう・かたな・きらめく カタナ）を持って、Shift を押しながら 左クリック** → パリィ。かまえ（上段・中段・下段）は関係なく、いつも同じ パリィ。
2. はしっている（Shift＋移動）ときに クリックしても出る。出したら その場で止まる。おわったとき まだ Shift と 移動キーを押していれば、また はしり出す。
3. パリィの間は 歩けない・ジャンプできない（今の わざと同じ）。空中で出したら、横には動かず、落ちるのは今のまま。
4. 受けの間に 妖怪の攻撃（からかさ・ろくろくび・ぬりかべ の攻撃、ちょうちんの火の玉）が当たると **成功**: ダメージ 0・押されない・パキィーン・一瞬スロー・キャラが青白く光る・妖怪が よろける（頭の上に よろけアイコン）。火の玉は ちょうちんへ はね返る。
5. 成功すると すぐ「きめ」（決めポーズ 8 ステップ）になり、そのあと すぐ 切りかかれる。
6. 受けが おわったあと（すき）に当たると **早すぎ**（はじめの 12 ステップは 半分のダメージ）。それより あとは ふつうのダメージ。
7. よろけている妖怪への 次の一撃（刀・パンチ・弓・はね返した火の玉）は **2 倍**。2 倍が当たると アイコンが ぱっと消える。
8. 刀でない道具（ツルハシ・オノ・クワ・なぎなた・弓・すで）の Shift＋クリックは 今のまま（ほる・パンチ など）。

### 3.3 画面の配置

- HUD（ハート・ホットバー・かまえの印・わざの名前）は 変わらない。新しい HUD の部品は ない（3 つの画面の大きさ 1280×800・1440×900・1024×700 で 今と同じ。AC30）。
- **よろけアイコン** は 妖怪の 頭の上（世界の中に置く。画面の はしに 出さない）。上から順に「アイコン → 名前（二つ名のとき）→ 体力のバー → 妖怪」。名前・バーに 重ならない。
- 大きさは 世界の中の大きさ（近いと大きく 遠いと小さい）。いちばん小さいときの目安: 16 ブロック先で 形が分かる（オーナー確認 AC33）。
- **いちばん多いとき**: 受けの 1 回で 何体も成功したとき・はね返しが重なったとき、よろけている妖怪 ぜんぶに 1 つずつ（同時の数の上限は 出ている妖怪の数と同じ）。アイコンどうしが重なっても よい（妖怪が重なっているとき）。光は キャラに 1 つだけ。
- 青白い光は キャラの体の まわり だけ。ねらいの ＋マーク・ハートに かぶさらない。

### 4.2 入力（Shift＋攻撃）

| 持ち物 | Shift | 攻撃（左クリック） | どうなる |
|---|---|---|---|
| 刀 | 押している | このステップで 押した | **パリィ**（ねらいが ブロック・作物・妖怪・何もない、どれでも。ほる・しゅうかく は しない） |
| 刀 | 押している | 押しつづけ（前から押している） | 何も出さない（パリィは おしつづけで くり返さない。わざも出さない） |
| 刀 | 押していない | 押した・押しつづけ | 今のまま（わざ・ほる・しゅうかく） |
| 刀 | 押しつづけている間に Shift を押した | 押しつづけ | 次の わざは 出ない（Shift を はなすと また 押しつづけの わざ） |
| 刀でない物 | どちらでも | どちらでも | 今のまま（ほる・パンチ・なぎなた・弓・クワ） |

- 出せるとき: 刀が 何もしていない（idle）とき、または わざ・パリィ の 先行入力の間（わざは さいご 8 ステップ、パリィは F33〜40・きめの間）。先行入力で 押したら、今のが おわった 次のステップに パリィが出る（わざの先行入力と同じく、あとに押した方が 勝つ）。
- かまえを変えている間（8 ステップ）は 先行入力として受ける（今の わざと同じ）。
- 出せないとき: もちもの画面・案内画面・やられている 間。
- はしる: パリィの間は 歩く速さ 0・ジャンプなし（`bladeMoveMul` と同じ考え）。はしりの勢いは 始めた ステップで 止まる（すべらない）。

### 4.3 成功

| 項目 | 値 |
|---|---|
| ダメージ | 0（防具の たいきゅうも 刀の たいきゅうも へらない） |
| 押される（ノックバック）・むてき | なし（成功では むてきを つけない。むてき中に 成功しても 成功） |
| スロー | 成功の 次のステップから **6 ステップ** の間、ゲームの時間が **0.25 倍**（実時間 24 フレーム = 0.4 秒）。7 ステップ目から 1 倍 |
| 青白い光 | 成功の 次のステップから **20 ステップ**（スローを ふくめ 実時間 6×4 + 14 = 38 フレーム ≈ 0.63 秒） |
| 音 | `parry`（1 回のパリィで 1 回） |
| 妖怪 | 攻撃が 取り消され（このあと その攻撃は当たらない）、**よろけ 90 ステップ**（§4.5） |
| 火の玉 | はね返す（§4.6） |
| いくつ同時でも | 受け・きめの間に当たった 攻撃 ぜんぶが 成功（2 体なら 2 体とも よろける）。スロー・光・音は 1 回 |

- スローは ゲームの時間 ぜんぶ（プレイヤー・妖怪・火の玉・刀・天気）が ゆっくり。音・BGM・HUD の動きは ふつう。もちもの画面の 0.25 倍と かさなったら かけ算（パリィは もちもの画面では 出せないので ふつうは 起きない）。
- スローの のこり・光の のこり は ゲームのステップで 数える（テストで 決定的に 数えられる）。

### 4.5 よろけ（妖怪）

| 項目 | 値 |
|---|---|
| 長さ | **90 ステップ**（1.5 秒）。よろけた ステップの 次から 数える |
| 動き | 歩かない・向きを変えない・攻撃しない・体当たりの ダメージを出さない。うかぶ物（ちょうちん）は うかんだまま。押される（ノックバック・ふっとび）と 落ちるは ふつう |
| 2 倍 | よろけの間に プレイヤーから受ける **次の 1 回の ダメージが 2 倍**（0.01 の位に まるめる。WEAPON-4 §4.3 と同じ）。刀の わざ・パンチ・弓・はね返した火の玉、どれでも。2 回目からは ふつう |
| アイコン | よろけの間 出る。2 倍が当たったら 消える（よろけは のこりも 続く） |
| おわり | 90 ステップで ふつうに もどる。もどったら その妖怪の「次の攻撃まで」（からかさ 120・ちょうちん 180・ろくろくび 150・ぬりかべ 120 ステップ）を待ってから 攻撃できる |
| もう一度 よろけた | のこりを 90 に もどす。2 倍は 1 回分だけ（重ねない。使っていたら また 1 回分） |
| 倒れた・帰った・消えた | よろけも アイコンも 消える |

- 2 倍の例: かたな 突き 3 → 6、ぼくとう 切り上げ 2.3 → 4.6、きらめく 切り上げ 6.9 → 13.8、きらめく 大けさぎり 15 → 30、すで 1 → 2、弓（段 3）3 → 6。大けさぎり（扇）で よろけた妖怪 2 体に当たれば 2 体とも 2 倍。
- **90 で足りるか（自分で計算した）**: いちばん おそい成功（F20 = ステップ S）→ きめ S+1〜S+8 → 大けさぎりを S+9 に始めると 当たりは わざの F29〜34 = S+37〜S+42。よろけ（S+1〜S+90）の中。くっついた からかさ には 突き（S+13）・切り上げ（S+28〜30）でも 間に合う。

### 4.6 火の玉の はね返し

| 項目 | 値 |
|---|---|
| いつ | 受け（F3〜20）・きめ の間に 火の玉が プレイヤーの体に当たった ステップ |
| 向き | **投げた ちょうちんの 当たりの箱の まん中へ まっすぐ**（はね返した ステップの 位置。そのあと 追いかけない）。ちょうちんが もういない・倒れかけ・帰りかけ なら、来た向きの **逆** |
| 速さ | **10 ブロック/秒**（今の火の玉 5 の 2 倍） |
| とどく | はね返した所から 8 ブロック（今と同じ長さ）。かべ・ブロックに当たったら 消える（今のまま） |
| 当たる | 妖怪（出かけ・倒れかけ・帰りかけ でない）の 当たりの箱。**プレイヤーには もう当たらない** |
| ダメージ | はね返した刀の 強さ × 1（ぼくとう 2・かたな 4・きらめく 6）。よろけ中なら 2 倍 |
| 当たった妖怪 | **よろける**（§4.5。90 ステップ）。スロー・光・`parry` の音は 出さない（はね返したときに 出ている） |

- 早すぎ（F21〜32）で当たった火の玉は はね返さない（半分のダメージで 消える）。
- 1 回のパリィで 火の玉が いくつ来ても ぜんぶ はね返す。
- **速さを変えた理由**: ちょうちんは 攻撃のあと 秒速 1 で動くので、5 ブロック先から 5 の速さで もどると 1 秒で 1 ブロック動いて 外れやすい。10 なら 0.5 秒で 0.5 ブロック。当たりの箱の 半分どうし（ちょうちん 0.4 + 火の玉 0.25 = 0.65）の中に おさまる。

## 8. PO の値から変えた所・オーナーに聞くこと

1. **【変えた】スロー 12 → 6 ステップ**: 12 ステップを 0.25 倍に すると 実時間 0.8 秒で「一瞬」より 長く 止まったように 感じるため、6（実時間 0.4 秒）にした。試作で 長さを見てもらう（AC28）。
2. **【変えた】はね返す向き・速さ**: 「逆向き・同じ速さ」→「投げた ちょうちんへ・2 倍の速さ」。ちょうちんは 動くので 逆向き・5 では 外れやすい（§4.6）。
3. **【加えた】成功したら すきを きめ 8 に かえる**: 成功の すぐあとに 切りかかれる 気持ちよさのため（MOTION #10 の キャンセル）。成功は 攻撃が 来ないと 起きないので 連打の 得には ならない。
4. **【聞く】後ろからの攻撃も 受けられる** ことにした（6 歳向け）。向きを 見たほうが よければ、前 ±90° などに できる。
5. **【聞く】かまえの 2 ステップに 当たったら 失敗（ふつうのダメージ）**。やさしくするなら ここも 早すぎと 同じ 半分に できる。
6. **【聞く】はね返した火の玉の ダメージは 刀の強さ（かたなで 4）**、当たった妖怪も よろける。ちょうちん（体力 5）は かたなで はね返し 1 回 + 1 回で 倒れる。
7. **【聞く】パリィの 遊び方を どう知るか**: 画面に 字は 出さない。パパが教える / 案内画面に 1 つ 絵で足す / はじめて成功したら じっせき、のどれにするか（このタスクでは 作らない）。
8. 連打（AC20）: 押しつづけても くり返さない。毎ステップ 押し直すと 40 ステップに 1 回 出て、受けは 18/40。早すぎで 半分 12/40。強すぎるなら すきを のばす（AC29）。
9. `BALANCE.md` の こわさ（ちょうちんの 飛び道具 ×2）は パリィで 少し下がるが、このタスクでは 変えない。
