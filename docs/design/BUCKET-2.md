# BUCKET-2: マグマの バケツ・わきどころを くむ（仕様書）

- 土台: `docs/design/BUCKET-1.md`（バケツ・みずの バケツ）、`docs/design/WAKIDOKORO.md`（わきどころ・液体の 音）。ここに 書いていない ことは 土台の まま。
- ゆずの 仕様（2026-11-03）。滝の エレベーターは この 票では やらない。

## 1. ねらい
- からの バケツで マグマも くめる。わきどころ（水・マグマ）は バケツで だけ とれる（こわしても 何も 落ちない は そのまま）。
- マグマの バケツで マグマを 置ける。置いた マグマは ふつうの マグマ（燃やす・あつい・水で こくようせき は 今の しくみ）。

## 2. 決めた こと
| こと | 決め |
|---|---|
| 新しい アイテム | `magma_bucket`（マグマの バケツ）。`bucket`・`water_bucket` の id は かえない（保存の まま） |
| 量 | マグマの バケツも 量 1〜8 を `water` 欄に 入れる（同じ 欄。欄 なしは 8）。保存の 形は かわらない |
| くむ: ながれる 液体 | からの バケツ → 線が 最初に 通った 液体の 種類の バケツ。みずの バケツは 水だけ、マグマの バケツは マグマだけ 足せる（WATER-1 §4.4 と 同じ 量の 決め） |
| くむ: わきどころ | からの バケツで わきどころを ねらって 右クリック → わきどころは 空気に なり、量 8 の みず / マグマの バケツ。入って いる バケツでは くめない |
| 置く | ふつうの 液体（量は バケツの 量）。わきどころには 戻らない（わきどころ を 動かすのは ずっと 出る 水を 作れて しまう ので、置くのは いつも 有限の 液体） |
| 置ける マス | BUCKET-1 §2.1 と 同じ（air・体と 重ならない…）。マグマも 同じ |
| 音 | 置いた とき `liquidSounds` の placeWater / placeMagma（WaterSystem.noteSound で 同じ 間引き・距離）。マグマが 水に ふれて こくようせきに なる 音は 今の erode |
| しずくの つぶ | 水だけ（マグマは なし） |
| 手に 入れ方 | バケツの レシピは 今の まま（てつの インゴット 3）。マグマの バケツは マグマを くむ ことで だけ（レシピ なし） |
| 絵 | 3 つ: から・みず（今の）・マグマ（新。みずの 絵の 水の 色を マグマの 橙・赤・黄 に） |

## 3. 受け入れ（AC）
1. からの バケツで マグマ（量 8）を くむ → magma_bucket（量 8）、マスは 空気。（unit）
2. みずの バケツで マグマは くめない・マグマの バケツで 水は くめない。（unit）
3. からの バケツで わきどころ（水・マグマ）→ それぞれの バケツ（量 8）、わきどころは 空気。入った バケツでは かわらない。（unit・E2E）
4. マグマの バケツで 置く → マグマ（量 = バケツ）、バケツは から。音 placeMagma。（unit・E2E）
5. 保存: magma_bucket の 量が 読み直しで のこる。（unit）
6. 絵: 3 つの 16x16 が ちがう。（unit・スクショ）
