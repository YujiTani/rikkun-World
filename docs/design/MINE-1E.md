## 1. ねらい（りっくんが どう 楽しむか）

yuzu（15:23）「一本道を降りていくだけなので、あれだとあんまり冒険感がなさそう」への こたえ。

- **坑道ごとに 性格が ちがう**: ふかい・あさい、ひろい・せまい、まっすぐ・ふくざつ、キャンプあと や 迷路が ある・ない。入る たびに「こんどの 坑道は どんな かな」（15:39）。
- **階の かさなり**: さか道で 1 つ 下の 階へ → その 階を 横に 探検 → また さか道で 下へ。下り口は 階の 本道（床に ふるい レール）の むこう。
- **分かれ道と 行きどまりの くじ**: 横穴から えだ道が 分かれ、どっちに 行くか えらぶ。行きどまりの 先は 大当たり（宝箱）・中あたり（きらきらの へや）・あたり（鉱石 少し）・はずれ。はずれに 見えても **ひびの かべ** を ほりつづけると 奥に かくしべや（15:33・15:34）。
- **迷路の 階**: 同じ 高さで 分かれ道・ぐるっと 回る 道・行きどまりの ある 小さな 迷路（15:35）。
- **むかしの 坑道あと・冒険者の キャンプあと**: こわれた わく・ふるい レール・たおれた はしご・くずれて ふさがった 道。たんすに かびた パン・つかいかけの つるはし・妖怪の 落とし物（15:37）。ちょうちんの まわりは 妖怪が わかない **かくれて 休める 所**（子どもは 戦うより かくれる のが すき）。
- **こわく ない・落ちない** は のこす: 落ちない・作った とき 明るい・**どこからでも 歩いて 入口に もどれる 道が ある**（一方通行の 段差 なし）。**帰り道の しるしは 作らない**（yuzu 16:33「帰り道わからなくなるのも醍醐味なので大丈夫」。迷うのも 冒険。自分で チョークの やじるしを かくのは よい）。

## 2. 遊び方（子どもの 遊びで 見た 流れ）

```
入口（1C と 同じ 木の わくの 門）─▶ さか道を おりる
 ─▶ 1 つめの 階の 上り口（ひろば。上へ もどる さか道の 口）
 ─▶ 階の 本道（床に ふるい レール）。わきに 横穴・えだ道・キャンプあと・迷路の 入口
     ├─ 横穴 ─▶ ほらあな・ふしぎな ほらあな（1D）・こべや
     │    └─ えだ道（分かれ道）─▶ 行きどまりの くじ
     │         大当たり: 宝箱の へや ／ 中あたり: きらきらの へや ／ あたり: 鉱石が 少し
     │         はずれ: ただの 行きどまり ／ ひびの かべ → ほりつづける → かくしべや！
     ├─ むかしの えだ道（こわれた わく・とぎれた レール。口が くずれた いしで ふさがって いる ことも → ほれば 通れる）
     ├─ キャンプあと（ちょうちん・ふとん・たきびの あと・たんす → かびた パン「うぇ〜」）
     └─ 迷路の 入口 ─▶ 迷路の いちばん おくに ごほうび
 ─▶ 本道の おわりの 下り口 ─▶ さか道 ─▶ 次の 階 …
 ─▶ いちばん 下の 階の おくに いちばん 下の へや（宝箱は 3 つに 1 つ。1C の まま）
 ─▶ 帰りは 来た 道を 思い出して 上り口 → さか道 → … → 入口（迷っても、どこからでも 歩いて もどれる 道は ある。自分で かいた チョークも 目じるし）
```

- 1C の「たいまつで 明るい さか道を 下りるだけ で ふかい 所まで 行ける」は のこす: どの 階も 本道を レールに そって 歩けば 下り口に つく（横に それなくても いちばん 下まで 行ける）。
- **はじまりの 坑道は 1C の 形の まま**（yuzu 16:33「始まりの坑道をおおきくしなくていいです」）。1E の 性格・階の かさなり・えだ道・迷路・キャンプあとは ほかの 坑道 だけ（スタートの 見え方の 描画回数を ふやさない。§4.14）。1D で なかほどの 横穴が ほたるの ほらあなに つながる（MINE-1 §4.7.1・D8）。はじめての 6 歳は はじまりの 坑道で 坑道に なれて、となりの 坑道で 冒険に 出会う。

## 4. ルール・数値

### 4.1 坑道の 性格（15:39）【PO 案: ぜんぶの 数。1 か所の 表に】
- **坑道ごとに 性格を シードつきの くじで 決める**（世界の シードと 区画。1C の 坑道の くじとは べつの 乱数）。数は **1 か所の 表**（性格の 表）に 書き、テストは 表から 読む（#311）。

  | 性格 | くじ |
  |---|---|
  | ふかさ（いちばん 下の 階の 層） | ふかい 60%・なかほど 30%・あさい 10% |
  | 階の 数（いちばん 下の 階を 入れる） | ふかい 3〜5・なかほど 2〜3・あさい 2（同じ わりあい） |
  | 広さ（坑道 ぜんぶの 箱の 1 辺） | 64 マス 25%・96 マス 50%・128 マス 25% |
  | ふくざつさ | やさしい 30%・ふつう 45%・ふくざつ 25% |
  | キャンプあと | あり 1/3 |
  | 迷路の 階 | ふくざつさ で きまる（下の 表） |
  | ひびの 行きどまり | 行きどまり ごとの くじ（§4.4） |

- **はじまりの 坑道は 性格を 引かない**（1C の 形の まま。`style` は null。§2）【レビューの あと。yuzu 16:33】。
- 15:39 の「深さ、複雑さ、小部屋の数、坂の数、全体的な広さ」との つながり: 深さ ＝ ふかさ、複雑さ ＝ ふくざつさ、広さ ＝ 広さ。**さか道の 数** は ふかさ・階の 数・1 本の 長さで 坑道ごとに かわる（下。くじの 行に しない わけ: 階の 高さと 1 本の 長さで 決まる 数 なので、べつに 引くと 合わない）。**小部屋の 数**（行きどまりの へや・こべや・かくしべや・キャンプあと）は ふくざつさ（横穴・えだ道の 本数）と 行きどまりの くじで 坑道ごとに かわる。

- **ふくざつさ の 表**:

  | | やさしい | ふつう | ふくざつ |
  |---|---|---|---|
  | 階 1 つの 横穴（本数） | 0〜1 | 1〜2 | 1〜3 |
  | 横穴 1 本の えだ道（本数） | 0〜1 | 0〜1 | 0〜2 |
  | 坑道 ぜんぶの えだ道の 上限 | 2 | 5 | 8 |

### 4.11 安全と「もどれる」きまり（MINE-1 §4.5.3 を 1E に ひろげる）
1E の どの 道（さか道・ひろば・本道・横穴・えだ道・行きどまりの へや・迷路・キャンプあと・かくしべや）も MINE-1 §4.5.3 の 1〜4・6・7 を まもる（床の 下 2 マス 固い・かべ・天井 固い〔口・出口 いがい〕・入口の まわりに ふち なし・作った とき 光 6 以上・天井の 上の 石・こわい かざり なし）。**ひびの いし・くずれた いしの マス** は「ほった あと」で 見る（道の マスに 数え、ほった あとも 1〜4 を まもる）。

**もどれる**（体の 安全 だけ。§4.5.3 の 5 を かえる。デザインレビュー 周 4 の あと yuzu 16:33）:
1. **一方通行の 段差 なし**: 上り下りは さか道（2 マスで 1 段）と 横穴・えだ道（2 マスに 1 段 まで）だけ。ひろば・本道・迷路・へやは 平ら。
2. **入口から どの 道の マスへ 行っても 歩いて もどれる 道が ある**（道さがし。MINE-1 §6.1 の 歩ける きまり。C4 と 同じ 見かた）。
3. たいまつを とって 暗く なっても 道の 形は かわらない ので 歩いて もどれる（1C の まま）。
4. **帰り道の しるしは 作らない**: 向きを しめす 2 本 ならびの たいまつ・入口を さす チョークの やじるしを 生成で 置かない（yuzu 16:33「いやチョークのやじるしはかいちゃだめ。帰り道わからなくなるのも醍醐味なので大丈夫」）。迷うのも 冒険。自分で かく チョークは よい。1E の たいまつは 明るさ（§4.5.3 の 4）の ため だけに 置く。1C の 入口・横穴の 出口の 両がわの たいまつは 1C の まま のこるが、**向きの しるし では ない**（くぐって 入口へ 行けるとは かぎらない）。

- **形の きまり**（迷いすぎない 大きさ。しるし では ない）: 分かれ目は 階の 中で「本道 → 横穴 → えだ道」の 2 つ まで（えだ道から 分かれない。階を 下りる たびに 本道に もどる）・曲がりは 本道 1・横穴 2・えだ道 1 まで（曲がり角は 平らな 3×3・たいまつ）・迷路は 入口まで 60 歩 以内（§4.6）。ふるい レールは 本道に しく（たどれば 上り口・下り口・いちばん 下の へやに つく 形の 事実。帰り道の しるし として 言い切らない）。
- **1F の やかた**（`MINE-1F.md`）: あやしい 横穴は 上の 1〜3 を まもる。大広間・祭壇だけ 明るさの 例外（光 2 以上。`MINE-1F.md` §4.2）。

### 4.13 1C の 坑道を どう 作りかえるか（保存の 版・古い 坑道）【PO 案】
- **保存の 版**: 1E で **1 つ 上げる**（1D の 6 → **7** ＝ 1E の 坑道の 版。マージの 順が かわれば 1 つずつ）。版の 数は `src/save/gens.ts` の 1 か所（#304）。1F で もう 1 つ 上げる（→ 8。`MINE-1F.md` §4.9。古い 列の 持ち方は この 節と 同じ）。
- **古い 列の 一覧を 1 つ 足す**（1E の 一覧。1E の 版より 前に 保存した 列。作り方・書き方・ふやさない・へらさない は MINE-1 §4.8 の 坑道・部屋の 一覧と 同じ）。
  - 一覧は 古い ほうが 新しい ほうに ふくまれる（坑道 ⊆ 部屋 ⊆ 1E）ので、**一覧が ふえても meta の 大きさは 保存の 列 1 つに つき 12 バイト 以下**（一覧 1 つ ぶん）に おさえる（例: 列ごとに「どの 版から の 古い 列か」を 1 つ 持つ。やり方は developer）。
- **区画ごとに どちらの 坑道を 作るか**:
  1. その 区画の **1C・1D の 作り方の 坑道**（版 6 の 計画）が 1E の 一覧の 列（坑道の まわり 2 マス）に かかる → **1C・1D の 坑道を そのまま 作る**（りっくんの 世界の 古い 坑道は のこる。とちゅうで 切れない）。**1C・1D の 作り方は 消さずに のこす**。
  2. かからない → **1E の 坑道**。1E の 坑道は 1E の 一覧の 列（まわり 2 マス）と、その 列に かかる 1D の 部屋（まわり 4 マス）に かからない 場所だけ（かかるなら ほかの 入口の 候補。なければ その 区画は 坑道 なし）。
  - 1D の くじの 部屋も 同じ: 1E の 一覧の 列に かかる 部屋は 版 6 の 作り方（1C・1D の 坑道を よけた 場所）の まま。ほかの 部屋は 作った ほうの 坑道を よける。
- **はじまりの 坑道**: **いつも 1C・1D の 作り方**（`gen: 'c'`。§2。yuzu 16:33）。入口の 場所（`meta.shaftStart`）も 形も 1E で かわらない（古い 世界も 新しい 世界も 同じ）。1E の 区画の くじ（上の 1・2）は はじまりの 区画には 使わない。
- **1C・1D の meta の 書き方も 読む**: 版 5・6 で 書いた `oldCols: { kodo: number[]; heya?: number[] }` を そのまま 読み、1E の 一覧と いっしょに 持つ（書き方を かえても 古い meta が 読める こと。E16）。
- 宝箱・キャンプの たんす・チョークの しるし・ひびの いしは ブロックで 持つ ので 列の 保存で のこる。行きどまりの くじ・性格は シードで きまる（保存しない）。
- 坑道の 世界（`ShaftWorld`）は 世界ごとに 1 つ（生成・実績・surface・窓口が 同じ 物を 見る。1C の まま）。
