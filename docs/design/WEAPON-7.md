## 2. 土台（武器に よらない しくみ。PR1）

### 2.1 レジェンダリーの データ（1 つ 足すと 武器が ふえる）

武器ごとに 下の データを 1 つ 持つ。設定 **`legendary: LegendaryDef[]`**（`settings.get/set`）。アイテム（`ItemId`・名前・めずらしさ `legendary`・絵）は いつもどおり アイテムの 表に 足す。

```ts
// src/contracts.ts（名前は この仕様で 決める。中の しくみ は 開発）
interface LegendaryDef {
  item: ItemId;
  /** 強さ P。[最小, 最大] なら 落ちた ときに 整数で 決めて その 1 本に 保存（§5.1） */
  power: number | [number, number];
  /** ためわざ（null = ためない。押しつづけは 今どおり くり返す） */
  charge: LegendaryCharge | null;
  /** ふつうの わざに 足す 効果（見た目・音・弾）。0 こ 以上 */
  onAttack: LegendaryAttackFx[];
  /** 手に 持っている 間の 効果。0 こ 以上 */
  passive: LegendaryPassive[];
}
// たいきゅうは 今の 表 `toolDurability`（W2 の 設定）に 10000 で 入れる（§2.4）
type LegendaryCharge =
  | { kind: 'lightning'; chargeTicks: number; range: number; radius: number; damageMul: number; knock: [number, number]; strikeF: number; boltSteps: number; recovery: number }
  | { kind: 'shining'; chargeTicks: number; rise: number; riseSteps: number; holdSteps: number; fallSteps: number; radius: number; damageMul: number; hitEvery: number; push: [number, number]; cooldown: number };
type LegendaryAttackFx =
  | { kind: 'trail'; style: 'thunder' | 'rainbow' }            // 軌跡に まぜる 見た目と 音
  | { kind: 'wave'; speed: number; range: number; radius: number; damageMul: number; knock: [number, number] };
type LegendaryPassive = { kind: 'moveMul'; mul: number };
```

- **ためわざは `charge.kind` で 中身を 差しかえる**。新しい ためわざを 足す ときは `kind` を 1 つ 足し、その 中身を この 仕様の §3・§5 と 同じ 書き方で 決める。
- `legendary` に ある 刀は 今の 刀の なかま（かまえ・3 つの わざ・パリィ・ほる・射程 2.2・わざの 長さ）。**3 段攻撃（`bladeCombo`）にも 入る**（yuzu 2026-10-19。段の 出かた・ふみこみ・音は きらめく カタナと 同じ）。ためわざの ある 刀（雷神剣）は、つなぎの 窓（`combo.open`）に 押すと 次の 段（ためは 始めない）。窓の 外・3 段目の さいご 8F の 押しは 今までどおり ための 先行入力。押しつづけると、段が おわった あと ためが 始まる。風神剣は 段ごとに 真空波が 出る。
- 今の 刀の 強さの 表（`weaponDamage`）は レジェンダリーでは 使わず `power` を 読む。

### 2.2 ためる・はなす（第 1.2 版 §2・§4.1 の 考えを 使い回す。段は 1 つ）

| 項目 | きまり |
|---|---|
| 始まり | `charge` が ある 武器で ひだりクリックを 押した（ふりわけが わざ）→ ため（ためF 1）。Shift＋押す は 今どおり パリィ（ため中に Shift を 押しても パリィに ならない・はしらない。はなして わざの さいご 8F に Shift＋押すと パリィ） |
| ふりわけ | 今のまま（WEAPON-2 §2.1-6）: 押した ステップに 照準の 先 5 以内の いちばん 手前が ブロックなら **ほる**（ためない）。だから 雷神剣で 近い 地面を ねらって 押すと ほる。雷は 妖怪か 5 より 遠い 所を ねらう 使い方（妖怪が 手前に いれば ためる）。ため中に ねらいが ブロックに 変わっても ためは 続く |
| たおした あつかい | 雷・真空波・ドームで たおした 妖怪も「プレイヤーが たおした」（経験値・ドロップ・実績・ヌシの 表） |
| ため いっぱい | ためF が `chargeTicks`（雷 60 = 1.0 秒、虹 90 = 1.5 秒）に なった ステップ。音 `chargeReady` ＋ 体が「ぴくっ」2F ＋ 刀の 光が 大きく なる |
| はなす | はなした ステップに、いっぱい なら **ためわざ**、まだ なら **今の かまえの ふつうの わざ**（その ステップが F1） |
| ため中 | 歩く 0.5 倍・はしらない・地面での ジャンプ なし（水の中は 上へ およげる）・見る向きは 自由・R と 右クリックは 何もしない・攻撃を 受けても ためは 消えない |
| 消える | 持ちかえ・Q・1〜9・やられた・もちもの画面・案内画面・止めた → ためは 消える（音なし。何も へらない） |
| くり返さない | わざが おわった 次の ステップに 押していれば すぐ 次の ため（押しっぱなしで 同じ わざを くり返さない） |
| ため の 形 | ためF 1 から かまえに よらず **おおげさぎりの ふりかぶりの コマ（コマ 5。刀を 頭の上へ）** で 止める（空へ かかげる 形。雷・虹の どちらにも 合う）。うつりの 混ぜは 2 コマ以内。歩く 間は かまえ歩き ＋ 光 |
| ため の 光 | 押した 時から 刀に 光が つき、いっぱいで 大きく なる（2 つの 大きさ。色は 武器の 色。点滅しない） |

- 段は 1 つに した（第 1.2 版は 2 段）。ためわざが 武器ごとに 1 つで、6 歳に「いっぱいに なったら はなす」だけで 分かる ため。
- `charge` が null の 武器（風神剣）は 今の 刀と 同じ（押しつづけで くり返す）。

### 2.3 ヌシの ドロップ表

- **つなぎ方**: ヌシを **プレイヤーが** たおした とき、今の ドロップ（その 妖怪の 表を 4 回）の **あとに**、ヌシの 表から **かならず 1 本**（引く 回数を ふやさない。ヌシの 表の 選び方と 虹の 強さは **べつの シード付き 乱数**〈ワールドの シード ＋ 固定の 数〉で 引き、今の ドロップの 乱数の 列は ずらさない）。落下で たおれた・あさに 帰った ヌシは 出さない（今と 同じ）。ぬりかべ は ヌシに ならない（今のまま）。
- 確率は **100%**（O7）。出し方: 今の 袋（`DropField`）で 地面に。出来事は 今の `drop`。
- **袋が にじ色に かがやく**（O7）: 今の legendary の 光の柱と 足もとの わは もう にじ色に 流れる（`src/fx/bagVisuals.ts`）。この 刀の 袋は それに 加えて **袋 そのものの 色も にじ色に ゆっくり 変わる**（1 回りに 3 秒より ゆっくり。点滅なし）。ほかの legendary の 物（今は ない）も 同じ。
- **テロップ**（O7）: 落ちた ステップに §2.6 の テロップを 出す。
- **表は `legendary` の データから 作る**（PR1 では 雷神剣 だけ、PR2 で 風神剣、PR3 で 虹が 入る）。設定 **`nushiDrops: { item: ItemId; weight: number }[]`**（初期値 = `legendary` の ぜんぶ、weight 1）。
- **選び方**（O11）: 表の ぜんぶから **weight で ランダムに 1 本**（初期値は どれも weight 1 = 同じ 重さ）。持っている か・前に 何が 出たか は 見ない（同じ 物が つづけて 出る ことも ある）。虹は 強さが 毎回 ちがうので、2 本目も 意味が ある。
- 「手に 入れた」= もちものに 入った とき（袋を ひろう・テストの `inventory.add` も）。袋を ひろわずに 消えたら 手に 入れて いない。実績（§2.5）に 使う。
- 保存（世界ごと）: `legendGot: ItemId[]`（手に 入れた ことの ある 物）。前の 保存に ない ときは 空。
- 目安: ヌシに 出会うのは 約 36 晩に 1 回（BALANCE §2.5 の 数。二つ名 4.3% が 2〜3 晩に 1 回 → 1 晩 約 9 体 → ヌシ 0.3% は 約 333 体に 1 体）。3 本が 同じ 重さで ランダムなので、3 本 ぜんぶ そろうまでの ヌシの 数は 平均 3 ×（1 ＋ 1/2 ＋ 1/3）= **5.5 体**（約 198 晩）。早く さわらせたい なら ヌシの 出る 確率を 上げる 別 issue（BALANCE）。

### 2.4 たいきゅう 10000（O11）

- 3 本とも **たいきゅう 10000**（今の 表 `toolDurability` に 足す）。たいきゅうの きまりは 今の 刀と 同じ（WEAPON-2 §4.6）: バー・のこり わずか（10% = のこり 1000 で `wearLow` と「！」）・こわれる（`toolBreak`。もちものから 消える）・修理なし。
- へり方: ふつうの わざ = 今の 刀（`toolWear.blade`: 当てた 1・ほった 2）。**落雷 = 1 体でも 当たれば 1**（空ぶり 0）。**シャイニング = 1 体でも 当たれば 1 回に 1**。**真空波 = 0**（ふった 刀の 分は 刀の きまりで 数える）。
- 目安: 10000 ＝ 妖怪に 当てる 1 万回。1 体を 当てつづけて つき 41 ステップに 1 回 → 10000 × 41 ÷ 60 ÷ 3600 = **約 1.9 時間** 当てつづけて やっと 0。ふつうに 遊ぶなら まず こわれない。
- もちものの 説明の 行は 今の 形 `たいきゅう 10000 / 10000`（いちばん 長く なる。§7.2）。
- **BALANCE §2.6-4**（たいきゅうは 同じ 段階と そろえる: き 59・いし 131・てつ 250・すいしょう 500）の **例外**: つくれず ヌシで しか 手に 入らない 武器だけ、段階の 数に そろえず 10000（すいしょう 500 の 20 倍）。BALANCE §2.6-4 に その 1 行を 書き足した（2.2 版）。

### 5.3 ドームの 当たり

- ドーム = プレイヤーの 体の 中心を 中心と した **半径 7 の 球**（うかぶ・おりる 間は 今の 半径）。
- 妖怪の 箱が ドームに 重なったら（ふれたら）: ダメージ **P × 2.5**（強さ 4 → 10、7 → 17.5、10 → 25）・ドームの 外向きに 水平 3・上へ 2 で はじく。**同じ 妖怪には 60 ステップに 1 回まで**（1 回の シャイニングで 1 体に 多くて 4 回: 240 ステップ ÷ 60。はじかれて ドームの 外に 出れば 1 回）。かべごしでも 当たる（ドームは 光なので）。
- **プレイヤーは 安全**: シャイニングの 間（うかぶ〜おりる）は 妖怪の 攻撃・火の玉が プレイヤーに 当たらない（火の玉は ドームに ふれたら 消える。小さな 光の つぶ）。どうぶつ・ブロックには 何も しない。
- **見た目**（yuzu の 見本 shining.jpg・dome.png〈O10〉。3 案は いらない。見本どおりの 試作 → yuzu）:
  - **まん中が 白く 光る**: プレイヤーの まわり（半径 1.5 くらい）に 白い 光の 玉。プレイヤーの 体は 光の 中に うすく 見える（かくさない。白で ぬりつぶさない）。
  - **ドーム**: 半径 7 の 球の まく。中は ほとんど すける（75% 以上 すける）。**ふちが 光る**（横から 見て 球の りんかくが 明るい）。
  - **光る リング**: ドームが 地面と 交わる 所に 明るい わ（地面に そう。シャイニングの 間 ずっと。とどまる 間は 体の 中心が 地面から 約 2.9 上〈体の 中心 0.9 ＋ うく 2〉なので わの 半径は √(7² − 2.9²) ≒ 6.4。うかぶ・おりる 間は 球の 大きさと 高さに あわせて かわる）。「ここまでが ドーム」が 分かる。
  - **にじ色の 光の 帯**: 3〜5 本の 細長い 帯が ドームの 面に そって **うずを まいて 回る**（1 回りに 4 秒より ゆっくり）。帯の 色は にじ（赤〜むらさき が 帯の 中で 流れる）。

## 6. 強さの 確かめ（BALANCE を こわしすぎない）

**ふつうの わざの ダメージ**（P × 0.75 / 1.15 / 2.5。0.01 の 位）と **たおす 回数**（M = 1。体力 からかさ 8・ちょうちん 5・ろくろくび 12・ぬりかべ 40、ヌシの からかさ M = 1 は 24）

| 武器（P） | つき / きりあげ / おおげさぎり | からかさ | ろくろくび | ぬりかべ | ヌシの からかさ 24 |
|---|---|---|---|---|---|
| かたな（4） | 3 / 4.6 / 10 | 3 / 2 / 1 | 4 / 3 / 2 | 14 / 9 / 4 | 8 / 6 / 3 |
| 風神剣（6）＋ 波 1.8 | 4.5 / 6.9 / 15（＋1.8 → 6.3 / 8.7 / 16.8） | 2 / 1 / 1（波 こみ） | 2 / 2 / 1 | 7 / 5 / 3 | 4 / 3 / 2 |
| 雷神剣（8） | 6 / 9.2 / 20 | 2 / 1 / 1 | 2 / 2 / 1 | 7 / 5 / 2 | 4 / 3 / 2 |
| 虹（10・いちばん 強い） | 7.5 / 11.5 / 25 | 2 / 1 / 1 | 2 / 2 / 1 | 6 / 4 / 2 | 4 / 3 / 1 |

- **BALANCE の 物さし**（段階 3 の 武器: からかさ M = 2.25 の 18 を きりあげ 4 回、M = 3 の 24 を 6 回まで）: 雷神剣 9.2 → 2 回・3 回、虹 10 → 11.5 → 2 回・3 回。**物さしの 約 2 倍 強い**。風神剣 6.9 → 3 回・4 回。虹 4（4.6）は ちょうど 物さし（4 回・6 回）。
- 考え: ヌシを たおした 人だけの 「伝説」なので 段階 3 より 強くて よい（O3・O5 の 強さは オーナーの 数）。ただし **ぬりかべ（40）は まだ 2〜7 回** かかり、「1 発で なんでも たおれる」には ならない。M = 3 の ヌシの からかさ（72）は 雷神剣 おおげさぎり 4 回・落雷 5 回。
- **1 秒あたり**（1 体に 当てつづけ）: かたな おおげさぎり 10 × 60 ÷ 106 = 5.66。雷神剣 おおげさぎり 20 × 60 ÷ 106 = 11.3、落雷 16 × 60 ÷（60 + 45）= 9.1（1 体なら おおげさぎりより 少し 弱い。まとめて 当たるのが 強み）。風神剣 つき ＋ 波 6.3 × 60 ÷ 41 = 9.2。虹（10）の シャイニング 25 × 3 ÷（90 + 260 + 600）× 60 = 4.7（休みが あるので 攻める わざ では なく 守る わざ）。
- 安全（BALANCE §2.7）は 妖怪の 強さの きまりなので 変わらない。シャイニングの「安全な 4 秒」は 10 秒の 休みで いつも 出せない。
