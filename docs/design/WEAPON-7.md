## 遊び方の要点（yuzu の OK 用）

1. **ヌシが まれに 落とす 新しい 刀「にじまる」（仮の 名前。いまほし 7・レジェンダリー）だけ**、ひだりクリックを **押しっぱなしで ためて、はなすと ためわざ**（ゆみと 同じ 手ざわり）。ほかの刀は 今のまま。
2. ためは **2 段**: 0.33 秒で 段 1、0.83 秒で 段 2（いっぱい）。段は **刀の 光と 音の 高さ**で 分かる（ゲージは 出さない）。いっぱいの まま ずっと 持てる。
3. **短く 押して はなせば 今の かまえの ふつうの わざ**（つき・きりあげ・おおげさぎり）。この刀では「押しつづけで 同じ わざを くり返す」の かわりに ためになる。
4. ためわざは **かまえごとに 3 つ**（今の わざの 強い版）: 中段 = 遠くまで **つらぬく つき**、下段 = 高く **うかせる きりあげ**、上段 = とびこむ **ズバーン の おおげさぎり**。段 2 で 当てると 画面が 小さく ゆれる。
5. ためている 間は **ゆっくり 歩ける**（0.5 倍）。はなした ときの 向きに 出る（向きの補助も 効く）。持ちかえると ためは 消えるだけ（何も へらない）。
6. 強さ: いっぱいに ためて 当てつづけると、かたなの いちばん強い 使い方の **約 1.23〜1.28 倍**（きらめく カタナの 3 段と ほぼ 同じ）。ためた 時間で 損は しない。
7. パリィは 今のまま（ためている 間は Shift を 見ない。はなして わざが 出たあと、いつもどおり Shift＋クリック）。
8. 手に 入れ方: **ヌシを たおすと ときどき 落とす**（つくれない）。推奨: 1 本目は 50%、2 体目の ヌシで かならず。2 本目 からは 10%。刃は にじいろ。推奨は **強さ 4（かたなと 同じ）・こわれない**（やっと 手に 入れた 宝物が なくならない）。名前・落ちる 確率・強さは 案から 選ぶ（§5）。

## 1. ねらい（りっくんがどう楽しむか）

- 「ぐぐぐっ…」と ボタンを 押したまま 待つと、刀が だんだん 光って「キィン！」「キィィン！」。はなすと **ズバーン！** と いつもより 大きな わざ。**がまんした ぶんだけ すごい** が、ボタン 1 つで 分かる。
- ためた まま ゆっくり 近づいて、ここだ！で はなす。**「いつ はなすか」を 自分で 決める** 手ごたえ。
- かまえで ためわざが ちがう（つらぬく・うかせる・とびこむ）ので、今の「かまえ ごっこ」が そのまま 生きる。

- **いちばん 強い 妖怪（ヌシ）を たおした ごほうび** なので、手に 入れた とき「やった！」が 大きい。にじいろの 刃は 持っている だけで じまんに なる。

## 2. 遊び方（プレイヤーから見た動き）

### 2.1 ためる・はなす

1. ためられる刀（`bladeCharge.items`。§5 の ヌシの 刀）を 持って、ひだりクリックを **押す**（そのステップの ふりわけ〈WEAPON-2 §2.1-6〉が わざ のとき）→ **ため** が 始まる（ためF 1）。押している 間 ためF が 1 ずつ ふえる。
2. ためF が **20** に なった ステップで **段 1**、**50** に なった ステップで **段 2（いっぱい）**。段が 上がった ステップに 音と「ぴくっ」（§3）。段 2 の あとは はなすまで そのまま（時間の 上限なし）。
3. **はなした**（押していない 最初の）ステップに、その前までの ためF で 段を 決めて わざを 始める（そのステップが わざの F1）:
   - 段 0（ためF 1〜19）→ **今の かまえの ふつうの わざ**（数・長さ・形は 今のまま）。
   - 段 1・段 2 → **ためわざ**（§4.2〜§4.4）。
4. ためている 間: 歩く速さ **0.5 倍**・ジャンプ できない・はしらない（Shift を 見ない）。見る向き（マウス）は いつでも 動かせる。キャラは 見ている 向きを 向く（今の 歩きと 同じ。わざの 向きは まだ 決めない）。
5. わざの 向き u・向きの補助（WEAPON-3 §4.2・§4.3）は **はなした ステップ**（わざの F1）に 決める。補助の「とどく」は 出る わざで 見る（§4.5）。
6. ためわざが おわったら（または ふつうの わざが おわったら）次の ステップは idle。そのとき ひだりクリックを **押していれば**（いつ 押したかに よらない）、すぐ 次の ため（ためF 1）を 始める。だから 押しっぱなしでも 同じ わざは くり返さない（ために なる）。
7. わざの さいご 8F（今の 先行入力）に 押して、おわる前に **はなした** ときは 今のまま「おぼえた わざ」= 次の ステップに ふつうの わざ。
8. 段 0 で はなしても 失敗では ない（ふつうの わざが 出る）。

| 案 | 1 本目 | ヌシを たおす 数（平均 / 多くて） | 晩の 目安（× 約 36 晩） | 2 本目から |
|---|---|---|---|---|
| 1（推奨） | **50%・2 体目で かならず** | 0.5 × 1 + 0.5 × 2 = **1.5 体** / **2 体** | 平均 約 54 晩 / 多くて 約 72 晩 | **10%**（10 体に 1 本） |
| 2 | 1/3・3 体目で かならず | 1/3 × 1 + 2/9 × 2 + 4/9 × 3 = 19/9 ≈ **2.1 体** / **3 体** | 約 76 晩 / 約 108 晩 | 10% |
| 3 | 100%（はじめての ヌシで かならず） | **1 体** / 1 体 | 約 36 晩 | 10% |

- **推奨 1 の 理由**: オーナーの「まれに 落とす」を 守りつつ（たおしても 出ない ことが ある どきどき）、外れても 2 体目で かならず 出るので「もう 出ない」に ならない。ヌシ 自体が とても まれ（約 36 晩に 1 回）なので、刀の 確率を これより 下げると 6 歳には 長すぎる。
- **2 本目から 10% の 理由**: 推奨の「こわれない」（§5.3）では 2 本目は 予備（なくした・たんすに しまった ときの ため）。めったに 出ない くらいで よい。案 C（こわれる）を 選んだ ときは、刀が こわれたら `got` を false に もどし、また 1 本目の きまり（こわれた 宝物を とりもどせる）。
- 気になる 点（この issue の 外）: ためわざを りっくんが 早く さわるには、ヌシの 出る 確率（0.3%）の 方が 大きく 効く。上げるなら BALANCE の 別 issue（PO に 伝える）。
- 設定 `nushiBlade` = `{ item: 'nushi_katana', firstChance: 0.5, pityAt: 2, laterChance: 0.1 }`（案 3 は `firstChance: 1`、案 2 は `1/3`・`pityAt: 3`）。

## 10. オーナーに 決めて もらうこと（オーナー確認①）

1. **名前**（§5.1）: 推奨 **「にじまる」**。ほかに「ぬしまる」「ヌシの かたな」。
2. **ヌシから 落ちる 確率**（§5.2）: 推奨 **案 1（1 本目は 50%・2 体目の ヌシで かならず。平均 1.5 体。2 本目からは 10%）**。案 2 = 1/3・3 体目で かならず（平均 2.1 体）、案 3 = はじめての ヌシで かならず。ヌシに 出会うのは 約 36 晩に 1 回 なので、手に 入るまで 推奨でも 平均 約 54 晩（多くて 約 72 晩）。早く さわらせたい なら ヌシの 出る 確率を 上げる 別 issue も ある。
3. **強さ・たいきゅう**（§5.3）: 推奨 **案 A（強さ 4・こわれない）**。B = 強さ 5・こわれない（いちばん 強い）、C = 強さ 4・たいきゅう 1000・こわれる（ヌシで とりもどす）。
4. **ためる 段の 数と 長さ**: 推奨 **2 段（0.33 秒・0.83 秒）**。1 段だけ（0.5 秒）にも できる。
5. **ためている 間 歩けるか**: 推奨 **ゆっくり 歩ける（0.5 倍）**。止まる（0）にも できる（設定 `moveMul`）。
6. **実績 3 つ**（「はじめて いっぱい ためて あてた！」「はじめて にじまる を てにいれた！」「にじまる で はじめて たおした！」）を 入れるか: 推奨 入れる。
- ためている 光の 見た目（§3.2 の 3 案）は アートの 試作で あとから 選ぶ（タスク票 進め方 3）。

### PO の 値から 変えた・加えた（仕様で 決めた）

1. ためが 出るかを `rarityAtLeast(item, 'legendary')` → **設定 `bladeCharge.items`** に した。武器が 変わっても しくみを 変えずに すみ、めずらしさを 設定で 変えても わざが 変わらない（WEAPON-6 と 同じ 考え）。
2. ためわざは **かまえごとに 3 つ**（今の わざの 強い版）。新しい 体の 絵が いらず、かまえの 遊びが 生きる。段 2 だけ 特色（つらぬく・高く うく・遠くへ ふっとぶ）。
3. 段 0 の 間は ポーズを 変えない（短く 押した ときの ふつうの わざを きれいに 出すため）。ふりかぶりは 段 1 から。
4. ため中に 攻撃を 受けても ためは 消えない（6 歳が「ためが すぐ 消える」で いやに ならないように）。
5. ヌシの 刀の 落ちる 引きは ドロップ表に 入れず、ヌシを たおした ときに べつに 1 回（4 回 引く ぶん 確率が 4 倍に ならない・ほかの ドロップの 結果を 変えない）。
6. 推奨の「こわれない」は BALANCE §2.6-4（たいきゅうを 段階で そろえる）の 例外（つくれない 武器だけ）。
