## 1. ねらい

- 「侍 の 防具」は **たたかい が じょうず に なる** 防具。パリィ が 決まり やすい・とばされ にくい・刀 が つよい・走る と カランコロン。

## 2. 遊び方

1. ヌシ を たおす → いつも の レジェンダリー の 袋 と 同じ ように、にじ色 の 袋 で 侍装備 が 出る こと が ある（§4.2）。

3. うで の マス は 1 つ なので、**明珍手甲 と 忍びの手甲 は 同時 に つけられない**（どちら か を えらぶ）。

### 4.3 明珍陣笠: パリィ の 受け を 0.5 秒 に

**今 の しくみ**（`src/combat/parry.ts`・W2 `parryTicks { ready 2, guard 18, recover 20 }`・`parryEarlyTicks` 12）:

| 区間 | F（今） | 当たったら |
|---|---|---|
| かまえ `ready` | F1〜2 | おしい（半分） |
| 受け `guard` | F3〜20（18 = 0.3 秒） | 成功 |
| すき（早すぎ） | F21〜32（`parryEarlyTicks` 12） | おしい（半分） |
| すき（もどり） | F33〜40 | 失敗。さいご 8（`bladeBufferTicks`）で 先行入力 |
| ぜんぶ | 40 | |

- 「おしい」の おわり は `ready + guard + parryEarlyTicks` で 決まり、ぜんぶ の 長さ は `ready + guard + recover`。だから **guard を のばす と、おしい の 区間 は うしろ に ずれる だけ で 長さ は 12 の まま**。recover を 変えなければ 全体 も 同じ だけ のびる。
- 決定 の「今 約 0.33 秒（20 コマ）」は、受け 18 ＋ かまえ 2 を 数えた 数 と 思われる（成功 する の は 今 18）。

**おすすめ（案 A）**: 陣笠 を 着て いる とき だけ **`guard` 18 → 30**（成功 が ちょうど 30 コマ = 0.5 秒）。`ready` 2・`recover` 20・`parryEarlyTicks` 12 は かえない。

| 区間 | F（陣笠） | 長さ |
|---|---|---|
| かまえ（おしい） | F1〜2 | 2 |
| 受け（成功） | **F3〜32** | **30** |
| すき・早すぎ（おしい） | F33〜44 | 12（今 と 同じ） |
| すき・もどり（失敗・さいご 8 で 先行入力） | F45〜52 | 8（今 と 同じ） |
| ぜんぶ | 52 | ＋12（空ぶり の とき だけ 0.2 秒 長い） |

- 成功 すれば すぐ きめ（8）に なる ので、成功 の とき は 長く ならない（F3 で 成功 → F12 に 次。F32 で 成功 → F41 に 次）。
- 長く なる の は 空ぶり の すき だけ。「受け を 長く する かわり に、空ぶり は 少し 長い」は わざ の 手ごたえ と して よい（WEAPON-5 MOTION #9 の 後すき）。
- 比べた 案（とらない）:
  - 案 B: guard 30・recover 12（全体 44）。失敗 の 区間 が 無く なり、先行入力 の さいご 8 が おしい の 区間 と 重なる。WEAPON-5 の 区間 の きまり が くずれる。
  - 案 C: guard 28（かまえ ＋ 受け で 30 と 数える。全体 50）。決定 の「20 → 30」を かまえ 込み と よんだ 場合。成功 は 28 コマ（0.47 秒）。
  - どちら の よみ か は **PO 確認**（おすすめ は 案 A。決定 の「ジャスト 受付 0.5 秒」を そのまま 成功 の 長さ に した）。
- 数 は 調整表 の `jingasaGuardTicks` 30（W2 の `parryTicks.guard` の かわり に、陣笠 の とき だけ 使う）。
- **パリィ を 始めた ステップ** に 陣笠 を 着て いれば、その パリィ の あいだ ずっと 30（今 の しくみ も 始めた ステップ の 設定 を 使う）。途中 で ぬいで も 着て も、その パリィ は かわらない。
- 絵 と 刀 の きせき: 受け の 絵（今 の F7〜20 の コマ）を 12 コマ 長く 止める。見せる F = `F ≤ 20 → F`・`21〜32 → 20`・`33 以上 → F − 12`。キャラ の コマ（`parryCells.ts`）と 刀 の 道（`parryFx.ts` の perTick）の 両方 に 同じ 引きもどし を つかう（新しい 絵 は 作らない）。

### 4.4 明珍羽織: とばされる 距離 3 割（共通 の「とばされにくさ」）

**共通 の 倍率**（オーナー「共通設定 みたいに 使いまわせる 仕様に」）:

- 調整表 に 防具 ごと の `knockbackMul`（とばされる 距離 の 倍率。1 = 今 の まま）。今 は `samurai_haori: 0.3` だけ。
- 「今 の とばされる 倍率」を 返す **関数 1 つ**（例 `knockbackMulOf(着て いる 防具)`）。プレイヤー の 押される しくみ と がしゃどくろ の はじき の **両方 が この 関数 だけ を 読む**。
- いくつか の 防具 に 値 が ある とき は **いちばん 小さい 値**（0.3 と 0.5 → 0.3）。かけ算 に しない（重ねて 0 に 近づき すぎない。「いちばん つよい 防具 が 効く」と 分かり やすい）。何 も 無い → 1（**PO 確認**）。
- 値 は 0〜1 に おさめる（0 なら とばされない）。

**どこ に かける か**:

| 押し | 今 の 数 | 羽織（×0.3） |
|---|---|---|
| ふつう の 妖怪 の 攻撃・火の玉（`PlayerCombat` の 押す 距離 `knockback`、10 ステップ で 動く） | 1.8 ブロック | **0.54 ブロック** |
| がしゃどくろ の 打撃・衝撃波（`BigShock` の `stagger.knockSpeed`） | 11 ブロック/秒 | 3.3 |
| がしゃどくろ の 小さい 衝撃（`tapKnockSpeed`） | 7 | 2.1 |
| がしゃどくろ の 払い（`sweep.knockSpeed`） | 22 | 6.6 |

- **横 の 距離・速さ だけ** に かける。上 へ の はね（`knockbackUp` 4.5・`stagger.knockUp` 5・`sweep.knockUp` 7）は かえない（**PO 確認**）。上 にも かける と、速さ で はじく がしゃどくろ は 空中 の 時間 も へり、距離 が 3 割 より ずっと 小さく（約 1 割）なる ため。当たった 手ごたえ（ぴょん と はねる）も のこる。
- がしゃどくろ の 当たり は `combat.damage` を 通る ので、ふつう の 押し（1.8）と はじき の 速さ の 両方 に 同じ 倍率 が かかる。
- かけない（**PO 確認**）: がしゃどくろ の コア を たたいた とき の ふり落とし（`core.throwOff`。体 の 上 から おろす しかけ）・とどめ の 一撃 の はじき（`finish.blow`。演出）。ひるみ の 時間（`stagger.sec` など）・ダメージ も かえない。
- パリィ 成功 で 押されない の は 今 の まま。

### 4.5 明珍手甲: 刀 1.5 倍・防御力 10 無視

**1.5 倍**:
- 刀 の 強さ（`weaponDamage`。レジェンダリー は `legendPowerOf` の 強さ P、虹 は 1 本 ごと の 強さ）を **× 1.5** して から、今 の 計算（わざ の 倍率 → 0.01 の 位 に まるめる `techDamage`）を する。整数 に は まるめない（今 も 小数 の ダメージ が ある。WEAPON-4 §4.3）。
  - 例: 木刀 2 → 3、かたな 4 → 6、きんの かたな 5 → 7.5、虹 7 → 10.5。かたな の けさぎり 4 × 2.5 = 10 → 6 × 2.5 = 15。
- 刀 = `BLADE_ITEMS`（木刀・かたな・きらめく カタナ・きんの かたな・雷神剣・風神剣・虹）。**素手・弓 は 対象外**（決定）。なぎなた・きんの つるはし／おの で たたく の も 刀 で は ない ので 対象外（**PO 確認**）。
- **刀 から 出る 物 にも 効く（おすすめ。PO 確認）**: 真空波・らせん・雷・ドーム（ためわざ も）は ぜんぶ 刀 の 強さ P × 倍率 で 決まる ので、P を 1.5 倍 に した 数 を 使う。「この 手甲 で 刀 が 1.5 倍 つよく なる」が 1 つ の きまり で 言える。強さ を 決める 時 は 今 の まま（ふつう の わざ は 当たった とき、真空波・らせん は 出した とき、ドーム は 始めた とき）。その 時 に 着て いれば 1.5 倍。
- 対象外: パリィ の はね返し（火の玉 の 強さ で 決まる）・マッチョ の パンチ・忍びの手甲 の 小太刀（もともと 同時 に つけられない）。
- よろけ の 2 倍 は 今 と 同じ く その あと に かかる（1.5 × 2 = 3 倍）。

**防御力 10 無視**:
- がしゃどくろ の 部位 の 計算（#293 `damageOf`）: 今 `ダメージ = 最低 1（強さ × 部位倍率 − 防御力）`。手甲 の とき は **`最低 1（強さ × 部位倍率 − max(0, 防御力 − 10)）`**。部位倍率 0 の 部位 は 今 と 同じ く 0。
  - 例（手・防御力 30・倍率 1.0）: 虹 10 の けさぎり → 手甲 なし 25 − 30 → 1、手甲 37.5 − 20 = **17.5**。コア（防御力 0・倍率 9）: 10 × 2.5 × 9 = 225 → 手甲 337.5（無視 は 0 より 下 に しない）。
- 無視 が 効く の は 1.5 倍 と 同じ 対象（刀 と 刀 から 出る 物）だけ。弓・パンチ は 防御力 そのまま。
- 防御力 を もつ 相手 は 今 がしゃどくろ の 部位 だけ。あと で 防御力 の ある 妖怪 を 足す とき も 同じ 式 を 使う（防御力 を ひく 所 を 1 か所 に する）。
- 数 は 調整表 の `tekkoBladeMul` 1.5・`tekkoDefIgnore` 10。

### 4.6 明珍下駄: 走る と 1 歩 ごと に 下駄 の 音

- 今 は 足音 の しくみ が 無い。下駄 用 に「走って いる 時間」で 1 歩 を 数える（キャラ の 絵 の 状態 は 読まない ので、絵 が 読めて いない とき も テスト でも 同じ）。
- **コード で 確かめた こと**: 走り の 絵 の うで の ふり は 1 周 `DOLL_SWING_PERIOD_SECONDS` = **1.0 秒**（`src/camera/config.ts`・`BlockDoll.ts` の `phase`）で、**走っても 歩いても 同じ**（走る 速さ `runSpeed` 5.6 で 変わらない）。うで は 1 周 で 0 を 2 回 よこぎる（左右 で 2 歩）→ **1 歩 = 0.5 秒**（走る 速さ 5.6 だと 約 2.8 ブロック）。なので 1 歩 を 距離 で 数える と 絵 の 足どり と ずれる。**時間 で 数える**。
- 1 歩 = `getaStepTicks` **30 ステップ**（0.5 秒。`DOLL_SWING_PERIOD_SECONDS` ÷ 2 を 60 ステップ/秒 で 数えた 数。うで の ふり が 0 を よこぎる 間隔 と 同じ）。
- 数える とき（ぜんぶ の とき だけ 1 ステップ ずつ 足す）: 下駄 を 着て いる・走る 入力 が 効いて いる（`running`。シフト ＋ 移動 キー）・地面 に 立って いる（`onGround`）・水 の 中 で ない（`inWater` で ない）・横 の 速さ が `getaMinSpeed`（1 ブロック/秒）以上（かべ に 向かって 押し続けて いても 動いて いなければ 足さない）。
- 数え が 30 に なる たび に `getaStep` を 1 回 鳴らし、数え を 0 に もどす。
- 鳴らさない（数え を 0 に もどす）: 歩き（シフト なし）・止まった・ジャンプ 中・落ちて いる・はじかれて 空中・水 の 中・パリィ や わざ で 止まって いる（動かない ので 自然 に 鳴らない）・ひるみ・やられた。もどした あと 走り 始める と、0.5 秒 走って から 1 歩目（絵 の うで は 走り 始め で 下がって いる ところ から 0.5 秒 後 に 0 を よこぎる ので 合う）。
- 走る 速さ が かわって も（レジェンダリー の 速さ の 倍率 など）絵 の うで の ふり は 同じ 1.0 秒 なので、音 の 間 も 0.5 秒 の まま（絵 と 音 は いつも 合う）。
- 下駄 の ふせぐ 量 は 落下 2（§4.1）。走る 速さ など は かえない。
