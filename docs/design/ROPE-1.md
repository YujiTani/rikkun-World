# ROPE-1: ロープ（仕様書）

## 1. ねらい（りっくんがどう楽しむか）
がけや ふかい あなを、ロープを たらして するする おりたり のぼったり できる。たかい ところから 落ちずに 冒険できる。

## 2. 遊び方（プレイヤーから見た動き）
1. 作業台で いと 3 → ロープ 4 本（または あさ 8 → ロープ 4 本）。あさ は くさ・はっぱ・はな を こわすと 約 1/3 で 1 こ でる。
2. （版 3）ロープを 手に もち、**がけに むかって 立って** 右クリック（ねらいは 見ない）。→ 足もとの マスに「ロープを まきつけた くい」が でる。
3. 向いて いる ほう（4 方向で いちばん 近い ほう）の となりの マスから 下へ ロープが たれる。1 本で 10 マスまで。持っている 本数 N で 10 × N マスまで。
   - がけ = まえの マスと その 1 つ下が どちらも あいて いる（水も あき）。たいら・かべ・空中（足もとの 下が 固くない）では 何も おきず、へらない。
4. 10 × N マス 以内で 床に とどくと、いちばん 下の マスは 絵の ちがう「ロープだまり」（まいた なわ）に なる。とどかなければ ぶらさがった まま。
5. ロープの マスに 体が 入ると つかまる。（版 3）**スペース = のぼる、シフト = おりる**、なにも しない = その 場で とまる（落ちない）。まえ・うしろ・よこは ふつうに 歩く（がけの 上へ もどる・はなれる）。ロープの 上では 走らない。
   - ロープに つかまって いる 間は 落ちた 高さを ためない。ゆっくり おりて 床・ロープだまりに ついても 着地ダメージ 0。とちゅうで はなれて 落ちたら、はなれた 高さから 数える。
6. ロープの どの マス（くい・ロープだまりも）を こわしても、たれた ロープ ぜんぶが 一度に 消えて、つかった 本数が 持ち物に もどる。

## 3. 画面・見た目
- 文字: 名前「ロープ」、ロープだまり「ロープだまり」。説明は ひらがな・カタカナ。ずかんの 文は 小 1・小 2 の 漢字＋ルビ。
- 色・形: 十字の 板で 描く ほそい なわ（2 色の よりの しま）。ロープだまりは 下に 3 だんの わ。アイコンは まいた わ＋たれた はし。こまかい 色は アートチーム（`docs/art/rope-1/`）。
- 本数の 見せ方: 持ち物・ホットバーの マスの 右下の 数字（今の しくみ。2 本 以上で 出る）。説明の 文に「1 ぽん で 10 マス」と 書く。
- 音: 置く・こわす は 今の 共通の 音。のぼる 音は なし（くり返す 行動は 控えめ `docs/fun.md`）。

## 4. ルール・数値
| 項目 | 値 |
|---|---|
| 1 本で たれる 長さ | 10 マス |
| 最大の 長さ | 10 × 手に 持っている マスの 本数 |
| つかう 本数 | ⌈たれた 長さ ÷ 10⌉（持っている 本数が 上限） |
| もどる 本数 | ⌈つながった ロープの 長さ ÷ 10⌉（つかった 本数と 同じ） |
| のぼる・おりる 速さ | 3 マス/秒（スペース・シフト） |
| くいの 場所 | 足もとの マス（あき か くさ。下が 固い）。たれる 列は 向いた ほうの となり、くいと 同じ 高さから 下へ |
| 作り方 | 作業台 いと 3 → ロープ 4（あさ 8 → ロープ 4 も） |
| あさ（hemp）の でる ブロック | くさ（grass・kusa）・はっぱ（leaves・momiji_leaves・matsu_leaves）・はな（flower_y・flower_o・flower_p・nobana）。すすきは 入れない |
| あさの でる 確率・数 | 1 回 こわすごと 1/3 で 1 こ（いつもの ドロップに 足すだけ） |
| あさの かわり | いと 1 こ → あさ 2.5 こ。はんぱは 切り上げ（1→3・2→5・3→8） |
| あさで 作れる 作り方 | ゆみ（き 3・あさ 8）・むしとりあみ（き 1・あさ 5）・ロープ（あさ 8 → 4）。カードは もとの 1 枚、作り方の えらびで かえる（たいまつと 同じ）。ぬのは 作り方が なく（ようかいの ドロップ だけ）なので なし |
| 重ね数 | 64 |

## 5. 例外のとき
- はじめの マスが ふさがっている → 置けない（へらない）。
- とちゅうに 水 → 水の マスにも たれる。ほかの ブロック・妖怪の 箱・建築中の 場所で とまる（そこが 床 あつかい → ロープだまり）。
- 世界の 底（外）に とどいた → ロープだまりは できない。
- 持ち物が いっぱいで もどらない 分 → 足もとに 落とし物（今の `giveStacks`）。
- 2 つの ロープが たてに くっついた とき → 1 本の ロープと して こわれる（もどる 本数は 合わせた 長さから。少し へる ことが ある。→ オーナー確認）。

## 版 3 追加: つなぎ・ロープの さく（オーナー 2026-11-01 18:34）
- **どちらに なるか**: ロープを もって 右クリック（地面に 立って いる とき）。
  1. つないで いる → 足もとに **ロープの さく**（下の 4）。
  2. つないで いない・まえが がけ（まえの マスと その 1 つ下が あき）→ 版 3 の たらす ロープ。
  3. つないで いない・がけで ない（たいら・かべ）→ **つなぎ**。
- **つなぎ**: 足もとに くい（rope_stake）を 1 本 うつ（ロープ 1 本 へる）。長さ = うつ ときに もって いた 本数 × 10 マス（へった 1 本も 入れる）。くいの まん中から プレイヤーの こし（足もと + 0.9）までの きょり（3D）が 長さより 先へ 行けない（遠ざかる 向きの 速さを けす。PlayerController の 1 ステップの うごきに かける）。くいと プレイヤーの 間に 細い なわの 線を かく。
- **ぶら下がり**: つないだ まま がけから 落ちると、長さ いっぱいで とまる（くいより 1 マス 以上 下・地面に いない とき）。そこから スペース = のぼる・シフト = おりる（長さより 下へは 行かない）・なにも しない = とまる。地面に つくと おわり。ぶら下がり中は 落下ダメージを ためない（ダメージ 0）。
- **さく（rope_fence）**: つないで いる 間、地面で 右クリック → 足もとの 1 マスに さく（ロープ 1 本）。プレイヤーは さくの 上へ のる（足もと + 1）。さくの 上で もう 1 回 → 上に つむ。当たりは 1 マスの ブロック（よこから とおれない・上を 歩ける・ジャンプ 1.25 マスで こえる）。くいと さくの 間に なわは わたらない。
- **こわす**: さく・つなぎの くい は それ だけ 消えて 1 本 もどる（つなぎの くいなら つなぎも きれる）。がけの たらす ロープ（くい・なわ・ロープだまり）は 版 3 の まま どこを こわしても ぜんぶ 消えて ceil(長さ/10) 本。つなぎの くいか どうかは 「いま つないで いる くいの 場所」で きめる。
- **つなぎが きれる とき**: くいが こわれた／なくなった、長さ + 3 マス より 遠くへ 飛んだ（リスポーン・ワープ）。ほかの アイテムに もちかえても きれない（ロープを もって いなくても つながった まま）。くいへ もどっても きれない（こわして おわり）。
- **きめ**: つないで いる 間は がけの 前でも さく に なる（たらす ロープは つなぎを きってから）。
