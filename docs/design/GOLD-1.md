## 1. ねらい（りっくん が どう 楽しむ か）

- にわとり と なかよく なる と、きん の たまご を うんで くれる。その たまご を かまど で 焼く と ぴかぴか の「きん」に なり、いちばん つよい ふつう の そうび が 作れる。「なかよく する → たから → つよく なる」が 1 本 に つながる。
- なかよし は 毎日 の おせわ（むし・なでる）で ふえ、ほうって おく と 少し ずつ へる。待つ 時間 は 字 で なく **まる が うまって いく 絵** で 分かる。
- 地下 で たまに 出る **はらぱんみみず**（ほし 5）は「いっぱつ で なかよし まんたん」の 切り札。地下 を ほる・たたかう 楽しみ が ふえる。

## 2. 遊び方（プレイヤー から 見た 動き）

1. なかま の 大人 の にわとり（外 の なかま でも 小屋 の 子 でも）を ねらう と、照準 の 下 に **なかよし パネル**（ハート の メーター と、むし・て の 2 つ の まち時計）が 出る（§3.2）。
2. むし を あげる → なかよし ＋15。なでる → ＋10。どちら も、した あと 5 分 は その 子 に **その こと が できない**（むし は 手もと に のこる。まち時計 の まる が うまって いく。うまったら また できる）。
3. 10 分 ごと に なかよし −5（0 より 下 に は ならない）。
4. なかよし が **70 を こえて いる** あいだ だけ、うむ たまご が 金 に なる こと が ある。メーター の 70 の 所 に きん の たまご の しるし。こえて いる と メーター が きんいろ に なる。
5. はらぱんみみず を 持って なかま の 大人 を 右クリック → なかよし が いっぱつ で 100。
6. きん の たまご を かまど で 焼く → きん 1。きん で 8 つ の そうび を 作る。

### 3.2 なかよし パネル（何 が 分かれば よい か。絵 は アート）

- **出る とき**: なかま の **大人**（外 の なかま・小屋 の 子）を ねらって いる あいだ（照準 の 下 の 案内 が 出る とき と 同じ）。やせい・ひよこ・だっこ 中 は 出ない。
- **ハート の メーター**: 0〜100 を 10 こ の 区切り で 見せる（1 区切り = 10。切り上げ で なく 切り捨て: 75 → 7 こ と 半分 は 出さず 7 こ）。**70 の 区切り の 上 に きん の たまご の しるし**。
  - 70 以下: ハート は ピンク。たまご の しるし は 灰色。
  - 70 を こえる（71 以上）: ハート が きんいろ に なり、たまご の しるし が 色つき で ゆっくり 光る（1.5 秒 に 1 回 強く・弱く。点滅 しない）。
- **まち時計 2 つ**（ハート の 右 に、むし の 絵 と 手 の 絵）:
  - ふやせる とき: 絵 は ふつう の 色、まる は いっぱい（みどり の わく）。
  - まち中: 絵 は 灰色、まわり の まる が **のこり に 合わせて 時計回り に うまって いく**（0 → 5 分 で いっぱい）。うまった ステップ に 1 回 ぽよん と はねて 色 が もどる（音 は 小さく 1 回。§3.4）。
- **10 分 の へり** は 見せない（へった とき に メーター が 1 つ 分 しずか に 減る だけ。音 なし・しかる 絵 なし）。

  - **LIVE-1・LIVE-2 から の かわり**: なかま の 大人 は むし を 5 分 に 1 回 しか たべない ので、ふつう の たまご（むし 4 回 に 1 こ・8 回目 は かならず）も 1 わ あたり **約 20 分 に 1 こ**（むし 4 回 = 15 分〜、多くて 8 回 = 35 分 で かならず）に へる（オーナー決定。へって よい）。おなかいっぱい（600 ステップ）は のこる が、まち 18,000 の ほう が 長い ので なかま の 大人 で は 目立たない。ひよこ・やせい は まち を もたない ので 今 の まま。
  - むし の まち と なでる の まち は **べつべつ**（むし の まち中 でも なでれば ＋10）。
  - もう 100 の とき に たべた・なでた: なつき度 は 100 の まま、**まち は はじまる**（あげた・なでた あと 5 分 は できない、の きまり は いつも 同じ）。
  - なでる は **今 の なでる と 同じ 右クリック**（すで でも、むし・はらぱんみみず 以外 の 物 を 持って いても。なかま は はなした 瞬間。LIVE-1 §2.3）。（決定 の「手 で 右クリック」を 今 の なでる と 読んだ。**PO 確認**）

  - だっこ（40 ながおし）は なでる に 入らない（ふえない）。
- **へる**: 子 ごと に「へる まで の のこり」を もち、世界 の 時計 で 1 ステップ ずつ へらす（はなれて いても・ねて いても へる。ゲーム が 止まって いる あいだ は 止まる）。0 に なった ステップ に なつき度 −5（0 より 下 に しない）、のこり を 36,000 に もどす。たべる・なでる で のこり は もどらない。
  - 同じ ステップ に 「へる」と「ふえる」が ある とき は **へる が 先**。
- **保存**: 子 ごと に `natsuki`（0〜100）・`natsukiBugWait`・`natsukiPetWait`（0〜18,000）・`natsukiDecayLeft`（1〜36,000）を セーブ に 入れる。読む とき おかしい 値（数 で ない・はんい 外・小数）は はんい に おさめて 整数 に する（なし は はじめ の 値）。
- **計算 し直し**（0 から、むし と なでる を まち が あけた とたん に する とき）: 0分 25 → 5分 50 → 10分 45（−5）→ 70（＋25。70 は こえて いない）→ 15分 95。**約 15 分 で 金 が 出る 状態**。むし だけ なら 15・30・40・55・65・80 で 約 25 分。100 から 何 も しない と 60 分 で 70（こえて いない）に なる ＝ 1 時間 に 1 回 むし を あげれば 70 を こえた まま。

### 4.5 金 の たまご の 確率（LIVE-2 §2.8 の `goldChance` に 合わせる）

たまご を うむ ステップ（`layEgg`。むし を あげて 60 ステップ 目）の その 子 の 値 で きめる:

```
もし natsuki ≤ natsukiGoldMin（70）なら        → 0（金 に ならない）
そうでなく goldMiss ≥ goldPity（30）なら       → 1（かならず）
そうでなければ p = min(goldCap, きほん ＋ むし の 上乗せ)   … 今 の 式 の まま
               マッチョ なら p × goldMachoMul（2）
```

- **マッチョ 2 倍 は 上限 8% の あと に かける**。マッチョ の 上限 は **16%**（`goldCap` 0.08 × 2）。マッチョ は かならず ひよこ から 小屋 で そだつ（`raised`）ので、むし 0 で 4%×2 = 8%、むし 80 ぴき で 8%×2 = **16%**。ふつう の 子 は 今 の まま（野原 1〜5%、そだてた 4〜8%）。（「上限 の あと に 2 倍」に した。上限 の 前 だと むし を あげた マッチョ が ふつう と 同じ 8% に なり、2 倍 が 消える ため。**PO 確認**）
- **30 こ の かならず**: 70 を こえて いる とき に うんだ 金 で ない たまご だけ 数える。**70 以下 で うんだ たまご は `goldMiss` を かえない**（ふやさない・0 に しない）。70 以下 の とき は `goldMiss` が 30 でも 金 に ならない（こえた あと の 最初 の たまご が かならず 金）。マッチョ でも 30 こ の まま（2 倍 で 15 こ に は しない）。（**PO 確認**）
- 乱数 は 今 と 同じく **いつも 1 つ つかう**（70 以下 でも 1 つ すてる。ほか の くじ が ずれない）。
- LIVE-2 §2.8 の「マッチョ だけ の 上乗せ は 無い」・§2.10 の「金 の 確率 は 同じ」と `src/animals/gold.ts` の 説明 は この 決定 で かわる（開発 の PR で 説明 を 直し、LIVE-2 に「GOLD-1 で かわった」と 1 行 足す）。

### 4.6 はらぱんみみず の あげかた
