## 0. 要点（さきに読む所）

1. **1 つの世界を 2 人で**。コントローラー 2 本（同じ機種）。1P はキーボード＋マウスも今までどおり使える。ネットはなし。
2. **2 本目のコントローラーで ＋ を押すと 2P が参加**。2P は 1P の横に「ぽん」と出る。やめるときは 2P のもちもの画面の「やめる」を長押し。
3. **2P が いる あいだは ずっと 左右に 分ける**（左 1P・右 2P、入れかえない。2 人が 近くても 遠くても 同じ）。1P も 2P も 自分の カメラを 自分で 回せる（**1P と 2P の 動かし方は 同じ**）。2P が いない ときは 今までどおり 1 人の 全面。（1.7 までの「近いときは 1 画面・ルーペ・色の 2 段階・ゆれ止めの 幅」は **1.8 で やめた**。オーナー yuzu 2026-11-06 16:14「2P側が操作しにくすぎるので」）。相手が 自分の 画面の 外に いる ときは、自分の 半分の ふちに **相手の 色の 矢印** が 出て 相手の いる 向きを さす（ルーペの かわり。オーナー 16:17。§2.4）。
4. 2P が 参加して 画面が 分かれる 時だけ 小さな「しゅっ」。やめて 1 画面に もどる 時は 鳴らさない。
5. 画面の上に **距離メーター「▼P1 ━━━ ▼P2」**。2 人が離れるほど棒が伸びる（「どれくらい はなれたか」が 分かる）。
6. 離れすぎを止める仕組みは **入れない**。重くなったら、2P が いる あいだ 影を切る・遠くを描かないなどで軽くする。
7. **持ち物とレベルは別々、たんすと実績は共有、仲間には当たらない**。2P が倒れたら 1P の横に戻る。
8. **最初に渡す形（段階 1）で、2 人でちゃんと遊べる**: 2P は歩く・掘る・置く・戦う・自分のもちもの。画面は 左右分割・距離メーターまで そろえて渡す（見えない壁などの「とちゅうの形」は遊ぶ人に出さない）。本・建築士さん・とりごや・たんす・つくる・そうびは 1P だけ（段階 2・3 で足す）。作る途中で「画面を 2 回描く試作」で重さを測る。
9. **1P・2P の コントローラーは せっていで えらぶ**（作業 2.5、§2.7）: せってい → コントローラー → 「つかう コントローラー」。いま つながっている 物から えらび、**えらんだ コントローラーの ＋ で 決まる**。同じ 物を 決めると 自動で 入れかえ、ボタンを おすと 光る。キーボード・マウスは いつも 1P。この 機械に おぼえる。
10. **【段階 2】2 人の ときの もちもの画面は 2 人用**（段階 2 の はじめ、§3.3。オーナー 2026-11-06 20:39・20:58）: 1P も 2P も、1 人の ときと 同じ 中身（もちもの・そうび・つくる）を **自分の 側の 半分**（1P 左・2P 右）に 出す。もう 1 人は 止まらず 遊びつづける。1 人の ときは 今の 全面の まま。作業 3 は 今の 形（2P は 小さい パネル。1P は §2.6・AC84）。

## 1. ねらい（りっくんがどう楽しむか）

- パパや兄弟と **同じ世界で、同時に** 掘ったり戦ったりできる。「こっちにきて！」「みつけた！」が生まれる。
- 2 人が **それぞれ好きな所へ行ける**。はじめから 自分の 半分の 画面が あるので、近くても 遠くても 困らない。2P も 1P と 同じ 動かし方（自分の カメラ）。
- 画面の ようすが 遊んでいる とちゅうで かわらない（かわるのは 参加・やめる の 時だけ）。2 人の はなれぐあいは メーターの 棒の 長さで 分かる。
- 持ち物は自分の物。**たんすに入れてあげる**（段階 2）ことで「わたす」遊びができる。
- 仲間には攻撃が当たらないので、けんかにならない。

## 2. 遊び方（プレイヤーから見た動き）

### 2.1 参加する

1. 1P がふだんどおり遊んでいる（キー＋マウス、または 1 本目のパッド）。
2. 2 本目のパッドをつなぐ。画面の右下に小さく「＋で さんか」（ひらがな＋ ＋ボタンの絵）が出る（3 秒、またはボタンを押すまで）。出るのは **2P の 候補**（§2.7。その ＋ で 参加できる パッド）が 0 から 1 に なった とき だけ。候補が ない（つながっているのが 1P の 物だけ・決めた 2P の 番号が つながっていない。3 本目は 候補に ならない）ときは 出ない。2P が いる ときは 出さない。**世界が 止まっている あいだ**（せってい画面・本・案内画面など）は 出さず、その あいだに 候補が 0 から 1 に なったら、**世界が 動きだした ステップから 3 秒** 出す。止まっている あいだの ＋ は 参加に ならない（今の まま。1P の パッドの ＋ は メニューの 操作、2P の 候補の ＋ は 何も しない）。作業 3 から ふつうの URL で 出る。
3. 2 本目のパッドで **＋** を押す → 2P が 1P の右横（1 マスあけた空いている所）に「ぽん」と出る。2P の色の光と短い音（参加は 1 回きりのお祝い。`docs/fun.md` の小さな達成）。
4. 画面が 左右に 分かれ（§2.4）、2P のホットバーとハートが右半分の下に出る。距離メーターが上に出る。

- どのパッドが 1P・2P か: **せっていの「つかう コントローラー」で 決める**（§2.7）。決めるまでは 番号の 小さい 物が 1P・つぎが 2P。（作業 2 までの「最初に使った 1 本が 1P・1P でない方が 2P」→ 作業 2.5 §2.7 で変わった）
- パッドが 1 本だけのとき: 2P がいなければ、そのパッドは 1P（§2.7 の「1 本のときの かわり」）。1 本で 2P を動かしたいときは、その 1 本を 2P に 決める（1P は パッドなし＝キーボードだけ）。
- 2P がはじめて参加した世界では、2P の持ち物は **からっぽ**（新しい世界の 1P と同じ）。前に参加したことのある世界では、前の持ち物で始まる（§6）。

### 2.2 やめる・はずれる

| できごと | どうなる |
|---|---|
| 2P のもちもの画面の「やめる」を **2 秒長押し** | 2P が「ぽん」と消える。持ち物はセーブに残る。画面は 1 人用（全面）に戻る |
| 2P のパッドの電池切れ・ぬけた | 2P の入力を全部はなす（歩きっぱなしにしない）。2P はその場で止まり、頭の上に「？」。そのあいだ妖怪は 2P をねらわない。つなぎ直して何か押せば続きから |
| ぬけたまま 60 秒 | 自動で「やめる」と同じ |
| 1P のパッドがぬけた | GAMEPAD-1 のまま（キーがあれば続く）。2P は 1P にならない（段階 1） |

- **ぬけたときの表示**: 2P の側（右半分の中央）に、パッドの絵と「コントローラーを つないでね」。2P の頭の上に「？」。つなぎ直してどれかのボタンを押すと消える。
- **「やめる」の長押し**: ボタンに「ながおし で やめる」と書き、押しているあいだゲージが左から右へたまる（2 秒で満タン）。とちゅうではなすとゲージはすっと 0 に戻り、何も起きない。段階 1 は 2P の 小さい パネル（`duo-inv-p2`）が 開いている あいだ `confirm`（けってい）を 押しつづけると たまる（今の 形）。【段階 2】2 人用の もちもの画面（§3.3）では、いちばん 下の「やめる」を 十字で えらんで `confirm` を 押しつづける ときだけ たまる。
- **まちがえてやめたとき**: もう一度 2P のパッドで ＋ を押せば、すぐ参加しなおせる。持ち物はやめた時に保存してあるので、そのまま戻る（失うものはない）。

### 2.3 2 人のときの画面（1.8: ずっと 左右）

| ようす | いつ | 見え方 |
|---|---|---|
| **1 人の 全面** | 2P が いない | 今までどおり（1P が 全面） |
| **左右に分割** | 2P が 参加している あいだ **ずっと**（2 人が 近くても 遠くても。距離では かわらない） | 左半分 1P、右半分 2P。まん中に細い線。ななめにはしない |

- 左右の割り当ては **いつも 1P 左・2P 右**。キャラが逆にいても入れかえない（混乱をふせぐ）。
- 1P と 2P は **同じ 決まり**で 遊ぶ（自分の カメラ・自分の 半分・同じ 動かし方。オーナー「すべての仕様が1Pと2Pでおなじになってほしい」）。
- ようすが かわるのは **2P の 参加・やめる（自動で やめる・読みなおしも）の 時だけ**。
- 1.7 までの「1 画面（1P が真ん中・引いた カメラ）」「ルーペ（丸わくに 2P を 映す）」「ルーペの わくの 色の 3 段」「距離で 分かれる・もどる（ゆれ止めの 幅）」は **1.8 で やめた**。ルーペは **相手の 向きの 矢印** に かえた（オーナー 16:17。§2.4）。
- 相手の いる 所は、**矢印**（向き。§2.4）と **距離メーター**（はなれぐあい。§9.4）で 分かる。

### 2.4 切りかわるときの見せ方

| 切りかえ | 見せ方（ふつう） | 動きを減らす設定（`prefers-reduced-motion`） |
|---|---|---|
| 2P が 参加 → 分割 | 2P が「ぽん」と 出た ステップから、まん中に上から線がおりて、右半分が 2P の景色になる（約 0.4 秒）。小さな「しゅっ」の音 | 0.15 秒のふわっと切りかえ（音は 同じ） |
| 2P が やめる（長押し・ぬけて 60 秒）→ 1 人の 全面 | 右半分がちぢんで消え、1P の 景色が 全面に もどる（約 0.4 秒）。音は なし（やめるの「ぽん」だけ） | 0.15 秒のふわっと切りかえ |

- 読みなおし（タイトルへ もどる・よみこむ）で 2P が やめる ときは、`location.reload()` の 直前なので 見せ方は ない（§2.6）。
- 強い点滅はしない。白く光らせない。
- **「しゅっ」（`duoSplit`。作り方は §3.4）は 2P が 参加して 左右に 分かれる 時だけ 1 回**。やめて 1 画面に もどる 時・距離が かわった 時は 鳴らさない。動きを 減らす 設定でも 音は 鳴らす（音は 動きでは ないので）。参加は「やめる」の 長押しの あとに しか 起きないので、くり返し 鳴る ことは ない。
- 1.7 までの「1 画面 ⇔ ルーペ ⇔ 分割」の 見せ方・色の 段の 変わり方・ようすの 1 秒の 待ち（ゆれ止め）は **1.8 で やめた**（距離で ようすが かわらないので いらない）。

#### 相手の 向きの 矢印（1.8。ルーペの かわり。オーナー 16:17）

- **何**: 1P の 半分には 2P を さす 矢印、2P の 半分には 1P を さす 矢印（どちらも 同じ 決まり）。形は 頭の 上の ▼ と 同じ 三角を 相手の 方へ 向けた 物（先が 相手を さす）＋ ねもとに 丸バッジ「P1」「P2」（メーターと 同じ 形）。色は **相手の 色**（`DUO_COLORS`。1P の 画面の 矢印は 2P の むらさき、2P の 画面の 矢印は 1P の ライム）、こい 2px ふち `--rk-bg-900`。HTML の 重ね（3D で 描かない）。
- **出る**: 相手の 体の 中心が、自分の カメラで 見て **自分の 半分の 内側 90% の 外**（うしろに いる・かべの 向こうで 画面の 外 も ふくむ）に 0.3 秒（18 ステップ）つづいた とき。かべに かくれていても 画面の 内側に 映る 所なら 出さない（見えて いなくても 方向は 合っている ため）。
- **消える**: 相手の 体の 中心が 自分の 半分の **内側 80% の 中** に 0.3 秒（18 ステップ）入った とき、または 2 人の 距離が **4 マス 以下** に なった とき（すぐ 横・うしろで 見えなくても、近いので いらない。その ステップで 消す）。2P が いない・倒れて 戻る までの あいだの 相手・パッドが ぬけた 2P も ふつうに さす（倒れた 人は 戻った 先を さす）。
- **向き**: 自分の 半分の 中心から 見た 相手の 方向。相手が カメラの 前なら 画面に 映した 位置の 方、**うしろなら 左右を そのまま にして 下向き**（カメラの 向きから 右うしろ なら 右下を さす）。角度は 画面の 上を 0°・時計回り。
- **置く所**: 自分の 半分の 中心から その 向きに のばした 線が、半分の ふちから 16px 内側の わくに 当たる 所。ただし **下の 22%（ホットバー）・上の 12%（メーター・お知らせ）・まん中の 線から 16px** には かけない（その 中に 入る ときは かからない 所まで ずらす。向きは かえない）。
- **大きさ**: 三角の 高さ ＝ 画面の 高さの 5%（800 で 40px、いちばん 小さくて 32px）。バッジは メーターと 同じ 大きさ。
- **見せ方**: 出る・消えるは ふわっと（約 0.2 秒）。動きを 減らす 設定では すぐ。点滅しない。音は なし（くり返すので）。動いている あいだ 位置と 向きは 毎コマ 追う。
- **重さ**: HTML の 重ねなので 描画回数・三角形は ふえない（ルーペの 2 回目の 描画が なくなる）。
- 切りかえの途中は遊びを止めない（ヒットストップ・入力はそのまま）。

### 2.5 2P の動かし方

- ボタンは GAMEPAD-1 §3.3 の表と同じ（ZR ほる・こうげき、ZL おく、L/R ホットバー、Y もちもの…）。
- **いつも 1P と 同じ 動かし方**（1.8）: 2P は 自分の 半分の 画面の 自分の カメラを 右スティックで 回す（1 人のときと同じ）。左スティックは 2P の カメラの 向きで 歩く。ねらいは 2P の カメラから（右半分の 中央に ＋マーク。§3.1）。
- 参加した 瞬間の 2P のカメラの向きは、**1P の カメラの 向きと 同じ** にする（2 人が 同じ 方を 見て 始まる）。
- 1.7 までの「1 画面・ルーペの ときは 1P の カメラで、2P は 画面の 向きで 歩く」「分割 → 1 画面に 戻った ときの 向き」は **1.8 で やめた**（2P が 操作しにくすぎる。オーナー 16:14）。
- 1P はキーボード＋マウス、または 1 本目のパッド。どちらも今までどおり。

### 2.6 いっしょに遊ぶ決まり

| こと | 決まり |
|---|---|
| 仲間への攻撃 | 当たらない（刀も弓もすりぬける。ダメージ 0、のけぞりなし） |
| 体どうし | ぶつからない（重なってよい） |
| 同じブロックを 2 人で掘る | 先に掘り終わった方がこわす。もう 1 人の途中までの分は 0 に戻る |
| ブロックを置く | 自分の体のほか、**仲間の体のある所にも置けない**（はさまらないように） |
| 落ちている物 | 先にふれた人の持ち物へ。いっぱいなら、もう 1 人がひろえる |
| 2P が倒れた | 2P の画面（右半分）に「たおれちゃった」。3 秒後に **1P の横に戻る**（ハート満タン）。おとしもの袋は 1P と同じ決まり（M3 §2.10） |
| 1P が倒れた | 今の 1P の決まりのまま（倒れた画面は 1P 側だけ）。2P は遊び続ける |
| 1P が倒れている間に 2P も倒れた | 2P は 1P が起きたあと、1P の横に戻る |
| 1P が本・建築士さんの画面を開いた | 今のとおり世界が止まる。2P の側に「ちょっと まってね」 |
| もちもの画面を開いた | 2P の パネル（段階 1 の 小さい パネル）を 開いても **世界は 止めず、時間も ゆっくりに しない**（1P が 遊んでいるので）。**1P の もちもの画面（全面）**は、2 人の とき **開いている あいだ 世界が 止まり、2P の 側に「ちょっと まってね」**（本・建築士さんと 同じ 決まり。yuzu 2026-11-06 21:03。作業 3 の 3d で 本番に 出す 時から）。1 人の ときは 今の まま（全面・0.25 倍）。【段階 2】1P・2P とも 2 人用の 半分の 画面に なり、止めない 形に かわる（§3.3） |
| 2P が つくる | 【段階 2】（段階 2 の はじめ。2 人用 画面と いっしょ）: 数えるのは 2P の もちもの だけ（たんすの 素材を 2P が つかうのは たんす（共有）と いっしょに 決める）。できた 物は 2P の もちものへ。2P の ログ（つくった・ひろった）は 出さない。段階 1 では 2P は つくれない |
| 朝・夜・天気 | 2 人で同じ |
| レベル（けいけんち） | **1 人ずつ別々**（オーナー決定）。妖怪を倒した人（さいごの 1 発を当てた人）にけいけんちが入る。レベルが上がったときのハート全回復も、その人だけ。2P のレベルのバーは 2P のホットバーの上に出す |
| 実績 | **2 人で同じ（共有）**（オーナー決定）。どちらがやっても世界の実績になる。レベルの実績は、どちらかのレベルが届いたら取れる。実績のお知らせは今のまま 1 つ（上の中央） |
| 1P が「さいしょから」・別の世界をえらぶ・セーブを読み直す | 2P も やめる。新しい世界では 2P はいない状態で始まる。**ゲームの 中で 起きるのは 次の 2 つ だけ**（さいしょから・別の 世界は タイトル画面で えらぶので、そこでは もう 2P は いない）。どちらも **2P を やめさせるのは 読みなおす（`location.reload()`）直前**。読みなおさない とき（「いいえ」・保存の 失敗・よみこみの 失敗）は 2P は のこる（AC71・AC72）: |

| 　└ おとなの「よみこむ」（ファイルから 読み直す） | 読み直す 直前に 2P を やめさせる。今の 世界は 書かない きまり（ファイルの 中身で かわる）なので、**今の 2P の 持ち物は 書かない**。ファイルに `p2` が あれば、それが つぎに 参加した ときの 2P の 持ち物。たしかめで「いいえ」・よみこみの 失敗の ときは 2P は のこる |

**作業 3a の 決め（PO 2026-11-06。#416 の テスト準備）**:

- 2P の「ふつうの こうげき」は **1P と 同じ ふつうの こうげき**（手に もっている 物で パンチ・刀の ふり・弓）。レジェンダリーの わざ・パリィは 段階 2。
- 2P も 妖怪から ダメージを 受ける。体当たり・こうげき・火の玉・およぎの ぺちん は、**その 妖怪が ねらっている 相手の 体の 箱**で 当たりを 見る。

- おとしもの袋は 1P と 同じ 決まり（M3 §2.10）で 3a に 入れる（上の「2P が倒れた」）。
- 妖怪の「近い方」（AC39・AC40）は **3 次元の 直線の 距離**で くらべる。

### 2.7 つかう コントローラー（段階 1・作業 2.5。#401）

せってい →「コントローラー」→ **つかう コントローラー** で、1P と 2P が つかう コントローラーを えらぶ（画面は §3.2、数は §9.6。オーナー 2026-11-06 14:57 の 直し §11.1-5）。

- **えらべる物は いま つながっている コントローラー だけ**。名前は つながった 並び（ブラウザの 番号＝`Gamepad.index` の 小さい 順）で「コントローラー 1」「コントローラー 2」…（ブラウザは ふつう 4 本まで）。名前は いつも 今の 並びで 出す（1 本 ぬけると 名前が つめて かわる）。0 本なら ボタンは なく「コントローラーを つないでね」。2 本は 同じ機種なので、名前（`id`）では 見分けない。
- **キーボードと マウスは いつも 1P**（えらぶ物に 出さない）。「なし」の ボタンは ない。
- **1P の パッドなし**: えらぶ ボタンでは なく、入れかえの 結果で 起きる（例: 1 本だけで それを 2P に 決めた）。そのとき 1P は キーボード・マウス だけ（前の `pad=2p` と 同じ）。
- **えらぶ 流れ**:
  1. 1P か 2P の 行で コントローラーの ボタンを おす（マウス・キー・1P の パッドの けってい）。
  2. その 行が **待ち** に なる: えらんだ ボタンが 点線の わくに なり、行の 下に「コントローラー 2 の ＋を おしてね」（＋の 絵つき）。
  3. **えらんだ その コントローラーで ＋** が おされたら 決まり。保存して **すぐ 効く**。ヘルプ帯に「きまったよ！」（音は 今の メニューの けってい音。新しい 音は 作らない）。
  - **決めた ＋ は だれの 操作にも ならない**（せってい画面を とじない・スタートメニューや もちものを 開かない・2P の 参加にも ならない）。
  - 待ちの あいだ、ほかの コントローラーの ＋ は 何も しない（決めない・メニューも とじない）。
  - **待ちを やめる**（何も かわらず 待ちが おわる）のは: せってい画面を 動かしている **1P の パッドの もどる（みぎの面 A）・十字**、**キーボードの Esc**、**マウスで ほかを おす**（ほかの ボタン・タブ・もどる・とじる）、えらんだ コントローラーが ぬけた、**15 秒**（固定ステップ 900 回）たった。えらんだ 物が 1P の パッド そのもの でも 同じ（その パッドの もどる・十字で やめる）。時間切れの ときは ヘルプ帯に「じかんぎれ。もういちど えらんでね」。
  - えらんだ コントローラーの ＋ 以外の ボタンは **光るだけ**。ただし えらんだ 物が 1P の パッドでも ある ときは、もどる・十字は 上の「待ちを やめる」が 先（光るのも する）。
  - マウスで べつの えらぶ ボタンを おすと 待ちは そちらに うつる（1P の パッドでは 十字で やめてから えらびなおす）。もう 決まっている 物を おしても 待ちに しない。
  - 15 秒の わけ: 待ちの あいだ ほかの ＋ が きかないので、わすれて 放っておいても すぐ もとに もどる ように。6 歳が コントローラーを 手に とって ＋ を おすには 足りる 長さ。
  - **すぐ 効く わけ**: ＋ を おした 人の 手に その コントローラーが あると 分かったので、すぐ 切りかえても まよわない（1.3 の「とじたとき」は、パッドで えらぶ とちゅうに その パッドが 1P で なくなるのを ふせぐ ためだったが、＋ の 確認で いらなくなった）。
- **入れかえ**: もう片方と 同じ コントローラーを 決めると、もう片方は **のこりの つながっている 1 本**（番号の いちばん 小さい 物）に、なければ **パッドなし** に 自動で かわる。1P と 2P が 同じ コントローラーに なる ことは ない。もう片方が 自動で かわった ときは **いつも** ヘルプ帯に「1P と 2P を いれかえたよ」（パッドなしに なった ときも 同じ。「きまったよ！」の かわりに 出す）。
- **えらばれていない コントローラー**（1P・2P の どちらでもない 物）は むし（§10 の 3 本目と 同じ）。ボタン確認画面に「つかっていない」と 出すのは 今回 やらない（§13）。
- **光る**: コントローラーの ボタン（十字・肩・＋−・スティックの おしこみ も）を おしている あいだと、はなして 0.5 秒（固定ステップ 30 回。§9.6）、1P・2P の 行の その コントローラーの ボタンが 光る（どれが コントローラー 1 か 分かる ように）。スティックを たおすだけ では 光らない（ドリフトで 光りっぱなしに ならないように）。光る 色は **今 その コントローラーで 動いている 人**（1P ライム・2P むらさき・だれも 動いていない 物は 白）。1 本のときの かわり（下）の 最中は、2P に 決めた 物でも ライム。点滅は しない。2P の コントローラーは せってい画面を うごかさず、光るだけ（＋ の 確認は べつ）。
- **おぼえる 所**: この 機械（ブラウザ）に 1 つ。世界ごと では ない（世界の セーブには 入れない）。決めた ときだけ 書く。キーと 形は §9.6。まだ 決めていない・読めない・JSON で ない・知らない 値・1P と 2P が 同じ 番号・localStorage が つかえない → **はじめの 動き**（下）。エラーは 出さず、こわれた 値は つぎに 決めるまで 書きかえない。
- **はじめの 動き**（まだ 決めていない とき）: 1P＝つながっている うちで 番号の いちばん 小さい 物、2P＝その つぎ（作業 2 までと 同じ）。
- **決めた あとの 動き**: 1P・2P は 決めた 番号の コントローラーを 読む。
  - 2P が パッドなし（まだ 決めていない・入れかえで なくなった）の ときは、1P で ない 番号の いちばん 小さい つながっている 物が 2P の 候補（その ＋ で 参加できる）。
  - 1P が パッドなし に 決まっている ときは、どの コントローラーも 1P を うごかさない（スタートメニューも ひらかない）。
- **パッドが 0 本**: 1P は キーボード・マウス。タブは「コントローラーを つないでね」と 小さく「つないだら ボタンを おしてね」（ブラウザは ボタンを おすまで パッドを 見せないため）。
- **1 本のときの かわり**: 2P が いない あいだ、1P に 決めた コントローラーが つながっていなくて 2P の 物だけ つながっていれば、**その コントローラーで 1P を うごかす**（1 人で あそべなく ならないように。その ＋ は スタートメニューで、参加には ならない）。1P の 物が つながったら、そのステップで かわりの 入力を 全部 はなして もとに もどる。1P が パッドなし に 決まっている ときは かわりを しない（その コントローラーは 2P 用）。2P が 参加したら かわりは おわる。
- **つなぎなおし**: 2P の コントローラーが ぬけたら §2.2 の まま（「コントローラーを つないでね」・60 秒で やめる）。もどるのは **決めた 番号に つながった 物で ボタンを おしたとき だけ**（1P の 物や ほかの 番号では もどらない。作業 2 までの「1P でない どれか」から 変わった）。**参加中に 1P の パッドが ぬけても、2P の パッドを 1P に しない**（かわりは 2P が いない ときだけ。§2.2 の「1P のパッドがぬけた」と 同じ）。2 本とも ぬいて 逆の じゅんに さすと 番号が 入れかわるので、つかう コントローラー で ボタンを おし、光るのを 見て 決めなおす（ヘルプ帯の 文に 書く）。
- **2P が 参加中に 決めたとき**（決めた ときに すぐ 効く。2P は やめない）:
  - 2P の コントローラーが かわった: そのステップで 2P の 入力を 全部 はなし、新しい 物の ボタンを 全部 はなしてから（決めた ＋ も ふくむ）2P の 操作に なる。スティックは はなさなくて よい（倒したままなら そのまま 歩く）。新しい 物が つながっていなければ「つなぎなおし待ち」（`padLost`。§2.2 の 表示と 60 秒）。
  - 1P の コントローラーが かわった: 1P の パッドの 入力を 全部 はなす（キー・マウスは そのまま）。新しい 物も ボタンを 全部 はなしてから（スティックは はなさなくて よい）。せってい画面は、そのあと 新しい 1P の 物で うごく。
  - 1P が パッドなし に なった: 1P は キーボード・マウス だけ。ロックは キーボードの ときの 決まり（GAMEPAD-1 §2.4）に もどる。
  - かわらない 人は 何も 起きない。
- **いつ タブを 出すか**（作業 3 で 書きかえ）: **いつも 出す**（ふつうの URL でも。パッドが 0 本でも「コントローラーを つないでね」の 形で 出す）。保存してある 値も いつも 読む。作業 3 で 2P が ＋ で 参加できるように なるのと 同じ PR で 出す（決める 所だけ 先に 出て 2P が 出てこない、を 作らない）。作業 2.5 の あいだは `?duo=dev` の ときだけ 出し、ふだんは 保存を 読まず はじめの 動き だった（りっくんが とちゅうの 形を 見ない。§8）。
- **`?duo=dev&pad=2p` は なくす**: `pad=2p` は 読まない。パッドが 1 本しか ない ときの 開発は、つかう コントローラー で その 1 本を 2P に 決める（1P は パッドなしに なる）。テストは `duo.setPadChoice({ p1: null, p2: 0 })`（§12.0。＋ の 確認を とばす）。作業 3 から `setPadChoice` は ふつうの URL でも 効く（タブが いつも あるので、タブで 決めるのと 同じ 口）。作業 2.5 の あいだは ふつうの URL では false を 返し、保存も しなかった。
- **参加中の 1P の パッドは 固定**（作業 3。#409 の あとで 見つけた 直し）: 2P が 参加している あいだ、1P が 読む パッドは 参加した ときの 物の まま。保存が ない ときに 2P の パッドが まだ 決まっていない（パッドなしで 参加した）あいだも 同じ。1P の パッドが ぬけても ほかの パッドは 1P に ならない（1P は キー・マウスで 続け、ぬけた 物を つなぎなおすと また それで 動く）。ほかの パッドは 2P の 候補の まま（その ＋・スティックで 2P の パッドに 決まる）。参加中に 1P の パッドが かわるのは、つかう コントローラー で 決めた ときだけ。
- **待ちの あいだに はなした ＋**（作業 3。#409 の あとで 見つけた 直し）: 待ちの あいだ ＋ は 操作に しないが、**はなした ことは 読む**。待ちに なる 前から ＋ を 押していて 待ちの あいだに はなしても、＋ が 押しっぱなしに のこらない（そのあと ＋ を 1 回 押せば ふつうに 効く。2 回 押さなくて よい）。待ちの あいだに 押した ＋ は、待ちが おわった あとで はなしても 何も 起きない（今の まま）。

### 3.2 せっていの「つかう コントローラー」タブ（作業 2.5）

- 置く所: SETTINGS-1 §4 の 2 だん目（`data-screen="controls"`）の タブを **キーボード/マウス・ゲームパッド・つかう コントローラー**（`ctrl-tab-use`）の 3 つに する。つかう コントローラー は キーボード/マウス と 同じく **2 だん目の まま 中身が かわる**（3 だん目へは 行かない）。タブは 左右・十字で 移れる（今と 同じ）。
- 中身（`ctrl-panel-use`。上から）:

```
[ヘルプ帯]
だれが どれを つかう？                                      … 見出し 24px
 (1P)  [コントローラー 1 ✓] [コントローラー 2]               … use-p1-c1 / use-p1-c2 …
 (2P)  [コントローラー 1]   [コントローラー 2 ✓]             … use-p2-c1 / use-p2-c2 …
 [ふだん] キーボードと マウスは いつも 1P だよ               … use-note（16px 灰色）
 [待ち]   [＋の絵] コントローラー 2 の ＋を おしてね          … 同じ 所（20px、その人の 色の ふち）

 0 本の とき（2 行の ボタンの かわりに 1 つ）:
 [パッドの絵] コントローラーを つないでね                     … use-none
```

## 5. 世界を 2 か所読みこむとき

- 2P が 1P の近く（48 マスより近い）のあいだは、**今の輪 1 つ**（中心 1P、ふだんの大きさ `RING_FULL`）のまま。
- 2P が 48 マスより離れたら、**輪を 2 つ**（中心 1P と 2P）にする。そのとき 2 つとも **小さい輪**（`RING_SMALL` と同じ: 描く 4・光 5・生成 6・残す 8・捨てる 5 列）にする。32 マスより近づいたら 1 つ（ふだんの大きさ）に戻す（幅を持たせる）。
- **起動のとき 1 回だけの前提を外す**: いまは `setRing()` を起動で 1 回だけ呼び（#203）、`getRing()` の値を `ChunkStream`・メッシュ側・`R_DRAW` などの定数が前提にしている。遊んでいる最中に輪の大きさと中心の数が変わっても、読みこみ・光・メッシュ・捨てる が正しく動くようにする（定数の `R_*` を「今の輪」から読むものに直すかどうかは開発が決める）。
- **重なりは 1 回だけ数える**: 列は今と同じ列の番号（`colKey(cx, cz)`）で 1 つの集まりに入れる。ある列が「描く・光・生成・残す」のどれに入るかは、**2 つの中心からのチェビシェフ距離の小さい方** で決める。近い順の並び（`compareNear`）も小さい方の距離で並べる。だから 2 つの輪が重なる所の列は 1 つとして数えられ、2 回読みこまれない。
- **上限**: 持つ列の合計（重なりは 1 回）は、1 人のふだんの最大（441 列）の **1.35 倍（595 列）まで**。小さい輪 2 つが重ならないときで 17×17×2＝578 列なので入る。
- 輪が小さくなるときは、外になった列を **少しずつ** 捨てる（1 コマで全部捨ててカクっとしない。量は開発が決める）。
- 読みこみが追いつかないとき: その人は「読みこみ中」の今の決まり（VOX-D: 動かない・落ちない）で待つ。2P だけが待つときも 1P は遊べる。
- かすみ（霧）は輪 2 つのあいだ、描く範囲に合わせて近くする（遠くのふちが見えないように）。1.8 から 分割は 参加の 時に 起きるので、輪の 1⇔2 の 切りかえで かすみが 目立って かわらないよう、**2P が いる あいだは いつも 近い かすみ**に そろえる（§7.2。切りかえは 参加・やめるの 瞬間）。
- **見えない壁は作らない**。2P はどこまでも行ける（オーナー決定「離れすぎ防止なし」）。ただし §8 の「早く遊ばせたいとき」の仮の壁は、作業 2 までのあいだだけ使ってよい（オーナー OK 済み）。

## 6. セーブ

- 2P の分は **世界のセーブに 1 か所** 足す（例: `p2: { inventory, level }`。`level` は 1P の `level` と同じ形 `{ level, xp }`。段階 2 で `armor` も）。`p2` は足すだけのキーなので **セーブの版（`SAVE_VERSION`）は上げない**（上げると `validMeta` が古いセーブを読まなくなるため。PO 2026-11-06）。
- 実績は世界で 1 つ（今の `achievements` のまま）。2P の分を別に持たない。
- 2P の場所・向きは保存しない（次に参加したら 1P の横に出る）。ハートは満タンで始まる（1P の今の決まりと同じ）。
- 2P が一度も参加していない世界: `p2` はなし。古いセーブはそのまま読める（2P なしとして）。
- 2P が「やめる」→ その時点で 2P の持ち物を保存する。遊んでいる最中は 1P と同じ時間おきの保存に入る。
- たんす・ブロック・作物・妖怪の記録など世界の物は 1 つ（今のまま）。
- 2P が参加したことのある世界をキーボードだけで開いても、2P の持ち物は消えない。

## 7. 重さの測り方（クラウドに GPU はない）

時間（ms）で合否を決めない（#255）。描画回数・三角形・処理の仕事の数で、**同じテストの中で「1 人のとき」とくらべたふえ** を見る。本当の速さはオーナーの Mac の F3 で見る。

### 7.1 試作で先に測る（作業 2 の前）

段階 1 の作業 1 が終わったら、分割の本番（作業 2）を作る前に **「画面を 2 回描く試作」** で測る。

- 試作の名前は **`duo-proto`**（とりごやの `coop` と分ける）。試作のコードは `src/proto/duo/` に置き、試作だけの入口（例: `proto-duo.html`）か URL `?duoProto=1` で動かす。**本番のコード（`src/main.ts` など）から `src/proto/` を import しない**（eslint の `no-restricted-imports`。CLAUDE.md のきまり）。測り終わったら試作は消すか `src/proto/` に残すだけにする。

| 測る場面 | 内容 |
|---|---|
| A | 1 人（いまのまま）。同じシード・同じ場所・同じ向き |
| B | 1 画面＋ルーペ（大きい画面 1 回＋小さい丸 1 回） |
| C | 分割（左右に 1 回ずつ。2P は 1P から 60 マス、輪 2 つ）。**輪 2 つは試作の中で独自に作ってよい**（本番の §5 の作りを待たない。数を測れればよい） |
| D | C ＋軽くする工夫（§7.2）をぜんぶ入れた物 |

記録する数（`npm run perf` の形にそろえ、`perf-results/` に残す）: 描画回数（draw calls）、三角形、影の地図を描いた回数、持っている列の数、メッシュの数、1 ステップの更新の処理時間、1 コマの描画の処理時間（クラウドは目安。前後の比だけ見る）。

**決め方**: D が A の **描画回数 2.0 倍以下・三角形 1.8 倍以下・持つ列 1.35 倍以下** なら作業 2 へ進む。こえたら §7.2 の工夫を足すか、perf-engineer に相談してから進む。オーナーの Mac で C・D を遊んで、カクカクしないかを見てもらう（オーナー確認）。

### 7.2 軽くする工夫（2P が いる あいだ＝分割の あいだ。2P が やめて 1 人に 戻ったら 2 秒後に元へ）

効く順に試す（どれを入れるかは試作の数で決める）。

1. 影を切る（影の地図を描かない）
2. 遠くを描かない（小さい輪・かすみを近く）
3. ~~ルーペは 2 コマに 1 回だけ描きかえる~~（1.7 まで。1.8 で ルーペを やめた）
4. 画素の細かさを下げる（今は最大 2 倍 → 1.5 倍）
5. 小ブロックの細かい形を、近い所だけにする

- 工夫を入れる・外すときに画面が目立って変わる物（影・かすみ）は、分割の切りかえ（参加・やめる）と **同じ瞬間** に変える（別々に目立たせない）。
- 1.8 から 2P が いる あいだ ずっと 分割なので、工夫も ずっと 入る（重さは §9.9）。
