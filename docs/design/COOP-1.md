## 0. 要点（さきに読む所）

1. **1 つの世界を 2 人で**。コントローラー 2 本（同じ機種）。1P はキーボード＋マウスも今までどおり使える。ネットはなし。
2. **2 本目のコントローラーで ＋ を押すと 2P が参加**。2P は 1P の横に「ぽん」と出る。やめるときは 2P のもちもの画面の「やめる」を長押し。
3. **近いときは 1 つの画面**（1P が真ん中。カメラはふだんより少し引く）。2P が画面の外に出ると、はしに **ルーペ**（小さな丸わくに 2P を映す）。もっと離れると **左右に分割**（左 1P・右 2P、ずっと固定）。ルーペはふくらんで右半分になる。
4. **ルーペのわくの色が 2 段階で変わって**「もうすぐ分かれるよ」を知らせる（ふつう → 1 段目 → 2 段目 → 分割）。近づいてもすぐには戻らず、少し幅を持たせてゆれないようにする。
5. 画面の上に **距離メーター「▼P1 ━━━ ▼P2」**。2 人が離れるほど棒が伸び、真ん中の印をこえると分かれる。棒の色もルーペと同じ段の色。
6. 離れすぎを止める仕組みは **入れない**。重くなったら、分割のあいだだけ影を切る・遠くを描かないなどで軽くする。
7. **持ち物とレベルは別々、たんすと実績は共有、仲間には当たらない**。2P が倒れたら 1P の横に戻る。
8. **最初に渡す形（段階 1）で、2 人でちゃんと遊べる**: 2P は歩く・掘る・置く・戦う・自分のもちもの。画面は 1 画面・ルーペ・色の段・左右分割・距離メーターまで全部そろえて渡す（見えない壁などの「とちゅうの形」は遊ぶ人に出さない）。本・建築士さん・とりごや・たんす・つくる・そうびは 1P だけ（段階 2・3 で足す）。作る途中で「画面を 2 回描く試作」で重さを測る。
9. **1P・2P の パッドは せっていで えらぶ**（作業 2.5、§2.7）: せってい → コントローラー → 「ふたりあそび」。同じ パッドを えらぶと 自動で 入れかえ、ボタンを おすと その パッドの 行が 光る。この 機械に おぼえる（はじめは 1P＝パッド 1・2P＝パッド 2）。

## 1. ねらい（りっくんがどう楽しむか）

- パパや兄弟と **同じ世界で、同時に** 掘ったり戦ったりできる。「こっちにきて！」「みつけた！」が生まれる。
- 2 人が **それぞれ好きな所へ行ける**。くっついていなくても、画面が自然に分かれて困らない。
- 画面がいきなり変わってびっくりしないように、**ルーペの色とメーターで「もうすぐ分かれる」が先に分かる**。字が読めなくても色と棒の長さで分かる。
- 持ち物は自分の物。**たんすに入れてあげる**（段階 2）ことで「わたす」遊びができる。
- 仲間には攻撃が当たらないので、けんかにならない。

## 2. 遊び方（プレイヤーから見た動き）

### 2.1 参加する

1. 1P がふだんどおり遊んでいる（キー＋マウス、または 1 本目のパッド）。
2. 2 本目のパッドをつなぐ。画面の右下に小さく「＋で さんか」（ひらがな＋ ＋ボタンの絵）が出る（3 秒、またはボタンを押すまで）。
3. 2 本目のパッドで **＋** を押す → 2P が 1P の右横（1 マスあけた空いている所）に「ぽん」と出る。2P の色の光と短い音（参加は 1 回きりのお祝い。`docs/fun.md` の小さな達成）。
4. 2P のホットバーとハートが画面の右下に出る。距離メーターが上に出る。

- どのパッドが 1P・2P か: **せっていの「ふたりあそび」で えらぶ**（§2.7）。はじめは パッド 1 が 1P・パッド 2 が 2P。（作業 2 までの「最初に使った 1 本が 1P・1P でない方が 2P」→ 作業 2.5 §2.7 で変わった）
- パッドが 1 本だけのとき: 2P がいなければ、そのパッドは 1P（§2.7 の「1 本のときの かわり」）。1 本で 2P を動かしたいときは 1P＝なし（キーボードだけ）にする。
- 2P がはじめて参加した世界では、2P の持ち物は **からっぽ**（新しい世界の 1P と同じ）。前に参加したことのある世界では、前の持ち物で始まる（§6）。

### 2.2 やめる・はずれる

| できごと | どうなる |
|---|---|
| 2P のもちもの画面の「やめる」を **2 秒長押し** | 2P が「ぽん」と消える。持ち物はセーブに残る。画面は 1 人用に戻る（カメラの引きも戻る） |
| 2P のパッドの電池切れ・ぬけた | 2P の入力を全部はなす（歩きっぱなしにしない）。2P はその場で止まり、頭の上に「？」。そのあいだ妖怪は 2P をねらわない。つなぎ直して何か押せば続きから |
| ぬけたまま 60 秒 | 自動で「やめる」と同じ |
| 1P のパッドがぬけた | GAMEPAD-1 のまま（キーがあれば続く）。2P は 1P にならない（段階 1） |

- **ぬけたときの表示**: 2P の側（1 画面・ルーペなら右下の 2P のホットバーの上、分割なら右半分の中央）に、パッドの絵と「コントローラーを つないでね」。2P の頭の上に「？」。つなぎ直してどれかのボタンを押すと消える。
- **「やめる」の長押し**: ボタンに「ながおし で やめる」と書き、押しているあいだゲージが左から右へたまる（2 秒で満タン）。とちゅうではなすとゲージはすっと 0 に戻り、何も起きない。
- **まちがえてやめたとき**: もう一度 2P のパッドで ＋ を押せば、すぐ参加しなおせる。持ち物はやめた時に保存してあるので、そのまま戻る（失うものはない）。

### 2.3 2 人のときの画面（3 つのようす）

| ようす | いつ | 見え方 |
|---|---|---|
| **1 画面** | 2P が画面に入っていて、2 人が近い | 1P が真ん中。カメラはふだんより引く（2 人とも入りやすい） |
| **1 画面＋ルーペ** | 2P が画面の外に出た（でもまだ分かれる距離ではない） | 画面のはし、2P のいる方向に丸わく。中に 2P とそのまわり |
| **左右に分割** | 2 人がもっと離れた | 左半分 1P、右半分 2P。まん中に細い線。ななめにはしない |

- ルーペのわくの色: 2 人の距離で 3 段（ふつう → 1 段目 → 2 段目）→ 分割（§9.2）。メーターの棒も同じ色。
- 2P が画面に入っていても離れていれば（遠くに見えている）、ルーペは出ないが、メーターの色は変わり、分ける距離になれば分かれる。
- 左右の割り当ては **いつも 1P 左・2P 右**。キャラが逆にいても入れかえない（混乱をふせぐ）。

### 2.4 切りかわるときの見せ方

| 切りかえ | 見せ方（ふつう） | 動きを減らす設定（`prefers-reduced-motion`） |
|---|---|---|
| 1 画面 → ルーペ | 丸わくが小さく出て、ふわっと大きくなる（約 0.2 秒） | すぐ出す |
| ルーペ → 1 画面 | 丸わくがしぼんで消える（約 0.2 秒） | すぐ消す |
| ルーペ → 分割 | **ルーペがふくらんで右半分になる**（約 0.4 秒）。小さな「しゅっ」の音 | 0.15 秒のふわっと切りかえ |
| 1 画面（ルーペなし）→ 分割 | まん中に上から線がおりて、右半分が 2P の景色になる（約 0.4 秒） | 同上 |
| 分割 → 1 画面 | 右半分が 2P のいる方へちぢみ、ルーペか 2P 本人に重なって消える（約 0.4 秒） | 同上 |
| ルーペの色の段が変わる | わくの色がすっと変わる（約 0.3 秒）。音はなし（くり返すので控えめ） | すぐ変える |

- 強い点滅はしない。白く光らせない。
- 画面のようす（1 画面・ルーペ・分割）を切りかえたあと **1 秒は次のようすの切りかえをしない**（ゆれ止め。参加・やめるは別）。ルーペの **色の段にはこの待ちはない**（色は §9.2 の上りと下りの幅だけでゆれを止める）。
- 切りかえの途中は遊びを止めない（ヒットストップ・入力はそのまま）。

### 2.5 2P の動かし方

- ボタンは GAMEPAD-1 §3.3 の表と同じ（ZR ほる・こうげき、ZL おく、L/R ホットバー、Y もちもの…）。
- **1 画面・ルーペのとき**: カメラは 1P のもの。2P の左スティックは **画面の向きで** 歩く（上に倒すと画面の奥へ）。2P は歩く方を向く。右スティックは 2P の向き（左右）とねらいの上下だけを変え、カメラは動かさない。2P のねらうブロックは **2P の色のわく** で光る（＋マークは 1P だけ）。
- **分割のとき**: 2P は自分のカメラを右スティックで回す（1 人のときと同じ）。分割した瞬間の 2P のカメラの向きは、それまでの画面の向きと同じにする（左スティックの向きがひっくり返らない）。
- **分割 → 1 画面に戻ったとき**: 2P が左スティックを倒したままなら、はなすまで前の向きのまま歩く（急に向きが変わらない）。
- 1P はキーボード＋マウス、または 1 本目のパッド。どちらも今までどおり。

### 2.6 いっしょに遊ぶ決まり

| こと | 決まり |
|---|---|
| 仲間への攻撃 | 当たらない（刀も弓もすりぬける。ダメージ 0、のけぞりなし） |
| 体どうし | ぶつからない（重なってよい） |
| 同じブロックを 2 人で掘る | 先に掘り終わった方がこわす。もう 1 人の途中までの分は 0 に戻る |
| ブロックを置く | 自分の体のほか、**仲間の体のある所にも置けない**（はさまらないように） |
| 落ちている物 | 先にふれた人の持ち物へ。いっぱいなら、もう 1 人がひろえる |
| 2P が倒れた | 2P の画面（分割なら右半分、1 画面なら右下の小わく）に「たおれちゃった」。3 秒後に **1P の横に戻る**（ハート満タン）。おとしもの袋は 1P と同じ決まり（M3 §2.10） |
| 1P が倒れた | 今の 1P の決まりのまま（倒れた画面は 1P 側だけ）。2P は遊び続ける |
| 1P が倒れている間に 2P も倒れた | 2P は 1P が起きたあと、1P の横に戻る |
| 1P が本・建築士さんの画面を開いた | 今のとおり世界が止まる。2P の側に「ちょっと まってね」 |
| もちもの画面を開いた | 2 人のときは **時間をゆっくりにしない**（もう 1 人が遊んでいるので） |
| 朝・夜・天気 | 2 人で同じ |
| レベル（けいけんち） | **1 人ずつ別々**（オーナー決定）。妖怪を倒した人（さいごの 1 発を当てた人）にけいけんちが入る。レベルが上がったときのハート全回復も、その人だけ。2P のレベルのバーは 2P のホットバーの上に出す |
| 実績 | **2 人で同じ（共有）**（オーナー決定）。どちらがやっても世界の実績になる。レベルの実績は、どちらかのレベルが届いたら取れる。実績のお知らせは今のまま 1 つ（上の中央） |
| 1P が「さいしょから」・別の世界をえらぶ・セーブを読み直す | 2P も一度やめる（2P の持ち物を保存してから）。新しい世界では 2P はいない状態で始まる |

### 2.7 コントローラーの わりあて（段階 1・作業 2.5。#401）

せってい →「コントローラー」→ **ふたりあそび** で、1P と 2P が つかう パッドを えらぶ（画面は §3.2、数は §9.6）。

- **パッドの 番号**: ブラウザの パッドの 並び（`navigator.getGamepads()` の 場所＝`Gamepad.index`）の 0 ばんが **パッド 1**、1 ばんが **パッド 2**。2 ばんから あとは 3 本目（§10 の とおり むし）。2 本は 同じ機種なので、名前（`id`）では 見分けない。
- **えらべる物**: 1P＝パッド 1／パッド 2／なし（キーボードだけ）。2P＝パッド 1／パッド 2。**キーボードと マウスは いつも 1P**（えらぶ物に 出さない）。
- **はじめの 値**: 1P＝パッド 1、2P＝パッド 2（作業 2 までの「番号の 小さい方が 1P」と ふだんは 同じ 動き）。
- **入れかえ**: もう片方と 同じ パッドを えらぶと、もう片方は **のこりの パッド** に 自動で かわる（例: 1P＝パッド 1・2P＝パッド 2 で 1P に パッド 2 → 2P は パッド 1）。1P＝なし の ときは ぶつからないので 入れかえない。1P と 2P が 同じ パッドに なることは ない。もう片方が 自動で かわった ときは **いつも** ヘルプ帯に「1P と 2P の パッドを いれかえたよ」（どの 組から でも。かわらなかった ときは 出さない）。
- **えらばれていない パッド**（1P＝なし の ときの もう 1 本）は 3 本目と 同じ あつかい（むし）。ボタン確認画面に「つかっていない」と 出すのは 今回 やらない（§13）。
- **光る**: パッド 1・2 の 行は、その パッドの ボタン（十字・肩・＋−・スティックの おしこみ も）を おしている あいだと、はなして 0.5 秒（固定ステップ 30 回で 数える。§9.6）光る。スティックを たおすだけ では 光らない（ドリフトで 光りっぱなしに ならないように）。行の 札（1P／2P／つかわない）と 光る 色は **今 その パッドで 動いている 人**（1P ライム・2P むらさき・だれも 動いていない パッドは 白）。えらびと ちがう ことが ある: 1 本のときの かわりの 最中は、2P に えらんだ パッドでも 札は 1P・光るのは ライム。点滅は しない。どちらの パッドでも 光る（2P の パッドは せってい画面を うごかさず、光るだけ）。
- **「つながっていないよ」**: その 番号に パッドが ない 行は「つながっていないよ」（灰色）と、小さく「つないだら ボタンを おしてね」（ブラウザは ボタンを おすまで パッドを 見せないため）。つながっていない パッドも えらべる（あとで つなぐ 用）。
- **いつ 効くか**: えらぶと すぐ 保存。ゲームに 効くのは **せってい画面が とじる すべての 時**（せってい画面が 開いている から 開いていない に なった 時＝`isOpen()` が false に なった 時。とじる・外を クリック・＋・Esc・スタートメニューごと とじる・タイトルへ もどる など、とじ方は とわない）。開いている あいだは 前の 1P の パッドで せってい画面を うごかせる（パッドで えらんでいる とちゅうに、その パッドが 1P で なくなって うごかせなくなるのを ふせぐ）。
- **おぼえる 所**: この 機械（ブラウザ）に 1 つ。世界ごと では ない（世界の セーブには 入れない）。キーと 形は §9.6。読めない・JSON で ない・知らない 値・`p1` と `p2` が 同じ・localStorage が つかえない → **はじめの 値で 動く**。エラーは 出さず、こわれた 値は つぎに えらぶまで 書きかえない。
- **パッドが 0 本**: 1P は キーボード・マウス。パッドの 行は 2 つとも「つながっていないよ」。
- **パッドが 1 本だけ（1 本のときの かわり）**: 2P が いない あいだ、1P の パッドが つながっていなくて 2P の パッドだけ つながっていれば、**その パッドで 1P を うごかす**（1 人で あそべなく ならないように。その ＋ は スタートメニューで、参加には ならない）。1P の パッドが つながったら、かわりの パッドの 入力を 全部 はなして もとに もどる。1P＝なし の ときは かわりを しない（その パッドは 2P 用。前の `pad=2p` と 同じ）。2P が 参加したら かわりは おわり、2P は えらんだ 番号の パッドだけ。
- **つなぎなおし**: 2P の パッドが ぬけたら §2.2 の まま（「コントローラーを つないでね」・60 秒で やめる）。もどるのは **えらんだ 番号に つながった パッドで ボタンを おしたとき だけ**（1P の パッドや 3 本目では もどらない。作業 2 までの「1P でない どれか」から 変わった）。2 本とも ぬいて 逆の じゅんに さすと 番号が 入れかわるので、そのときは ふたりあそび で ボタンを おし、光る 行を 見て えらびなおす（ヘルプ帯の 文に 書く）。
- **2P が 参加中に かえたとき**（とじた ときに 効く。2P は やめない）:
  - 2P の パッドが かわった: そのステップで 2P の 入力を 全部 はなし、新しい パッドの ボタンを 全部 はなしてから 2P の 操作に なる（押しっぱなしで 急に 動かない。スティックは はなさなくて よい。倒したままなら はなしたあとの ステップから そのまま 歩く）。新しい パッドが つながっていなければ「つなぎなおし待ち」（`padLost`。§2.2 の 表示と 60 秒）。
  - 1P の パッドが かわった: 1P の パッドの 入力を 全部 はなす（キー・マウスは そのまま）。新しい パッドも ボタンを 全部 はなしてから（スティックは はなさなくて よい）。
  - 1P＝なし に した: 1P は キーボード・マウス だけ。ロックは キーボードの ときの 決まり（GAMEPAD-1 §2.4）に もどる。
  - かわらない 人は 何も 起きない。
- **いつ タブを 出すか**: 2P が 参加できる ときだけ（作業 3 までは `?duo=dev` の とき、作業 3 から いつも）。出ない ときは 保存してある 値を 読まず、**はじめの 値で 動く**（りっくんが とちゅうの 形を 見ない。§8）。
- **`?duo=dev&pad=2p` は なくす**: `pad=2p` は 読まない。パッドが 1 本しか ない ときの 開発は、ふたりあそび で 1P＝なし・2P＝パッド 1 に する（テストは `duo.setPadChoice`。§12.0。ふつうの URL では `setPadChoice` は false を 返し、保存も しない）。

## 3. 画面・見た目

- 文字（ひらがな・カタカナ。漢字はふりがな付き）: 「＋で さんか」「やめる」（長押しのゲージ付き）「たおれちゃった」「ちょっと まってね」「コントローラーを つないでね」。「P1」「P2」は記号として使う（色と ▼ でも分かる）。
- 色・形（オーナー決定）: 
  - **ルーペの段の色**: ふつう＝白 → 1 段目＝黄 → 2 段目＝オレンジ（仮の色。赤は「ダメージ」と混ざるので使わない）。最後の色あいはアートの 3 案からオーナーが選ぶ。
  - **1P・2P の色**: アートの 3 案からオーナーが選ぶ（キャラ頭上の ▼、メーターの ▼、ホットバーのふち、ねらいのわく、ルーペの 2P 側に使う）。

## 5. 世界を 2 か所読みこむとき

- 2P が 1P の近く（48 マスより近い）のあいだは、**今の輪 1 つ**（中心 1P、ふだんの大きさ `RING_FULL`）のまま。
- 2P が 48 マスより離れたら、**輪を 2 つ**（中心 1P と 2P）にする。そのとき 2 つとも **小さい輪**（`RING_SMALL` と同じ: 描く 4・光 5・生成 6・残す 8・捨てる 5 列）にする。32 マスより近づいたら 1 つ（ふだんの大きさ）に戻す（幅を持たせる）。
- **起動のとき 1 回だけの前提を外す**: いまは `setRing()` を起動で 1 回だけ呼び（#203）、`getRing()` の値を `ChunkStream`・メッシュ側・`R_DRAW` などの定数が前提にしている。遊んでいる最中に輪の大きさと中心の数が変わっても、読みこみ・光・メッシュ・捨てる が正しく動くようにする（定数の `R_*` を「今の輪」から読むものに直すかどうかは開発が決める）。
- **重なりは 1 回だけ数える**: 列は今と同じ列の番号（`colKey(cx, cz)`）で 1 つの集まりに入れる。ある列が「描く・光・生成・残す」のどれに入るかは、**2 つの中心からのチェビシェフ距離の小さい方** で決める。近い順の並び（`compareNear`）も小さい方の距離で並べる。だから 2 つの輪が重なる所の列は 1 つとして数えられ、2 回読みこまれない。
- **上限**: 持つ列の合計（重なりは 1 回）は、1 人のふだんの最大（441 列）の **1.35 倍（595 列）まで**。小さい輪 2 つが重ならないときで 17×17×2＝578 列なので入る。
- 輪が小さくなるときは、外になった列を **少しずつ** 捨てる（1 コマで全部捨ててカクっとしない。量は開発が決める）。
- 読みこみが追いつかないとき: その人は「読みこみ中」の今の決まり（VOX-D: 動かない・落ちない）で待つ。2P だけが待つときも 1P は遊べる。
- かすみ（霧）は輪 2 つのあいだ、描く範囲に合わせて近くする（遠くのふちが見えないように）。切りかえは分割の切りかえと同じ瞬間にそろえる（§7.2）。
- **見えない壁は作らない**。2P はどこまでも行ける（オーナー決定「離れすぎ防止なし」）。ただし §8 の「早く遊ばせたいとき」の仮の壁は、作業 2 までのあいだだけ使ってよい（オーナー OK 済み）。

## 6. セーブ

- 2P の分は **世界のセーブに 1 か所** 足す（例: `p2: { inventory, level }`。`level` は 1P の `level` と同じ形 `{ level, xp }`。段階 2 で `armor` も）。`p2` は足すだけのキーなので **セーブの版（`SAVE_VERSION`）は上げない**（上げると `validMeta` が古いセーブを読まなくなるため。PO 2026-11-06）。
- 実績は世界で 1 つ（今の `achievements` のまま）。2P の分を別に持たない。
- 2P の場所・向きは保存しない（次に参加したら 1P の横に出る）。ハートは満タンで始まる（1P の今の決まりと同じ）。
- 2P が一度も参加していない世界: `p2` はなし。古いセーブはそのまま読める（2P なしとして）。
- 2P が「やめる」→ その時点で 2P の持ち物を保存する。遊んでいる最中は 1P と同じ時間おきの保存に入る。
- たんす・ブロック・作物・妖怪の記録など世界の物は 1 つ（今のまま）。
- 2P が参加したことのある世界をキーボードだけで開いても、2P の持ち物は消えない。

## 7. 重さの測り方（クラウドに GPU はない）

時間（ms）で合否を決めない（#255）。描画回数・三角形・処理の仕事の数で、**同じテストの中で「1 人のとき」とくらべたふえ** を見る。本当の速さはオーナーの Mac の F3 で見る。

### 7.1 試作で先に測る（作業 2 の前）

段階 1 の作業 1 が終わったら、分割の本番（作業 2）を作る前に **「画面を 2 回描く試作」** で測る。

- 試作の名前は **`duo-proto`**（とりごやの `coop` と分ける）。試作のコードは `src/proto/duo/` に置き、試作だけの入口（例: `proto-duo.html`）か URL `?duoProto=1` で動かす。**本番のコード（`src/main.ts` など）から `src/proto/` を import しない**（eslint の `no-restricted-imports`。CLAUDE.md のきまり）。測り終わったら試作は消すか `src/proto/` に残すだけにする。

| 測る場面 | 内容 |
|---|---|
| A | 1 人（いまのまま）。同じシード・同じ場所・同じ向き |
| B | 1 画面＋ルーペ（大きい画面 1 回＋小さい丸 1 回） |
| C | 分割（左右に 1 回ずつ。2P は 1P から 60 マス、輪 2 つ）。**輪 2 つは試作の中で独自に作ってよい**（本番の §5 の作りを待たない。数を測れればよい） |
| D | C ＋軽くする工夫（§7.2）をぜんぶ入れた物 |

記録する数（`npm run perf` の形にそろえ、`perf-results/` に残す）: 描画回数（draw calls）、三角形、影の地図を描いた回数、持っている列の数、メッシュの数、1 ステップの更新の処理時間、1 コマの描画の処理時間（クラウドは目安。前後の比だけ見る）。

**決め方**: D が A の **描画回数 2.0 倍以下・三角形 1.8 倍以下・持つ列 1.35 倍以下** なら作業 2 へ進む。こえたら §7.2 の工夫を足すか、perf-engineer に相談してから進む。オーナーの Mac で C・D を遊んで、カクカクしないかを見てもらう（オーナー確認）。

### 7.2 軽くする工夫（分割のあいだだけ。1 画面に戻ったら 2 秒後に元へ）

効く順に試す（どれを入れるかは試作の数で決める）。

1. 影を切る（影の地図を描かない）
2. 遠くを描かない（小さい輪・かすみを近く）
3. ルーペは 2 コマに 1 回だけ描きかえる・近く（16 マス）だけ描く
4. 画素の細かさを下げる（今は最大 2 倍 → 1.5 倍）
5. 小ブロックの細かい形を、近い所だけにする

- 工夫を入れる・外すときに画面が目立って変わる物（影・かすみ）は、分割の切りかえと **同じ瞬間** に変える（別々に目立たせない）。

### 9.2 ようすの切りかえ（2 人の直線距離。マス）

| 切りかえ | 上がる（離れていく）: この値 **以上** で | 下がる（近づく）: この値 **以下** で | 1 秒の待ち |
