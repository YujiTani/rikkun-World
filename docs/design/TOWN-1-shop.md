## 2. 遊び方（つづき）

### 2.6 よろずや〔1C〕
1. よろずやさん を ねらって 右クリック（「はなす」。HOUSE-1 §2.2 の 4・6 と 同じ）→ ふきだし「いらっしゃい！ ようかいダマと こうかん するよ」→ **よろずやの 画面**（§3.2）。
2. 画面: 上に「もっている ようかいダマ」（ようかいダマの 絵 ＋ 数）。まん中に 品の **カード**（品の 絵 ＋ ようかいダマの 絵 ＋ ねだん）。カードを えらぶと 下の 帯に 大きな 絵・名前（ルビ つき）・中身の 数（「8 ほん」など）と「**こうかん**」ボタン。
3. ようかいダマが たりない 品は カードが うすく（灰色）なり、こうかん ボタンも 灰色。押すと よろずやさんの ふきだし「ようかいダマが あと 3 こ たりないよ」（たりない 数は 見せて よい。遊びの 数）と はずむ 明るい 音。何も へらない。
4. こうかん: ようかいダマが へり、品が もちものに 入る（入らない 分は 足もと）。1 回 押すと 1 セット。在庫は かぎり なし。
5. 品と ねだんは §4.2（決定の 表）。**レジェンダリー武器・金剛（こんごう）そうびは 売らない**。家の レシピの まきものは **まだ おぼえて いない** レシピから くじ（どれが 出るかは あけるまで ないしょ。ぜんぶ おぼえたら カードに「もう ぜんぶ もってるよ」で 灰色）。
6. カードの いちばん 後ろ 2 つが **こばこ** と **おおばこ**（§2.7）。
7. 開いて いる 間: 1 人の ときは 全面・世界を 止める（建築士さんの メニューと 同じ）。2 人の ときは **開いた 人の 半分**に 出し **世界は 止めない**（COOP-1 1.16「ぜんぶ 半分」・COOP-1 §3.3 の もちもの画面と 同じ）【PO 案】。**1.3**: 街にも 妖怪が 入って くる ので、2 人の ときは 開いた 人（1P でも 2P でも）にも 妖怪の こうげきが 当たる（その場に 止まり、ハートが へる。画面は とじない。やられたら とじる。TOWN-1 §2.9・§5・§7.1）。1 人の ときは 世界が 止まる ので おそわれない。✕・Esc（パッドは もどる）で とじる。街の はんいを 出たら 自動で とじる。

### 2.7 たからばこ（ガチャ）〔1C〕
1. よろずやの 中に 2 つの たからばこ（おおばこ は 一段 高い 台の 上）。よろずやの 画面で えらぶ:
   - **こばこ**（10 ダマ）: **坑道（こうどう）の 宝箱と 同じ くじ**（宝箱の 表 `kodo` を そのまま つかう）。
   - **おおばこ**（100 ダマ）: **段 4 かくてい**（ミラクル ★6 が 1 つ かならず）＋ **レジェンダリー ★7 が 出るかも しれない**（§4.3）。
2. くじは 宝箱と 同じ しくみ（`rollChest` と 宝箱の 表）を つかう。おおばこ の 表を **1 行 足す だけ**（§4.3）。中身は めずらしさ（RARITY-7 の ★と ふちの 色）つき。のぞく 物も 宝箱と 同じ（ようかいダマ・せっけいず・レシピの まきもの など は 出ない）。
3. くじの たね ＝ 世界の シード・プレイヤー（1P／2P）・その 人が その 箱を あけた 回数（同じ セーブで 同じ 順なら いつも 同じ 中身。テストで 再現 できる）。
4. **あける 演出**: ようかいダマを はらう → 画面の まん中で 箱の ふたが あく → 中身が 1 つずつ ぽん（めずらしさの ふちの 色）→ 全部 ならんで「とじる」。「もう 1 かい」ボタンは 置かない（自分で えらびなおす）【PO 案】。中身は 出た 時に もちもの（入らない 分は 足もと）。
5. 中身の 見本: 箱の カードを えらぶと 下の 帯に「こんな ものが でるかも」（★の ならびの 絵）。わりあいの 数は 見せない。

### 2.10 かえりの おふだ〔1E〕
1. よろずやで 売る（§4.2）。もちものの マスに 入る 物（かさなる）。
2. 手に もって **右クリック（つかう）**: その 人の まわりが ふわっと 光り（§4.7 の ため）、おわると **ふんすいの 前**（ひろばの 門がわ）へ ぱっと うつる。おふだが 1 まい へる。とおくの 森でも、坑道の いちばん 下でも、夜でも つかえる（どこからでも。決定）。
3. ため の 間に 歩いても・たたかれても やめない（6 歳が にげながら つかえる）【PO 案】。ため の 間も 妖怪の こうげきは ふつうに 当たる。
4. 街の わかない はんい（1.3。1.2 の「安全の はんい」。116×116）の 中では つかえない（おふだは へらない。ふきだし「もう まちに いるよ」）。
5. 2 人の ときは つかった 人 だけ うつる。もう 1 人は その まま（COOP-1 の「はなれすぎを 止めない」の とおり。相手の やじるしで 向きが 分かる）。
6. 宝箱・たからばこ からは 出さない【PO 案: 今の 宝箱の くじの 当たり方を かえない。EXCLUDED に 理由つきで 足す】。

### 2.11 かじやさん〔1E〕
1. 奥の 列の **かじやの 建物**（TOWN-1-place §2.2b）。炉の 前に かじやさんが 立つ（歩かない。ときどき つちで かなとこを たたく 動き）。かじやさんに 話す →「どれを なおす？」→ **なおす 画面**: その 人の もちもの と **着て いる そうび** の 中で、たいきゅうが へって いる **武器・道具・防具** の カード（絵 ＋ たいきゅうの バー ＋ ようかいダマの 絵 ＋ ねだん）。
2. カードを えらんで「**なおす**」: ようかいダマが へり、その 物の たいきゅうが **まんたん** に もどる。トンカンの 動きと 音、炉の 火が 1 回 ぼっと 大きく なる。
3. ねだんは **めずらしさの 段 だけ** で 決まる（どれだけ へって いても 同じ。§4.8）。たりない ときは よろずやと 同じ 灰色・ふきだし。
4. なおす 物が 1 つも ない ときは ふきだし「どれも ピカピカ だね！」で 画面の かわりに なる。
5. 決定の「武器・道具」に **防具も 入れる**【PO 案: こわれる 物は ぜんぶ 同じ 所で なおせる 方が 6 歳に 分かりやすい】。たいきゅうの ない 物（ブロック・食べ物）は 出ない。
6. 1.1 の「かじやさんは ひろばの やたい」は **やめた**（オーナーの 5 版の 絵: 石の 炉の 建物）。

### 2.12 やたい（かいとり）〔1E〕
1. ひろばの かいとりの やたい（「やさい」の かんばん）。やたいさんに 話す → **かいとり 画面**: その 人の もちものに ある **やさい・たまご・鉱石** の カード（絵 ＋「□ →」＋ ようかいダマの 絵 ＋「1」。§3.2）。下の 帯に「□ こ で ようかいダマ 1 こ」。§4.9 の 表の 物だけ。
2. カードを えらんで「**わたす**」: その 数 だけ へり ようかいダマ 1。1 回 押すと 1 組。たりない ときは 灰色（「あと □ こ」）。
3. **1 日に もらえる ようかいダマに 上限**（§4.9）。上限に なると ふきだし「きょうは もう いっぱい。また あした ね」で 灰色。つぎの ひる（ゲームの 日が かわる）で もどる。人ごと。
4. わたした 物は もどらない（確かめは なし。1 組ずつ なので まちがえても 少し）。

### 2.13 やたいの 食事〔1E〕（決定 18:20「食事できるようにしていい。ライフの回復」）
1. ひろばの **だんごの やたい**（だんごやさん）と **ごはんの やたい**（ごはんやさん。前に 赤い ベンチ）。人に 話す → ふきだし「おなか すいた？」の 下に ボタン「**たべる**」（食べ物の 絵 ＋ ようかいダマの 絵 ＋ ねだん）と「✕」。
2. 「たべる」: ようかいダマが へり、ふきだしが とじて **その 場で 食べる**（もぐもぐ 30 ステップ ＝ 0.5 秒）→ 体力が ふえる（§4.10。だんご ＝ 少し、ごはん ＝ ぜんぶ）。ハートが 1 こずつ ぽん ぽん と ふえて 見える。食べ物は もちものに 入らない。1.3: もぐもぐ の 間は 世界が 動いて いて 妖怪の こうげきも 当たるが、食べるのは やめない（回復は へらさない。TOWN-1 §5）【PO 案】。
3. 体力が もう まんたん の ときは ボタンが 灰色、押すと ふきだし「おなか いっぱい だね！」。ようかいダマは へらない。
4. ようかいダマが たりない ときは よろずやと 同じ 灰色・ふきだし「ようかいダマが あと □ こ たりないよ」。
5. 画面の きまりは よろずやと 同じ（1 人 止める／2 人 半分・止めない）。食べるのは 開いた 人 だけ。
6. かざりの やたい（おめん など）は 話せない・買えない（右の 案内に「はなす」が 出ない）。
