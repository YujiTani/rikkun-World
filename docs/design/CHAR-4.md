## 1. ねらい（りっくんが どう 楽しむか）

- 刀を ふると、刃先が 通った所に **ぴかっと 光る 半月** が のこって すっと 消える。「シュッ」の 音と いっしょに、自分の 切った 形が 目に 見える。
- 木刀は 茶色、かたなは 白、きらきらの かたなは 水色に 星が 3 つ。**字が 読めなくても 色で どの 刀か 分かる**。キャラが 持っている 刃の色も 同じ色なので、持ちかえると すぐ 分かる。
- 3 つの わざで 形が ちがう（大けさぎり = 右上から 左下への 大きな 半月、切り上げ = 右下から 左上への 半月、突き = 前への 短い 光）。かまえと わざの つながりが 形で 分かる。

## 2. 遊び方（プレイヤーから見た動き）

1. ぼくとう・かたな・きらきらの かたなを 持つ → キャラの絵の 刃が その刀の色に なる（持ちかえた ステップから）。
2. クリックで わざ（CHAR-2 のまま）→ 刃先が 大きく 動く あいだ（§4.2 の「書く時間」）、刃先の 後ろに 光の 帯が のびる。
3. 刃先が 止まると、帯は **しっぽ（古い方）から** 消え、のこりも 4 だんで うすくなり、書きおわりから 0.15 秒で なくなる。
4. 当たっても 外れても 同じ 軌跡（当たったときの 星・ゆれ・音は 今のまま）。おしつづけて くりかえしても 毎回 同じ 大きさ。
5. なぎなた・つるはし・素手・弓では 新しい 軌跡は 出ない（なぎなたの 白い弧は 今のまま）。

## 4. ルール・数値

### 4.1 いつ 出すか

- 出すのは **刀（`BLADE_ITEMS` = ぼくとう・かたな・きらきらの かたな）の わざ**（突き・大けさぎり・切り上げ）だけ。
- 1 つの わざで 1 本。わざを 始めた ステップに 前の 軌跡が のこっていたら すぐ 消す（初期の 長さでは おこらない。§4.7）。

### 4.2 書く時間（刃先が 大きく 動く あいだ）

絵の時 τ（CHAR-2 §4.2。`blade_path.json` の `perTick` の 番号と 同じ 数え方）で 決める。

| わざ | 書く時間（τ） | 初期の 長さでの ステップの 時刻 | 点を 書く ステップ | 見える ステップ |
|---|---|---|---|---|
| 突き | 2 〜 6 | 2 〜 6 | F2〜F6（5 点） | F3〜F14 |
| 大けさぎり | 28 〜 34（= 当たり） | 28 〜 34 | F28〜F34（7 点） | F29〜F42 |
| 切り上げ | 38 〜 43（= 当たり） | 38 〜 43 | F38〜F43（6 点） | F39〜F51 |

- 大けさぎり・切り上げは 当たり（active）と 同じ。突きは 刃先が 前へ 出はじめる τ 2 から（当たりの τ 4〜6 だけでは 刃先が 約 0.24 しか 動かず 点の ように 短いため。τ 2〜6 で 約 0.8。§9 Q1）。
- **時刻**: わざの ステップ F = f の おわりを 時刻 f とする（F1 の はじめが 0）。τ と 時刻の あいだは CHAR-2 §4.2 の 段階ごとの 比（設定の 長さが 絵と 同じなら τ = 時刻）。τ が 段階 p（絵の 長さ L_p・設定の長さ S_p・絵の 中の はじまり P_p、設定の 中の はじまり B_p）の中なら 時刻 = B_p + (τ − P_p) × S_p ÷ L_p。
- **点**: 書く時間の 中に おわりの 時刻が ある ステップ（と、はじまりの 時刻に ちょうど おわる ステップ）ごとに 1 点。その点の 刃先・つばの 位置は §4.3。
- **見える部分**: いまの 時刻を n とすると、時刻 [max(書きはじめ, n − 9), min(n, 書きおわり)]。この はばが 0 より 大きい ステップだけ 見える。表の「見える ステップ」は これを 計算した もの（例 大けさぎり: F28 は [28, 28] で はば 0、F42 は [33, 34]、F43 は [34, 34] で 消える）。
- 設定の 長さを 変えたとき（テスト用）の 例: 大けさぎり 14/3/36 → 書く時間は 時刻 14〜17、点は F14〜F17（τ 28・30・32・34）、見える ステップは F15〜F25。

### 4.3 刃先・つばの 位置（3D の データから）

- データ: `blade_path.json`（PO が `art/char-sheets/blade_path.json` に 置く。ゲームには 組みこみ、ダウンロードを 待たない）。わざごとに `perTick`（番号 = τ。突き 0〜41・大けさぎり 0〜106・切り上げ 0〜104）、各点に `base`（つば）・`tip`（刃先）= [右, 上, 前]（m）、原点は その τ の 腰の 真下の 地面。
- τ が 整数でないときは、となりの 4 つの 点を 通る なめらかな 曲線で うめる（見本 `render.py` の `cr` と 同じ形。点は かならず 通る）。
- **世界の 位置** = その 時刻の 体の 本当の 位置（当たり判定の 足もと。かべで 止まったら 止まった 位置）＋ k × （右 × r ＋ 上 × y ＋ 前 × u の 向きの ベクトル）
  - u = わざの 向き（`blade.state().move.dirDeg`。わざの あいだ 変わらない。CHAR-2 §4.5）。yaw の 数え方は 今の まま（0 = 北 −Z、90 = 東 +X）。前 = (sin u, 0, −cos u)、右 = (cos u, 0, sin u)、上 = (0, 1, 0)。
  - k = 板の 大きさ ÷ 絵の span = (span × 1.8 ÷ modelH) ÷ span = 1.8 ÷ 1.7 = **1.0588**（キャラの絵と 同じ 倍率。`atlas.json` の `modelH` から 計算する）。
  - 体の 位置は ステップの おわりの 位置。ステップの あいだの 時刻は となりの 2 つの おわりの 位置を 直線で つなぐ。
- **書いた 点は 世界に とどまる**（あとで 体が 前へ 進んでも・カメラを 回しても 動かない）。
- **注意（絵の コマとの ずれ）**: 軌跡の 頭は ステップの おわりの 時（毎ステップ なめらかに 進む）。キャラの 絵は コマ（大けさぎり F29〜F34 は 2 tick ごと）で 変わるので、頭と 絵の 刃先は ステップに よって 最大 約 1 tick ずれる。F29〜F34 は 刃先が 1 tick に 0.3〜1 m 動く 所なので、ずれは 刃の 長さ（約 0.6）より 大きく なる ことが ある（例 F31 で 約 0.8 m）。試作で F29〜F34 を ぜんぶ 撮って オーナーが 見る（§10 の 4・§9 Q3）。
- 計算の 確認（ひらけた 平らな 地面・O = わざを 始めた 足もと・yaw 0。体は O ＋ 前 × A(f)。A は CHAR-2 §4.5）:

| 大けさぎり F34 刃先 | (−0.482, 0.312, 0.606) | 0.6539 | (−0.510, 0.330, −1.296) |

### 4.4 形・色・消え方（B グラデーション）

| 項目 | 決まり |
|---|---|
| 長さの 位置 q | 見える部分の しっぽ（古い方）を q = 0、頭（いちばん 新しい 所）を q = 1（時刻で 等分） |
| そとの へり | 刃先の 通り道 |
| うちの へり | 刃先 ＋ （つば − 刃先）× **0.45** × sin(π q)。まん中が ふとく（刃の長さ 約 0.58 × k の 0.45 = 約 0.28）、両はしは 0（とがる） |
| いちばん うすい はば（見る向きへ ひらく） | カメラから 刃先への 向きを v、通り道の 向きを t、n = v × t の 向き（長さ 1）とする。（うちの へり − 刃先）の n の 成分が **0.10 × sin(π q)** より 小さいときは、うちの へりを n の 向き（つばの 側。（つば − 刃先）・n と 同じ 符号）へ 足りない ぶん ずらす。v と t が ほぼ 平行（\|v × t\| < 0.01）なら ずらさない。毎ステップ その ステップの カメラで 決める |

### 4.6 キャラの絵の 刃の色

- **色の 番号の 数え方**: 色見本の 表（`PALETTE_RGB`、0 から 数える）の 20 番 = 刃の地、21 番 = 刃の ふちの光（PO の 言う 20・21）。PNG を 読んだ あとの 色番号（0 = とうめい、1 = 表の 0 番 …）では 21・22。色見本は 22 色に なる。2 色の 値は 撮り直しの 絵と 同じ（PO が `art/CHAR-1-v2/palette.json` に 書いた。20 番 = (218, 215, 225)・21 番 = (253, 251, 252)。今の 刃の 表の 6 番 (218, 215, 224)・18 番 (253, 251, 253) と ほぼ 同じで、どれとも ちがう 色なので 読むとき ぴったり その番号に なる）。
- 撮り直しの 絵（PO 済み。記録は タスク票）: 刀の 6 まいだけ 刃の ドットが 20・21 番。ほかの 8 まい（`idle`・`walk`・`run`・`jump`・`bow_*` 4 まい）には 20・21 番は 1 つも ない。
  - 撮り直しの 前と ちがって よい ドット: 刃の 色の 入れかえ（20・21 番に なった 所）と、**刃から 3 ドット 以内の ふち**（1 まいに 約 1,100〜2,700 = 見える ドットの 約 0.2% 以下。刃の 色の 重みで ふちの 多数決が 少し ずれた ぶん）。それより 外は 1 まいに 10 ドット 以下（記録 0〜7）。
  - 数は PO が 確かめた（タスク票の 記録）。見た目が 変わって 見えないかは オーナー（AC21）。
- **ゲームが 読む ときの 番号**: `npm run pack:char` は 色を そのまま 写すが、ゲームは 読む ときに `src/char/palette.ts` で 番号に するので、`palette.ts` が 22 色に なる 前に 新しい 絵を 入れると 20・21 番が 6・18 番に 丸まって 刃の 色が かわらない。だから `palette.ts` 22 色 → `pack:char` → `public/models/char/` 入れかえ の 順（§10）。
- 板の 色: 持っている 物が 刀（`BLADE_ITEMS`）なら 20 番 = その 刀の `blade`、21 番 = `bladeShine`。それ以外（弓・素手・ほか）は 色見本の 色の まま。ほかの 色と 同じに 明るさ（`uTint`）・霧・影が かかる。
- 変わる 時: 持ちかえた ステップの 板から（ぼくとう → かたな の 持ちかえで、次の 描画で もう 白い 刃）。
- `readCell`（テスト用）は PNG の 色の まま 返す（武器の 色に しない。CHAR-2 AC33 は そのまま）。
- 影の 板（`src/world/render/shadow/shadowPatch.ts`）は 板の シェーダーの 色の 1 行を 文字で 書きかえている。色見本の 値を かえる だけなら その 1 行は 変えずに すむ（変えるなら 影の パッチも 合わせる）。

### 4.7 同時に 出る 数・くりかえし

- 軌跡は いつも 1 本 以下。初期の 長さでは 次の わざ（突き F42・大けさぎり F107・切り上げ F105）までに 前の 軌跡は 消えている（突き F15・大けさぎり F43・切り上げ F52）。

### 4.8 性能の 上限（CI に GPU は ない。数は three.js の 物の数・頂点・三角形で 数える）

| 場面 | 描画回数の 増え | 三角形の 増え | GPU メモリの 増え |
|---|---|---|---|
| 軌跡が 出ていない | **0**（軌跡の 物は ぜんぶ 見えない） | 0 | — |
| ぼくとう・かたなの 軌跡 | **1 以下** | **288 以下**（区切り 36 × だん 4 × 2） | 頂点の 入れ物 **64 KiB 以下**（はじめに 1 回 作る。だんの さかいを くっきり のこすため さかいで 頂点を 共有しない: めやす 37 列 × だん 4 × 2 = 296 頂点、位置と 色で 1 頂点 28 バイト → 約 8.3 KB ＋ 番号 約 1.7 KB = 約 10 KB） |

- PR に `npm run perf` の 前後（描画回数・三角形・処理時間）を のせる（全体ルール C）。
