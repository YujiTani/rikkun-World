# SETTINGS-1: せってい・スタートメニュー（仕様書）

> オーナー承認（2026-11-05）を そのまま 書く。土台は main `9fd5afe`（#393）。押しっぱなしの Action 記憶と、知らない機種で割り当て未保存のときの面ボタン抑制は 変えない。
> 前の決まり: GAMEPAD-1 の ＋ は → 本仕様。音の入口は SOUND.md §7 → 本仕様。

## 1. ねらい

- コントローラーの ボタンを、表で 見て、押しなおして 変えられる。
- 右スティックを 倒したときの みる はやさを、自分で 決められる（押しこみの R3 ではない）。
- ＋ と Esc は 同じ「スタートメニュー」。もちものとは 別。
- おと・ボタン・みる はやさは 1 つの「せってい」に 入る。
- タイトルがめんに もどるときは、聞いてから。ほぞんに 失敗したら もどらない。

## 2. ことば

| 画面 | 呼び方 |
|---|---|
| Esc で 出る 案内（クリックして あそぼう） | スタートメニュー |
| E / パッド左の面 | もちもの・クラフトメニュー |

## 3. スタートメニュー

- 遊び中の Esc と ＋ は、スタートメニューを ひらく。もう一度 ＋（パッド）で とじる。
- メニューが 開いているあいだ、ほる・あるく・みる・すてるは 出さない。
- 十字は 今 開いているメニュー（スタート・もちもの・せってい・確認）の フォーカスだけを 動かす。遊び中の 十字は 今までどおり（↓ すてる、← できごと、↑→ 空き）。
- したの面（B）は 決定。みぎの面（A）は ひとつ もどる。
- 「タイトルがめんに もどる」→ 確認「本当にタイトル画面にもどりますか？」（ふりがな付き）。ボタンは もどる / やめる。はじめの フォーカスは やめる。
- もどる: 保存を 待つ。失敗、または 保存できないのに 捨てることになるときは、もどらず「ほぞん できなかったよ。このまま あそぼう」。成功しても「ほぞんした」とは 言わない。`?nosave=1` は 保存しない約束なので 読みこみ直してよい。

## 4. せってい

1. **そうさ**の表: すること / キー・マウス / コントローラー。キーは 今の割り当て（表示だけ）。コントローラーは Switch の 位置の 文字（B A Y X、L R ZL ZR、＋ −、十字）。行を 選ぶと 次の ボタンを 待つ。Esc・「やめる」・（パッドで 入り始めたとき）＋ は 変えずに やめる。同じボタンが 別の ことに 付いていたら、前の方を 外して ことばで 知らせる（黙って 消さない）。「もとにもどす」は 確認し、はじめは やめる。かまえは キー R のまま、パッドには 置かない。
2. **みる はやさ**: つまみと 数字。おそい / はやい。0.4〜6、はじめ 2.4。マウスでも 十字の 左右でも。保存する。もとにもどせる。デッドゾーンとは 別。1 ステップにつき 1 回だけ掛け、フレームの 実時間では 掛けない。
3. **おと**: 今の ぜんぶ・おんがく・こうかおん・おと。保存キー `rikkun.audio.v1` はそのまま。
4. **動作確認**: id、mapping、軸、ボタン、デッドゾーン、まんなかを おぼえる。遊びの 表とは 分ける。

保存してある ボタン割り当てと 校正は、消さない。＋ だけ、古い初期値（もちもの）のまま保存されているときは スタートメニューに 直す。ほかを 変えてある ＋ はそのまま。

## 5. やらないこと

- 振動、ジャイロ、パッドのかまえ、キーボードの割り当て変更。
- みかた切替の カメラ本体（入力は 今までどおり届く。見た目は まだ かわらない、と 書く）。
- 3D の 戻し。
