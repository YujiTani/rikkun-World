> オーナー承認（2026-11-05）を そのまま 書く。土台は main `9fd5afe`（#393）。押しっぱなしの Action 記憶と、知らない機種で割り当て未保存のときの面ボタン抑制は 変えない。
> 前の決まり: GAMEPAD-1 の ＋ は → 本仕様。音の入口は SOUND.md §7 → 本仕様。

## 1. ねらい

- コントローラーの ボタンを、図のまわりの ことばから 押しなおして 変えられる（2026-11-06 オーナーが 表から 図へ 変更）。
- 右スティックを 倒したときの みる はやさを、自分で 決められる（押しこみの R3 ではない）。
- ＋ と Esc は 同じ「スタートメニュー」。もちものとは 別。
- おと・ボタン・みる はやさは 1 つの「せってい」に 入る。
- タイトルがめんに もどるときは、聞いてから。ほぞんに 失敗したら もどらない。

## 2. ことば

| 画面 | 呼び方 |
|---|---|
| Esc で 出る 案内（クリックして あそぼう） | スタートメニュー |
| E / パッド左の面 | もちもの・クラフトメニュー |

## 3. スタートメニュー

- 遊び中の Esc と ＋ は、スタートメニューを ひらく。もう一度 ＋（パッド）で とじる。
- メニューが 開いているあいだ、ほる・あるく・みる・すてるは 出さない。
- 十字は 今 開いているメニュー（スタート・もちもの・せってい・確認）の フォーカスだけを 動かす。遊び中の 十字は 今までどおり（↓ すてる、← できごと、↑→ 空き）。
- したの面（B）は 決定。みぎの面（A）は ひとつ もどる。
- 「タイトルがめんに もどる」→ 確認「本当にタイトル画面にもどりますか？」（ふりがな付き）。ボタンは もどる / やめる。はじめの フォーカスは やめる。
- もどる: 保存を 待つ。失敗、または 保存できないのに 捨てることになるときは、もどらず「ほぞん できなかったよ。このまま あそぼう」。成功しても「ほぞんした」とは 言わない。`?nosave=1` は 保存しない約束なので 読みこみ直してよい。

## 4. せってい と ゲームパッド

1. **せってい**の上のタブは **音**・**カメラ**・**コントローラー**（testid `tab-sound`・`tab-camera`・`tab-controls`）。見えているのは選んだタブだけ。切りかえても値は残る。タブはマウス・キーボード（左右）・十字で移せ、選んでいるタブが分かる。**コントローラー**の中にもう 1 段、**キーボード/マウス**（`ctrl-tab-keys`）と **ゲームパッド**（`ctrl-tab-pad`）。キーボード/マウスは表だけ（表示のみ。2 列にならべて 1 画面に入れる）。せってい画面はホットバーより上に重なり、高さに入らないぶんは中でスクロールする。音の横棒は右いっぱいまで広げる。
2. **ゲームパッド**（別の全画面ではなく、コントローラータブの中）: 中央に Switch 風の図（オリジナル。B 下・A 右・Y 左・X 上、L/R、ZL/ZR、スティック、＋/−、十字）。上に 2 つのタブ **あそぶ とき**（`pad-tab-play`、はじめ）と **もちもの・クラフト**（`pad-tab-menu`）。
   - **図と線**: ボタン（またはまとまり: ZL/L・ZR/R・十字・ABXY・スティックと押しこみ）を細い四角でかこみ、その四角から左右の札の列へ、横にまっすぐ → 札の列のそばで 1 回だけ曲がって札へ、の線を 1 本だけ引く（折れは多くても 1 回）。左右の札の列は上と下をそろえ、図はその高さのまんなかに置く（図は縦にのばして、四角と札の高さを近づける）。線どうしは交わらない（四角の高さの順と札の順をそろえ、曲がる位置を全部の線で同じにする。計算は `padLayout.ts`、ユニットテストで確かめる）。札は重ならない。
   - **札の形**: `[ことば | ボタンの印]` の横長 1 まい（高さ 44px）。印は ZR・L・A・B などのローマ字、十字は十字の絵、スティックはスティックの絵。意味が 2 つ以上のことばは「ほる/こうげき」のように **スラッシュ**でつなぐ（「・」は使わない）。
   - **同じ意味の札は 1 まい**。同じ操作が 2 つのボタンにあるときは、印を並べる（例: `[できごと | − 十字←]`）。割り当てのないボタンは札を出さない。
   - **あそぶ とき**: 今の割り当て（あるく・ジャンプ・はしる・みる・みかた・ほる/こうげき・おく/たべる・てにもつ まえ/つぎ・もちもの/クラフト・スタートメニュー・できごと・すてる・まとめて すてる）。札を押すと図のその場所が光り、次に押したボタンへ、今までの決まりで割り当てる（やめる・衝突の知らせ・保存）。スティックは「あるく」「みる」のまま（押し直ししない）。
   - **もちもの・クラフト**（メニューを開いているとき。見るだけ）: 十字=えらぶ、した B=きめる、みぎ A=もどる、＋=スタートメニュー（`reader.ts` の menuOpen と同じ）。
   - ならびがわからない機種は、そのことを書く。はやさのつまみは置かず、「カメラの はやさ」でカメラタブを開く。
3. **みる はやさ**はカメラタブだけ（0.4〜6、はじめ 2.4。デッドゾーンとは別。1 ステップに 1 回）。**動作確認**（id・mapping・軸・ボタン・デッドゾーン・まんなか）はゲームパッド画面。
4. **おと**は音タブ。保存キー `rikkun.audio.v1`。
5. かまえはキー R のまま。パッドには置かない。Esc・「やめる」・（パッドで入り始めたとき）＋ は変えずにやめる。同じボタンが別のことに付いていたら、前を外して知らせる。

保存してある ボタン割り当てと 校正は、消さない。＋ だけ、古い初期値（もちもの）のまま保存されているときは スタートメニューに 直す。ほかを 変えてある ＋ はそのまま。

## 5. やらないこと

- 振動、ジャイロ、パッドのかまえ、キーボードの割り当て変更。
- みかた切替の カメラ本体（入力は 今までどおり届く。見た目は まだ かわらない、と 書く）。
- 3D の 戻し。
