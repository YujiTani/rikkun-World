### 4.3 男の子の 場面と 絵（案 B）

男の子のときは、持っている物に かかわらず CHAR-1 §4.4 の 決まりで 絵を えらぶ。ただし 下の 1 行を 先に 見る。

| # | 場面 | 絵（`scene` / `motion`） |
|---|---|---|
| G0 | 刀の わざ（刀の `phase` が startup・active・recovery）か パリィ（`parry.state().phase` が idle 以外）の あいだ | `stand` / `idle`（v に かかわらず。コマは たつの 進み方を 続ける） |
| G1〜 | そのほか | CHAR-1 §4.4（`stand`/`idle`・`walk`/`walk`・`run`/`run`・`jump`/`jump`）。刀・弓を 持っていても ジャンプの絵を 出す（刀が 絵に ないので CHAR-2 O8 の「かまえのまま」は 男の子には あてはめない） |

- 刀・弓・パリィの 絵（`katana_*`・`bow_*`・`parry`・`parryKime`）は 男の子のときは 読まない（`status` は `none` のまま）。
- 体の 動き・わざ・矢・パリィ・ふみこみ・向き・歩けない は キャラと 関係なく 同じ（CHAR-2 §4.5 の とおり「絵の読みこみに たよらない」）。

- かまえの印・弓の印は 今どおり（CHAR-2 §3）。

### 4.4 切りかえ（窓口 `char.set` だけ。その場で）

1. `char.set` で ちがう キャラに した ステップに: 前の キャラの 絵を **ぜんぶ** GPU から おろす（`status` は ぜんぶ `none`、`gpuBytes` から 引く）。読みこみの 待ち行列に のこっている 前の キャラの 絵は 読まない。読んでいる とちゅうの 絵は、読みおえても 使わず すてる（`gpuBytes` に 足さない）。
2. 同じ ステップから、新しい キャラの 絵を **はじめて 始めたときと 同じ 決まり** で 読む（たつ・あるく → はしる・ジャンプ。女の子なら 刀・弓を 持ったとき・パリィを 出したときに その組。CHAR-2 §4.7・WEAPON-5）。今 刀・弓を 持っている 女の子に もどしたら、すぐ その組も 読む。
3. 新しい キャラの たつ・あるく が 読めるまで 板を 出さない（`loaded` false。CHAR-1 §5）。板の 大きさは 新しい キャラの `modelH` に する。
4. 読みおえたら 次の 描画から 新しい キャラ。ページは 読み直さない。
5. 体の 位置・向き・持ち物・体力・刀・弓・パリィの 状態・カメラは 変えない（わざの とちゅうでも 取り消さない）。
6. 同じ キャラを えらんでも 何もしない（おろさない・読まない）。

- **重さ**: どの ステップでも `gpuBytes` = 今の キャラの 読みおえた 絵の よこ × たて の 合計（ちょうど）で、67,108,864 以下。前の キャラと 新しい キャラの 絵を 同時に 持たない（いちばん 重いのは 女の子を ぜんぶ 読んだとき 66,832,384）。
- 何度 切りかえても 同じ（GPU の 絵が ふえつづけない）。
- START-1 は 世界を 作る前に キャラを 決めるので この 切りかえを 使わない。この しくみは あとで 遊びの 途中の 切りかえを 足すとき と テストの ために 残す。
