2. **ほかの 建築士さん**は マップに ランダムに 出る。【PO 案】世界を 192×192 マス の 区画に 分け、区画ごとに シード付きの 乱数で **3 つに 1 つ** の 区画に 1 人。区画の 中の 水でない 立てる 地面。スタート地点の 区画は 最初の 1 人だけ（ふえない）。同じ シードなら いつも 同じ 場所。
3. 建築士さんは その場から あまり 動かない【PO 案: いる 場所から 3 マス 以内を ゆっくり うろうろ】。たたいても 弓で うっても **へらない・たおれない**（ちょっと よろけて「おっとっと」の 動き）。妖怪は 建築士さんを ねらわない。
4. **話しかける** = 建築士さんを ねらって 右クリック（今の `secondary`。ねらえる きょりは 今の ブロックを 置ける きょりと 同じ）。建築士さんは こちらを 向いて **うなずき**、頭の 上に **ふきだし**（ひらがな）、声は 言葉ではない「ぽぽぽ」の ような 鳴き声（音の 方向 B「木の おもちゃと オルゴール」）。ふきだしと いっしょに **メニュー**（§2.3）が 出る。ゲームの 時間は メニューの 間 止まる【PO 案: もちもの画面と 同じ あつかい】。
5. **はじめて 話した とき** だけ、道具「みずもり」と「どうづき」を 1 こずつ くれる【PO 案】。ふきだし「こんにちは！ ぼくは けんちくし。いえを たてるよ」→「これを あげる。みずもり と どうづき だよ」。そのあと なくしても（持ち物にも たんすにも ない とき）、メニューの「どうぐを もらう」で また 1 こ もらえる【PO 案】。

### 2.4 くら（あずける・とりだす）
1. 材料は 建築士さんに あずける。**どの 建築士さんでも 同じ くら（共有）**。
2. **1 種類 999 こ まで**、種類の 数に 上限なし。
3. **いつでも 好きな 数を 取り出せる**（持ち物に 入る 分だけ）。
4. 画面【PO 案】: 左 = 自分の 持ち物（36 マス）、右 = くらの 中身（あずけた 種類だけ、登録表の 並び順。1 マスに 絵と 数）。マスを クリック → 下に 数の えらび（「−10」「−1」 数 「＋1」「＋10」「ぜんぶ」）と 「あずける」か「とりだす」の ボタン。はじめの 数は 1。
5. あずけられる 物【PO 案】: 1 マスに 2 こ 以上 重なる 物（ブロック・ざいりょう・たべもの など）。1 こ しか 重ならない 物（どうぐ・ぶき・ぼうぐ・せっけいず・キット）は あずけられない（マスが うすく なり、クリックしても 何も 起きない）。
6. くらの 材料は **建築にだけ** 使う（作る画面・かまどの 材料には ならない。決定に ないため）。
7. **「ひつような もの」ポップアップ**: くらの 画面・エディター・「けんちくを はじめる」の どこからでも **何度でも** 開ける。今の せっけいず（か エディターの 今の 形）に 必要な 材料を 1 行ずつ: 絵・名前・**ひつよう**・**くら に ある**・**たりない**（たりない が 1 以上なら 赤い 数字、0 なら 緑の ✓）。

### 2.5 エディター
3 つの タブ「そと」「なか」「なまえ」。下に いつも「ひつような もの」「せっけいずを つくる」「✕」。

**そと（外装）**: 1 版は **豆腐（とうふ）の 家・1 階 だけ**。ボタンで えらぶ:
- **大きさ**: 小・中・大（§4.1）。
- **窓の 数**: 「−」「＋」で 0〜上限（大きさで ちがう。§4.1）。窓は きまった 場所に 自動で 入る（§4.2）。
- **戸の 場所**: 「まえ」「みぎ」「うしろ」「ひだり」の 4 つ。戸は えらんだ 壁の まん中。
- 右に 家の 見本（ゆっくり 回る 3D か 斜め上からの 絵。アートに 任せる）が すぐ 変わる。

**なか（内装）**: 上から 見た **方眼**（家の 中の 床）。
- 左に 家具の 絵の ならび（9 種。§4.3）。家具を えらんで 方眼の マスを クリック → **置く**。置いた 家具を えらんで 「とる」「みぎに まわす」「ひだりに まわす」（右クリック でも とる【PO 案】）。
- 方眼の まん中は **だいこくばしら**（はじめから ある。動かせない・とれない）。
- **戸の 前の 1 マス** には 置けない【PO 案。出入りの 道を のこす】。そこは 方眼に 足あとの 絵。
- 置けない 所（はみ出す・重なる・柱・戸の 前）に 持っていくと 家具の 形が **赤** に なり、クリックしても 置けない。置ける 所は **白**。
- 同じ 家具を いくつ 置いても よい（材料が その分 ふえる）。

**外装・内装の それぞれに 必要な 材料（ブロック）の 数** が ある（§4.1・§4.3）。エディターの 下に「そと □□・なか □□」の 小さな 材料の 絵と 数（くわしくは「ひつような もの」）。

### 2.6 名前
- 名前 = **前の 文字**（画面の 50 音ボタンで **8 文字まで**）＋ **後ろの 文字**（「のいえ」「ハウス」「のおうち」「ひみつきち」「のやしき」から 1 つ。2 版で レシピで ふえる）。
- 前の 文字の 画面【PO 案】: ひらがなの 50 音表（あ〜ん ＋ ゛ ゜ ＋ 小さい ゃゅょっ ＋ ー）と「カタカナ」切りかえ・「1 もじ けす」・「できた」。゛ ゜ は 直前の 字に つく（つけられない 字では 押せない）。9 文字目は 入らない（ボタンが うすく なる）。
- 字を 入れる 画面の 中では **Esc いがいの キーを ゲームの 操作に しない**（図鑑と 同じ）。キーボードの 字の 入力は 受けない（50 音ボタン だけ）【PO 案】。Backspace は「1 もじ けす」と 同じ【PO 案】。
- 前の 文字が 0 字の まま せっけいずを 作ると、前の 文字は「<番号>ばん」（例「3ばん」）に なる【PO 案】。後ろの 文字の はじめは「のいえ」【PO 案】。
- **せっけいず・キット・家 で 同じ 名前** を 使う。**キットは 建築士さんの ところで 名前を つけなおせる**（§2.3）。せっけいずの 名前は 作ったら 変えない【PO 案】。
- **家に 入ると 画面に 名前が 出る**（§3）。

### 2.7 せっけいず
- エディターの「せっけいずを つくる」で、アイテム「**<名前>の せっけいず**」が 持ち物に 入る。**番号は 自動**（その 世界で 作った 順に 1, 2, 3 …。アイテムの 説明に「<番号>ばん」）。
- せっけいずは 1 マスに 1 こ。中に 形（大きさ・窓・戸・家具）・名前・番号を 持つ。材料は いらない（作るのは ただ）【PO 案】。
- 同じ せっけいずで 何けんでも 建てられる（建てても なくならない）【PO 案】。
- 持ち物が いっぱい なら 作れない（ボタンは 押せる が ふきだし「もちものが いっぱい だよ」）【PO 案】。

### 2.8 けんちくを はじめる
1. メニューの「けんちくを はじめる」→ 持っている **せっけいず と キット** の 一覧（絵・名前）。
   - **せっけいず**: くらに 材料（外装＋内装）が **そろって いる ときだけ** 選べる。そろって いなければ うすく なり、押すと「ひつような もの」が 開く（たりない が 赤）。ふきだし「ざいりょうが たりないよ」。
   - **キット**: 材料は いらない（もう 払って ある）。いつでも 選べる。
2. 選ぶと **上空の 視点** に なる（§3.4）。プレイヤーの まわりで **家が 入る かためた つちの 場所** が **緑** で 出る。
3. 家の 形の わく（カーソル）を 動かして（移動キー・矢印・マウス）、**決定** で 建築が 始まる。Esc で もどる（何も 使わない）。
4. 決定の とき: せっけいず なら くらから 材料が へる（せっけいずは のこる）。キット なら キットが 持ち物から へる。
5. 置ける 場所が 1 つも ない ときは 上空の 視点に ならず、ふきだし「かためた つちの ばしょが ないよ。みずもり と どうづき で つくってね」。

### 2.9 地盤（じばん）: みずもり と じがため
1. **みずもり**（道具）を 手に 持って 地面を 右クリック → その ブロックの 高さが **きじゅん**（ものさしの 高さ）に なる。まわり（§4.4）の 地面の 上に 色が つく: **きじゅんより 高すぎる 所 = 赤（↓）**、**低すぎる 所 = 青（↑）**。ちょうどの 所は 色なし。
2. 赤い 所は ほる、青い 所は うめる（今の ほる・おく）と、色が すぐ 消える。
3. **どうづき**（道具）を 手に 持って 地面を 右クリック → トントン たたく「**じがため**」。たたいた ブロックと、まわり 3×3 の **同じ 高さの** 土・くさ・すな・ゆき が「**かためた つち**」に なる（§4.4）。たたく たびに **よいとまけの 掛け声** の 音。
4. かためた つち は ふつうに ほれる（ほると つち 1 こ）【PO 案】。

### 2.10 建築中
1. 決定すると 場所に **足場** が 立ち、**壁が 下から 少しずつ** 立ちあがり、さいごに 屋根と 家具。時間は 豆腐の 家・小で **2 分 30 秒**（決定の 2〜3 分。§4.5）。
2. 建築を 始めた 建築士さんは 建築の 場所の 戸の 前に うつり（ぱっと）、とんかちで 打つ 動き。
3. **遠くへ 行っても 建築は 進む**（世界の 時計で 進む。ゲームが 止まって いる 間は 止まる）。
4. **建築中の 建築士さんに 話す** と、あと どれくらいか 教えて くれる（ふきだし。§4.5 の 言い方）。ほかの 建築士さんに 話しても 同じ ことを 言う【PO 案】。
5. 建築中の 場所の まわり（§4.6）では **妖怪が 湧かない**。
6. 建築中の 場所の ブロックは 置けない・こわせない。プレイヤーは 足場の 中に 入れない【PO 案】。
7. **完成**: 足場が 消えて、紙ふぶき と 短い ファンファーレ（§3.5）、画面の 上に「<名前> が できた！」。建築士さんが よろこぶ。戸は しまった 形で できる。建築士さんは プレイヤーが 32 マス 以上 はなれたら もとの 場所へ もどる【PO 案】。

### 2.11 家の 中は 安全地帯
1. 家の 中（§4.6 の 箱）では **妖怪が 湧かない**。
2. **戸**: 右クリックで あける・しめる。**しめると 妖怪は 入れない**（しまった 戸は 妖怪には かべ）。あいて いる 戸は だれでも 通れる。窓は 通れない（光は 通る）。
3. 家の 中に 入ると（外 → 中）画面に **家の 名前** が 出る（§3.3）。
4. 家の 壁・床・屋根・窓・戸・家具は こわせない【PO 案。こわすのは だいこくばしら だけ】。家の 中に ブロック（たいまつ など）を 置くのは 今どおり できる。

### 2.13 こわす（だいこくばしら）
1. 家の **まん中** に コア「**だいこくばしら**」（床から 天井まで の 柱）。
2. だいこくばしらを ほる（左クリック）と、まちがい を ふせぐ ため 確かめの まど「だいこくばしらを こわすと いえは キットに もどるよ」［こわす］［やめる］が 出る【PO 案】。
3. ［こわす］→ 家が ぽんっと 消えて、持ち物に「**<名前>の キット**」（**名前は そのまま**）。床の 下は かためた つちに もどる【PO 案】（同じ 所に また 建てられる）。
4. たんす・かまどの 中身、こたつの たまご、家の 中に 置いた ブロックは、柱の あった 所に アイテムと して 出る【PO 案】。

| どうづきの 範囲 | たたいた ブロック を まん中に 3×3。同じ 高さ・上が 空気（か 消える 草花）の くさ・つち・すな・ゆき が かためた つちに なる |
| どうづきの 間（ま） | 20 ステップに 1 回（トントンの リズム。押しつづけても この 速さ） |
| かためた つちを たたく | 何も 変わらない（小さい 音） |
| みずもり・どうづき | 1 マスに 1 こ。こわれない（たいきゅう なし） |

- 計算の たしかめ: 小 5×5 は 3×3 を 4 回（かさなり こみ）で ぜんぶ かたまる（例: まん中 (1,1)(1,3)(3,1)(3,3) を たたく → 0〜4 の 列・行 ぜんぶ）。大 9×9 は 3×3 が すきま なく 9 回。

### 4.5 建築の 進み
| 項目 | 値 |
|---|---|
| 時間 | §4.1（世界の 時計の ステップ。ゲームが 止まって いる 間・ゲームを とじて いる 間は 進まない） |

### 4.6 妖怪と 安全地帯
| 項目 | 値 |
|---|---|
| 家の 中の 箱 | 中の 床の はば（3×3・5×5・7×7）× 中の 3 段。ここには 妖怪が 湧かない |
| 建築中の 湧かない 範囲【PO 案】 | 建築の 場所の まん中から 横 16 マス 以内（高さは 問わない）。完成したら この きまりは 終わり、家の 中の 箱の きまりに なる |
| しまった 戸 | 妖怪には 固い（通れない・こわせない）。プレイヤーは 右クリックで あける |
| 窓 | だれも 通れない。光は 通る |
| 今の 湧きの きまり（夜・暗い 所・屋根の 下、`src/yokai/ai/spawner.ts`） | 変えない。家の 中の 箱・建築中の 範囲を 「湧かない 場所」として 足すだけ |

### 4.7 建てられる 場所
- 家の 外の 寸法 W×W の 床の 段が **ぜんぶ かためた つち**（同じ 高さ）。
- その 上の 4 段（中 3 段＋屋根）が ぜんぶ 空気 か 消える 草花（くさ `kusa`・はな・すすき・のばな）。草花は 建築開始で 消える。
- ほかの 家・建築中の 場所と 重ならない。建築士さん・動物・妖怪が 中に いない（プレイヤーは §3.4 で 外へ うつす）。

### 4.8 新しい 物の 名前（テスト用の id は 案。決めるのは developer）
- アイテム: みずもり（`mizumori`）、どうづき（`dotsuki`）、<名前>の せっけいず（`sekkeizu`）、<名前>の キット（`ie_kit`）。せっけいず・キットは 1 こずつ 中身（形・名前・番号）を 持つ。
- ブロック: かためた つち（`katame_tsuchi`）、家の 床・壁・屋根・窓・戸（あく・しまる）、だいこくばしら、足場、テーブル・いす・あんどん・ほんだな・おふろ（ふとんは 今の `futon` を 置く 形）。
- 図鑑（ZUKAN-1）: 新しい アイテムは 登録表に のる ので 図鑑にも 出る。「てに いれかた」: みずもり・どうづき ＝「けんちくし から もらう」、せっけいず ＝「けんちくし の エディター で つくる」、キット ＝「いえ の だいこくばしら を こわす」【PO 案】。
