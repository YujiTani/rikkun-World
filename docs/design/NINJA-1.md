## 1. ねらい

- がしゃどくろ を たおす たび に、ふしぎ な 力 の ある 忍者 の 防具 が 1 つ ずつ 手 に 入る。「4 回 たおせば ぜんぶ そろう」が 次 の たたかい の 目当て に なる。
- はじめて の「とくべつ な 力 つき」防具。着る と 遊び が かわる（高い 所 から とびおりる・妖怪 の そば を こっそり 通る・たたく と 小太刀 が 追いかけて 切る）。

## 2. 遊び方

1. がしゃどくろ を たおす → 大きな 宝箱 から、まだ 手 に 入れて いない 忍者 の 防具 が 1 つ、にじ色 の 袋 で とびだす（にじ色 の 光 の 柱・上 の テロップ）。
2. ひろって、今 の 防具 と 同じ ように 4 つ の マス（あたま・からだ・うで・あし）に 着る。
3. 着て いる あいだ だけ 力 が 出る（§4.3）。ぬぐ と もどる。

### 4.2 手 に 入れ方

| 出どころ | 何 が | 数 |
|---|---|---|
| がしゃどくろ を たおす（大きな 宝箱 の 中身） | **まだ 手 に 入れた こと の ない** 忍者装備 から 1 つ | 1 回 に 1 こ。4 回 で ぜんぶ |
| 宝箱（#195 で できたら） | 同じ く まだ の 物 から 1 つ | `ninjaChestChance` **0.003**（0.3%） |

- 「手 に 入れた こと」= もちもの か 防具 の マス に 入った こと。忍者帳（にんじゃちょう。中 の 名前。LegendBook と 同じ 形）に 世界 ごと に 保存 する。こわれて も 消えない。前 の 保存 → 空。読みこんだ とき に もちもの・防具 の マス に ある 忍者装備 は 帳 に 入れる（#298 で もう 足袋 を 持って いる 人 に 2 こ 目 を 出さない）。
- まだ の 物 が 2 つ 以上 → シード付き の 乱数 で 1 つ（毎回 同じ 順 に しない。**PO 確認**）。
- 4 つ ぜんぶ 手 に 入れた あと（5 回目 から）: 今 **持って いない**（もちもの・防具 の マス・手 に もった 物 に 無い）忍者装備 が あれば その 中 から 1 つ、ぜんぶ 持って いれば 出ない（**PO 確認**。やられて 落とした 物 を とりもどせる ように）。宝箱 も 同じ。
- レア素材（すいしょう など。#298 の `reward.rare`）は 今 の まま 入る。`reward.guaranteed` の `ninja_tabi` は 上 の きまり に おきかえる。
- 宝箱 は まだ 無い ので、確率 と「引く」関数 だけ 用意 する（GOLD-1 §4.7 の `harapanChest` と 同じ 扱い。AC は ユニット だけ）。

### 4.3 とくべつ な 力（着て いる あいだ だけ）

| 防具 | 力 | 表 の 数 |
|---|---|---|
| 黒頭巾 | 水 の 中 の 酸素 の へり が ×0.5 | `zukinOxygenDrainMul` 0.5 |
| 忍び装束 | 妖怪 が **気づく** 距離 が ×0.5 | 感知 の 表 の `shinobiSightMul` 0.5（§4.4） |
| 忍びの手甲 | 刀・素手 で 妖怪 に 当てる たび、おくれて 小太刀 が ＋5 | `tekkoDelayTicks` 12（0.2 秒）・`tekkoDamage` 5 |
| 忍びの足袋 | 落ちて も ダメージ 0（高さ に かかわらず） | `armorValue.ninja_tabi.fall` を どんな 落下 より 大きく（#298 の 99 では 高さ 102 から ダメージ が 出る） |

**黒頭巾**: 酸素 の しくみ は まだ 無い。着て いる 防具 から「酸素 の へり の 倍率」を 返す 関数（頭巾 0.5・なし 1）だけ 用意 し、酸素 を 作る issue が それ を 使う。

**忍び装束**:
- 気づく（`notice`。うろうろ・さがす とき に 見つける）距離 だけ ×0.5。あきらめる 距離（`giveUp`）と 高さ の 差（`sightDy`）は かえない（**PO 確認**。気づかれる まで が こっそり、見つかったら ふつう に 追って くる）。
- もう 追って いる 妖怪 は そのまま 追う。
- 効く のは 感知 の 表 で `shinobi: true` の 妖怪（今 の 4 しゅ：からかさ・ちょうちん・ぬりかべ・ろくろくび）。がしゃどくろ など 大妖怪 は この AI を 使わない ので 効かない。あとで 大妖怪 を 足す とき は `shinobi: false` に する。

**忍びの手甲**（**PO 確認** の まとまり）:
- 対象（追い打ち が 出る）: 刀 の わざ が 当たった（`techHit`。レジェンダリー の 刀 の ふつう の わざ も）・パンチ が 当たった（`punchHit`。素手。道具・ブロック を 持った パンチ も 子ども に は 同じ「たたく」なので 入れる）。
- 対象外: 弓（`arrowHit`）・レジェンダリー の 真空波・らせん・雷・ドーム（ためわざ も。これら の 当たり には 今 `techHit`・`punchHit` の ような 専用 の 出来事 が 無い ので、`LegendSystem`・`WaveSystem` の 当たり を 区別 できる 形 に する のは 開発 が 決める。名前 は 仮）・パリィ の はね返し・マッチョ の パンチ・追い打ち 自身（追い打ち は 追い打ち を 出さない）。
- 1 回 の 当たり（1 体 ごと）に 1 回。けさぎり で 2 体 に 当たれば 2 回。
- 当てた ステップ から 12 ステップ 目 に、同じ 妖怪 に 5 ダメージ。押さない（ノックバック 0）・よろけ の 2 倍 を 使わない（つぎ の 本 の わざ の ため に のこす）・武器 の 強さ に かかわらず 5。
- その とき 妖怪 が もう たおれた・消えた → 何 も しない。追い打ち で たおれた ら ふつう に たおした こと（おとしもの・実績）。
- 待って いる あいだ に 手甲 を ぬいで も、もう 出た 追い打ち は 出る。待ち の 上限 16 本（それ より 多い ときは 古い 物 から 出さない）。
- 出来事 `kodachiHit`（yokaiId・damage）を 出す（音・絵・テスト 用）。
- **がしゃどくろ にも 効く**（推奨）: 刀・パンチ が がしゃどくろ の 箱 に 当たった ら、12 ステップ 後 に 同じ 部位 に 5 を わたす（`gashaBigHit` の `damageOf(部位, 5)`。部位 の 倍率・防御力 が かかり、倍率 0 の 部位 は 0）。4 つ そろえる ため の 2〜4 回目 の たたかい が 楽 に なる ごほうび。

### 4.4 妖怪 の 感知 の 表（改修。例 `src/yokai/ai/senseTuning.ts`）

- `KIND_AI` の `sight`・`giveUp` と `AI_CONST.sightDy`、`chaseTick` の `sightDy * 2` を この 表 1 か所 に うつす。`notice()`・`chaseTick` は この 表 を 読む。数 は 今 と 同じ（**装束 なし なら ふるまい は 1 つ も かわらない**）。
- 1 行 ずつ 単位 つき の 日本語 コメント（例 `sight: 18, // ブロック: これ 以内（よこ の 距離）に 来たら 気づく`）。

| からかさ | 18 | 24 | true |
| ちょうちん | 21 | 27 | true |
| ぬりかべ | 12 | 18 | true |
| ろくろくび | 18 | 24 | true |

| 全体 の 数 | 値 |
|---|---|
| `sightDy`（気づく 高さ の 差、ブロック） | 6 |
| `giveUpDyMul`（あきらめる 高さ の 差 = sightDy × これ） | 2 |
| `shinobiSightMul`（装束 の 倍率、割合） | 0.5 |

- 開発中 に コンソール で 上書き できる（`__rikkun` の 窓口。形 は 開発）。

## 5. 例外 の とき

- 同じ 忍者装備 を 2 こ 持つ こと は、5 回目 から の きまり（§4.2）で ふつう は 起きない。起きて も こわれない（ふつう に 持てる）。
- やられた とき は 今 の 防具 と 同じ く 袋 に 落ちる（とくべつ あつかい しない）。
- 前 の 保存 の `ninja_tabi`（たいきゅう 390 の 時 の へり方）: へった 量 は そのまま、最大 だけ 10000 に なる（今 の `readWear` の まま）。

## 9. 計算 し直し（自分 で）

- 気づく 距離 × 0.5: からかさ 9・ちょうちん 10.5・ぬりかべ 6・ろくろくび 9。
- 12 ステップ = 0.2 秒（60 ステップ = 1 秒）。
- ふせぐ: 4 − 2 = 2（頭巾 ball・装束 normal）、4 − 1 = 3（手甲 normal）。

## 10. PO 確認 の 一覧

1. 装束・手甲 の ふせぐ 量 を てつ の よろい・こて と 同じ（normal 2・1）に した（§4.1）。

3. 手甲 の 対象: 刀 の わざ と パンチ（道具 を 持った パンチ も）。弓・真空波・らせん・雷・ドーム・ためわざ・パリィ・マッチョ は 対象外。よろけ の 2 倍 は 使わない。がしゃどくろ にも 部位 の 計算 で 効く（§4.3）。
4. まだ の 物 から の 1 つ は シード付き の 乱数（§4.2）。
5. 4 つ そろった あと は「今 持って いない 物」から 1 つ、ぜんぶ 持って いれば 出ない（§4.2）。
