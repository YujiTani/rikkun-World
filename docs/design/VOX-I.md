## 1. ねらい（りっくんがどう楽しむか）

- 歩いていると **景色の色と形がガラッと変わる**。「あっ、ちがう国に来た！」が 30〜55 秒に 1 回ある。
- 国が 12 あるので「つぎは どんな国かな」が長く続く。スタートから歩いて 3 分で 3〜4 つの国に出会う。
- 遠くに **どれかの山の影** がいつも見え（霧の中に 約 3 こ）、山は 4 つの形（灰色の いわやま・とがった てんぐの やま・あかい もみじやま・白いぼうしの ゆきやま）があるので「あそこまで行こう」「ほかの山も見たい」と思える。
- 国ごとに **そこでしか ない物** が 1〜2 こある（§2.2）。「あそこに行けば ○○ が ある」と覚えられる。
- 字が読めなくても、**地面の色・草木の形・山の形** だけで どの国か分かる。

### 2.1 まとめた国と理由
- **もり 3 つ → 「もり」1 つ**（A もり・B なつの もり・C こだまの もり）。3 つとも数が同じ（`trees 0.75`）で、試作のスクショでも見分けがつかない。字が読めない子には同じ国。名前は §11 で選ぶ。
- **やさいの はら → はじまりの はらっぱ に入れる**。どちらも「平らな緑」で 色・形で見分けられない。やさいは はたけ の遊びにつながるので スタートのそばで すぐ見つかる方がよい（やせいの やさい 3 倍）。
- **はじまりの さと → はじまりの はらっぱ**。中身は同じ草原。スタートの目じるしは 今の たいまつ があるので、とうろう は てんぐの やま の てっぺんだけにする。
- **はなばたけ・かっぱの ぬま は のこす**。色の点々・池 という 見て分かる形があり、ほかの国と まちがえない。

### 2.3 国だけの物の置き方（#187。乱数は シード付き）

- 国だけの物は **その国の升目の中**（いちばん近い点が その国）にだけ置く。境目（`e < blend`）には 置かない。

### 2.4 光る物と 妖怪の出かた（designer が決めた）
- **光る物は 今の たいまつ と同じ きまりを そのまま使う**（ブロックの光が 5 より大きい所には 妖怪が出ない。`isDarkForSpawn` は変えない）。
  - すいしょう（光 9）: 光は 9・8・7・6 と弱まるので、すいしょうから **3 マス以内には 出ない、4 マス目から 出てよい**（光の広がり方は 今のまま）。
  - とうろう（光 14 = たいまつ と同じ）: **8 マス以内には 出ない**。
  - 理由: 「ひかる ところは あんしん」を どの光でも同じにすると 6 歳が覚えやすい。すいしょう・とうろう は 山の上の 小さな あんぜんな場所（登ったごほうび）になる。新しい例外を作らないので 実装も テストも 小さい。
- **ぬしの木の うろ の中（空気 2×2×3 = 12 マス）には 妖怪は 出ないし、入ってこない**（昼も夜も。妖怪は 入口の前で 向きを変える）。
  - 理由: §2.2 で「ひみつきち」と言うのに 中で妖怪に会うと こわい（rules A-1 安全）。うろ は 暗い・屋根の下 なので、今のきまりのままだと 昼でも 出てしまう。光る物を うろ に足すと「その国だけの物」が かぶるので、光ではなく「出ない所」として決める。
  - 中に入る前から 中にいた妖怪は いない（出ないので）。外から とんでくる物（や など）は 今のまま。

### 2.5 ひろう・置く の例外（今のきまりに ならう）
- 持ち物がいっぱいで ひろえない時（きのこ・はな・ひまわり・かいがら・たけのこ・はすの は・すいしょう・ゆき・おちば など）: 今の「いっぱいで ひろえない」と同じ動き（ブロックは こわれても 落ちた物は 地面に のこる、など今のまま）。
- ひまわり（2 段）: 置く場所の 上の 1 マスが ふさがっていたら 置けない（今の「置けない」と同じ返し）。
- はすの は: 水面（上が 空気の 水）にだけ置ける。ほかは 置けない（今の「置けない」と同じ返し）。
- 置けない時の返しは 「おしい」の明るい音（`fun.md` 4）。今の「置けない」があれば それを使う。

## 3. 世界の作り方（#184）

### 3.1 升目と点
- 世界を 1 辺 **112** ブロックの升目に分ける（96〜128 のまん中。§3.6 で 山が入る大きさから決めた）。
- 升目ごとに **まん中で**「しめり m」「でこぼこ b」の 2 本のノイズ（`noiseScale 256`）を読み、**順位** にして §3.2 の表で国を決める。
  - 「しめり」「でこぼこ」は ノイズの名前で、本当の しめりけ ではない。
  - **順位の作り方**: ノイズの値 → 0〜1 の順位 にする表を 1 回だけ作って config に書く（シードで変えない）。作り方: シード 20261012 で 間かく 16・4096×4096（65,536 か所）の値を読み、小さい順に並べた 1% きざみの 101 この値（0%・1%・…・100%）。値が表の間なら 直線で つなぐ。表の外は 0 か 1。
- 升目の点（ボロノイ）: ふつうの国は 升目の中の 28〜84（`pointMin 28`・`pointSpan 56`）。**山の国は まん中寄り 48〜64**（`mtnPointMin 48`・`mtnPointSpan 16`）。
- いちばん近い点の国が その場所の国。境目は `e`（2 番目に近い点までの距離 − いちばん近い点までの距離）が `blend 14` より小さい所で数をまぜる。地面のブロックの切りかえは 3×3 のかたまり単位。

### 3.2 国の表（でこぼこ 3 段 × しめり 4 列）

```
            しめり m →   0〜0.25        0.25〜0.5       0.5〜0.75           0.75〜1
                       （和の がわ）                    （季節の がわ）
 山   b ≥ 0.75        いわやま        てんぐの やま     もみじやま          ゆきやま        各 6.25%
 おか 0.375〜0.75     すすきの はら    たけやぶ         おおきな きの もり    もり           各 9.375%
 たいら b < 0.375     すなはま        かっぱの ぬま     はじまりの はらっぱ   はなばたけ       各 9.375%
```

- 合計: 6.25 × 4 ＋ 9.375 × 8 = 25 ＋ 75 = 100%。
- **和の国**（すすき・たけやぶ・かっぱ・てんぐ）は 左の 2 列、**季節の国**（おおきな きの もり・はなばたけ・もみじ・ゆき）は 右の 2 列。ノイズはなめらかなので となりの升目は表でも となりになりやすい → 和どうし・季節どうしが 近くに集まる。
- 山の すそ は 同じ列の「おか」の国になりやすい: いわやま → すすき、てんぐ → たけやぶ、もみじ → おおきな きの もり、ゆき → もり。
- すなはま（左下）と 山（上の段）の間には「おか」の段（はば 0.375）がある。

### 3.3 決める順番（どの順で作っても同じになる）
1. 表を引く（§3.2）。
2. **まびき**（山の国どうしは となりあわない）: 表で山になった升目は、**まわり 8 升目（3×3）の中で、表で山になった升目のうち b がいちばん大きいときだけ** 山の国。同じ値なら x が小さい方、つぎに z が小さい方。山になれなかった升目は **同じ列の「おか」の国**（ふもとの国）。はじまり（4.）で はらっぱ になる升目も この比べっこには入る（スタートのそばに山の点ができにくい）。
3. **山と すなはま**: すなはま の升目の まわり 8 升目に 2. のあとの山の国があれば、その升目は すすきの はら。
4. **はじまり**: 点が anchor（x 64, z 64）から **`startForce 80`** 以内の升目は はじまりの はらっぱ（山でも）。
- どれも まわり 2 升目以内の ノイズだけで決まる → 作る順に関係なく同じ。
- まびきで 山の点どうしは 升目 2 つ以上はなれる（点どうし 最低 224 + 48 − 64 = 208 ブロック）。山のすそ（頂上から 約 43）どうしが重ならない → 連山にならない。
- 山の国は 表の 25% から へる（目安 8〜12%）。§9 #184-AC3 の下限に届かなければ designer に差し戻し（しきい 0.75 を下げる）。

### 3.4 地面のきまり（となりの国の地面が すそに出ても変にならない）
- **すな は すなはま の 海から +8 より低い所だけ**。それより上は くさ（はまの おか）。
- **ゆき は ゆきやま の 海から +40 以上だけ**。それより下は くさ（すそは緑、てっぺんが白い ＝ 白いぼうし）。
- いし: いわやま 海から +20 より上・てんぐの やま +30 より上（今の `stoneTopFrom` のきまりは そのまま）。
- **すなはま の高さ**: 大陸の ふつうの高さ（海から 10〜20）に `landShift −12` で 海から −2〜+8 → すなはまの陸の 多くが すな、ひくい所が あさい海。半分より 草 が多い升目が出るなら designer に差し戻し（#184-AC13）。

### 3.5 はじまりの国
- スタートの升目の点は anchor から 最大 √(36² + 36²) ≈ 51（点は 28〜84、anchor は 64）→ 80 以内なので 必ず はらっぱ。`spawn()` の「はじまりのバイオーム」が必ず見つかる。

### 3.6 そびえる山
- 山の足し分 = `peak` ×（`e` が `mtnFrom` で 0、`mtnTo` でいっぱいになる なめらかな上がり `smoothstep`）× はじまりの土地の弱め `(1 − w)`。

- **頂上で `e` は 76 以上**: 山の点は 升目の 48〜64、まわり 8 升目は山でないので 点は 28〜84。いちばん近くても 112 + 28 − 64 = 76。
- 頂上で peak の 8 割以上: `mtnTo ≤ 14 + 62 ÷ 0.72 ≈ 100`（t = 0.72 で 0.81）。
- 今の山 `mountain.peak` は 50 → **20**（山の国以外の高台用）。高さの上限 y 270（海から 126）は今のまま。頂上がまれに平らに切れるのは よい。

## 8. テストで聞くこと（`window.__rikkun.biome`。値の形の約束）

3. **名前のふだ**（§4）と 12 国 ぜんぶ見つけた時の 紙ふぶき を入れるか。
4. **国だけの物**（§2.2）: 入れない物・とりかえたい物は あるか。
5. **とうろう は こわせない**（§5）で よいか。**うろ の中は 妖怪が出ない・入らない**（§2.4）で よいか。
