# VOX-I: 地形の種類（バイオーム）の 3 案（仕様書・案の段階）

- issue: #99（VOX-I）・#87（オーナー要望）。計画: `docs/design/VOX-plan.md` §3。
- この版は **オーナーが 1 つ選ぶための 3 案** だけ。選ばれたら、その案で仕様の全部（受け入れ基準・見た目の依頼・テスト）を書く。
- 数のもと: `src/world/gen/config.ts`（`biomes` は 草原・森 の仮 2 種）、`src/world/gen/terrain.ts` の `raw()`、`src/world/micro/microSurface.ts` の `MICRO_PARAMS`・`MICRO_FOREST`、`docs/art/DESIGN.md` §5.4。

## 1. ねらい（りっくんがどう楽しむか）

オーナーの要望（#87）: 「地形ごとの出会いがあると、もっとワクワクする」。

- 歩いていると、**景色の色と形がガラッと変わる所** に出る。「あっ、ちがう国に来た！」が 30〜60 秒に 1 回ある。
- 遠くに **大きな山の影** が見えて、「あそこまで行ってみよう」と思える（霧の向こう 360 ブロックまで影が見える）。
- 国ごとに **そこでしか とれない物・見られない物** が 1 つ以上ある（「つぎは 何が あるかな」）。
- 字が読めなくても、**地面の色・木の形・山の高さ** だけで、どの国か分かる。

## 2. 3 案に共通のきまり

### 2.1 種類の決め方（今のしくみのまま、数だけ変える）
- 世界を 1 辺 `cell` ブロックの升目に分け、升目ごとに点を 1 つ置く（ボロノイ）。いちばん近い点の種類が、その場所の種類。
- 点ごとに「しめり」「でこぼこ」の 2 本のノイズを読み、**順位（0〜1 に均一にならした値）** にしてから、案ごとの表で種類を引く。順位にするのは、表に書いた割合（％）がそのまま出るようにするため。
- 境目は今と同じく、近い 2 点の距離の差 `e`（= 2 番目に近い点までの距離 − いちばん近い点までの距離）が `blend` より小さい所で数をまぜる。地面のブロックの切りかえは 3×3 のかたまり単位（`DESIGN.md` §5.4 のカクカク）。

### 2.2 はじまりの国
- **点がスタートの角（`anchor` = x 64, z 64）から `startForce` ブロック以内の升目は、はじまりの国（今の「草原」）にする**。スタートさがし（`spawn()` の「はじまりのバイオーム」）が必ず見つかるように。
- スタートの升目の点は anchor から 最大 約 45（A・B）／ 約 57（C）なので（§7.4）、`startForce`（A・B 96、C 72）以内 → 必ずはじまりの国になる。
- はじまりの土地（スタートから 48 で平ら、192 でふつうに戻る）は今のまま。この中では山も丘も小さくなる。

### 2.3 そびえる山（A・B・C どれでも使う）
- 今の山（`mountain.peak = 50`、512 ブロックのノイズ）は、まれにしか高くならず「ゆるい丘」に見える。**山の国では、点を頂上にした山を 1 つ立てる**（どこに山があるか 遠くから分かる）。
- 山の足し分 = `peak` ×（`e` が `mtnFrom` で 0、`mtnTo` でいっぱいになる なめらかな上がり）× はじまりの土地の弱め `(1 − w)`。
  - `e < blend` の所（境目）は足し分 0 → **となりの国との間に高い崖ができない**。
  - `e` は点に向かって 1 ブロック進むと 最大 2 ふえるので、すそから頂上まで およそ `(mtnTo − mtnFrom) / 2` ブロック歩く。
- 今の山 `mountain.peak` は 50 → **20** に下げる（山の国以外の「高台」用。山の国と重なって上限 y 270 にぶつかる回数を減らす）。
- 高さの上限は今のまま y 270（海から 126）。頂上がまれに平らに切れるのは よい（てっぺんの広場）。
- 升目の点のはば: 山を真ん中に立てるため、点を升目のまん中寄りにする（A・B: `pointMin 32`・`pointSpan 64`。となりの点とは 最低 64 はなれる）。

### 2.4 はじめて入ったときの「名前のふだ」（入れるかもオーナーが選ぶ）
- その国に **はじめて** 入ったとき（境目をこえて まん中寄り `e ≥ blend` に 3 秒いたとき）だけ、画面の上に国の名前のふだ（ひらがな・漢字はふりがな）と国の小さな絵を 3 秒出し、短い明るい音を 1 回鳴らす。
- 2 回目からは出さない（くり返しは控えめ。`fun.md` 1）。全部の国を見つけたら「ぜんぶ みつけた！」で紙ふぶき（達成。`fun.md` 2）。
- 画面の配置: 画面の上のまん中、横はば 画面の 40%（最小 280px・最大 480px）。いちばん長い名前（C 案「こだまの もり」など 7 字＋ふりがな）でも 1 行。ホットバー・体力の表示と重ならない。小さい画面（横 800px 以下）は 文字を 8 割にする。
- 色・音の細かいきまりは アート（`docs/art/DESIGN.md`）・サウンド（`docs/audio/SOUND.md`）に任せる。

### 2.5 変えないこと
- 妖怪の強さは場所（スタートから遠い・地下）で決まる（決定済み）。国では変えない。
- 鉱石・洞くつのきまり、海面 y 144、陸の上限 y 270。
- 形のカクカク（3×3 のかたまり、坂 6 割・崖 4 割）。

## 3. 案 A「すぐ あそべる 5 つの くに」（新しいブロック 0）

**方向**: 今あるブロックだけで、オーナーの例（森・岩山・砂浜）＋ 野菜の原。絵の仕事なしで、いちばん早く入る。

| 国の名前 | ひとこと | 出会うもの |
|---|---|---|
| はじまりの はらっぱ | 今の草原。ひろくて 平ら | ゆるい丘、ときどき木、小さな岩 |
| もり | 木が いっぱい | 木のトンネル、草むら・岩・土が多い。**大きな木**（みき 7〜9 の「ぬしの木」）が 1 升目に 1 本 → 目じるし |
| いわやま | 灰色の 大きな山 | 海から 約 70〜90 の山。上は いし。**見える せきたん・てつ が多い**（ほりに行きたくなる）。頂上から遠くが見える |
| すなはま | 黄色い すなと あさい海 | 地面が すな、ひくくて平ら。海の近くでは入り江・あさせ・小さな島（じゃぶじゃぶ歩ける） |
| やさいの はら | 野菜が はえてる 原っぱ | やせいの たまねぎ・トマト・かぼちゃ・なす が はらっぱの 4 倍。ひろって はたけ に植えられる |

- **種類の表**（でこぼこ順位 b・しめり順位 m）: b ≥ 0.85 → いわやま（15%）／ それ以外で m < 0.2 → すなはま（17%）、0.2〜0.35 → やさいのはら（12.75%）、0.35〜0.6 → はらっぱ（21.25%）、0.6 以上 → もり（34%）。合計 100%。しめりの順に すなはま → やさい → はらっぱ → もり と並ぶので、となりどうしが自然。
- **山**: いわやま の peak 50、`mtnFrom 16`・`mtnTo 128`（すそから頂上まで 約 56 ブロック。平均で 1 ブロック進んで 0.9 上がる、いちばん急な所で 約 1.3。自動ジャンプで 1 段ずつ登れる。崖の所は まわり道）。
- **山の多さ**: 15% の升目。いちばん近い山の まん中は ふつう 150〜350 ブロック先（192 より内は低い）。霧の中（360）に 平均 3〜4 こ の山の影。
- **広さ**: 1 つの国は 1〜2 升目（128〜256 ブロック）。まっすぐ歩くと 約 130〜250 ブロック（歩いて 33〜65 秒、走って 23〜45 秒）ごとに 次の国。スタートから最初の別の国まで 約 100〜170 ブロック。
- **新しいブロック・絵**: なし。すなはま の地面は すな、いわやま の上は いし（今のタイル）。
- **重さ**: いわやま（高い崖・岩が多い）と もり（木）が三角形をふやす。すなはま・やさいのはら は 草原より軽いか同じ。

## 4. 案 B「きせつの くに」（新しいブロック 3）

**方向**: マイクラに近い数（6 種・雪山あり）だが、気候ではなく **「はる・なつ・あき・ふゆ」が となりあう** ふしぎな世界にする。6 歳が知っている季節で、色だけで国が分かる。

| 国の名前 | ひとこと | 出会うもの |
|---|---|---|
| はじまりの はらっぱ | はるの 原っぱ | 今の草原（やせいの野菜 少し） |
| はなばたけ | 花が いっぱいの はる | 黄・だいだい・うすむらさき の **はな**（3 色。ピンクは使わない、`DESIGN.md` §6）。ひろって 置ける |
| なつの もり | こい緑の もり | 木がいっぱい。草むら多め |
| おおきな きの もり | 大きな木が ならぶ | みき 2×2・高さ 10〜14 の 大木（今の き・はっぱ で組む）。木の下は 暗めで すずしい |
| もみじやま | あかい・きいろい あきの 山 | 海から 約 50〜65 の山、**もみじの はっぱ**（だいだい・黄）の木 |
| ゆきやま | しろい ふゆの 大きな山 | 海から 約 80〜100 の いちばん高い山。地面が **ゆき**（真っ白は使わず うす水色ぎみ、キャラの白い髪とかぶらない）。頂上から 全部の国が見える |

- **種類の表**: b ≥ 0.82 → 山（18%）。そのうち m ≥ 0.5 → ゆきやま（9%）、m < 0.5 → もみじやま（9%）／ それ以外: m < 0.3 → はなばたけ（24.6%）、0.3〜0.55 → はらっぱ（20.5%）、0.55〜0.8 → なつのもり（20.5%）、0.8 以上 → おおきなきのもり（16.4%）。合計 100%。
- **山**: ゆきやま peak 60（`mtnFrom 16`・`mtnTo 144`、すそから 約 64 ブロック、平均 0.94・急な所 約 1.4）。もみじやま peak 35（`16〜128`、約 56 ブロック、平均 0.63・急な所 約 0.94）。
- **山の多さ**: 18% の升目。いちばん近い山は ふつう 140〜330 ブロック先。
- **広さ**: 升目 128 のまま、しめり・でこぼこ のノイズを 384 → **320** に（国が少し小さく、変わりやすい）。次の国まで 約 120〜230 ブロック（歩いて 30〜58 秒）。
- **新しいブロック・絵**: **はな**（十字の板の草花、3 色）・**もみじの はっぱ**・**ゆき**（地面）。アートの 3 案 → オーナー選び が要る。
- **重さ**: はな（十字の板）がいちばん増える → 1 列（16×16）に 40 本まで。おおきなきのもり の大木は はっぱ が多い。ゆきやま は高い崖。

## 5. 案 C「ようかいの さと」（新しいブロック 2）

**方向**: マイクラにない **和の景色**。国の名前に 友だちのような妖怪（ようかい）の名前を入れ、「この国には だれが すんでるのかな」と思わせる（妖怪が本当に出るかは 別の issue。強さは場所のまま）。升目を小さくして、箱庭のように **つぎつぎ 景色が変わる**。

| 国の名前 | ひとこと | 出会うもの |
|---|---|---|
| はじまりの さと（里（さと）） | ひとが すむ 原っぱ | 今の草原、やせいの野菜。スタートの近くに いしの **とうろう**（いし と たいまつ で組む）が 1 つ |
| こだまの もり（木霊（こだま）） | しずかな もり | 木がいっぱい、草むら・岩が多い |
| たけやぶ | まっすぐな たけが びっしり | 高さ 4〜7 の **たけ**（細長い緑の柱）の林。間を くねくね 細い道が通る（迷路みたい）。たけ は きって とれる |
| すすきの はら | きんいろの 原っぱ | 背の高い **すすき**（金色の草）がゆれずに立つ、ゆるい丘。ひろくて 遠くまで見える |
| てんぐの やま（天狗（てんぐ）） | とがった 岩の 山 | 海から 約 55〜70 の山、まつ（平たい はっぱ の木、今の き・はっぱ）。**てっぺんに とうろう** → 登ったごほうびと目じるし。見える てつ が多い |
| かっぱの ぬま（河童（かっぱ）） | 小さな 池が いっぱい | ひくく平ら。1 升目に 4〜8 この **いけ**（はば 4〜8、深さ 1〜2 の みず。まわりより 1 段ひくい くぼみで、こぼれない形）。草むらが多い |

- **種類の表**: b ≥ 0.84 → てんぐのやま（16%）／ それ以外: m < 0.2 → すすきのはら（16.8%）、0.2〜0.45 → はじまりのさと（21%）、0.45〜0.65 → こだまのもり（16.8%）、0.65〜0.82 → たけやぶ（14.28%）、0.82 以上 → かっぱのぬま（15.12%）。合計 100%。
- **山**: てんぐのやま peak 40（`mtnFrom 12`・`mtnTo 96`、すそから 約 42 ブロック、平均 0.95・急な所 約 1.4）。
- **山の多さ**: 16% の升目。いちばん近い山は ふつう 190〜300 ブロック先（192 より内は低いため）。
- **広さ**: 升目 **96**（`pointMin 24`・`pointSpan 48`、となりの点とは最低 48）、ノイズ **256**、境目 `blend` **12**、`startForce` **72**。1 つの国は 1〜2 升目（96〜192 ブロック）。次の国まで 約 96〜190 ブロック（歩いて 24〜48 秒）。スタートから最初の別の国まで 約 70〜130 ブロック。
- **新しいブロック・絵**: **たけ**（固い・こわせる・持ち物になる）、**すすき**（十字の板の草、こわすと消える）。とうろう・まつ・いけ は 今のブロックで組む。
- **重さ**: たけやぶ（細い柱がびっしり → 見える面が多い）がいちばん重い → 1 列に 60 本まで。いけ は 水の面がふえる。升目が小さいので 境目のまぜる所がふえる（生成が少し重い）。

## 7. 数の表（PO の試作用。config にそのまま近い形）

- 草原（今）: `hillScale 64, hill 10, bump 1.5, cliff 0.04, trees 0.09`、MICRO: `tuft 0.6, rock 0.4, soil 0.22`（`tuft`・`soil` は しきい。tuft が小さいほど草むらが多い、soil が大きいほど土が見える所が多い）。
- 新しい項目: `ground`（いちばん上のブロック）、`peak`・`mtnFrom`・`mtnTo`（§2.3）、`landShift`（その国の高さを まるごと上げ下げ。境目でまぜる）、`wild`（やせいの野菜の量。はらっぱ = 1 倍）、`visibleOre`（見える せきたん・てつ の倍率。今 = 1）、`extra`（その国だけの物）。
- 共通で変える数: `height.mountain.peak 50 → 20`、`biome.startForce`（新）。

### 7.4 計算のたしかめ（designer が計算し直した）
- 割合の合計: A 15 + 17 + 12.75 + 21.25 + 34 = 100。B 9 + 9 + 24.6 + 20.5 + 20.5 + 16.4 = 100。C 16 + 16.8 + 21 + 16.8 + 14.28 + 15.12 = 100。
- 山のいちばん高い場合（海から）: 大陸の上限 50 ＋ 高台 20 ＋ peak ＋ hill ＋ bump。A 50+20+50+16+3 = 139、B 149、C 50+20+40+14+3 = 127 → どれも上限 126 をこえることがある（まれ。頂上が平らに切れる）。ふつう（大陸 10〜20・高台 0〜5・peak の 9 割・hill の半分）は A 約 70〜90、B ゆき 約 80〜100・もみじ 約 50〜65、C 約 55〜70。
- 坂の急さ: 平均 = peak ÷ ((mtnTo − mtnFrom) ÷ 2)、いちばん急 = 平均 × 1.5。A 50÷56 = 0.89 → 1.34。B ゆき 60÷64 = 0.94 → 1.41、もみじ 35÷56 = 0.63 → 0.94。C 40÷42 = 0.95 → 1.43。
- スタートの升目の点: x・z とも 32〜96（A・B）／ 24〜72（C）。anchor (64,64) からの距離は 最大 √(32²+32²) ≈ 45（A・B）、√(40²+40²) ≈ 57（C）。どちらも `startForce` 以内 → スタートは必ず はじまりの国。
- 歩く時間: 歩き 4.0、走り 5.6 ブロック/秒（`src/player/config.ts`）。128 ブロック = 32 秒（走って 23 秒）。
