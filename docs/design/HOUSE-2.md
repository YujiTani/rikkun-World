### 2.2 おぼえる（決定 3 ＝ A を 3.3 版で かえた: 「拾った 場で」→「**使った とき**」。yuzu 11-11 09:45）
- **使い方**: ホットバーで レシピの まきもの を えらんで（手に もって）**右クリック**。たべもの（やさい・たまご。`src/content/items/howText.ts` の「もって みぎクリック」、`src/dig/digFarm.ts` の たべる 道）と 同じ 道で、右クリックの はたらきが ある ブロック（戸・たんす・家具 など）を ねらって いる ときは そちらが 先（たべもの と 同じ きまり）。右の 案内は「**よむ**」。説明の 行: つかいかた「ひらいて よむと いえの つくりかたを ひとつ おぼえる」、どう つかう「もって みぎクリック」。
- 使うと まきもの が **1 まい へり**、その とき どの レシピか 決まって おぼえる: まだ おぼえて いない 物から 1 まい（シードつきの 乱数。**世界の シード と おぼえた 物 だけ から**。どの 坑道で 拾った まきもの か・何まい 持って いるか には よらない ので、使う 前に 保存して 開きなおしても 同じ）。同じ 物は 2 回 出ない。**1 まい目は かならず かわらの やね**（はじまりの 坑道は スタートから 24〜48 マス なので、はじめの 1 まいは すぐ 見つかる）。
- 使うのは 持ち物の 中で **手に もって いる とき だけ**（持ち物の 画面で マスを 押しても・たんすに 入れても・落ちて いても おぼえない）。1 回の 右クリックで 1 まい（長押しで 続けて 使わない。右クリックを はなして もう 1 回）【PO 案】。
- **ぜんぶ おぼえた あとに 使った**: まきもの 1 まい へって **かみ 3 まい**（決定 7。持ち物へ、入らない 分は 足もとに 落とす）と テロップ「もう ぜんぶ おぼえて いるよ。まきものは かみに なった」【PO 案 B。§7 の 15】。
- おぼえた とき（使った その 場）: テロップ「〇〇の レシピを おぼえた！ けんちくしさんの せっけいずで えらべるよ」（宝箱の テロップ〔NINJA-1 §3.2〕と 同じ 出し方）と 短い 音。〇〇 は §4.1 の レシピの 名前（「かわらの やね」。むら・おしろ・こうざん は つけない）。
- **2P**（COOP-1）: 持ち物は 1P・2P 別々 なので、まきものは 拾った・あけた 人の 持ち物に 入り、その 人が 使う。おぼえた 物は 世界に 1 つの 記録 なので、だれが 使っても 両方の エディターで えらべる。テロップ・紙ふぶきは **使った 人の 半分**（COOP-1 §3.7 (g)・表の 18 の「起こした 人の 半分」）。たんすに 入れて わたせる。
- おぼえた 物は 世界に 1 つの 記録（どの 建築士さんでも 同じ。セーブに 入る）。なくならない。
- **ぜんぶ おぼえた とき**（最後の 1 まいを 使った とき）は テロップを「レシピを ぜんぶ おぼえた！」に して、小さな 紙ふぶき（`docs/fun.md` §2。あつめきった 達成）。
- まきもの を 拾う・宝箱から 出る のは くり返す 行動 なので、拾った ときの 演出は いつもの 拾った 表示 だけ（音・テロップを 足さない。はじめての 1 回の 使い方の テロップ だけ 例外）。大きく よろこぶのは 使って おぼえた とき。

### 2.3 エディターで えらぶ（HOUSE-1 §2.5 を かえる。3 版で ポップアップに）

**① そとの パネル**: 上から「よこ」「たて」／「まどの かず」（HOUSE-1 の まま。yuzu 22:29 で のこす）／**ばしょの ボタン 5 つ**（やね・かべ・まど・と・かざり）。パネルの 名前の 行は なくし、名前は ヘルプ（下）で 出す。かざりの ボタンは かざりを 1 つ おぼえる まで 出さない（あいた 所は つめない。ほかの ボタンの 場所は かわらない）。
- **ばしょの ボタン**（yuzu 22:29「もっと わかりやすい 絵 ＋ 字」）: 上に その ばしょが 一目で 分かる 絵（アート。§3.4）、下に 字「やね」「かべ」「まど」「と」「かざり」（ひらがな。漢字は 使わない ので ルビは いらない。もし 漢字に する なら `ruby()` で ふりがなを 付け、高さは §3.2 の とおり ＋12）。えらんで いる 物の ✓ は ない（ばしょは えらぶ 物 では ない）。「あたらしい！」の 小さな 印は 絵の 右上。

**名前の ヘルプ**（yuzu 22:29。【PO 案】の 細部）:
- ばしょの ボタン・ポップアップの しゅるいの ボタンに マウスを のせて **0.2 秒（12 コマ）** で、カーソルの 近くに 名前の ふきだしが 出る。はなすと すぐ 消える。出て いる 間に となりの ボタンへ うつると 待たずに 切りかわる。押しても 消えない。
- 中身: しゅるいの ボタン ＝ しゅるいの 名前 1 行（例「おしろの かわらの やね」）。ばしょの ボタン ＝ 1 行目 ばしょの 名前、2 行目「いま: 〇〇」（その ばしょで えらんで いる しゅるい。かざりは「いま: 2 つ」・何も なければ「いま: なし」）。字は ひらがな・カタカナ、漢字が 入る ときは `ruby()`。
- 置き場所: **カーソルの 近く（マウスに ついて うごく）**（yuzu 22:29「カーソルの 近くが いい」・PO の 答え その 2 の 13。2026-11-10）。ふきだしは カーソルから 少し ずらして（ずらし 幅は developer。ゲームの 共通の ツールチップ `placeNear` と 同じ 考えで よい）**カーソルの 先を かくさない**。同じ ボタンの 上で マウスを うごかすと ふきだしも 同じだけ うごく（待ちなおさない）。右・下に 入らない ときは 左・上へ 出す。画面の ふち（16・24・32）で 止めて はみ出さない。ヘルプは 押せない 物（マウスを 通す）で、ほかの 物の 上に 重なって よい。（3.2 版の はじめの「ボタンに 合わせて 固定・上 8」は やめた）
- HOUSE-1 の 名前の 行（① の パネル・2 版の ポップアップの 下の だん）は **この ヘルプに おきかえる**（同じ 名前を 2 か所に 出さない。画面の 高さも あく）。② の 家具の 名前・③ は 今の まま。

**ばしょの ポップアップ**（しゅるいの 一覧）:
- ばしょの ボタンを 押すと 開く。① の パネルと 同じ 場所・同じ はば・まん中の 高さ いっぱい で パネルの 上に 重なる（§3.2）。**見本（左）は かくさない・暗く しない**（えらぶ たびに 家が かわるのを 見る）。見本は 開いて いる 間も ドラッグで まわせる。
- 上の だん: 左に その ばしょの 絵と 名前（「やね」など）、右に **✕**（とじる）。
- まん中: しゅるいの ボタン（絵 だけ・正方形）を **なかまごとに 1 行ずつ**、上から **いつもの**（なし・はじめから ある 物）→ **むら** → **おしろ** → **こうざん** の 順に ならべる。**行の 見出し・印は 付けない**（yuzu 22:29。行が かわる ことで なかまが 分かる）。いつもの 行は「なし」が いちばん 左（やね・かべ・まど だけ）。1 行 5 こ まで、こえたら その なかまの 中で 次の 行へ 折りかえす（今は いちばん 多い 行でも 4 こ）。**まだ おぼえて いない 物は 出さない**、行の 中は 左から つめる、空の 行は 出さない（すき間を あけない）。
- 名前の 行は 置かない（名前の ヘルプで 出す）。

### 2.4 建てる（HOUSE-1C に 足す）
- せっけいずに えらんだ 物が 入り、その とおりに 建つ（むら・おしろ・こうざん の 形も そのまま）。家の 外の 寸法（よこ・たて）は かわらない。**高さだけ** やね と かざりで かわる（§4.2 の 家の 箱。案では かわらない）。建てられる 場所の「上が 空気」の しらべも その 高さまで。
- 建てた 家は 今と 同じ ふつうの ブロック（決定 HOUSE-1 新 10）。てつの と（3 案 とも）は いえの と と 同じ はたらき（あく・しまる・妖怪には 固い・戸で 家の 名前を おぼえる）。まるい しょうじ・すいしょうの まど も しょうじと 同じ（だれも 通れない・光は 通る）。のれん は 固く ない（通れる。戸は ふつうに あく）。
- あかり 3 つ とも ちょうちんと 同じく まわりに 妖怪が 湧かない（ITEM-FX-1 の しくみ。家の 中は 安全地帯 の まま）。
- **「なし」の 家**（§2.3）: やね なしは 屋根の 段 なし（家の 箱が 低く なる。§4.2）、天井の ちょうちんは いつもの 高さ（中の 3 段目の まん中）に つるす（上に 何も ない が 落ちない）。かべ なしは 外まわりに 4 すみの 柱 と 戸 だけ。まど なしは 窓の 所が 空気。
  - **安全地帯**（HOUSE-1 §2.11）: 湧かないのは ちょうちん（あかり）の 力 なので、なしでも **中で 妖怪は 湧かない**（かわらない）。家の 記録は 湧きに 使わない（HOUSE-1 §2.11 の 2）ので 足す 物は ない。ただし かべ なし・まど なしの あなからは 妖怪が **歩いて 入れる**（しまった 戸の 守りは かべが ある 所 だけ）。これは えらんだ ときの ふきだし（§2.3）で 先に 知らせる。
  - **家の 記録・名前の 帯**: 戸で おぼえる（HOUSE-1 §2.11 の 4）ので かべ なしでも 戸が あれば 家。帯は 戸を 通って 入った とき だけ 出る（柱の あいだから 入ると 出ない）。
  - **できた！の しらべ**（HOUSE-1 §2.5）は かえない（ふとん 1 以上・あかり 1・赤い 家具 なし・よくない ことば なし）。なしは できた！を とめない。
- 建築の 時間は かえない（HOUSE-1 §4.1 の 式。なしでも 同じ）。見た目の 段階（HOUSE-1 §4.5）の 85〜100% に やね・かざり も 入る。
- 建てた あとで やねを かえたい ときは 手で 作りかえる。エディターで 建てた 家を 直す しくみは 作らない。

### 2.7 手で 置いた 家の 物の 案を おぼえる（3.4 版。2B の PO 決め「ブロックの 番号は 形ごと・案は 家の 記録から 場所で 引く・手で 置いた ブロックの 案は 2C で 決める」の つづき）
2B から ブロックは **形ごと**（`src/world/blocks/houseLookBlocks.ts` の `lk_*` 20 こ）で、むら・おしろ・こうざん は 家の 記録から 場所で 引く（`HouseBook.lookAt`・`dugItemAt`）。家の 外に 手で 置いた `lk_` ブロックには 家の 記録が ない ので、**置いた ときの 記録**を 世界に 1 つ もつ。

- **書く とき**: 案の ある 家の 物の アイテム（`<ばしょ>_<形>_<案>`。例 `roof_kawara_shiro`。13 の 形 × 3 案）を 手で 置いた とき、その マスに **案（`mura`・`shiro`・`kozan`）と 向き（`n`・`e`・`s`・`w`。前が 向く 方位。§2.6 の 置き方で きまる）** を 書く。むら でも 書く（家の マスに 置いた ときの ため。下の 順）。てつの と は 下と 上の 2 マス とも 書く。案の ない 物（いつもの 物・しゃちほこ・あかり・柱・家具）は 書かない。
- **消える とき**: その マスの ブロックが ほかの 物に かわったら すぐ 消える（ほる・水が 入る・建築士さんが 置きかえる・テストの `setBlock`・ほかに こわす しくみが 入ったら それも）。ただし **同じ 形の ブロックの あいだの かわり**（てつの との あく・しまる ＝ `lk_door_tetsu*` の 4 つ の あいだ）では 消えない。建築士さんが 家を 建てて その マスを 置きかえた ときは、同じ id を 置いても 消す（建築士さんの 置き方が 記録を 消す。「ブロックが かわった」の 見かたに よらない）。ほって アイテムが 出る ときは、消す 前の 案で アイテムを きめる（ほる・水 どちらでも、アイテムが 出る なら その 案）。いまの ゲームに ばくはつ は ない（入れる ときは ほる と 同じ きまり）。
- **どの 案か の 順**（見た目・ほった アイテム・`house.lookOf` が ぜんぶ 同じ 答え）: ① この 置いた ときの 記録 → ② 家の 記録（`HouseBook.lookAt`。その マスの ブロックが その しゅるいの ブロックの とき だけ。2B の `dugItemAt` の まま）→ ③ その 形の むら。**PO 案（家の 記録が 先）を かえた わけ**: 家の かべ（例 おしろの しっくい）を ほって、手で 作った こうざんの しっくいの かべ を 同じ マスに 置くと、ブロックは 同じ `lk_wall_shikkui` なので 家の 記録が 先だと「おしろ」に 見えて しまう。置いた ときの 記録は「その マスに 今 ある ブロックを 置いた 時」の 物 なので いつも 新しい。家を 建てる ときは 建築士さんが 置きかえた マスの 記録が 消える ので、家の 中は 家の 記録の 答えに なる。
- **向きを 使う 物**: やね（のき が その 向き）・のれん・はなだん・えんとつ（前が その 向き）。まど は しょうじ と 同じく となりの かべで、てつの と は いえの と と 同じく 南向き（向きは 書くが 使わない）。
- **保存の 形**（世界の セーブ。家の 記録と 同じ 世界の 物。1P・2P の 物 では ない）: キー `placedLooks` ＝ `[x, y, z, 案, 向き][]`（例 `[12, 64, -3, 'shiro', 's']`。x・y・z は 整数、案は `'mura' | 'shiro' | 'kozan'`、向きは `'n' | 'e' | 's' | 'w'`）。並びは きめない。
  - 読む とき: キーが ない（3.4 版より 前の セーブ）なら 記録 なし。形が おかしい 1 行は とばす（`HouseBook.restore` と 同じ）。その マスの ブロックが 案の ある `lk_` ブロック で ない 行は すてる。同じ マスが 2 行 あれば あとの 行。
  - 記録の 数は いつも 世界に 今 ある 手置きの 案の ある ブロックの 数 以下（消える とき が ある ので ふえつづけない）。
- **性能**: 1 マスの 案を しらべる 仕事は 記録の 数に よらない（記録を 10 倍に しても 1 マスで 記録を 見る 回数は ふえない。AC18b）。毎ステップ 記録 ぜんぶを 読む 物は 作らない。描きなおしは 置いた・消えた マスの 区 だけ（今の ブロックを 置いた ときと 同じ）。
- **建築士さんの 家と 重なる**: 建てる 場所は 床の 上 H − 1 段が 空気 で ない と 建たない（§4.2）ので、手置きの ブロックが 箱の 中に あれば ふつうは 建たない。床の 段・まわりの 足場 など 建築士さんが 置きかえた マスは 記録が 消える（家の 記録の 答えに なる）。建てた あとで 家の マスを ほって 手で 置くと 置いた 記録が 先（上の 順）。
- **2 人**: 記録は 世界に 1 つ。だれが 置いても 書き、だれが ほっても その 案の アイテムが ほった 人の 持ち物に 入る（入らなければ 今の 落とし方）。向きは 置いた 人から 見て きめる。同じ コマに 2 人が 別の マスに 置いても それぞれ 書く。

## 5. 例外の とき
- 持ち物が いっぱい: 宝箱・床の まきもの から 出た レシピの まきもの は 足もとに 落とす（宝箱の ほかの 物と 同じ。拾えば 入る。落ちた 物の きえ方も いつもの 落とし物と 同じ）。使って かみ 3 まいに なる ときも 入らない 分は 足もとに 落とす（使った まきものの マスが あく ので、たいてい 1 マスは 入る）。
- まきもの を 持った まま 使わない: いつまでも おぼえない（持ち物・たんす・落とし物 どこに あっても 何も おきない）。エディターにも 出ない。
- まきもの を 何まいも 持って いて、のこりの レシピより 多い: のこりを 使いきった あとの 分は かみ 3 まいずつ（案 B）。
- おぼえて いない 物は エディターで えらべない ので、せっけいずに 入る ことは ない。読みこんだ セーブの 作りかけ・せっけいずに、おぼえて いない しゅるい や 知らない id が ある ときは、その ばしょを いつもの 物（かざりは はずす）に して 読む【PO 案】。1 版の せっけいずは いつでも 建てられる。
- 2 版の 形の id（`kawara` など 案の ない id）が 作りかけに ある（2A の 前の 試作の セーブ）: 案 むら の 物と して 読む【PO 案】。
- 宝箱の ない 坑道の まきものを とらずに 帰った: 次に 来た とき まで のこる。水が 来ても 消えない。右クリック・ほる の どちらでも アイテムに なって 持ち物へ（3.3 版。2 版の「こわしても 消えない・右クリック だけ」は やめた）。
- はなだん を つけて 窓 0: 何も つかず、材料も 0（§2.3 の ふきだし）。
- やね なしで えんとつ・しゃちほこ を つけて いる／かべ なしで 窓・はなだん が ある: 建たず 材料 0、せっけいずには のこる（§2.3 の ふきだし。やね・かべを もどすと 出る）。
- かべ なしの 家で 戸を ほった: 1 版と 同じく 家の 記録が 消える（HOUSE-1 §2.13）。柱を ほっても 家の 記録は 消えない。

- かざりを ぜんぶ はずす: かざりの ばしょの ボタンは 出た まま（おぼえた 物が ある ため）。
- ポップアップを 開いた まま つぎへ・できた！ など: ポップアップを とじて から その ボタンの はたらき（§2.3）。開いた まま エディターを とじて 開きなおすと とじて いる。
- ななめの やね で 建てる 場所の 上 6 段の 中に 木の はっぱ が ある: 建てられない（HOUSE-1 の「上が 空気」と 同じ）。
