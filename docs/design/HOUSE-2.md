### 2.3 エディターで えらぶ（HOUSE-1 §2.5 を かえる。3 版で ポップアップに）

**ばしょの ポップアップ**（しゅるいの 一覧）:

## 5. 例外の とき
- 持ち物が いっぱい: レシピは 持ち物を 使わない ので おぼえる。かみ 3 まいの とき（ぜんぶ おぼえた あと）は 宝箱の ほかの 物と 同じ あつかい（入らない 分は 足もとに 落とす）。
- おぼえて いない 物は エディターで えらべない ので、せっけいずに 入る ことは ない。読みこんだ セーブの 作りかけ・せっけいずに、おぼえて いない しゅるい や 知らない id が ある ときは、その ばしょを いつもの 物（かざりは はずす）に して 読む【PO 案】。1 版の せっけいずは いつでも 建てられる。
- 2 版の 形の id（`kawara` など 案の ない id）が 作りかけに ある（2A の 前の 試作の セーブ）: 案 むら の 物と して 読む【PO 案】。
- 宝箱の ない 坑道の まきものを とらずに 帰った: 次に 来た とき まで のこる。まきものの マスを こわしても・水が 来ても 消えない（右クリック だけで とれる）。
- はなだん を つけて 窓 0: 何も つかず、材料も 0（§2.3 の ふきだし）。
- やね なしで えんとつ・しゃちほこ を つけて いる／かべ なしで 窓・はなだん が ある: 建たず 材料 0、せっけいずには のこる（§2.3 の ふきだし。やね・かべを もどすと 出る）。
- かべ なしの 家で 戸を ほった: 1 版と 同じく 家の 記録が 消える（HOUSE-1 §2.13）。柱を ほっても 家の 記録は 消えない。
- 名前の ヘルプが 出て いる 間に ポップアップが とじた・ボタンが 消えた（もどす で かざりの ボタンが 消えた など）: ヘルプも すぐ 消える。
- かざりを ぜんぶ はずす: かざりの ばしょの ボタンは 出た まま（おぼえた 物が ある ため）。
- ポップアップを 開いた まま つぎへ・できた！ など: ポップアップを とじて から その ボタンの はたらき（§2.3）。開いた まま エディターを とじて 開きなおすと とじて いる。
- ななめの やね で 建てる 場所の 上 6 段の 中に 木の はっぱ が ある: 建てられない（HOUSE-1 の「上が 空気」と 同じ）。

### 6.1 テスト用の フック案（名前と 形の 約束。置く 所は developer）
- 型の 名前: `Style ＝ 'mura' | 'shiro' | 'kozan'`、`Part ＝ 'roof' | 'wall' | 'window' | 'door' | 'deco'`。しゅるいの id ＝ いつもの 物は `'flat'`・`'ki'`・`'shoji'`・`'ie'`、なしは やね・かべ・まど とも `'none'`（press id は `roof-none`・`wall-none`・`window-none`。と には ない）、ほかは `` `${形}_${Style}` ``（`'kawara_shiro'` など。§4.1）、しゃちほこ は `'shachi'`。

- `editor().popupRows: string[][]`（ポップアップの 行ごとの ボタンの id。上から。なかまの ならびを 数を 書かずに 確かめる ため）。
- `blueprints()` に `wall`・`door`・`deco`。`houseBox(blueprint)` → `{ w, d, h }`。2B: `houseTriangles(blueprint)` → その 家の 三角形の 数（家具を のぞく）。
- 2C: ほった 物は 今の `house.blockAt`／`dugItemOf` の 答えで 見る。「つくる」は 今の 作り方の 窓口（カードの 一覧・作る）に 家の 物が 出るか で 見る（新しい フックは 足さない。3 案の えらびは 作る ときの 引数 `kind` を 足す）。
