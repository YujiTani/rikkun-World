# M2: 掘（ほ）る・置（お）く・持（も）ち物（もの）（仕様書）

- タスク票: `docs/tickets/M2.md`（plan F3・F4）
- 前提の仕様書: `docs/design/M1-01-world.md`（ブロック 4-2、テストに使ってよい場所 4-11）、`docs/design/M1-02-movement.md`（向き §4.3、時間とロック §2.4、人形 §3.3、テスト用窓口 §6.1、テスト地形 §6.2）

## 1. ねらい（りっくんがどう楽しむか）

- 見ているブロックに黒い枠が出る →「これをほれる」と分かる。
- クリックを押しっぱなしにすると、ひびが入っていき、ひびがいっぱいになるとブロックが「ぷるぷる」光って待つ。**もう 1 回クリック（とどめのひと押し）** で「ぽん！」とはじけ、下のホットバーにそのブロックが 1〜4 こ入る（いくつ出るかはお楽しみ。「+3」のように数が出て、マスが弾む）。かたいブロックほど時間がかかる（いし は がんばって 6 秒）。
- 右クリックで、えらんだブロックを置ける。押しっぱなしなら 0.5 秒ごとに続けて置ける。土で階段や家を作れる。
- 下を向くと自分の足が見え、右手に持っているブロックが見える。
- ページを閉じても、次に開けば続きから遊べる（自動セーブ）。
- 字が読めなくても、色（ブロックの絵）・数字（1〜9 のキー）・アイコンで分かる。

## 2. 遊び方（プレイヤーから見た動き）

### 2.1 操作（入力はすべて Action 経由。`src/input/actions.ts`）

| したいこと | キー・マウス | Action | 新しい？ |
|---|---|---|---|
| ほる | 左クリック（押しっぱなし → ひびがいっぱいになったら もう 1 回クリック） | `primary` | 既存 |
| おく | 右クリック（1 回で 1 こ。押しっぱなしで 0.5 秒ごと） | `secondary` | 既存 |
| ホットバーのマスをえらぶ | 数字キー 1〜9 | `hotbar1`〜`hotbar9` | 新 |
| となりのマスへ | マウスホイール 下 / 上 | `hotbarNext` / `hotbarPrev` | 新 |
| もちもの画面を ひらく・とじる | E | `toggleInventory` | 新 |
| もちもの画面を とじる（もどる） | Esc | `closeMenu` | 新 |

- 新しい Action はコントローラーのボタンにも後で割り当てられる形にする（キーやホイールを直接読まない）。
- マウスホイールは「動いた量（deltaY）」を足していき、**50 ごとに 1 マス** 動く（下 = 右のマス、上 = 左のマス）。行単位のホイールは 1 行 = 1 マス。Mac のトラックパッドで少しなぞっただけで何マスも飛ばないため。
- ロックが外れている（案内画面が出ている）あいだと、もちもの画面が開いているあいだは、`primary`・`secondary`・ホットバーの Action を無視する（M1-02 §2.4 の「遊びの入力」に入る）。

### 2.2 ねらう

- 目の位置（足もと＋1.62。三人称でも **プレイヤーの目** から）から、見ている向き（yaw・pitch、M1-02 §4.3）へまっすぐ線をのばし、**目から 5.0 ブロック以内** で最初にふれる「`air`・`water` 以外」のブロックが **ねらっているブロック**。
- `water` は線が通りぬける（水ごしに海の底をねらえる）。世界の外（`outside`）のマスは通りぬけ、ねらえない。目が世界の外（例: y=31 のブロックの上に立って目が y=33.62）にあっても線は同じに調べる。
- ねらっているブロックに黒い枠を出す（§3）。ねらうブロックが無ければ枠は出ない。
- 線が最初に入った面を **ねらっている面** とし、その面のとなりのマスが **置く場所**。
- ねらいはステップごとに決め直す。

### 2.3 ほる

- `primary` を押しているあいだ、ねらっているブロックの **ほった量** が 1 ステップに 1 ずつ増える。
- 押しているあいだ ひびが入る（3 だんかい。§4.1）。かたいブロックは何秒もかかるので、ひびが進むたびの「カッ」という音と見た目で「ちゃんとほれている」と分かるようにする。
- **ひびがいっぱい（MAX）**: ほった量が §4.1 の「ほる時間」N に届いたステップで、ほった量は N で止まり、**こわれずに待つ**（`ready`）。このとき 1 回だけ「キラッ」と鳴り、ブロックがぷるぷるふるえて やさしく光る（§3）。
- **MAX はもう減らない**（オーナー決定）: 押しっぱなしでも、はなしても、ねらいが外れても、時間がたっても MAX のまま。MAX がなくなるのは、**こわれたとき** と **別のブロックをほり始めたとき** だけ。
- **とどめのひと押し**: MAX のブロックをねらって `primary` を **押した瞬間**（はなしていたなら押したステップ、押しっぱなしなら一度はなして押し直したステップ）に、そのブロックは `air` になり、同じ種類のアイテムが **§4.1 の数（1〜最大のランダム）** だけ持ち物に入る（拾いに行かなくてよい。すぐ入る）。こわれる演出は派手め（§3）。
  - 理由（オーナー決定）: 押しっぱなしで勝手にこわれるより、「自分の 1 回のクリックでこわした」手ごたえを大事にする。
- **はなすと少しずつ戻る**: `primary` をはなした、またはねらいが外れたステップから、ほった量が毎ステップ `digDecayRate`（初期値 **1.0** = ほったのと同じ速さ）ずつ減る。ひびも減ったぶんだけ戻る。0 になったら、ほった量は消える。途中で同じブロックを押し直すと **残りから続く**。**MAX になったあとは減らない**（上）。
  - 別のブロックをほり始めたら、前のブロックの分は捨てる（MAX でも捨てる。おぼえておくのは最後の 1 こだけ）。
  - MAX が減らないので、人がクリックし直すあいだ（指がはなれている数ステップ）に MAX が消えることはない（版 3 の心配は解消）。
- とどめでこわしたあと **6 ステップ** は次のブロックをほり始めない（押しっぱなしで次のブロックがすぐ進まないため）。7 ステップ目から次のブロックを数え始める。
- **すででは ほれない**: `iron_ore`（てつ）はかたすぎて、M4 の道具が要る。押しても ほった量は 0 のまま、ひびは出ず、§3 の「つるはし が いるよ」の合図を出す。
- **ぜったいに ほれない**: `bedrock`（そこいし）。押すと §3 の「カチン」の合図だけ出す。
- **持ち物がいっぱい**: 出た数のうち **入りきらない分は捨てる**（1 こも入らなくても、ふつうにほれて、とどめでブロックは消える）。1 こも入らなかったときは、こわれたときに §3 の「もちもの が いっぱい」の合図を出す。
  - 遊び方のヒント: M2 では物を捨てられないので、いっぱいになったら **ブロックを置けば空きができる**。合図のアイコンは「ふくろ＋✕」で、もちもの画面を開くと満タンのマスが分かる。

### 2.4 おく

- `secondary` を **押した瞬間（1 ステップ目）に 1 回** 置く。**押しつづけると 30 ステップ（0.5 秒）ごと**（31・61・91 … ステップ目）に、そのときのねらいで同じことをくり返す。くり返しは前の 1 回が置けなかったときも続ける。
- 置けるのは、手に持っている（えらんでいるホットバーのマスの）アイテムがブロックのとき。置いたら そのマスの数が 1 減り、0 になったらマスは空になる。
- 置けないとき（§5）は何も変わらない（数も減らない。音も出さない）。

### 2.5 もちもの画面（E）

- ロック中に `toggleInventory`（E）を押すと、もちもの画面を開く。このときゲームが自分でポインターロックを外し、マウスの矢印を出す。**案内画面（あそぶ ボタン）は出さない**（M1-02 §2.3 の例外）。
- **開いているあいだも時間は進むが、ゆっくり（ふだんの 1/4 の速さ。1 秒に 15 ステップ）**。妖怪（ようかい）が出る M3 で、持ち物を見ているうちにやられにくくするため。遊びの Action（歩く・ジャンプ・向き・ほる・おく・ホットバー）は無視する。重力などはそのまま進む。テスト用の `step(n)` はゆっくりにならない（いつでもちょうど n ステップ。M1-02 §2.4）。
- もう一度 `toggleInventory`（E）を押す、または画面の「とじる」ボタンを押すと、閉じてロックをかけ直し、ふだんの速さで続きから遊べる。ロックがかけ直せなかったら（ブラウザの都合）案内画面（`クリックして つづきを あそぼう！`）を出し、時間は止まる（M1-02 §2.4）。
- `closeMenu`（Esc）で閉じたときは、案内画面（`クリックして つづきを あそぼう！`）を出し、時間は止まる（Esc ではロックをかけ直せないブラウザの決まりのため）。
- **テスト用の `lock.simulate` との関係**: `lock.simulate()` を一度でも呼んだあとは、ゲームが自分でロックを外す（もちもの画面を開く）と擬似の状態も「外れた（false）」になり、ゲームが自分でかけ直す（`toggleInventory`・「とじる」で閉じる）と擬似の状態は **かならず成功して「ロック中（true）」** になる。`closeMenu` で閉じたときは false のまま（案内画面）。
- `toggleInventory`・`closeMenu` は、F3 と同じく **時間が止まっていても** 押せばすぐ（0.2 秒以内に）効く。案内画面が出ているあいだの `toggleInventory` は無視する。
- 画面の中のマスの動かし方（クリック 2 回で動かす。トラックパッドでドラッグしなくてよい）:

| 手に持っているもの（カーソル） | クリックしたマス | どうなる |
|---|---|---|
| なし | アイテムあり | そのマスの全部をカーソルに持つ。マスは空。このマスを **「持ち上げたマス」** としておぼえる |
| あり | 空 | 全部をそのマスに置く。カーソルは空 |
| あり | 同じアイテム | 1 マスの上限まで重ねる。あまりはカーソルに残る |
| あり | ちがうアイテム | 入れかえる（カーソルにはそのマスのものが来る。「持ち上げたマス」は変えない） |
| なし | 空 | 何もしない |

- マスの外をクリックしても何もしない（M2 では捨てられない）。
- カーソルに持ったまま閉じたら（どの閉じ方でも）、カーソルのものを **「持ち上げたマス」** に戻す。そこが空でなければ §4.2 の入れ方で入れる（もともと持ち物に入っていたものなので必ず入る）。

### 2.6 自分の体と、手に持ったブロック

- **一人称**: 人形（M1-02 §3.3）の **あたまとからだは見えない（すけている）**、**うでとあしは見える**。下を向くと自分の足が見える。
- **右手に、えらんでいるマスのブロックを持つ**（ブロックを 0.25 の大きさの立方体で、ドット絵つき）。マスが空なら何も持たない。
- 一人称で前（pitch 0）を向いているとき、右手と持っているブロックが **画面の右下** に見えるように、右うでを前に出した「もつ形」にする（うでの角度・位置は見え方に合わせて調整してよい。体の動きとぴったり合っていなくてよい）。
- ほっているあいだは右うでを小さく振る（0.25 秒に 1 回）。置いたときも 1 回振る。
- **三人称**: 人形は全部見え（M1-02 のまま）、右手に同じブロックを持つ。
- カメラが体の中にあっても、体の内側（面のうら）が画面に映りこまない。

### 2.7 自動セーブ

- 遊んでいるあいだ、世界の変化・持ち物・プレイヤーの位置と向きを自動で保存する（§4.4）。ページを閉じて開き直すと続きから。開いた直後は案内画面（M1-02 §2.3）が出て、クリックすると続きから遊べる。
- 子どもには保存のことを見せない（保存中の文字・「保存できません」などは出さない）。
- **最初からやり直す（大人向け）**: アドレスの最後に `?reset=1` をつけて開く。

## 3. 画面・見た目

- 文字（ひらがな・カタカナ。漢字は使わない。使うなら `ruby()` でふりがな）:

| 場所 | 文字 |
|---|---|
| もちもの画面の上 | `もちもの` |
| とじるボタン | `とじる`（✕ の絵つき） |
| ブロックの名前（マスをえらんだとき） | M1-01 4-2 の名前（`つち`・`いし` など） |
| すででは ほれない合図 | `つるはし が いるよ` |
| いっぱいの合図 | `もちもの が いっぱい` |

- 色・形（すべてコードで描く）:
  - **ねらいの枠**: ブロックより少しだけ大きい箱の 12 本の辺を、黒（`#000000`、不透明度 60%）の細い線で描く。ほれないとき・いっぱいでアイテムが入らなかったときは 0.5 秒だけ赤（`#E53935`）になる。
  - **ひび**: ブロックの 6 面に重ねる、黒い線の 16×16 ドット絵 3 まい（だんかい 1 = 短い線 2 本、2 = 線が枝分かれ、3 = 面全体にひび）。
  - **MAX（あとひと押し）**: ブロックが小さくぷるぷるふるえ、白っぽいやさしい光がゆっくり強く・弱くなる（明るさの波は **1 秒に 3 回未満**。点滅はしない）。
  - **とどめでこわれたとき（派手め）**: ブロックが一瞬ふくらんでから消え、そのブロックの色の小さな四角（0.15 ブロック）が 6〜12 こ はじけて落ち、0.5 秒で消える。画面がごく弱く 0.1 秒ゆれる（設定 `fxShake` で切れる。酔わない大きさ）。
  - **置いたとき**: 置いたブロックが「ぽよん」と一瞬ふくらんで戻る（0.2 秒）。
  - **ホットバー**: 画面の下の真ん中に 9 マス。1 マスは画面幅 1280px のとき **64px 以上** の正方形、うすい黒の背景、灰色のふち。マスの左上に小さく数字 1〜9。アイテムはブロックの横の面の 16×16 ドット絵をくっきり（ぼかさず）大きく描く。数は 2 こ以上のとき右下に白い数字（黒いふち、20px 以上）。えらんでいるマスは **黄色（`#FFD54F`）の太いふち** で少し大きく見せる。
  - **えらんだときの名前**: マスをえらぶと、ホットバーの上にブロックの名前を 1.5 秒出す。
  - **アイテムが入ったとき**: 入ったマスが 0.2 秒「ぴょこん」と 1.2 倍にふくらんで戻り、マスの上に「+入った数」（例 `+3`）が出てふわっと上に消える（0.6 秒）。
  - **合図のアイコン**: 画面中央の「＋」の右下に 1 秒出す。「つるはし が いるよ」= ツルハシの 16×16 ドット絵＋赤い ✕。「もちもの が いっぱい」= ふくろの絵＋赤い ✕。
  - **もちもの画面**: 画面の中央にパネル。上に 3 段 × 9 マス（ふくろ）、少しあけて下に 1 段 × 9 マス（ホットバーと同じもの）。マスの大きさはホットバーと同じ。右上に大きな「とじる」ボタン（縦 64px 以上）。カーソルに持ったアイテムはマウスの矢印についていく。右側は M4 の「つくる」場所のためにあけておいてよい。うしろの世界はうすく見え、ゆっくり動いている。
  - **一人称の手足**: §2.6。色は M1-02 §3.3 の人形と同じ。
- 音（コードで作る短い音。大きい音・うるさい音・こわい音は使わない。オーナー確認）: ひびのだんかいが進むたびに「カッ」、MAX になったとき「キラッ」（1 回）、とどめでこわれたら「ぽん！」、アイテムが入ったら「ピッ」（**入った数が多いほど少し明るい音**。**続けて取ると少しずつ高くなる**。前に取ってから 2 秒以内なら半音上げ、上げるのは 8 回まで。2 秒あくと元の高さ）、置いたら「ぽよん」、ほれないとき「カチン」（押した瞬間 1 回）。
- 演出の決まり（オーナー決定「ドパゲー風」）: 気持ちよさは「ふくらむ・はじける・弾む・音が上がる」で出す。**点滅（1 秒に 3 回以上の明るさの変化）・大きい音・こわい音・強いゆれはしない**。

## 4. ルール・数値

数値は 1 か所の設定にまとめ、`settings.get/set`（M1-02 §6.1）で変えられるようにする。1 秒 = 60 ステップ。

### 4.1 ほる（かたさ）

**ほる時間 N（ステップ）＝ かたさ × 60 ÷ 道具の強さ**（小数は切り上げ）。N ステップでひびが MAX になり、とどめのひと押しでこわれる（§2.3）。M2 は素手だけで、素手の強さは **1.0**。M4 の道具は「強さ」と「レベル」を持ち、強さで速くなり、レベルで「すででは ほれない」ものがほれるようになる（数は M4 で決める）。

**決まり: ブロックを新しく足すときは、かならずこの表に「かたさ」「ほるのに要るレベル」「めずらしさ」を書く。**

| ブロック | かたさ（素手での秒数） | 素手のほる時間 | ほるのに要るレベル | めずらしさ（出る数） |
|---|---|---|---|---|
| `leaves` はっぱ | **0.25** | 15 ステップ | 0（素手で OK） | common（1〜4） |
| `grass` くさ | **0.5** | 30 | 0 | common（1〜4） |
| `dirt` つち | **0.5** | 30 | 0 | common（1〜4） |
| `sand` すな | **0.5** | 30 | 0 | common（1〜4） |
| `log` き | **5** | 300 | 0 | uncommon（1〜3） |
| `stone` いし | **6** | 360 | 0 | common（1〜4） |
| `coal_ore` せきたん | **10** | 600 | 0 | uncommon（1〜3） |
| `iron_ore` てつ | **15** | （ほれない） | **1**（M4 の道具） | rare（1〜2） |
| `bedrock` そこいし | こわれない | — | — | — |
| `water`・`air` | ねらえない | — | — | — |

**出てくる数（オーナー決定）**: とどめでこわれたとき、**1 〜 そのめずらしさの最大** の整数を、どれも同じ確率で 1 つ決める（シード付きの乱数。同じシード・同じ順番なら同じ数）。めずらしさごとの最大は common **4**・uncommon **3**・rare **2**・superRare（とてもめずらしい）以上 **1**。M2 に superRare のブロックは無い（あとで足すものに使う）。

（はっぱ・くさ・つち・すな は、き よりずっと短くして「ほるのが楽しい」を先に味わえるようにした。りっくんのプレイで調整）

| 項目 | 値 | 設定の名前 |
|---|---|---|
| とどく長さ | 目から **5.0 ブロック** | `reach` |
| かたさ | 上の表 | `hardness`（`{leaves:0.25, grass:0.5, ...}`。こわれないものは書かない） |
| ほるのに要るレベル | 上の表 | `harvestLevel`（`{iron_ore:1}`。書かないものは 0） |
| 素手の強さ・レベル | 強さ **1.0**、レベル **0** | `handPower`・`handLevel` |
| はなしたとき減る速さ | 1 ステップに **1.0**（ほったのと同じ速さ） | `digDecayRate` |
| MAX | ほった量が N に届いたら N で止まり、とどめを待つ。MAX は減らない（こわれるか、別のブロックをほり始めるまで） | — |
| こわしたあとの休み | **6 ステップ** | `digCooldown` |
| ひびのだんかいの数 | **3** | `crackStages` |
| ひびのだんかい | ほった量 k（0 より大きい。小数あり）、ほる時間 N のとき **min(3, 1 + floor(3k / N))**。ほった量が 0 なら 0。MAX のときは 3。例: つち（N=30）は k 1〜9 で 1、10〜19 で 2、20〜29 で 3 | — |
| 画面のゆれ | オン（ごく弱く 0.1 秒） | `fxShake`（true / false） |
| 出てくるアイテム | **ほったブロックと同じもの**（くさ → くさ、はっぱ → はっぱ） | — |
| めずらしさ | 上の表 | `rarity`（`{dirt:'common', log:'uncommon', iron_ore:'rare', ...}`） |
| めずらしさごとの最大の数 | common 4・uncommon 3・rare 2・superRare 1 | `dropMax`（`{common:4, uncommon:3, rare:2, superRare:1}`） |

**M3・M4 のための形（決まり）**
- M3「やられたら 50%」: マス（スロット）ごとにコイン投げ。**えらんでいるホットバーのマス（手に持っているもの）は対象外**。マスの形がこの表のとおりなら、そのまま使える。

- `primary` は M3 で「攻撃」にも使う。目の前に妖怪がいるときどちらを優先するかは M3 で決める。

## 6. 受け入れ基準

前提（M1-02 §6 と同じ書き方）:
- 新しいブラウザの状態（保存なし）で開き、`pause()` → `lock.simulate(true)` → テスト地形を作る → `player.set()` → `input.*` → `step()` の順。`inventory.clear()` で持ち物を空にしてから始める。
- 「床」「P」は M1-02 §6.2 の基本の床（`fill(0,8,0, 12,8,12,'stone')`、上面 y=9）と P（足 (2.5, 9, 6.5)、yaw 90 = 東、pitch 0）。目は (2.5, 10.62, 6.5)。
- 「T」= マス (4, 10, 6)。P の目から東へ 1.5 の所にある（面 x=4 の中央付近をねらう）。
- 「`primary` を n ステップ押す」= `input.press('primary')` → `step(n)`（はなすときは `input.release`）。「1 ステップだけ押す」= press → `step(1)` → release。
- 「**押し直す**」（とどめのひと押し）= `input.release('primary')` → `input.press('primary')` → `step(1)`（はなすと押すを同じステップに入れる）。
- 「ブロックをほる」（AC15・AC24 など）= `primary` を N ステップ押して MAX にしてから押し直す。
- **出てくる数**: 特にことわりがなければ、はじめに `settings.set('dropMax', {common:1, uncommon:1, rare:1, superRare:1})` にして、こわれたら **ちょうど 1 こ** 出るようにしてから確かめる（数を決め打ちするため）。ランダムの数は AC30 だけで確かめる。
- ブロックやプレイヤーを置き直したら、`step(1)` してから `target.get()` を読む（ねらいはステップごとに決め直す）。この `step(1)` は AC のステップ数に数えない。
- ふだんのシードで確かめる（テスト地形の場所はどのシードでも同じ。M1-01 4-11）。
