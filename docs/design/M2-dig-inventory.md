# M2: 掘（ほ）る・置（お）く・持（も）ち物（もの）（仕様書）

- タスク票: `docs/tickets/M2.md`（plan F3・F4）
- 前提の仕様書: `docs/design/M1-01-world.md`（ブロック 4-2、テストに使ってよい場所 4-11）、`docs/design/M1-02-movement.md`（向き §4.3、時間とロック §2.4、テスト用窓口 §6.1、テスト地形 §6.2）

## 1. ねらい（りっくんがどう楽しむか）

- 見ているブロックに黒い枠が出る →「これをほれる」と分かる。
- クリックを押しっぱなしにすると、ひびが入って「ぽん」とこわれ、下のホットバーにそのブロックが入る（マスが「ぴょこん」と弾む）。
- 右クリックで、えらんだブロックを置ける。土で階段や家を作れる。
- 字が読めなくても、色（ブロックの絵）・数字（1〜9 のキー）・アイコンで分かる。

## 2. 遊び方（プレイヤーから見た動き）

### 2.1 操作（入力はすべて Action 経由。`src/input/actions.ts`）

| したいこと | キー・マウス | Action | 新しい？ |
|---|---|---|---|
| ほる | 左クリック（押しっぱなし） | `primary` | 既存 |
| おく | 右クリック（1 回押すと 1 こ） | `secondary` | 既存 |
| ホットバーのマスをえらぶ | 数字キー 1〜9 | `hotbar1`〜`hotbar9` | 新 |
| となりのマスへ | マウスホイール 下 / 上 | `hotbarNext` / `hotbarPrev` | 新 |
| もちもの画面を ひらく・とじる | E | `toggleInventory` | 新 |
| もちもの画面を とじる（もどる） | Esc | `closeMenu` | 新 |

- 新しい Action はコントローラーのボタンにも後で割り当てられる形にする（キーやホイールを直接読まない）。
- マウスホイールは「動いた量（deltaY）」を足していき、**50 ごとに 1 マス** 動く（下 = 右のマス、上 = 左のマス）。行単位のホイールは 1 行 = 1 マス。Mac のトラックパッドで少しなぞっただけで何マスも飛ばないため。
- ロックが外れている（案内画面が出ている）あいだは、M1-02 §2.4 のとおり `primary`・`secondary`・ホットバーの Action は無視する。

### 2.2 ねらう

- 目の位置（足もと＋1.62。三人称でも **プレイヤーの目** から）から、見ている向き（yaw・pitch、M1-02 §4.3）へまっすぐ線をのばし、**目から 5.0 ブロック以内** で最初にふれる「`air`・`water` 以外」のブロックが **ねらっているブロック**。
- `water` は線が通りぬける（水ごしに海の底をねらえる）。世界の外（`outside`）はねらえない。
- ねらっているブロックに黒い枠を出す（§3）。ねらうブロックが無ければ枠は出ない。
- 線が最初に入った面を **ねらっている面** とし、その面のとなりのマスが **置く場所**。

### 2.3 ほる

- `primary` を押しているあいだ、ねらっているブロックの **ほった量** が 1 ステップに 1 ずつ増える。§4.1 の「ほる時間」に届いたステップで、そのブロックは `air` になり、同じ種類のアイテムが 1 こ持ち物に入る（拾いに行かなくてよい。すぐ入る）。
- 押しているあいだ ひびが入る（3 だんかい。§4.1）。
- `primary` をはなす、またはねらうブロックが変わると、ほった量は 0 に戻る。
- こわしたあと **6 ステップ** は次のブロックをほり始めない（押しっぱなしで 2 こ同時にこわれないため）。7 ステップ目から次のブロックを数え始める。
- **すででは ほれない**: `coal_ore`（せきたん）・`iron_ore`（てつ）は M4 のツルハシが要る。押しても ほった量は 0 のまま、ひびは出ず、§3 の「つるはし が いるよ」の合図を出す。
- **ぜったいに ほれない**: `bedrock`（そこいし）。押すと §3 の「カチン」の合図だけ出す。
- **持ち物がいっぱい**（そのアイテムが 1 こも入らない）: ほり始めない（ほった量 0、ひび無し）。§3 の「もちもの が いっぱい」の合図を出す。こわしてアイテムが消える、ということは起きない。

### 2.4 おく

- `secondary` を **押した瞬間に 1 回だけ** 置く（押しっぱなしでも 1 こ）。
- 置けるのは、手に持っている（えらんでいるホットバーのマスの）アイテムがブロックのとき。置いたら そのマスの数が 1 減り、0 になったらマスは空になる。
- 置けないとき（§5）は何も変わらない（数も減らない。音も出さない）。

### 2.5 もちもの画面（E）

- ロック中に `toggleInventory`（E）を押すと、もちもの画面を開く。このときゲームが自分でポインターロックを外し、マウスの矢印を出す。**案内画面（あそぶ ボタン）は出さない**（M1-02 §2.3 の例外）。
- 開いているあいだ **ゲームの時間は止まる**（ロックなしなので M1-02 §2.4 のとおり）。遊びの Action（歩く・ほる・おく・ホットバー）は無視する。
- もう一度 `toggleInventory`（E）を押す、または画面の「とじる」ボタンを押すと、閉じてロックをかけ直し、続きから遊べる。ロックがかけ直せなかったら（ブラウザの都合）案内画面（`クリックして つづきを あそぼう！`）を出す。
- `closeMenu`（Esc）で閉じたときは、案内画面（`クリックして つづきを あそぼう！`）を出す（Esc ではロックをかけ直せないブラウザの決まりのため）。
- `toggleInventory`・`closeMenu` は、F3 と同じく **時間が止まっていても** 押せばすぐ（0.2 秒以内に）効く。案内画面が出ているあいだの `toggleInventory` は無視する。
- 画面の中のマスの動かし方（クリック 2 回で動かす。トラックパッドでドラッグしなくてよい）:

| 手に持っているもの（カーソル） | クリックしたマス | どうなる |
|---|---|---|
| なし | アイテムあり | そのマスの全部をカーソルに持つ。マスは空 |
| あり | 空 | 全部をそのマスに置く |
| あり | 同じアイテム | 1 マスの上限まで重ねる。あまりはカーソルに残る |
| あり | ちがうアイテム | 入れかえる |
| なし | 空 | 何もしない |

- マスの外をクリックしても何もしない（M2 では捨てられない）。カーソルに持ったまま閉じたら、持っていたものは元のマスへ戻す（元のマスがうまっていたら §4.2 の入れ方で入れる）。

## 3. 画面・見た目

- 文字（ひらがな・カタカナ。漢字は使わない。使うなら `ruby()` でふりがな）:

| 場所 | 文字 |
|---|---|
| もちもの画面の上 | `もちもの` |
| とじるボタン | `とじる`（✕ の絵つき） |
| ブロックの名前（マスをえらんだとき） | M1-01 4-2 の名前（`つち`・`いし` など） |
| すででは ほれない合図 | `つるはし が いるよ` |
| いっぱいの合図 | `もちもの が いっぱい` |

- 色・形（すべてコードで描く）:
  - **ねらいの枠**: ブロックより少しだけ大きい箱の 12 本の辺を、黒（`#000000`、不透明度 60%）の細い線で描く。ほれない・いっぱいのときは 0.5 秒だけ赤（`#E53935`）になる。
  - **ひび**: ブロックの 6 面に重ねる、黒い線の 16×16 ドット絵 3 まい（だんかい 1 = 短い線 2 本、2 = 線が枝分かれ、3 = 面全体にひび）。
  - **こわれたとき**: そのブロックの色の小さな四角（0.15 ブロック）が 6 こ はじけて落ち、0.5 秒で消える。
  - **ホットバー**: 画面の下の真ん中に 9 マス。1 マスは画面幅 1280px のとき **64px 以上** の正方形、うすい黒の背景、灰色のふち。マスの左上に小さく数字 1〜9。アイテムはブロックの横の面の 16×16 ドット絵をくっきり（ぼかさず）大きく描く。数は 2 こ以上のとき右下に白い数字（黒いふち、20px 以上）。えらんでいるマスは **黄色（`#FFD54F`）の太いふち** で少し大きく見せる。
  - **えらんだときの名前**: マスをえらぶと、ホットバーの上にブロックの名前を 1.5 秒出す。
  - **アイテムが入ったとき**: 入ったマスが 0.2 秒「ぴょこん」と 1.2 倍にふくらんで戻る。
  - **合図のアイコン**: 画面中央の「＋」の右下に 1 秒出す。「つるはし が いるよ」= ツルハシの 16×16 ドット絵＋赤い ✕。「もちもの が いっぱい」= ふくろの絵＋赤い ✕。
  - **もちもの画面**: 画面の中央にパネル。上に 3 段 × 9 マス（ふくろ）、少しあけて下に 1 段 × 9 マス（ホットバーと同じもの）。マスの大きさはホットバーと同じ。右上に大きな「とじる」ボタン（縦 64px 以上）。カーソルに持ったアイテムはマウスの矢印についていく。右側は M4 の「つくる」場所のためにあけておいてよい。
- 音（コードで作る短い音。うるさい・こわい音は使わない。オーナー確認）: ほっているあいだ 0.25 秒ごとに小さな「コツ」、こわれたら「ぽん」、置いたら「とん」、ほれないとき「カチン」（押した瞬間 1 回）。

## 4. ルール・数値

数値は 1 か所の設定にまとめ、`settings.get/set`（M1-02 §6.1）で変えられるようにする。1 秒 = 60 ステップ。

### 4.1 ほる

| 項目 | 値 | 設定の名前 |
|---|---|---|
| とどく長さ | 目から **5.0 ブロック** | `reach` |
| ほる時間（ステップ） | `leaves` **15**（0.25 秒）、`grass`・`dirt`・`sand` **30**（0.5 秒）、`log` **60**（1 秒）、`stone` **120**（2 秒） | `digTicks`（`{leaves:15, grass:30, ...}`） |
| すででは ほれない | `coal_ore`・`iron_ore`（M4 でツルハシ） | （同じ設定で「ほれない」と書く） |
| ぜったい ほれない | `bedrock`。`water`・`air` はねらえない | — |
| こわしたあとの休み | **6 ステップ** | `digCooldown` |
| ひびのだんかい | ほった量 k（1 以上）、ほる時間 N のとき **1 + floor(3k / N)**（1〜3）。ほっていないときは 0 | — |
| 出てくるアイテム | **ほったブロックと同じもの**（くさ → くさ、はっぱ → はっぱ） | — |

（ほる時間はマイクラより短め。6 歳がすぐ結果を見られるように。りっくんのプレイで調整）

### 4.2 持ち物

| 項目 | 値 |
|---|---|
| マスの数 | **36**: 0〜8 がホットバー（左から 1〜9 のキー）、9〜35 がふくろ（もちもの画面の上 3 段、左上から右へ） |
| 1 マスの中身 | 空、または「アイテムの種類と数」（`{item, count}`） |
| 1 マスの上限 | ブロックは **64**。アイテムの種類ごとに決める（M4 の道具は 1） |
| アイテムの種類（M2） | 置けるブロック 8 種: `grass` `dirt` `stone` `sand` `log` `leaves` `coal_ore` `iron_ore`。名前は M1-01 4-2 のひらがな。それぞれ置くと同じブロックになる |
| 入れ方 | (1) 同じアイテムで上限に届いていないマスに、マス番号の小さい順（ホットバー → ふくろ）に入れる。(2) あまりは空のマスに、番号の小さい順に入れる。(3) それでもあまったら「入らなかった数」として返す |
| えらんでいるマス | 0〜8 のどれか。はじめは 0。ホイールは 8 の次が 0、0 の前が 8（ぐるっと回る） |
| はじめの持ち物 | 空 |

**M3・M4 のための形（決まり）**
- M3「やられたら 50%」: マス（スロット）ごとにコイン投げ。**えらんでいるホットバーのマス（手に持っているもの）は対象外**。マスの形がこの表のとおりなら、そのまま使える。
- M3 の落とし物・M4 のクラフトは、上の「入れ方」と同じ決まりで持ち物に入れる（入らなかった数が返る）。M4 は「種類を数える」「種類と数を指定して取り出す」も使う。
- M4 の道具は上限 1。こわれるまでの回数などは、マスの中身に項目を足して表す（M2 の 2 項目は変えない）。
- `primary` は M3 で「攻撃」にも使う。目の前に妖怪（ようかい）がいるときどちらを優先するかは M3 で決める。

### 4.3 置く

| 項目 | 値 |
|---|---|
| 置く場所 | ねらっている面のとなりのマス（§2.2） |
| 置けるマス | 中身が `air` か `water`（`water` は置いたブロックに置きかわる） |
| 1 回に置く数 | `secondary` を押した瞬間に 1 こ |

## 5. 例外のとき（持ち物がいっぱい、世界の端 など）

| とき | どうなる |
|---|---|
| 置く場所が **プレイヤーの体の箱**（0.6×1.8×0.6、M1-02 §4.1）と重なる（ふれているだけは OK） | 置かない。M3 からは妖怪の体も同じ |
| 置く場所が **世界の外**（x・z が 0〜63、y が 0〜31 の外） | 置かない（M1-01 4-8 の `outside`） |
| 置く場所が `air`・`water` 以外 | 置かない |
| 手に持っているマスが空 | 何もしない |
| ねらうブロックが無い（空を見ている、5.0 より遠い） | ほらない・置かない。枠も出ない |
| 持ち物がいっぱい | §2.3。ほり始めない、合図を出す |
| すででは ほれない・ぜったい ほれない | §2.3。ほった量 0、合図を出す |
| ロックが外れている・もちもの画面が開いている | ほらない・置かない・マスをえらばない（時間も止まっている） |
| ほっている途中で E を押した | ほった量は 0 に戻る |
| ブロックをほって、その上のブロックが浮いた | そのまま浮く（落ちてこない。すな も落ちない。M2 では重力ブロックなし） |
| スタート地点の列をほった・置いた | 戻る高さはそのとき計算し直す（M1-01 4-7） |
| 世界の変化・持ち物の保存 | M2 ではしない（ページを開き直すと元の島・空の持ち物）。自動セーブは別のタスク票で決める |

## 6. 受け入れ基準

前提（M1-02 §6 と同じ書き方）:
- `pause()` → `lock.simulate(true)` → テスト地形を作る → `player.set()` → `input.*` → `step()` の順。`inventory.clear()` で持ち物を空にしてから始める。
- 「床」「P」は M1-02 §6.2 の基本の床（`fill(0,8,0, 12,8,12,'stone')`、上面 y=9）と P（足 (2.5, 9, 6.5)、yaw 90 = 東、pitch 0）。目は (2.5, 10.62, 6.5)。
- 「T」= マス (4, 10, 6)。P の目から東へ 1.5 の所にある（面 x=4 の中央付近をねらう）。
- 「`primary` を n ステップ押す」= `input.press('primary')` → `step(n)`（はなすときは `input.release`）。「1 ステップだけ押す」= press → `step(1)` → release。
- ブロックやプレイヤーを置き直したら、`step(1)` してから `target.get()` を読む（ねらいはステップごとに決め直す）。この `step(1)` は AC のステップ数に数えない。
- ふだんのシードで確かめる（テスト地形の場所はどのシードでも同じ。M1-01 4-11）。

### 6.1 テスト用の窓口（M2 で足す分）

- 名前の決まりは M1-02 §6.1 と同じ（最上位は関数か入れ物のどちらか一方。入れ物の中身はすべて関数）。新しい入れ物は **`target`・`dig`・`inventory`** の 3 つ。`input` には `wheel` を 1 つ足す。
- 名前は開発係が変えてもよいが、変えたら `src/debug/testHook.ts` の型に書き、この表との対応を報告すること。

| 口 | 返すもの・すること |
|---|---|
| `target.get()` | `null` または `{ block:{x,y,z}, id, face:{x,y,z}（面の外向きの向き。各成分 −1・0・1）, place:{x,y,z}（置く場所。世界の外でもそのまま返す）, distance（目から面まで） }` |
| `dig.get()` | `{ active: boolean（今ほっている）, block:{x,y,z} \| null, progress: 0〜1（ほった量 ÷ ほる時間）, crackStage: 0〜3, blockedReason: null \| 'needTool' \| 'unbreakable' \| 'full' }`。`blockedReason` は `primary` を押していて、ほれないときだけ入る |
| `inventory.get()` | `{ slots: 36 この配列（null か {item, count}）, selected: 0〜8, open: boolean, cursor: null \| {item, count} }` |
| `inventory.setSlot(i, stack \| null)` | マス i を変える（テストの準備用。上限をこえる数は上限にする） |
| `inventory.clear()` | 全部空、`selected` 0、`cursor` null |
| `inventory.add(item, count)` | §4.2 の入れ方で入れ、入らなかった数を返す（M3・M4 も同じ決まりを使う） |
| `inventory.click(i)` | もちもの画面でマス i を左クリックしたのと同じ（§2.5 の表）。画面が閉じているときは何もしない |
| `inventory.itemTypes()` | `[{ id, name（ひらがな）, maxStack, placeBlock（置くと何のブロックになるか。置けないものは null） }]` |
| `input.wheel(deltaY)` | マウスホイールを deltaY 動かしたのと同じ（§2.1 の 50 ごとに 1 マス）。ロックが外れているときは無視 |
| `settings` の新しい名前 | `reach`・`digTicks`・`digCooldown`（§4.1） |
