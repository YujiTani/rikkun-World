## 1. ねらい（りっくん が どう 楽しむか）

- とりごや を ドン と 置く と、でこぼこ の 野原 でも **地面 が すっと たいら** に なって 小屋 が たつ。「おけない」で こまる こと が へる。
- ひよこ を だっこ して、とりごや の 前 で **えいっ と ぽいっ**。ひよこ が 山なり に とんで、さく の 上 で パタパタ … ふわっ と 中 に 着地 → その場 で **とりごや の こ**（いえ の しるし が ぽんっ）。入れた か どうか が 一目 で 分かる。
- こたつ に たまご を **3 こ** ならべて 入れる。天板 の 上 に たまご の 絵 が 3 つ ならび、だんだん うまって ゆれて ひび → ふとん の すそ から ひよこ が **にゅっ** と 出て くる。

## 2. 遊び方（かわる 所）

### 2.1 置く と たいら に なる（置き物 の きまり。LIVE-2 §2.1・§2.3 の「置く」を おきかえる）

- **このきまり を 使う 置き物**（プレイヤー が 置ける 何マス も ある 物。今 の コード を 調べた）:

| 置き物 | 足もと（床 の 広さ） | 置き物 の 高さ H（あける 高さ） | ずらし |
|---|---|---|---|
| とりごや `toriya` | 5×5 | 4 | ねらった 所 → まわり 8 か所（LIVE-2 §2.3 の まま） |
| こたつ `nukunuku`（2×2） | 2×2 | 1 | ねらった マス を かど に 4 むき（LIVE-2 §2.1 の まま） |

  - 1 マス の 置き物（たんす・かまど・たいまつ・ふつう の ブロック）は 今 の まま（たいら に しない）。かかし（`kakashi`＋`kakashi_head`）は 世界 を 作る とき だけ 出る ので 入れない。**これから 何マス も ある 置き物 を 足す とき は この きまり を 使う**（オーナー「こういう オブジェクト系 は 全て」）。
- **床 の 高さ**: ねらった 所 で ブロック を 置く なら 入る マス の 高さ（今 と 同じ きめかた）を **床 の 高さ y** と する。置き物 は y から y＋H−1 に 入る。
- **3 つ の マス の なかま**（ブロック の 種類 で きめる）:

| なかま | ブロック | 置く とき |
|---|---|---|
| **消える**（地面・草木） | くさ `grass`・つち `dirt`・いし `stone`・すな `sand`・ゆき `snow`・せきたん `coal_ore`・てつ `iron_ore`・はっぱ `leaves`・`momiji_leaves`・`matsu_leaves`・草花（`flower_y`・`flower_o`・`flower_p`・`susuki`・`kusa`・`nobana`） | 消える（なくなる だけ。§9 Q1） |
| **くうき** | `air` | そのまま |
| **じゃま**（上 の 2 つ 以外 ぜんぶ） | そこいし `bedrock`・みず `water`・き `log`・たけ `bamboo`・作った ブロック（レンガ・かわら など）・たいまつ（`start_torch` も）・たんす（中身 が ある）・かまど・はたけ・さく `saku`・スプリンクラー・作物・やせい の やさい・かかし・**ほか の 置き物**（こたつ の 4 マス・とりごや の ブロック） | **置けない** |

  - き・たけ を「じゃま」に した わけ: 木 の みき と、りっくん が 自分 で つんだ き の いえ を 見分け られない ので、こわさない 方 に した。はっぱ は 消える（木 の はっぱ が かかって いても 置ける）。
- **置ける 条件**（足もと の 1 列 ずつ 見る。1 か所 でも だめ なら その ずらし は だめ）:
  1. **うえ を あける**: y 〜 y＋H−1 の マス は「くうき」か「消える」。「じゃま」が 1 つ でも あれば だめ。
  2. **けずる 高さ は 2 まで**: 「消える」の うち 地面（くさ・つち・いし・すな・ゆき・せきたん・てつ）が **y＋2 より 上（y＋2 も ふくむ）に ある** 列 が あれば だめ（＝ 床 より 3 段目 から 上 に 地面 が ある ＝ 段差 3 以上）。はっぱ・草花 は 高さ に 関係 なく 消える。H ＝ 1 の こたつ は y の 1 段 だけ 見る ので、けずる の は いつも 1 まで。
  3. **うめる の は 2 まで**: y−1 が 固く ない（くうき・みず・草花）なら うめる。y−1・y−2 の 2 マス まで うめられる。**y−1 も y−2 も 固く なく、y−3 も 固く ない** 列 が あれば だめ（深い あな・がけ）。y−1（か y−2）が 固い ブロック なら それ を 床 に する（どの 固い ブロック でも よい。ただし **ほか の 置き物 の ブロック の 上 は だめ**）。
  4. 世界 の 読みこんで いない 所・世界 の 上 の はし・下 の はし に かかる → だめ。
  5. **プレイヤー の 体** が 置き物 の ブロック が 入る マス か うめる マス に 重なる → だめ（とりごや の 中 3×3 の あき に 立って いる の は よい）。**妖怪 の 体 の 箱** に 重なる → だめ（今 の まま）。
- **置いた とき**（1 ステップ で いっぺん に）:
  - うめる マス に **つち** を 置く。その 列 の いちばん 上 の うめ（＝ y−1）が つち に なる とき は **くさ** に する（まわり の 野原 と なじむ）。
  - y 〜 y＋H−1 の「消える」ブロック を くうき に する。そのあと 置き物 を 置く（とりごや は LIVE-2 §2.3 の 形、こたつ は 2×2）。
  - 消えた ブロック は **落とし物 に しない・持ち物 に も 入らない**（§9 Q1 ◎）。ほった 数 の 記録・実績 に も 数えない。
  - 置き物 を あとで こわして も、たいら に した 地面 は もどらない。
  - 中 に いた 動物 が うまったら 今 の きまり（中 の あいた 所 へ ワープ／そば へ ワープ）。
  - 演出: 足もと に 土けむり の つぶ（`dust`、1 列 に 1 つ まで・25 まで。くり返す 行動 では ない が 控えめ）。音 は 今 の 置く 音（とりごや `coopPlace`、こたつ ふつう の 置く 音）だけ。
- **すけた 形**（置く 前。今 の 白／赤）は その まま。白 の とき は 置いた あと の 形 で、たいら に なる 足もと の 板（足もと の 広さ の うすい 四角）を 床 の 高さ に いっしょ に 出す（どこ が たいら に なる か 分かる）。赤 は 今 の ななめ しま。
- **置けない とき**: 合図 `coopNoRoom` の 文 を **`ここ には おけない よ`**（絵: 小屋 ＋ でこぼこ の 地面）に かえる。こたつ も 置けない 所 で 右クリック したら 同じ 合図 を 出す（id は `coopNoRoom` の まま。今 の こたつ は 何も 出さない）。
- **変わる 遊び**: 前 は こたつ を 空中・水 の 中 に 置けた（LIVE-2 §5）。これから は 下 を 2 マス まで しか うめない ので、高い かべ の 横 や 深い 水 の 上 には 置けない。浅い 水（深さ 2 まで）の 底 から なら 水 を つち で うめて 置ける。床 の 高さ から 上 に 水 が ある 所 は 置けない。

### 2.2 だっこ から なげる（LIVE-1 §2.8「おろす」を おきかえる）

- だっこ 中 に 右クリック を 押した しゅんかん に **なげる**（今 の「おろす」の かわり。照準 の 下 の 語 は `なげる`）。
- **着く 所（着地点）** の きめかた:
  1. ブロック を ねらって いれば（とどく 距離 5）、そこ に ブロック を 置く なら 入る マス（今 と 同じ）。プレイヤー から の 水平 の きょり d が **4（`throwRange`）より 遠い** ときは、プレイヤー → その マス の 向き で 4 の 所 の 列 の、ねらった マス と 同じ 高さ ±1 で 立てる マス（上 が 固く ない・下 が 固い）に よせる。無ければ なげない（合図 `cantPutHere`）。
  2. 何も ねらって いなければ、プレイヤー の 前 **3 マス** の 列 で、目 の 高さ から 下 へ 見て はじめ に 立てる マス。8 マス 下 まで 無ければ その 3 マス 先 の 空中（パタパタ で おりる）。
  3. **d が 1 より 近い** ときは なげず に 今 の「そっと おろす」（20 ステップ）。
  - 着地点 が 固い マス → なげない・合図 `cantPutHere`・「ぷいっ」（今 の まま）。
  - 着地点 が とりごや の 中 3×3 で その 小屋 が 6 わ → なげない・`coopFull`。とりごや の 子 を 外 へ なげる とき なかま 8 わ → なげない・`friendFull`（今 の まま）。
- **とびかた**（決まった 道。乱数 なし）:
  - もちあげ **10 ステップ**（両手 で 頭 の 上 へ。「えいっ」）→ 手 から はなれる。はなれた ステップ に 手 は あく（すぐ ほか の こと が できる）。
  - はなれる 所 **S** ＝ プレイヤー の まん中・足 ＋ **2.2**。
  - 山なり の さいご の 所 **P** ＝ 着地点 の まん中・着地点 の 足 ＋ **2.0**。
  - S から P まで、てっぺん が **max(S の 高さ, P の 高さ) ＋ 0.5** の 放物線。かかる ステップ ＝ **20 ＋ 5×d**（四捨五入。d ＝ 3 で 35、d ＝ 4 で 40）。
  - P から 下 は **パタパタ**（ひよこ 2.5 マス/秒・大人 2.0 マス/秒。LIVE-1 §2.9・LIVE-2 §2.9）で まっすぐ おりて 着地（2.0 マス を ひよこ 48・大人 60 ステップ くらい）。着地 で ぽよん（大人）／コロン（ひよこ）。
  - 計算 し直し（さく を こえる か）: さく の 当たり は 地面 ＋2。S（＋2.2）も P（＋2.0）も てっぺん（＋2.5 以上）も さく より 高い ので、プレイヤー と 着地点 の 地面 が 同じ 高さ なら 道 の どこ でも 体 の 下（ひよこ は 足）が さく の 上 を とおる。d ＝ 1〜4 の どれ でも、さく の すぐ 外 に 立って、すぐ 内 の マス に も なげ入れ られる。
- **とちゅう で 当たる**: とんで いる 体 が 固い マス（かべ・天井・さく の 当たり・ねぐら・木 など）に 重なる ステップ に、そこ で 横 も 上 も 止めて、**その 場 から まっすぐ パタパタ で おりる**。音 `bonk`（ぽよん、小さく。いたく ない）。体 は 1 つ 前 の ステップ の 位置 に もどす（めりこまない）。
  - おりた 所 が とりごや の 中 3×3 → §2.3 の きまり で とりごや の 子。外 → なかま（とりごや の 子 を なげた 時 も 外 に 着けば なかま。なかま 8 わ なら その 小屋 の 中 の あいた 所 へ ワープ して とりごや の 子 の まま）。
  - さく・もん・ねぐら の 上 に 着いた → その 小屋 の 中 3×3 の いちばん 近い あいた マス へ ふわっ と よせる（0.5 マス/12 ステップ）。6 わ なら 小屋 の 外 の プレイヤー がわ の 地面 へ。
  - 妖怪・ほか の 動物 には 当たらない（すりぬける）。水 に 着いたら うく（今 の まま）。
- **こわく ない・いたく ない**: なげられた 子 は 目 を まるく して 羽 を ひろげる（びっくり でなく たのしい 顔）。着地 で ハート 1 つ（なげた あと だけ。小屋 に 入った 時 は §2.3 の ほう）。
- **着地点 の 目印**（だっこ 中 ずっと）: ◎ **出す**。着地点 の 地面 に **うすい 丸 の かげ**（直径 0.8、光らない・点滅 しない）。
  - その 着地点 で とりごや の 子 に なる とき は 丸 の 中 に **いえ の しるし**。
  - なげられない 所 は 丸 を 出さず、照準 の 下 の `なげる` を うすく（`disabled`）。
  - 道 の 線（点線 の 山なり）は 出さない（画面 が うるさく なる。丸 だけ で ねらえる）。
- **やられた とき**: その場 に そっと おろす（今 の まま。なげない）。

### 2.3 とりごや の 子 に なる・出ない（LIVE-2 §2.4 を おきかえる）

- **なる とき**: 足 の ある なかま が、とりごや の **中 3×3 に 着いた しゅんかん**（`coopEnterTicks` の 初期値 180 → **0**）。
  1. なげて（そっと おろして も）中 に 着地 した ステップ。
  2. ついて 歩いて きて、体 の まん中 が 中 3×3 に 入った ステップ。
- なった とき の 返し（今 の 出来事 `home` の 演出 を 少し 大きく）: 頭 の 上 に **いえ の しるし が ぽんっ と 大きく**（ふだん の しるし の 1.5 倍 で 出て 20 ステップ で ふつう に もどり、40 ステップ で 消える）・子 が くるっと まわる（20）・音 `home`（オルゴール 2 音。はじめて は 中 の お祝い ＋ 実績 の まま）。
  - 「いえ の しるし が だんだん うまる」（`fx().marks` の `home` 0〜1）は やめる。
- 6 わ の 小屋: 歩いて 入って も 小屋 の 子 に ならない（なかま の まま。しるし も 出ない）。なげ入れ は §2.2 で なげない。
- **とりごや の 子 は 自分 で は 出ない**（今 も もん を 通れない きまり。これ を 確かめる 基準 を 足す、AC7）。出す の は **だっこ → 外 へ なげる（おろす）だけ**。
  - オーナー の「勝手に出てきてしまう」は、前 の きまり で **3 秒 たつ 前 に プレイヤー が 出る と、ついて きた 子 が いっしょ に 出て しまう** こと と 読んだ。着いた しゅんかん に 小屋 の 子 に なる ので、プレイヤー が 出て も 子 は 中 に のこる。（読み が ちがう とき は §9 Q3）
  - その かわり「見に 入った だけ」で なかま が 小屋 の 子 に なる。つれて 歩く なかま を 入れたく ない とき は、もん の 外 で まって から 入る か、入って しまったら だっこ で 外 へ なげる（案内画面 の 2 行目 で 教える、§3.1）。
- ついてくる なかま は 今 の まま もん を 通れる。やせい・ついてくる 時間 0 の なかま は 通れない（今 の まま）。

### 2.4 こたつ に 3 こ（LIVE-2 §2.1「たまご を 入れる」〜「かえる」を おきかえる）

## 5. 例外 の とき

- **置こう と した 所 に こたつ・とりごや・たんす が ある**: じゃま → その ずらし は だめ。ほか の ずらし で 入れば そこ。

## 8. オーナー に 見せる 要点

1. とりごや・こたつ を 置く と、足もと の でこぼこ が たいら に なる（土・石・草 は 消える、くぼみ は 土 で うまる、段差 は 2 マス まで。き・レンガ・たんす など は こわさず「おけない」）。
2. だっこ から おろす と、前 へ **ぽいっ と 山なり** に なげる（4 マス まで）。さく の 上 を こえて パタパタ ふわっ と 着地。着く 所 に 丸 の かげ、とりごや の こ に なる 時 は 丸 に いえ の しるし。
3. とりごや の 中 に **着いた しゅんかん** に とりごや の こ（3 秒 まつ を やめる）。とりごや の こ は 自分 で は 出ない。出す の は だっこ で 外 へ なげる だけ。
4. こたつ に たまご **3 こ まで**。中 の たまご の 絵 は やめて、天板 の 上 に たまご の わく 3 つ（うまって いく・ゆれる）。かえる と ふとん の すそ から ひよこ が にゅっ。あたためる の は ぜんぶ で 6 こ まで。
5. さく・もん は 草花 の ような 板 の 見た目（当たり は 今 の まま 高さ 2）。

## 9. オーナー に 聞く こと（◎ は おすすめ）

- **Q1 たいら に した とき 消えた 土・石 は？** ◎ **消える だけ**（持ち物 が 土 で いっぱい に ならない。こわした 小屋 を 何度 も 置き直して 土 を ふやす うら技 も 出ない）／ 持ち物 に 入る（入らない 分 は おとしもの）。
- **Q2 こたつ の 上限 6 は？** ◎ **たまご の 数 で 6 こ まで**（こたつ 2 台 いっぱい ＝ 6。かえる ひよこ は なかま 8 わ まで なので 足りる）／ こたつ の 数 で 2 台 まで（3 台目 に は 入れられない）。
- **Q3「勝手 に 出て くる」は どれ？** ◎ **つれて 入った 子 が 3 秒 たつ 前 に いっしょ に 出て しまう**（→ 入った しゅんかん に とりごや の こ に する、で 直る）／ とりごや の こ に なった あと に 出て いった（→ 不具合 と して 開発 で 調べる。AC7 で 確かめる）／ ついて くる 子 は もん を 通れない ように して、入れる の は なげる だけ に したい。
