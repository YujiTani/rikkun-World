## 0. ここ で 作る もの・作らない もの

- 作る: 「いっしょ に たたかう」マッチョ にわとり（ねらう・はしる・パンチ・おうえん・かちポーズ）、ねらって いる 妖怪 の 上 の しるし、音 3 つ、設定 7 こ、実績 1 こ、案内画面 の 1 行、テスト用 の 窓口。
- 作らない: マッチョ ひよこ・ふつう の にわとり が たたかう（大人 の マッチョ だけ）。マッチョ が 自分 から 妖怪 を さがして たたく（プレイヤー が たたいた 妖怪 だけ。§9 Q5）。マッチョ の 体力・やられる・しぬ（§9 Q1 おすすめ）。マッチョ の レベル・つよく なる そうび（あと の issue）。妖怪 の 強さ・出かた・AI の 変更（BALANCE・M3 は さわらない）。

## 1. ねらい（りっくん が どう 楽しむか・何 を 感じて ほしいか）

- **そだてた マッチョ は たのもしい あいぼう**: こたつ で かえした マッチョ ひよこ を、とりごや で マッチョ にわとり に そだてる。とりごや から だして むし を あげると、ぼうけん に ついてくる。「そだてた から つよい なかま に なった！」。
- **ぼく が たたいた 妖怪 を いっしょ に やっつける**: りっくん が 妖怪 を ポコッ と たたくと、マッチョ が「コケッ！」と きあい を 入れて はしって いき、力こぶ の うで で ポコッ。りっくん が 主役、マッチョ は おてつだい（パンチ の 強さ は ぼくとう と 同じ 2、はやさ は ぼくとう の 半分 くらい）。
- **字 が 読めなく ても 分かる**: ねらって いる 妖怪 の 上 に 小さな 力こぶ の しるし。たおすと マッチョ が 力こぶ ポーズ で「ふんっ」。
- **こわく ない・かなしく ない**: マッチョ は やられない（§9 Q1 おすすめ）。血・けが の 表現 なし。パンチ の 当たり は 星 の ポコッ。

## 2. 遊び方

### 2.1 たたかう マッチョ（だれ が たたかうか）

次 を **ぜんぶ** みたす 子 を 「たたかう マッチョ」と よぶ:

1. `breed` `'macho'` かつ `stage` `'adult'`（マッチョ にわとり。ひよこ は たたかわない）。
2. `friend` true で `home` null（とりごや の 外 の なかま）。とりごや の 子 は たたかわない（ついてこない ので）。
3. `follow` > 0（ついてきて いる。LIVE-1 §2.7。§9 Q4）。
4. だっこ 中・なげられて とんで いる 中・パタパタ 中・いただきます 中 で ない。

- つれだす 道 は 今 の しくみ の まま: とりごや の 中 で 大人 に なる（LIVE-2 §2.5）→ だっこ して 外 へ ぽいっ（LIVE-2.1 B）→ なかま（`follow` 0）→ **むし を あげる と 5 分 ついてくる**（LIVE-1）。`raised` は 見ない（マッチョ の 大人 は かならず とりごや で そだつ ため）。
- たたかう 数 の 上限: **`machoFighters` 3 わ**（§9 Q3）。たたかう マッチョ が 4 わ 以上 いる とき は、**なかま に なった 順 が 早い 3 わ** が たたかい、ほか は ふつう に ついてくる（おうえん も しない）。

### 2.2 ねらう 妖怪 を きめる

- **きっかけ**: プレイヤー の こうげき（すで・ぼくとう・かたな など の ぶき・ゆみ の や・わざ）で **妖怪 の 体力 が へった ステップ**。その 妖怪 が プレイヤー から 水平 **`machoLeash` 12 マス 以内** なら、たたかう マッチョ ぜんいん の ねらい を その 妖怪 に する（あたらしく たたいた 妖怪 に のりかえる）。
  - からぶり・パリィ で はじいた だけ・体力 が へらない 当たり（ぬりかべ の かたい 所 など）は きっかけ に ならない。
  - マッチョ の パンチ で へった 時 は きっかけ に ならない（ねらい は かわらない）。
- ねらい を きめた ステップ: マッチョ の 頭 の 上 に「！」が 20 ステップ・音 `machoGo`（コケッ！ きあい）。その 妖怪 の 頭 の 上 に **力こぶ の しるし**（§3.2）。出来事 `machoTarget`（`id`・`yokai`）。音 `machoGo` は 1 つ の ねらい に 1 回（同じ 妖怪 を 何 回 たたいて も 鳴らさない）。
- **ねらい を やめる**（その ステップ に ふつう の ついてくる に もどる。出来事 `machoGiveUp`（`id`・`reason`））:
  - 妖怪 が たおれた（`reason` `'defeat'`。§2.4 の かちポーズ）・あさ で 帰った／消えた（`'gone'`）。
  - 妖怪 が プレイヤー から 水平 **16 マス** より はなれた（`'far'`）。
  - プレイヤー が その 妖怪 を **`machoForget` 600 ステップ（10 秒）** たたかなかった（`'forget'`）。
  - `follow` が 0 に なった・だっこ された・プレイヤー が やられた（`'stop'`）。

### 2.3 はしる・パンチ

- ねらい が ある あいだ、マッチョ は その 妖怪 へ **`machoRunSpeed` 5.0 マス/秒** で はしる（ついてくる 4.0 より 少し はやい。とぶ ような ダッシュ）。段 の のぼり・水 に 入らない・深い 所 に おりない は LIVE-1 の ついてくる と 同じ。妖怪・プレイヤー と は ぶつからない（すりぬける。LIVE-1 の まま）。
- **とどく**: 妖怪 の 当たり の 箱 まで 水平 **`machoReach` 1.2 マス 以内** かつ 高さ の ちがい **2 マス 以内** で パンチ を はじめる。
- **パンチ**（1 回 `machoAtkTicks` 30 ステップ。§3.3）: ため 8 → パンチ 4（**12 ステップ 目 に 当たる**）→ もどり 18。とどいて いる あいだ 30 ステップ ごと に くり返す。
  - 12 ステップ 目 に まだ とどいて いれば 妖怪 の 体力 を **`machoAtk` 2**（ぼくとう と 同じ。§9 Q2）へらす。とどいて いなければ からぶり（何 も へらない・音 なし）。
  - 場所 の 倍率・二つ名 で マッチョ の 2 は かわらない（妖怪 の 体力 が ふえる だけ。BALANCE §2.3）。
  - **妖怪 を 押さない**（ノックバック 0。プレイヤー の まえ から 妖怪 を とばして じゃま しない ため）。妖怪 の ねらい（だれ を おいかけるか）も かえない。
  - 当たり の 見た目: 星 の ポコッ つぶ（小）・音 `machoPunch`（ポコッ。プレイヤー の パンチ より 小さく）。妖怪 の 体力 の バー は ふつう に へる。
- **とどかない 妖怪**（ちょうちん が 水 の 上・がけ の 上 など）: はしり はじめて **180 ステップ** とどかなかったら、プレイヤー の そば（ついてくる 止まる 距離）に もどって **おうえん**（その場 で 力こぶ を 上下。音 なし）。ねらい は のこし、とどく 所 に 来たら また はしる。
- 夜・妖怪 が いない とき は ふつう の なかま と 同じ（LIVE-1 の まま）。

### 2.4 たおした とき

- たおした の が マッチョ の パンチ でも プレイヤー でも、**ようかいだま・ドロップ・経験値 は ぜんぶ プレイヤー の もの**（今 の たおした とき と 同じ。M3 §2）。
- マッチョ の パンチ で たおした とき: 記録 `machoKO:*` ＋1。
- ねらって いた マッチョ は **かちポーズ**（力こぶ 30 ステップ）・音 `machoFlex`（ふんっ！ 明るく 短く）。2 わ 以上 でも 音 は 1 回。そのあと ついてくる に もどる。
- はじめて マッチョ が たおした とき だけ 実績（§4.5。小 の おめでとう）。2 回目 から は かちポーズ と 音 だけ（くり返す 行動 の 演出 は 控えめ。`docs/fun.md`）。

### 2.5 マッチョ と 妖怪（§9 Q1 の おすすめ で 書く）

- **妖怪 は マッチョ を ねらわない・マッチョ に こうげき が 当たらない**（LIVE-1 §2.2「たたけない」の まま。火の玉 も すりぬける）。マッチョ は やられない・体力 なし。
- プレイヤー の こうげき・や も マッチョ に 当たらない（LIVE-1 の まま）。マッチョ の パンチ も プレイヤー・ほか の にわとり・ブロック に 当たらない。

| たたかう とき | マッチョ 3 わ・妖怪 5 体 で、仕事 の 数 の ふえ は マッチョ 1 わ に つき ねらい 1 体 を 見る 分 だけ（妖怪 の 数 を 2 倍 に しても ふえない） |
| 描画 | 「ねらい なし」と くらべて 描画回数 の ふえ **2 以下**、三角形 の ふえ **200 以下**（しるし・「！」・星 の つぶ）。ねらい が おわると ふえ 0 |
| 時間 | 測る なら 記録 だけ（【perf】） |

## 5. 例外 の とき

- **ねらい の 妖怪 が プレイヤー の うしろ で ほか の 妖怪 に かこまれた**: マッチョ は ねらい だけ を たたく（ほか の 妖怪 は たたかない）。
- **プレイヤー が やられた**: ねらい を やめる（`'stop'`）。`follow` > 0 の マッチョ は 生き返った 所 へ ワープ（LIVE-1 の まま）。
- **はしって いる とちゅう で `follow` が 0**: その場 で とまる（LIVE-1 の まま。ワープ しない）。
- **プレイヤー が 16 マス より はなれた**: ねらい を やめ、LIVE-1 の ワープ の きまり（16 より とおい と ワープ）に もどる。
- **だっこ した**: ねらい を やめる。おろした（なげた）あと は ふつう の ついてくる。つぎ に プレイヤー が たたいた とき に また ねらう。
- **とりごや に なげ入れた**: とりごや の 子 に なり、たたかわない。
- **ひよこ の マッチョ**: たたかわない（ついてくる だけ）。大人 に なった あと 外 に 出して むし を あげれば たたかう。
- **ヌシ・たいしょう**: ふつう に ねらう（強さ は かえない）。ヌシ を マッチョ が たおして も 紙ふぶき は 今 の まま 1 回。
- **ゆみ で とおく の 妖怪 を たたいた**: 12 マス 以内 なら ねらう。それ より とおい なら ねらわない。
- **2 体 を こうごに たたいた**: さいご に たたいた 方 に のりかえる（`machoGo` は のりかえる たび に 1 回）。
- **夜 が あけて 妖怪 が 帰る**: `'gone'` で やめる。かちポーズ・記録 なし。

## 8. オーナー に 見せる 要点

1. とりごや で そだった **マッチョ にわとり** を 外 に 出して むし を あげると、5 分 ぼうけん に ついてくる。
2. りっくん が 妖怪 を たたくと、マッチョ が「コケッ！」と はしって いき、力こぶ で ポコッ（強さ は ぼくとう と 同じ 2、はやさ は 半分）。妖怪 の 上 に 力こぶ の しるし。
3. たおすと マッチョ が 力こぶ ポーズ で「ふんっ！」。ごほうび は りっくん に 入る。はじめて の とき だけ 小さな 実績。
4. マッチョ は 自分 から は たたかわない（りっくん が 主役）。妖怪 に ねらわれず、やられない。
5. いっしょ に たたかう の は 3 わ まで。
