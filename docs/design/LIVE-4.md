## 0. ここ で 作る もの・作らない もの

- 作る: 「いっしょ に たたかう」マッチョ にわとり 1 わ（ねらう・はしる・パンチ・3 回目 の きりあげ パンチ・おうえん・かちポーズ）、ねらって いる 妖怪 の 上 の しるし、音 4 つ、設定 6 こ、実績 1 こ、案内画面 の 1 行、テスト用 の 窓口。
- 作らない: マッチョ ひよこ・ふつう の にわとり が たたかう（大人 の マッチョ だけ）。マッチョ が 自分 から 妖怪 を さがして たたく（きっかけ は §2.2 の 2 つ だけ）。マッチョ の 体力・やられる・しぬ（Q1）。2 わ 以上 で たたかう（Q3）。マッチョ の レベル・そうび（あと の issue）。妖怪 の 強さ・出かた・AI の 変更（BALANCE・M3 は さわらない）。

## 1. ねらい（りっくん が どう 楽しむか・何 を 感じて ほしいか）

- **そだてた マッチョ は たのもしい あいぼう**: こたつ で かえした マッチョ ひよこ を、とりごや で マッチョ にわとり に そだてる。とりごや から だして むし を あげると、ぼうけん に ついてくる。「そだてた から つよい なかま に なった！」。
- **いっしょ に やっつける・まもって くれる**: りっくん が 妖怪 を ポコッ と たたくと、マッチョ が「コケッ！」と はしって いって 力こぶ の うで で ポコッ。りっくん が 妖怪 に たたかれた ときも、その 妖怪 に かかって いく。
- **3 回目 は きりあげ**: ポコッ・ポコッ・**ドーン！** 3 回目 は 下 から 上 へ の パンチ で、妖怪 が ふわっと うく（刀 の 切り上げ と 同じ）。リズム が 分かって たのしい。
- **字 が 読めなく ても 分かる**: ねらって いる 妖怪 の 上 に 小さな 力こぶ の しるし。たおすと マッチョ が 力こぶ ポーズ で「ふんっ」。
- **こわく ない・かなしく ない**: マッチョ は ねらわれない・やられない。血・けが の 表現 なし。パンチ の 当たり は 星 の ポコッ。

## 2. 遊び方

### 2.1 たたかう マッチョ（だれ が たたかうか）

次 を **ぜんぶ** みたす 子 を 「たたかえる マッチョ」と よぶ:

1. `breed` `'macho'` かつ `stage` `'adult'`（マッチョ にわとり。ひよこ は たたかわない）。
2. `friend` true で `home` null（とりごや の 外 の なかま）。とりごや の 子 は たたかわない（ついてこない ので）。
3. `follow` > 0（ついてきて いる。LIVE-1 §2.7 の まま。むし で 5 分 に もどる。Q4）。
4. だっこ 中・なげられて とんで いる 中・パタパタ 中・いただきます 中 で ない。

- つれだす 道 は 今 の しくみ の まま: とりごや の 中 で 大人 に なる（LIVE-2 §2.5）→ だっこ して 外 へ ぽいっ（LIVE-2.1 B）→ なかま（`follow` 0）→ **むし を あげる と 5 分 ついてくる**（LIVE-1）。`raised` は 見ない（マッチョ の 大人 は かならず とりごや で そだつ ため）。
- **たたかう の は 1 わ だけ**（`machoFighters` 1。Q3）。たたかえる マッチョ が 2 わ 以上 いる とき は、**なかま に なった 順 が いちばん 早い 1 わ** が たたかい、ほか は ふつう に ついてくる（おうえん も しない）。その 1 わ が たたかえなく なった（だっこ・`follow` 0 など）ら、次 の ステップ から 次 に 早い 1 わ が たたかう 子 に なる（ねらい は その 子 に うつらない。つぎ の きっかけ を まつ）。

### 2.2 ねらう 妖怪 を きめる（きっかけ は 2 つ）

- **きっかけ 1（りっくん が たたいた）**: プレイヤー の こうげき（すで・ぼくとう・かたな など の ぶき・ゆみ の や・わざ）で **妖怪 の 体力 が へった ステップ**。
- **きっかけ 2（りっくん を たたいた）**: 妖怪 の こうげき（ふつう の こうげき・火の玉・体当たり）で **プレイヤー の 体力 が へった ステップ**。その こうげき を した 妖怪（火の玉 なら 火の玉 を うった 妖怪）。Q5。
- どちら も、その 妖怪 が プレイヤー から 水平 **`machoLeash` 12 マス 以内** なら、たたかう マッチョ の ねらい を その 妖怪 に する。**さいご の きっかけ が かつ**（ほか の 妖怪 に のりかえる）。同じ ステップ に 2 つ ある とき は きっかけ 1 を さき に する（りっくん が えらんだ 妖怪 を 大事 に する）。
  - きっかけ に ならない もの: からぶり。体力 が へらない 当たり（ぬりかべ の かたい 所 など）。パリィ で はじいた 妖怪 の こうげき・防具 で 0 に なった こうげき（プレイヤー の 体力 が へらない）。落ちた・みず など 妖怪 の せい で ない ダメージ。マッチョ の パンチ で 体力 が へった とき（ねらい は かわらない）。
- ねらい を きめた ステップ: マッチョ の 頭 の 上 に「！」が 20 ステップ・音 `machoGo`（コケッ！ きあい）。その 妖怪 の 頭 の 上 に **力こぶ の しるし**（§3.2）。出来事 `machoTarget`（`id`・`yokai`・`cause`: `'playerHit'｜'playerHurt'`）。音 `machoGo` は 1 つ の ねらい に 1 回（同じ 妖怪 で きっかけ が 何 回 あって も 鳴らさない）。
- **ねらい を やめる**（その ステップ に ふつう の ついてくる に もどる。出来事 `machoGiveUp`（`id`・`reason`））:
  - 妖怪 が たおれた（`reason` `'defeat'`。§2.4 の かちポーズ）・あさ で 帰った／消えた（`'gone'`）。
  - 妖怪 が プレイヤー から 水平 **16 マス** より はなれた（`'far'`）。
  - その 妖怪 で **`machoForget` 600 ステップ（10 秒）** きっかけ が なかった（`'forget'`）。
  - `follow` が 0 に なった・だっこ された・プレイヤー が やられた・たたかう 子 で なく なった（`'stop'`）。

### 2.3 はしる・パンチ

- ねらい が ある あいだ、マッチョ は その 妖怪 へ **`machoRunSpeed` 5.0 マス/秒** で はしる（ついてくる 4.0 より 少し はやい ダッシュ）。段 の のぼり・水 に 入らない・深い 所 に おりない は LIVE-1 の ついてくる と 同じ。妖怪・プレイヤー と は ぶつからない（すりぬける。LIVE-1 の まま）。
- **とどく**: 妖怪 の 当たり の 箱 まで 水平 **`machoReach` 1.2 マス 以内** かつ 高さ の ちがい **2 マス 以内** で パンチ を はじめる。
- **はやさ は ぼくとう と 同じ**（Q2）: 1 回 の パンチ の ながさ・当たる コマ は ぼくとう の **突き（中段 の わざ）の フレーム** を 使う。**設定 `bladeTech.thrust` を 読む**（ため ＝ `startup`、当たる ＝ `active` の さいしょ の コマ、もどり ＝ `active` の のこり ＋ `recovery`）。今 の 数（4・2・35）で は **1 回 41 ステップ**・**5 ステップ 目 に 当たる**。ぼくとう の 数 が かわったら マッチョ も いっしょ に かわる（マッチョ 用 の 時間 の 設定 は 作らない）。とどいて いる あいだ くり返す。
- **ふつう の パンチ**（1 回目・2 回目）: 当たる コマ に まだ とどいて いれば 妖怪 の 体力 を **`machoAtk` 2**（ぼくとう の 強さ `weaponDamage.bokuto` と 同じ）へらす。**妖怪 を 押さない**（ノックバック 0）。
- **きりあげ パンチ**（3 回目・6 回目・9 回目 …）: **刀 の 切り上げ と 同じ こと を する**（Q2）。
  - ダメージ ＝ `machoAtk` × `bladeDamageMul.kiriage`（今 1.15 → **2.3**。刀 と 同じ 小数 2 けた の 丸め）。
  - **ノックバック と うき ＝ `bladeKnock.kiriage`**（今 `[1.0, 7]`: プレイヤー で なく **マッチョ から 遠い 向き** へ 水平 1.0、上 へ 7 ブロック/秒 で ふわっと ういて、落ちかた は 今 の 妖怪 の 落下。ちょうちん は 押し上げられて から もとの 高さ へ もどる）。**ぬりかべ は 押されない・うかない**（今 の まま）。
  - 刀 の 切り上げ と 同じ 「体力 を へらす 口」と 「押す・うかす 口」を 使う（新しい うかしかた を 作らない）。
- **数え方**: 「当たった パンチ」を ねらい ごと に 1・2・3 … と 数える（からぶり は 数えない）。3 の 倍数 が きりあげ。ねらい が かわる・やめる と 0 に もどる。きりあげ は とどいた 時 だけ（からぶり で 番 を 使わない）。
- 当たる コマ に とどいて いなければ からぶり（何 も へらない・音 なし・数えない）。
- 場所 の 倍率・二つ名 で マッチョ の 強さ は かわらない（妖怪 の 体力 が ふえる だけ。BALANCE §2.3）。妖怪 の ねらい（だれ を おいかけるか）も かえない。
- 当たり の 見た目: ふつう は 星 の ポコッ つぶ（小）・音 `machoPunch`。きりあげ は 上 へ とぶ 星 3 つ ＋ 音 `machoUpper`（ドーン！ 下 から 上 へ。刀 の `kiriage` より みじかく かわいく）。妖怪 の 体力 の バー は ふつう に へる。
- **とどかない 妖怪**（ちょうちん が 水 の 上・がけ の 上 など）: はしり はじめて **180 ステップ** とどかなかったら、プレイヤー の そば（ついてくる 止まる 距離）に もどって **おうえん**（その場 で 力こぶ を 上下。音 なし）。ねらい は のこし、とどく 所 に 来たら また はしる。
- 夜・妖怪 が いない とき は ふつう の なかま と 同じ（LIVE-1 の まま）。

### 2.4 たおした とき

- たおした の が マッチョ の パンチ でも プレイヤー でも、**ようかいだま・ドロップ・経験値 は ぜんぶ プレイヤー の もの**（今 の たおした とき と 同じ。M3 §2）。
- マッチョ の パンチ で たおした とき: 記録 `machoKO:*` ＋1。
- ねらって いた マッチョ は **かちポーズ**（力こぶ 30 ステップ）・音 `machoFlex`（ふんっ！ 明るく 短く）。そのあと ついてくる に もどる。
- はじめて マッチョ が たおした とき だけ 実績（§4.5。小 の おめでとう）。2 回目 から は かちポーズ と 音 だけ（くり返す 行動 の 演出 は 控えめ。`docs/fun.md`）。

### 2.5 マッチョ と 妖怪（Q1: ねらわれない・やられない）

- **妖怪 は マッチョ を ねらわない・マッチョ に こうげき が 当たらない**（LIVE-1 §2.2「たたけない」の まま。火の玉 も すりぬける）。マッチョ は やられない・体力 なし。
- プレイヤー の こうげき・や も マッチョ に 当たらない（LIVE-1 の まま）。マッチョ の パンチ も プレイヤー・ほか の にわとり・ブロック・ねらい で ない 妖怪 に 当たらない（きりあげ も ねらい の 1 体 だけ。刀 の 扇形 の よう に まわり を まきこまない）。

## 5. 例外 の とき

- **ねらい の 妖怪 が ほか の 妖怪 と いっしょ に いる**: マッチョ は ねらい だけ を たたく（きりあげ も まきこまない）。ほか の 妖怪 が りっくん を たたいたら、そっち に のりかえる（きっかけ 2）。
- **りっくん が 2 体 に 同時 に たたかれた**: 体力 が へった 順（同じ ステップ なら 妖怪 の id の 小さい 方。決まった 順 で テスト で 再現 できる よう に）で さいご の 1 体。
- **パリィ で はじいた・防具 で 0**: プレイヤー の 体力 が へらない ので きっかけ に ならない。
- **プレイヤー が やられた**: ねらい を やめる（`'stop'`）。`follow` > 0 の マッチョ は 生き返った 所 へ ワープ（LIVE-1 の まま）。
- **はしって いる とちゅう で `follow` が 0**: その場 で とまる（LIVE-1 の まま。ワープ しない）。
- **プレイヤー が 16 マス より はなれた**: ねらい を やめ、LIVE-1 の ワープ の きまり（16 より とおい と ワープ）に もどる。
- **だっこ した**: ねらい を やめる。おろした（なげた）あと は ふつう の ついてくる。つぎ の きっかけ で また ねらう。
- **とりごや に なげ入れた**: とりごや の 子 に なり、たたかわない。
- **たたかう 1 わ が とりごや に 入った・だっこ された**: 次 に 早い マッチョ が たたかう 子 に なる（§2.1）。
- **ひよこ の マッチョ**: たたかわない（ついてくる だけ）。
- **きりあげ で ういた 妖怪 に とどかなく なった**: 次 の パンチ の 当たる コマ に 高さ 2 マス を こえて いれば からぶり（数えない）。落ちて くれば また 当たる。
- **ヌシ・たいしょう**: ふつう に ねらう（強さ は かえない）。ヌシ を マッチョ が たおして も 紙ふぶき は 今 の まま 1 回。
- **ゆみ で とおく の 妖怪 を たたいた・とおく から 火の玉 で たたかれた**: 12 マス 以内 なら ねらう。それ より とおい なら ねらわない。
- **夜 が あけて 妖怪 が 帰る**: `'gone'` で やめる。かちポーズ・記録 なし。
