# WATER-1: 水の 流れ（仕様書）

- issue #376。オーナー（yuzu）の OK した 要点 1〜7 に 合わせる。**子ども向けの 特別な きまりは 足さない**（yuzu「子供向けのルールは特にいらない」）。
- 手本: Minecraft の MOD「Water Physics Overhaul」の 有限の 水。
- 変える 仕様: `BUCKET-1.md`（この 書の §4.4・§4.5・§3）。ほかは 今の まま。1 秒 = 60 ステップ。

## 1. ねらい
- 水が **ほんものの 量** を もつ。くめば へり、そそげば ふえ、こぼせば 低い 所へ 流れて たまる。
- 池を 掘って 川から 水を 引く・穴に 水を ためる・せきとめる、を 自分で 考えて できる。

## 2. 遊び方（プレイヤーから 見た 動き）
- 海・川・池（生成の 水）は ふだんは しずかで 動かない。となりを 掘ると 流れ出し、穴を うめる。そのぶん 元の 水面が 少し さがる。
- バケツで くむと その マスの 水が へる（なくなる）。そそぐと そこに 水が でき、平らに 広がる・下へ 落ちる。
- 水の マスに ブロックを 置くと、水は となりへ 押し出される。
- 浅い 水（量 1〜3）は 歩いて 通れる。深い 水（量 4〜8）は 泳ぐ（§4.6）。

## 3. 画面・見た目
- 文字: 新しい 文字は ない（量 1〜7 の 水も 名前は `みず`）。
- 色・形: **水面の 高さ = 量 ÷ 8**（量 4 なら マスの 半分の 高さ）。すぐ 上の マスが 水（量は 問わない）なら いっぱいの 高さで 描く（つながって 見える）。横の 面も その 高さまで。テクスチャ・色・すけ方は 今の `water` の まま。
- みずの バケツ の 量: じょうろ と 同じ 青い 棒（M7-2 §3.2 (4)）で 見せる。はば = 量 ÷ 8。
- 音: 新しい 音は 作らない。流れる 音も 出さない（くり返す ことなので 静か に。`docs/fun.md`）。バケツの 音は BUCKET-1 §3.3 の まま。

## 4. ルール・数値

### 4.1 数（1 か所の 表。#304）
| 項目 | 値 | 意味 |
|---|---|---|
| `waterMax` | 8 つぶ | 1 マスに 入る 水の 量の 上限 |
| `waterTickSteps` | 15 ステップ（0.25 秒） | 水を 計算する 間かく（1 パス） |
| `waterPassMax` | 512 マス | 1 パスで 計算する 水の マスの 上限 |
| `waterSearch` | 7 マス | 低い 所を さがす 横の きょり |
| `waterDeep` | 4 つぶ | 泳ぐ・深い 水と 数える 量（§4.6） |
| `bucketTake` | 8 つぶ | バケツ 1 杯に 入る 量 |

### 4.2 水の きまり（量 a のマスを 1 回 計算する とき）
- **水が 入れる マス**: `air` と 水（量 1〜7。量 8 は いっぱい）だけ。たいまつ・作物・家具・世界の外・読みこんで いない 列 には 入らない（壁と 同じ）。
- 1 回の 計算は 次の 順。量は その場で 書きかえる（あとの マスは 新しい 量を 見る）。
  1. **落ちる**: すぐ 下が `air` か 量 b < 8 の 水 → `min(a, 8 − b)` つぶ を 下へ。a が 0 に なれば その マスは `air`。
  2. **低い 所へ 向かう**: 1 の あと a > 0 で、下へ 落ちられ なかった とき。北（−z）・東（+x）・南（+z）・西（−x）の **まっすぐ 4 本**を、1〜7 マス 先まで 見る（とちゅうが 水の 入れない マスなら そこで やめる）。d マス 先の マスの すぐ 下が `air` か 量 < 8 の 水 なら「低い 所」。いちばん 近い 低い 所（同じ きょり なら 北→東→南→西 の 先）の 向きの **となり** の 量 n が n < a なら、そこへ 1 つぶ 動かす。
  3. **平らに なる**: 2 で 動かなかった とき。北→東→南→西 の 順に、となりが 水の 入れる マスで 量 n（`air` は 0）が **a − n ≥ 2** なら 1 つぶ 動かす（となり 1 つに 1 つぶ まで。a は そのつど へる）。
- **止まる**: 1〜3 の どれも 動かない マスは 止まる。差が 1 以下なら 動かないので、平らな 床の 量 1 の 水たまりは そのまま のこる（低い 所が 7 マス 以内に なければ）。
- **量は 保たれる**: 1〜3 は 動かす だけ。へる・ふえる のは バケツ（§4.4）と 押し出しで 行き場が ない とき（§4.5）だけ。

### 4.3 チッキング・キュー（起きている 水の リスト）
- **入れる**: マスの ブロックが かわった（水の 量・置く・掘る・バケツ）とき、その マスと まわり 6 マス の うち **水の マス** を リストの うしろに 入れる。すでに 入って いれば 入れない（同じ マスは 1 つ）。
- **パス**: ステップ番号が `waterTickSteps` で 割りきれる ステップに、リストの 頭から 最大 `waterPassMax` マスを 1 回ずつ 計算する。パスの 間に 起きた マスは リストの うしろ（次の パス以後）。のこりは 次の パスへ（頭から 順に）。
- **眠る**: 計算して 何も 動かなかった マスは リストから 外す。動いた マスは うしろに 入れ直し、量が かわった 相手の マスと その まわり 6 マスの 水も 入れる。
- **生成の 水**: 海・川・池は 作った とき 眠った まま（リストに 入れない）。となりが かわった ときだけ 起きる。
- **リストは 保存しない**。読みこみ（つづきから・列を 読みこむ）の ときの 起こし方:
  - 保存から 読んだ 列（プレイヤーが かえた 列）: 中の **量 1〜7 の 水** と、**すぐ 下が `air` か 量 < 8 の 水 の 量 8 の 水** を 入れる。
  - 新しく 作った 列: 入れない（生成の 水は 眠る）。
  - 列を 読みこんだ とき、となりの 読みこみ ずみ の 列との さかいの 1 列 の **量 1〜7 の 水** を 入れる（読みこむ 前は 壁 だった ため）。
- **順番は 決まっている**: 同じ 世界・同じ 操作なら いつも 同じ 結果（乱数を 使わない）。

### 4.4 バケツ（BUCKET-1 を 置きかえる 所）
- **くむ**: ねらいかた・ふりわけ（4d）は BUCKET-1 の まま。そのマスから `min(bucketTake − 今の バケツの 量, そのマスの 量)` つぶ を とる。マスは へり、0 なら `air`。海・川・池も へる（まわりの 水が 起きて 流れこむ）。
  - からの `バケツ` → `みずの バケツ`（量 = とった 分。1〜8）。
  - 量 8 未満の `みずの バケツ` でも くめる（8 まで たす）。量 8 なら 何も かわらず `fullCan`（BUCKET-1 の まま）。
- **そそぐ**: 置ける マスの きまり（`air` だけ・体・妖怪・作物）は BUCKET-1 §2.1 の まま。そこに バケツの 量 ぶんの 水を 置き（量 8 未満 なら その 量の 水）、`バケツ`（から）に もどる。置いた マスは リストに 入る。
- 量は `ItemStack.water`（じょうろ と 同じ 欄）に 1〜8 で もつ。**欄が 無い `water_bucket`（前の 保存）は 量 8**。
- BUCKET-1 §1 の「くんだ所の 水は へらない」・§2.1 の「水の マスは そのまま」は この 節で **置きかえる**。

### 4.5 ブロックを 置く・掘る
- **置く**: 量 a の 水の マスに ブロックを 置くと、水は こわれず、となりへ 押し出す。順は 上 → 北 → 東 → 南 → 西 → 下。水の 入れる マスを 8 まで みたして いく。入りきらない 分は 消える。もらった マスは リストに 入る。
- **掘る**: 掘って `air` に なった マスの まわり 6 マスの 水が 起きる（§4.3）。

### 4.6 番号（ビット）と 判定
- 保存は 今の まま 1 マス = Uint8 の ブロック番号（`BLOCK_TYPES` の 順）。番号は うしろに 足す。
- **量 1〜7 の 水**: id `water_1`〜`water_7`。番号は **W0 + (量 − 1)**。W0 = 足す ときの 種類の 数 以上で いちばん 小さい **8 の 倍数**（今 147 種 → W0 = 152、`water_1` = 152 … `water_7` = 158）。下 3 ビット = 量 − 1（`n & 7`）、`n >> 3 === W0 >> 3` で 量 1〜7 の 水と 分かる。
- W0 までの 空き番号（今 147〜151）と W0 + 7（今 159）は **予約**（世界に 出ない 空きの 種類。固くない・こわれない）。次の 新しい ブロックは W0 + 8 から。
- **量 8 は 今の `water`（番号 9）の まま**。生成・前の 保存の 水は そのまま 量 8 として 読める → 前の 保存は 読み直し なしで 使える。`SAVE_GEN`・`SAVE_VERSION` は かえない（前の 版の ゲームでは 新しい 保存は 読めない。これまでと 同じ）。
- 量 1〜7 の 種類: 名前 `みず`、固くない、こわれない、アイテムに ならない（今の `water` と 同じ）。
- **判定を 1 か所に**: `getBlock(...) === 'water'` の 比べ（いま src に 約 31 か所）を、次の 2 つに そろえる。
| 判定 | 本当に なる 量 | 使う 所 |
|---|---|---|
| `isWater` | 1〜8 | 畑の 湿り（M7-2 ①。量 1 でも しめる）・ねらいの 線（バケツ・れじぇんど・かげ・がしゃ・家の 地面 など）・落とし物が 水に 落ちた か |
| `isDeepWater` | `waterDeep`〜8（4〜8） | 泳ぐ（プレイヤー）・妖怪の 水よけ と 泳ぎ・どうぶつ・落とし物が うく |
- 浅い 水（1〜3）では 泳がず、ふつうに 歩く。妖怪・どうぶつ も 歩いて 通る。
- **リストの マスの 形**（1 つの 整数。JS の 安全な 整数 2^53 未満に 入る）:
  - `local = (y << 8) | ((z & 15) << 4) | (x & 15)`（17 ビット。y 0〜351）
  - `chunk = (cx + 2048) * 4096 + (cz + 2048)`（cx = x >> 4、cz = z >> 4。各 12 ビット。世界の 果て ±30000 は ±1875 列 なので 入る）
  - `key = chunk * 131072 + local`（合わせて 41 ビット）。もどす ときは `local = key % 131072`、`chunk = Math.floor(key / 131072)`。

## 5. 例外のとき
- 世界の 上・下の はし、世界の 果ての 壁、読みこんで いない 列: 水は 入らない（壁）。
- プレイヤー・妖怪・どうぶつ・落とし物 の いる マス: 水は ふつうに 入る（体は 水を じゃま しない）。
- 量 1〜7 の 水の マスに そそぐ: BUCKET-1 の まま（水を ねらう 線は くむ に なる）。
- リストが とても 長い（大きな 穴に 海が 流れこむ）: 1 パス 512 マス まで。のこりは 次へ。ゆっくり 流れる が 止まらない。
- 押し出しで 行き場が ない（まわりが ぜんぶ 固い・いっぱい）: のこりは 消える。
- 量 8 の 水の 上に 水が ある・ない で 見た目が かわる だけで、量は かわらない。
