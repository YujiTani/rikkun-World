## 1. ねらい
- 水が **ほんものの 量** を もつ。くめば へり、そそげば ふえ、こぼせば 低い 所へ 流れて たまる。
- 池を 掘って 川から 水を 引く・穴に 水を ためる・せきとめる、を 自分で 考えて できる。

## 2. 遊び方（プレイヤーから 見た 動き）
- 海・川・池（生成の 水）は ふだんは 動かない。となりを 掘ると 流れ出して 穴を うめ、元の 水面が 少し さがる。
- バケツで くむと その マスの 水が へる。そそぐと そこに 水が でき、下へ 落ち・平らに 広がる。
- 水の マスに ブロックを 置くと、水は となりへ 押し出される。
- 浅い 水（量 1〜3）は 歩いて 通る。深い 水（量 4〜8）は 泳ぐ（§4.6）。

## 3. 画面・見た目
- 文字: 新しい 文字は ない（量 1〜7 の 水も 名前は `みず`）。
- **水面の 高さ = 量 ÷ 8**（量 4 なら マスの 半分）。すぐ 上が 水（量は 問わない）なら いっぱいの 高さ。テクスチャ・色・すけ方は 今の `water` の まま。
- **高さが ちがう 水どうしの 横の 面**: 高い ほうの マスが、となりの 水面の 高さから 自分の 水面までの 横の 面を 描く（同じ 高さ なら 今と 同じく 描かない）。
- **ゆらめき**（2 版。yuzu は PR を 手元で 見て 決める。事前の GIF 確認は しない）:
  1. 水面（上の 面）の 頂点を 時間で 少し 上下に ゆらす。ずれは 純関数 `waveOffset(wx, wz, t)`（`src/world/blocks/water.ts`）= `waveAmp × (1 + sin(世界の x・z と 時間 から 作る 角度)) ÷ 2` を **下向きに** 引く（水面より 上に 出ない）。shader も 同じ 定数（§4.1）から 作る。世界の 座標で 決めるので、となりの マスと 同じ 角の 頂点は 同じ だけ ゆれ、つぎめが 切れない。**横の 面の 上の 辺も 同じ だけ 動かす**。`waveAmp` は **0.125 未満**（量 1 = 1/8 の 水面が 底を こえない）。
  2. 水の テクスチャを 時間で ゆっくり ずらす。**流れて いる 水**（横の となりとの 量の 差が 2 以上、または 下が 入れる マス）は 低い ほうへ `flowScroll` で 流す。それ 以外は その場で `idleScroll` で ゆらめく。向きは メッシュを 作る ときに 決める。
  - 水の material（`src/world/render/rendererMaterials.ts` の `waterMaterial`・`lodWaterMaterial`。`applyLightShader` と 同じ `onBeforeCompile` の やり方）に **時間の uniform を 1 つ 足す だけ**。描画回数・三角形は ふやさない。
  - 時間は **ゲームの ステップ から 作る**（ステップ数 ÷ 60 秒）。一時停止中・`pause()` 中は 止まる。テストで 同じ ステップなら 同じ 絵。
- みずの バケツ の 量: じょうろ と 同じ 青い 棒（M7-2 §3.2 (4)）。はば = 量 ÷ 8。
- 音: 新しい 音は 作らない。流れる 音も 出さない（`docs/fun.md` の くり返す こと）。バケツの 音は BUCKET-1 §3.3 の まま。
- 見た目の 段取り（#154）: 量 1〜7 の 水面・横の 面・ゆらめきを ゲームに 入れた 試作で yuzu が 見る（テストの 準備の 前に 量 1〜8 の 水の 試作スクショ。ゆらめきは PR を 手元で）。

### 4.2 水の きまり
- **入れる マス**: `air` と 量 1〜7 の 水 だけ。**量 8 の 水・たいまつ・作物・家具・世界の外・読みこんで いない 列 には 入らない**（壁と 同じ）。低い 所を さがす 線も 入れない マスで 止まる。
- **量 a の マスを 1 回 計算する**（量は その場で 書きかえ、あとの マスは 新しい 量を 見る。1 回で する のは 下の 1 つ だけ）:
```
下 = 入れる → min(a, 8 − 下の量) を 下へ。おわり
北・東・南・西 の 順に まっすぐ 1〜7 マス（入れない マスで 止まる）、
  その マスの 下が 入れる なら「低い 所」。いちばん 近い もの（同じ なら 北→東→南→西）
低い 所が ある かつ その向きの となりの 量 < a → となりへ 1 つぶ。おわり
北・東・南・西 の 順に、となりが 入れる かつ a − となり ≥ 2 → 1 つぶ（a は そのつど へる）
```
- 量が 0 に なった マスは `air`。どこも 動かなければ「止まった」。差が 1 以下では 動かないので、平らな 床の 量 1 の 水たまりは 低い 所が 7 マス 以内に なければ のこる。
- **量は 保たれる**: へる・ふえる のは バケツ（§4.4）と 押し出しで 行き場が ない とき（§4.5）だけ。

### 4.3 チッキング・キュー（起きている 水の リスト）
- **入れる**: マスの ブロックが かわった とき（`world.setBlock` の 1 か所。掘る・置く・バケツ・水の 計算・生成中の 建物・妖怪の 石・gasha・house など 全部）、その マスと まわり 6 マス の うち **水の マス** を リストの うしろへ。同じ マスは 1 つ だけ。
  - この フックは **かわる 前の id** を 受けとり、前が 水 なら その 量を §4.5 の 押し出しに 使う（だれが `setBlock` しても 同じ）。
  - **`VoxelWorld.fill` では 起こさない**（テストが `fill` で 作る 池は 眠る）。
- **パス**: ステップ番号が `waterTickSteps` で 割りきれる ステップに、リストの 頭から 最大 `waterPassMax` マスを 1 回ずつ 計算する。パスの 中で 起きた マスは 次の パス以後。のこりは 次の パスの 頭から。
- **眠る**: 動かなかった マスは リストから 外す。動いた マスは うしろへ 入れ直す（量が かわった 相手の マスも 上の「入れる」で 入る）。
- **生成の 水**: 海・川・池は 作った とき 眠った まま。となりが かわった ときだけ 起きる。
- **眠った 水は 遠くの 新しい 穴に 気づかない**: 水から 2〜7 マス 先に 穴を 掘っても、水の となりが かわらない かぎり 流れない（PO 決め: 許す）。
- **リストは 保存しない**。読みこみの 起こし方（**動く かも しれない 水** を 起こす）:
  - 「動く かも しれない」= §4.2 の 計算で 動く マス（`water.stable` が false に する マス）。
  - **保存から 読んだ 列**（プレイヤーが かえた 列）を 読みこんだ とき: その 列の 動く かも しれない 水 ぜんぶ。
  - 列を 読みこんだ とき、その 列と となりの 読みこみ ずみ の 列 の **さかいの 1 列** の、動く かも しれない 水（保存から 読んだ 列の 側 だけ）。
  - 新しく 作った 列の 中は 起こさない（生成の 水は 眠る）。
  - 列を 手放す ときは、その 列の マスを リストから 外す（読みこみ直しで 上の きまりで 起きる）。
  - 上は 主な 道（`loadColumn`）の 話。保険の 道（`src/save/restore.ts` 143 行・`src/save/streamRestore.ts` 78 行）は `setBlock` で 当てるので、そこで 起きる。
- **順番**: 乱数を 使わない。**同じ 世界を 同じ 並びで 読みこみ、同じ 操作を すれば 同じ 結果**（列の 読みこみ順が ちがえば 止まった 形が ちがう ことは ある）。
- **テスト用の 止め**: `water.pause(true)` の 間は パスを しない（リストは ためる）。水を 置いて 動かしたく ない 前からの テスト用（§6.3）。

### 4.4 バケツ（BUCKET-1 を 置きかえる 所）
- **くむ**: ねらい・ふりわけ（4d）は BUCKET-1 の まま。マスから `min(8 − 今の バケツの 量, マスの 量)` を とる。マスは へり、0 なら `air`。海・川・池も へる（まわりが 起きて 流れこむ）。
  - からの `バケツ` → `みずの バケツ`（量 = とった 分）。量 8 未満の `みずの バケツ` でも くみ足せる。量 8 なら 何も かわらず `fullCan`。
- **そそぐ**: 置ける マスの きまり（`air` だけ・体・妖怪・作物）は BUCKET-1 §2.1 の まま。バケツの 量 ぶん の 水（8 なら `water`、1〜7 なら `water_<量>`）を 置き、`バケツ` に もどる。
- 量は `ItemStack.water` に 1〜8（じょうろ と 同じ 欄）。**欄の ない `water_bucket`（前の 保存）は 量 8**。保存の 形は かえない。
- BUCKET-1 §1「くんだ所の 水は へらない」・§2.1「水の マスは そのまま」を 置きかえる。**じょうろ は 今の まま**（くんでも 水は へらない）。

### 4.5 ブロックを 置く・掘る
- **置く**: 量 a の 水の マスに ブロックを 置くと、**上 → 北 → 東 → 南 → 西 → 下** の 順に、入れる マスを 8 まで みたして 押し出す。入りきらない 分は 消える。
- **掘る**: 掘って `air` に なった マスの まわりの 水が 起きる（§4.3）。

### 4.6 番号（ビット）・判定・描画
- 保存の 事実: 世界の 中は 1 マス = Uint8 の 番号（`BLOCK_TYPES` の 順）。**保存は 列ごとに 使った id の 文字の 一覧＋その 中の 番号**（`src/save/chunkCodec.ts`）なので、番号を 足しても 前の 保存は そのまま 読める。新しい 保存（`water_3` など）は 前の 版の ゲームでは 読めない（知らない id。これまでと 同じ）。`SAVE_GEN`・`SAVE_VERSION`・列の 形の 版 は かえない。
- **量 1〜7**: id `water_1`〜`water_7`、番号 **W0 + (量 − 1)**。W0 = 足す ときの 種類の 数 以上で いちばん 小さい **8 の 倍数**（今 147 種 → W0 = 152、`water_7` = 158）。`(n & 7) + 1` = 量、`n >> 3 === W0 >> 3` で 量 1〜7。
- **予約**: W0 までの 空き（今 147〜151）と W0 + 7（今 159）に `reserved_<番号>`（固くない・こわれない・名前 `くうき`。世界に 置かない）。次の 新しい ブロックは W0 + 8 から。番号は 255 まで（`houseBlocks.test.ts` の 256 以下）。この あと のこり 96。のこり 16 を 切る 前に 2 バイトへの 別 issue を 立てる。
- **量 8 は 今の `water`（番号 9）の まま**。生成・前の 保存の 水は 量 8。
- 量 1〜7 の 種類: 名前 `みず`、固くない、こわれない、アイテムに ならない、光は `water` と 同じ（1 弱める）、不透明 で ない。
- **契約の 関数**（ブロックの 判定の 1 ファイル `src/world/blocks/water.ts`）: `waterAmount(id | 番号)` → 0〜8（水で なければ 0）、`waterId(n)` → n = 0 `air`・1〜7 `water_n`・8 `water`、`isWater`（1〜8）、`isDeepWater`（`waterDeep`〜8）、`isWaterIndex(番号)`（1〜8）。
- **置きかえ表**（`=== 'water'`・`!== 'water'`・`=== WATER`・集合の `'water'`。書く 側 `setBlock(…, 'water')`・生成の `fill(WATER)` は そのまま）:

- 表は ファイルの 目安（行は 2 版の 時点）。AC2 の テストが 見つけた 所で 表に ない ものは、意味で 3 つに 分けて この 表に 足す。

## 5. 例外のとき
- 世界の 上・下の はし、果ての 壁、読みこんで いない 列: 入らない（壁）。
- プレイヤー・妖怪・どうぶつ・落とし物 の いる マス: 水は ふつうに 入る。
- 量 1〜7 の 水に そそぐ: BUCKET-1 の まま（水を ねらう 線は くむ）。
- 大きな 穴に 海が 流れこむ: 1 パス 512 マス まで。ゆっくり だが 止まらない。
- 海面に ブロックを 置く: 上に 押し出され、上に 量 1 などの うすい 水が のこる（オーナー確認 AC20）。
