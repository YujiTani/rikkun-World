## 遊び方の要点（オーナーの OK 用）

1. 風神剣も **押しっぱなしで ためて、はなすと ためわざ**。押し方・ためる 長さ（1 秒）・ため中に ゆっくり 歩ける・パリィとの 関係・体の 動き（刀を 頭の 上へ → ふりおろす）は **雷神剣と まったく 同じ**。
2. はなすと、刀を ふりおろした 所から **ねじれた 2 本の 風の おび（ドリル）が 回りながら** **前へ まっすぐ 12 マス** とぶ（1 秒）。とちゅうの 妖怪（ようかい）を **ぜんぶ つらぬいて**、1 体に 12 の ダメージ と 「ぐいっ」と 前へ 押し流す。地下でも 屋根の 下でも 使える（雷神剣と ちがう 所）。
3. 短く 押せば、今までの ふつうの わざ ＋ 小さな 真空波（変わらない）。
4. **ため中の 見た目と 音が 新しく なる（雷神剣も 風神剣も）**: 光の つぶが 体の まん中へ すいこまれつづけ、「ぎゅいーん」と 音が 上がっていく。いっぱいに なると 光の 輪が 1 回 ぱっと 広がって 合図の 音、その あとは きらきらが ゆっくり 回り、小さな 音が 鳴りつづける。はなすと すっと 消える。色は 風神剣 = 白〜水色、雷神剣 = 白〜黄色。
5. 風神剣を 手に 持っている 間、**画面の ハートの 上・左はしに「はやい くつ」の アイコン**（字は なし）が 出る。持ちかえると 消える。

## 1. ねらい（りっくんが どう 楽しむか）

- 雷神剣 =「ねらった 所に 上から ドーン」、風神剣 =「前に 一直線、まとめて ビューン」。**同じ 押し方で、ちがう 気持ちよさ**。ならんで 来る 妖怪を 1 発で まとめて 押し流す 楽しさ。
- ためる 動きは 雷神剣で もう 覚えている ので、新しく 覚える ことは「風神剣でも ためられる」だけ。
- **ためて いる 1 秒が 気持ちいい**: 光が 集まる・音が 上がる で「たまっていく」が 目と 耳で 分かり、いっぱいの 合図で「いま はなせば でる！」が 字なしで 分かる（今は 1 秒 音なし・光が 大きく なる だけで 分かりにくい）。
- 「足が はやい」が 目で 分かる（今は 気づきにくい）。くつの アイコンで「この 剣を 持つと はやく なる」と 分かる。

### 2.3 らせんの かぜの とび方・当たり

**数え方**（G2）: 生まれた ステップ（F6）を **a = 0** と する。a の ときの まん中の 点 **P(a) = B ＋ u ×（1.0 ＋ 0.2 × a）**。
- a = 0（F6）: P(0) の 1 点で 当たりを 見る（動かない）。
- a = 1〜60（F7〜F66）: 1 ステップ 0.2 進み、**P(a−1) から P(a) まで** の 筒で 当たりを 見る。
- a = 60（F66）の 当たりを 見た あとに `spiralEnd`（range）。このとき `traveled` = 12.0、まん中は B ＋ 13.0。

| 項目 | 値 |
|---|---|
| 生まれる 所 | P(0) = B から u の 向きへ **1.0** 前 |
| 向き | u（**水平**。見上げても 見下ろしても 地面に そって まっすぐ） |
| 速さ | **12 マス/秒**（1 ステップ 0.2）。重力 なし・まがらない |
| とどく | **12 マス**（a 60 = 1.0 秒）で 消える（小さな 風の けむり） |
| 太さ（当たり） | **半径 1.0 の 玉**を P(a−1) から P(a) まで 動かした 形（直径 2 マスの 筒）に、妖怪の 当たりの 箱（今の 真空波と 同じ 見方: 妖怪の 半径 r の 円柱）が 重なったら 当たり。つまり 妖怪の 中心が 線から 横に **1.0 ＋ r 以内** |
| つらぬく | **つらぬく**。1 つの かぜで 同じ 妖怪には 1 回だけ。何体 当たっても 消えない |
| ダメージ | **P × 2.0 = 12**（0.01 の 位）。ためない ふつうの 真空波（1.8）の 6.7 倍 |
| ふっとび | かぜの 向きへ **水平 3・上へ 1**（押し流す）。ぬりかべ は 押されない（今の きまり） |
| ブロック | まん中の 点 P(a) が 固い ブロック・はっぱに 入ったら 消える（風の けむり。ブロックは こわさない）。水・十字の 草花・たいまつ は とおりぬける（今の 真空波と 同じ） |
| 当たらない 物 | プレイヤー・どうぶつ・ブロック・妖怪の 火の玉（消さない） |
| たおした あつかい | プレイヤーが たおした（経験値・ドロップ・実績・ヌシの 表） |
| たいきゅう | **1 体でも 当たれば 1 へる**（何体でも 1。空ぶり 0。落雷と 同じ） |
| 同時に とぶ 数（G3） | **らせんは 1 つ まで**（いちばん 早くて ため 60 ＋ わざ 45 = 105 ステップに 1 回。とぶのは 61 ステップ（a 0〜60）なので 重ならない）。ふつうの 真空波の 上限は **今の コードの 8 つ（`MAX_WAVES`）の まま**で、らせんは その 8 に **数えない**（べつ）。ふだんの 遊びで 同時に 出る 真空波の 見込みは 3 つ |
| 地下・屋根の 下 | **使える**（空が 見えるか は 見ない） |

- **段差と かべ**（G4）: まん中の 点は 肩の 高さ（足もと ＋ 約 1.4）を とぶ。前に **高さ 1 マスの 段差**（足もとの 高さの ブロック 1 つ）は 上を こえて とびつづける。**高さ 2 マス 以上の かべ**（肩の 高さに ブロックが ある）に 来たら、P(a) が かべに 入った ステップで 消える（今の 真空波と 同じ 考え）。
- **当たる はんい**（テストの はば。からかさ r = 0.6 で 計算。妖怪の r は 0.4〜0.9）: 線の 上（横 0）の 妖怪は、前へ **B − r 〜 B ＋ 14.0 ＋ r**（玉の 後ろはしは P(0) − 1.0 = B、前はしは P(60) ＋ 1.0 = B ＋ 14.0。そこから 妖怪の 半径 r だけ 広がる）。
  - **必ず 当たる**: 前 **2〜12**、横 **0.8 以内**。
  - **必ず 当たらない**: 前 **15 より 先**（r 0.9 でも 14.9 まで）、横 **2.0 より 外**（r 0.9 でも 1.9 まで）、**後ろ 1.0 より 後ろ**（r 0.9 でも −0.9 まで）。
  - 体の すぐ 後ろ（からかさ なら 後ろ 0.6 まで）は 玉の はしが ふれて 当たる ことが ある（生まれる 玉の 半径の ため。直さない）。

## 3. 画面・見た目

### 3.1 らせんの かぜ（B「らせんの おび」。見本 `docs/art/WEAPON-8/spiral-b.png`）

- 「**ねじれた 2 本の 風の おびが ドリルの ように 回って 前へ とんで いく**」が 6 歳に 一目で 分かる。ふつうの 真空波（白い 三日月）と **形で ちがう**。

  - 見た目の 太さ（直径）= 当たりの 直径 2 マス の **1.6〜2.4 マス**。B の 見本は 約 1.5 なので、ゲームでは **1.6〜2.0 に 大きく して 入れる**（形は 同じ。三角形の 数は 変わらない）。
  - 見た目の 長さ（進む 向き）は 約 3 マス（art の 見本の まま）。
  - 回る 速さ: 軸の まわりの 回転は **1 回り 15 ステップ（0.25 秒）より ゆっくり**。おすすめ 24 ステップ（おびが 2 本 なので 12 ステップで 同じ 形に 見える）。art の「4 コマ × 3 ステップ」の くり返しは この 速さに 合わせる。
  - art の 区間（出る a 0〜1 → のびる a 2〜3 → 決め a 4〜9 → とぶ → ほどける）は **見た目の 大きさ・明るさ だけ**。決め の 間も 位置は 1 ステップ 0.2 進む（当たりは §2.3 の まま）。ほどける（6 ステップ）は `spiralEnd` の あとに 出す。
  - 出る・消える の 明るさの 上げ下げは 1 回ずつ。**点滅しない**。画面 ぜんたいを 光らせない・色づけない。
  - 新しい 絵の 作り方（`docs/art/PIPELINE.md`）: 「いつも カメラに 正面・一番 決まる 絵・ペラペラに 見せない」。横から 見ても、後ろ（一人称で 自分が 出した 物を 追う 向き）から 見ても 消えて 見えない（B は 本物の 3D の おびで、どの 向きも 厚みが ある）。

  - 性能の 上限（エフェクト 1 つ）: **描画回数 4・三角形 150**。B は 描画 1〜2・三角形 98。
  - 当たった 妖怪: 今の 星 ＋ 小さな 風の すじ（くり返す ので 小さく）。
  - ブロック・とどく おわり で 消える とき: 小さな 風の けむり（6〜10 ステップ）。
- 一人称で 自分の 目の 前（P(0) = B＋1.0）で 視界を ふさがない: a 0〜5（1.2 マス 進む まで）は 見た目を 小さく・うすく してよい（当たりは 変えない）。
- 「動きを減らす」: おびを 回さない（回転 0。形・大きさ・当たりは 同じ）。
- 確かめの 絵 4 枚・CRITERIA 表（1〜17）は art の 3 案に ついている。体の 動きは 雷神剣の 物を そのまま 使うので MOTION の 新しい 確かめは いらない（落雷で 確かめ済み）。「ふりおろしの F6 に 前へ 出る」つながりを 横から 見た 絵 1 枚（MOTION の「横から 見た 動き」）は **ゲームに 入れた 試作の スクショで 補う**（G6。WEAPON-7 G3 と 同じ 扱い）。
