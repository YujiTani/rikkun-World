## 遊び方の要点（オーナーの OK 用）

1. 風神剣も **押しっぱなしで ためて、はなすと ためわざ**。押し方・ためる 長さ（1 秒）・ため中に ゆっくり 歩ける・パリィとの 関係・体の 動き（刀を 頭の 上へ → ふりおろす）は **雷神剣と まったく 同じ**。
2. はなすと、刀を ふりおろした 所から **らせんに 回る 風の かたまり** が **前へ まっすぐ 12 マス** とぶ（1 秒）。とちゅうの 妖怪（ようかい）を **ぜんぶ つらぬいて**、1 体に 12 の ダメージ と 「ぐいっ」と 前へ 押し流す。地下でも 屋根の 下でも 使える（雷神剣と ちがう 所）。
3. 短く 押せば、今までの ふつうの わざ ＋ 小さな 真空波（変わらない）。
4. 風神剣を 手に 持っている 間、**画面の ハートの 上に「はやい」の アイコン**（風と 足の 絵）が 出る。持ちかえると 消える。

## 1. ねらい（りっくんが どう 楽しむか）

- 雷神剣 =「ねらった 所に 上から ドーン」、風神剣 =「前に 一直線、まとめて ビューン」。**同じ 押し方で、ちがう 気持ちよさ**。ならんで 来る 妖怪を 1 発で まとめて 押し流す 楽しさ。
- ためる 動きは 雷神剣で もう 覚えている ので、新しく 覚える ことは「風神剣でも ためられる」だけ。
- 「足が はやい」が 目で 分かる（今は 気づきにくい）。アイコンで「この 剣を 持つと はやく なる」と 分かる。

### 2.3 らせんの かぜの とび方・当たり

| 項目 | 値 |
|---|---|
| 生まれる 所 | B から u の 向きへ **1.0** 前（体の 前はし。後ろの 妖怪には 当たらない） |
| 向き | u（**水平**。見上げても 見下ろしても 地面に そって まっすぐ） |
| 速さ | **12 マス/秒**（1 ステップ 0.2）。重力 なし・まがらない |
| とどく | **12 マス**（60 ステップ = 1.0 秒）で 消える（小さな 風の けむり） |
| 太さ（当たり） | **半径 1.0 の 玉**を 前の 位置から 次の 位置まで 動かした 形（直径 2 マスの 筒）に 箱が 重なった 妖怪 |
| つらぬく | **つらぬく**。1 つの かぜで 同じ 妖怪には 1 回だけ。何体 当たっても 消えない |
| ダメージ | **P × 2.0 = 12**（0.01 の 位）。ためない ふつうの 真空波（1.8）の 6.7 倍 |
| ふっとび | かぜの 向きへ **水平 3・上へ 1**（押し流す）。ぬりかべ は 押されない（今の きまり） |
| ブロック | まん中の 点が 固い ブロック・はっぱに 入ったら 消える（風の けむり。ブロックは こわさない）。水・十字の 草花・たいまつ は とおりぬける（今の 真空波と 同じ） |
| 当たらない 物 | プレイヤー・どうぶつ・ブロック・妖怪の 火の玉（消さない） |
| たおした あつかい | プレイヤーが たおした（経験値・ドロップ・実績・ヌシの 表） |
| たいきゅう | **1 体でも 当たれば 1 へる**（何体でも 1。空ぶり 0。落雷と 同じ） |
| 同時に とぶ 数 | 1 つ（いちばん 早くて ため 60 ＋ わざ 45 = 105 ステップに 1 回。とぶのは 60 ステップ なので 重ならない）。ふつうの 真空波と 合わせても 3 つまで |
| 地下・屋根の 下 | **使える**（空が 見えるか は 見ない） |

- 「必ず 当たる / 必ず 当たらない」（テストの はば）: 線の 上に 立つ 妖怪は、B から 前 **2〜12** なら 必ず 当たる、**15 より 先** なら 必ず 当たらない。線から 横に **0.8 以内**（箱の 中心）なら 当たる、**2.0 より 外** なら 当たらない。

## 3. 画面・見た目

### 3.1 らせんの かぜ（何が 分かれば よいか。絵は art の 決定に 従う）

- 「**ぐるぐる 回る 風の かたまりが 前へ とんで いく**」が 6 歳に 一目で 分かる。ふつうの 真空波（白い 三日月）と **形で ちがう**（色ちがい だけに しない）。
- 遊びに 関わる 数（art は この 中で 作る）:
  - 見た目の 太さ（直径）= 当たりの 直径 2 マス の **1.6〜2.4 マス**（見た目より 当たりが 大きすぎ・小さすぎ に しない）。
  - 見た目の 長さ（進む 向き）は 2〜3 マス を 目安（art が 決める）。
  - 回る 速さ: 1 回りに 0.25 秒より ゆっくり（目が 回らない）。
  - 出る・消える の 明るさの 上げ下げは 1 回ずつ。**点滅しない**。画面 ぜんたいを 光らせない・色づけない。
  - 新しい 絵の 作り方（`docs/art/PIPELINE.md`）: 「いつも カメラに 正面・一番 決まる 絵・ペラペラに 見せない」。横から 見ても、後ろ（一人称で 自分が 出した 物を 追う 向き）から 見ても 消えて 見えない。
  - 性能の 上限（エフェクト 1 つ）: **描画回数 4・三角形 150**。とんでいる 間の 風の つぶ（あれば）も こみ。
  - 当たった 妖怪: 今の 星 ＋ 小さな 風の すじ（くり返す ので 小さく）。
  - ブロック・とどく おわり で 消える とき: 小さな 風の けむり（今の 真空波の けむりを 大きく した 物で よい。6〜10 ステップ）。
- 一人称で 自分の 目の 前（生まれる 所 B＋1.0）で 視界を ふさがない: 生まれて 6 ステップ（1.2 マス 進む まで）は 見た目を 小さく・うすく してよい（当たりは 変えない）。
- 確かめの 絵 4 枚（シルエット・白黒・ぼかし・今の 物と ならべた 絵）と CRITERIA 表（1〜17）は art-director の 3 案に つける。体の 動きは 雷神剣の 物を そのまま 使うので MOTION の 新しい 確かめは いらない（落雷で 確かめ済み）。ただし「ふりおろしの F6 に 前へ 出る」つながりを 横から 見た 絵 1 枚（MOTION の「横から 見た 動き」）で 見る。

- **いちばん 多い とき**（これから バフが 4 つ。字なし アイコン 4 つ ＋ すき間 3）: 1280 で 4 × 35 ＋ 3 × 4 ＋ 8 = 160 → 右はし 480 < 528。1024 で 4 × 30 ＋ 3 × 3.4 ＋ 6.8 = 137 → 377 < 417。1440 で 4 × 39 ＋ 3 × 4.5 ＋ 9 = 179 → 539 < 594。4 つ までは 字を 出さず アイコン だけ に する（字は 1 つの とき だけ）。
- 照準（画面の まん中）・合図の チップ（照準の 下 48px、まん中ぞろえ）とは 上下で 150px 以上 はなれる。左はしの レベルアップの 字（まん中）にも かぶらない。
- 案 B・C を 選んだ ときは、PO が この 表を 直す 依頼を する（かたまりの はばの 計算: 1024 で B は 右の おしらせ まで 約 26px、C は 約 60px）。

## 4. ルール・数値（データ）

風神剣の `legendary` の データを 下に 変える（WEAPON-7 §4.1 の `charge: null` を 置きかえる）。`LegendaryCharge` に `kind` を 1 つ 足す（WEAPON-7 §2.1 の 足し方）。

```ts
// src/contracts.ts の LegendaryCharge に 足す（名前は この 仕様で 決める）
| { kind: 'spiral'; chargeTicks: number; launchF: number; recovery: number;
    speed: number; range: number; radius: number; damageMul: number; knock: [number, number] }
```

| 項目 | 値 |
|---|---|
| charge | `{ kind: 'spiral', chargeTicks: 60, launchF: 6, recovery: 40, speed: 12, range: 12, radius: 1.0, damageMul: 2.0, knock: [3, 1] }` |
| わざの 長さ | 5 ＋ `recovery` 40 = **45**（落雷と 同じ 数え方） |
| power・onAttack・passive | 今の まま（6・真空波・はやさ 1.2） |
| もちものの 説明「なにに つかう」 | `てに もつと はやく はしれる。ためて はなすと かぜ が とぶ`（空白 のぞき 25 字。今の 文 21 字より 4 字 長いが、いちばん 長い 58 字 以下） |
| 説明「つかいかた」 | 雷神剣と 同じ（`。ながおし して はなすと ためわざ` が つく） |
| 設定 | 新しい 設定は なし（ため中の 歩き `legendaryChargeWalk` 0.5 を 使う） |

### 4.1 強さの 確かめ（BALANCE を こわさない）

たおす 回数（M = 1。体力 からかさ 8・ちょうちん 5・ろくろくび 12・ぬりかべ 40・ヌシの からかさ 24、M = 3 の ヌシ 72）

| わざ | 1 発 | からかさ | ろくろくび | ぬりかべ | ヌシ 24 | ヌシ M3 72 |
|---|---|---|---|---|---|---|
| らせんの かぜ | 12 | 1 | 1 | 4 | 2 | 6 |
| 落雷（くらべる） | 16 | 1 | 1 | 3 | 2 | 5 |
| 風神剣 おおげさぎり ＋ 波 | 16.8 | 1 | 1 | 3 | 2 | 5 |

- **1 体に 当てつづけ**（1 秒あたり）: らせん 12 × 60 ÷（60 ＋ 45）= **6.9**。落雷 9.1・風神剣 おおげさぎり＋波 9.5 より 弱い → 1 体なら ふつうの わざの 方が 強く、**ならんだ むれを まとめて 押し流す のが 強み**（雷神剣は まるく、風神剣は 一直線、と 遊び方が 分かれる）。
- ぬりかべ（40）は 4 発 かかる（1 発で なんでも たおれる には ならない）。BALANCE §2.7（妖怪の 安全の きまり）は 妖怪の 数なので 変わらない。
- ふっとび 水平 3 は 落雷（2）より 大きいが、押す だけ（落下は 今の 妖怪の きまり）。むれを 遠くへ 押しやる ので プレイヤーは 安全に なる 方向。
