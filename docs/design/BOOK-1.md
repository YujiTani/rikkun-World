# BOOK-1: ルールブックを 3D の本にする（仕様書）

issue #42 / タスク票 `docs/tickets/BOOK-1.md` / 指摘台帳 `docs/loop-ledger/BOOK-1.md` / オーナー決定 `docs/decisions/2026-10-18-rulebook-3d.md`

## 1. ねらい（りっくんがどう楽しむか）

- いまの案内画面（Esc で出る「あそびかた」）は、1 つのタブに カードが 4〜11 まい ならび、6 歳は読み飛ばす（#42）。
- これを **3D の 1 さつの本** にする。ボタンを押すと 本が画面のまんなかに あらわれ、ゆっくり ひらいて **目次（もくじ）**。章を押すと ページがめくれて **章の項目の一覧**、項目を押すと **大きな絵と 短い説明**。
- 「本を ひらいて さがす」こと自体が ちょっとした ぼうけん。読みたい所だけ 2 回押せば たどりつく（ぜんぶ順に めくらなくてよい）。
- 字が読めなくても、目次・一覧には 絵がついていて、項目のページの絵には「押すキー・マウスのボタン」と「そうすると どうなるか」が 描いてある（CRITERIA #12）。
- 新しいわざ（パリィ #199・3 段攻撃 #69・チャージ #70 など）は **項目のデータを 1 つ足すだけ** で本にのる。

## 2. 遊び方（プレイヤーから見た動き）

### 2.1 本の 3 つの ページ（流れ）

```
案内画面（Esc） ──「あそびかたの ほん」ボタン──▶ 本があらわれる → ゆっくり ひらく
   ▲                                                   │
   │ とじる                                             ▼
   └──────────────── ① もくじ（章 5 つの リンク）
                          │ 章を押す（めくる）       ▲ もどる
                          ▼                          │
                     ② 章の一覧（その章の 項目の リンク）
                          │ 項目を押す（めくる）     ▲ もどる
                          ▼                          │
                     ③ 項目（左に 絵・右に 見出しと 説明）◀ ▶ で となりの項目
```

- 本は いつも **見開き**（左右 2 ページ）で 正面を向いて止まる。
  - ① もくじ: 左 ＝ 本の名前「あそびかたの ほん」と キャラの絵。右 ＝ 章の リンク 5 つ（絵 ＋ 名前）。
  - ② 章の一覧: 左上に 章の名前。左右に 項目の リンク（小さな絵 ＋ 見出し）を 6 こずつ、1 見開きに 12 こまで。13 こ以上の章は 一覧が 2 見開き目に つづき、一覧の右下の ▶ で めくる（§2.6）。
  - ③ 項目: 左 ＝ 挿絵（さしえ）1 つ。右 ＝ 見出し ＋ 説明 1〜2 文 ＋ 章の中の何こ目かの 点（●●●○○）。

### 2.2 本を出す・しまう
- 案内画面（今と同じ: ゲームのはじめ・Esc を押したとき）に、**「あそびかたの ほん」ボタン**（本の絵 ＋ 字）を出す。今の タブと カードは なくす。「クリックして あそぼう！」ボタンは 今のまま。
- ボタンを押す → 本が 画面のまんなかに あらわれ（とじた表紙）→ ゆっくり 表紙がひらいて ① もくじ。**毎回 もくじから**（オーナーの流れどおり）。
- とじる（✕）を押す → 本が とじて 消え、案内画面にもどる。そのあと「あそぼう」で 遊びにもどる。
- 本が出ている間、本の外（うすい黒の所）をクリックしても 遊びは始まらない（まちがって とじない・遊び始めない）。とじるのは ✕ か Esc だけ。

### 2.3 ボタンと キー
本の外がわに、いつも同じ場所の ボタンを置く（字が読めなくても 形で分かる 記号）。

| ボタン | 場所 | はたらき | キー |
|---|---|---|---|
| もどる（⬅ の矢印） | 本の左上の外 | 1 つ前の ページへ（③→②→①）。① では出さない | Esc か Backspace（① で Esc は とじる） |
| もくじ（しおりの絵） | もどるの右 | ① もくじへ。① では出さない | なし |
| とじる（✕） | 本の右上の外 | 本をとじる | ① で Esc |
| ◀ ▶ | 本の左右の外（③ と 13 こ以上の ② だけ） | ③: 同じ章の となりの項目へ。② : 一覧の つづきへ | ← → |

- リンク（章・項目）は クリックで ひらく。キーでの 選び方は 作らない（マウスで押すのが 6 歳に分かりやすい。必要になったら 別の issue）。
- **キーは 本が出ているときだけ** はたらく。遊んでいる間（ロック中）の ← → Esc Backspace は 今のまま（歩くなど）で、本は 何も変わらない。
- キーの押しっぱなし（くり返し）では 動かない。押しなおすと 動く。
- マウスのホイールは 使わない（MacBook のトラックパッドは 慣性で 何回も 動くため）。

### 2.4 動きの途中
- あらわれる・ひらく・めくる・とじる の 動きの間は、リンクと ◀ ▶・もどる・もくじ を 受けつけない（押しても 何も起きない。字のかさね（§3.5）も 動きの間は 出ていない）。
- **とじる（✕・Esc）だけは 動きの途中でも 効く**（すぐ とじる動きへ）。
- 動きの長さは オーナーが試作で決める。動きは 1/60 秒の 固定ステップで 数える（ゲームの世界の時間が止まっていても 進む）。テストは コマ送りで 途中を作れる（§4.4 `bookAnimLeft`）。

### 2.5 はしで押したとき（失敗のかえし）
- ③ の 章の 最初の項目で ◀（←）、最後の項目で ▶（→）を押すと、本が 小さく 1 回ゆれて やわらかい音。項目は変わらない。ぐるっと 最初にもどることは しない。
- 最初・最後の ◀ ／ ▶ は うすくして「もう ない」と分かる（うすさ ＋ 形。色だけにしない）。

### 2.6 あとから足す（新しいわざ など）
- 1 項目 ＝ データ 1 つ: 「id・章・見出し・説明（1〜2 文）・挿絵の指定」。章も データ 1 つ（id・名前・絵）。
- 項目を足すときは、**このデータを ならびの好きな所に 1 つ足すだけ**。もくじ・章の一覧（12 こをこえたら 2 見開き目）・◀ ▶ の となり・点の数・テストの窓口（§4.4）は 全部 ならびから決まる。
- そのため **データと「本の中の行き来」の計算は、画面（DOM・3D）と分けて**、データを渡すだけで テストできる形にする（AC4）。
- 例（パリィ。文は WEAPON-5 の仕様で決める）:
  | id | 章 | 見出し | 説明 | 挿絵 |
  |---|---|---|---|---|
  | `fight-parry` | たたかう | パリィ | （例）てきの こうげきに あわせて ○○ で はじく | 妖怪の こうげきを かたなで はじき、ほしが とぶ |
- 3 段攻撃 #69（`fight-combo`）・チャージ #70（`fight-charge`）も同じ。3 つ足すと たたかう は 13 こ → 一覧が 2 見開きになる（それで よい）。その わざの仕様書に「本に足す項目」の行を書く。
- 「挿絵の指定」の中身は 挿絵の作り方の案（§3.4）で 形がちがう（案 A ＝ 場面の置き方、案 B ＝ 絵の式、案 C ＝ 絵のファイル 1 まい）。オーナーが 案を選んだら、この例の表と §4.3 の「挿絵」の欄を その形で 書き直す（v3）。

## 3. 画面・見た目

- 説明は **1〜2 文**（「。」で区切る）・**50 文字まで**（空白・ふりがなを数えない）。いちばん長いのは 41 文字（`grow-seeds`）。

### 3.2 色・形（くわしい色・ドット・形は アートの 3 案 → 選んだあと `docs/art/DESIGN.md`）
分かればよいこと:
- **本だと分かる**: 表紙・紙・とじ目・ページの あつみ が 3D で見える。
- **今どこか**: ① ② ③ で 紙の上の 作りが はっきり ちがう（① 大きな章の絵が 5 つ、② 小さな絵の 一覧、③ 大きな絵 1 つ）。② ③ では 左上に 章の絵と名前。

| できごと | 動き | 音（名前は `bookSounds` の記録） |

| 章・項目を ひらく／◀ ▶／もどる／もくじ | ページが めくれる（もどるは 逆むき） | 短い 紙の音。毎回 すこし ちがう（高さや 2〜3 種から。fun.md 1）（`turn`） |

### 3.5 字の出し方（3D の紙に ruby() の字をのせる）— 候補と推し
ページの字には ふりがな（`ruby()`）が要り、テストは 字と リンクを 読める必要がある。

| 候補 | やり方 | よい所 | 気になる所 |
|---|---|---|---|
| **1. 止まっている間は HTML を 紙に かさねる（推し）** | 本が 正面を向いて止まったら、紙の 位置・大きさに ぴったり合わせて 今の UI と同じ HTML を 上にかさねる。動きの間は HTML を消し、紙には 絵（③ の挿絵・① ② の 札の絵）だけを出す | ruby() も 今の UI 部品・UI 検査も そのまま。字が くっきり。クリックは ふつうの ボタン。テストは DOM で読める | 動きの間は 字が見えない（めくりは 短いので 気にならない見込み。試作で オーナーが見る）。紙と HTML の 位置合わせが いる |
| 2. HTML を 絵にして 紙にはる | HTML を 画像にして（SVG の中に HTML を入れる方法など）3D の紙の 模様にする。クリックは 3D の当たり判定で 札を見つける | めくりの間も 字が見える | 画像にする手間と 重さ。字が ななめで ぼやける。字の大きさ・濃さを UI 検査で はかれない。クリックを 自分で作る |
| 3. 紙の 絵の上に 字を 自分で描く | キャンバスに 字と ふりがなを 自分で ならべて描く | 3D の中で 完結 | ruby() を 使えない（ふりがなの ならべ方を 作りなおし）。UI 検査・テストが 読めない |

- **推しは 1**。止まった本は 正面を向く（すこし あつみが 見えるだけ）ので、HTML は 平らな 四角を かさねるだけで 合う。めくりの間に 字が消えるのは、紙の絵（札の形・挿絵）が 見えていれば 迷わない。
- 1 にしたときの きまり: かさねた HTML の 四角と、3D の紙が 画面に うつる 四角の ずれは 2px 以内（AC17）。画面の大きさが 変わったら 合わせなおす。

## 5. 例外のとき
- **はし**: §2.5。項目は変わらず、ゆれと音だけ。`bookBumps` が 1 ふえる。
- **動きの途中**: リンク・◀▶・もどる・もくじ は 受けつけない。✕・Esc（①）は 効く。
- **キーの くり返し**: 動かない。
- **遊んでいる間（ロック中）**: 本の キーは 何もしない（← → は 今のまま 遊びの 入力）。
- **音・かげの設定の つまみに キーの的（フォーカス）があるとき**: ← → は つまみへ（本は 動かない）。
- **じゅんびちゅう（起動中）**: 「あそびかたの ほん」ボタンは 押せる。本は 読める。「あそぼう」だけ 今と同じく 押せない。
- **画面の大きさが 変わった**: 本の大きさ・HTML の かさねを すぐ 合わせなおす。
- **もちもの画面・おめでとう画面**: 本は出ない（今の案内画面と同じ）。本が出ている間に おめでとう が来たら、本を とじてから 出す（今の案内画面と同じ じゅん）。
- **項目が 0 この章・id が かさなる**: 作らない（ユニットテストで見る）。
- **動きを減らす設定**: 動きは 0 コマ。音・ページの変わり方は 同じ。
