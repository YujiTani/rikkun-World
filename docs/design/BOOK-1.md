# BOOK-1: ルールブックを本の形にする（仕様書）

issue #42 / タスク票 `docs/tickets/BOOK-1.md` / 指摘台帳 `docs/loop-ledger/BOOK-1.md`

## 1. ねらい（りっくんがどう楽しむか）

- いまの案内画面（Esc で出る「あそびかた」）は、1 つのタブに カードが 4〜11 まい ならび、6 歳は読み飛ばす（#42）。そだてる は 3 だんで スクロールまである。
- これを **1 さつの本** にする。1 ページに **挿絵（さしえ）1 つ ＋ 説明 1〜2 文** だけ。りっくんは ▶ を押して 1 ページずつ めくり、「つぎは なにかな」と 絵本のように読める。
- 字が読めなくても、挿絵に「押すキー・マウスのボタン」と「そうすると どうなるか」が 描いてあるので分かる（CRITERIA #12）。
- パパと いっしょに「12 ページを みて」と話せるよう、ページ番号がある。
- 新しいわざ（パリィ #199・3 段攻撃 #69・チャージ #70 など）は **ページのデータを 1 つ足すだけ** で本にのる。本が「ゲームといっしょに あつくなっていく」のも りっくんの楽しみにする。

## 2. 遊び方（プレイヤーから見た動き）

### 2.1 開く・閉じる（今と同じ）
- 本は **今の案内画面と同じとき** に出る: ゲームのはじめ、Esc を押したとき（マウスのロックが外れたとき）。新しいキーは足さない。
- 本の下の「クリックして あそぼう！」ボタンを押すと、今と同じく 遊びにもどる（本は閉じる）。
- 本の **外**（うすい黒の所）をクリックしても、今と同じく 遊びにもどる。
- 本の **中**（紙・しおり・◀ ▶）をクリックしても、遊びは始まらない（今のタブと同じ）。

### 2.2 めくる
| やり方 | つぎのページ | まえのページ |
|---|---|---|
| キー | → か D | ← か A |
| マウス | ▶ ボタン（本の右の外がわ） | ◀ ボタン（本の左の外がわ） |
| ページをクリック | 紙の **右半分** | 紙の **左半分** |

- 1 回押すと 1 ページ。キーを押しっぱなしにしても、くり返してはめくれない（押しなおすと めくれる）。
- めくりの動き（案ごとにちがう。§3.4）の途中で もう 1 回押したら、今の動きをすぐ終えて 次のページへ。**押した回数 ＝ めくれた枚数**。
- ページの番号は押した瞬間に変わる（動きは見た目だけ）。
- 本は 1 本の道: うごく の さいごの次は ほる・おく の 1 ページ目。章をまたいでも ▶ だけで 最後まで読める。
- 最初のページで ◀、最後のページで ▶ を押すと、本が小さく 1 回ゆれて やわらかい音（§3.3）。ページは変わらない。最初と最後をつなげて ぐるっと回ることはしない（どこが おわりか分かるように）。
- マウスのホイールでは めくらない（MacBook のトラックパッドは 慣性で何枚も飛ぶため）。

### 2.3 目次（しおり）
- 本の上のふちに、**章の しおり** を 5 つならべる（今のタブと同じ ならび・名前・絵）: 🏃うごく ／ ⛏ほる・おく ／ ⚔たたかう ／ 🔨つくる・やく ／ 🌱そだてる。
- しおりを押すと その章の 1 ページ目へ とぶ。今 読んでいるページの章の しおりが 選ばれた見た目（今のタブの黄色と同じ考え）。▶ で章をまたぐと しおりの選ばれ方も かわる。
- 別に「もくじのページ」は作らない（しおりが いつも見えているので、それが目次）。

### 2.4 ページ番号
- 紙の下に 2 つ出す:
  - **章の中の何まい目か** を 点で: ●●●○○（大きめ。数字が読めなくても のこりが分かる）。
  - **本全体のページ番号** を 数字で: 「12 / 40」（小さめ。パパと話す用）。数字の右の数は ページの数から出す（決め打ちしない）。

### 2.5 最後に読んだページを覚える
- 本を閉じて また開くと、**さいごに見ていたページ** から（今のタブを覚えるのと同じ。そのあそびの間だけ）。
- 読みこみなおし（リロード）・はじめて開いたときは 1 ページ目（うごく の 1 まい目）。
- セーブには入れない。

### 2.6 あとから足す（新しいわざ など）
- 1 ページ ＝ データ 1 つ: 「ページの名前（id）・章・説明（1〜2 文）・挿絵の指定」。
- ページを足すときは、**このデータを ならびの好きな所に 1 つ足すだけ**。ページ番号・点・しおりの とび先・最後のページ・テストの窓口（§4.4）は 全部 ならびから自動で決まる。ほかのコードは変えない。
- 例（WEAPON-5 パリィが入るとき。文は WEAPON-5 の仕様で決める）:
  | id | 章 | 説明 | 挿絵 |
  |---|---|---|---|
  | `fight-parry` | たたかう | （例）てきの こうげきに あわせて ○○ で はじく | 妖怪の こうげきを かたなで はじき、ほしが とぶ |
- 3 段攻撃 #69（`fight-combo`）・チャージ #70（`fight-charge`）も同じ。その わざの仕様書に「本に足すページ」の行を書く。
- 章を足すとき（6 つ目の章）も、章のデータを 1 つ足すだけ。しおりは 6 つまで 1024 はばに入れる（§3.6）。

## 3. 画面・見た目

### 3.1 文字
- 説明はひらがな・カタカナ。漢字は `ruby()` で必ずふりがな。今の文をできるだけそのまま使う（§4.3。オーナーが見てきた言い方）。
- 1 ページの説明は **1〜2 文**（「。」で区切る）。**50 文字まで**（空白・ふりがなを数えない）。いちばん長いのは 41 文字（`grow-seeds`）。
- しおりの名前は今のまま（いちばん長いのは「つくる・やく」6 文字）。

### 3.2 色・形（くわしい色・ドットは アートの 3 案 → `docs/art/DESIGN.md`）
分かればよいこと:
- **本だと分かる**: 表紙（まわりのふち）・紙・とじ目。
- **今どこか**: 選ばれた しおり、点の ●、ページ番号。
- **押せる所**: ◀ ▶ と しおりは 押せそうに見える（ふくらみ・かげ）。最初・最後のページの ◀／▶ は うすくして「もう ない」と分かる（色だけでなく うすさ・形で。CRITERIA #13）。
- **挿絵が主役**: 目を細めて見て、最初に目が行くのは挿絵（#3）。紙は無地に近く、細かさは挿絵に集める（#4）。
- 字は紙の上で読みやすい濃さ（明るさの比 4.5:1 以上。#14）。

### 3.3 音（くわしくは `docs/audio/SOUND.md` に まかせる）・盛り上げ（`docs/fun.md`）
ページをめくるのは **くり返す行動**。演出は ひかえめ、大きさは続けても変えない。紙ふぶき・ファンファーレは出さない（読んだだけで達成ではない）。

| できごと | 動き | 音 |
|---|---|---|
| 本が出る | 案ごとの ひらく動き（短く）。動きを減らす設定では なし | なし（今と同じ） |
| ページをめくる | 案ごとの めくりの動き | 短い紙の音。毎回すこしちがう（高さや 2〜3 種から。fun.md 1） |
| しおりで章へとぶ | めくりと同じ動き | 今のタブの「ポン」 |
| 最初・最後で さらに押した（失敗） | 本が左右に小さく 1 回ゆれる | やわらかく はずむ音（ブーという音にしない。fun.md 4） |
| あそびにもどる | 今と同じ | 今と同じ |

- 強い点滅なし。「うごきを へらす」設定・端末の「動きを減らす」では、めくり・ゆれの動きを止め、すぐ入れかえる（音は鳴る）。

### 3.5 ページの中の作り（3 案共通）
- 1 ページに 見えるのは **挿絵 1 つ ＋ 説明 1 つ だけ**。となりのページの中身は 見せない（見開きの形にする案でも、左右で 1 ページ分 ＝ 左が絵・右が字）。
- 上から: 挿絵（紙の中の面積の 4 割以上）→ 説明 → 点とページ番号。
- 説明の字は 挿絵の上に のせない（読みにくくなるため）。

### 3.6 画面の配置
すべて 本＋あそぼうボタン の かたまりを 画面のまんなかに置く。左下の「おと・かげ」、右下の「おとなの ひと」は 今の場所のまま。

| 部品 | 置き方 |
|---|---|
| しおり | 本の上のふち。高さ 64px 以上・字 24px 以上（今の `GUIDE_TAB_STYLE` と同じ） |
| 本 | まんなか。たて：よこ ＝ およそ 3：4。大きさは 画面に合わせて かわるが、**どのページでも同じ大きさ**（ページで あそぼうボタンが動かない） |
| ◀ ▶ | 本の左右の外がわ、本の高さのまんなか。64×64px 以上 |
| あそぼうボタン | 本の下。今と同じ大きさ（はば max(40vw, 512px)・高さ 96px 以上） |

大きさの計算（たての予算 ＝ 上の余白 16 ＋ しおり 64 ＋ すきま 8 ＋ 本 ＋ すきま 16 ＋ ボタン 96 ＋ 下の余白 16 ＝ 216 ＋ 本の高さ。よこの予算 ＝ 本のはば ＋ ◀▶ と すきま (64＋16)×2 ＋ 左右の余白 16×2 ＝ 本のはば ＋ 192）:

| 画面 | 本の高さの上限 | 本の目安（高さ×はば） | よこの合計 |
|---|---|---|---|
| 1024×700 | 700−216 ＝ 484 | 480×640 | 640＋192 ＝ 832 ≦ 1024 |
| 1280×800 | 800−216 ＝ 584 | 560×747 | 747＋192 ＝ 939 ≦ 1280 |
| 1440×900 | 900−216 ＝ 684 | 640×853 | 853＋192 ＝ 1045 ≦ 1440 |

1024×700 の 本の中（ふち 24 をのぞいて 592×432）: 点と番号 40 ＋ 説明 3 行（字 26px・ルビこみの行の高さ 約 49 → 148）＋ すきま 12×2 ＝ 212 → 挿絵 220×592（面積 51%。4 割以上 ○）。

いちばん多いとき:
- **いちばん長い説明**（`grow-seeds` 41 文字・空白こみ 約 55 字）: 1024×700 で 592 はばに 26px → 1 行 約 22 字 → 3 行に入る。説明の所に スクロールを出さない。
- **章がいちばん長い**（今は そだてる 12 ページ）: 点は 15 こまで 1 行。16 こ以上の章になったら 点をやめて「3 / 16」の数字だけにする。
- **ページがふえた**: ページ番号は 3 けた（「100 / 120」）まで はみださない。
- **章が 6 つ**: しおり 6 つが 1024 はばで 1 行に入る（今の しおりの さいしょうはば 約 152px × 6 ＋ すきま 12×5 ＝ 972 ≦ 1024−32）。7 つ目からは 2 行にせず、デザインに相談（そのときに決める）。

## 4. ルール・数値

### 4.1 数値
| 項目 | 値 |
|---|---|
| 1 ページの説明 | 1〜2 文・50 文字まで（空白・ふりがなは数えない） |
| 1 回の押す・クリックで めくれる枚数 | 1 |
| キーの押しっぱなし（くり返し） | めくらない |
| ◀ ▶ の大きさ | 64×64px 以上（1280×800） |

| 最初・最後で押したときの ゆれ | 1 回（めくれない） |

### 4.4 テストの窓口（`window.__rikkun`）
今の `lock.get()` と `lock.tab(name)` を そのまま使い、本の項目を足す（名前は この表のとおり。中の作り方は開発が決める）。

`lock.get()` に足す・意味が変わる項目:
| 項目 | 中身 |
|---|---|
| `bookPageIds` | 全ページの id（本のならび） |
| `bookPageId` | いま見ているページの id |
| `bookPage` | いま見ているページの番号（1 から） ＝ `bookPageIds` の中の位置 ＋ 1 |
| `bookPageCount` | ページの数 |
| `bookChapters` | 章のならび。1 つずつ `{ id, label, firstPage, pageCount }`（firstPage は 1 から） |
| `bookCaption` | いま見ているページの説明（ふりがなをのぞいた字） |
| `bookBumps` | 最初・最後で さらに押して ゆれた回数（ひらいてから の合計） |
| `bookSounds` | 本が鳴らした音の名前の記録（`turn`・`chapter`・`bump`） |
| `guideTab` | いま見ているページの章の id（今と同じ名前。意味は「今の章」） |
| `guideTabs` / `guideTabIds` | しおりの名前・id（今と同じ） |
| `guideItems` | いま見ている章の ページ数（今の「タブの項目数」と同じ意味。たたかう・そだてる は ページを分けたぶん ふえる） |

操作:
| 操作 | 中身 |
|---|---|
| `lock.tab(chapterId)` | その章の 1 ページ目へ（今と同じ名前。しおりを押したのと同じ） |
| `lock.page(pageId)` | そのページへ とぶ（テストの準備用。動きなし・音なし） |

画面: 見えているページの要素に `data-page-id`（ページの id）を付ける。見えていないページは DOM にあっても `hidden`（テストが「見えている 1 まい」を見分けられること）。

## 5. 例外のとき
- **最初・最後**: §2.2。ページは変わらず、ゆれと音だけ。`bookBumps` が 1 ふえる。
- **押しっぱなし**: くり返しの キー入力では めくらない。
- **めくりの途中で押す**: すぐ次へ（押した回数 ＝ 枚数）。
- **音・かげの設定を さわっている間**: 音の大きさのつまみ などに キーの的（フォーカス）があるときは、← → は そのつまみへ（本はめくらない）。A・D も同じ。
- **じゅんびちゅう（起動中）**: 本は読める・めくれる。あそぼうボタンだけ 今と同じく押せない。
- **おとなの ひと** の箱・音・かげ の設定: 本の外。今の場所・はたらきのまま。
- **ページのデータが 0 まいの章**: 作らない（ユニットテストで見る）。
- **id が同じページ が 2 つ**: 作らない（ユニットテストで見る）。
- **もちもの画面・おめでとう画面が出ているとき**: 本は出ない（今の案内画面と同じ）。
- **動きを減らす設定**: めくり・ひらく・ゆれ の動きなし。音・ページの変わり方は同じ。
