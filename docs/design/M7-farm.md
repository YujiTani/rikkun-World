## 1. ねらい（りっくんがどう楽しむか）

- 「つちを たがやして、たねを まいて、そだつのを まつ」が、字を読まなくても 絵と動きで分かる。
- まいた たねが **4 回 すがたを かえて**（め → は → みが すこし → みのった）大きくなるのが見える。もどってきたら「おおきく なってる！」。
- みのった やさいは 色で分かる（たまねぎ=しろ・トマト=あか・かぼちゃ=オレンジ・なす=むらさき）。**ひだりクリック 1 回で しゅうかく**。やさいと たねが ぽんっと とびだす。
- **みずの そば** の はたけは こい色になって、**はやく そだつ**。「かわの となりに はたけを つくろう！」（M5 の ひらち が ちょうど そういう場所）。
- やさいを たべると ハートが もどる（「そだてて たべられる」— 計画書 M7 の確認方法）。
- しゅうかくすると たねが もどるので、はたけは どんどん ひろげられる。
- **たね は 配らない**（オーナー決定）。世界の あちこちに ある「たね の ありか」を **見つける** のが ぼうけん になる: スタートから 見える **ふるい はたけ の あと**（かかし が目じるし）、野原（のはら）に はえている **やせいの やさい**、くさ を こわすと ときどき、妖怪（ようかい）の まれな おとしもの。見つけるたびに 実績。

## 2. 遊び方（プレイヤーから見た動き）

### 2.1 はじめ — たね を 見つける（§4.5）
- はじめは たね を 持っていない（配らない）。
- スタートで 北を向くと、右前の方に **かかし** が見える。そこが **ふるい はたけ の あと**: かわいた はたけ 12 マス・こわれた さく・**たんす**（中に たね が少し）。たんす を あけて たね を とると、すぐ まける。
- 野原・もり の ふち・かわ ぞい には **やせいの やさい**（みのった すがた。少し光る）が はえている。ひだりクリックで とると やさい 1 こ と たね が入る。
- **くさ ブロック を こわすと** ときどき（1/8）たね が出る。場所で 出やすい たね が ちがう。
- **からかさ・ろくろくび** を たおすと、まれに たね を おとす。
- しゅうかく でも たね が 1〜2 こ もどる。

### 2.2 たがやす（くさ・つち → はたけ）
- **くわ** を持って、くさ か つち のブロックを ねらって **右クリック 1 回** → **はたけ** になる（ザクッ という音・つちの つぶ が とぶ・うでを ふる）。
- **すで**（えらんでいるマスが からっぽ）でも たがやせる。ただし **右クリック 3 回**（同じブロックに。1 回ごとに つちの つぶ と 小さな ザクッ。3 回目で はたけ）。
- 右クリックを おしつづけると、置く と同じ間（30 ステップ）ごとに 1 回と数える（くわ なら ねらいを動かすと つぎつぎ たがやせる）。
- たがやせるのは **上のマスが くうき** の くさ・つち だけ。

### 2.3 たねを まく
- **たね** を持って、**はたけ** を ねらって右クリック → はたけ の **上のマス** に その やさいの **め（0 だんかい）** が出る。たねが 1 こ へる（ポコッ という音）。
- おしつづけると 30 ステップごとに、ねらっている はたけ に まく（ならべて まける）。
- たねを持って くさ・つち を ねらって右クリックしたら、何も変わらず **合図**（§3.3）で「くわ で たがやそう」を 絵で見せる。

### 2.4 そだつ
- 時間がたつと、**ときどき 1 だん** そだつ（マイクラ風。0 → 1 → 2 → 3 だんかい＝みのった）。段階ごとに 絵が大きくなる（§3.2）。同じ日に まいても、早い作物・おそい作物 が ある（だいたいの時間は §4.4 の表。ゲームの「にち」で書く）。
- **明るい所（明るさ 9 以上）でだけ そだつ**。外なら ひる（と 明るい あさ・ゆうがた）。よる は 止まる。**たいまつ の近く** なら よる も そだつ（家の中・あなの中でも たいまつ で そだてられる）。
- **しめった はたけ**（みずの そば。§4.3）では はやく そだつ（だいたい 1.5 倍）。かわいた はたけ でも そだつ。
- もちもの画面のあいだは ゲームと同じく 1/4 の速さ。案内画面・おめでとう画面・やられた画面・ページを閉じているあいだは そだたない。
- 作物を ねらうと、画面の「ほる名前」（M2）の横に **4 つの まる** が出て、今の段階まで みどりに なる（みのったら 4 つとも 金色）。しめった はたけ の上なら **しずくの絵** も出る（字が読めなくても「あと どれくらい」「みずが ある」が分かる）。

### 2.5 しゅうかく
- **みのった（3 だんかい）作物** を ねらって **ひだりクリック** → その場で しゅうかく（ほる時間・ひび は無い。押した瞬間）。
  - **持っているもの**: **ゆみ 以外は なんでも**（すで・つるはし・くわ・かたな類・たね・やさい・ブロック）しゅうかく できる。**ゆみ** を持っているときは 今までどおり や を とばし、しゅうかく しない。
  - **ねらい**: 作物は 固くないが、ねらいの線は **作物のマス（1×1×1 の箱）に 当たる**（うしろの はたけ・ブロック ではなく 作物を ねらう）。作物より 手前に 妖怪がいれば 今までどおり 妖怪を たたく。
  - やさい と たね が持ち物に入る（数は §4.4）。見た目は、やさいの絵が 作物の所から ぽんっと 上に とびだして、0.4 秒で プレイヤーへ 吸いこまれる。音は「ポン！」＋ 小さなチャイム。
  - 作物は消え、**はたけ は のこる**（すぐ また まける）。
  - おしつづけて ねらいを べつの みのった作物 へ動かすと、つぎつぎ しゅうかく できる。
- **まだ みのっていない作物** を ひだりクリック → **こわれない**。作物が ぷるっと ゆれて（0.3 秒）、「ぷるん」という やさしい音（まだだよ）。ほった量・ひびは 出ない。
- 作物は 固くない（通りぬけられる。上に立てない）。
- **やせいの やさい**（§4.5）も 同じく ひだりクリックで とれる（いつでも みのっている）。やさい 1 こ と たね 1〜2 こ。とると 消えて、もとの くさ の上は くうき に もどる（もう はえない）。

### 2.6 たべる（PO 提案。§8-4）
- **やさい** を持って **右クリック** → 1 こ たべて **ハートが もどる**（§4.4）。「もぐもぐ」の音＋やさいの色の つぶ。
- **押した瞬間だけ** たべる（押しつづけても 1 こ。もう 1 こ たべるには はなして 押しなおす）。待ち時間（クールダウン）は 無い。
- ハートが まんたん のときは たべない（へらない）。合図で ハートの絵（§3.3）。

### 2.7 右クリックの ふりわけ（上から順に。当てはまったら そこで おわり）

| 順 | 条件 | すること |
|---|---|---|
| 1 | たんす を ねらっている | ひらく（M6） |
| 2 | かまど を ねらっている | やく画面（M4） |
| 3 | 防具を持っている | きる（M4） |
| 4 | くわ か すで で、上が くうき の くさ・つち を ねらっている | たがやす（§2.2） |
| 5 | たね を持って、上が くうき の はたけ を ねらっている | まく（§2.3） |
| 6 | たね を持って、くさ・つち を ねらっている | 合図（くわ で たがやそう） |
| 7 | やさい を持っている（ねらいは どこでもよい・何もなくてもよい） | たべる（§2.6） |
| 8 | 置けるもの を持っている | 置く（M2。はたけ の上にも置ける） |

- 1〜3・6・7 は押した瞬間だけ。4・5・8 は押した瞬間と 30 ステップごと（M2 の置く と同じ）。
- 作物を ねらって右クリック: 上のどれにも当たらなければ 何もしない（撫でる は フェーズ 2）。
- **オーナーの順「たんす → かまど → 防具 → 耕す/植える → 置く」のまま**。たべる は 置けない やさい だけなので 置く とぶつからない。

### 4.4 そだつ・しゅうかく・たね・たべる

**そだつ時間**（オーナー決定。ゲームの「にち」で書く。マイクラ風）

- **1 にち** = ゲームの 1 日（あさ〜ひる〜ゆうがた〜よる の 1 周）の ステップ数 = `dayTicks + duskTicks + nightTicks + dawnTicks`（今 **91,800**。実時間 25.5 分）。
- **明るい ステップ** だけ 数える: 作物のマスの 明るさ（M4 の `LightField.level`。時刻をふくむ）が **9 以上** の ステップ。9 未満の ステップは 何も 進まない。
- 表の時間 T = 0 だんかい → 3 だんかい に かかる **明るい ステップ の 平均**:

| やさい | かわいた はたけ | しめった はたけ | T（かわいた / しめった、ステップ） |
|---|---|---|---|
| トマト | **0.75 にち** | **0.5 にち** | 68,850 / 45,900 |
| たまねぎ・なす | **1.25 にち** | **0.85 にち** | 114,750 / 78,030 |
| かぼちゃ | **2 にち** | **1.3 にち** | 183,600 / 119,340 |

- 目安: 外の はたけ は よる に止まるので、カレンダーの日数は 表より 長い（外の 明るい時間は 1 にち の 6 わり くらい）。しめった トマト は あさ に まけば その ひる の うちに とれる ことが多い。たいまつ で 1 日じゅう 明るくすれば 表の とおり。
- **ときどき 1 だん**（シード付きの乱数）: 明るい ステップ ごとに、作物 1 つにつき 確率 `p = 3 × (1 − e^−3) ÷ T`（約 2.85 ÷ T）で 1 だん 進む。
- **待ちすぎない きまり**（6 歳が こまらないように。マイクラには無い）: 同じ だん に いる 明るい ステップ が `3 ÷ p`（約 1.05 T）に なったら、その ステップで 必ず 1 だん 進む。→ 1 つの作物が 0 → 3 に かかるのは いちばん長くて 約 3.2 T。p の式は この きまり を入れて 平均が T に なるように してある（1 だん の 平均 = (1 − e^−3) ÷ p = T ÷ 3）。
- だんが 進むと「同じだんに いる ステップ」は 0 から 数えなおす。しめり は その ステップの しめり で p を決める（とちゅうで 変わってよい）。
- 乱数は 農業 専用の シード付き乱数（世界のシードから作る）。同じ シード・同じ 操作 なら 同じ結果。
- 設定: `farmGrowDays`（`{dry:{onion:1.25, tomato:0.75, pumpkin:2, eggplant:1.25}, wet:{onion:0.85, tomato:0.5, pumpkin:1.3, eggplant:0.85}}`）・`farmMinLight`（9）・`farmMaxWaitFactor`（3。「待ちすぎない」の 3）。

## 5. 例外のとき

- **持ち物が いっぱい（しゅうかく・やせいの やさい・たね が出た）**: しゅうかく は する。入らない分は その場に 落とし物（光の柱・10 分で消える・拾える。M6 の すてる と同じ）。
- **はたけ を こわした（上に 作物）**: はたけ は つち 1 こ。作物も いっしょに なくなり、みのっていれば しゅうかく と同じもの（やさい・たね。記録も しゅうかく 1）、みのっていなければ **たね 1 こ** が もどる（まいた たね を なくさない）。
- **作物の上のマス**: 作物のマスには ブロックを置けない（くうき・みず ではないため。M2 のまま）。
- **はたけ の上に ブロックを置いた**: はたけ のまま（つち に もどさない）。その ブロックを こわせば また まける。
- **たね を持って 作物 を ねらった**: 何もしない（合図も出さない）。
- **くわ・すで で はたけ を ねらった**: 何もしない。
- **上が くうき でない くさ・つち**（たいまつ・ブロックが のっている・みず の下）: たがやせない。何も出ない。
- **やられたとき**: たね・やさい・くわ も ほかの持ち物と同じ（M3 §2.8 の 50%）。はたけ・作物 は そのまま。
- **はなれている作物**: 世界は ぜんぶ 読みこまれているので、とおくでも そだつ。
- **ページを閉じていた時間**: そだたない（保存した そだち具合から 続く）。
- **くさ を こわして たね**: 置いた くさ を こわしても 出る（くさ は こわすと 1〜4 こ 入るので、置いて こわす を くり返しても 1 回 1/8 だけ）。
- **ねらい が とどかない**: M2 の ねらう距離（5）のまま。
- **やせいの やさい の 下の くさ を こわした**: やせいの やさい も いっしょに とれる（とった と同じもの・記録も同じ）。
- **かかし**: こわれない（ひびも出ない。M2 の `unbreakable`）。下の地面を こわすと 空中に のこる（こわれない たいまつ と同じ あつかい）。
- **ふるい はたけ の たんす**: ふつうの たんす と同じ（こわせる・こわすと 中身は まわりに 落とし物）。`seedFrom:oldfarm` は その たんす から たね を 持ち物に うつしたとき（こわして 落とし物を 拾ったときも）1 回目 だけ 数える。
- **くらい所の 作物**: 明るさ 8 以下 では 何日 たっても そだたない（こわれない・かれない）。HUD の まる は そのまま。
- **妖怪の おとしもの の たね**: 今の おとしもの と同じ（光の柱・拾える）。

## 8. デザイナーが決めたこと（オーナー確認①で見せる要点）

1. **ながれ**: くわ（か すで）で くさ・つち に右クリック → はたけ。たね を持って はたけ に右クリック → め。待つと 4 だんかい。**みのったら ひだりクリック 1 回で しゅうかく**、はたけ は のこる。みのる前は ひだりクリックしても こわれない（ぷるっと ゆれるだけ。まちがえて 消さない）。
2. **くわ は ある（き 2・いし 1）**。すで でも たがやせるが **3 回** 要る（くわ は 1 回）。**オーナー案（すで でも同じ）から変えた理由**: くわ を 作る 目当て を作るため。すで でも できるので 作らなくても 遊べる。
3. **右クリックの順**: たんす → かまど → 防具 → たがやす／まく → たべる → 置く（オーナー案に「たべる」を 置く の前に入れただけ）。
