## 1. ねらい（りっくんがどう楽しむか）

- 「つちを たがやして、たねを まいて、そだつのを まつ」が、字を読まなくても 絵と動きで分かる。
- まいた たねが **4 回 すがたを かえて**（め → は → みが すこし → みのった）大きくなるのが見える。もどってきたら「おおきく なってる！」。
- みのった やさいは 色で分かる（たまねぎ=しろ・トマト=あか・かぼちゃ=オレンジ・なす=むらさき）。**ひだりクリック 1 回で しゅうかく**。やさいと たねが ぽんっと とびだす。
- **みずの そば** の はたけは こい色になって、**はやく そだつ**。「かわの となりに はたけを つくろう！」（M5 の ひらち が ちょうど そういう場所）。
- やさいを たべると ハートが もどる（「そだてて たべられる」— 計画書 M7 の確認方法）。
- しゅうかくすると たねが もどるので、はたけは どんどん ひろげられる。

## 2. 遊び方（プレイヤーから見た動き）

### 2.1 はじめ
- M7 の版で はじめて遊ぶとき（新しい世界でも、前の保存の続きでも）、持ち物に **4 しゅるいの たね を 3 こずつ** 入る（1 回だけ）。拾ったときのログ（M4 §2.12）に 4 行出る。
- たねは ほかにも、**くさ ブロック を こわすと** ときどき（§4.4）1 こ 出る。しゅうかくでも 1〜2 こ もどる。

### 2.2 たがやす（くさ・つち → はたけ）
- **くわ** を持って、くさ か つち のブロックを ねらって **右クリック 1 回** → **はたけ** になる（ザクッ という音・つちの つぶ が とぶ・うでを ふる）。
- **すで**（えらんでいるマスが からっぽ）でも たがやせる。ただし **右クリック 3 回**（同じブロックに。1 回ごとに つちの つぶ と 小さな ザクッ。3 回目で はたけ）。
- 右クリックを おしつづけると、置く と同じ間（30 ステップ）ごとに 1 回と数える（くわ なら ねらいを動かすと つぎつぎ たがやせる）。
- たがやせるのは **上のマスが くうき** の くさ・つち だけ。

### 2.3 たねを まく
- **たね** を持って、**はたけ** を ねらって右クリック → はたけ の **上のマス** に その やさいの **め（0 だんかい）** が出る。たねが 1 こ へる（ポコッ という音）。
- おしつづけると 30 ステップごとに、ねらっている はたけ に まく（ならべて まける）。
- たねを持って くさ・つち を ねらって右クリックしたら、何も変わらず **合図**（§3.3）で「くわ で たがやそう」を 絵で見せる。

### 2.4 そだつ
- 時間がたつと、自動で 0 → 1 → 2 → 3 だんかい（みのった）と そだつ。段階ごとに 絵が大きくなる（§3.2）。
- **しめった はたけ**（みずの そば。§4.3）では **1.5 倍** はやく そだつ。かわいた はたけ でも（ゆっくり）そだつ。
- ひる も よる も そだつ。もちもの画面のあいだは ゲームと同じく 1/4 の速さ。案内画面・おめでとう画面・やられた画面・ページを閉じているあいだは そだたない。
- 作物を ねらうと、画面の「ほる名前」（M2）の横に **4 つの まる** が出て、今の段階まで みどりに なる（みのったら 4 つとも 金色）。しめった はたけ の上なら **しずくの絵** も出る（字が読めなくても「あと どれくらい」「みずが ある」が分かる）。

### 2.5 しゅうかく
- **みのった（3 だんかい）作物** を ねらって **ひだりクリック** → その場で しゅうかく（ほる時間・ひび は無い。押した瞬間）。
  - やさい と たね が持ち物に入る（数は §4.4）。見た目は、やさいの絵が 作物の所から ぽんっと 上に とびだして、0.4 秒で プレイヤーへ 吸いこまれる。音は「ポン！」＋ 小さなチャイム。
  - 作物は消え、**はたけ は のこる**（すぐ また まける）。
  - おしつづけて ねらいを べつの みのった作物 へ動かすと、つぎつぎ しゅうかく できる。
- **まだ みのっていない作物** を ひだりクリック → **こわれない**。作物が ぷるっと ゆれて（0.3 秒）、「ぷるん」という やさしい音（まだだよ）。ほった量・ひびは 出ない。
- 作物は 固くない（通りぬけられる。上に立てない）。

### 2.6 たべる（PO 提案。§8-4）
- **やさい** を持って **右クリック**（押した瞬間だけ）→ 1 こ たべて **ハートが もどる**（§4.4）。「もぐもぐ」の音＋やさいの色の つぶ。
- ハートが まんたん のときは たべない（へらない）。合図で ハートの絵（§3.3）。

### 2.7 右クリックの ふりわけ（上から順に。当てはまったら そこで おわり）

| 順 | 条件 | すること |
|---|---|---|
| 1 | たんす を ねらっている | ひらく（M6） |
| 2 | かまど を ねらっている | やく画面（M4） |
| 3 | 防具を持っている | きる（M4） |
| 4 | くわ か すで で、上が くうき の くさ・つち を ねらっている | たがやす（§2.2） |
| 5 | たね を持って、上が くうき の はたけ を ねらっている | まく（§2.3） |
| 6 | たね を持って、くさ・つち を ねらっている | 合図（くわ で たがやそう） |
| 7 | やさい を持っている（ねらいは どこでもよい・何もなくてもよい） | たべる（§2.6） |
| 8 | 置けるもの を持っている | 置く（M2。はたけ の上にも置ける） |

- 1〜3・6・7 は押した瞬間だけ。4・5・8 は押した瞬間と 30 ステップごと（M2 の置く と同じ）。
- 作物を ねらって右クリック: 上のどれにも当たらなければ 何もしない（撫でる は フェーズ 2）。
- **オーナーの順「たんす → かまど → 防具 → 耕す/植える → 置く」のまま**。たべる は 置けない やさい だけなので 置く とぶつからない。

### 4.4 そだつ・しゅうかく・たね・たべる

**そだつ時間**（0 だんかい → 3 だんかい まで。どの段階の間も 同じ長さ = 全体の 1/3）

| やさい | かわいた（ステップ） | しめった（ステップ = かわいた ÷ 1.5） | オーナー案の速さ |
|---|---|---|---|

## 5. 例外のとき

- **持ち物が いっぱい（しゅうかく・たね が出た・はじめの おくりもの）**: しゅうかく は する。入らない分は その場に 落とし物（光の柱・10 分で消える・拾える。M6 の すてる と同じ）。
- **はたけ を こわした（上に 作物）**: はたけ は つち 1 こ。作物も いっしょに なくなり、みのっていれば しゅうかく と同じもの（やさい・たね。記録も しゅうかく 1）、みのっていなければ **たね 1 こ** が もどる（まいた たね を なくさない）。
- **作物の上のマス**: 作物のマスには ブロックを置けない（くうき・みず ではないため。M2 のまま）。
- **はたけ の上に ブロックを置いた**: はたけ のまま（つち に もどさない）。その ブロックを こわせば また まける。
- **たね を持って 作物 を ねらった**: 何もしない（合図も出さない）。
- **くわ・すで で はたけ を ねらった**: 何もしない。
- **上が くうき でない くさ・つち**（たいまつ・ブロックが のっている・みず の下）: たがやせない。何も出ない。
- **やられたとき**: たね・やさい・くわ も ほかの持ち物と同じ（M3 §2.8 の 50%）。はたけ・作物 は そのまま。
- **はなれている作物**: 世界は ぜんぶ 読みこまれているので、とおくでも そだつ。
- **ページを閉じていた時間**: そだたない（保存した そだち具合から 続く）。
- **くさ を こわして たね**: 置いた くさ を こわしても 出る（くさ は こわすと 1〜4 こ 入るので、置いて こわす を くり返しても 1 回 1/8 だけ）。
- **ねらい が とどかない**: M2 の ねらう距離（5）のまま。

## 8. デザイナーが決めたこと（オーナー確認①で見せる要点）

1. **ながれ**: くわ（か すで）で くさ・つち に右クリック → はたけ。たね を持って はたけ に右クリック → め。待つと 4 だんかい。**みのったら ひだりクリック 1 回で しゅうかく**、はたけ は のこる。みのる前は ひだりクリックしても こわれない（ぷるっと ゆれるだけ。まちがえて 消さない）。
2. **くわ は ある（き 2・いし 1）**。すで でも たがやせるが **3 回** 要る（くわ は 1 回）。**オーナー案（すで でも同じ）から変えた理由**: くわ を 作る 目当て を作るため。すで でも できるので 作らなくても 遊べる。
3. **右クリックの順**: たんす → かまど → 防具 → たがやす／まく → たべる → 置く（オーナー案に「たべる」を 置く の前に入れただけ）。
4. **たべる を フェーズ 1 に入れる（PO 提案）**: やさい を持って右クリックで ハートが もどる（ハート 1 こ、かぼちゃ 2 こ）。おなか ゲージ は まだ無いので 体力が へっているときだけ。計画書の M7「そだてて たべられる」に合わせ、しゅうかく した やさい に すぐ 使い道が できる。
5. **そだつ時間**: しめった はたけ で トマト 2 分・たまねぎ／なす 3 分 20 秒・かぼちゃ 5 分（かわいた と 1.5 倍 おそい）。乱数なし（いつも同じ時間）。ひる よる 関係なし。
6. **しめる**: みず から 横 4 マス以内（マイクラと同じ）。M5 の ひらち は かわ の となりなので ちょうどいい。かわいた はたけ が つち に もどる・ふみあらす は **無し**（こまらないように）。**みず を引く しかけ は フェーズ 1 で作らない**（ジョウロ は フェーズ 2）。
7. **たね**: はじめに 4 しゅるい × 3 こ を 持ち物に（前の保存の 続きでも 1 回）。くさ を こわすと 1/8 で 出る。しゅうかく で 1〜2 こ もどる。**オーナー案「スタート地点付近」を「持ち物に入れる」にした理由**: 落とし物 だと 10 分で消えて なくす ことがあり、前の保存の 続き では スタートに いないため。
8. **見た目**: はたけ は つち より暗い茶色に よこの すじ、しめると もっと暗く 青っぽく しずくの点。作物は 十字の板で、段階ごとに 高さ 4・7・11・14 ドット。**め の 根もと に 野菜の色の つぶ**（0 だんかい でも どれか分かる）。みのると 夜でも 明るく見える（少し光る）。
9. **ことば**: 「たはた」を **「はたけ」** に（6 歳が 知っている ことば）。
10. **マスの色**: たね は しょくぶつ（みどり）、くわ は どうぐ（あお）、**やさい は 新しい「たべもの」の うめ色**（あとの 料理・くだもの も ここ）。
11. **ねらった作物の しるし**: 名前の横に まる 4 つ（そだった分 みどり、みのったら 金色）＋ しずく。字が読めなくても「あと どれくらい」が分かる。
12. **実績 19 こ を足す**（ぜんぶ 199）。新しい分類 **「そだてる」**（M8 の 動物も ここ）。「はじめて しゅうかく した！」は すぐ おめでとう画面に出る。
13. **案内画面に 5 つ目の タブ「そだてる」**。
