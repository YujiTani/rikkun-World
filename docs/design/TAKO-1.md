# TAKO-1: うみの 妖怪（ようかい）「タコはちまき」と すみ・ふで（仕様書）

決定: `docs/decisions/2026-10-30-tako.md`（オーナー yuzu 2026-10-30）。タスク票: `docs/tickets/TAKO-1.md`。
足し方: `src/content/CLAUDE.md`・`docs/design/YOKAI-REGISTRY.md`・`docs/design/ITEM-REGISTRY.md`。

## 1. ねらい（りっくんが どう 楽しむか）
- はじめての「うみの 中に いる」妖怪。うみに もぐると、はちまきの たこが 足を ぐるぐる まわして びゅーん → ふわふわ。
- 近づくと すみを ぷーっと はいて にげる。おいかけて かたなで たたく「おにごっこ」が 遊び。
- たおすと かならず すみ が 出る。すみ と たけ で ふで が 作れる（ハウジング #339 の せっけいずで 使う）。

## 2. 遊び方（プレイヤーから 見た 動き）
1. うみ（とくに すなはまの 国）に 入ると、水面から 1〜3 ブロック 下を タコはちまき が およいでいる。ひる も よる も いる。
2. およぎ方: 「はやく すすむ（足を ヘリコプターの ように まわす）1.5 秒 → とまって ふわふわ 4 秒」を くり返す。向きは とまっている 間に かえる。
3. りっくんが 近く（§4 の すみ距離）に 来ると、すみを はいて、りっくんから はなれる 向きに はやく すすむ（にげる）。すみは 黒っぽい けむり。ダメージは ない。けむりの 中に 目が あると 画面が 少し 暗く なる だけ。
4. 自分からは おそってこない。たたかれると、足で ぺちん と 1 回 はんげき（ハート 半分）。
5. からかさ と 同じ くらい の 強さ（からかさ と 同じ 回数で たおれる）。たおすと すみ 1〜2 こ（かならず）＋ 経験値・メダル・図鑑（ずかん）・実績・二つ名（ふたつな）は ほかの 妖怪と 同じ。
6. 陸（りく）には 上がらない。水の ない マスへは すすまない。

### 2.1 プレイヤーの 攻撃は 水の 中に とどくか（調べた 結果と 決まり）
- 今の コード: ねらいの 線（`dig/raycast.ts`）は みず を すどおり する。妖怪への 当たり（`PlayerCombat.pickYokai`）も 水で 止まらない。なので **今の まま 水の 中の 妖怪に とどく**。新しい きまりは 足さない。
- 今の プレイヤーは 水の 中で ゆっくり（`waterSpeedMul` 0.5）、ジャンプ ×0.85 で 上へ およげる（`PlayerController` の `inWater`）。もぐるのは 重さで しずむ だけ。これは 変えない。
- とどく 距離: パンチ 3.5・かたな 照準 4.5 ブロック。水面に 立った（うかんだ）りっくんの 目 から、水面の 1〜3 ブロック 下（§4 のおよぐ 深さ）は とどく。もぐれば もっと 近い。
- ゆみ の や は 今の きまりの まま（変えない）。

### 2.2 今の 妖怪の 泳げなさ（調べた 結果）と タコはちまき の ちがい
| 今の しくみ | 今 | タコはちまき |
|---|---|---|
| `motion.avoidsWater` | からかさ・ちょうちん true、ぬりかべ・ろくろくび false（水の 底を 歩くだけ） | 使わない（およぐ 印で 別の 動き） |
| `mover.place`（足場 `groundSupport`） | 地面 か 水の 底に 立つ | 足場を 見ない。体の 箱が ぜんぶ 水の マスの ときだけ 動ける |
| `fall`（落ちる・水で ×0.5） | 重さで 落ちる | 落ちない・落下ダメージ なし・水で おそく ならない（速さは §4 の 表） |
| `stone`（ぬりかべ の 石化） | ぬりかべ だけ | 関係 なし |
| `placement.fits`（二つ名の 体が 入るか） | 地面で 見る | 体の 箱が ぜんぶ 水か で 見る（入らなければ 二つ名なし） |
| `spawner.trySpawn` | 水の 列には 出ない | 水の 列 だけに 出る（§4.3） |

- 印は `traits.swims`（YokaiTraits に 1 つ 足す。書かない = なし）。「水の 中を およぐ・陸に 上がらない・落ちない・水の 列に わく」を この 1 つの 印で 決める。コードに `kind === …` を 書かない（ratchet）。

## 3. 画面・見た目
- 文字: 名前「タコはちまき」（カタカナ＋ひらがな。オーナー 2026-10-30 で「たこにゅうどう」から 変更。持ち物の「たこ（凧, id `kite`）」とは 別。妖怪の id は `tako_hachimaki`）。すみ「すみ」、ふで「ふで」。
- 色・形: 試作 C（しかくい 頭に 白い はちまき・とがった 口・こい 赤・太い 8 本足）。試作 `/mnt/project-files/octopus/look/src/octo.ts`、v2 `/mnt/project-files/octopus/look/v2/`。シルエットで「はちまきの たこ」と 分かる こと。細かい 色・箱は アート（`docs/art/DESIGN.md`）に まかせる。色ちがい 3 段階・二つ名の 頭の 印（はちまきの 上に 重ならない 位置）も アート。
- 動き: はやく すすむ 間は 8 本足が ヘリコプターの ように 水平に まわる。とまる 間は 足を ゆるく たらして 上下に ふわふわ。すみを はく ときは 試作の「ため 0.4 秒 → はく → 広がる → 消える」（区間は 試作 README の 表）。
- すみの けむり: こい あいいろ（まっ黒・点滅は 使わない）。小さな 箱 10 こまで。
- 画面が 暗く なる: 目が けむりの 中の とき、画面に 黒い うすい 板（§4）。ふちから じわっと。点滅しない。
- 音: はやく すすむ「ぶるるる」、すみ「ぷしゅっ」、ぺちん。サウンドチーム（`docs/audio/SOUND.md`）。くり返す 音なので 小さめ。たおした 音・メダルは 共通。
- アイテムの 2D の 絵: すみ（すみの かたまり・黒い 四角）・ふで（竹の じく＋黒い 穂先）。手に 持つ 形は いらない（ふでは 2D の 絵を そのまま）。

## 5. 例外のとき
- 水を うめて タコはちまき の 体の マスが 水で なくなった: その 場で とまり、3 秒 たっても 水に もどれなければ けむりを 出して 消える（ドロップ・経験値 なし。`leaving` と 同じ 消え方）。
- 水の マスが 小さく（深さ 4 未満）なった: とまって ふわふわ し、すすめる 向きを さがす。
- タコはちまき を おいかけて 陸に 上がった りっくん: たこは 水の 中に のこる。ねらいの 線は 今の まま。
- 二つ名で 体が 大きく なって 水に 入らない: 二つ名 なし（`placement.fits` の 今の きまりと 同じ）。
- 持ち物が いっぱいで すみが 入らない: ほかの ドロップと 同じ（ふくろに 入る）。
- 作業台で たけ が 1 本 だけ: ふで の カードは 足りない 表示（ほかの レシピと 同じ）。
- 大妖怪の ドームや 虹の はじき（`airSafe`）: たこは 水の 外へ とばされない（のけぞりと 同じく 水の マスで 止まる）。
