## 2. 遊び方（つづき）

### 2.2 街〔1B-1・1B-2〕
**置き場所と 向き**〔1B-1〕
1. 新しい 世界でも 前の 世界でも、はじまりの はらっぱ の **スタート地点の そば** に 街が 1 つ ある（§4.5）。同じ シードなら いつも 同じ 場所・同じ 形。
2. **門は スタート地点の ほうを 向き、スタート地点に 立つと 門・たいこ橋・石どうろうの あかりが 見える**（決定「プレイヤーの最初のリスポンの場所の近くに作って」。やられて もどった ときも 同じ）。門と スタート地点の あいだに 見通しを ふさぐ ブロックを 置かない（街を 作る とき スタート地点から 門までの 木・岩は 消して よい。プレイヤーの 置いた 物は 消さない）。
   - **1.3: はじまりの木を 先に 守る**（決定 2026-11-14 15:12）。はじまりの木（スタートの そばの 3 本。VOX-B T4。さいしょの 木材の もと）の **みき** に、街の はんい・すそ（はんいの 外の 地面を ならす 所）・見通しの 道（門 → スタートの 線の まわりで 木・岩を 消す 所）の どれも かからない 場所を 先に えらぶ。その ため **門が スタートから 28 マスより 遠く なる 世界も ある**（100 の シードで 数こ）。**はじまりの 坑道**（入口・道・盛り土）にも かからない。くわしくは §4.5「置き場所」。
3. 下の「手前・奥・西・東」は **門の がわを 手前（南）** と した 言い方。街は スタート地点の 方向に 合わせて 4 つの 向きの どれかに まわして 置く（形は 同じ）。

**街の 形**（5 版の 絵 `town-top.png` の とおり。寸法は §4.5）
4. **奥の 列（門の 反対がわ）は 石がきで 1 段 高い**。石がきの 上に 建物 3 つが 横に ならぶ: 西から **よろずや**・**かじや**・**だいくさんの こや**。石がきの 下を 奥の 用水路が 通り、**橋 3 本**（よろずや と だいくさんの 前は 赤い たいこ橋、かじやの 前は 石の 橋）で わたって 上がる。橋の 先から 奥の 列へは **ジャンプ なしで 歩いて 上がれる**。
5. **まん中は ひろば**（石だたみ）。まん中に **段々の ふんすい**（§4.5）: 白い 石を 4 段 つんだ 塔、水が 段を 落ちて まわりの 池に たまる（水は かざりで 池の 外へ ながれ出さない）。池の ふちに あかり、まわりに **ベンチ 4 つ** と **花の うえこみ 4 つ**、池に こい と はす。ふんすいの 前（門がわ）が おふだで もどる 所。
6. ひろばの まわりに **やたい**: 話せる やたい 3 つ（**かいとりの やたい**〔「やさい」の かんばん、黄と 緑の ひさし〕・**だんごの やたい**・**ごはんの やたい**）と **かざりの やたい**（おめん など。買えない。人が いない）。ひろばの 奥には **かざりの 町家（まちや）** と **おちゃや**（入れない。戸は しまって いる）。**話せる やたいには かならず 人が 立ち、かざりの やたいには 人が いない**（字が 読めなくても 分かる）【PO 案】。同じ かんばんの やたいを 2 つ 置かない（アートの 絵の 青い「やさい」の やたいは かんばんを ほかの 物に かえる）【PO 案】。
7. **東の 列**: 奥に **ものしりさんの 道場**、手前に 竹がきで かこんだ **アスレチック**（§2.15）。道場の 中庭が **板ばり・じゃりの けいこ場**（白い 線の わ、木刀かけ、太鼓、のぼり）で、**わらにんぎょう 3 つ** と **まと 2 つ**（ちかい・とおい）が ある。
8. **西の 列**: 西の 用水路の 外がわに **あきち 3 区画**（決定 16:59「何軒か空き地」）。いけがきと 木の ふだで 区画が 分かる。どの 区画も 家を 1 けん 建てられる 広さ（§4.5。**5 版の 絵の 9×9 は せまいので 12×12 に 直す**）。あきちも 妖怪の **わかない** はんいの 中（1.3: 外から 歩いて 来た 妖怪は あきちにも 入れる。家の 中・戸の きまりは HOUSE-1 の まま ＝ 戸を しめれば 入って こない）。**地盤の きまりは HOUSE-1 の まま**: 地面は はじめ たいらな つち（同じ 高さ）にして おき、みずもり → どうづきで かためた つち に する のは プレイヤー（HOUSE-1 §2.9）。だれの 区画かは 決めない（2 人で どれを 使っても よい）。西の 用水路の 橋 2 本で ひろばと つながる。
9. **手前**: 手前の 用水路を **赤い たいこ橋** で わたり、**赤い 門** を くぐって 外へ。門の 外の 道の 両がわに 石どうろう と 赤い のぼり。
   - **1.3: 門は 2 かいだての 楼門（ろうもん）**（決定 2026-11-14。設計は 共有フォルダ `town/art/gate/`〔`gate-design.png`・`gate-parts.md`・`gate-layers.md`。リポジトリ外〕）: 朱の 丸柱・青みどりの とびら・2 かいの らんかん・黒い かわらの 大屋根と 下の 屋根・金の かざり・しゃちほこ。寸法は §4.5。**門にも アスレチックの 門にも 字の かんばんは つけない**（5 版の 絵の「りっくんの まち」「どうじょうへ」の 板は 作らない）。**細かい 作りこみ（形ブロックの パーツ）は 門 だけ**。ほかの 建物は 今の 作りこみの まま。
10. **木**: 街の 木は **今の ゲームの 木（treeV2。1 本ずつ 形が ちがう 木）の 形を そのまま つかう**（決定「今の ゲームの 1 本ずつ 形が ちがう 木」）。新しい 木の 形は 作らない。さくら色の 葉が 今の 木に あれば つかって よい（なければ 今の 木 だけ）。木も 街の ブロックなので プレイヤーは こわせない（1.4: 妖怪の わざで こわれたら §2.16 で 同じ 形に もどる。街の 木は 同じ たねで 同じ 形）。
11. **建物は 1 つずつ ちがう 形**（決定「同じ物のコピーにしない」）。同じ 建物の 絵を まわしたり 色を かえたり した だけの 物を 置かない（かざりの 町家 2 けんも 形を かえる）。それぞれの 形は §2.2b。

**あかり**〔1B-1・1B-2〕
12. 決定 17:00「灯りをたくさんつけて妖怪が来れないように」と 20:00 ごろの「ちょうちんは 少なめ」を 両方 まもる: **街の ふちに ぐるっと 石どうろう**（8 マス ごと）、ふんすいの ふち・ひろば・用水路の 石段の 口・門に あかり。**紙の ちょうちんは 少なめ**（建物と やたいに 少し。§4.5 の 数）。夜は 街が 遠くから 明るく 見え、6 歳に「**あそこが まちだ**」と 分かる。**1.3: あかりは かざりと 目じるし**（決定 2026-11-14: 妖怪は 街に 入れる）。あかりで 妖怪を 止める しくみは ない。子どもに「あかるいから ようかいは こない」と 言わない（ものしりさんの 説明にも 書かない）。あかりも 街の ブロック なので プレイヤーは こわせない（1.4: 妖怪の わざで こわれたら §2.16 で もどる）。

**しくみ**〔1B-1〕
13. **1.3: 妖怪は わかないが 入って くる**（決定 2026-11-14 11:07「入れて、ふつうに たたかう」。1.2 の「安全地帯 ＝ 入れない・当たらない」は やめた）:
   - 街の **わかない はんい**（§4.5。街の はんい ＋ まわり 8 マス）の 中では 妖怪が **わかない**（夜も）。
   - 外の 妖怪は **歩いて 中へ 入れる**（門からも ふちの どこからでも。かべは 作らない）。中でも ふつうに 動き・ねらい・こうげき する。朝に 帰る きまりも 外と 同じ。
