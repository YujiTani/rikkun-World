## 2. 遊び方（つづき）

### 2.2 街〔1B-1・1B-2〕
**置き場所と 向き**〔1B-1〕
1. 新しい 世界でも 前の 世界でも、はじまりの はらっぱ の **スタート地点の そば** に 街が 1 つ ある（§4.5）。同じ シードなら いつも 同じ 場所・同じ 形。
2. **門は スタート地点の ほうを 向き、スタート地点に 立つと 門・たいこ橋・石どうろうの あかりが 見える**（決定「プレイヤーの最初のリスポンの場所の近くに作って」。やられて もどった ときも 同じ）。門と スタート地点の あいだに 見通しを ふさぐ ブロックを 置かない（街を 作る とき スタート地点から 門までの 木・岩は 消して よい。プレイヤーの 置いた 物は 消さない）。
3. 下の「手前・奥・西・東」は **門の がわを 手前（南）** と した 言い方。街は スタート地点の 方向に 合わせて 4 つの 向きの どれかに まわして 置く（形は 同じ）。

**街の 形**（5 版の 絵 `town-top.png` の とおり。寸法は §4.5）
4. **奥の 列（門の 反対がわ）は 石がきで 1 段 高い**。石がきの 上に 建物 3 つが 横に ならぶ: 西から **よろずや**・**かじや**・**だいくさんの こや**。石がきの 下を 奥の 用水路が 通り、**橋 3 本**（よろずや と だいくさんの 前は 赤い たいこ橋、かじやの 前は 石の 橋）で わたって 上がる。橋の 先から 奥の 列へは **ジャンプ なしで 歩いて 上がれる**。
5. **まん中は ひろば**（石だたみ）。まん中に **段々の ふんすい**（§4.5）: 白い 石を 4 段 つんだ 塔、水が 段を 落ちて まわりの 池に たまる（水は かざりで 池の 外へ ながれ出さない）。池の ふちに あかり、まわりに **ベンチ 4 つ** と **花の うえこみ 4 つ**、池に こい と はす。ふんすいの 前（門がわ）が おふだで もどる 所。
6. ひろばの まわりに **やたい**: 話せる やたい 3 つ（**かいとりの やたい**〔「やさい」の かんばん、黄と 緑の ひさし〕・**だんごの やたい**・**ごはんの やたい**）と **かざりの やたい**（おめん など。買えない。人が いない）。ひろばの 奥には **かざりの 町家（まちや）** と **おちゃや**（入れない。戸は しまって いる）。**話せる やたいには かならず 人が 立ち、かざりの やたいには 人が いない**（字が 読めなくても 分かる）【PO 案】。同じ かんばんの やたいを 2 つ 置かない（アートの 絵の 青い「やさい」の やたいは かんばんを ほかの 物に かえる）【PO 案】。
7. **東の 列**: 奥に **ものしりさんの 道場**、手前に 竹がきで かこんだ **アスレチック**（§2.15）。道場の 中庭が **板ばり・じゃりの けいこ場**（白い 線の わ、木刀かけ、太鼓、のぼり）で、**わらにんぎょう 3 つ** と **まと 2 つ**（ちかい・とおい）が ある。
8. **西の 列**: 西の 用水路の 外がわに **あきち 3 区画**（決定 16:59「何軒か空き地」）。いけがきと 木の ふだで 区画が 分かる。どの 区画も 家を 1 けん 建てられる 広さ（§4.5。**5 版の 絵の 9×9 は せまいので 12×12 に 直す**）。あきちは 安全地帯の 中なので、建てた 家は はじめから 妖怪の 来ない 家。**地盤の きまりは HOUSE-1 の まま**: 地面は はじめ たいらな つち（同じ 高さ）にして おき、みずもり → どうづきで かためた つち に する のは プレイヤー（HOUSE-1 §2.9）。だれの 区画かは 決めない（2 人で どれを 使っても よい）。西の 用水路の 橋 2 本で ひろばと つながる。
9. **手前**: 手前の 用水路を **赤い たいこ橋** で わたり、**赤い 門**（黒い かわらの 屋根）を くぐって 外へ。門の 外の 道の 両がわに 石どうろう と 赤い のぼり。
10. **木**: 街の 木は **今の ゲームの 木（treeV2。1 本ずつ 形が ちがう 木）の 形を そのまま つかう**（決定「今の ゲームの 1 本ずつ 形が ちがう 木」）。新しい 木の 形は 作らない。さくら色の 葉が 今の 木に あれば つかって よい（なければ 今の 木 だけ）。木も 街の ブロックなので こわせない。
11. **建物は 1 つずつ ちがう 形**（決定「同じ物のコピーにしない」）。同じ 建物の 絵を まわしたり 色を かえたり した だけの 物を 置かない（かざりの 町家 2 けんも 形を かえる）。それぞれの 形は §2.2b。

**あかり**〔1B-1・1B-2〕
12. 決定 17:00「灯りをたくさんつけて妖怪が来れないように」と 20:00 ごろの「ちょうちんは 少なめ」を 両方 まもる: **街の ふちに ぐるっと 石どうろう**（8 マス ごと）、ふんすいの ふち・ひろば・用水路の 石段の 口・門に あかり。**紙の ちょうちんは 少なめ**（建物と やたいに 少し。§4.5 の 数）。夜は 街が 遠くから 明るく 見え、6 歳に「**あかるいから ようかいは こられない**」と 分かる（ものしりさんの めあて 1 の 説明でも ひとこと「まちは あかるいから ようかいは こないよ」）。しくみは 下の 安全地帯の まま（あかりで 決めて いるのでは ない）。あかりも 街の ブロック なので こわせず、もし 消えても 安全地帯は 消えない。

**しくみ**〔1B-1〕
13. **安全地帯**: 街の はんい（§4.5）には 妖怪が **わかない**。外の 妖怪は はんいの ふちから 中へ **入れない**（ふちで 向きを かえて はなれる）。妖怪の こうげき（とびどうぐ も）は はんいの 中の プレイヤーに 当たらない。夜も 同じ。1P・2P とも 同じ。
14. **街は こわせない**: 街の はんいの ブロック（用水路・木・あかり・建物 も）は ほれない（ひびも 入らない）・ブロックを 置けない。ほろうと すると 手が「こつん」と はねかえる（1 回の 小さな 返し）。右の 案内は「ほる」を 出さない【PO 案】。**ただし あきちの 区画の 中**（地面から 上も 下も）は ふつうに ほる・おく が できる（地盤を つくり、家を 建て、作りかえる ため）。街の 中で 家を 建てられるのは **1 つの あきちの 中に ぜんぶ 入る 場所 だけ**（HOUSE-1 の 上空の 視点で、あきちから はみ出す 所・道・ひろばは 赤）。街の 外は 今の まま。
15. **街の 中では 落ちても いたくない**（§2.14 の 4。おすすめ【PO 案】）。
16. 街の 人（よろずやさん・建築士さん・ものしりさん・かじやさん・やたいさん・だんごやさん・ごはんやさん）と わらにんぎょう・まとは たたいても 弓で うっても **へらない・たおれない**（HOUSE-1 §2.2 の 3 と 同じ よろけ）。ようかいダマ・けいけんちは 出ない。

### 2.14 用水路（ようすいろ）〔1B-1〕（決定 20:28・20:37）
1. 街の 水の 道は 川では なく **用水路**: **地面から 5 マス ほり下げた 石がきの みぞ**。底に 水が ながれて いる ように 見える（水は かざり。§4.5c）。みぞの 上の ふちには **石の てすり**（ひくい。橋と 石段の 口だけ あける）。
2. **橋は みぞの 上を わたる**（地面と 同じ 高さ〜たいこ橋は 少し 高い）。橋の 下も 底の 通り道が 通る（頭が つかえない）。
3. **底は 水ぎわの 通り道（石）で ぜんぶ つながる**: 水の となりに はば 1 以上の 石の 通り道が あり、みぞの どこからでも 泳がずに 歩ける。通り道は 水の 片がわ でも 両がわ でも よく、両がわの ときは 橋の 下などの 石の ふみ板で 両がわが つながる（§4.5c）。水は ふかさ 1（おぼれない）で、水の 面と 通り道の 上の 面は 同じ 高さ（水から そのまま 歩いて 出られる）。
4. **落ちても いたくない**【PO 案・おすすめ】: 今の 落下の きまりでは 3 マスまで いたくなく、こえた 1 マスごとに 体力 1（ハート 半分）へる（`src/combat/config.ts` の `safeFallHeight: 3`・`fallDamagePerBlock: 1`。水の 中に 着いた ときは へらない）。用水路の 通り道へ 落ちると 5 マス → 体力 2（ハート 1 こ）、奥の 列（1 段 高い）や たいこ橋から なら 6 マス → 体力 3 へる。6 歳が 見て まわる 街で、うっかり 落ちて いたい のは こわい ので、**街の はんいの 中（§4.5 の 100×100。高さは 問わない）では 落下で 体力が へらない** に する。おちた ときは「ぽてっ」（通り道）か「ぽちゃん」（水）の 小さな 音と しぶき だけ。街の 外の 落下は 今の まま。
   - ほかの 案（TOWN-1 §7 で オーナーに きく）: 〔案 B〕用水路の みぞの 中 だけ いたくない（アスレチックや 2 階からは 今の まま）。〔案 C〕今の まま（通り道に 落ちると ハート 1 こ。水に 落ちれば 0）。
5. **上がる 石段**（決定 20:37「どこからでも 12 マス以内」）: はば 2 の 石段が みぞの かべに そって ついて いて、**用水路の 底の どの マス（水の マスも）からも、底を 歩いて 12 マス 以内で いちばん 近い 石段の 下に つく**。石段は **ジャンプ なしで 前に 歩く だけで 上がれる**。
6. **石段の 上の 口には あかり 1 つ と 赤い のぼり 1 本**（底から 見上げて 出口が 分かる。夜も 光る）。
7. 用水路の 水は **あふれない・ひろがらない・へらない**（今の 水の しくみで 通り道や 外へ ながれ出さない）。用水路の はしは 街の ふちで 石がきで とじる（街の 外の 水と つながらない）。
8. みぞの 中も 街の はんい（こわせない・妖怪が 来ない）。

### 2.15 アスレチック（忍者の しゅぎょう場）〔1B-2〕（決定「もっと 広く、ジャンプして 移動するのが 楽しい コース」・STORIES 追加）
1. 道場の 手前に 竹がきで かこんだ 広い にわ。入り口に 小さな 門（「どうじょうへ」の ふだ）。まわりに 忍者の 旗・緑の のぼり・見物の ベンチ。
2. **コース**（この 順に まわれる。`athletic.png`）: **くい**（高さ 1〜3 の 丸太の くいを 1 本ずつ とびうつる）→ **ゆれる 丸太**（つり下げた 丸太が ゆっくり ゆれる。乗れる）→ **あみの やぐら**（あみを のぼる）→ **つり橋**（やぐら どうしを つなぐ）→ **すべり台**（赤。やぐらから 下へ）→ **池の とび石**（池の 上の 石を とびうつる）→ **ゴールの 太鼓**（「ゴール」の 旗の ある やぐらの 上）。
3. どこで 落ちても いたくない（§2.14 の 4。下は 草か 池）。池は ふかさ 1（おぼれない）。落ちたら その 場から やりなおせる（はじめに もどらなくて よい）。
4. **ゴールの 太鼓** を たたくと「ドン！」。**その 人が はじめて たたいた とき だけ**「ゴール！」の 字と 小さな 紙ふぶき（中）。2 回目 から は「ドン！」の 音と 太鼓が ゆれる だけ（くり返す 行動は ひかえめ。`docs/fun.md`）。
5. めあて 2（ジャンプで だん を のぼろう）の **れんしゅうの だん** は コースの さいしょの くい（高さ 1）。めあて 4（ロープ）の **れんしゅうの がけ**（高さ 4）は あみの やぐらの 横（上に ロープを かける 所）。
6. コースの 道具も 街の ブロックで こわせない。
