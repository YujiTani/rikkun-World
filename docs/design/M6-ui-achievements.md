## 1. ねらい（りっくんがどう楽しむか）

- **作る画面は 絵だけ**。ならんだ絵のうち **光っているもの が作れる**。字が読めなくても「光る → おす → できた！」。
- 絵にマウスを合わせると、一覧の右の **せつめい パネル**（くわしい説明の 別の わく）の中身が その絵に替わる。名前・★（めずらしさ）・「なにに つかう？」・「どう つかう？」（マウスやキーの絵）・つよさ（四角の数）・材料（もっている数・いる数、足りないと赤）と、大きな **つくる** ボタン。お父さん・お母さんが読んであげても分かる。
- 作ると **「ぽよん」＋光のつぶ＋「トントン ぽん！」**。続けて作ると音がだんだん高くなる（ドパゲー風）。**はじめて作ったものは、赤と金の 横断幕（おうだんまく）が くるくる回りながら 出てきて キラッと光り、ファンファーレ**。「また ちがうのを 作りたい！」につながる。
- あそんでいると **実績（じっせき）** がたまる。「はじめて つち ブロック を こわした！」「からかさ を 10 ぴき たおした！」。取ると **ゲームが止まって 画面の真ん中に「おめでとう！」** とメダル。ボタンを押して閉じる（大事なお知らせなので、うっかり消えない）。
- もちもの画面の **じっせき** のページで、取ったメダルをながめられる。まだのものは **「？？？」**（何があるかは ないしょ → さがすのが楽しい）。
- 画面ぜんぶ（HUD・もちもの・案内・やられた画面…）を **モダンで すっきり、メリハリのある見た目** に作り直す（オーナー決定）。大事なもの（ハート・レベル・えらんでいるマス・光るボタン）が ぱっと目に入り、押すと「カチッ」と手ごたえ。
- こわくない・目がチカチカしない（画面全体の点滅なし、光の変化は 1 秒に 3 回未満）。

## 2. 遊び方（プレイヤーから見た動き）

### 2.1 作る画面（つくる・やく）

もちもの画面（E）の右がわの「つくる」「やく」（M4 §2.2・§2.3）を、**ドット絵のマスの一覧** に変える。決まり（材料の数え方・いっぱいのとき・かまど・ねんりょう）は M4 のまま。

**(1) 一覧（マス）**
- つくる: M4 §4.1 の 20 こ＋**たんす**（§2.9。21 番目）の **21 こ** を、その順に **4 列 × 6 段**（のこり 3 マスは空ける。あとで足すレシピ用）。やく: **4 こ** を 1 段（上に ねんりょう 3 種の絵と数。M4 のまま）。
- マスは **絵だけ**（名前・材料の列は出さない）。画面幅 1280px のとき マスは **56px**、絵は **48px**（16×16 の 3 倍）、マスの間 8px（第 3 版。1280×720 に入るよう §3.6 (2) の寸法で決め直した）。
- マスの見た目（表の上から先に当てはまるもの。印は重ねてよい）:

| 状態 | 見た目 |
|---|---|
| **つくれる**（材料がそろう。やく は ねんりょう も） | 絵は ふつうの色。アクセント（`--rk-accent`）の太いわく 4px＋光 `--rk-glow`＋やさしい光が 1.5 秒に 1 回 強く・弱く（M4 と同じ。点滅しない）。マスが 2 秒に 1 回 2px ふわっと上下 |
| 足りない | 絵が **灰色（白黒）で 不透明度 35%**。わくは `--rk-line` |
| （印）できる数が 2 こ以上 | 右下に `×4` |
| （印）**つくった ことがある** | 左下に 小さな みどりの ✓（12px）。一度も作っていないものには付かない |
| （印）働きが あとのもの（M4 の「作れるだけ」6 こ） | 右上に 小さな 時計（M4 と同じ） |
| （やく だけ）焼いている・待っている | M4 のまま（下の オレンジの棒・右上の `あと 3`） |

- **えらぶ と つくる**（第 3 版。G2 で決め直した）:
  - **えらんでいるマス** が いつも 1 つある（白い ふち 4px＋右上に小さな ▼）。えらんでいるマスが **つくれる** ときは、その上に **ゆびの印**（16×16 を 2 倍。下向きに おす手）を出し、1.5 秒に 1 回 ぽよん と 小さく はねる（明るさは 変えない）。字が読めなくても「もう いちど おす」と分かるように（第 4 版。G12）。光る 黄色の わく（つくれる）と 白い ふち（えらんでいる）は 両方 同時に 出てよい（白い ふち が 内側、黄色の わく が 外側）。もちもの画面を開いたときは、前に えらんでいたマス（はじめは つくれる いちばん前のマス、無ければ 1 つ目）。
  - **えらんでいない マスを クリック → えらぶ**（せつめい パネル が そのマスに替わり、つくる ボタンが そのマスの ものになる。音「ポン」）。
  - **えらんでいる マスを もう一度 クリック → つくる（やく）**。つまり 同じマスを 2 回 クリックすると作れる（「えらんで、もう いちど おす」）。足りないときは マスが小さくふるえて「ぷぷ」（M4）。
  - **せつめい パネル の つくる ボタン** を押しても、えらんでいるマスを つくる。
  - M4 の「カードを 1 回 クリックで つくる」から変えた理由: せつめい を ひらいた まま ボタンへ マウスを動かすと、とちゅうの マスで 中身が替わってしまう（G2）。えらぶ を クリックにすれば、マウスが どこを通っても パネルの中身は 替わらない。

**(2) くわしい説明の パネル（せつめい パネル）— 決まった場所に いつも出す**
- つくる・やく の場所の **右がわに 決まった パネル**（はば **320px**、高さは マスの一覧と同じ。§3.6 (2) の図）。浮かせない・マスに重ならない・閉じない（つくる・やく の場所が出ているあいだ ずっと出ている）。
- **中身**: **マウスを合わせているマス** があれば その中身（「みている」）、合わせていなければ **えらんでいるマス** の中身。マスに マウスを合わせた瞬間に替わり、マスから はなれた瞬間に えらんでいるマスに もどる（待ち時間なし。前の版の「閉じるまで 15 画面ステップ」は なくした）。左どなり・右どなり の マスへ なぞって動かせば、つぎつぎ 見くらべられる。
- **つくる ボタン は いつも えらんでいるマス のもの**。合わせているマスが えらんでいるマスと ちがうあいだ、ボタンの上に 小さく `クリック で えらぶ`（小 16px・`--rk-text-sub`）を出し、ボタンは えらんでいるマスの状態のまま。マウスが パネルに入ったら（マスから はなれたので）中身は えらんでいるマス。
- カーソルに何か持っているときも パネルは出す（中身は えらんでいるマス。合わせても替えない）。
- 見た目: §3.5 の「カード」（`--rk-bg-800`、角丸 14px）、ふちは めずらしさの色（3px）。中の余白 16px、かたまりの間 12px・中 8px。字は §3.5 (3) の 5 段だけ。
- 中身（上から。すべて §2.2 の説明の表と設定の値から作る。たて に 入りきらないときは 3〜7 の所だけ スクロール。1 と 8 は いつも見える）。
  - 第 4 版（G11）: 入りきるように つめる — つよさ は **2 列** にならべる（3 つでも 2 行）、くらべ（`すで は 1`）は 別の行にせず メーターの右に 小 16px で、ざいりょう は **横にならべる チップ**（1 つ 絵 32px＋`2 / 3`。3 つまで 1 行、4 つ以上で 2 行）。見つもり（よろい・なぎなた）: 余白 32＋1 名前 48＋2 めずらしさ 28＋3 なにに 2 行 56＋4 どう 2 行 56＋5 つよさ 2 行 56＋6 ざいりょう 1 行 40＋8 ボタン 56＋すき間 12×6 = **444 ≦ 448**。
  - それでも はみ出すとき（文の長い たんす・たいまつ など）は、3〜7 の所の下はしに **▼ と `つづき`**（小 16px・`--rk-text-sub`）を出し、ホイール か ▼ を クリック で 下へ。いちばん下まで行ったら ▼ を消す。▼ は 1.5 秒に 1 回 2px 下へ ゆれる（明るさは 変えない）。

### 2.2 全アイテムの説明（せつめいの 表）

- 「なにに」「どう」は下の表の文をそのまま出す（字はすべて ひらがな・カタカナ・数字）。**「どこで」は自動で作る**: ほって出るものは「〇〇 を ほる」、妖怪のドロップ表（`YOKAI_DROPS`）にあれば「〇〇 が おとす」（妖怪の名前を表の順で `・` でつなぐ）、レシピのできるものなら「〇〇 3・〇〇 2 で つくる」「〇〇 1 を かまど で やく」。**「つかいみち」も自動**: そのアイテムを材料に使うレシピのできるもの（M4 の順）。
- 「つよさ」の数は設定（`toolPower`・`weaponDamage`・`weaponReach`・`weaponTicks`・`arrowDamage`・`arrowRange`・`armorValue`）から読む。表の数は今の初期値。
- ボタン: `[1〜9]` = ホットバーで えらぶ、`[ひだり]` = ひだりクリック、`[ひだり ながく]` = ひだりクリック を おしつづける、`[みぎ]` = みぎクリック、`[E]` = もちもの画面。

### 2.8 アイテムを すてる（オーナー追加要望 その2-2）

**(1) あそんでいるとき（ロック中）**
- 新しい Action を 2 つ: **`drop`**（キー **Q**）＝ 手に持っているもの（えらんでいるホットバーのマス）を **1 こ** すてる。**`dropStack`**（**Shift＋Q**）＝ そのマスの **ぜんぶ** をすてる。
  - 今の `src/input/actions.ts` は キー（`KeyboardEvent.code`）1 つ → Action 1 つ で、Shift などの 修飾キーを見ていない。**担当 D が 修飾キーつきの キーの割り当て（「Shift＋KeyQ → dropStack」）の しくみを足す**。Shift＋Q のときは `drop` は 出さない（どちらか 1 つ）。Shift だけ・Q だけ の ほかの Action への 影響は ない（今 Shift は 使っていない）。
- **押した瞬間に 1 回だけ**（押しっぱなしでも くり返さない）。PO 案は「Q で 1 こ」だけ。6 歳が Q を押しっぱなしにして 気づかずに全部すてるのを ふせぐため、くり返しなし に決めた。
- 手が空なら 何もしない（音もなし）。
- 投げ方: 目の高さから 0.3 下、向いている方へ 横 **4 ブロック/秒**・上へ **2 ブロック/秒** で とび出し、M3 の落とし物と同じく 重力で落ちて止まる（だいたい 1.5〜2 ブロック先）。出る所が ブロックの中なら 足もとに出す。
- 投げたものは **今の落とし物（`DropField`）と同じ**: 光の柱（めずらしさの色）・水にうかぶ・**消えるまで 36,000 ステップ（10 分。`dropBagTicks`）**・保存される・拾える。
- **すぐ拾い直さない**: 投げてから **60 ステップ（1 秒）** は プレイヤーが近くても 拾わない（`dropPickupDelay`）。これがないと 投げた瞬間に 足もとで 拾ってしまう（PO 案に足した）。妖怪のドロップ・やられた落とし物 は今までどおり すぐ拾える。
- 音「ポイッ」（短く軽い音）。人形の うでの動き `throw`（うで の層・優先 3・**12 ステップ**: 右うでを前へ ふる）。

**(2) もちもの画面のとき**
- **クリックでは すてない**（第 3 版）: カーソルに持ったまま パネルの外を クリックしても **何もしない**（M2 §2.5 のまま）。6 歳が まちがえて クリックして すてないように、すてるのは 下の **ドラッグで パネルの外へ出したとき だけ** にした。
- **ドラッグ**: アイテムのあるマスで マウスを押し、押したまま 8px 以上 動かすと ドラッグになる（押しただけ・8px 未満で はなしたら M2 の クリック と同じ）。そのまま **パネルの外** で はなす → そのマスの **ぜんぶ** をすてる（PO 案どおり）。パネルの中で はなしたら、はなした所のマスへ M2 のクリックと同じ決まりで動かす（マスでなければ 元のマスにもどす）。カーソルに何か持っているときは ドラッグにならない。
- 合わせているマスで **Q** → そのマスから 1 こ、**Shift＋Q** → そのマスの全部（ゲームと同じキーで同じ意味。くり返し同じ）。
- どれも 投げる向き・速さは (1) と同じ（プレイヤーの前へ）。もちもの画面のあいだも ゆっくり 飛ぶ。
- ドラッグしているあいだは **パネルの外 ぜんたい を うすい赤**（`--rk-ng` 不透明度 15%。ドラッグを始めたとき 1 回 200ms で出し、終わったら 消す。くり返し変えない）にし、パネルの外に カーソルが出たら カーソルの絵の下に `すてる` の札（チップ。本文 20px・左に `--rk-ng` の帯）を出す。字が読めなくても「外は すてる場所」と分かる。
- そうびのマス（4 つ）・たんす のマス（§2.9）からも 同じように すてられる。

### 3.5 デザインの決まり（スタイルガイド）— ゲームの UI 全体を作り直す（オーナー決定）

**方針**: ゲームの中身は マイクラ風、**見た目は モダン**（フラット寄り・大胆な色・メリハリ・なめらかな動き）。和風は **アクセントだけ**（朱色・小さな青海波もよう・メダルや横断幕の右はし）。**情報が見やすいこと が いちばん**。画像ファイルは使わず、CSS と コードで描く 16×16 のドット絵だけ。

- **この節は M1〜M5 の仕様書の「色・形」の記述より優先する**。場所・数・動きのきまり（例 M4 のタブの高さ 64px、ホットバーのマス数、ツールチップの中身）と M1〜M5 の自動の受け入れ基準は そのまま守る（ぶつかったら 基準のほうを守り、PO に報告）。
- 数はすべて 画面幅 1280px のとき。ほかの幅では `clamp()` で 0.85〜1.5 倍（文字は 16px より小さくしない）。

**(1) 5 つの基本ルール（どう使うか）**

| ルール | このゲームでのきまり |
|---|---|
| **強弱（階層）** | 1 つの画面で いちばん大事なもの 1 つだけ を「表示」か「見出し」の大きさ・太さ 800・あざやかな色にする（例: おめでとう画面の `おめでとう！`、せつめい ウィンドウの 名前、もちもの画面の えらんでいるマス）。補足（くらべ・日・小さな数）は「小」16px・`--rk-text-sub` |
| **近接（グループ化）** | 同じ種類は 1 つの **かたまり**（パネル 1 枚）にまとめる。かたまりの中のすき間 8px、かたまりどうし 16px 以上、画面のはしから 24px。HUD のかたまりは §3.6 の 4 つだけ |
| **整列** | 8px の格子にそろえる。HUD のかたまりは 画面のはし（24px）か ホットバーの はし にそろえる。パネルの中は 左はしをそろえる（数字だけ右はし） |
| **コントラスト** | 文字と背景の明るさの比 **4.5 以上**（24px 以上の字と絵は 3 以上）。HUD は 世界の上に出るので、かならず うすい下地（`--rk-hud-bg`）の上にのせる |
| **くり返し（一貫性）** | 同じ役割は同じ部品（下の (6)）。押せるもの = ボタンの形、マス = マスの形、数の棒 = バーの形。色の意味は どこでも同じ（黄 = 押せる・えらんでいる、みどり = ある・できた、赤 = 足りない・ダメージ、青 = 知らせ） |

## 5. 例外のとき

- **ようかいだま**（`yokai_orb`）: いまは手に入らない（M4 でドロップから外れた）。古い保存で持っていたら、説明は `いまは つかえない よ`・どこで は `むかし の ようかい が おとした`。実績・§6.2 のテストの対象外。
- **せつめい パネル**: カーソルに何か持っているときは 合わせても 中身を替えない（えらんでいるマスのまま）。つくる を押して いっぱい だったら `もちもの が いっぱい！` の文字の合図。
- **横断幕のじゅんばん** が 4 こ以上になったら、4 こ目からは 横断幕を出さず（音もなし）、実績の列には入る（おめでとう画面で見える）。
- **同じステップで いくつも取った**: 見せていない列に 表の順で入る。おめでとう画面は 1 枚。
- **おめでとう画面のあいだ**: ゲームは止まる。自動セーブはしない（閉じたあとの次の自動セーブ）。ページを閉じたら、見せていない列は保存に残って次に出る。
- **やられた画面のあいだ** に取ったもの（`death.all` など）は、復活してから しずかなとき に出す。
- **案内画面**（ロックが外れた）のあいだは何も出さない。もちもの画面のあいだは 出してよい（もちもの画面の上に重ねる）。
- **数の上限**: 記録は 2,000,000,000 で止める（それ以上ふえない）。
- **準備用の窓口**（`inventory.add`・`armor.set`・`level.set`・`craft.make` ほか）で変えたものも 記録する（`craft.make` は つくった、`inventory.add` は 拾った に数えない — M4 §2.12 と同じ）。ただし `achievements.reset()` のあとから数える。
