- この仕様書に書いていないことは今のまま。1 ステップ = 1/60 秒。F は そのわざの `frame`（わざを始めたステップ = F1）。R = 刀の射程（2.2）。P = 刀の強さ（`weaponDamage`）。
- **新しい絵は作らない**。2・3 段目は 今の 3 つの わざの絵を、出だしだけ ちぢめて 使い回す（CHAR-2 §4.2 の「段階ごとの比」）。

## 遊び方の要点（yuzu の OK 用）

1. **きらめく カタナ だけ**、ひだりクリックを **つづけて 押す** と 3 れんぞくの わざになる（オーナー決定）。ほかの刀は今のまま。
2. **中段**: つき → きりあげ → おおげさぎり。**下段**: きりあげ → つき → おおげさぎり。さいごは いつも おおげさぎり（とびこんで ふっとばす「きめ」）。**上段** は おおげさぎり 1 発のまま（推奨。§8-3）。
3. 押すのは「当たりが出たあと〜わざの おわり」まで（0.3〜0.6 秒の間に もう 1 回）。早く押しても おぼえていて ちょうどよい所で 次が出る。押さなければ 今どおり 1 段目にもどる。押しつづけ（長押し）では つながらない。
4. 何段目かは 刃の軌跡の 星の数（1・2・3 こ）で分かる（推奨。§8-2）。2・3 段目は 音が少し高くなる。
5. つなぎの間でも Shift＋クリックで パリィが出る。
6. おすすめの数: 3 段ぜんぶ当てると、かたなの いちばん強い使い方（おおげさぎりを当てつづける）の **約 1.2〜1.3 倍** の速さで 妖怪が へる。
7. **きらめく カタナの見直し**（推奨 案 A）: 強さ 6 → **4**（かたなと同じ。強さの上のぶんは 3 段攻撃）、たいきゅう 500 → **300**、つくる材料 **かたな 1・すいしょう 1**（今は すいしょう 2・てつ 3・き 1）。

## 1. ねらい（りっくんがどう楽しむか）

- 「ぽち・ぽち・ぽち」と リズムよく 押すと、つき → きりあげ → **ズバッと とびこむ おおげさぎり** が つながって 妖怪が ふっとぶ。ボタン 1 つで「れんぞくわざ が きまった！」が 味わえる。
- 1 段目・2 段目で 少し 押されて はなれた 妖怪にも、3 段目の とびこみ（3.1 マス）で とどく。つながる 意味が 体で分かる。
- きらめく カタナは「強い数」ではなく「**この刀だけの わざ**」で 特別になる（O3）。

## 2. 遊び方（プレイヤーから見た動き）

1. きらめく カタナを持ち、今のかまえの わざ（1 段目）を出す。数は今のまま（WEAPON-4）。
2. 1 段目の **当たりの はじめから わざの おわり**（§4.2 の「つなぎの窓」）に ひだりクリックを もう一度 **押す** → 1 段目の もどりを切って 2 段目。出るのは「キャンセルできる F」（§4.2）より あと。早く押したら おぼえておき、その F で出る。
3. 2 段目の窓で また押す → 3 段目（おおげさぎり）。3 段目は さいごまで出しきる（もどり 72F は 今の おおげさぎりと同じ。外したら すき が長い）。
4. 3 段目の さいご 8F に押すと（今の先行入力）、次は 1 段目から。窓で押さなかったとき・わざが おわって 何もしていない（idle）ときに押したときも 1 段目。
5. **当たらなくても つながる**（推奨。§8-4）。空ぶりでも 押せば 次の段が出る。
6. 各段は「新しく わざを始める」のと同じあつかい: その段を始めるステップに 向き u・向きの補助（WEAPON-3 §4.2・§4.3。その段の わざの とどく で見る）・ふみこみの向きを決め直す。だから 段ごとに 方向キーで 向きを変えられる。
7. かまえ（HUD の 印）は 変わらない（中段から出した きりあげ でも 印は 中段のまま）。
8. 押しつづけ（長押し）は 今のまま「同じ 1 段目を くり返す」。つながるのは 押し直したときだけ。
9. つなぎの窓で Shift＋クリック → パリィ（§4.5）。そのあとは 1 段目から。
10. ほかの刀（ぼくとう・かたな）・ほかの道具は まったく今のまま。

## 3. 画面・見た目

- **色・形（何が分かればよいか。細かいきまりは `docs/art/DESIGN.md`）**
  - 2・3 段目の 体の動きは 今の わざの絵。出だしが 短いぶん、ためが 速く見える。前の段の もどりの とちゅうから 次の段の コマ 0 へ うつる所は、ポーズが とぶ。うつりの 混ぜは **2 コマ以内**（MOTION #8・#10。混ぜ方は 開発・アートにまかせる）。見え方は オーナー確認（AC30）。
  - 3 段目が おわったあと 体は 今のかまえの形へ もどる（かまえ変えと同じ 8F の 混ぜ。見た目だけ。ゲームの数は 待たない）。
  - **何段目か の印（推奨 案 A。§8-2）**: きらめく カタナの 軌跡の 星（CHAR-4 §4.4。今は いつも 3 こ）を **段の数と同じ** にする。1 段目 = 1 こ（q 0.55）、2 段目 = 2 こ（q 0.25・0.85）、3 段目 = 3 こ（q 0.25・0.55・0.85。今と同じ）。上段の おおげさぎり 1 発は 1 段目なので 1 こ。色だけで 分けない（CRITERIA #13: 数で 分かる）。

### 4.3 強さ（DPS）の確かめ

ダメージの倍率・ノックバック・形・当たる数は 段に かかわらず その わざの今の数（WEAPON-4 §4.1。つき 0.75・きりあげ 1.15・おおげさぎり 2.5）。3 段で 0.75 + 1.15 + 2.5 = **4.4 × P**。

**物さし（PO の値から変えた。§8-7）**: 「かたなの いちばん強い 単発の くり返し」= かたな（P 4）で おおげさぎりを 当てつづける = 10 × 60 ÷ 106 = **5.66/秒**。ここに 1.2〜1.4 倍。

| | 1 回の 3 段 | 長さ | 1 秒あたり | かたな おおげさぎり（5.66）との比 | かたなの その かまえの 1 段目の くり返しとの比 |
|---|---|---|---|---|---|
| 中段（P 4） | 17.6 | 145 | 17.6 × 60 ÷ 145 = **7.28** | **1.287** | つき 4.39 の 1.66 |
| 下段（P 4） | 17.6 | 152 | 17.6 × 60 ÷ 152 = **6.95** | **1.227** | きりあげ 5.31 の 1.31 |
| 中段（P 5。案 B） | 22 | 145 | **9.10** | 1.608 | |
| 中段（P 6。今の強さのまま） | 26.4 | 145 | **10.92** | 1.930 | |

- 案 A（P 4）で 1.2〜1.3 倍に 入る。今の強さ 6 のままだと 約 1.9 倍で O3「ちょっと強い」を こえる。
- つなぎが ない（1 段目だけ・上段）ときの きらめく カタナは かたなと 同じ（案 A）。
- **たおす速さの例（案 A・M = 1。いちばん速く押す）**: からかさ 8 → 3 + 4.6 = 7.6 で のこり 0.4 → 3 段目で たおれる（68 ステップ目 = 1.13 秒）。かたなの きりあげ 2 回は 72 ステップ目（1.2 秒）、つき 3 回は 87 ステップ目（1.45 秒）。ぬりかべ 40（押されない）→ 3 段 2 回（35.2）＋ つき 3（38.2）＋ きりあげ 4.6（42.8）= 5 回目の段で たおれる: 145 × 2 + 20 + 13 = **323 ステップ（5.4 秒）**。かたなの おおげさぎり 4 回は 3 × 106 + 29 = 347（5.8 秒）。
- 1 回ごとの ダメージは 変わらないので、BALANCE の「たおす回数」の物さしは こわれない（§4.6）。

### 4.4 動き（ふみこみ・絵のコマ・軌跡）の数

- **絵のコマ**: 段のわざも CHAR-2 §4.2 の「段階ごとの比」で コマを出す（絵の長さは `atlas.json` のまま）。当たりと もどりの長さは 1 段目と同じなので、**2・3 段目の 当たり・もどりの コマは 1 段目と 同じ**（きりあげ 2 段目の F13 = きりあげ 1 段目の F20 の コマ、おおげさぎり 3 段目の F21 = 1 段目の F29 の コマ）。出だしだけ 速く流れる。
- **ふみこみ**（おおげさぎり 3 段目）: 線 A は 絵の時で 決まるので、3 段目の F(20 + j) = 1 段目の F(28 + j)。A(20) = 0.309、A(21) = 0.4、A(26) = 2.6、A(29) = 3.1、A(98) = 3.1。とまり方（かべ・がけ・妖怪）は WEAPON-4 §4.5 のまま。きりあげ・つき は 0（今のまま）。
- **向きの補助の とどく**: 3 段目の おおげさぎりも R + A(当たりの おわり) = 2.2 + 2.6 = **4.8**（WEAPON-4 §4.2 と同じ）。
- **軌跡の窓**（CHAR-4 §4.2。τ は今のまま、時刻へは 比で うつす）: きりあげ 2 段目 τ 19 → 時刻 12、τ 22 → 15（点は F12〜15 の 4 つ）。おおげさぎり 3 段目 τ 28 → 20、τ 34 → 26（F20〜26 の 7 つ）。つき は 同じ。
- **軌跡は 同時に 1 本**: 1 段目の つきの軌跡は F15 で消え（C = 21 より前）、きりあげ 1 段目は F31（C = 35 より前）、きりあげ 2 段目は F24（C = 28 より前）で消える。次の段を始めるときに 前の軌跡は もう ない。
- **絵と 数の つなぎ**: キャラの絵・軌跡は 今 `settings.bladeTech` から わざの長さを 読んでいる。段のわざは 長さが ちがうので、**`blade.state().lengths`**（そのわざの 今の 出だし・当たり・もどり）を 読む（§4.7）。

### 4.5 パリィ（WEAPON-5）との つなぎ

- きらめく カタナの 1・2 段目の **つなぎの窓**（§4.2）で Shift＋ひだりクリックを **押した** → パリィ。始まるのは C か 押した F ＋ 1 の おそい方（つなぎと 同じ）。ほかの刀・3 段目は 今のまま（さいご 8F だけ）。
- 窓の中で つなぎ（ひだりクリック）と パリィ（Shift＋ひだりクリック）を 両方 押したら、あとに押した方（今の きまり）。
- パリィのあとは 段が もどる（次の わざは 1 段目）。
- パリィの 数（2/18/20・きめ 8 など）は 今のまま。
- 決めた理由: 3 れんぞくの とちゅうでも 妖怪の攻撃を 受けられる（6 歳が「ボタンを押しすぎて 守れない」を へらす）。パリィは 攻撃が来ないと 得をしないので、つなぎを 切るための 近道には ならない。
