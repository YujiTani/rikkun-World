## 1. ねらい（りっくん が どう 楽しむか）

- 自分 の キャラ が **「ぼく の おさむらい」** に なる。オーナー の 見本（9 体）の ような、**小さな 箱 を 組み合わせた ボクセル の 体** と **ドット絵 の 表面** の ちびキャラ（**4 頭身**）。
- **かっこいい・こわくない**: 四角い 顔 に 大きめ の 目、まゆ、にこっ と した 口。血・きず・こわい 面（めん）は ない。かぶと を かぶっても 顔 は 見える。
- 防具 を 着る ほど **よろい武者（むしゃ）** に なっていく（かぶと・よろい・こて・すねあて が 見た目 で 分かる）。
- 刀 を **両手 で しっかり にぎる**、弓 を **ひじ を 引いて ひきしぼる**。

## 2. 遊び方（プレイヤー から 見た 動き）

- 遊び方 は かわらない。三人称（`V`）の 人形 と 一人称 の 腕 の 見た目・動き が かわる。
- 背 の 高さ・当たり の 大きさ・目 の 高さ（カメラ）・歩く 速さ は 今のまま。
- 防具 を 着ると その 部分 が よろい に なる（§4.5）。何も 着て いない ときは **着物 と はかま だけ**。
- 持ち物 に 刀 が あると **こし に 刀 と さや** が 見える（§4.6）。

## 3. 画面・見た目

### 3.1 基本 の 1 体 と 色ちがい

- **基本 = 見本 の 中上（まん中 の 上）**: 黒い かみ・頭 の 上 に まげ（赤い ひも）・みどり の 着物（白い えり・中 は 黒）・こい みどり の はかま・赤 の 帯 と ピンク の むすび目・黒い ブーツ に 赤い ひも。防具 を 着ると 黒 の 板 に 金 の ふち と 赤い ひも（おどし）。
- **色ちがい**（形 は 同じ、色 だけ ちがう。§3.5）: 「むらさき」（見本 左上）・「くろ」（見本 右上）・「こん」（見本 右中）。**基本 の 色 は オーナー確認 待ち なので みどり の まま**。ゲーム の 中 で 色 を えらぶ しくみ は 今回 作らない（あとで 作れる よう、色ちがい は 同じ 形・同じ 張り方 で 色 だけ 差しかえ できる こと）。
- 見本 の ほか の 1 体（茶色 の ツンツン頭 など）を 基本 に えらび なおしても、**からだ の 寸法（§3.3）は 同じ** に する。かわる のは 頭 の かみ の 形 と 色 だけ なので、この 仕様 の 基準 は そのまま 通る。

### 3.2 格子（ドット の 形 と 色）

- **背 1.80 ブロック = 64 ドット**。**1 マス = 1 ドット ≈ 0.028 ブロック**（1.8 ÷ 64 = 0.028125）。正面 は 64×64 の マス に 入る（はば は 36 マス だけ 使う）。`.` = 何も ない。横 は **左 が 前**（はば 24 マス）。
- **4 頭身**: 頭（かみ の 上 〜 あご）**15 マス**（04〜18 行、はば 16）、からだ（くび 〜 足 の うら）**45 マス**（19〜63 行）。頭 1 : からだ 3。**まげ（00〜03 行）は 頭 に 入れない**。
- かぶと の くわがた は 背 の 上 に はみ出る（行番号 −8〜−1）。
- テクスチャ は 1 マス の 面 = 1 ドット（§3.4）なので、格子 が ほぼ そのまま 表面 の ドット絵 に なる。
- 行 の 書き方: `NN <正面 36 マス>     <横 24 マス>`（防具 あり は 正面 だけ）。

### 3.3 からだ の 寸法 と 「両手持ち が できる 体」の 条件

1 マス = 0.028125 ブロック。

| 部分 | 大きさ（はば × 高さ × おく、マス） | ブロック |
|---|---|---|
| まげ | 6 × 4 × 6 | 0.17 × 0.11 × 0.17 |
| 頭 | 16 × 15 × 16 | 0.45 × 0.42 × 0.45 |
| 胴（くび 〜 はかま の 上） | 14 × 23 × 10 | 0.39 × 0.65 × 0.28 |
| うで（1 本） | 5 × 23 × 5（上うで 10・下うで 8・手 5） | 0.14 × 0.65 × 0.14 |
| あし（1 本） | 6 × 22 × 8（はかま は 2 本 で 16 × 16） | 0.17 × 0.62 × 0.23 |
| はば（防具 なし ／ 大袖 つき） | 24 ／ 30 | 0.675 ／ 0.84 |

**記号**: s = 左右 の かた の 骨 の 中心 の 間。L = かた の 骨 → 手 の にぎり の 中心 の 長さ（ひじ を のばした とき）。かた の 骨 は 胴 の はし から **2 マス 内がわ**（x = ±0.14）、高さ **1.195**（21 行 の まん中）。手 の にぎり の 中心 は 39 行。

| 条件 | 中身 | 基本 の 体 |
|---|---|---|
| **C1 とどく** | **s ≦ L − 0.10** | s = **0.28**、L = **0.52** → 0.28 ≦ 0.42 ○ |
| **C2 上段** | 上段 で にぎり が **目 より 上**: L ≧（かた の 骨 → 目 の 高さ）＋ 0.05 | 目 1.43 → 0.24 ＋ 0.05 = 0.29 ≦ 0.52 ○ |
| **C3 弓** | 段 3 で 右手 が ほお の 横: かた の 骨 → ほお の 横 の 点 ≦ L − 0.05 | 約 0.22 ≦ 0.47 ○ |
| **C4 動き の とちゅう** | 刀 を 持つ 全 キー と その あいだ で、左手 の reach ≦ 0.98（§4.3.1 の 表） | 最大 0.88 ○ |

- かた の 骨 は 胴 の 中 に ある ので、うで を 内 へ よせると うで の 箱 が 胴 に 少し めりこむ。見て へん で なければ よい（オーナー確認）。大袖・よろい を 着れば かくれる。
- 体 を 直す とき（色ちがい・ほか の 見本）も C1〜C4 を 守る。守れない 体 を オーナー に 出す とき は「両手持ち が 小さく 見える」と 書く。

### 3.4 テクスチャ（ドット絵・くっきり）

| 項目 | 値 |
|---|---|
| 枚数 | 色ちがい 1 つ に つき **1 枚**（からだ・防具・さや・一人称 の 腕 を ぜんぶ 1 枚 に ならべる）。色ちがい は 同じ 張り方（UV）で 色 だけ ちがう |
| 大きさ | **はば 256 × 高さ 128 以下**（見こみ: 本体 約 5,700 ドット ＋ 防具 約 5,500 ＋ 一人称 の 腕 約 500 ＝ 約 12,000 ドット、すき間 を 入れて 約 15,000。256×128 ＝ 32,768 に 入る） |

### 4.2 層 と 時間 の きまり

- **時間**: 動き は ゲーム の ステップ で 決める。毎ステップ、動き の 時間 を「始めて から の F ÷ 60」に **決めて 入れる**（画面 の 時間 で 進めない）。`down`（たおれた 量 0〜1）と `bow_draw`（引いた 量 pull 0〜1）は 時間 で なく 量 で 位置 を 決める。同じ 入力・同じ ステップ なら 同じ 形。
- 動き の 0F = 始める 前 の 形。n F = WEAPON-2 の「F n」の 形。
- **層**: 上半身（`spine` から 上・うで）と 下半身（`hips`・あし・草摺）。
  - 止まって いる: かまえ・わざ・弓 は 全身（足 の 前後・ひざ も WEAPON-2 どおり）。
  - 歩いて・走って いる: 足 は 歩く／走る、上半身 は かまえ・わざ・弓・ほる など。
  - 大げさ斬り の 硬直 中 は 全身（動けない）。
  - 優先 は 今と 同じ: down 6 > hurt 5 > うで 4・3 > jump・land 3 > walk 2 > idle 1。
- **あと から 合わせる 所**（動き の データ の あと、毎ステップ 計算 で 直す）:
  1. **左手（刀）**: 刀 を 持つ とき、左うで は **2 本 の 骨（上うで・下うで）の IK** で 左手 を 刀 の「左手 の にぎり 点」に 合わせる。ひじ は 外・下 向き に 曲げる。かまえ・かまえ変え・わざ の 全 F。
  2. **右手（弓）**: 弓 を 引く とき、右うで は 同じ IK で 右手 を「つる の 引いた 点」に 合わせる。ひじ は 外・後ろ 向き（段 3 で ひじ が 後ろ へ 出る）。
  3. **突き の 上下**: 突き の 持続（F5〜6）と その 前後 の うつり で、`chest` を 照準 の 上下（pitch）に 合わせて まわす（最大 ±45°。それ より 上・下 を 見て いる ときは ±45° で 止める）。むね ごと まわす ので 左手 の reach は かわらない。

  1. 箱 と 箱 が くっついて **見えない 面 を 消す**。
  2. 同じ 平面 で となり合う 面 を **1 枚 に まとめる**（色 は テクスチャ に ある ので、似た 色 でも まとめて よい）。
  3. くわがた・つか の **段々 を 細い 板 数 枚** に して、段々 は テクスチャ で 描く。
  4. 一人称 の 腕 を 本体 の 腕 と 同じ 形 に して 使いまわす。
- 本当 の fps は オーナー の Mac で F3（オーナー確認）。

### 4.8 作り方（くらべて 決める）

| | ① Python で glTF を 直接 書く | ② bpy（Blender を Python で。pip の bpy 5.2.2、Python 3.13） |
|---|---|---|
| 箱 の 組み合わせ との 相性 | ◎ 箱 は 頂点 8・面 6 で 書ける。1 頂点 = 1 骨（重み 1）なので 重み の 計算 が いらない | ○ できる が、箱 の 組み合わせ には 重い |
| 動き | ○ §4.3 の 表 の 角度 を そのまま キー に 書く（自分 で 回転 を 計算） | ◎ Blender の しくみ で 作る |
| 入れる もの | ◎ Python の 標準 だけ（PNG も 標準 の 圧縮 で 書ける） | △ 数百 MB。クラウド で 書き出し まで 動く か 未確認 |
| 毎回 同じ もの | ◎ バイト まで 同じ に できる | ○ 名前・長さ・頂点数 は 同じ |
| まちがい やすさ | △ 骨 の 逆行列・データ の 並び を 自分 で 書く → 形式 チェック で 見つける | ◎ |
| オーナー の「Blender で」 | ○ 出来た GLB は Mac の Blender で 読み込んで 見られる | ◎ `.blend` を 開いて 直せる |

- **おすすめ: ① 直接 書く**（箱 の 組み合わせ・かたい 重み・表 から 作る 動き なので、重い 道具 が いらず、毎回 同じ もの が できる）。オーナー が「Blender で 開いて 直したい」なら ② に する（オーナー確認①）。
- どちら でも 最初 に **小さな ためし**（箱 2 こ ＋ 骨 2 本 ＋ 動き 1 つ ＋ テクスチャ を GLB に 書き、形式 チェック を 通し、Three.js で 読んで 動く）を して から 本番。
- **形式 チェック**: Khronos の glTF Validator（npm `gltf-validator`）で まちがい（error）0。作る 手順 に 入れる。
- 出来た GLB と テクスチャ は リポジトリ に 入れる（`npm run dev`・テスト は Python なし で 動く）。作る スクリプト と 文字 の 格子 も 入れる。
- Three.js では GLB を 読み込み、骨 付き の 形 と AnimationMixer で 動かす（§4.2 の とおり 時間 を 決めて 入れる）。

## 8. オーナー確認① で 見せる 要点

1. **見本 の 中上（みどり）を 基本 に**、色ちがい「むらさき・くろ・こん」。どれ を 基本 に するか（ほか の 見本 の 頭 に かえても よい）。
2. **4 頭身・背 64 ドット（1 ドット ≈ 0.028 ブロック）・1 ドット = 1 マス の 面**。顔 に まゆ と 大きな 目、着物 の えり と ひだ、よろい の 板 と ひも の 模様 まで ドット で 描く。
3. **防具 なし は 着物 と はかま だけ**。かぶと（金 の くわがた・顔 は 見える）／よろい（胴 と 草摺）／こて（大袖 と うで）／すねあて。
4. **こし の 刀 と さや**: 刀 を 持って いる ときだけ。手 に 持つ と さや だけ。
5. **両手持ち**: 右手 は 表 の 角度、左手 は 自動 で つか を にぎる。そのため 体 は「かた の 間 0.28・うで 0.52」、右うで は いつも 少し 内 へ よせる。大げさ斬り は「頭 の 上」から、切り上げ は ひじ を 少し 曲げて ふりあげる（どの とちゅう でも 左手 が とどく）。うで が 少し 胴 に めりこむ（よろい を 着れば 見えない）。
6. **一人称 の 腕 も この モデル の 腕**。
7. **作り方**: Python で 直接 書く（おすすめ。軽い・毎回 同じ）か、Blender を Python で 動かす（`.blend` を Mac で 開いて 直せる）か。
8. **性能**: 描画回数 は 今 の 約 20 → 6 以下。三角形 は 本体 2,000・防具 2,000 以下（模様 は テクスチャ）。
9. **走る 動き** は 作る が まだ 見えない。光 の 計算 なし（夜 に 暗く なる のは 今と 同じ）。
