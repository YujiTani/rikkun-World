# CHAR-1: プレイヤー の キャラモデル を オリジナル に（ドット絵風 の 現代風 お侍さん）（仕様書）

- タスク票: `docs/tickets/CHAR-1.md`（オーナー要望 2026-10-13 と 追加）
- 前提: **WEAPON-2 が `main` に 入った あと** に 作る。かまえ・わざ・弓 の 形 と 時間 は `docs/design/WEAPON-2.md` §3.1〜§3.3・§4.2（この 版 は `rikkun-weapons` の WEAPON-2 第 3 版 を 見て 書いた）。
- 今の 人形: `src/camera/BlockDoll.ts`（箱 の 人形・高さ 1.8・前 = −Z・原点 = 足もと）、`dollAnim.ts`（うで の 層 と からだ の 層）、`heldTools.ts`（持ち物 の 模型）、`dollArmor.ts`（防具）。
- 1 秒 = 60 ステップ。**F = 1 ステップ**。
- この 仕様 は 見た目 と 動き だけ。遊び の ルール・当たり判定・数値 は 変えない。画面 に 新しい 文字 は 出さない。
- 書いていない ことは 今のまま。

## 1. ねらい（りっくん が どう 楽しむか）

- 自分 の キャラ が **「ぼく の おさむらい」** に なる。マイクラ の 人 では なく、このゲーム だけ の 顔。
- **かっこいい・こわくない**: 大きな 丸い 目・にこっと した 口・はっきり した 色。血・きず・こわい 顔 は ない。
- 刀 を **両手 で しっかり にぎる**、弓 を **ひじ を 引いて ひきしぼる**。ひじ・ひざ・手首 が 曲がる ので、WEAPON-2 の かまえ・わざ が「ほんもの っぽく」見える。
- 見た目 は **ドット絵**（くっきり した 四角 の 点）。ブロック の 世界 から 少し ずれて よい（オーナー追加）。

## 2. 遊び方（プレイヤー から 見た 動き）

- 遊び方 は 何も かわらない。三人称（`V`）で 見える 人形 と、一人称 の 腕 の 見た目・動き が かわる。
- 背 の 高さ・当たり の 大きさ・目 の 高さ（カメラ）・歩く 速さ は 今のまま。
- 防具 を 着ると その 防具 が 人形 に 見える（今と 同じ）。持ち物 は 右手（ゆみ だけ 左手）に 持つ（今と 同じ）。

## 3. 画面・見た目

### 3.2 形（モデル）の きまり

- **ローポリ の 箱 の 組み合わせ**。1 部分 = 箱 1〜3 こ。ひじ・ひざ で 2 つ に 分かれた 箱（上 と 下）。つなぎ目 は 箱 を 少し 重ねて すき間 を 見せない（曲げても 中 が 見えない）。
- 1 つ の 頂点 は 1 つ の 骨 に だけ つく（かたい 部品。テクスチャ が のびない ので ドット が くずれない）。
- 原点 = 足もと の 中央、前 = −Z、上 = +Y、背 1.80（今の 人形 と 同じ）。
- かお・目 は テクスチャ に 描く（目 は 大きく、光 の 白 1 ドット。口 は にこっ）。まばたき は 今回 なし。
- 光 の 計算 は しない（今の 人形 と 同じ「色 そのまま」）。かげ は テクスチャ に こい 色 の ドット で 描く。むてき の 点滅（うすく なる）は 今と 同じ に できる こと。

### 3.3 テクスチャ（ドット絵・くっきり）

| 項目 | 値 |
|---|---|
| 枚数 | **1 枚**（からだ・防具・一人称 の 腕 を ぜんぶ 1 枚 に ならべる） |
| 大きさ | **128×128 以下** |
| 細かさ | **1 ドット = 1/32 ブロック**（頭 0.5 → 16 ドット）。全 部分 で 同じ 細かさ（ドット の 大きさ が そろう） |
| 見え方 | 近く で 見ても ぼやけない（ドット の さかい が くっきり。まぜて ならす 拡大 を しない）。遠く で ちらつき が 目立たない（オーナー確認） |
| 色 | §3.1 の 色 ＋ 各色 の こい かげ 1 色。ふち（りんかく）に 1 ドット の こい 色 |
| 透明 | 使わない（ぜんぶ 不透明。点滅 の うすさ だけ 別） |
| もと | §3.1 の ような「文字 の 格子」を 正 と し、そこ から 作る（直す とき は 文字 を 直す） |

- 細かさ を ブロック と 同じ 1/16 に する 案 も ある（もっと マイクラ っぽい・顔 が 8 ドット で 表情 が 出しにくい）。→ オーナー確認① で 聞く。

### 4.2 アニメーション（動き）の 一覧

**時間 の きまり**: 動き の 時間 は ゲーム の ステップ で 決める（同じ 入力・同じ ステップ なら 同じ 形。画面 の fps に よらない）。動き の 0F = 始める 前 の 形、n F の 形 = WEAPON-2 の「F n」の 形。

**層 の きまり**（今の「うで の 層・からだ の 層」と 同じ 考え）
- 上半身（`spine` から 上・うで）と 下半身（`hips`・あし）に 分ける。
- **止まって いる** とき: かまえ・わざ・弓 は 全身（足 の 前後・ひざ も WEAPON-2 どおり）。
- **歩いて・走って いる** とき: 足 は 歩く／走る、上半身 は かまえ・わざ・弓・ほる など。
- 大げさ斬り の 硬直（動けない）中 は 全身。
- やられる（たおれる）と よろめき（hurt）は いちばん 上（今の 優先 と 同じ: down 6 > hurt 5 > うで 4・3 > jump・land 3 > walk 2 > idle 1）。

#### WEAPON-2 の 時間表 と の 対応（キー に する F）

角度 は WEAPON-2 の 書き方（`rx` = うで を 前 へ 上げる 角度、`rz` = 外 向き が 正、刀 の 向き = みね の 線 の 水平 から の 角度）。**新しい 人形 では `rx`・`rz` を「かた から 手首 へ の 線」の 角度 と する**（ひじ が 曲がって も 意味 が かわらない）。

| 動き | キー F | うで（rx・rz） | 刀 の 向き | 足・からだ | ひじ（新） |
|---|---|---|---|---|---|
| 中段 | — | 50・−8 | +15° | 右足 前 +15°・左足 −15°・ひざ 10° | 両ひじ 30〜50° 曲げる |
| 上段 | — | 165・−5 | +135° | 左足 前・ひざ 10°・ひねり −10° | 両ひじ 40〜70° |
| 下段 | — | 25・−8 | −30° | 右足 前・ひざ 20°・前 へ 10° | 両ひじ 10〜30° |
| 突き | 0 / 4 / 6 / 7 / 14 | 50 → 42 → **88**（6〜7 そのまま）→ 50 | +15 → +5 → **0**（見る 上下 に 合わせる。むね を 最大 ±45° まわす）→ +15 | F6: 右足 +25°・からだ 前 15° | F6 で ほぼ のびる（10° 以下） |
| 大げさ斬り | 0 / 9 / 12 / 28 / 36 | 165・−5 → **178・+20** → **40・−35** →（28 まで そのまま）→ 165・−5 | +135 → +160 → **−40** → −40 → +135 | ひねり −10 → −25 → **+30**（F12 で 0.08 しずむ）→ +30 → −10 | F9 で 曲げる（60° 以上）→ F12 で のびる |
| 切り上げ | 0 / 5 / 8 / 18 | 25・−8 → 15・−30 → **150・+25** → 25・−8 | −30 → −55 → **+110** → −30 | ひねり 0 → +20 → **−20**、ひざ 20 → 25 → **5** → 20 | F5 で 曲げる → F8 で のびる |

| 弓 段 1 | pull 0.40 | 右 rz +15 | — | — | 右ひじ 60° |
| 弓 段 2 | pull 0.70 | 右 rz +25 | — | — | 右ひじ 90° |
| 弓 段 3 | pull 1.00 | 右手 が **ほお の 横**（rz +35） | — | ひねり −10° | 右ひじ **110° 以上**（ひじ が 後ろ へ 出る） |

- 弓 の ふるえ・しなり は 弓 の 模型 の 仕事（WEAPON-2 §3.3）。人形 は 右手 が **つる の 引いた 点** に いる こと だけ 守る。
- 「歩いて いる とき は 歩き の ゆれ を 足す」（WEAPON-2 §3.1）は 上 の 層 の きまり で 守る。

### 4.4 一人称 の 腕

- **このモデル の 腕 に する**（タスク票 の 問い へ の 答え）。そで の 色・手・こて は 三人称 と 同じ 見た目。
- 見える の は **ひじ から 先**（そで の 先・手・持ち物・こて）。頭・からだ は 出さない（今と 同じ）。
- 一人称 の 位置 と 動き は、今の 一人称 の 動き と WEAPON-2 §3.1〜§3.3 の 画面 の 位置（つか・剣先・引き手）を **そのまま 守る**。一人称 用 に 別 の 動き を 作って よい（三人称 の 動き を そのまま 使う 必要 は ない）。一人称 用 の 腕 の 形 は 同じ ファイル に 入れて よい。
- 刀 は **両手 が 見える**（中段: 右下 に 2 つ の こぶし が ならぶ）。上段 は 右上 に 両手。弓 は 左手 が 弓、右手 が つる。

### 4.6 作り方（どう やって モデル を 作るか）

| | ① bpy（Blender を Python で 動かす。pip の bpy 5.2.2、Python 3.13） | ② Python で glTF を 直接 書く |
|---|---|---|
| オーナー の「Blender で」 | ◎ そのまま。`.blend` も 出せる ので Mac の Blender で 開いて 見る・直す こと が できる | △ Blender を 使わない（GLB を Blender に 読み込む こと は できる） |
| 骨・重み・動き | ◎ Blender の しくみ で 作り、Blender の glTF 書き出し を 使う（形式 の まちがい が 少ない） | △ 骨 の 逆行列・重み・動き の データ を 自分 で 書く。まちがえやすい |
| 入れる もの | △ 大きい（数百 MB）。Python 3.13 が 要る。クラウド で ちゃんと 動くか まだ 分からない | ◎ 小さい（標準 ＋ 画像 を 書く 道具 くらい） |
| 毎回 同じ もの が できるか | ○（名前・長さ・頂点数 は 同じ。ファイル の バイト は ちがう ことが ある） | ◎ |
| ドット絵 テクスチャ | どちら も「文字 の 格子 → PNG」を Python で 作る（同じ） | 同じ |

- **おすすめ: ① bpy**。ただし **最初 に 小さな ためし**（箱 2 こ ＋ 骨 2 本 ＋ 動き 1 つ を GLB に 書き出し、Three.js で 読んで 動く か）を する。ためし が だめ なら ② に 切りかえる（どちら でも 出来上がり の GLB の 約束〈骨・動き・部品 の 名前〉は 同じ）。
- 出来た GLB は リポジトリ に 入れる（`npm run dev`・テスト は Python なし で 動く）。作る スクリプト と 文字 の 格子 も 入れる（作り直せる ように）。
- 出来た GLB は glTF の 形式 チェック を 通す（まちがい 0）。
- Three.js では GLB を 読み込み、骨 付き の 形 と 動き の まぜ合わせ（AnimationMixer）で 動かす（タスク票 どおり）。こまかい 作り は 開発 が 決める。
