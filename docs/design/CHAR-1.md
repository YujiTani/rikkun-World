## 1. ねらい（りっくん が どう 楽しむか）

- 自分 の キャラ が **「ぼく の おさむらい」** に なる。オーナー の 見本（9 体）の ような、**小さな 箱 を 組み合わせた ボクセル の 体** と **ドット絵 の 表面**。**5 頭身** で 手足 が 長く、すらっと かっこいい。
- **うで と あし に 関節**: ひじ・手首・ひざ・足首 で 曲がる のが 見て 分かる。手 は にぎる／ひらく。マイクラ より 動き で いろいろ 表せる。
- **かっこいい・こわくない**: 四角い 顔 に 大きめ の 目、まゆ、にこっ と した 口。血・きず・こわい 面（めん）は ない。かぶと を かぶっても 顔 は 見える。
- 防具 を 着る ほど **よろい武者（むしゃ）** に なっていく。
- 刀 を **両手 で しっかり にぎる**（うで が 胴 に めりこまない）、弓 を **ひじ を 引いて ひきしぼる**。

## 2. 遊び方（プレイヤー から 見た 動き）

- 遊び方 は かわらない。三人称（`V`）の 人形 と 一人称 の 腕 の 見た目・動き が かわる。
- 背 の 高さ・当たり の 大きさ・目 の 高さ（カメラ）・歩く 速さ は 今のまま。
- 防具 を 着ると その 部分 が よろい に なる（§4.5）。何も 着て いない ときは **着物 と はかま だけ**。
- 持ち物 に 刀 が あると **こし に 刀 と さや** が 見える（§4.6）。

## 3. 画面・見た目

### 3.1 基本 の 1 体 と 色ちがい

- **基本 = 「こん」（オーナー決定、見本 右中 の 色）**: 茶色 の かみ・頭 の 後ろ 上 に まげ（オレンジ の ひも）・こん の 着物（白い えり・中 は 黒）・むらさき の はかま・オレンジ茶 の 帯 と むすび目・黒い ブーツ に ひも。防具 を 着ると こげ茶 の 板 に 金 の ふち と ひも（おどし）。
- **色ちがい**（形 は 同じ、色 だけ ちがう。§3.5）: 「みどり」（見本 中上）・「むらさき」（見本 左上）・「くろ」（見本 右上）。ゲーム の 中 で 色 を えらぶ しくみ は 今回 作らない（あとで 作れる よう、色ちがい は 同じ 形・同じ 張り方 で 色 だけ 差しかえ できる こと）。
- 見本 の ほか の 頭（ツンツン頭 など）に かえても、**からだ の 寸法（§3.3）は 同じ** に する。

### 3.2 格子（ドット の 形 と 色）

- **背 1.80 ブロック = 64 ドット**。**1 マス = 1 ドット ≈ 0.028 ブロック**（1.8 ÷ 64 = 0.028125）。正面 は 64×64 の マス に 入る（はば は 36 マス だけ 使う）。`.` = 何も ない。横 は **左 が 前**（はば 24 マス）。
- **5 頭身**: 頭（かみ の 上 〜 あご）**12 マス**（04〜15 行、はば 12）、からだ（くび 〜 足 の うら）**48 マス**（16〜63 行）。頭 1 : からだ 4。**まげ（00〜03 行）は 頭 に 入れない**。
- かぶと の くわがた は 背 の 上 に はみ出る（行番号 −8〜−1）。
- テクスチャ は 1 マス の 面 = 1 ドット（§3.4）なので、格子 が ほぼ そのまま 表面 の ドット絵 に なる。
- 行 の 書き方: `NN <正面 36 マス>     <横 24 マス>`（防具 あり は 正面 だけ）。
- 色 は 基本「こん」。記号 は 色 の 表（下）。

### 4.2 層 と 時間 の きまり

- **時間**: 動き は ゲーム の ステップ で 決める。毎ステップ、動き の 時間 を「始めて から の F ÷ 60」に **決めて 入れる**（画面 の 時間 で 進めない）。`down`（たおれた 量）と `bow_draw`（引いた 量 pull）は 量 で 位置 を 決める。同じ 入力・同じ ステップ なら 同じ 形。

- **層**: 上半身（`spine` から 上・うで）と 下半身（`hips`・あし・草摺）。
  - 止まって いる: かまえ・わざ・弓 は 全身（足 の 前後・ひざ も）。

### 4.4 一人称 の 腕

- **このモデル の 腕 に する**（オーナー OK）。着物 の そで・手・指・こて（着て いれば）が 三人称 と 同じ 見た目。見える の は **ひじ から 先**（ひじ の 箱・下うで・手・指）。頭・からだ・大袖 は 出さない。

- 刀 は 両手 が 見える（左手 も IK で つか に つく）。弓 は 左手 が 弓、右手 が つる。

### 4.8 作り方（くらべて 決める）

| | ① Python で glTF を 直接 書く | ② bpy（Blender を Python で。pip の bpy 5.2.2、Python 3.13） |
|---|---|---|
| 箱 の 組み合わせ との 相性 | ◎ 箱 は 頂点 8・面 6 で 書ける。1 頂点 = 1 骨（重み 1）なので 重み の 計算 が いらない | ○ できる が、箱 の 組み合わせ には 重い |
| 動き | ○ §4.3 の 表 の 角度 を そのまま キー に 書く（自分 で 回転 を 計算） | ◎ Blender の しくみ で 作る |
| 入れる もの | ◎ Python の 標準 だけ（PNG も 標準 の 圧縮 で 書ける） | △ 数百 MB。クラウド で 書き出し まで 動く か 未確認 |
| 毎回 同じ もの | ◎ バイト まで 同じ に できる | ○ 名前・長さ・頂点数 は 同じ |
| まちがい やすさ | △ 骨 の 逆行列・データ の 並び を 自分 で 書く → 形式 チェック で 見つける | ◎ |
| オーナー の「Blender で」 | ○ 出来た GLB は Mac の Blender で 読み込んで 見られる | ◎ `.blend` を 開いて 直せる |

- **おすすめ: ① 直接 書く**。オーナー が「Blender で 開いて 直したい」なら ② に する（オーナー確認①）。
- どちら でも 最初 に **小さな ためし**（箱 2 こ ＋ 骨 2 本 ＋ 動き 1 つ ＋ テクスチャ を GLB に 書き、形式 チェック を 通し、Three.js で 読んで 動く）を して から 本番。
- **形式 チェック**: Khronos の glTF Validator（npm `gltf-validator`）で まちがい（error）0。
- 出来た GLB と テクスチャ は リポジトリ に 入れる（`npm run dev`・テスト は Python なし で 動く）。作る スクリプト と 文字 の 格子 も 入れる。
- Three.js では GLB を 読み込み、骨 付き の 形 と AnimationMixer で 動かす（§4.2 の とおり 時間 を 決めて 入れる）。

## 8. オーナー確認① で 見せる 要点

1. **基本 は 「こん」**（オーナー決定）。色ちがい「みどり・むらさき・くろ」は 形 が 同じ で 色 だけ。
2. **5 頭身・背 64 ドット（1 ドット ≈ 0.028 ブロック）**。頭 12 ドット、手足 が 長い。顔 に まゆ と 大きな 目、えり と ひだ、よろい の 板 と ひも まで ドット で 描く。
3. **うで と あし に 関節**: 上うで・ひじ・下うで・手・指、もも・ひざ・すね・足 が 別 の 箱。ひじ・ひざ に 小さな 箱 を 入れて 曲げても すき間 が 見えない。指 は にぎる／ひらく。歩く・ほる・たたく・なげる・弓・刀 で ひじ と ひざ を どう 曲げるか は §4.3.2 の 表。
4. **うで の めりこみ を なくした**: うで の 骨 は うで の 箱 の 中心 の まま（ずらさない）。かた の 間 0.39・うで 0.60 に して、ひじ を 外 へ はり、手 を まん中 へ よせる のは 下うで。どの わざ の とちゅう でも 左手 が とどく（reach 最大 0.89）し、うで が 胴 に 入らない（1 ドット まで）。そのため 下段 は 手 を 少し 前（rx 35）、大げさ斬り の ふりかぶり は 頭 の 上、切り上げ F5 は ひじ を はる。
5. **防具 なし は 着物 と はかま だけ**。かぶと（金 の くわがた・顔 は 見える）／よろい（胴 と 草摺）／こて（大袖 と うで）／すねあて。
6. **こし の 刀 と さや**: 刀 を 持って いる ときだけ。手 に 持つ と さや だけ。
7. **一人称 の 腕 も この モデル の 腕**（OK 済み。指 も 動く）。
8. **作り方**: Python で 直接 書く（おすすめ）か、Blender を Python で 動かす か。
9. **性能**: 描画回数 は 今 の 約 20 → 6 以下。関節 を 入れても 三角形 は 本体 約 720・防具 約 600（上限 2,000）。
10. **走る 動き** は 作る が まだ 見えない。光 の 計算 なし（夜 に 暗く なる のは 今と 同じ）。三人称 で 矢 が 人形 の 目 より 少し 上 から 出る（見て 気に なるか）。
