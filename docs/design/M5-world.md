# M5: 広（ひろ）い世界（せかい）（仕様書）

- タスク票: `docs/tickets/M5.md`（オーナーの決定 2026-10-12）
- もとの島の決まり: `docs/design/M1-01-world.md`（以下 M1-01）。この仕様書に書いていないことは M1-01 のまま（座標を +32 ずらして読む。§4-2）。

## 1. ねらい（りっくんがどう楽しむか）

- スタートはいつもの「おか」。北を向くと、いつもの岩山（いわやま）の向こうに **大きな やま** が見える。「あそこまで行ってみたい！」
- 西へ行くと木がいっぱいの **もり**、東へ行くと まっ平らな **ひらち** と **かわ**、南へ行くと ひろい **くさはら** と **いけ**。どっちへ行っても、ちがう景色（けしき）がある。
- やまに登ると、はだかの いし に せきたん・てつ が見えていて、ほりたくなる。
- ひらち（M7 で田んぼ・畑）と くさはら（M8 で動物）は、つぎの遊びの「場所」になる。
- 迷子（まいご）になりにくいように、場所は **いつも同じ方角**（やま=北、もり=西、ひらち=東、くさはら=南）にある。シードで変わるのは少しの位置と形だけ。

## 2. 遊び方（プレイヤーから見た動き）

1. 起動するとスタート地点（おかの真ん中）に立ち、北を向いている。前と同じ「こわれない たいまつ」が右前にある。
2. どの方角にも歩いて行ける。地面の段差はどこでも 1 段以下なので、ジャンプで必ず登れる（落ちて動けなくなる所がない）。
3. かわ・いけ・うみ は深さ 1 段。歩いて渡れる（おぼれない）。
4. 世界の端（はし）は今までと同じ「見えないかべ」。まわりはうみなので、ふつうは端まで行かない。
5. 遠くは かすみ でぼんやりする（§4-7）。
6. 前の世界の保存は使わない。はじめて起動すると新しい世界のスタートから始まる（§4-9）。子どもには何も出さない。

## 3. 画面・見た目

- 文字: 新しい文字は出さない。場所の名前（やま・もり・ひらち・かわ・いけ・くさはら・おか）は仕様書とテストの呼び名で、画面には出さない。
- 色・形: 新しいブロックは作らない（M1-01 §4-2 と M4 のブロックだけ）。場所の見分けは次でつける。

| 場所 | 見た目 |
|---|---|
| やま | 高い。上のほうは灰色（いし）で、黒い点（せきたん）・はだ色の点（てつ）が表面に見える。下のほうは くさ |
| もり | 木がぎっしり。はっぱの濃（こ）い緑 |
| ひらち | まっ平らな くさ。木が 1 本もない。わきに かわ |
| かわ・いけ | 青い みず。まわりは くさ（うみの近くだけ すな） |
| くさはら | ゆるい なだらかな くさ。木はほとんどない。真ん中あたりに いけ |
| おか | 今の島と同じ（平らなスタート・岩山・木） |

- 音: 新しい音はない。

| 項目 | 値（前 → 新） |
|---|---|

## 5. 例外のとき

- **かわを渡る**: みず は深さ 1 段なので歩ける（M1-02 の水の中の動き）。橋（はし）は作らない。ブロックを置いて橋にしてもよい。
- **やまの上から落ちる**: 段差 1 以下なので落ちる所はない。プレイヤーが掘って作った穴は今までどおり。
- **シードで決まりが守れないとき**: 位置・高さを幅の中で選び直してよい（同じシードなら同じ結果）。それでもだめなら開発係が数値の幅を調整し、変えた数を報告する。
- **古い保存**: §4-9。こわれた保存と同じ扱い。子どもには何も出さない。
- **ブラウザの保存がいっぱい**: 今までどおり保存せずに遊び続ける。

## デザイナーが決めたこと（オーナーに見せたい判断点）

1. **高さを 32 → 48 段** にした。やま を「高め」（頂上 h=22〜25。スタートより 10〜15 段高い）にしつつ、頂上の上にも 20 段以上 つみ上げる余地を残すため。
2. **方角を固定**（やま=北、もり=西、ひらち=東、くさはら=南）。6 歳が迷子になりにくい。シードでは少しずれるだけ。
3. **ひらち は みず の面と同じ高さ（h=7）**。M7 で「みず のとなりを田んぼにする」がそのままできる。
4. **段差はどこでも 1 段以下** のまま（やまにもがけを作らない）。落ちて痛い・登れなくて困る、がない。
5. **みず の深さはどこでも 1 段**（かわ・いけ もうみと同じ）。おぼれない・橋がなくても渡れる。
6. **新しいブロックは作らない**（雪・花などは無し）。場所は形と既存の色で見分ける。
7. 妖怪の出る距離は変えない。かわりに「64 より遠い妖怪は消える」を足した。
8. かすみ は 40〜80（前より少し近い）。描くのは 88 以内のチャンクだけ。
9. 古い保存は gen 2 で全部捨てる（gen の無い保存も）。
10. テスト用の場所は今と同じ北西のすみ（x,z=0〜12）。新しい世界でも必ずうみなので変えない。
