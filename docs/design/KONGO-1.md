## 1. ねらい
- 金の 次の「さいきょう」の そうび。ふかい 層で ダイヤを 見つけて、ぜんぶ ダイヤの そうびに する、という 長い 目標を 作る。
- はじめての ★6「ミラクル」の アイテム。しゅ色（#ff7a3d）の ほし・ふちで「金より すごい」が 字を 読まなくても 分かる。

## 2. 遊び方
1. 炭鉱の ふかい 層で ダイヤの 鉱石を ほる（MINE-1B。ほれる 道具の 段階は MINE-1B が 決める）→ アイテム「ダイヤ」が 手に 入る。
2. 作業台で 金の そうびと 同じ 作り方（きん → ダイヤ）で こんごうの そうびを 作る。
3. 使い方は 金・てつの 同じ 物と 同じ（かたな で たたく、ゆみ で や、つるはし・おの で ほる、防具 を きる）。特別な 力は ない。

### 4.3 強さ（数は 登録表 1 か所。単位つき 日本語コメント）
| id | たたく つよさ（ダメージ） | ほる（強さ・レベル） | たいきゅう（回） | ふせぐ（normal/ball/fall） |
|---|---|---|---|---|
| `kongo_katana` | **7**（金 5） | — | **1500** | — |
| `kongo_yumi` | や 段 1・2・3 = **3・4・7**（金 2・3・5） | — | **1500** | — |
| `kongo_pickaxe` | **6** | **8**・**最大**（下記） | **1500** | — |
| `kongo_axe` | **6** | **8**・0（金と 同じ 種類の きまり） | **1500** | — |
| `kongo_kabuto` | — | — | **1500** | 0/**4**/0（金 3） |
| `kongo_yoroi` | — | — | **1500** | **4**/0/0（金 3） |
| `kongo_kote` | — | — | **1500** | **3**/0/0（金 2） |
| `kongo_suneate` | — | — | **1500** | 0/0/**4**（金 3） |

- **つるはしの レベル = 全ブロックの いる 段階の 最大 以上、かつ ほかの つるはし（`kin_pickaxe`・てつ など）の レベル 以上**。今は てつ＝2 が いちばん 上なので 2（`kin_pickaxe` と 同じ。金との 差は ほる強さ 8 と たいきゅう）。MINE-1B が ダイヤの 鉱石に 3 を つけたら 3 に 上げる。数は 登録表に 1 か所で、2 つの 条件は ユニットテストが 表から 計算して 確かめる（数の 決めうち でなく。AC4）。

- 説明の 表の メーターの 最大は `src/craft/info/table.ts` の `STAT_MAX`（今 dig 6・damage 6・guard 5）。たたく 7 と ほる強さ 8 が こえるので **damage 8・dig 8 に 上げる**（guard 5 は 4 が 入る ので その まま。**PO 確認**）。受ける ダメージの 最低 1 の きまりは かわらない。妖怪の 強さは 変えない。

### 4.4 ★6（mythic）を はじめて 使う ことの 影響
今 `mythic` の アイテムは 0 こ。この 仕様で 9 こ に なる。
- **色**: `drops/rarityTable.ts` の 段 5（#ff7a3d・`flame`・「ミラクル」）を はじめて 画面で 使う。表は 変えない。ツールチップ・持ち物の ふち・光の 柱・`--rk-rarity-5`（tokens.css）が 正しく 出るか UI 検査で 見る（AC11）。
- **図鑑**: `ZUKAN_SHADOW_INDEX` は 6（★7 だけ 影）なので、★6 は ふつうに 名前と 絵が 出る。図鑑の めずらしさ ごとの 数・並びに ★6 の 行が はじめて 入る。0 この 段を 前提に した 表示・テストが あれば 直す（tester）。
- **件数の テスト**: 「全部で 何こ」を 決めうちに しない（ルール C、#311）。今 決めうちの 所（めずらしさの 当てはめの 数・`itemCategory.test.ts` の 全アイテム数・`content/__snapshots__` など）は 表から 数える 形に するか、+9 する（tester）。値の 写しは わざと 変えた ときだけ 更新（`npx vitest run -u src/content`）。
- **実績**: 「ほし 5」実績（`obtainRarity:epic`）は ★5 だけ なので こんごうでは とれない（GOLD-1 §10-8 と 同じ）。★6 の 実績は 作らない（決定に ない）。
- **ドロップの 数**: `dropMax.mythic` は 1（今の 表の まま）。

### 4.5 材料 ダイヤ と MINE-1B の 順番
- ダイヤの 鉱石と「ほると ダイヤ が 出る」は MINE-1B（#349）で 足す。本 仕様では 仮 id `diamond` と 呼ぶ。**id は 先に マージする ほうが 決め、あとの ほうが 合わせる**（同じ アイテムを 2 か所に 書かない。ルール #304）。
- **材料が まだ 手に 入らない 間も、装備 9 この 定義・レシピ・絵は 入る**:
  - KONGO-1 が 先なら: `diamond` の アイテム（名前・重ね 64・mythic・metal・説明・2D の 絵）は こんごう シリーズの 定義ファイルに 置く。説明の「どこで」は 鉱石が 入るまで 書かない（`noInfoOk` には 足さない。`use` だけ 書く）。MINE-1B は 鉱石の ブロックと ドロップだけ 足し、この アイテムを 使う。
  - MINE-1B が 先なら: そこで 入った ダイヤの アイテムを レシピで 使い、こんごう 側では 定義しない。名前・めずらしさ・絵が この 仕様と ちがえば その 差を PO に 上げる。
  - どちらでも、ダイヤ 0 この 間は 作業台の こんごうの カードは「たりない」の 今の 出し方。テスト・遊びは `give` で 確かめる。

## 5. 例外の とき
- ダイヤが たりない: 今の たりない 出し方（カードが うすい）。数は へらない。
- こわれた（たいきゅう 0）: 今の 道具・防具と 同じ（消える）。
- 古い セーブ: 新しい id が 無いだけ。読み込みは かわらない。
