## 1. ねらい（りっくん が どう 楽しむか）

- **むし を とる**: あみ を つくって き を パサッ と ふると、ときどき いもむし が ぴょん と とれる。「とれた！」。とれなくても 3 回 ふれば かならず 1 ぴき。
- **なかよく なる**: にわとり に むし を あげる と もぐもぐ、頭 の 上 の ハート が 1 つ うまる。すぐ には 2 ひき目 を たべない（おなかいっぱい の しるし）。少し まって また あげる。**3 回 で なかま**。はじめて の なかま は 紙ふぶき。
- **いっしょ に あるく**: なかま は とことこ ついてくる。頭 の 上 の あしあと が へって いき、なくなる と その場 で のんびり。また むし を あげる と ついてくる。「むし で なかよし が つづく」。
- **だっこ**: なかま を ぎゅっと だっこ して、すきな 所 へ つれていける。がけ の 上 から おろす と パタパタ ふわっ と おりる。
- **たまご**: なかま に むし を あげる と、ときどき しゃがんで たまご を ポン。たべる と ハート が もどる（LIVE-2 では あたためて ひよこ に）。
- **たたかない**: にわとり は たたけない（ねらい に 入らない）。かわり に だっこ できる。

## 2. 遊び方

### 2.1 であう（のこす）

（版 2 と 同じ。本文 を 書き写す）

- **出る 所**: その 列 の くに（`biome.at(x, z).kind`）が `harappa`（はらっぱ）か `hana`（はなばたけ）で、いちばん 上 の ブロック が くさ（`grass`）、その 上 2 マス が くうき、上 が ふさがって いない（空 が 見える）所。はじまり の 場所 は はらっぱ。
- **出る とき**: `day`（ひる）の あいだ だけ。`animalSpawnInterval`（600 ステップ）ごと に 1 回 ためす。プレイヤー から 水平 64 以内 の やせい が `animalWildMax`（3）わ より 少ない とき、水平 16〜40 マス の 場所 を 20 か所 まで さがして 1 わ 出す。シード 付き 乱数（妖怪・世界 と **別 の 流れ**。台帳 G5-4）。同じ シード・同じ 操作 なら 同じ 場所。
- **出かた**: 30 ステップ で ふわっと あらわれる。その あいだ は **ねらえない**（`target()` null・右クリック は うしろ へ 通る）。

- 消える: やせい は 水平 64 より とおく で 消える。ただし **ハート 1 以上 の やせい は 96**。y < −10 でも 消える。やせい は 保存 しない。
- 野原 に 出る の は **大人 の にわとり** だけ（ひよこ は 野原 に 出ない。LIVE-2 で たまご から）。

### 2.2 うろうろ・こっち を 見る・たたけない（のこす）

（版 2 と 同じ。本文 を 書き写す）

- **うろうろ**: 歩く（`animalWanderSpeed` 1.0 マス/秒、120〜300 ステップ）と 休む（120〜240 ステップ、地面 を つつく）を くり返す。1 段 は のぼれる、2 段 は のぼれない。3 マス より 深い 所 へ は おりない。みず に は 入らない。
- **こっち を 見る**: プレイヤー が 水平 `animalLookDist`（6）マス 以内 だと 歩く の を やめ、30 ステップ 以内 に 体 と 頭 を プレイヤー へ 向ける（`state` `'look'`・`lookingAtPlayer` true）。6 マス より はなれる と うろうろ に もどる。
- **たたけない**: 体力 が 無い。すで・つるはし・刀（かたな）・弓（ゆみ）・妖怪 の こうげき・火の玉・落ちる・みず の どれ でも へらない・たおれない・とばされない。左クリック・刀・や の ねらい に 入らない（うしろ の ブロック を ほる。ねらい補助 も えらばない）。プレイヤー・妖怪 と は ぶつからない（すりぬける）。妖怪 は にわとり を おいかけない。
- **ブロック と は ぶつかる**（上 に 立つ・かべ で 止まる）。にわとり の いる マス に も ブロック を 置ける。うまった にわとり は 次 の ステップ で 上 3 マス 以内 の あいた 所 へ 出る。無ければ なかま は プレイヤー の そば へ ワープ（§2.7）、やせい は そっと 消える。
- **ねらう 箱**: 横 0.8×0.8・高さ 1.0（体 より ひと回り 大きい）。目 から の 線（とどく 距離 5）が ブロック より 手前 で 当たる とき ねらって いる。

### 2.4 むしとりあみ と むし

- **つくる**: `mushi_ami`（むしとりあみ）= き（`log`）1・いと（`string`）2。つくる カード の いちばん うしろ。道具（`tool`）。1 マス に 1 本。**たいきゅう なし**（こわれない。6 歳 が なくして 泣かない）。左クリック では すで と 同じ。
- **ふる**: 0b の 条件 で 右クリック → あみ を ふる（20 ステップ: 上げる 4・ふる 6・とめる 10）。ねらった ブロック は こわれない。
- **とれる か**（ふった ステップ に きまる）:
  1. その き が **おやすみ**（ねらった ブロック から 水平 `bugTreeRadius`（4）マス 以内 で、`bugTreeCooldown`（1,800 ステップ = 30 秒）以内 に むし が とれた）→ **とれない**。合図 `treeEmpty`。はっぱ が ゆれる だけ。
  2. おやすみ で なければ、`bugChance`（1/3）で とれる。**`bugPity`（2）回 つづけて とれなかったら 次 は かならず**（= どの き でも 3 回 ふれば 1 ぴき）。つづけて の 数 は おやすみ の き を ふった 時 は 数えず、とれたら 0 に もどる（保存 しない）。乱数 は シード 付き（妖怪 と 別 の 流れ）。
- **とれた**: ふって 10 ステップ 目 に、ねらった ブロック の 面 から いもむし が ぴょん と とび出し、20 ステップ で プレイヤー へ とんで 持ち物 に 入る（つまり 押して **30 ステップ 目 に 持ち物 ＋1**）。持ち物 が いっぱい なら 足もと に おとしもの と して おちる（M3 の おとしもの と 同じ）。その 場所（ねらった ブロック）を おやすみ の 中心 に する。
- **とれなかった**: はっぱ が がさがさ ゆれて はっぱ の つぶ 4 つ。失敗 の 合図 は 出さない（くり返す 行動。fun.md §1）。
- `mushi`（むし）: 置けない。たべられない。上限 は やさい と 同じ。カテゴリー は たべもの で なく **「そだてる」の なかま**（たね と 同じ 所）。めずらしさ common。

### 2.5 むし を あげる・おなかいっぱい

- **にわとり を ねらって むし を 持って 右クリック**（やせい は 押した ステップ、なかま は はなした ステップ。この ステップ を 下 で「あげた ステップ」と よぶ）:
  - **おなかいっぱい で ない** → たべる。**むし 1 は あげた ステップ に へる**。ついばむ 30 ステップ。あげた ステップ から **おなかいっぱい `animalFullTicks`（600 ステップ = 10 秒）**。
    - やせい: ハート ＋1。3 つ目 を たべおわった ステップ（押して 30 目）に なかま（§2.6）。
    - なかま: ついてくる 時間 が **まんたん に もどる**（§2.7。とまって いた なかま も また ついてくる）。そして たまご の くじ（§2.10）。
    - 注（LIVE-2）: 小屋 の 子 は ついてくる 時間 を 使わない（むし で `follow` は 変わらない）。ひよこ は たまご の くじ を ひかない。くわしく は `docs/design/LIVE-2.md` §2.2・§2.4（台帳 G14）。
  - **おなかいっぱい** → たべない。**むし は へらない**。にわとり は おなか を ぽんと ふくらませて 首 を ふる（20 ステップ）、合図 `fullHint`（絵: まるい おなか の にわとり ＋ すなどけい）。
  - ついばんで いる あいだ（30）に 押して も 何も 起きない。
- **むし 以外**（やさい・すで・あみ・たまご・ブロック・道具 など）→ **なでる**（目 を ほそめて ふるふる 30 ステップ・ハート 1 つ・「コッ♪」。持って いる 物 は へらない・防具 も きない・ブロック も 置かない）。やせい を なでた とき は ハート は ふえず くび を かしげて「コッ」、合図 `feedHint`。**なでて も たまご は 出ない**。
- **なかま が いっぱい**（8 わ）: やせい の 3 つ目 の むし は たべない（むし へらない・ハート 2 の まま・おなかいっぱい に ならない）。合図 `friendFull`。
- おなかいっぱい は やせい・なかま どちら も。保存 しない（読み直す と 0）。

### 2.6 なかま に なる（のこす ＋ 1 つ）

（版 2 と 同じ。本文 を 書き写す）

- なかま に なる と 首 に **藍 の リボン**（結び目 が 体 の 右）が つき、頭 の 上 の ハート 3 つ は ぱっと はじけて 消える。
- **はじめて の なかま**（記録 `friend:*` が 0 → 1）: 大きく 祝う。ジャンプ 2 回（40 ステップ）、ハート はじけ 8（`burst`）、紙ふぶき（`confetti` 60 まで）、ファンファーレ `friendFirst`（BGM を 一時 もりあげて もどす）。実績 `animal.friend.1` は すぐ おめでとう画面。
- **2 わ目 から**: ジャンプ 1 回（20）、はじけ 5、オルゴール 3 音 `friend`。紙ふぶき なし。
- お祝い の あいだ（40／20）は 右クリック しても 何も 起きない。

- 足す: なかま に なった とき ついてくる 時間 は まんたん（18,000）。

## 5. 例外 の とき

- **持ち物 が いっぱい**: とれた むし・うんだ たまご は 足もと に おちる（10 分 で 消える）。
- **あみ で ねらった き を とちゅう で こわした**: ふった ステップ に きまる ので、とれた むし は そのまま とぶ。
- **人 が 置いた はっぱ・き**: 自然 の き と 同じ（ブロック の しゅるい だけ で 見る）。
- **だっこ 中 に みず に 入る**: そのまま（にわとり も ぬれない）。**だっこ 中 に 持ち物 が かわる**: 関係 ない。
- **だっこ 中 に 保存・ページ を とじる**: 足もと に いる（§4.4）。
- **だっこ 中 に なかま の 上限 が かわる**: 関係 ない（だっこ は なかま だけ）。
- **おろす 所 が 世界 の 外・読みこんで いない**: `cantPutHere`。
- **がけ の 下 へ おろす**: パタパタ で おりる。みず に 落ちたら うく。y < −10 なら ワープ（なかま は 消えない）。
- **`follow` 0 の なかま から とおく はなれた**: そこ に いる（読みこまれて いない 間 は うごかない）。もどれば いる。
- **夜**: なかま は ついてくる。むし は 夜 も とれる。たまご も うむ。やせい は 新しく 出ない。
- **妖怪 が そば**: にわとり は にげない・やられない。
- **プレイヤー が やられた**: だっこ は その場 に おろす。`follow` > 0 の なかま は 生き返った 所 へ ワープ。
- **ゲーム が 止まって いる・画面 を 開いて いる**: にわとり も 時間 も 止まる。
