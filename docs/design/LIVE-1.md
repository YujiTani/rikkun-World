- issue: #65（優先度:3 畜産・オーナー要望）／タスク票: `docs/tickets/LIVE-1.md`／全体 の あらすじ: `/mnt/project-files/livestock/PLAN.md`

- 1 秒 = 60 ステップ。「1 日（にち）」= `time.day()` が 1 ふえる まで（今 91,800 ステップ。あさ の はじめ〈`dayTick` 0〉で ふえる）。
- 画面 の 文字 は ひらがな・カタカナ。漢字 は `ruby()` の ふりがな つき。操作 の 案内 は **絵 が 先**（M7 の 照準 の 下 の 絵 と 1 語 を 使い回す）。

## 1. ねらい（りっくん が どう 楽しむか）

- **であう**: はらっぱ を 歩いて いると「コッコッ」と 声 が して、にわとり が うろうろ して いる。近づくと くるっと こっち を 見る。
- **なかよく なる**: はたけ で そだてた やさい を 持って 右（みぎ）クリック で あげる と、もぐもぐ たべて ハート が 1 つ ふえる（頭 の 上 の ハート 3 つ が 1 つずつ 色 で うまる）。**3 回 で「なかま」**。はじめて の なかま は 紙ふぶき と ファンファーレ で 大きく お祝い。
- **ついてくる**: なかま は りっくん の うしろ を とことこ ついてくる。とおく に はなれても、ポン と そば に 来る。「ぼく の にわとり」。
- **まいにち の おくりもの**: なかま を なでる と、1 日 1 回 たまご を ポン と 足もと に おとす。たまご は たべる と ハート が もどる。「そだてた やさい で そだてる」が つながる。
- **たたかない・肉 に しない**: にわとり は たたけない（こうげき は すりぬける）・こわれない。なかよく なる だけ の 遊び（PLAN §1）。

## 2. 遊び方（プレイヤー から 見た 動き）

### 2.1 であう（やせい の にわとり が 出る）

- **出る 所**: その 列 の くに（`biome.at(x, z).kind`）が **`harappa`（はらっぱ）か `hana`（はなばたけ）** で、いちばん 上 の ブロック が **くさ**（`grass`）、その 上 2 マス が くうき、上 が ふさがって いない（妖怪 の「くらい 所」の しらべかた と 同じ。空 が 見える）所。はじまり の 場所 は はらっぱ なので、さいしょ から 近く に 出る。
- **出る とき**: 時刻 が **ひる（`day`）の あいだ だけ**。`animalSpawnInterval`（600 ステップ = 10 秒）ごと に 1 回 ためす。プレイヤー から 水平 64 マス 以内 の やせい が `animalWildMax`（3）わ より 少ない とき、プレイヤー から 水平 16〜40 マス の 場所 を 20 か所 まで さがして、見つかった ら 1 わ 出す。乱数 は 世界 の シード から 作る（同じ シード・同じ 操作 なら 同じ 場所）。
- **出かた**: 30 ステップ で ふわっと あらわれる（妖怪 と 同じ 長さ）。16 マス 以上 はなれた 所 なので、目 の 前 に いきなり は 出ない。
- **消える**: やせい は プレイヤー から 水平 64 マス より とおく なる と そっと 消える（妖怪 の `farRemoveDist` と 同じ）。世界 の 下（y < −10）に 落ちても 消える。**やせい は 保存 しない**（ページ を 開き直す と いない。ハート の とちゅう も 消える）。
- よる・ゆうがた・あさがた は 新しく 出ない が、もう いる やせい は そのまま（ねる 動き は LIVE-2 以降）。

### 2.2 うろうろ・こっち を 見る

- やせい は **歩く**（`animalWanderSpeed` 1.0 マス/秒、120〜300 ステップ）と **休む**（120〜240 ステップ、地面 を つつく など）を くり返す。
- **1 段 は のぼれる**、2 段 は のぼれない。3 マス より 深い 所 へ は おりない。**みず に は 入らない**（うろうろ では よける）。
- **こっち を 見る**: プレイヤー が 水平 `animalLookDist`（6）マス 以内 に いる と、歩く の を やめて 体 と 頭 を プレイヤー へ 向ける（30 ステップ 以内）。6 マス より はなれる と うろうろ に もどる。止まって くれる ので、やさい を あげやすい。

### 2.3 たたけない・すりぬける

- にわとり に は **体力 が 無い**。すで・つるはし・刀（かたな）・弓（ゆみ）・妖怪 の こうげき・火の玉・落ちる・みず、どれ でも へらない・たおれない・とばされない。
- 左（ひだり）クリック・刀・や の **ねらい に 入らない**（にわとり が いない の と 同じ。うしろ の ブロック を ほる。ねらい補助 も えらばない。妖怪 の ふちどり も 付かない）。
- プレイヤー・妖怪 と は ぶつからない（すりぬける）。妖怪 は にわとり を おいかけない・こうげき しない。
- ブロック と は ぶつかる（上 に 立つ・かべ で 止まる）。にわとり の いる マス に も ブロック を 置ける。うまった にわとり は 次 の ステップ で 上 3 マス 以内 の あいた 所 へ 出る。無ければ、なかま は プレイヤー の そば へ ワープ（§2.6）、やせい は そっと 消える。

### 2.4 やさい を あげる（なかよく なる）

- **にわとり を ねらって 右クリック**（押した 瞬間 だけ）。ねらう の は 目 から の 線（M2 の とどく 距離 5）が、ブロック に 当たる より 手前 で にわとり の **ねらう 箱**（横 0.8×0.8・高さ 1.0。体 より ひと回り 大きい。6 歳 が ねらいやすい ように）に 当たる とき。
- **やさい（たまねぎ・トマト・かぼちゃ・なす）を 持って いる** と **あげる**:
  - やさい が 1 こ へり、にわとり が もぐもぐ ついばむ（`animalReactTicks` 30 ステップ）。ハート が 1 つ のぼり、頭 の 上 の しるし（§3.3）の ハート が 1 つ うまる。
  - やせい の ハート は 0 → 1 → 2 → **3 で なかま**。3 つ目 を たべおわった ステップ（押して 30 ステップ 目）に なかま に なる（§2.5）。
  - ついばんで いる あいだ（30 ステップ）に 押しても 何も 起きない（やさい も へらない）。
- **やさい 以外 を 持って いる**（すで・たね・たまご・ブロック・道具・防具・じょうろ・バケツ など）と **なでる**（§2.7）。やせい は なでても ハート は ふえず、くびを かしげて「コッ」と 鳴き、合図 `feedHint`「やさい を もって 右（みぎ）クリック で あげよう」が 出る（失敗 は「おしい」で 返す。fun.md §4）。
- **なかま が いっぱい**（`animalFriendMax` 8 わ）の とき、やせい は 2 つ目 の ハート まで は ふつう に たべる が、3 つ目 に なる やさい は たべない（やさい は へらない・ハート 2 の まま）。合図 `friendFull`「なかま は 8 わ まで」。

### 2.5 なかま に なる（お祝い）

- なかま に なる と、首 に **なかま の しるし**（リボン など。形 で 分かる もの。§3.2）が つき、頭 の 上 の ハート 3 つ は ぱっと はじけて 消える。
- **はじめて の なかま**（記録 `friend:*` が 0 → 1）: **大きく 祝う**（fun.md §2）。にわとり が 2 回 ジャンプ（40 ステップ）、ハート 8 つ が まわり に はじける、**紙ふぶき**、短い ファンファーレ（BGM を 一時 もりあげて もどす）。実績「はじめて なかま が できた！」は 小さく しない → すぐ おめでとう画面。
- **2 わ目 から**: 中くらい。ジャンプ 1 回（20 ステップ）、ハート 5 つ、短い よろこび の 音（オルゴール 3 音）。紙ふぶき なし。
- お祝い の あいだ（40 / 20 ステップ）は 右クリック しても 何も 起きない。

### 2.6 ついてくる

- なかま は プレイヤー から 水平 **`animalFollowStart`（4）マス より はなれる と 歩きだし**、**`animalFollowStop`（2.5）マス 以内 で 止まる**。速さ は `animalFollowSpeed`（4.0 マス/秒 = プレイヤー の 歩く 速さ）。走る と 少しずつ はなれる。
- 1 段 は のぼる・2 段 は のぼれない。おりる 深さ に 上限 は 無い（落ちても へらない。羽 を ぱたぱた）。みず に 入ったら うかんで 半分 の 速さ で 進む。
- **ワープ**（ポン と そば に 来る）: 次 の どれか で、プレイヤー から 水平 2〜3 マス・プレイヤー の 足 の 高さ ±1 の、下 が 固い ブロック・その マス が くうき（みず でも よい）の 所 へ 一瞬 で 来る。けむり の ポフ と 小さな 音。
  1. 水平 `animalWarpDist`（16）マス より はなれた、または 高さ の 差 が 6 マス より 大きい。
  2. 4 マス より はなれて いて、`animalStuckTicks`（120）ステップ の あいだ 0.5 マス も 近づけ なかった（かべ・2 段 の 段差 など）。
  3. うまった（§2.3）・世界 の 下 に 落ちた。
  - 来られる 所 が 無い とき（せまい 穴 の 中・海 の まん中 など）は その まま 待ち、60 ステップ ごと に さがし直す。
- 止まって いる なかま どうし は 中心 が 0.5 マス 以上 はなれる（重ならない。プレイヤー の まわり に ならぶ）。
- 「まってて」（その場 で 待つ）は LIVE-1 に 入れない（すむ所 と いっしょ に LIVE-2 以降）。
- なかま は 消えない（どれ だけ はなれても ワープ で もどる。プレイヤー が やられても、生き返った 所 へ ワープ）。

### 2.7 なでる と たまご（1 日 1 回）

- **なかま を ねらって 右クリック**（やさい 以外 を 持って いる とき）→ **なでる**: 目 を ほそめて ふるふる（30 ステップ）、ハート 1 つ、「コッ♪」。
- **なかま に やさい を あげる**: その 日 の たまご が まだ なら たべる（やさい 1 へる。30 ステップ）。もう たまご を くれた 日 なら **たべない**（やさい は へらない）で、なでる と 同じ に なる。
- **たまご**: なでた・たべた とき、その なかま が **今日（`time.day()`）まだ たまご を くれて いなければ**、押した ステップ から **60 ステップ 目**（`animalEggDelay`。ふるふる 30 → しゃがんで ポン 30）に、足もと に たまご 1 こ を おとす。
  - たまご は ふつう の おとしもの（M3・M6 の 落ちた アイテム と 同じ。近づくと ひろう・10 分 で 消える・保存 される）。はねる 速さ は 小さく（足もと から 横 1 マス 以内 に 止まる）。
  - 今日 もう くれた なかま を なでる と、ハート 1 つ と「コッ」だけ。合図 `eggLater`「たまご は また あした」。
  - 「今日」は `time.day()`。あさ（1 日 の はじめ）に なると また くれる。なかま ごと に 別 に 数える（8 わ なら 1 日 8 こ まで）。
- たまご を くれる 動き の あいだ（60 ステップ）は、その なかま へ の 右クリック は 何も 起きない。

### 2.8 たまご を たべる

- **たまご**（`egg`）を 持って 右クリック → 1 こ たべて ハート 1 こ（体力 `animalEggHeal` 2）もどる。M7 §2.6 の たべる と 同じ（押した 瞬間 だけ・体力 まんたん なら たべず 合図 `full`・「もぐもぐ」）。
- ねらい が にわとり の とき は §2.9 の 0 が 先（なでる）。

### 2.9 右クリック の ふりわけ（M7-2 §2.4〈と BUCKET-1〉の 上 に 0 を 足す。9 を ひろげる）

| 順 | 条件 | すること | 押しかた |
|---|---|---|---|
| **0** | **にわとり を ねらって いる**（線 が ブロック より 手前 で ねらう 箱 に 当たる） | やさい を 持つ: **あげる**（§2.4。なかま で 今日 もう たまご なら なでる）／ほか: **なでる**（§2.7。やせい は 合図 `feedHint`） | 瞬間 |
| 1〜8 | 今まで どおり（たんす・かまど・防具・バケツ・じょうろ・作物 を なでる・たがやす・まく・合図） | 今まで どおり | 今まで どおり |
| 9 | やさい **か たまご** を 持って いる | たべる | 瞬間 |
| 10 | 置ける もの | 置く | 瞬間＋30 |

- 0 が いちばん 先 なので、にわとり の うしろ の たんす・作物 は ひらかない・なでない。防具 を 持って にわとり を ねらうと きない で なでる。
- 押しつづけ の くりかえし の ステップ では 0 を しない（ほか の 段 へ も 進まない。にわとり の うしろ に ブロック が 置かれない）。
- 実行 と 照準 の 下 の 案内（`previewRightClick`）は 同じ 判定 を 使う（M7 の まま）。
- 左クリック は 今まで どおり（にわとり は ねらい に 入らない。§2.3）。

## 5. 例外 の とき

- **持ち物 が いっぱい で たまご が 出た**: 地面 に のこる（10 分 で 消える）。あいたら ひろえる。
- **たまご が みず・がけ に 落ちた**: 落ちた アイテム の きまり の まま（うく・落ちる）。
- **夜**: なかま は ついてくる・たまご も くれる（1 日 1 回 の まま）。やせい は 新しく 出ない。
- **妖怪 が そば に いる**: にわとり は にげない・こわがらない・やられない。
- **プレイヤー が やられた**: なかま は 消えない。生き返った 所 へ ワープ（はなれた ので）。持ち物 の たまご は ほか の 持ち物 と 同じ（M3 §2.8）。
- **プレイヤー が 走って とおく へ**: 16 マス で ワープ。
- **せまい 所（1 マス の 穴・トンネル）**: 来られる 所 が 無ければ 待つ。トンネル で は 1 列 に ならんで よい（重ならない 0.5 は 守る）。
- **読みこんで いない 列 に いる**: うごかない（時間 だけ 進む）。なかま は ワープ で そば に もどる。
- **ゲーム が 止まって いる・画面 を 開いて いる**: にわとり も 止まる（ほか と 同じ）。
- **なかま に たまご を もらう 動き の とちゅう で 保存・開き直し**: たまご は 出ない が `eggDay` は 押した 時 に 今日 に なって いる（1 日 1 回 を こえない。小さな 損 は 気に しない）。
- **にわとり を ねらって 押しつづけ**: 押した 瞬間 だけ。うしろ に ブロック は 置かれない。

## 8. デザイナー が 決めた こと（オーナー確認① で 見せる 要点）

1. **出る 所**: くに が はらっぱ・はなばたけ の くさ の 上、ひる だけ、10 秒 に 1 回 ためして 近く に 3 わ まで。やせい は 保存 しない。
2. **たたけない** は「ねらい に 入らない・ぶつからない」に した（左クリック は うしろ の ブロック を ほる）。
3. **あげる**: やさい 3 こ で なかま（どの やさい も 1）。やさい 以外 で 押す と なでる（やせい は「やさい を あげよう」の 合図）。
4. **なかま の 上限 8 わ**（性能 と 画面 の にぎやかさ の ため。タスク票 に 無い 数）。
5. **ついてくる**: 4 マス で 歩きだし 2.5 で 止まる、16 マス か 近づけない 2 秒 で ポン と ワープ。「まってて」は 入れない。
6. **たまご**: なでる・えさ の あと 1 秒 で ポン。「1 日」は あさ で 切りかわる（`time.day()`）。今日 もう くれた なかま は やさい を たべない（むだ に しない）。
7. **右クリック**: にわとり を ねらって いる とき が いちばん 先（防具 を 持っていても なでる）。
8. **実績 12 こ**（§4.5）。`eat:*` に たまご を 入れず、「はじめて たまご を たべた！」を 別 に した。
