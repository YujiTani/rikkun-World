# BUCKET-1: バケツ（水を くんで 運び、畑の そばに 置く）（仕様書）

- タスク票: `docs/tickets/BUCKET-1.md`（issue #62）。土台: `docs/design/M7-2-farm.md`（以下「M7-2」）。**ここに 書いていない ことは M7・M7-2 の まま**。
- 画面の文字・1 秒 = 60 ステップ・案内は アイコン優先 は M7-2 の 頭書き と 同じ。#61（水が ないと 育たない）と セットで 使う。

## 1. ねらい
- かわ の 水を バケツで くんで、はなれた 畑の そばに **ざばっと 1 マスの 水を 置く** → まわりの 畑が こい色（しめった）に なり、作物が 育つ。「ぼくが 水を 引いてきた！」。じょうろ（1 回ずつ まく）と ちがい、**置いた 水は ずっと 畑を しめらせる**。
- くんだ所の 水は へらない（池や 海に 穴が あかない。6 歳が こまらない）。置いた 水から また くめる。

## 2. 遊び方
### 2.1 くむ・おく
- **つくる**（§4.2）→ `バケツ`（からっぽ）。
- **くむ**: バケツを 持って **水を ねらって 右クリック 1 回** → その マスの アイテムが `みずの バケツ` に かわる。「水を ねらう」は M7-2 §2.1 と 同じ線（とどく距離 5、目の マスの 水は 数えない、固いブロック・作物より 手前で `water` を 通る）。**水の マスは そのまま**。みずの バケツで くんでも 何も かわらない（じょうろ まんたん と 同じ ちゃぷん）。
- **おく**: みずの バケツを 持って ブロックを ねらって 右クリック → **ブロックを 置くのと 同じ マス**（ねらった面の 手前。M2）に `water` が 1 マス でき、`バケツ` に もどる。
- **置ける マス**（ぜんぶ 満たす）: いまが `air`（水・ほかの ブロック・世界の外 は ×）／プレイヤーの体と 重ならない（ふつうの ブロックと 同じ）／妖怪の 箱の所で ない（M3）／ねらった ブロックが 作物・やせいの やさい で ない（作物の上に 水が うかぶ まちがい を ふせぐ）。
- **水の上には 置けない**: 水を ねらう 線は いつも「くむ」に なる（4d が 先）。
- **まちがえて 置いた 水を けす**: その水の マスに ブロックを 置いて ほる（今の しくみ）。
- **くりかえし押し**（押しつづけ）は 何も しない。くむ・おく・合図 は 押した瞬間 だけ。
- バケツは こわれない（WEAPON-2 の `permanent`）。

### 2.2 右クリックの ふりわけ（M7-2 §2.4 の 4c の あとに 4d〜4g を 足す。ほかの 段は そのまま）
| 順 | 条件 | すること | 押しかた |
|---|---|---|---|
| 4d | バケツ（から・みず どちらも）を 持って、線が 水を 通る | **くむ**（から → みず。みず なら 何も かわらず ちゃぷん） | 瞬間 |
| 4e | みずの バケツ を 持って、§2.1 の 置ける マスが ある | **おく** | 瞬間 |
| 4f | バケツ（から）を 持っている（4d で ない。ねらいは 何でも・無くても） | **合図** `bucket` | 瞬間 |
| 4g | みずの バケツ を 持って、4d・4e で ない | ねらいが あれば 軽い「コン」だけ。無ければ 何も しない | 瞬間 |
- バケツを 持つときは 4d〜4g で おわり、5（なでる）〜10 には 進まない（じょうろ と 同じ 扱い）。たんす・かまど（1・2）は 先に ひらく。
- 実行 と 照準の下の 案内（`previewRightClick`）は 同じ 1 つの 判定（M7 の まま）。

### 4.2 レシピ（カード 29 まい目 = スプリンクラー の すぐ うしろ、たね 4 まい の 前）
| id | できるもの | 材料 |
|---|---|---|
| `bucket` | バケツ 1（から） | **てつの かたまり 3** |
- 釣り合い: 置いた 水は 横 4 以内（9×9）を ずっと しめらせ、水の 置き場で 1 マス 使う。スプリンクラー（てつ 4・いし 2、5×5、どこでも 動く）より 安く、ながい じょうろ（てつ 3・き 1）と 同じ くらい。1 つで 何度でも 使えるので 2 つ目は いらない。みずの バケツ は つくれない（くむ だけ）。

### 4.3 しめる（M7-2 §4.3 は かえない）
- 置いた 水は ふつうの `water`。① 水の そば（`farmWetRange` 4・y か y+1）に そのまま 入る → 置いて **60 ステップ 以内**（`farmWetRecheckTicks`）に そばの はたけが しめり、けして 60 ステップ 以内に（ほかの 水・②・③ が 無ければ）かわく。

### 4.5 保存
- **アイテム だけで すむ**: `ItemStack` は かえない（から・みず は id が ちがう）。置いた 水は 世界の ブロックとして 今まで どおり 保存。`SAVE_GEN`・`SAVE_VERSION`・`farm.v` は かえない。

## 5. 例外
- 持ち物 いっぱい: くむ・おく は 同じ マスの id が かわる だけ（あふれない）。たんす・すてる・やられて 落とす（M3 の 50%）・落とし物: ふつうの アイテムと 同じ。みずの バケツは みずの まま。
- 世界の外・上の はし・体の中・妖怪の 箱・作物・空（ねらい なし）: 置けない（4g）。たんす・かまど を ねらう: ひらく（1・2）。
- ねらいが とどかない（5 マス）: くめない・置けない。目が 水の 中: その マスは 数えない（M7-2 のまま）。
- 置いた 水の 上に ブロック → 水は きえて ブロック（M2 の 今の きまり）。はたけの 上に 水を 置く: その はたけ は しめるが 作物は まけない（上が くうき で ない）。
- よる・くらい所: しめる のは 時刻に 関係なし（そだつ のは M7 の まま）。
