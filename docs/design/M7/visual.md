# M7-01 デザイン仕様（フェーズ1: 畑の基本）

> ステータス: デザイン中（オーナー確認待ち）

## 1. 目的
畑を耕して種をまき、時間経過で作物が育って収穫できる。  
6歳の子でも「土を耕して、種をまいて、育つのを待つ」流れが直感的にわかるようにする。

## 2. ブロックの見た目

### たはた（耕した土）
- 普通の土より少し暗い茶色
- 表面に浅い筋（耕した跡）が入っている
- 湿ったたはたはさらに暗く、少し青みがかる

### 作物（4段階）
各野菜で色と形を変える。段階が進むごとに大きく・はっきりする。

| 野菜 | 色のイメージ | 0段階（芽） | 1段階 | 2段階 | 3段階（成熟） |
|------|--------------|-------------|-------|-------|----------------|
| たまねぎ | 白〜薄緑 | 小さな芽 | 葉が少し | 葉が広がる | 白い玉が見える |
| トマト | 赤 | 小さな芽 | 緑の葉 | 実が少し | 赤い実が目立つ |
| かぼちゃ | オレンジ | 小さな芽 | 葉 | 実が膨らむ | オレンジの実 |
| なす | 紫 | 小さな芽 | 葉 | 実が少し | 紫の実 |

- 作物は土の上に立つ薄い板（または小さな箱）として描く
- 成熟時は少し光る（キラキラはフェーズ2以降）

## 3. 操作の流れ

1. **耕す**  
   土または草の上を右クリック（くわを持っているとき、または素手）→ たはたになる

2. **種をまく**  
   種を持ってたはたを右クリック → 作物の0段階が植わる

3. **待つ**  
   時間が経つと自動で成長する。近くに水があると少し早く育つ

4. **収穫**  
   成熟した作物を左クリック → 作物と種が落ちる。たはたが残る

## 4. 種アイテム
- 見た目は小さな袋または種そのもの
- 名前はひらがな（「たまねぎのたね」など）
- ホットバーに入れて使える

## 5. 受け入れ基準
- [ ] 土を耕すとたはたになる
- [ ] たはたに種をまける
- [ ] 作物が4段階で育つ（見た目が変わる）
- [ ] 成熟した作物を壊すと収穫できる
- [ ] 近くに水があると土が湿る
- [ ] 野菜ごとに成長速度が違う
- [ ] 画面の文字はひらがな・カタカナ（漢字はルビ）

## 6. やらないこと（このフェーズ）
- ジョウロ・スプリンクラー・撫でる
- キッチン・料理
- 果物
- 複雑な演出
