# M7 農業・料理システム 実装計画

> ステータス: 計画中（2026-10-12）

## 1. 目的

6歳向けのマインクラフト風ゲームに、畑で野菜を育ててキッチンで料理を作るシステムを追加する。  
果物は木からのレアドロップとし、料理に入れるとバフが強化される。

## 2. 全体の論理構造

```
[世界]
  VoxelWorld
    ├─ たはた / 湿ったたはた
    ├─ 作物ブロック（4野菜 × 4段階）
    └─ スプリンクラー（設置型）

[農業システム]  src/farm/
  FarmSystem
    ├─ till()          耕す
    ├─ plant()         種をまく
    ├─ tick()          成長更新
    ├─ harvest()       収穫
    ├─ pet()           撫でる（ご機嫌）
    └─ water()         水やり

[調理システム]  src/craft/ または src/kitchen/（新規）
  KitchenStation / Oven
    ├─ 器具スロット（セットして使う）
    └─ レシピ判定 → 料理アイテム生成

[アイテム]
  種・作物・果物・調理器具・料理
```

## 3. フェーズ分け

| フェーズ | 内容 | 主なファイル |
|----------|------|--------------|
| 1 | 畑の基本（耕す・植える・成長・収穫） | `src/farm/`, `src/world/blocks/` |
| 2 | お世話（ジョウロ・スプリンクラー・撫でる） | `src/farm/` |
| 3 | 調理ステーション（キッチン・オーブン・器具セット） | `src/kitchen/`（新規） |
| 4 | パイ・ケーキとバフ | `src/kitchen/`, `src/combat/` or 新規 buff |
| 5 | 調整・演出・保存 | 全体 |

## 4. データ構造（案）

### 作物の状態
```ts
interface CropState {
  kind: 'onion' | 'tomato' | 'pumpkin' | 'eggplant';
  stage: 0 | 1 | 2 | 3;
  progress: number;   // 0〜1
  mood: number;       // 0〜100
}
```

### 調理ステーション
```ts
interface StationState {
  tools: (ItemId | null)[];  // セットされた器具
  // 材料は一時的にインベントリから消費
}
```

## 5. 既存システムとの接続点

- `DigSystem`: 右クリックで耕す／植える／収穫／撫でる／水やりを分岐
- `main.ts`: `FarmSystem.tick()` をゲームループに追加
- `Inventory`: 種・作物・果物・器具・料理を追加
- `save`: 作物の成長状態とステーションの器具を保存
- `contracts.ts`: 新しい BlockId / ItemId を追加

## 6. グラフエンジニアリングでの進め方

1. デザインループで見た目・操作の仕様を確定（オーナー確認①）
2. 開発ループで担当分けに沿って実装
3. テストループで受け入れ基準を検証
4. 必要に応じて性能最適化ループ

## 7. 注意点

- 文字はひらがな・カタカナ。漢字はルビ
- 乱数はシード付き
- 成長は固定ステップで進める（テストしやすく）
- フェーズをまたいだ機能を一度に入れない
