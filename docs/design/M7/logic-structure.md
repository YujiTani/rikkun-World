# M7 農業システム 論理構造メモ

> この資料はオーナーの元資料・最初の案。実装した決まりの正は M7-farm.md・M7-2-farm.md・BUCKET-1.md（ちがう所は仕様書が正。例: 耕すのは 3 回、作物は stageTicks）。果物・料理・バフ・季節などフェーズ 3 以降の案はここにだけある。

## 責務の分離

| モジュール | 責務 | 依存先 |
|------------|------|--------|
| `FarmSystem` | 成長ロジック・状態管理 | `VoxelWorld` |
| `KitchenSystem`（予定） | レシピ判定・料理生成 | `Inventory` |
| `DigSystem` | 入力の振り分け | `FarmSystem`, `Inventory` |
| `WorldRenderer` | ブロックの描画 | ブロック定義 |

## 成長の流れ

1. `tick(dt)` が呼ばれる
2. 各作物について水源 or スプリンクラーをチェック
3. ご機嫌ボーナスを加味して progress を加算
4. progress が 1 を超えたら stage を進め、ブロックを更新

## 収穫の流れ

1. 成熟（stage === 3）かチェック
2. ご機嫌が高い場合は追加ドロップ判定
3. 作物と種を返す
4. ブロックをたはたに戻す

## 拡張ポイント

- 新しい野菜は `CropKind` と成長時間を足すだけ
- 果物はドロップテーブルに追加
- バフは料理アイテム使用時に `PlayerCombat` または専用の BuffSystem で適用
