# FOOTSTEPS: 足音（issue #50 の ① だけ）

- 出どころ: #50「音のない行動が多い」（サウンド）。ゆず 2026-11-04: 足音 だけ 先に。ジャンプ・着地・泳ぐ・まわりの 音・妖怪の 音は やらない（#50 は のこす）。

## 1. 決めた こと
| こと | 決め |
|---|---|
| 1 歩の 数え方 | 明珍下駄（`src/craft/geta.ts`）の 数え方を 共用する: `striding()`（地面・水の 外・横の 速さ getaMinSpeed 1 以上）と `StepCounter`。下駄の 数え方は かわらない |
| 間かく | 歩く 24 ステップ（0.4 秒）・走る 18 ステップ（0.3 秒）に 1 歩（`FOOTSTEP_TUNING`）。足音は 地面の 判定が 1 ステップ ゆれても 数えを 0 に しない（下駄は 今どおり 0 に もどす） |
| 下駄 | 下駄を はいて 走る ときは 下駄の 音（ogg）だけ（とくべつな 音を そのまま）。下駄で 歩く・下駄なしは 地面の 足音 |
| 地面の 種類 | 足もと（足の 0.05 下）の ブロック → 表 `KIND_OF`（id の 直書き 比べ なし）: grass（草・はっぱ）・dirt（土・はたけ・ねんど）・sand・snow・wood（木・たんす・小屋の ゆか）・stone（ほか ぜんぶ） |
| 音 | `sfxVoices` の noise・sine で コードで 作る（音ファイル なし）。どの 部品も gain 0.07 以下（ほる 音より 小さい） |
| 鳴らない とき | 空中・止まって いる・水の 中・あそび 以外の 画面・やられた / ひるみ中 |
| あさい 水 | やらない（水の 中は 鳴らさない。泳ぐ 音と いっしょに あとで） |

## 2. 受け入れ
1. 種類の 表（unit）。2. 歩く 24・走る 18 ステップに 1 歩（unit）。3. 空中・止まる・水では 鳴らない（unit・E2E）。4. 小さい 音（unit）。5. 下駄で 走る ときは 足音を 鳴らさない（unit）。6. 2 秒 歩くと 3〜6 歩（E2E）。
