# WATERFALL-1: ずっと 流れる 滝（わきみず・たきつぼ）と マグマ（仕様書）

- オーナー（yuzu）の 方向: わきみず ＋ たきつぼ（わきみずの 水が 落ちた 所に 確率で たきつぼ）。滝エレベーター・泳ぎは 次の issue 候補。マグマは 水と 同じ しくみ（8 この 番号の 並び・下 3 ビットに 量）、おそい チック・みじかい 横の 広がり、水に ふれると 石／こくようせき、光る 絵と ゆっくりした ゆらめき。
- 土台: WATER-1（`docs/design/WATER-1.md`。有限の 水・起こす リスト・ビット詰め・ゆらめく 水面）。WATER-1 の きまり・数は かえない。
- 指摘台帳: `docs/loop-ledger/WATER-1.md` と 同じ 形で `docs/loop-ledger/WATERFALL-1.md`。

## 1. ねらい
- 高い 所に わきみずを 置くと 滝が できて、たきつぼが できたら **ずっと 流れつづける**（あふれない・かれない）。
- マグマは 水と 同じ 有限の 液体で、ゆっくり 流れ、水と 出会うと こくようせきに かたまる。

## 2. 遊び方
- **わきみず**（作業台: いし 4 ＋ すいしょう 1 → 1）: どこにでも 置ける 固い ブロック。0.25 秒ごとに 1 つぶ（量 1）の 水を 出す。出口は 下 → 北 → 東 → 南 → 西 の 入れる マス（WATER-1 の 「入れる」= air か 量 1〜7 の 水）。
- 水は WATER-1 の とおり 落ちて、床に たまる。**たきつぼが できる まで 少し たまる**。
- **たきつぼ**: わきみずの 出口から まっすぐ 下の 床（`takiReach` = 32 マス 以内）の 上に 水が ある とき、わきみずが 1 つぶ 出す ごとに 確率 `takiChance` = 0.05 で、その 床が たきつぼに かわる（シード つき）。
  - できた あと: わきみずは 毎回 **たきつぼの 真上の マス（から なら その 北・東・南・西）から 1 つぶ けして、同じ 1 つぶを 出口に 出す**。けす 水が なければ 出さない。出口が いっぱいなら けさない。だから 合計は かわらない（あふれない・かれない）。
  - 少なくとも 「列の 高さ ＋ 8」つぶ たまって から できる（§4.2 minPool）。
  - たきつぼを こわすと いし 1 こ。こわすと また ふえる 動き（確率で できる）に もどる。
- **つながり**（わきみず ↔ たきつぼ）は 保存しない。毎回 「出口の 真下の 床が たきつぼ か」で 決める。だから 自然生成でも 2 つの ブロックを その 位置に 置けば 動く（§5 の 範囲外の 生成も この きまりで 足せる）。
- **マグマの わきみず**（作業台: いし 4 ＋ せきたん 4 ＋ すいしょう 1 → 1）: 0.75 秒ごとに マグマを 1 つぶ。たきつぼは ない（ふえる だけ。たいらな 床では 半径 7 くらいで 止まる。穴・がけでは 下へ 流れる）。光る（12）。
- **マグマ**: 水と 同じ 3 つの きまり（落ちる → 低い 所 → ならす）で、おそく・せまく 流れる（§4.1）。
  - 水に ふれる（上下 北東南西）と その マグマの マスは **こくようせき** に なる（水は へらない・マグマは きえる）。
  - マグマの マスに ブロックを 置くと 水と 同じく 押し出される。
  - あぶない: 体（足もと か こし）が マグマに ふれて いると、はいった すぐに 1、そのあと 0.5 秒ごとに 1 の ダメージ（むてき中でも）。動きは 水と 同じだけ おそい。光る（12）。
- **こくようせき**: とても かたい（12。てつの つるはし から）。ほると 1 こ。置ける。作り方は ない。

## 3. 見た目
- 絵: `docs/art/waterfall-1/`（わきみず・たきつぼ・こくようせき・マグマの わきみず・マグマ。16×16 ドット）。アトラスの さいごに 7 まい 足す。
- マグマは 水の メッシュ（液体の 面）で 描く: 液面の 高さ = 量 ÷ 8、同じ 種類どうしで つながる。水と マグマの 間は 面を 描かない（となりは 固い 物と 同じ）。
- ゆらめき: 水の shader と 同じ uniform 1 つ。マグマの 液面の 頂点の 印は 0.6（はばが 0.6 倍）、印が 1 未満の 頂点は 時間を 0.35 倍（ゆっくり）。描画回数・三角形は ふえない。
- 光: マグマ・マグマの わきみず は EMISSION 12（ほたるいし 7・たいまつ 14 の 間）。

### 4.2 わきみず・たきつぼ（`SPRING_TUNING`）
| 項目 | 値 | 理由 |
|---|---|---|
| waterEvery | 15 ステップ | 水の パスと 同じ。1 パスで 1 マス 落ちるので、列が とぎれない 細い 滝に なる |
| magmaEvery | 45 ステップ | マグマの パスと 同じ |
| takiChance | 0.05 / 回 | 期待 20 回 = 5 秒 = 20 つぶ（量 8 の マス 2.5 こ ぶん）たまって から できる。「少し たまる」。99% で 90 回（約 23 秒・90 つぶ）以内 |
| minPool | 8 つぶ | たきつぼは わきみずが 「列の 高さ ＋ 8」つぶ 出す まで できない。まわる 水が 列を うめて 滝が とぎれない（列が とぎれる 形を さける ため。ゲームで 見て 足した） |
| takiReach | 32 マス | 出口の 真下を たどる 上限（毎回 たどるので 重さの 上限でも ある） |
| takiFloor | grass・dirt・stone・sand・snow・nendo・sekkaiseki・katame_tsuchi | 自然の 地面だけ（家・家具・鉱石・こくようせきは ならない） |
- 乱数: `springRoll(seed, わきみずの x, y, z, 回数)`（整数の まぜあわせ。Math.random を 使わない）。回数は わきみずごとに メモリで 数える（保存しない）。
- わきみずの 一覧: `setBlock` の フック（置いた・こわした）と、保存から 読んだ 列の 読みこみ（セクションの パレットに わきみずが ある 時だけ 見る）。生成の 列には わきみずは 無い。

### 4.3 液体の 芯（`src/world/water/liquidCore.ts`）
- WATER-1 の `waterSystem.ts` の 計算・起こす リスト・押し出し・読みこみを、液体の 種類で 使える 形に 出した。水の 動きは 1 マスも かえない（WATER-1 の ユニットが 全部 そのまま 緑）。
- **パスの 中の 順**: 取り出した マスを 下（y の 小さい）から 計算する（同じ 高さは リストの 順）。落ちる 列で 上の つぶが 下の つぶに 追いついて 3 つぶの かたまりに なり、滝が 点線に なる のを ふせぐ。WATER-1 の ユニット 69 本は そのまま 緑（形・パスの 数は かわらない）。
- `createWaterSystem` が 水 と マグマ の 芯 2 つ と わきみずを まとめる。`setBlock` の フックは 1 つ（まわり 6 マスを 1 回ずつ 読んで、水なら 水の リスト、マグマなら マグマの リスト）。
- マグマの 芯は 流れる 前に「水に ふれて いるか」を 見る（ふれて いれば こくようせき。押し出しは しない）。

### 4.5 あぶない 液体（既存の 仕様の 確認）
- 液体に ふれた ダメージの 仕様は 無かった（水は 泳ぐ・落下ダメージを けす だけ）。最小の きまりを §2 に 足した（1 / 0.5 秒・すぐ 1 回）。画面の 合図は 落下ダメージと 同じ `fallHurt`（赤い ふち・痛い 音）。妖怪は マグマで ダメージを 受けない（範囲外）。

## 5. 範囲外（次の issue 候補）
- 滝エレベーター（滝の 中で 上へ）: 泳ぎは WATER-1 §4.6 で もう ある（深い 水で 泳ぐ）。滝の 列は 量 1 の 水なので 泳ぎに ならない。上へ 運ぶ 力は 新しい 物理なので 次へ。
- 自然生成の 滝・マグマだまり: しくみは 2 つの ブロックを 置く だけで 動く（§2）。生成の 場所えらび（がけ・地下）は 世界の 見た目に かかわるので 次へ。
- マグマの バケツ・マグマの たきつぼ・マグマで 燃える／とける ブロック・妖怪への ダメージ。
