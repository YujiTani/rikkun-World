## 1. ねらい（りっくんがどう楽しむか）

- **刀**: 「かまえ」を かえると、出る **わざ** が かわる。かまえ を えらんで 戦う「さむらい ごっこ」。
  - **中段（ちゅうだん）→ 突（つ）き**: はやくて、とおくまで とどく。でも まっすぐ だけ なので ねらって 当てる。
  - **上段（じょうだん）→ 大（おお）げさ斬（ぎ）り**: 頭の上から ぶんっと ななめに ふりおろす。前が ぜんぶ 当たって いちばん 強い。でも ふったあと しばらく 動けない。
  - **下段（げだん）→ 切（き）り上（あ）げ**: 下から 上へ。高い所の 妖怪（ちょうちん・ろくろくび の 首）にも 当たる。妖怪が ふわっと うく。
- **弓**: ひだりクリック を **ながく おすほど 強く ひいて、とおくへ 山なりに とぶ**。いつも 同じだけ ひけば 同じ所に 落ちる。「もうちょっと 上を ねらおう」と 自分で 合わせる **ねらう 練習**。
- どちらも 血は 出ない。当たると 白い 星と「ポコーン」。

## 2. 遊び方（プレイヤーから見た動き）

### 2.1 刀（ぼくとう・かたな・きらきらの かたな。3 つとも 同じ かまえ・わざ。強さ だけ ちがう。ぼくとう は いちばん 弱い〈オーナー決定〉）

1. 刀を ホットバーで えらぶと、**両手で 持って 中段** に かまえる（毎回 中段から。ほかの物に 持ちかえて もどると 中段）。
2. **かまえ を かえる**: **`R` キー だけ**（オーナー決定。右クリック は 今のまま。§2.3）。押すごとに **中段 → 上段 → 下段 → 中段 …** と まわる。かえるのに 8F（§4.2）。
3. **わざ**: ひだりクリック で、今の かまえ の わざ が 出る（中段=突き、上段=大げさ斬り、下段=切り上げ）。
4. **おしつづける** と、わざ が おわるたびに 同じ わざ を くりかえす。
5. **先（さき）に 押しておける**（先行入力）: わざ の とちゅう（持続〜硬直の さいご 8F まで）に ひだりクリック や `R` を 押すと、おわった 次の ステップに それが 出る（1 つだけ おぼえる。あとから 押した方）。6 歳が 少し はやく 押しても 出る。
6. **ひだりクリック の ふりわけ**（オーナー決定: 刀 でも ほれる。PO 決定: **照準 の 線 で いちばん 手前 の 物 を 優先**。M7 §2.5 と 同じ）。押した ステップ に 照準 の 線 で、次の 3 つ の うち **いちばん 手前** に ある もの を 見る:
   - 妖怪（線 の **4.5 以内**）→ **わざ**。
   - みのった 作物・やせいの やさい（M7。M2 の とどく 距離 5 以内）→ **しゅうかく**（わざ は 出ない）。
   - ブロック（とどく 距離 5 以内）→ **ほる**（ほる 強さ・レベル は **すで と 同じ**。M2 の ひび・もういちど 押す も 同じ。うで は 刀 で ほる 動き〈今の `dig`〉）。
   - どれも ない → **わざ**（空振り。扇形 の わざ は 照準 に いない 妖怪 にも 当たる）。
   - 例: 妖怪 が 作物 より 手前 → たたく（わざ）。作物 が 妖怪 より 手前 → しゅうかく。
   - おしつづけ で ほっている とちゅう に 照準 に 妖怪 が 入ったら、次の ステップ から わざ（ほった 量 は M2 の きまり で へっていく）。わざ の とちゅう は ほらない。
7. わざ の あいだの 動き: §4.2 の「歩く速さ」。大げさ斬り の 硬直 24F は **動けない・ジャンプ できない**（オーナー指定「振り切って動けない」）。見る向き（マウス）は いつでも 動かせる（よわない ため）。

### 2.2 弓（ゆみ）

1. ゆみ を えらび、**ひだりクリック を 押しているあいだ ひく**（や が 1 本 以上 要る）。
2. ひいている 長さで **段（だん）** が 上がる（§4.4）。段は **ゆみ の しなり**（つる の 引き と 弓 の まがり。一人称 では 弓 を 引く 手 の 位置）と **段 ごと の 音** で 分かる（オーナー決定: 画面 の ゲージ は 出さない）。
3. **はなした** ときに 飛ぶ。段が 高いほど はやく とおくへ（山なり）。**段 0（ひきが たりない）で はなすと 飛ばない**（や は へらない。「ぽよん」）。
4. 段 3（いちばん 強い）まで ひいたら、はなすまで そのまま 待てる（ずっと 持てる）。
5. ひいている あいだ 歩く速さ 0.5 倍。持ちかえる と ひくのを やめる（や は へらない）。
6. 飛んだ や は **重力で 落ちる 放物線**（§4.4）。ブロックに ささった や は 30 秒 のこり、近づくと 拾える（§4.4）。
7. **落ちる 場所 の 目安（点線 など）は 出さない**（オーナー決定）。飛んだ や の 山なり を 見て、次 の ねらい を 自分で 合わせる。

### 2.3 キー（今の 割りあて と ならべて）

| 行動 | 今 | 新しく |
|---|---|---|
| ひだりクリック（`primary`） | ほる・たたく・ゆみ | 刀: §2.1 の 6 の ふりわけ（いちばん 手前 が 妖怪 → わざ、作物 → しゅうかく、ブロック → ほる、何も ない → わざ）。ゆみ: 押して ひく・はなして 飛ばす |
| 右クリック（`secondary`） | 置く・きる・ひらく・たがやす・まく・たべる。刀 を 持っているときは 何もしない（M4 §5） | **今のまま**（オーナー決定） |
| **`R`（新しい Action `stanceNext`）** | 使っていない | 刀: かまえ を かえる。刀 以外: 何もしない |

- **`R` を 選んだ理由**: 今 使っていない（W・A・S・D・Space・V・F3・1〜9・E・Esc・Q だけ）。左手の 人さし指 で W の ななめ右下に すぐ とどく。オーナー決定 で かまえ は `R` だけ。
- 将来の コントローラー: `stanceNext` を 1 つの ボタンに あてる（Action 経由 なので そのまま）。

## 3. 画面・見た目

### 3.1 刀の かまえ（人形〈三人称〉と 一人称）

**決まり**: 刀は **両手持ち**（右手 が つば の すぐ下、左手 が つか の はし）。足は かまえ ごとに **前後に ひらく**（前の足 +15°・後ろの足 −15°。ももの 前後の 角度）。ひざ を 少し 曲げる。

角度の 書き方（人形の うで は 今の `ArmPose` と 同じ: `rx` = 前に 上げる 角度〈0 = 下、90 = 前に 水平、180 = 真上〉、`rz` = 外むき が 正。左右の うで を 同じ 値に すると 両手が そろう）。**刀の 向き** = 刀の みね に 沿った 線 の 水平からの 角度（上が 正。0 = 前に 水平）。

| かまえ | うで（両手） | 刀の 向き | 足 | からだ | オーナーの 資料 との 対応 |
|---|---|---|---|---|---|
| **中段**（正眼〈せいがん〉） | rx 50・rz −8（両手が へその 前で そろう） | **+15°**（剣先 が 相手の のど〜目 の 高さ） | **右足 前** +15°・左足 −15°、ひざ 10° | まっすぐ | 剣先を 喉・眉間、右足前 |
| **上段**（左上段） | rx 165・rz −5（両手 が 頭の 上） | **+135°**（剣先 は 頭の うしろ ななめ上） | **左足 前** +15°・右足 −15°、ひざ 10° | 右かたを 少し 引く（ひねり −10°） | 頭上に 掲げ 剣先は 斜め後ろ、左足前 |
| **下段** | rx 25・rz −8 | **−30°**（剣先 が ひざ の 高さ、前 0.8 ブロック） | **右足 前** +15°・左足 −15°、ひざ **20°**（ひくい） | 前に 10° かがむ | 剣先を 膝の高さ |

**一人称**（画面の 位置 は 画面の はば・高さ を 0〜1。左上 が (0,0)。照準 は (0.5, 0.5)）

| かまえ | 両手（つか） の 位置 | 剣先 の 位置 | 見え方 |
|---|---|---|---|
| 中段 | (0.62, 0.95) | **(0.54, 0.56)** | 右下 から 照準 の すぐ 右下 へ ななめに 刀が のびる |
| 上段 | (0.72, 0.06) | 画面の 外（上） | 画面の 右上に 両手 と つば と 刃の 根もと だけ 見える（「上に かかげてる」） |
| 下段 | (0.60, 1.00) | **(0.50, 0.84)** | 画面 下の まん中 に 刀が 前へ 下向きに のびる |

- かまえ を かえる 8F は 前の かまえ から 次の かまえ へ なめらかに うつる（`easeInOut`）。
- 歩いているときは 今の 歩きの ゆれ を 足す。

### 3.3 しるし・表示（HUD）

**刀**
- **かまえ の しるし**: 刀を 持っているとき だけ、ホットバー の 上 まん中 に 3 つ の 絵（16×16 を 2 倍、間 8px）を 横に: 中段（刀が 前へ 水平）・上段（刀が 上）・下段（刀が 下）。今の かまえ は **3 倍・アクセント（`--rk-accent`）の わく**、ほか は 不透明度 50%。今の かまえ の 下に 名前 `中段（ちゅうだん）`・`上段（じょうだん）`・`下段（げだん）`（本文 20px）。右はし に 小さく `R` キー の 絵（「これで かわる」）。
- かえた とき 今の 絵が ぽよん（1.0 → 1.2 → 1.0、8F）。
- **わざ の 名前**: わざ を 始めた ステップ から 24F、照準 の 上 に `つき！`・`おおげさぎり！`・`きりあげ！`（見出し 24px、白・こい ふち）。最後の 8F で うすく なる。
- **ふり の あと**（きせき）: 刀の 刃 が 通った 所に 白い 帯（ふち `#CFE8FF`）。持続 の あいだ 出て 8F で 消える（点滅 では ない。1 回 だけ）。突き は まっすぐ の 細い 線。
- **当たった**: 当たった 所に 白い 星 6 こ が とびちる（0.3 秒）、妖怪 は 今の「ゆれ（`model.hit()`）」。大げさ斬り が 当たったときは 画面が 0.1 秒 小さく ゆれる（2px。明るさ は 変えない）。**血・赤い 色 は 出さない**。
- 大げさ斬り の 硬直 前半 は 照準 の まわり に うすい 灰色 の わ（「いま 動けない」）。

**弓**
- **（オーナー決定）ひきしぼり具合 は ゆみ の しなり だけ で 見せる**。画面 に ゲージ・数・文字 は 出さない。カメラ の ズーム も しない。**落ちる 道 の 点線・落ちる 場所 の しるし も 出さない**。分かる 手がかり は (1) しなり の 形、(2) 一人称 の 引き手 の 位置、(3) 段 ごと の 音（§3.4）の 3 つ。
- **しなり 3 段 の 絵**（弓 を 横 から 見た 形。三人称 の 人形 の 弓 と、一人称 の 弓 は この 形 を 使う。段 の あいだ は 6F で なめらかに うつり、段 に 着いたら その 形 で 止まる）

```
  段 0（ひく前）     段 1（10F〜）      段 2（25F〜）      段 3（40F〜）
      )                 )                  )                  )
      |\               |  \               |    \             |      \
      | |              |   >              |     >            |       >   ← 右手（つる）
      |/               |  /               |    /             |      /
      )                 )                  )                  )
   つる 0%           つる 40%           つる 70%           つる 100%
   まがり 0°         まがり 12°         まがり 22°         まがり 32°・ふるえ
```

| 段 | つる を 引く 量（いちばん 引いた 時 = 100%） | 弓 の まがり（両はし が 内がわ へ たおれる 角度） | 一人称 で 見える 所（画面 0〜1） | 三人称 の 人形 |
|---|---|---|---|---|
| 0（1〜9F） | 0 → 25%（引いた 長さ に 合わせて だんだん） | 0 → 5° | 弓 を 持つ 左手 (0.40, 0.70)、右手 は つる に かかる (0.48, 0.70) | 左うで rx 90（前へ）、右うで rx 90 |
| 1（10F〜） | **40%** | **12°** | 右手 が (0.62, 0.72) へ | 右うで の ひじ を 引く（rz +15） |
| 2（25F〜） | **70%** | **22°** | 右手 が (0.80, 0.74) へ（画面 の 右はし 近く） | 右うで rz +25 |
| 3（40F〜） | **100%** | **32°**。弓 が 小さく ふるえる（±0.5°、5F で 1 往復。明るさ・色 は 変えない） | 右手 は 画面 の 外（ほお の 横）。や の 先 が 照準 の すぐ 下 (0.50, 0.56) | 右手 が ほお の 横（rz +35）、からだ を 少し 弓 の 方へ ひねる（−10°） |

- 段 が 上がった ステップ で 弓 が 「ぴくっ」と 2F だけ 小さく 動く ＋ 段 の 音。見のがしても 音 で 分かる。
- 弓 の 色・形 そのもの は 今のまま（まがり と つる だけ 変わる）。
- ささった や は ブロック に 半分 ささった 形で 見える。拾えると 拾ったログ（M4 §2.12）。

### 3.5 6 歳 向けの 工夫（まとめ）

## 4. ルール・数値

数値は 1 か所の 設定 に まとめ、`settings.get/set` で 変えられる ように する。

### 4.1 向き と 体の 座標（当たり判定 の 書き方）

- P = プレイヤーの 足もと の 中央。E = 目の位置（今の 目の高さ）。
- 前 f = (sin yaw, 0, −cos yaw)（yaw は M1-02 の 決まり。0 = 北）。右 r = (cos yaw, 0, sin yaw)。上 u = (0,1,0)。
- 見る 向き d = 照準 の 方向（上下 の 向き pitch を ふくむ、長さ 1）。
- 妖怪の「当たりの箱」は 今の `raycast` に 使う 箱 と 同じ。
- **当たる** = その 箱 と 当たりの形 が 重なる。開発係は 近い計算 で よいが、次 を 守る:
  - **必ず 当たる**: 箱 の **中心**（横 の 中心、高さ の まん中）が 形 の 中 に あり、形 の さかい から **0.3 以上 内がわ**。
  - **必ず 当たらない**: 箱 の **どの 点** も 形 から **0.3 以上 外がわ**。箱 は 向き に よって かどが 出るので、横 の 半分 r の 箱 は 中心 から **r√2**（からかさ r=0.6 → 0.85、ちょうちん r=0.4 → 0.57）まで を 箱 と して 数える。
  - 突き の カプセル（半径 0.2）は 細い ので「必ず 当たる」を 次 で 決める: **中心線 が 箱 の 中 を 通り、箱 に 入る 点 が E から 4.2（= 4.5 − 0.3）以内**。
  - どちら でも ない 所（さかい の まわり）は どちら でも よい。**妖怪 の 大きさ の せい で さかい の 外 の 妖怪 に 当たる のは それで よい**（オーナー判断。例: 角度 の ふち の からかさ、大げさ斬り の 高さ の 少し 上 の ちょうちん）。テスト は「必ず 当たる」「必ず 当たらない」の 2 つ だけ を 使う。
  - テスト で 使う 箱 の 大きさ（`src/yokai/ai/config.ts`）: からかさ 半径 0.6・高さ 1.6、ちょうちん 半径 0.4・高さ 1.7、ぬりかべ 半径 0.9・高さ 3.0、ろくろくび 半径 0.4・高さ 2.9。
- **かべ ごし は 当たらない**: E から 妖怪の 箱 の 中心 への 線 が 固いブロック に さえぎられたら 当たらない。

|---|---|---|---|---|---|---|
| 突き（中段） | **4F**（F1〜4） | **2F**（F5〜6） | **8F**（F7〜14） | **14F** | F5〜14 | 0.7 倍。持続 で 前へ 0.25 ブロック ふみこむ（かべ が あれば 止まる） |

### 4.3 当たりの 形・ダメージ・ノックバック

**当たりの 形**

| わざ | 形 | 大きさ | 当たる 数 |
|---|---|---|---|
| 突き | **E から d の 方向 の カプセル**（太さ の ある 線） | 長さ **4.5**（今の かたな 3.0 より 長い）、半径 **0.2** | **1 体**（線 で いちばん 手前） |

**ダメージ**（妖怪の 体力。今の `src/yokai/stats.ts`: からかさ 4・ちょうちん 2・**ぬりかべ 48**・ろくろくび 4）

- わざ の ダメージ = 刀の 強さ（今の `weaponDamage`。ぼくとう 2・かたな 4・きらきらの かたな 6）× 倍率。突き は 切り捨て、最低 1。

| | 倍率 | ぼくとう | かたな | きらきらの かたな |
|---|---|---|---|---|
| 突き | ×0.75 | **1** | **3** | **4** |
| 切り上げ | ×1.0 | **2** | **4** | **6** |
| 大げさ斬り | ×2.0 | **4** | **8** | **12** |

- **かたな では** 1 秒 あたり（おしつづけ）の ダメージ が だいたい 同じ（突き 3÷14F、切り上げ 4÷18F、大げさ斬り 8÷36F ≒ 12.9・13.3・13.3/秒）。ちがいは **形・すき・ふっとび**。ぼくとう（4.3・6.7・6.7）・きらきらの かたな（17.1・20・20）は 突き が 少し 弱い（切り捨て の ため）。
- たおす 回数（かたな。体力 ÷ ダメージ の 切り上げ）: からかさ・ろくろくび 突き 2・切り上げ 1・大げさ 1。ちょうちん どれも 1。**ぬりかべ（48）突き 16・切り上げ 12・大げさ 6**（大げさ斬り が いちばん 早い）。

| 大げさ斬り | **2.5** | 2 ブロック/秒 |

### 4.4 弓（ゆみ）

**ひく 段**（ひだりクリック を 押した ステップ を 1。や が 0 本 なら 押した ステップ に「カチン」〈今の `noArrow`〉で ひかない）

| 段 | 押している 長さ（はなした ステップ の 値） | 飛ぶ 速さ v | ダメージ | ノックバック | 平らな 所で 45° に うったときの とどく 距離（目安） |
|---|---|---|---|---|---|
| 0 | 1〜9F | **飛ばない**（や は へらない） | — | — | — |
| 1 | 10〜24F | **12** ブロック/秒 | **1** | 0.5 | 約 7 |
| 2 | 25〜39F | **20** ブロック/秒 | **2** | 1.0 | 約 20 |
| 3 | 40F〜（ずっと 持てる） | **28** ブロック/秒 | **3** | 1.5 | 約 39 |

- 段 は 「押している 長さ」だけ で 決まる（ランダム なし）。だから 同じ 長さ・同じ 向き・同じ 場所 なら いつも 同じ 所 に 落ちる。
- はなした あと、次に ひけるのは **10F 後**（や を つがえる）。

**飛び方（放物線）**

- 出る 位置: p₀ = E + 0.3·d。初めの 速度: **v⃗₀ = v·d**（d は 照準 の 方向。上下 の 向き をふくむ）。
- 重力: **g = 20 ブロック/秒²**（下向き）。空気の ていこう なし。
- 1 ステップ（Δ = 1/60 秒）ごとに、**先に 速度、次に 位置**:
  - v_y ← v_y − g·Δ
  - p ← p + v⃗·Δ（x・y・z とも）
- → n ステップ 後: p_x = p₀ₓ + v₀ₓ·nΔ、p_z も 同じ、**p_y = p₀ᵧ + v₀ᵧ·nΔ − g·Δ²·n(n+1)/2**。
- 連続 で 書くと p(t) = p₀ + v⃗₀ t − ½ g t² u（目安。テストは 上の ステップ の 式 で 比べる）。平らな 所で 45° の 距離 ≒ v²/g。
- 当たり: 各 ステップ で、前の 位置 から 新しい 位置 まで の 線分 で、ブロック と 妖怪 の いちばん 手前 に 当たる（今の しくみ と 同じ 考え）。
- 消える: 妖怪 に 当たる・世界の外・飛んでから **600F（10 秒）**。
- や の 向き は 速度 の 向き（落ちるとき 先が 下を 向く）。
- **ささった や**: ブロック に 当たった や は その 位置 に **1,800F（30 秒）** のこる。プレイヤー の 体の 箱 が その 点 から 水平 1.2・高さ 2 以内 に 入ると **や 1 本 が 持ち物 に もどる**（入らなければ のこる）。のこる 数 は 32 本 まで（こえたら 古い 方 から 消える）。保存しない。
- 落ちる 場所 の 目安 は 出さない（オーナー決定。計算 も 画面 に 使わない）。
- 設定: `bowStageTicks`（`[10, 25, 40]`）・`bowSpeed`（`[12, 20, 28]`）・`bowDamage`（`[1, 2, 3]`）・`bowKnock`（`[0.5, 1.0, 1.5]`）・`arrowGravity`（20）・`arrowLifeTicks`（600）・`bowNockTicks`（10）・`arrowStuckTicks`（1800）・`arrowStuckMax`（32）・`bowMoveMul`（0.5）・`bowBend`（`{pull:[0.4,0.7,1.0], bendDeg:[12,22,32], blendTicks:6}`）。今の `bowDrawTicks`・`bowInterval`・`arrowSpeed`・`arrowRange`・`arrowDamage` は 使わなくなる（§6.2）。

### 4.5 なぎなた・素手（今回は「直す 方針」だけ。作るのは あと）

- **しくみ を そろえる**: すべての 武器・素手 を 刀と 同じ「発生・持続・硬直」と「当たりの 形（線 か 扇形）」で 書く。今の「目からの 線 1 本・30 ステップ 後 に 当たる」は やめる。
- **素手**: 左右 交互 の パンチ。発生 6F・持続 2F・硬直 10F くらい（今の 30F は 遅すぎて 当たった 気が しない）。形 は 長さ 2.5 の 線。ダメージ 1、ノックバック 0.8。両手 は 顔の 前 に かまえる（ボクシング の 形）。

- **つるはし など**: 素手 と 同じ パンチ の しくみ（持っている 物 を ふる 見た目）。
- 直す ときに この 仕様書 の §4.1〜§4.3 の 書き方 を 使う。

**(4) こわれる**
- たいきゅう が 0 に なった その 行動 は ちゃんと 効く（最後 の 1 回 で ブロック が こわれる・ダメージ が 入る・や が 飛ぶ）。そのあと 同じ ステップ で 道具 が マス から 消える。
- 刀・ゆみ が こわれたら、その ステップ で かまえ・わざ・ひく は おわる（次は すで）。
- **防具 の 計算 の 順**: `PlayerCombat.hurt()` が 種類 と **元 の ダメージ** を `armor.cut(kind, amount)` に わたす → 防具 は **先 に カット を 決めて 返し**、**その あと** ふせいだ 防具 の たいきゅう を へらす（呼ぶ 1 か所 は §7 の F）。
- **防具 が こわれたら**: その 攻撃 の カット は こわれる 前 の 防具 で 計算（最後 の 1 回 は ちゃんと 守る）。その あと そうび の マス が 空 に なり、次 の 攻撃 から その 分 の カット が 無い。人形 の その 防具 も 消える。
- 見た目・音 は §3.6。拾ったログ と 同じ 所に `〇〇 が こわれた`（道具 の 絵、`--rk-info` の 帯）を 1 行。

**(5) のこり わずか の 合図**
- たいきゅう が **のこり 10% 以下**（切り上げ。きの つるはし なら 6 以下）に なった とき、**1 回 だけ** 合図: チップ `〇〇 が もうすぐ こわれるよ`（M6 の 合図、120F）と 音「ピピッ」。
- その あと は マス の バー が 赤 で、マス の 左上 に 小さな「！」の 印（16×16、`--rk-ng` の まる に 白 の ！。点滅 しない）。

**(6) データ と 保存**
- たいきゅう で へる 道具 は 上限 1（今も 1）。マス の 中身 に「へった 量」を 持つ（`ItemStack` に 足す。PO が 契約 を 決める）。へった 量 0 は 新品。
- つくった とき・拾った とき は その 道具 の へった 量 を たもつ（つくった ものは 新品）。持ち物 の 中 で 動かす・たんす に しまう・すてる（落とし物）・やられて おとす（ふくろ）でも たもつ。
- **着ている 防具 も へった 量 つき で 持つ**（今 の 防具 は 品名 だけ で 持っている ので、着る・ぬぐ・入れかえ・やられて ふくろ へ・保存〈`ArmorSnapshot`〉の どれ でも へった 量 を いっしょ に 運ぶ 形 に する）。着る と 持ち物 の マス の へった 量 が そうび へ、ぬぐ と そうび の へった 量 が 持ち物 へ。
- 自動セーブ で 保存 する（持ち物・たんす・落とし物・ふくろ・着ている 防具）。前の 保存（へった 量 が 無い。`ArmorSnapshot` が 品名 だけ の もの もふくむ）は 新品 と して 読む。
- 直す（修理）は 今回 は 無い（あとで: かまど・材料 で 直す など）。

**(7) M7 との つなぎ**: M7 が 先 に 入る（PO 決定）ので、くわ は 上 の 表 の とおり「たいきゅう で へる」131・たがやす 1 回 で 1。しゅうかく で は へらない。

**(8) 説明 の 表・ツールチップ**（M6 §2.2・M4 §2.13 に 足す）
- 「たいきゅう で へる」道具 の つよさ に `たいきゅう 250`（新品 の 値。メーター は 使わない）、ツールチップ に `たいきゅう 180 / 250`（今 の のこり / 新品）。
- 「なにに つかう」の 下 に なかま の 文: `つかうと へって、0 で こわれる`（たいきゅう）・`つかうと 1 こ へる`（つかうと なくなる）・`へらない`（ずっと へらない）。

## 5. 例外 の とき

- **刀 で ブロック**: §2.1 の 6 の とおり ほれる（すで と 同じ 強さ。たいきゅう は 1 こ こわすと 2 へる。§4.6）。わざ の 当たりの 形 が ブロック に かさなっても ブロック は かわらない。
- **大げさ斬り の 扇形 に 妖怪 が いて、照準 は ブロック**: 押した ステップ の ふりわけ は「ほる」（照準 が 決める）。扇形 の 妖怪 を 切りたい ときは 照準 を 妖怪 か 空 に 向ける。
- **わざ の とちゅう で 持ちかえた**: その ステップ で わざ を やめる（当たり なし）。もどると 中段。
- **わざ の とちゅう で もちもの画面 を ひらいた**: ゲーム の 時間 と 同じく ゆっくり 進む（1/4）。案内画面・おめでとう画面・やられた画面 では 止まる。
- **やられた**: わざ・ひく は やめる。
- **水の 中**: わざ・ゆみ は ふつうに 使える（歩く 速さ は 水 の 速さ × わざ の 倍率）。
- **や が 世界の 上 へ 出た**: y が 世界の 高さ を こえても、x・z が 中 なら 落ちて くる まで 消さない（600F で 消える）。
- **ゆみ を ひいたまま や が 0 本 に なった**（たんす に しまった など）: はなしても 飛ばない（「カチン」）。
- **先行入力 が 2 つ**: あとから 押した 方 だけ（かまえ を かえる と わざ なら、あと の 方）。
- **M7 の しゅうかく**: M7 の きまり（M7 §2.5: ゆみ は しゅうかく しない、ほか は する。作物 より 手前 に 妖怪 が いれば たたく）は そのまま。刀 も §2.1 の 6 の とおり いちばん 手前 で 決まる。**しゅうかく では たいきゅう は へらない**（刀・つるはし・くわ どれ で も。ブロック を こわす 扱い に しない）。
