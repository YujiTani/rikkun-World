## 確認できた点（問題なし）

- WEAPON-2 第 5 版 §3.2 の 時間表（突き 14F・大げさ 36F・切り上げ 18F）と §4.2 のキー F、弓 pull は CHAR-1 §4.2 と一致。骨の数 18＋差しこみ口 3＝21（24 以下）。
- 描画回数 6・三角形 1,200（箱 約 40 こ×12＝約 480 で 足りる）・防具 800・一人称 400 は 箱の数から見て現実的。GLB 300KB は余裕。
- 例外（読み込み中・読めない・名前の無い動き）の代わりの扱い、`parts`・`armAnim`・`animTick` を残す約束は 今の `hook.ts` と合う。固定ステップは `dollAnim.advance` が 1/60 秒ごと なので、動きを ステップで決める方針も合う。
- 担当 M（`tools/char/`・`public/models/`）と R（`src/camera/samurai/`）は ファイルが重ならない。WEAPON-2 が先に main に入る前提で、WEAPON-2 の C（`src/camera/`）と重ならない順番になっている。
