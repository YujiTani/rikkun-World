## 1. マイクラが 見やすい わけ（しくみ・考え方 だけ。絵は まねしない）

マイクラの 絵（テクスチャー）は 著作物なので **写さない・なぞらない**。下は 見て 分かる「きまり」だけ。このゲームの 最初の 絵（`src/world/blocks/textures.ts`、コードで 描いた 16×16）も もともと 同じ きまりに 合っていた。

| きまり | マイクラ（考え方） | 最初の main の 絵 | いま（ごつごつの 色） |

## 5. 見やすさの はかり方（目安）

画面の 明るさを「9 画素より 大きい ちがい（形の 明暗）」と「9 画素より 小さい ちがい（ざらざら）」に 分け、その 比（形 ÷ ざらざら）を 出す。空は のぞく。大きいほど「形が 見えて、ざらざらが 少ない」。
くわしく: 明るさ（0.2126R＋0.7152G＋0.0722B）を 9×9 画素の 箱で ぼかした 物の ばらつき（形）÷ もとの 明るさ − ぼかした 物 の ばらつき（ざらざら）。空と 画面の ふちは のぞく。
目で 見た 感じとも 合う が、すみの 暗さ（AO）の 良さ（段の 根元が わかる）は この 数では 出にくい。

## 7. おすすめ

**(a) 元の 絵を 投影 ＋ (3) キャラの 丸い 影**。面の 明るさは いまの まま（上 1.0・横 0.8・下 0.6 ＝ 最初の main と 同じ）。(2) すみの 暗さ は いまは 入れない。

1. **最初の main と 同じ 絵が そのまま 出る**（オーナーの 言う「最初の テクスチャー」そのもの）。たんす・かまど・鉱石 の 決まった 絵も くずれない（(b)(c) は 9×9 に つぶれて たんすの 取っ手が 黒い かたまりに なる。シートの 下の 段）。
2. **見やすさの 数が いまより 2〜7 割 上がる**（上空は 最初の main と ほぼ 同じ）。(b) の ほうが 数は 1 割 ほど 上 だが、(b) は 色の 点と 形の 段が 同じ 大きさ（1/9）で、色の 点が でこぼこに 見える 弱みが のこる。(a) は 模様の 点（1/16）が 形の 段（1/9）より 小さく、目が「形」と「模様」を 分けられる（マイクラの きまり と 同じ）。
3. **いちばん 軽い**: 三角形が いまより 27% 少ない。
4. **(3) は ほぼ ただ で、キャラが どこに 立って いるか・どの 段の 上か が 分かる**。6 歳が 段を ジャンプで のぼる とき・穴の ふちに 立つ とき に 効く。

いまは 入れない もの:
- (2) すみの 暗さ: 段の 根元は 分かるが、画面ぜんたいの 見やすさは 上がらず、三角形 2.6 倍。#144（太陽・たいまつの 影）が 入ってから いっしょに 見て 決める。入れるなら 三角形を ふやさない やり方（シェーダーで となりの 小ブロックを 読む）を 先に 試す。
- (1) 面の 明るさ（マイクラ式）: ただ だが 効き目が 小さく、画面が 少し 暗く なる。好みで `?tex=a&shade=mc,blob` も 見て ください。
