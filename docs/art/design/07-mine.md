### 20.2 鉱石: B「とびだす つぶ」
- ブロックの 見える 面ごとに つぶを おく。がらは 3 つ から ブロックの 位置の ハッシュで 1 つ（面ごとに べつ）。
- **つぶは 表面の 層に のこし、まわり 1 小ブロックの 表面を ほる（みぞ）**。つぶが 1 小ブロック とびだして 見え、みぞに 影（AO）が できる。つぶの 下の 層にも つぶの こい 色を ぬる（みぞの 横から 見える）。
- 地の 石: いまの いしの 絵（`stone`）。ほり方は **いまの つちと 同じ（4・2）**。いし（6・3）より 少なく して つぶを 読みやすく、B の 見本（3・1）より 多く した（A の ねんど・せっかいせきの 横で 平らな 板に 見えた ため。まぜた 見本で 直した）。
- つぶの 色は 小ブロックごとに ぬる（**TEX-A「色は 絵の 投影 だけ」の 例外。鉱石の つぶ だけ**）。つぶの 色は おさえない（calm しない。さがす 目じるし。01-world の 鉱石の きまり と 同じ）。

- がらの 座標（u・v = 面の 中の 0〜8、d = 表面からの ふかさ）は `proto/designs.py` の `opt_b` の `coal_layout`・`iron_layout`・`gold_layout`・`cry_layout`・`hot_layout`・`dia_layout`（ダイヤ = ハッシュの たね 408、3 つの 位置から 1 つ）。
- きん と てつ は 色だけで なく 形（小さな 四角い 粒 ／ まるい こぶ）と 明るさで 分かれる（色覚 2 型でも。CRITERIA 13）。
- **ダイヤ と きん・すいしょう・ほたるいし**: 形 = ダイヤ だけ ななめの ふち（ひし形）。ほかは 四角（きん = 小さな 粒 3 つ、すいしょう = くぼみの 中の はしら、ほたるいし = こい 地に 光る わ）。色 = 白に うすい むらさき ／ きいろ ／ 水色 ／ きみどり。白黒でも ダイヤが いちばん 明るい。**ダイヤは 光らない**（光るのは ほたるいし だけ。暗い 所で まぎれない）。光の つぶ（パーティクル）も 出さない（§15.3: 世界で 2 しゅるい まで）。
- 光る つぶ（ほたるいし）は 自分の 色で 光り、面の 明るさ・AO を かけない（夜・ほらあなでも 見える）。

### 20.3 ほたるいしの いき
- 光る つぶの 明るさを **±12%・4 秒の サイン**で ゆっくり 変える。3×3×3 小ブロックの まとまりごとに 位置で ずらす（つぶごとに ずれる）。点滅 しない（§15.3: 2 秒より ゆっくり・±15% まで）。
- 「うごきを へらす」で 止める（光る 強さは そのまま）。

### 20.4 ほたるいしの 光（7）
- 強さ **7**。置いた マス 7・となり 6 で「少し 明るい」の 段、2 マス 先で 光の 段は おわる。→ **まわり 1 マスが ぼんやり、あとは 光る つぶが 星の ように 見える**。「明るい」の 段には ならない。
- 色は ほたる色（うすい みどり、かける 色 [0.80, 1.0, 0.74]）・明るさ 0.35（たいまつの「少し 明るい」0.5 より 暗い）。たいまつの だいだいと 色・明るさで 分かる。そのため ブロックの 光を たいまつ・ほたる の 2 本に 分ける。むずかしい ときは developer が PO・art-director に 相談（だいだい 0.5 なら いまの しくみの まま。光 7 は 1 マス だけ なので 見た目の ちがいは 小さい）。
- ほたるいしは 光を 通さない ブロック。光は となりの 空気へ 広がる。
- **光る 数**: ふつうは §15.1 D の 少ない物（1 列 8 こ まで）。**ほたるの ほらあなだけ 例外**で 部屋 1 つに 見える 24〜32 こ（上限 32 は PO 案）。重さは 数で はかり、こえたら へらす（MINE-1 §4.9。§15.4 の 2）。例外は 数 だけで、光の 強さ 7・いき（20.3）は かえない。
