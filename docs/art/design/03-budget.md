## 15. ブロックの予算（国のブロック・これからの 世界のブロック。#87・#99）

オーナー決定（2026-10-17）: 「1 ブロックあたりの容量の限界を決めて、その中なら自由に特徴を持たせてよい」。
**この 章の 数の 中なら、pixel-artist・modeler・developer は オーナーに 聞かずに 特徴（もよう・形・顔・まばたき・ゆれ・光・つぶ）を 足してよい。こえるとき・新しい 種類の うごきを 足すときは オーナーに 聞く。** 安全（15.4）は 予算より 先。
数は 1 ブロックの **種類** あたり（1 こ ごとでは ない）。見本: `/mnt/project-files/biome/art/final-1.png`〜`final-3.png`（3 まいめに 予算の 図）。

### 15.1 形（1 ブロックの 三角形）
はかり方: 9×9×9 の 形を、同じ 平面の 面を 四角に つないで 数える（見本の 道具 `/mnt/project-files/biome/art/tools/sheets.py` の `greedy_tris`）。「宙に 1 こ」= 6 面とも 見える とき（ただの 箱 = 12）、「上だけ」= 上から 見える 面だけ。

| 組 | なかま | 上限 | くらべ（いま） |
|---|---|---|---|
| A 地面（面が つながって 広く ならぶ） | いし・つち・すな・ゆき・おちば・あさせ・てつ など | **上だけ 110・宙に 1 こ 320** | いまの くさ 上だけ 約 109、いし 宙に 約 250〜310（ごつごつ） |
| B たくさん ならぶ 柱・はっぱ（となりと すきまが 出る） | たけ・はっぱ・もみじの はっぱ・まつの はっぱ・き（みき） | **宙に 1 こ 120** | いまの はっぱ 約 70〜100 |
| C 十字の板・うすい板 | はな・すすき・きのこ・たけのこ・ひまわり（2 段）・かいがら | **板 8 まい（三角形 16）** | いまの 十字の板 8 |
| D 少ない物（1 列 = 16×16 に 8 こ まで。ほたるの ほらあなの ほたるいしは 15.4 の 2 の 例外） | すいしょう・はすの は・とうろう・国の 目じるし | **宙に 1 こ 400** | |

- B の へんな形は **カメラから 16 ブロック の 中だけ**。外（16〜32 の 小ブロック・箱の 段・LOD）は ただの 箱（たけやぶ は 1 列 60 本 × 高さ 約 5.5 と 多いため。32 まで 形を 出すと 1 コマ 約 +40 万）。

- 描画回数は 形・絵・まばたき・ゆれ では ふやさない（同じ チャンクの メッシュ・同じ atlas）。つぶ だけ 1 しゅるい +1（15.3）。

### 15.4 安全（予算より 先。こえたら だめ）
1. **強い 点滅は しない**（rules D・`fun.md` 6）。明るさを 変える 物は 1 秒に 3 回より はやく 変えない ことに 加えて、ここでは **2 秒より はやく 変えない**（15.3 の いき）。赤い 光・白い ぴかっ は 使わない。
2. 画面の 広い 所（地面・はっぱ・草）を **同時に 同じ 明るさで 変えない**（場所で ずらす）。地面の ブロックは 光らない（光るのは D の 少ない物 だけ。1 列 8 こ まで）。
   - **例外: ほたるの ほらあなの ほたるいし**（yuzu 2026-10-30 04:36「多く置いてよい」）。部屋 1 つに 見える **24〜32 こ**（上限 32 は PO 案）。重さは 数で はかり、こえたら へらす（`docs/design/MINE-1.md` §4.9）。例外は **数 だけ**: 光の 強さ 7 は 15.3 の「9 まで」の 中、いき（±12%・4 秒）も 15.3 の まま。ほかの 所の ほたるいしは D の 少ない物 の まま。
3. **くり返し 見る 物は 控えめ**（`fun.md` 1）: 見つけても 音・演出は 足さない。まばたき・ゆれは 同じ 大きさの まま（続けても 大きく しない）。紙ふぶき・花火 は 世界の ブロックでは 出さない（達成の とき だけ。`fun.md` 2）。
4. 「うごきを へらす」設定（端末の 設定も）で、まばたき・ゆれ・いき・つぶ は **ぜんぶ 止まる**（顔は コマ 1、光は 一定）。光る こと（光の 強さ）は のこす（暗い 所の 見え方が 変わらない ように）。
5. こわく しない: 顔は 地上（空の 光が ある 面）だけに 出す 物を 決めて よい（ねむり岩）。ほらあな・夜に 目だけ 光る 絵は 作らない。
