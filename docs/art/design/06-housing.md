### 19.4 うなずき（話しかけた とき。HOUSE-1 §3.6。1 コマ = 1 ステップ = 1/60 秒）

性格: 「うん！」と はっきり 1 回。決めポーズ = 顔を 下げきった 所（`A.png` 2 だん目 右）。

| 区間 | コマ | 頭（前へ。＋ = 下） | 頭の かしげ | 体（前へ） |

| 少し 上げる | 0〜4（4） | 0 → −9°（なめらか） | 頭 × 0.18（−1.6°） | 0 |
| こくっと 下げる | 4〜8（4） | −9 → **+26°**（**加速**: t²） | +4.7° | 2 コマ おくれて 0 → 3° |
| 止め | 8〜12（4） | +26° | +4.7° | 3 → 6° |
| もどる | 12〜20（8） | +26 → 0°（なめらか） | → 0 | 6° を 14 まで、22 で 0 |

- 体は 頭より **2 コマ おくれて** 6° だけ ついていく（22 コマ目で おわる）。左の 手（`armL`）は 体の 0.8 倍 ゆれる。木づちは かたに のせた まま（`tool` は いつも x +28°・z −10°）。

- ふきだし・「ぽぽぽ」は 0 コマ目（話しかけた 次の コマ）に 出す（MOTION #3）。
- 「うごきを へらす」設定でも うなずきは のこす（遊びの 返事）。
