# アートのスタイルガイド — 世界（ブロック・影・形・空・わく）§1〜12

> `docs/art/DESIGN.md`（目次とオーナー決定のまとめ）の章。章の番号はもとの DESIGN.md のまま（「DESIGN §16」などの参照はそのまま使える）。

## 1. ひとことで

**手で ほった ジオラマ（もけい）の 島に、最初の ドット絵を はった もの。**
1 ブロック = 9×9×9 の 小ブロック。形は「3×3 の かけら」で ごつごつ。**色は 1 ブロックの 各面に 16×16 の 絵を そのまま うつす**（でこぼこの 小ブロックは、その 場所の 画素の 色）。
影は 色で ぬらない。**面の 向きの 明るさ・すみの 暗がり（AO）・キャラの 丸い 影** で 出す。人が 作った 道具の ブロックは でこぼこに せず、まっすぐな 1 ブロックの 箱（「作った 物は まっすぐ、自然は ごつごつ」）。

なぜ 見やすいか（マイクラを 調べた きまり。絵は 写さない。くわしくは `texture-back.md` 1 章）:
1. 物ごとに 色の なかまが はっきり ちがう（草・土・石・砂・木）。
2. 1 まいの 絵の 中は 地の色 ＋ 近い色 2 こ くらい。明るさの 差は ±1〜2 割（点で ざらざら させすぎない）。
3. **形の 段（1/9）と 絵の 点（1/16）の 大きさが ちがう** → 目が「形」と「模様」を 分けられる。
4. 面の 向きで 明るさが 決まっている（3 章）。

## 2. 小ブロックと ドット感

| きまり | 値 |
|---|---|
| 小ブロックの大きさ | 1/9 ブロック（9×9×9）。形の 単位 |
| 絵の 点の 大きさ | 1/16 ブロック（16×16 の タイル）。色の 単位。小ブロックとは そろえない |
| 形の単位 | 3×3（面）・3×3×3（かど・かたまり）。1 マスの単位は「草の芽」「みぞ」だけ |
| ふち線（輪郭の線） | 描かない。りんかくは 形（けずった かど）と 面の 明るさ・AO で 出す |
| 色の 付け方 | **場所 だけで 決める**: 面の 向き ＋ ワールドの 座標 → タイルの 画素（4.1）。同じ 場所は いつも 同じ 色。Math.random なし |
| 絵の 数 | 1 ブロックに [上, 下, 横] の 3 まい（`BLOCK_TILES`）。4 つの 横は 同じ 絵 |
| 遠く | 40 ブロックから 80 ブロックへ、画素の 色を タイルの 平均色へ なめらかに よせる（ミップの かわり。上空で ちらつかない）。80 より 遠くと LOD は 平均色 だけ（4.4） |

## 3. 影の きまり（3 つとも 入れる）

光の 明るさ（空の光・ブロックの光・昼夜 = いまの `lightShader`）は 変えない。色 = **タイルの 画素 × (1) 面の 明るさ × (2) AO × 光**。(3) は キャラの 足もと だけ。

### 3.1 (1) 面の 明るさ（マイクラ式）

| 面 | 上 | 南・北（±z） | 東・西（±x） | 下 |
|---|---|---|---|---|
| 明るさ | **1.0** | **0.68** | **0.5** | **0.45** |
| （前: #146〜#309 の 前） | 1.0 | 0.8 | 0.6 | 0.5 |
| （さらに 前: 9×9×9 の 前の main） | 1.0 | 0.8 | 0.8 | 0.6 |

- **#309（2026-10-25 オーナー OK）**: 1 段ずつの さかいを 見やすく するため、横と 下の 面を 少し 暗く した（南北 0.8→0.68・東西 0.6→0.5・下 0.5→0.45）。下の「決めた わけ」の 数は #146 の ときの もの。

- **決めた わけ**:
  1. いちばん 多く 見える 上の 面と、スタートの 向き（北）で 見える 南北の 面は 最初の main と 同じ 1.0・0.8。最初の main の 見え方（明るさの ふんいき）は ほぼ そのまま（地面の 平均の 明るさ −3%）。
  2. 東西を 0.6 に 下げると、1 ブロックの 見える 2 つの 横の 面の 明るさが ちがう ので、**箱の たての かどが 見える**。平らな 道具の 箱・段・崖が 箱に 見える（最初の main では 2 つの 横が 同じ 0.8 で、かどは 絵の ふち だけ で 分かっていた）。
  3. オーナーが 選んだ 見本（`texture-back-shade.png` の「(a) ＋ (1)(2)(3) 全部」の 行）は この 値。
  4. 費用 0（数字 だけ）。
- 小ブロックの 面・箱の 段・平らな 道具の 箱・LOD・水 …… **世界の ブロックの 面は 全部 同じ 値**（となりどうしで 明るさが くいちがわない）。たいまつ・十字の 板は いまの まま。値は `src/world/render/config.ts` の 1 か所に おく。
- オーナーが Mac で 見て「最初より 暗い」と 感じたら、東西 0.8・下 0.6（前の 値）に もどせる ように する（数字の 置きかえ だけ）。

### 3.2 (2) 角の 暗がり（AO）

- **小ブロックの 面**: 面の 4 すみ ごとに、面の 前の 層で となりの 2 つ（s1, s2）と かど（c）の 小ブロックを 見る。`s1 && s2 → 3`、それ以外は `s1 + s2 + c` の 段。明るさ = 段 0: **1.0**・1: **0.75**・2: **0.58**・3: **0.45**（#309 で 少し 強く した。前は 0.82・0.68・0.55）。面の 中は 4 すみ から なめらかに（双線形）。
- **平らな 道具の 箱**: 1 ブロック 単位で 同じ 式（となりの ブロック で 見る。マイクラと 同じ）。箱の まわりの 地面の 小ブロックは 箱を「全部 つまった 9×9×9」と して 見る（箱の 根もとが 暗く なる）。
- **箱の 段（r より 外）・LOD**: AO なし。r の 8 ブロック 手前から r で AO を 1.0 へ なめらかに 消す（段の 切りかえで ぱっと 変わらない）。
- **三角形を ふやさない 作り方を 第一案に する**（試作の 頂点 AO は 三角形 約 2.6 倍 だった）。作り方・上限・こえた ときは `TEX-A.md`。
- 暗い 所（夜・ほらあな）でも 同じ 割合で かける（空の光・たいまつの光 どちらにも）。
- 見え方の 目安: 段の 根もと・へこみの 底・木の 根もとが 少し 暗く なる。真っ黒に しない（いちばん 暗くて 0.45）。

### 3.3 (3) キャラの 丸い 影

- 足もとに ふちの ぼけた 丸 1 まい。大きさ 0.9 ブロック。中心の こさ 0.55 → 6 割の 所で 0.4 → ふちで 0。
- **まぜ方は かけ算**（地面の 色 ×（1 − こさ））。色を 足さない（暗い ほらあなで 青く うかない）。霧は かけない。
- 置く 高さ: 足の 下の いちばん 上の 固い ブロックの 上 ＋ 0.13（小ブロック 1 こ ぶんの でこぼこに うもれない）。重なりの 判定は する（かべの むこうには 出ない）。
- 高く とぶ ほど 小さく うすく（地面から h ブロックで こさ・大きさ ×(1 − h/6)、大きさは 0.6 倍 まで）。6 ブロック より 上では 出さない。
- **キャラの 板より 先に 描く**（あとに 描くと 影が くつの 上に のる）。
- 水の 中（足が 水の ブロックの 中）・水の 上では 出さない。
- 描画回数 +1・三角形 +2。妖怪には まだ 付けない（あとで 決める）。
- 太陽・たいまつの 位置から 計算する 影は #144（ここの きまりと ぶつかる ときは #144 で 決めなおす）。

## 4. 絵（タイル）の きまり

### 4.1 そのまま 投影
- 面の 向きで [上, 下, 横] の タイルを えらび、面の 中の 位置（ワールド座標の 小数部）を 16 倍して 画素を 読む。上・下 = (x, z)、東西の 横 = (z, y)、南北の 横 = (x, y)。**絵の 上（行 0）が ブロックの 上**。左右の 向きは 9×9×9 の 前の main（`meshChunk.ts` の `pushFace` の UV）と 同じに する（試作 `texShader.ts` は これで 合わせた）。
- **でこぼこの 小ブロックは、その 場所の 画素の 色**（へこみの 底も、まわりの 面の 絵の つづき。3D の 模様は 使わない）。
- 色は sRGB の 絵を 線形に して から 3 章の 明るさを かける。
- 形の 決まった 絵（たんす・かまど・鉱石・レンガ・かわら）も そのまま 見える こと（9×9 に 縮めない）。

### 4.2 小ブロック地形（草の 横）
- てっぺんの 面は 上の 絵（grass_top など）。
- 横に 見える 面は、**その 場所の 地面の てっぺんから 何 小ブロック 下か** で grass_side の 行を 決める（1 小ブロック = 16/9 行）。しばふの 帯（上の 4 行 = 小ブロック 約 2.25 こ）が でこぼこに そって つき、その 下は 土の 絵。16 行より 下は dirt の 絵を くり返す。
- 土の 見える 所（`microSoil`）は dirt の 絵。岩は stone の 絵。

- マイクラの 絵を 見て 写さない・なぞらない（きまり だけ まねる）。

### 4.3b ざわざわを へらす（#194、2026-10-17 オーナー決定 E）
- 自然の ブロック（くさ・つち・いし・すな・き・はっぱ・そこいし、鉱石の 地の いし）は、4.3 の 絵を **地の色へ 明暗を 半分（contrast 0.5）・彩度 8 割（saturation 0.8）** に おさえて 使う（`TILE_CALM`・`calmColor`、式は `docs/tickets/CALM.md`）。点の 場所は 変えない。
- 鉱石の つぶ・道具や 人が 作った ブロック（かまど・たんす・レンガ・かわら・たいまつ）・作物・キャラは おさえない（さがす 目じるし・目立たせたい 物）。
- 面の 明るさ（3.1）・AO（3.2）は いまの まま（弱めると 地面が 平たく 見えた）。
- 新しい 自然の タイル（12 の 国 #185 など）も この おさえかたを かける。4.3 の 表の 色は おさえる 前の 色。

### 4.4 遠くの 箱の 段・LOD
- **箱の 段**（小ブロックの 外〜48）: 1 ブロックの 箱に、4.1 と 同じ 投影（近くと 同じ 絵・同じ 色）。でこぼこと 小ブロック地形は 出ない。
- **LOD**（その 外）: 面ごとに タイルの **平均色** × 3.1 の 明るさ（上・南北・東西）。いまの `lodMesh.ts` の 平均色（`tileAverage`）の まま。
- 近く → 箱 → LOD で 同じ ブロックの 同じ 向きの 面の 平均の 色が ±6% に おさまる こと（2 章の「遠く」の よせかた で つなぐ）。

### 4.5 夜・ほらあな・水
- 夜・ほらあなの 暗さ・たいまつの 光（あたたかい 色あい）は いまの しくみの まま（`lightShader`）。絵が 変わる だけ。
- 鉱石は ほらあなの かべで 最初の main と 同じ くらい 見える こと（`texture-back-check.png` B）。
- 水は 水の 絵（すけ）の まま。水ごしに 底の 絵が 見える。

## 5. 形のきまり（でこぼこ）

### 5.1 共通
1. **へこませるのは 見える面の側だけ。** 見えない面（となりに くっつく面）の外側の層は ぜんぶ つめる（`dentable`）。これを守らないと ブロックのさかいに すきまが見える。
2. へこみの深さは **1〜3 マス**（1/9〜1/3 ブロック）。2 マス以上の へこみを 面の 2〜3 割に入れる（「ごつごつ」と分かる深さ）。
3. 見える面が 2 つ出会う **へり・かど** は、3×3×3 の かたまり ごとに けずる（崖・山・岩の シルエットを ごつごつに）。
4. 1 マスの ばらばらの穴は 作らない。単位は 3×3 の かけら。1 マスの物は「草の芽」「木の みぞ」だけ。
5. ブロックの外（9 マスの外）には はみ出さない（となりと重なる・当たり判定と ずれる）。
6. **人が 作った 道具の ブロックは でこぼこに しない**（5.3）。

### 5.2 種類ごと（今の強さ。`gotsugotsu.ts` の 形）

| もの | 面の へこみ（9 枚中 1 マス / 2 マス） | へり・かど（10 中） | そのほか |
|---|---|---|---|
| くさ（上） | 3×3 ごとに 4 つの高さ: くぼみ 3 割（2 マス、まんなか 3 マス、ときどき 草の芽 1 本）/ 草の芽 3 割（1 マスめ に 3 本に 1 本）/ 1 段ひくい 2 割 / つまった 2 割 | 崖の しばふ の くちびる 5 | |
| くさ（崖の横） | しばふ の下のはし（y=5）を 3 マスに 1 マス ギザギザ。下の土は 1 マス 引っこむ（ひさし）＋ 4/9 で 2 マス、まんなか ときどき 3 マス | | |
| つち | 4 / 2 | 5 | |
| いし | 6 / 3 | 7 | 2 マス めの かけら の 半分は まんなか が 3 マス |
| そこいし | 6 / 3 | 7 | |
| すな | 横 3 / 1 | 3 | 上は 風の しま（1 マス） |
| せきたん・てつ | まわりの石 5 / 2 | 0 | **でこぼこの まま**（地形の 一部）。色は 4.1 の 投影 だけで 出す |
| き | | | たての みぞ: 外 1 マスは 2 本に 1 本、2 マスめ は 4 本に 1 本。上下は 年輪 |
| はっぱ | | | 3×3×3 の かたまり 27 こ。外の かたまり は ときどき無い（かど 5 割・へり 2 割） |

- 色の 段（外 1・外 2・1 段内・2 段内）・まだら・草の先 は **使わない**（形の 穴あけ だけ 使う）。へこみの 暗さは 3.2 の AO で 出る。

### 5.3 平らな 箱で 描く ブロック（道具・人が 作った 物）

| ブロック | id | 絵 [上, 下, 横] |
|---|---|---|
| かまど | `furnace` | furnace_top / furnace_top / furnace_side |
| たんす | `tansu` | tansu_top / tansu_top / tansu_front |
| スプリンクラー | `sprinkler` | sprinkler_top / sprinkler_bottom / sprinkler_side |
| レンガ | `brick` | brick |
| かわら | `kawara` | kawara |
| はたけ・ぬれた はたけ | `farmland`・`farmland_wet` | farmland(_wet)_top / dirt / farmland(_wet)_side |

- 9×9×9 の 前と 同じ **1 ブロックの 箱**（6 面。となりが 不透明の 面は 描かない）。絵は 4.1 の 向きの まま。
- 影の 付け方も 前と 同じ（面の 明るさ ＋ 角の 光の なめらかな 平均）に、3.1 の 値と 3.2 の ブロック単位の AO を かける（となりの でこぼこの 地形と 明るさを そろえる）。
- **箱の まわりに すきまを 作らない**: 箱を 置いた 地面（箱の 下の ブロック）と となりの 地面の 小ブロックは、箱に ふれる 所で 空が 見える すきまを 作らない（いまの 小ブロック地形では 置いた ブロックの 根もとに 空色の すきまが 出る。`texture-back-check.png` A。`TEX-A.md` 基準 9）。
- 作業台・チェストと いう ブロックは いまの ゲームに ない（しまう 物は たんす）。これから 道具の ブロックを 足す ときは この 表に 入れる。
- たいまつ・十字の板（作物・やせいの やさい・かかし・さく）・水は いまの まま（atlas の 絵）。
- 鉱石は 地形 なので 平らに しない（ほらあなで くらべて、平らに しても 目立ちかたは ほぼ 同じ。平らだと 石の かべの 中で「置いた ブロック」に 見える）。

### 5.4 小ブロック地形（VOX-2）
形は `src/proto/voxel/terrain/microSurface.ts` の `MICRO_PARAMS`。色は 4.2。
1. **地形の表情は 3×3 のかたまり単位**で決める（ふちが カクカク。なめらかな 丸いふちにしない）。
   - 小さな丘（2 マスずつの だんだん、最大 +7）/ くぼ地（だんだん、最大 −5）/ 草むら（かたまりごとに 0・1・2 マス）/ 土が見える所（1 マス へこむ・土の 絵。面の 1 割くらい）。
   - 平らな所は おだやかに（うねり ±1.6・ごつごつ ±0.6・かたまりのずれ ±1）。でこぼこは 表情の所に まとめる（メリハリ・三角形も へる）。
2. 1 ブロックの段差は 坂 6 割・崖 4 割（崖の下に がれき、上のふちに かけ）。岩は ブロックをまたぐ 3〜12 マス。
3. キャラの足もとが 土でも 見やすいこと（6 章）。スクショ: `docs/screenshots/VOX-2/micro-*.png`（色は 古い）。

## 6. キャラ（ピンクのパーカーのドット絵）との 見やすさ
- キャラの いちばん大きい色（ピンク）・白い髪 は、世界の どの色とも かぶらせない。世界に ピンク・マゼンタ・真っ白を 使わない（花を足すときも ピンクは さける。黄・だいだい・うす紫 は よい）。
- キャラの足もとに来る もの（くさ・つち・すな・いし）の 上の 面は、タイルの いちばん 暗い 点 × いちばん 暗い AO（0.45）でも 明るさ（V）20% 以上（黒い くつ・ズボンが 地面に とけない。つちの `#6F4520` は V 44% → 24%）。
- タイルの 明るい 点は 地の色の +2 割 まで（明るい 点が 多いと 白い髪が 目立たなくなる）。
- 丸い 影（3.3）で 足もとが 分かる こと。
- たしかめ方: `docs/art/texture-back/texture-back.png` の キャラの まわり・足もと 2 倍 で、キャラの りんかくが ひと目で分かること。

## 7. ねらったブロックのわく（置く場所の しめし方）
- 今のゲームと同じ **わく**（`TargetOutline`: 12 本の辺、黒 60%、ブロックより 0.004 大きい、太さ 0.022）を そのまま使う。地面に マス目は足さない。
- わくは ブロックの「箱」の辺に出す（けずった形には そわせない）。けずった かど でも 1 ブロックの大きさが 分かるように。
- 色は 今の 3 つ（ふつう 黒 / いま押して 黄 `#FFD54F` / できない 赤 `#E53935`）。点滅させない（`fun.md` 6）。「いま押して」の光は ゆっくり 明るさが変わる今のままでよい。
- くぼみの暗い所で 黒いわくが 見えにくいときは、本番で わくを「地面より手前に描く（重なりを無視）」か「太さ 0.03 まで」にしてよい（色は変えない）。

## 8. 空と霧
- 空 `#6EA8E0`・霧 `#A6C6E4`（near 100・far 360）。霧の色は 空より 明るく うすい青。
- 霧は 遠くを かくすためで、こわい 暗さ に使わない。夜・ほらあな を作るときは「こい青・むらさき」に寄せ、黒にしない。
- 時間で 空の色を変えるときも 点滅・急な変化はしない（数秒かけて 変える）。

## 9. 盛り上げのきまり（`docs/fun.md`）との関係
- 世界のブロックの **うごき（まばたき・ゆれ）・光る・つぶ は 15 章の「ブロックの予算」の中なら 入れてよい**（オーナー決定 2026-10-17 `docs/decisions/2026-10-17-biome-countries.md`。前の「動かない・光らない」より優先）。点滅は しない。画面いっぱいに出る物（地面・草・はっぱ）は とくに 控えめにする（くり返し見る物。`fun.md` 1）。
- ほる・おく の手ごたえ（かけら が とぶ など）は エフェクトの係が `fun.md` 1 のとおり 控えめに作る。かけら の色は そのブロックの タイルの 地の色 と 暗い 点の 色 の 2 色を使う（新しい色を足さない）。
- 紙ふぶき・花火 は 達成のとき だけ。世界の見た目のほうでは 出さない。

## 10. これから作るブロック（道具・建物・はたけ など）のきまり
1. 絵は 16×16 の タイル を [上, 下, 横] で 描く（4.3 の きまり。地の色 ＋ 近い色 1〜2 こ、点 30〜60）。pixel-artist が `textures.ts` と 同じ 形で 作る。
2. 形: 自然の 物（土・石・すな の なかま）は 5.2 の つち〜いし の 強さで でこぼこ。**人が 作った 道具・建物の ブロックは 5.3 の 平らな 箱**（表に 足す）。
3. 何の物か は **絵の もよう**で分かるようにする（色だけに たよらない）。前の main の 絵（かまどの 口・たんすの 引き出し・レンガの 目地・かわらの 波・スプリンクラーの 青い 線）と 同じ 考え。
4. 世界に ピンク・真っ白・真っ黒 を使わない（6 章）。
5. 三角形を 11 章の目安で たしかめる。

## 12. レビューの軽微な指摘（`docs/loop-ledger/VOX-1.md`）の 直し方の方針（まだ実装しない）

- **G1 木と草の形が マイクラに近い**
