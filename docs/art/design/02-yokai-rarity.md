- 印は 頭の グループ（顔の板の親）の子にする（首・かさ の動きに ついてくる）。位置の目安: からかさ = かさの 2 段め（y 1.43）・かんむりは てっぺん（y 1.6）、ちょうちん = どうの 上（ふたの上・えの まわり）、ろくろくび = 頭の上（まげの上）。ぬりかべ は かべの 上の はし（はちまき は かべの 上の方に まく、かんむり は てっぺん）（2026-10-23 #270 で 印が つくように なった）。
- **ひとだま**（2026-10-23 yuzu 決定、`docs/decisions/2026-10-23-nushi-hitodama.md`）: 14×20 ドット 6 コマで しっぽが 左右に ゆれ からだが 少し ふくらむ（約 9 コマ/秒、ゲームの 時間で 進める）。細い うねる しっぽ・下に 渦。頭の 左右に 1 つずつ、片方を 高く（身長の 0.88 倍・0.68 倍）、位相を ずらして 少し 上下。まわらない。大きさは 身長の 0.5 倍（0.45〜1.4）。十字の板（45° まわす）。
- 印は 夜も 同じ暗さに する（ひとだま だけは 暗くしない）。こわい顔にしない（顔の絵は 変えない）。
- 性能（からかさ 1 体）: たいしょう +4 回・+48 三角形、ヌシ +9 回・+108 三角形（同じ色の箱を 1 つの形に まとめれば もっと へる）。たいしょう・ヌシ は 同時に 1 体まで。

### 13.4 おの 3 本（かた刃）
- 形: つるはし と同じ **ななめの え**（左下 → 右上）の 上の方に、**片側だけの 大きな 刃**（右下へ ひろがる。刃先 1〜2 ドットは 明るい色）。うしろに 小さな みね。つるはし = T、くわ = L、おの = 片側の くさび で 16px でも 見分ける。
- 色（刃 / かげ / 刃先）: き `#C99860` / `#9A6A3A` / `#ECC890`、いし `#8A8A8A` / `#666666` / `#BDBDBD`、てつ `#E0E0E8` / `#A8A8B4` / `#FFFFFF`。え `#8A5A2E` / かげ `#5A3A1A`。まわり 1 ドットを `#2A1E14` で ふちどる（くわ と同じ）。
- マス: どうぐ の 背景 `--rk-cat-tool` `#2A5C99`。ふち 3px = めずらしさ（き・いし = 白 `#FFFFFF`、てつ = 青 `#7FB8FF`。`src/drops/rarity.ts` に つるはし と同じ段で 足す）。
- 手に持つ形（`src/camera/heldTools.ts` の Part の書き方）: え 0.05 角 × 0.55、みね 0.08×0.07×0.1、刃 0.16×0.04×0.12（横へ 0.1）、刃先 0.05×0.045×0.18（横へ 0.2）。色は 上と同じ（え は 今の `WOOD`）。
