## developer（形・光・いき・宝箱）
1. **鉱石 6 つ（B）**: `grain_block()` と 各 `*_layout` の 座標を そのまま 写す。面ごとに ブロックの 位置の ハッシュで がらを 1 つ（たね: せきたん 401・てつ 402・きん 403・すいしょう 404・ほたるいし 405・ダイヤ 408）。つぶは 表面に のこし、まわり 1 小ブロックの 表面を ほる。**ダイヤ だけ** みぞを もう 1 だん ほる（`dia_layout` の ほる マス）。地の いしは いまの つちと 同じ ほり方（4・2）。つぶの 色は 小ブロックごと（頂点色。TEX-A の 例外、鉱石の つぶ だけ・calm しない）。いまの `coal_ore`・`iron_ore` も B に 置きかえる。
2. **ほたるいし**: 光る 小ブロックは 自分の 色 × 強さ（芯 1.0・わの 十字 0.85・わの かど 0.55）で、面の 明るさ・AO を かけない。いき = ±12%・4 秒の サイン、3×3×3 小ブロックの まとまりごとに 位置で ずらす。「うごきを へらす」で 止める（強さは そのまま）。光 **7**、ほたる色 [0.80, 1.0, 0.74]・明るさ 0.35（ブロックの 光を たいまつ・ほたるの 2 本に 分ける。むずかしい ときは PO・art-director に 相談。20.4）。光を 通さない ブロック。置く 数は ふつう D の 少ない物（1 列 8 こ まで）、**ほたるの ほらあなだけ 例外で 見える 24〜32 こ**（仕様 §4.9。予算 §15.4 の 2）。
3. **ダイヤ**: 光らない・つぶ（パーティクル）なし。ほかは 1 と 同じ。
4. **ブロック A**: `nendo` = いまの つちと 同じ ごつごつ（4・2・ふち 5）、`sekkaiseki` = いまの いしと 同じ（6・3・7）、`shikkui`・`kodo_waku` = 平らな 箱。わくは 道の かべ・天井に うめて 柱 2 本 ＋ はり（道を せまく しない）。
5. **つらら**: 十字の 板（草花と 同じ。三角形 8）。天井の 下だけ・光を 通す・ゆれない。
6. **宝箱 4 段階 v2**（2 マス。こたつ 2×2 と 同じ「本体 ＋ のこりの マス」。仕様 §4.6）: `chest2.py` の `grids(段)` の 18×9×9（とじた・あけた）を 半分に 切って、**本体 = 前から 見て 左**（x 0〜8）・のこり = 右（x 9〜17）の 9×9×9 に する。前 = 見本の +z を へやの ほうに 合わせて まわす（向き 4 つ。id の 持ち方は developer。仕様 §4.4）。色は 部分ごとに 1 色（`PAL`。絵の 投影 なし）、1・2 の 木（からだ・ふた）だけ 16×16 の 木目の まだら（`mats_of()`）。区の メッシュに 足す（描画 +0）。三角形は 見本で 1 マス 106〜232（仕様 §4.9 の 1 マス 400 の 中）。
   - **あけた 形**は べつの ブロック（2 マス とも）。`grids(段)['open']`（ふたを うしろへ 90 度・中は からっぽ。マスの 外に 出る でっぱりは のぞいた 形）。区の メッシュで マスの 外に 出せる なら、動きの おわり（90°）と 同じ 形（でっぱりも のこす）に して よい（DESIGN 20.7）。
   - **ふたが あく 動き**（4 段階 とも 同じ・0.46 秒。**yuzu の 確認 なしで `chest-v2-open.gif` の とおり**〔2026-10-30 05:51〕）: `KEYS`（0 → 10° → 4° → 90° → 78° → 90°）と `EASE` の とおり。動く 間だけ ふた（`grids(段)['lid']`）を べつの メッシュに して ちょうつがい（y 4/9・z 3/9 の x に そった 線）の まわりに まわし、からだは `body_open`。おわったら あけた ブロックに かえる（描画 +1 は 0.46 秒 だけ）。90 度より うしろへ 行かない。「うごきを へらす」では すぐ あけた 形。光の 柱・音の 合わせ方は DESIGN 20.7。
7. **遠く**: 16 ブロックより 遠くの 鉱石は pixel-artist の 平らな 絵 ＋ いまの いしの 形【PO 確認】。
8. **たいまつ**: いまの たいまつ（新しい 絵 なし。こわせる・持って かえれる）。
9. **たしかめ**（見た目が 変わる ので テストの 準備の 前に yuzu の OK。CLAUDE.md の 3）: ゲームの 中で `mix.png` §7 と 同じ 場面（いちばん 下の へやと 宝箱・ふかい 層の ダイヤ・ほたるの ほらあな・しょうにゅうどうの つらら・ちていこの きし・坑道の さか道）と、`chest-v2.png` と 同じ ならび（宝箱 4 段階の とじた・あけた）を 撮る。ほたるいしの いきと 宝箱の ふたの 動きは `window.__rikkun` で 一時停止・コマ送り して GIF（ふつう ＋ 4 倍 おそい）。ふたの 動きの GIF は art-director・PO が 見る（yuzu には 見せない。05:51）。スクショと GIF は PO に わたす（PO → yuzu）。art-director が 見る 点: つぶの 出かた（みぞの 影）・ダイヤの ひし形・ほたるの 光の 広がり（まわり 1 マス）・宝箱の 影と 色・あけた 形・ふたの 動き（20.7）・遠くの 切りかえ。性能は `npm run perf` で 描画回数・三角形を くらべる（§20.8: ほたるいしの 多い 部屋で 約 +3 割まで）。
