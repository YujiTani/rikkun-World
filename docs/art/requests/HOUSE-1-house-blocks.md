## やる こと

### 1. ブロック 3 つ（平らな 箱。DESIGN 5.3 の 表に 足した）
1. タイル 12 まいを atlas に 足す（16×16・Nearest。名前は 案 → developer が 決める）。絵は `houseLookTiles()` の まま（シード つき。Math.random なし）。
2. `house_floor` ＝ [hl_floor_top, hl_floor_side, hl_floor_side]、`house_wall` ＝ [hl_wall_top, hl_wall_top, hl_wall]、`house_roof` ＝ [hl_roof_top, **hl_ceiling**, hl_roof_side]（やねの 下の 面 ＝ 家の 天井）。
3. 形は ただの 1 ブロックの 箱（9×9×9 の でこぼこを 付けない。`gotsugotsu` などの Look に 足さない）。影・AO は ほかの 平らな 箱と 同じ。

### 2. しょうじ（小物。光を 通す）
1. 箱 3 つ（`shojiBoxes()`。点 = 1/16、+z = 家の 外）: **紙の 板** [0, 0, 1.5]〜[16, 16, 14.5]（前・うしろ ＝ hl_shoji。**前・うしろの 面 だけ 描く**: 上下は かべ、左右は となりの かべに うまる）、**窓台** [−1, −1, −2]〜[17, 1, 18]・**上の 横木** [−1, 15, −2]〜[17, 17, 18]（hl_shoji_edge。6 面）。
2. **紙は いつも 中から 明るく 見える**（`glow`）: 紙の 面だけ 頂点の 光を 空の光 0・ブロックの光 0.8（12/15）、面の こさ 1 に する（ちょうちんの「自分で 光る」と 同じ 考え）。日の 影を うけず、どの かべの 窓も 同じ 明るさ、よるは あかりの 色。まわりの 光の 計算は かえない。
3. **向きが 2 つ**: まえ・うしろの かべ と ひだり・みぎの かべ（x と z を 入れかえた 形。`swapXZ`）。ふとんと 同じく id を 分ける か 向きを 持つ（developer が 決める）。建築士さんは かべの 向きで 置く。手で 置く ときは プレイヤーの 向き。
4. まわりの かべの 面（窓の 左右の あなの 面）は ふつうに 見える 面と して 描く。
5. 光: 不透明度 0（小物と 同じ）。妖怪・プレイヤーは 通れない（仕様 §4.6 の 表）。

### 3. いえの と（2 マス・あく／しまる。小物）
1. しめた 形: 1 マス ごとに 板 1 まい [0, 0, 12]〜[16, 16, 16]（外がわ より、あつみ 4 点）。前・うしろ ＝ hl_door_low（下の マス）／ hl_door_up（上の マス）、ふち ＝ hl_door_edge。上下の 面は 描かない。2 まいの あわせ目・てつの おび・しんちゅうの わの 取っ手は 絵。
   - **戸わく と ひさし**（`DOOR_FRAME`。あいても しまっても 同じ。下の マスに 持たせ、点は 下の マスの 左前 下から）: はしら [−2, 0, −1]〜[1, 32, 17]・[15, 0, −1]〜[18, 32, 17]、かもい [−2, 30, −1]〜[18, 33, 17]（hl_shoji_edge。外と 中へ 1 点 出る）、ひさし [−4, 33, 16]〜[20, 35, 20]（上 hl_roof_top・横と 下 hl_roof_side。外 だけ）。**かべに うまる 面は 描かない**（`skip`: はしらの 外がわの 横と 上・かもいの 左右と 上・ひさしの うしろ）。
2. あけた 形: 外へ 90 度、左右に 2 まい（[0, 0, 16]〜[4, 16, 24] と [12, 0, 16]〜[16, 16, 24]。大きな 面に とびらの 絵、右の とびらは 絵を 8 点 ずらす）。
3. **向きが 4 つ**（戸は まえ・みぎ・うしろ・ひだり の かべ。外 ＝ 家の 外がわ）。ふとんの `turnBox` と 同じ やり方で まわす。
4. あく・しまるは 形が 入れかわる だけ（動きの GIF は いらない。yuzu 2026-10-30「決まった見た目に付く小さな動きは GIF 確認を省く」）。音は サウンド チーム。
