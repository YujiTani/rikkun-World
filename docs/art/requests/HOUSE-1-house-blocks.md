## やる こと

### 1. ブロック 3 つ（平らな 箱。DESIGN 5.3 の 表に 足した）
1. タイル 12 まいを atlas に 足す（16×16・Nearest。名前は 案 → developer が 決める）。絵は `houseLookTiles()` の まま（シード つき。Math.random なし）。
2. `house_floor` ＝ [hl_floor_top, hl_floor_side, hl_floor_side]、`house_wall` ＝ [hl_wall_top, hl_wall_top, hl_wall]、`house_roof` ＝ [hl_roof_top, **hl_ceiling**, hl_roof_side]（やねの 下の 面 ＝ 家の 天井）。
3. 形は ただの 1 ブロックの 箱（9×9×9 の でこぼこを 付けない。`gotsugotsu` などの Look に 足さない）。影・AO は ほかの 平らな 箱と 同じ。

### 2. しょうじ（小物。光を 通す）
1. 紙の 板 1 まい: 点で [0, 0, 7.5]〜[16, 16, 8.5]（かべの あつみの まん中）。前・うしろ ＝ hl_shoji、ふち ＝ hl_shoji_edge。**上下の 面は 描かない**（上と 下は かべ）。
2. **向きが 2 つ**: まえ・うしろの かべ（紙が 東西に のびる）と ひだり・みぎの かべ（[7.5, 0, 0]〜[8.5, 16, 16]）。ふとんと 同じく id を 分ける か 向きを 持つ（developer が 決める）。建築士さんは かべの 向きで 置く。手で 置く ときは プレイヤーの 向き。
3. まわりの かべの 面（窓の 上下左右）は ふつうに 見える 面と して 描く（ここが「へこんだ しょうじ」の あつみに 見える）。
4. 光: 不透明度 0（小物と 同じ）。妖怪・プレイヤーは 通れない（仕様 §4.6 の 表）。

### 3. いえの と（2 マス・あく／しまる。小物）
1. しめた 形: 1 マス ごとに 板 1 まい [0, 0, 12]〜[16, 16, 16]（外がわ より、あつみ 4 点）。前・うしろ ＝ hl_door_low（下の マス）／ hl_door_up（上の マス）、ふち ＝ hl_door_edge。上下の 面は 描かない。2 まいの あわせ目・てつの おび・わの 取っ手は 絵。
