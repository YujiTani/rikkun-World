## 開発への申し送り（ゲームに入れるときに要る物）
1. **新しいブロック（デザイン・PO に知らせる）**: VOX-I §5 の 12 種に 足して **まつの はっぱ**（形 2 の たな。まつの みきは 今の き。見本の 赤い みきは 色の目安）と **とうろう**（火の 1 ブロック。光 14。VOX-I は「いし＋たいまつ」なので 置きかえ）。すいしょうの 光 9 は まわり 3〜4 マスを「暗い所」でなくするので、妖怪の出かた（`isDarkForSpawn`）への 影響を デザインが 決める。
2. **アニメの しくみ（三角形・描画回数 +0）**: 面の 頂点に タイルの番号は もう ある → 「アニメの表」（タイル番号 → コマ 3 まいの番号・間の秒数の はば・ふだんの コマ）を 小さな uniform か DataTexture で わたし、シェーダーで `time` と 場所の ハッシュから コマを えらぶ。メッシュは 作り直さない。小ブロックの半径の外・「うごきを へらす」では コマ 1。
3. **ときどき の 絵**: メッシュを作るとき、面ごとに `hash(x, y, z, 面)` で ときどきの絵に 差しかえる（ブロックの種類ごとの表: 絵・わりあい・どの面か・地上だけか）。地上だけ（ねむり岩）は その面の 空の光 > 0 で きめる。Math.random なし。
4. **ゆれ**: 十字の板（すすき・はな・ひまわりの 上の段）の 頂点シェーダーで、上の頂点だけ `A·sin(2π(t/4) + (wx+wz)·0.35)`、A = 1/16。根もとは 0。
5. **光・いき**: `src/world/light/opacity.ts` の `EMISSION` に すいしょう 9・とうろう 14。すいしょうの 面は 夜も 暗くしない（自分の色）＋ 明るさ ×(1 + 0.08·sin(2πt/4 + 場所)) 。点滅なし。
6. **つぶ**: 1 しゅるい 1 つの `Points` か `InstancedMesh`（描画 +1）。すいしょう: 24 ブロック以内の すいしょうから 3〜5 秒に 1 つぶ、1.5 秒で 出て きえる、画面 16 まで。もみじ: 下が空いた 16 ブロック以内の もみじの はっぱ から、0.5 ブロック/秒で ひらひら 落ちて 地面で きえる、画面 12 まで。乱数は シード付き。
7. **形（`fill`）**: たけ（くねくね・16 ブロック以内）・き（こぶ）・もみじ（とげとげ）・まつの はっぱ（たな）・ゆき（おもち）・おちば（もりもり）・はすの は（そり）・すいしょう（たば）。見本の形は `tools/sheets.py`・`extra.py` の `sh_*`。本番は MagicaVoxel / Goxel の .vox から。地面に 広く並ぶ ゆき・おちば は 小ブロック地形（§5.4）の 表面の種類に 足し、形 2 は 段の へり（まるい おもちの ふち・もりもりの でこぼこ）に 使う。
8. **テストで読めるように**（`window.__rikkun`）: ブロックごとの アニメ の 今のコマ・ときどき の絵か・光の強さ・つぶの数・「うごきを へらす」の 状態。予算の数（三角形・タイル・つぶの上限）は テストで 1 種類ずつ 確かめられる。
9. **性能**: perf-engineer が `npm run perf` で たけやぶ・もみじやま・おおきな きの もり・ゆきやま を はかる（どの国も 903,036 以下・r=32 で 120 万以下・描画回数 +2 まで）。fps は オーナーの Mac の F3。
10. **見た目の OK**: 見本シートで 決めない。ゲームに入れた 試作の スクショで オーナーの OK（rules C）。顔の絵は オーナーの見本を もらってから 描き直す。
