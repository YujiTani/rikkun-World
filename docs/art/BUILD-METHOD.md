# 目立つ 建物の 作り方（門の ときの やり方。1 ページ）

街の 門（楼門）を 作った とき うまく いった 流れ。**めだつ 建物**（遠くから 見て 主役に なる 物。いまは 門だけ）に 使う。ほかの 建物は 今の 作りこみの まま（`docs/design/TOWN-1-place.md` §2.2b・「細かい 作りこみは 門だけ」）。

## 流れ

1. **参考画像を 集める**（アートの 係）。リポジトリには 置かない（共有フォルダ `town/ref/`）。
2. **アートの 係が 1/16 の 箱の 設計を 作る**: パーツ（形ブロック）ごとに 箱 `[x0, y0, z0, x1, y1, z1, 絵]` を 1/16 単位の 整数で 決め（1 パーツ 8 箱 以内・光らない・新しい 絵は 少なく）、全体の 絵（`gate-design.png`）と、**方眼の 設計図**（段ごとの 表 `gate-layers.md`・パーツ表 `gate-parts.md`・方眼の 絵）を 出す。表は 絵を 作った スクリプトから **そのまま 書き出す**（絵と 表は 同じ 1 つの データ。手で 書かない）。
3. **オーナーに 見せる**（設計の 絵と 方眼）。OK が 出て から 実装へ。
4. **開発の 係が 表を 機械で 写して 建てる**: `src/town/townGateLayers.ts`（段ごとの 表）・パーツは `src/world/blocks/townDecoGate.ts`。**表は 写経せず、書き出した ものを スクリプトで 取りこむ**（写しまちがいが 起きない）。ユニットで「箱の 角は 0〜16 の 整数・光る 物 なし・寸法」を 確かめる（`townGate.test.ts`）。
5. **スクショ**を 撮って 設計の 絵と くらべ、オーナーに 見せる（`/mnt/project-files/town/shots/`。deviceScaleFactor 2・プレイヤーが 被写体に 重ならない 所から。自分で 開いて 見る）。

## 道具

`/mnt/project-files/town/art/gate/tools/`（リポジトリの 外）。`gate_model.py`（パーツと 置き方の データ）・`render.py`（絵）・`make_grid.py`（方眼）・`make_docs.py`・`make_sheets.py`（表と 一覧の 書き出し）。使う ときは そのフォルダを 作業場に コピーして、`python3 make_grid.py <出力先>` のように 動かす。新しい 建物を 作る ときも この 道具の データの 部分だけ 差しかえる。

## 気を つける 所

- 向きは 1 つだけ（正面が 東の 形）で 書き、4 向きは `face()` の 式で 作る（今の 門と 同じ）。
- あかりの 数（ちょうちん・あんどんの 上限）を 食わない。光る パーツは 作らない。
- 参考画像・大きな 絵は リポジトリに 入れない。入れて よい のは 表（コード）と この メモだけ。
