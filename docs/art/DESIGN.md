## 1. ひとことで

**手で ほった ジオラマ（もけい）の 島に、最初の ドット絵を はった もの。**
1 ブロック = 9×9×9 の 小ブロック。形は「3×3 の かけら」で ごつごつ。**色は 1 ブロックの 各面に 16×16 の 絵を そのまま うつす**（でこぼこの 小ブロックは、その 場所の 画素の 色）。
影は 色で ぬらない。**面の 向きの 明るさ・すみの 暗がり（AO）・キャラの 丸い 影** で 出す。人が 作った 道具の ブロックは でこぼこに せず、まっすぐな 1 ブロックの 箱（「作った 物は まっすぐ、自然は ごつごつ」）。

なぜ 見やすいか（マイクラを 調べた きまり。絵は 写さない。くわしくは `texture-back.md` 1 章）:
1. 物ごとに 色の なかまが はっきり ちがう（草・土・石・砂・木）。
2. 1 まいの 絵の 中は 地の色 ＋ 近い色 2 こ くらい。明るさの 差は ±1〜2 割（点で ざらざら させすぎない）。
3. **形の 段（1/9）と 絵の 点（1/16）の 大きさが ちがう** → 目が「形」と「模様」を 分けられる。
4. 面の 向きで 明るさが 決まっている（3 章）。

## 2. 小ブロックと ドット感

| きまり | 値 |
|---|---|
| 小ブロックの大きさ | 1/9 ブロック（9×9×9）。形の 単位 |
| 絵の 点の 大きさ | 1/16 ブロック（16×16 の タイル）。色の 単位。小ブロックとは そろえない |
| 形の単位 | 3×3（面）・3×3×3（かど・かたまり）。1 マスの単位は「草の芽」「みぞ」だけ |
| ふち線（輪郭の線） | 描かない。りんかくは 形（けずった かど）と 面の 明るさ・AO で 出す |
| 色の 付け方 | **場所 だけで 決める**: 面の 向き ＋ ワールドの 座標 → タイルの 画素（4.1）。同じ 場所は いつも 同じ 色。Math.random なし |
| 絵の 数 | 1 ブロックに [上, 下, 横] の 3 まい（`BLOCK_TILES`）。4 つの 横は 同じ 絵 |
| 遠く | 40 ブロックから 80 ブロックへ、画素の 色を タイルの 平均色へ なめらかに よせる（ミップの かわり。上空で ちらつかない）。80 より 遠くと LOD は 平均色 だけ（4.4） |

## 3. 影の きまり（3 つとも 入れる）

光の 明るさ（空の光・ブロックの光・昼夜 = いまの `lightShader`）は 変えない。色 = **タイルの 画素 × (1) 面の 明るさ × (2) AO × 光**。(3) は キャラの 足もと だけ。

### 3.1 (1) 面の 明るさ（マイクラ式）

| 面 | 上 | 南・北（±z） | 東・西（±x） | 下 |
|---|---|---|---|---|
| 明るさ | **1.0** | **0.8** | **0.6** | **0.5** |
| （前: 9×9×9 の 前の main と いま） | 1.0 | 0.8 | 0.8 | 0.6 |

- **決めた わけ**:
  1. いちばん 多く 見える 上の 面と、スタートの 向き（北）で 見える 南北の 面は 最初の main と 同じ 1.0・0.8。最初の main の 見え方（明るさの ふんいき）は ほぼ そのまま（地面の 平均の 明るさ −3%）。
  2. 東西を 0.6 に 下げると、1 ブロックの 見える 2 つの 横の 面の 明るさが ちがう ので、**箱の たての かどが 見える**。平らな 道具の 箱・段・崖が 箱に 見える（最初の main では 2 つの 横が 同じ 0.8 で、かどは 絵の ふち だけ で 分かっていた）。
  3. オーナーが 選んだ 見本（`texture-back-shade.png` の「(a) ＋ (1)(2)(3) 全部」の 行）は この 値。
  4. 費用 0（数字 だけ）。
- 小ブロックの 面・箱の 段・平らな 道具の 箱・LOD・水 …… **世界の ブロックの 面は 全部 同じ 値**（となりどうしで 明るさが くいちがわない）。たいまつ・十字の 板は いまの まま。値は `src/world/render/config.ts` の 1 か所に おく。
- オーナーが Mac で 見て「最初より 暗い」と 感じたら、東西 0.8・下 0.6（前の 値）に もどせる ように する（数字の 置きかえ だけ）。

### 3.2 (2) 角の 暗がり（AO）

- **小ブロックの 面**: 面の 4 すみ ごとに、面の 前の 層で となりの 2 つ（s1, s2）と かど（c）の 小ブロックを 見る。`s1 && s2 → 3`、それ以外は `s1 + s2 + c` の 段。明るさ = 段 0: **1.0**・1: **0.82**・2: **0.68**・3: **0.55**。面の 中は 4 すみ から なめらかに（双線形）。
- **平らな 道具の 箱**: 1 ブロック 単位で 同じ 式（となりの ブロック で 見る。マイクラと 同じ）。箱の まわりの 地面の 小ブロックは 箱を「全部 つまった 9×9×9」と して 見る（箱の 根もとが 暗く なる）。
- **箱の 段（r より 外）・LOD**: AO なし。r の 8 ブロック 手前から r で AO を 1.0 へ なめらかに 消す（段の 切りかえで ぱっと 変わらない）。
- **三角形を ふやさない 作り方を 第一案に する**（試作の 頂点 AO は 三角形 約 2.6 倍 だった）。作り方・上限・こえた ときは `TEX-A.md`。
- 暗い 所（夜・ほらあな）でも 同じ 割合で かける（空の光・たいまつの光 どちらにも）。
- 見え方の 目安: 段の 根もと・へこみの 底・木の 根もとが 少し 暗く なる。真っ黒に しない（いちばん 暗くて 0.55）。

### 3.3 (3) キャラの 丸い 影

- 足もとに ふちの ぼけた 丸 1 まい。大きさ 0.9 ブロック。中心の こさ 0.55 → 6 割の 所で 0.4 → ふちで 0。
- **まぜ方は かけ算**（地面の 色 ×（1 − こさ））。色を 足さない（暗い ほらあなで 青く うかない）。霧は かけない。
- 置く 高さ: 足の 下の いちばん 上の 固い ブロックの 上 ＋ 0.13（小ブロック 1 こ ぶんの でこぼこに うもれない）。重なりの 判定は する（かべの むこうには 出ない）。
- 高く とぶ ほど 小さく うすく（地面から h ブロックで こさ・大きさ ×(1 − h/6)、大きさは 0.6 倍 まで）。6 ブロック より 上では 出さない。
- **キャラの 板より 先に 描く**（あとに 描くと 影が くつの 上に のる）。
- 水の 中（足が 水の ブロックの 中）・水の 上では 出さない。
- 描画回数 +1・三角形 +2。妖怪には まだ 付けない（あとで 決める）。
- 太陽・たいまつの 位置から 計算する 影は #144（ここの きまりと ぶつかる ときは #144 で 決めなおす）。

## 4. 絵（タイル）の きまり

### 4.1 そのまま 投影
- 面の 向きで [上, 下, 横] の タイルを えらび、面の 中の 位置（ワールド座標の 小数部）を 16 倍して 画素を 読む。上・下 = (x, z)、東西の 横 = (z, y)、南北の 横 = (x, y)。**絵の 上（行 0）が ブロックの 上**。左右の 向きは 9×9×9 の 前の main（`meshChunk.ts` の `pushFace` の UV）と 同じに する（試作 `texShader.ts` は これで 合わせた）。
- **でこぼこの 小ブロックは、その 場所の 画素の 色**（へこみの 底も、まわりの 面の 絵の つづき。3D の 模様は 使わない）。
- 色は sRGB の 絵を 線形に して から 3 章の 明るさを かける。
- 形の 決まった 絵（たんす・かまど・鉱石・レンガ・かわら）も そのまま 見える こと（9×9 に 縮めない）。

### 4.2 小ブロック地形（草の 横）
- てっぺんの 面は 上の 絵（grass_top など）。
- 横に 見える 面は、**その 場所の 地面の てっぺんから 何 小ブロック 下か** で grass_side の 行を 決める（1 小ブロック = 16/9 行）。しばふの 帯（上の 4 行 = 小ブロック 約 2.25 こ）が でこぼこに そって つき、その 下は 土の 絵。16 行より 下は dirt の 絵を くり返す。
- 土の 見える 所（`microSoil`）は dirt の 絵。岩は stone の 絵。

### 4.3b ざわざわを へらす（#194、2026-10-17 オーナー決定 E）
- 自然の ブロック（くさ・つち・いし・すな・き・はっぱ・そこいし、鉱石の 地の いし）は、4.3 の 絵を **地の色へ 明暗を 半分（contrast 0.5）・彩度 8 割（saturation 0.8）** に おさえて 使う（`TILE_CALM`・`calmColor`、式は `docs/tickets/CALM.md`）。点の 場所は 変えない。

### 4.4 遠くの 箱の 段・LOD
- **箱の 段**（小ブロックの 外〜48）: 1 ブロックの 箱に、4.1 と 同じ 投影（近くと 同じ 絵・同じ 色）。でこぼこと 小ブロック地形は 出ない。
- **LOD**（その 外）: 面ごとに タイルの **平均色** × 3.1 の 明るさ（上・南北・東西）。いまの `lodMesh.ts` の 平均色（`tileAverage`）の まま。
- 近く → 箱 → LOD で 同じ ブロックの 同じ 向きの 面の 平均の 色が ±6% に おさまる こと（2 章の「遠く」の よせかた で つなぐ）。

### 4.5 夜・ほらあな・水
- 夜・ほらあなの 暗さ・たいまつの 光（あたたかい 色あい）は いまの しくみの まま（`lightShader`）。絵が 変わる だけ。
- 鉱石は ほらあなの かべで 最初の main と 同じ くらい 見える こと（`texture-back-check.png` B）。
- 水は 水の 絵（すけ）の まま。水ごしに 底の 絵が 見える。

## 5. 形のきまり（でこぼこ）

### 5.1 共通
1. **へこませるのは 見える面の側だけ。** 見えない面（となりに くっつく面）の外側の層は ぜんぶ つめる（`dentable`）。これを守らないと ブロックのさかいに すきまが見える。
2. へこみの深さは **1〜3 マス**（1/9〜1/3 ブロック）。2 マス以上の へこみを 面の 2〜3 割に入れる（「ごつごつ」と分かる深さ）。
3. 見える面が 2 つ出会う **へり・かど** は、3×3×3 の かたまり ごとに けずる（崖・山・岩の シルエットを ごつごつに）。
4. 1 マスの ばらばらの穴は 作らない。単位は 3×3 の かけら。1 マスの物は「草の芽」「木の みぞ」だけ。
5. ブロックの外（9 マスの外）には はみ出さない（となりと重なる・当たり判定と ずれる）。
6. **人が 作った 道具の ブロックは でこぼこに しない**（5.3）。

### 5.4 小ブロック地形（VOX-2）
形は `src/proto/voxel/terrain/microSurface.ts` の `MICRO_PARAMS`。色は 4.2。
1. **地形の表情は 3×3 のかたまり単位**で決める（ふちが カクカク。なめらかな 丸いふちにしない）。
   - 小さな丘（2 マスずつの だんだん、最大 +7）/ くぼ地（だんだん、最大 −5）/ 草むら（かたまりごとに 0・1・2 マス）/ 土が見える所（1 マス へこむ・土の 絵。面の 1 割くらい）。
   - 平らな所は おだやかに（うねり ±1.6・ごつごつ ±0.6・かたまりのずれ ±1）。でこぼこは 表情の所に まとめる（メリハリ・三角形も へる）。

## 8. 空と霧
- 空 `#6EA8E0`・霧 `#A6C6E4`（near 100・far 360）。霧の色は 空より 明るく うすい青。

### 15.3 うごき・光る・つぶ
| | 上限 |
|---|---|
| まばたき（顔の ある 絵） | 1 回 **0.2 秒**（はんめ 0.05 → とじる 0.1 → はんめ 0.05）。間は **3 秒 以上**（種類ごとに 3〜12 秒の はばで、場所で ずらす。そろって まばたき しない）。「ふだん 閉じて いて ときどき ぱちっ」も 同じ 数 |
| ゆれ（十字の板 だけ） | 上の はしで **1/16 ブロック まで**、1 往復 **3 秒 以上**。となりと 少しずつ ずらす（風の なみ）。下（根もと）は うごかさない |
| うごく 場所 | 小ブロックの 半径（r = 32）の 中だけ。外は コマ 1（ふつう）の まま |
| 光る（ブロックの 光） | 光の 強さ **9 まで**（たいまつ 14 の「少し 明るい」が 3 マス くらい）。たいまつ と 同じ 14 は 「たいまつ を 中に 持つ 物」（とうろう）だけ。自分の 色は 夜でも 見える（暗く しない） |
| いき（光る 物の 明るさの ゆっくりした 変化） | 1 回 **2 秒 以上**、明るさ **±15% まで**。なめらかに（サイン）。光る 物 だけ |

### 15.4 安全（予算より 先。こえたら だめ）
1. **強い 点滅は しない**（rules D・`fun.md` 6）。明るさを 変える 物は 1 秒に 3 回より はやく 変えない ことに 加えて、ここでは **2 秒より はやく 変えない**（15.3 の いき）。赤い 光・白い ぴかっ は 使わない。
2. 画面の 広い 所（地面・はっぱ・草）を **同時に 同じ 明るさで 変えない**（場所で ずらす）。地面の ブロックは 光らない（光るのは D の 少ない物 だけ）。
3. **くり返し 見る 物は 控えめ**（`fun.md` 1）: 見つけても 音・演出は 足さない。まばたき・ゆれは 同じ 大きさの まま（続けても 大きく しない）。紙ふぶき・花火 は 世界の ブロックでは 出さない（達成の とき だけ。`fun.md` 2）。
4. 「うごきを へらす」設定（端末の 設定も）で、まばたき・ゆれ・いき・つぶ は **ぜんぶ 止まる**（顔は コマ 1、光は 一定）。光る こと（光の 強さ）は のこす（暗い 所の 見え方が 変わらない ように）。
5. こわく しない: 顔は 地上（空の 光が ある 面）だけに 出す 物を 決めて よい（ねむり岩）。ほらあな・夜に 目だけ 光る 絵は 作らない。
