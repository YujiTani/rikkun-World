## 1. ひとことで

**手で ほった ジオラマ（もけい）の島。** 草むら・けずった岩・ほりかげ。
1 ブロック = 9×9×9 の小ブロック。形は「3×3 の かけら」で作り、1 マスの ばらばらの つぶ（ノイズ）は使わない（マイクラの「ざらざらの箱」から はなれる・三角形も へる）。
光で かげを作るのではなく、**へこみの底ほど 暗い色**を ぬって かげに見せる（ほりかげ）。

## 2. 小ブロックとドット感

| きまり | 値 |
|---|---|
| 小ブロックの大きさ | 1/9 ブロック（9×9×9） |
| 形の単位 | 3×3（面）・3×3×3（かど・かたまり）。1 マスの単位は「草の芽」「みぞ」だけ |
| ふち線（輪郭の線） | 描かない。りんかくは 形（けずった かど）と 明るさの段で出す |
| 色の付け方 | ブロックの中の 位置だけで決める（同じ場所は いつも同じ色。Math.random なし） |
| 色の数 | 1 つの もの 4 段（下の表）。パレット全体で 255 色まで |

## 3. 明るさの段（ほりかげ）

どの もの も 4 段の色を持つ。「ブロックの いちばん近い面からの深さ」で決める。

| 段 | 深さ | 使い方 |
|---|---|---|
| 外 1 | 0 | ふつうの面 |
| 外 2 | 0 | 3×3 ごとに 3 枚に 1 枚（まだら。つぶ ではなく かけら） |
| 1 段内 | 1 | へこみの底・草むらの すきま |
| 2 段内 | 2 以上 | 深い へこみ・くぼみの底 |

- 外 1 → 2 段内 で 明るさ（HSV の V）を 4〜5 割 下げる。2 段内を 黒に近づけない（遠くで 汚れ・穴に見える）。
- 上の面ほど明るく（草の先・はっぱ の上の段）、下ほど暗い。

## 5. 形のきまり（でこぼこを はっきり強く）

### 5.1 共通
1. **へこませるのは 見える面の側だけ。** 見えない面（となりに くっつく面）の外側の層は ぜんぶ つめる（`dentable`）。これを守らないと ブロックのさかいに すきまが見える。
2. へこみの深さは **1〜3 マス**（1/9〜1/3 ブロック）。2 マス以上の へこみを 面の 2〜3 割に入れる（「ごつごつ」と分かる深さ）。
3. 見える面が 2 つ出会う **へり・かど** は、3×3×3 の かたまり ごとに けずる（崖・山・岩の シルエットを ごつごつに）。
4. 1 マスの ばらばらの穴は 作らない。単位は 3×3 の かけら。1 マスの物は「草の芽」「木の みぞ」だけ。
5. ブロックの外（9 マスの外）には はみ出さない（となりと重なる・当たり判定と ずれる）。
6. 人が作った物（かまど・れんが・かわら・たんす・スプリンクラー）は けずりを弱く（自然の物より 1/3 くらい）。「作った物は まっすぐ、自然は ごつごつ」で 見分ける。

### 5.3 平らな地面の「マス目」について
- 地面に さかい線・マス目は **足さない**（オーナー決定）。
- 見えない面の層を つめるきまり（5.1-1）のせいで、くぼみが ブロックのはしに来ると 1 マスの「へり」が のこる。くぼみは 3 割までにして、つまった しばふ・草の芽 と まぜ、へりが 線のように 続かないようにする（いまの割合で 線には見えない。スクショで確認ずみ）。

### 5.4 小ブロック地形（VOX-2 の試作 `?terrain=micro`。まだ オーナー確認前）
形は `src/proto/voxel/terrain/microSurface.ts` の `MICRO_PARAMS`、色は `gotsugotsu.ts` の `terrainColor`。
1. **地形の表情は 3×3 のかたまり単位**で決める（ふちが カクカク。なめらかな 丸いふちにしない）。
   - 小さな丘（2 マスずつの だんだん、最大 +7）/ くぼ地（だんだん、最大 −5）/ 草むら（かたまりごとに 0・1・2 マス。すきまが 2 段内の色）/ 土が見える所（1 マス へこむ・土の色。面の 1 割くらい）。
   - 平らな所は おだやかに（うねり ±1.6・ごつごつ ±0.6・かたまりのずれ ±1）。でこぼこは 表情の所に まとめる（メリハリ・三角形も へる）。
2. 1 ブロックの段差は 坂 6 割・崖 4 割（崖の下に がれき、上のふちに かけ）。岩は ブロックをまたぐ 3〜12 マス。
3. 色: てっぺんは となりが高いほど 暗い（1 マス = 1 段内、2 マス以上 = 2 段内）。横に見える しばふは 上から 2 マスめ = 外 2、3 マスめ = 1 段内（上の面ほど明るい）。しばふ は 3〜4 マスで、その下は 土。
4. キャラの足もとが 土でも 見やすいこと（土の 2 段内 `#4A2D1C` は V 29%）。スクショ: `docs/screenshots/VOX-2/micro-*.png`。
5. 性能（hybrid r=16、2026-10-16）: スタート 21.2 万三角形・10.0 MB、上空 63.2 万・16.5 MB、作り直し 中央値 46 ms。

## 6. キャラ（ピンクのパーカーのドット絵）との 見やすさ
- キャラの いちばん大きい色（ピンク）・白い髪 は、世界の どの色とも かぶらせない。世界に ピンク・マゼンタ・真っ白を 使わない（花を足すときも ピンクは さける。黄・だいだい・うす紫 は よい）。
- キャラの足もとに来る もの（くさ・つち・すな・いし）の 2 段内は 明るさ（V）20% 以上（黒い くつ・ズボンが 地面に とけない）。
- 草の先 `#8CCB55` は 面の 1 割以下（明るい点が 多いと 白い髪が 目立たなくなる）。
- たしかめ方: `gotsugotsu-char-front.png` / `-char-side.png` で、キャラの りんかくが ひと目で分かること。

## 7. ねらったブロックのわく（置く場所の しめし方）
- 今のゲームと同じ **わく**（`TargetOutline`: 12 本の辺、黒 60%、ブロックより 0.004 大きい、太さ 0.022）を そのまま使う。地面に マス目は足さない。
- わくは ブロックの「箱」の辺に出す（けずった形には そわせない）。けずった かど でも 1 ブロックの大きさが 分かるように。
- 色は 今の 3 つ（ふつう 黒 / いま押して 黄 `#FFD54F` / できない 赤 `#E53935`）。点滅させない（`fun.md` 6）。「いま押して」の光は ゆっくり 明るさが変わる今のままでよい。
- くぼみの暗い所で 黒いわくが 見えにくいときは、本番で わくを「地面より手前に描く（重なりを無視）」か「太さ 0.03 まで」にしてよい（色は変えない）。

## 8. 空と霧
- 空 `#6EA8E0`・霧 `#A6C6E4`（near 100・far 360）。霧の色は 空より 明るく うすい青。
- 霧は 遠くを かくすためで、こわい 暗さ に使わない。夜・ほらあな を作るときは「こい青・むらさき」に寄せ、黒にしない。
- 時間で 空の色を変えるときも 点滅・急な変化はしない（数秒かけて 変える）。

## 9. 盛り上げのきまり（`docs/fun.md`）との関係
- 世界のブロックは 動かない・光らない・点滅しない。ゆれる草・光る鉱石 は 足さない（画面いっぱいに出るので 目が つかれる。くり返し見る物は 控えめ）。
- ほる・おく の手ごたえ（かけら が とぶ など）は エフェクトの係が `fun.md` 1 のとおり 控えめに作る。かけら の色は そのブロックの 外 1・1 段内 の 2 色を使う（新しい色を足さない）。
- 紙ふぶき・花火 は 達成のとき だけ。世界の見た目のほうでは 出さない。

## 10. これから作るブロック（かまど・れんが・はたけ など）のきまり
1. 4 段の色（外 1・外 2・1 段内・2 段内）を作る。外 1 → 2 段内 は 明るさを 4〜5 割 下げる（3 章）。
2. 形は 3×3 の かけら で作る。自然の物は 5.2 の つち〜いし の強さ、人が作った物は 弱く（2 / 0、かど 0）。
3. 何の物か は **形の もよう**で分かるようにする（色だけに たよらない）:
   - れんが: 3 段の よこ長の かけら（まんなかの段は つぎ目が ずれる）。目地を 1 マス へこませる。
   - かまど: 石の 4 段。前の面に 3×3 の 口（2 マス へこみ、底は 火の色 `#E8AC78` → 本番で決める）。
   - かわら: 上の面に よこの 波（2 マスおきの 段）。
   - たんす: 木の色。前の面に 引き出しの みぞ（1 マス、たて 3 段）。
   - はたけ: つちより 1 段 暗い（いまの `farmland` の色）。上の面に たての うね（3 マスおきに 1 マス へこむ）。ぬれた はたけは さらに 暗く、うね の底を 少し青み に。
   - スプリンクラー: 青い灰色。人が作った物の きまり。
4. 世界に ピンク・真っ白・真っ黒 を使わない（6 章）。
5. 三角形を 下の 11 章の目安で たしかめる（`npm run perf` の voxel-looks）。

## 12. レビューの軽微な指摘（`docs/loop-ledger/VOX-1.md`）の 直し方の方針（まだ実装しない）

- **G1 木と草の形が マイクラに近い**
  - 木: 「みき 1 本＋四角い はっぱの箱」をやめ、**ジオラマの木**にする。みきは 下が広い（根もと 1 段だけ となりに 3×3 の根を はみ出させる＝根の ブロック）。はっぱは 箱を積むのではなく、大きさのちがう **まるい かたまり 2〜3 こ**（はっぱ ブロックの 3×3×3 の かたまりを かど 7 割・へり 4 割 けずって まるく）を ずらして重ねる。高さ・はっぱの数は 木ごとに かえる（世界を作る係＝ developer にたのむ形の表）。
  - 草ブロック: 「上だけ緑・横は土」の 2 層に見えないように、横の しばふ は 下のはしが ギザギザで（今あり）、崖の くちびる を まるく けずる（今あり）。さらに 横の しばふ の高さを 3×3 ごとに 2〜4 マスで かえ、たれさがる「草のすそ」にする。
- **G4 せきたん の黒い点が 遠くで 汚れに見える**
  - かたまり の色を 黒 → **こい むらさきがかった 灰色** `#4A4458` / 上の段 `#6E6684` に明るくする（2 段内より 明るく）。
  - かたまり は とび出す形にした（今回）。さらに 1 ブロックの かたまり の数を 4〜6 → 2〜3 こ に へらし、2 つを つなげて 大きく（3×6×3）する。遠くで「点」ではなく「すじ」に見えるように。
  - 遠くの 箱（3D テクスチャ）でも 同じ色になるので、本番の LOD の色も 合わせる（14 章 2）。
- **G5 水の色**
  - 水は 空と 草に合わせ、**少し みどりがかった 明るい青** `#4F9FD8`、すき通り 0.6（今と同じ）。あさい所（すな の上）は 明るい `#7EC3E6` に見えるよう、すなの色が すけることで出す（色を 2 つにしない）。
  - 水の面は たいら のまま（ごつごつ させない。「岩はごつごつ、水はなめらか」の 対比）。ゆらゆら 動かすなら ゆっくり（1 周 4 秒以上）、光の点滅はしない。
  - 実装には Look に水の色を足す必要がある（14 章 1）。

## 14. 本番への申し送り（範囲外。本番の作業で直す）
1. **水の色を Look で変えられない**: 水は `ProtoScene` の 平らな半透明（`0x2f6fe0`）のまま。`Look` に `water`（色・すき通り）を足す。
2. **遠くの LOD が ゲーム本体の色**: 上空の外がわ（かんたんメッシュ）は Look と関係なく 本体の色で、霧で なじませているだけ。B の 4 章の色に合わせる。上空では 近く（でこぼこで 暗く見える）と 遠く（たいら）の 明るさの差が 四角く見えるので、遠くの色は 外 1 と 1 段内 の あいだ にする。
3. **3D テクスチャと へこみの ずれ**: テクスチャは `exposed = ALL_FACES` で `fill` を呼ぶため、穴のマスは `base` 1 色になる。今は「ALL_FACES のときは 穴をあけない」で しのいでいる（6 面とも見える 宙に浮いた 1 個だけ へこまない）。`KindSpec` に 色だけを返す `color(x,y,z)` を足し、テクスチャは それで作る。
4. **世界のブロック以外の 仮の色**: かまど・かわら・れんが・たんす・はたけ・スプリンクラーは 色だけ（形は いしと同じ けずり）。10 章のきまりで アートが作り直す。
