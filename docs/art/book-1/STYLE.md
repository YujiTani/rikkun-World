## 2. 本の 形（3D）

- **本の 四角 ＝ 表紙・金具を ふくむ 外がわ**（仕様 §3.6）。1280×800 で 640×960（上 96・左 160）。表紙が 紙より はみだすのは 上下左右 **16px**（金具も この 16px の 中に おさめる。試作の ななめの 金具は 外へ 出たので やめる）。
- 紙の 1 ページ: 1024×700 で 389×508、1280×800 で 464×608、1440×900 で 524×688。紙の 内がわの ふち 24px。
- 表紙の あつみ 18px（画面の px と 同じ 単位。§6）、紙の たばの あつみ 20px（左右 それぞれ）。かどは 四角で よい（まるい かどは 札と ボタンで 出す）。

- **かげ**: 本の 下に まるい ぼかしの 板（右下へ 14・22 ずらす）。

### 3.1 札の アイコンが 白黒で 下じきに とける件の 直し方
試作では 明るい アイコン（かたな）が うすい 丸の 下じきの 上で 白黒にすると 消えかけた。
- アイコンには **1 ドットの こい ふち（`#3a2614`）** を つける（挿絵の アイテムと 同じ `outline()`。拡大後は 3〜4px）。
- 下じきの 丸は `#efe2c4` ＋ 金の ふち 2px。ふちで 分かれるので、明るい 絵も こい 絵も 下じきと とけない。
- 確かめ: ② の スクショを 白黒に して、12 この アイコンが ぜんぶ 形で 見えること。

## 4. 動き（長さは オーナーが 試作で 決める）
- あらわれる: とじた本が まんなかに（0.82 倍・上を 奥へ 0.4 ラジアン かたむけ）→ ひらきながら 1 倍・かたむき 0 へ。
- ひらく: 表紙（左の まとまり）が とじ目を じくに 180° 回る。**厚紙は まがらない**（まっすぐのまま ぱたん）。
- めくる: 紙 1 まい（あつみ 4）が 同じく まっすぐのまま 回る。
- ゆれ: 本全体が 左右に 1 回。強い 点滅なし。

**作り方（仕様が かわっても 回しなおすだけ）**
- 1 項目の 組み立ては **`docs/art/book-1/tools/scenes.py` の 1 か所**（id ごとの 部品の ならび）。部品の 描き方は `book_px.py`。
- **キーの 字は ゲームの 割り当てから**: `src/input/actions.ts` の `DEFAULT_KEY_BINDINGS`（マウスは `DEFAULT_MOUSE_BINDINGS`）を 書き出して、部品 `key`（行動の 名前 例 `jump`）・`move4`・`keyrange`・`mouse`（`primary`／`secondary`）が その キー・ボタンを 描く。キーを かえたら 何も なおさずに 回しなおすだけ。アイテムの 絵も ゲームの 絵を その つど 書き出す。
- 回し方（リポジトリの 中だけで できる）:
  ```
  node docs/art/book-1/tools/build_book_art.mjs              # public/book/ の 40 まいを 作りなおす
  node docs/art/book-1/tools/build_book_art.mjs <フォルダ> move-walk   # 1 まいだけ 別の 場所へ
  ```
  中で やること: vite の 開発サーバーを 立てて `export.html`（`export_assets.ts`: アイコン・タイル・マウス・まきもの・妖怪の 3D の 形・キーの 割り当て）を Playwright の Chromium で 開き、`node_modules/.cache/book-art/` に 書き出す → `compose_book_art.py` が `scenes.py` を 読んで 組む。いるもの: `npm ci` ずみ・python3 と Pillow。
- 新しい 項目（パリィ など）は `scenes.py` に 1 行 足して 回しなおす。見本の シートは 自分で 見てから 渡す（rules D）。

**PNG に した わけ**（コードの ドット絵に しない）: 道具で いつでも 作りなおせるので、ゲームの 中で 描く コードを ふやさない。40 まいで 約 150KB、③ を ひらいたときに その 1 まいだけ 読めば よい。

## 6. 3D の 作り方の 要点（developer 用。試作 `/home/claude/book-proto/src/ui/bookProto.ts`）

- **px と 同じ 単位にする**: `PerspectiveCamera(fov 30)` を z ＝ (画面の 高さ ÷ 2) ÷ tan(15°) に 置いて 原点を 見る。こうすると z ＝ 0 の 面の 1 単位が 画面の 1px に なり、紙の 上の 面（z ＝ 0）に HTML を ぴったり かさねられる（仕様 AC17 の ずれ 2px 以内）。本の まんなかの 画面の 位置へ グループを ずらす（y は 上が ＋ なので `400 − 中心の y`）。
- **紙の たば**: 左右 1 つずつ `BoxGeometry(ページの はば, 高さ, あつみ)`。材料は 6 面の 配列で、上の 面（`pz`、配列の 4 番）だけ `MeshBasicMaterial`（紙の 色が 光で かわらず、字との 明るさの 比が はかった とおりに なる）、横の 面は あつみの すじの 絵の `MeshLambertMaterial`（横向きの 面 `px/nx` と 上下の 面 `py/ny` で すじの 向きを かえた 2 まい）。
- **表紙**: 左右 1 まいずつ、紙より 16 大きい 箱を 紙の 下に。外がわの 絵は 下の 面（`nz`、配列の 5 番）。左の 表紙と 左の 紙を 1 つの グループに 入れ、とじ目（x ＝ 0）を じくに `rotation.y` を π → 0 に すると ひらく。`nz` の 絵は 回したあと 正しい 向きに 見えるので **反転しない**（試作で 反転して さかさまに なった）。
- **ひらく 途中**: 本全体の グループで `rotation.x = −0.4×(1−e)`、`scale = 1 − 0.18×(1−e)`、`position.x = −(ページの はば ÷ 2)×(1−e)`（とじた本を まんなかに）。e は ease-in-out。
- **光**: `HemisphereLight(0xffffff, 0x666677, 1.6)` ＋ 左上奥から `DirectionalLight(1.4)`。
- **描く 回数**: 止まっている間は 描かない（仕様 §2.2b）。動きの 間だけ `render()`。後ろの ゲームは 描きなおさない。試作の 案 C で 描画 35 回・三角形 626（宝石の 円柱と わが 大半）。同じ 材料の 金具を 1 つに まとめれば 描画は 15 回くらいに へる。
- 本は 自分の `WebGLRenderer`（`alpha: true`）で ゲームの 上に かさねた。ゲームの renderer に 入れるかは 開発が 決める（そのときも 止まっている間は 描かない）。
- 表紙・紙の 絵は canvas で 作る（試作の `coverTex`・`paperTex`・`edgeTex`）。とじたら `dispose()`。
- ボタン・札は HTML（ふつうの `<button>`）。動きの 間は かくす。
